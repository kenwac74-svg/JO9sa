JO9 UI_overhaul_SNKmod
버전 0.1

Jack-o-nine-tails 2.3.2.5 한국어판용 UI 패치입니다.
메인 UI와 개인실 UI, 개인실 식단·착유·출산 연결을 포함한 누적 배포본입니다.

[처음 설치]
기존 UI 패치나 백업 폴더가 없는 순정 게임에 설치할 수 있습니다.
1. 게임을 종료하고 이 압축파일을 별도 폴더에 풉니다.
2. APPLY.cmd를 실행하여 게임의 game/jack.qsp를 선택합니다.
3. 설치기가 변경 전 파일을 game/_JO9_SNKmod_STATE에 자동 백업한 뒤 적용합니다.
사전에 백업 폴더를 만들거나 이전 테스트 패치를 설치할 필요가 없습니다.
설치 후 생성된 백업 폴더는 복원에 필요하므로 보관하세요.

[파일과 복원]
- UI 이미지는 game/content/pic/SNKmod에 설치합니다.
- jack.qsp, css/base.css, json/menu_icon.json과 조건에 맞는 engine/jack.exe를 적용합니다.
- 캐릭터·일반 배경 원본 이미지와 세이브는 수정하지 않습니다.
- CHECK.cmd: 설치 계획 확인.
- RESTORE.cmd: 설치 기록에 따라 변경 파일을 설치 전 상태로 복원.
- SNKmod 이미지 폴더만 수동 삭제하지 마세요.
- 설치 후 파일이 바뀌었다면 해당 파일을 알리고 Y/N을 묻습니다.

[기존 설치본]
이전 SNKmod 테스트판 설치 기록도 인식합니다.
업데이트 시 기존 기록으로 먼저 복원한 뒤 적용합니다.
다른 QSP 수정 모드는 동일한 본문을 덮어쓸 수 있어 호환을 보장하지 않습니다.
기존 모드의 백업이 없다면 이미 덮어쓴 원본 파일을 새로 복구할 수는 없습니다.

[개인실]
- 식사 설정 → 보상 → 씻기 → 조건부 모유 착유 순서입니다.
- 처벌·처분·청소·음식 준비·안개 괴물 착정은 개인실에서 제공하지 않습니다.
- 임신 150일 이상이면 기존 출산 이벤트를 호출하고 같은 개인실로 복귀합니다.
- 출산비 500 스파크 및 비용 부족 시 원작 불이익 분기를 유지합니다.

이 배포본에는 개인 세이브, 테스트 세이브 및 기존 백업 폴더를 포함하지 않습니다.
