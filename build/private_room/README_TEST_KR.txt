우측 패널: 거주자 카드 → 닫을 수 있는 안내 → 주인공 카드.
빠른 행동: 식사 설정 / 보상 / 씻기. 주인공 하단 행동 버튼 없음.
기존 질문·칭찬·교육·성교육·가정교사 로직을 개인실 대상으로 연결했습니다.

복원
게임 종료 후 RESTORE.cmd를 실행하세요. 설치기가 만든 백업을 삭제하지 마세요.
R3 위에 설치한 경우 복원은 최초 SNKmod 설치 전 상태를 기준으로 합니다.
설치 이후 변경된 파일은 전체 목록을 표시하고 Y/N(예/아니요)으로 확인합니다.
Y는 변경본을 _JO9_SNKmod_STATE 내부 changed 폴더에 별도 보관한 뒤 계속합니다.
N은 파일을 바꾸지 않고 취소합니다. 설치와 복원 모두 동일하게 적용합니다.
