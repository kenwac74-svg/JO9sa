# 통합 WORKSHOP · 2.4.0.0 (2026-10-14)

현재 플레이 게임에 설치 완료. 수정 직전 백업 커밋 `6c0d8ec`, 복구 자료 `backups/workshop_before_20261014_074203.zip` 및 `docs/checkpoints/workshop_before_20261014_074203.json`.

## 사용

게임을 재실행하고 **Other → WORKSHOP**을 누른다. 열린 내부 브라우저 `http://127.0.0.1:3813/workshop`은 이미지 교체/대사 편집 탭을 제공한다. 다음 WORKSHOP 실행은 SHOW HTML 스냅샷을 갱신하며, 열린 통합창이 감지 결과를 받는다. 이미지 업로드·편집 목록과 대사 초안은 탭 이동 시 유지된다.

SHOW HTML에 표시된 대사/참고정보를 QSP 원문과 대조하고 실제 감지 이미지로 사용처를 구분한다. 여러 후보가 같거나 탐색 제한에 도달하면 자동 확정하지 않는다. 후보를 선택하거나 기존 검색을 이용한다. 작성 중인 대사, 페이지 추가, 미리보기, AI 응답 또는 요청 중 수동 선택은 자동 감지가 교체하지 않는다. 화면에 원문이 없으면 원문 없음으로 표시한다. HTML/QSP/세이브 코드는 실행하지 않는다.

이미지 탭은 해당 게임에 등록된 이미지 서버를 인증된 동일 출처 경로로 연결한다. 페이지 먼저 열기/포트 변경에도 CSP가 유지되고 기존 파일·폴더 선택기가 같은 출처에서 작동한다. 등록 PID 확인, GET 경로 제한, 세션 토큰, 동일 출처 검사를 적용한다. 추가 컷·체크리스트 연결은 기존 인증된 bridge를 사용한다.

## 변경과 증거

- QSP 버전 설정/표시 문자열: 9개 location의 `2.3.2.5` → `2.4.0.0`. 현재 bf7bc5e8 기준으로 공식 `apply_mods.ps1` 사용. 248개 location 왕복, 버전 외 문자열/행동 레코드 보존, 구문 오류 코드 증감 없음, 반복 적용 검증.
- Native menu: 기존 `Image Workshop` 데이터만 동일 길이의 `WORKSHOP`으로 변경. EXE 전체 길이/코드 오프셋 유지. `tools/patch-workshop-menu.py`는 확인된 원본/적용본 해시만 허용한다. EXE 자체는 기존 engine 내부 버전과 구분한다.
- 단위/HTTP 회귀 **19/19**. 실제 원문을 사용한 격리 브라우저에서 약국 이벤트 19914/17389행과 현재 이미지 2개 연결, 이미지 업로드 목록·대사 초안의 왕복 탭 유지 확인. 실제 설치 파일은 저장소와 바이트 일치, HTTP200/현재 게임 경로 확인.
- 독립 검수 3개 수정: 늦은 감지 응답의 초안 교체, 이미지 서버 후속 시작 시 CSP 차단, 잘린 후보의 잘못된 자동 확정. 각각 보호 검사·동일 출처 연결·불완전 탐색 자동 확정 금지로 해결.

정확한 해시: `records/workshop/2026-10-14-unified-workshop.json`.

## 사용자에게 남은 게임 점검

Native 게임 실행/메뉴 클릭은 저장소 규칙에 따라 사용자가 한다. 게임을 재실행하여 제목 2.4.0.0과 WORKSHOP 메뉴, 서로 다른 두 장면을 감지했을 때 이미지/대사가 함께 갱신되는지 확인한다. 실제 게임 SHOW HTML 입력은 아직 사용자가 검증하지 않았다. 기존 스냅샷에는 raw HTML이 없어 최초 화면은 다시 감지 안내가 정상이다.

## 복구 및 다른 PC

게임/도구를 종료하고 백업 ZIP의 game/ 하위 7개 파일을 실제 game 폴더 같은 상대 경로로 복원한다. 새 helper 파일은 복원한 구 서버에서 사용하지 않는다. 도구를 다시 시작하면 이전 UI/QSP/메뉴로 돌아간다. 원본 저장소와 이미지 폴더를 통째로 복사할 필요가 없다.

다른 PC에서는 기존 모딩 도구 실행기로 최신 소스를 설치하고, 실제 QSP에 버전 mod를 적용한다. 메뉴 helper는 확인된 engine 해시가 같을 때만 실행한다. 다르면 덮어쓰지 말고 먼저 분석한다. 기존 10월 13일 전달 ZIP은 그 시점의 보관본이며 이번 변경이 자동 포함되지는 않는다.

## 실행 계획 기록

Ruling: 이미 승인된 설계/구현 및 GitHub 기록 지시에 따라 별도 승인 질문 없이 현재 브랜치에 커밋·푸시한다. 새 PR/머지는 만들지 않는다.
Ruling: 페이지 먼저 열기와 브라우저 폴더 선택기의 같은 출처 요구를 해결하기 위해 안정된 인증 proxy를 사용한다. wildcard CSP를 추가하지 않는다.
Ruling: 탐색 비용 제한은 유지하되 후보가 잘렸을 때 자동 확정을 금지한다. 더 많은 후보는 수동 검색으로 좁힌다.

스킬 실행계획 Task 1-7 검증 완료. Task 8은 독립 검토 반영/기록 후 커밋·원격 ref 확인으로 마무리한다. 시험 서버/탭은 정리한다. 실제 게임 검증은 사용자 경계다.

## 창 제목 보완 (2026-10-14)

사용자 화면에서 창 제목이 여전히 2.3.2.5임을 확인했다. 이전 작업은 QSP 내부 버전 설정/표시를 수정했으나 `game/config.xml`의 title을 누락했다. engine은 config.xml과 `title="(.+)"` 패턴을 읽는다.

`tools/update-game-title.py`로 title을 `Jack-o-nine-tails 2.4.0.0 & Kor Ver`로 수정했다. UTF16LE BOM/188바이트/1280x800 크기/아이콘을 보존하고 버전 문자열만 동일 길이로 치환했다. 원래의 ampersand를 XML 파서로 재직렬화하지 않았다. 실행파일 해시는 그대로이다. 적용 전/후 해시와 백업은 `records/workshop/2026-10-14-game-window-title.json`에 있다. 새 PC의 메뉴/title 설치에도 이 helper를 함께 실행한다. 이미 실행 중인 게임의 제목은 재실행해야 새 값으로 표시된다.
