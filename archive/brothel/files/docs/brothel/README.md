# JO9 창관모드 문서 색인

이 폴더는 `brothel` 브랜치의 창관모드 기획·분석·프로토타입 문서를 보관한다.

## 문서 우선순위

1. 사용자의 최신 명시적 결정
2. 기능별 최신 상세 명세
3. 통합 확정사항 문서
4. 복원 기준 문서
5. 초기 v0.1 기획 자료

과거 문서와 최신 기능 명세가 충돌하면 최신 기능 명세를 우선한다.

## 현재 문서

- `NECRO_WING_SPEC_v0_2.md`
  - 네크로관의 최신 기준 명세
  - 이터널 로마의 고소득 특수 고객층, 사망 노예의 최종 상품화, 30일 운영, 해부극장·말리피센트 해금 퀘스트, 1,000 스파크 계약금, 상태·저장 구조
  - 부활·재사망·`REVIVED`·`death_sequence`를 제외
  - `NECRO_WING_SPEC_v0_1.md`의 충돌 부분을 대체

- `NECRO_WING_SPEC_v0_1.md`
  - 이전 네크로관 기능 초안
  - 저장 안정성 검토 이력 보존용
  - 부활·재사망 관련 항목은 폐기되었으며 구현 기준으로 사용하지 않음

- `BIFROST_COMPARISON_AND_DECISIONS.md`
  - 비프로스트 원형 비교, 고객·매칭·연장전·Trait·경제 설계

- `BROTHEL_DESIGN_RECOVERY.md`
  - 과거 대화와 기획서에서 복원한 창관모드 결정사항

- `PROTOTYPE_SPEC_v0_1.md`
  - 독립 수직 슬라이스 프로토타입 명세

- `QSP_INTEGRATION_STATUS.md`
  - 실제 QSP 통합의 준비 상태와 소스 버전 차이

## 현재 구현 상태

네크로관은 설계 명세만 확정된 상태이며 QSP에는 아직 구현되지 않았다. 실제 구현 전에는 `NECRO_WING_SPEC_v0_2.md`의 구현 전 확인사항을 원본 QSP에서 검증한다.
