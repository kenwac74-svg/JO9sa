# JO9 창관모드 — 네크로관 기능·설정 명세 v0.2

- 상태: **최신 기준 명세**
- 적용 브랜치: `brothel`
- 구현 상태: 미구현
- 우선순위: 사용자 최신 결정 > 이 문서 > `NECRO_WING_SPEC_v0_1.md`

## 0. v0.2 변경 요약

이 문서는 v0.1의 저장 안정성 구조를 유지하면서 다음을 바로잡고 확정한다.

- JO9에 존재하지 않는 **부활·재사망·`REVIVED`·`death_sequence`** 요소를 전부 제외한다.
- 네크로관의 핵심 설정을 다음 세 층위로 고정한다.
  - 세계관: 이터널 로마의 극단적 취향을 가진 부유층을 위한 비밀 고급 서비스
  - 플레이 동기: 사망한 노예의 남은 상품가치를 제한된 기간 동안 끝까지 회수
  - 콘텐츠 방향: 외형·능력·Trait·접객 이력·사망 상태와 사망 원인을 상품 정보로 활용
- 네크로관 Lv.1은 자동 구매가 아니라 **네크로폴리스 해부극장과 말리피센트의 해금 퀘스트**를 통해 개방한다.
- 말리피센트에게 지급하는 **1,000 스파크는 시설 건설비가 아니라 고객망·사업권 해금 계약금**으로 처리한다.

## 1. 핵심 설정

네크로관은 이터널 로마의 변태적이고 극단적인 성적 취향을 가진 고소득 고객층을 대상으로 하는 창관의 특별관이다.

사망한 노예의 육체와 생전 외형·능력·Trait·접객 이력·사망 당시 상태·사망 원인을 상품 정보로 등록하고, 사망일을 포함한 30일 동안 제한적으로 영업한다.

플레이어는 노예가 사망하면서 잃게 된 장기 가치의 일부를 마지막까지 회수한다. 네크로관은 죽음의 손실을 없애는 시설이 아니라, 손실이 확정된 뒤 남은 가치를 냉혹하게 수익화하는 후속 시설이다.

### 1.1 표현 원칙

- 영혼·강령술·부활·저주를 전제로 하지 않는다.
- 사망자가 반응하거나 의식을 유지하는 것처럼 서술하지 않는다.
- 추모·애도보다 상품성·소유권·기간·가격·희소성을 중심으로 쓴다.
- 잔혹함은 과장된 공포 묘사보다, 이런 서비스를 정상적인 사업처럼 계약·등록·정산하는 이터널 로마의 태도에서 드러낸다.
- 네크로관의 고객은 단순한 기괴한 인물이 아니라 돈과 권력을 가진 고소득 특수 고객층이다.

## 2. 기능 기준표

| 항목 | 기준 |
|---|---|
| 사용 가능 기간 | 사망일 포함 30일 |
| 기간 계산 | `available_until = death_day + 29` |
| 기간 만료 | 기록 보존, 배치 불가, 배치 중이면 자동 해제 |
| 구형 세이브 | 최초 변환일을 임시 사망일로 지정하고 30일 전부 보장 |
| 시설 해금 | 창관 Lv.4 / Lv.7 / Lv.10에서 네크로관 Lv.1 / 2 / 3 |
| 슬롯 | 시설 레벨별 1 / 2 / 3명 |
| 건설비 | 같은 레벨 시설 기준비의 150%, 올림 |
| 유지비 | 같은 레벨 시설 기준비의 125%, 올림 |
| 운영 제한 | 슬롯 하나당 영업 페이즈 기본 1회 사용 |
| 체력·정신력·행동력 | 사용하지 않음 |
| 기록 삭제 | 자동 삭제하지 않고 사망 기록부에 계속 보존 |
| Lv.1 추가 해금비 | 말리피센트 계약금 1,000 스파크 |

`1,000 스파크`는 네크로관 건설비를 대체하지 않는다. 퀘스트 완료와 특수 고객 소개망을 여는 일회성 계약금이며, 지급 후 네크로관 Lv.1 건설 메뉴가 해금된다.

## 3. 해금 퀘스트 — 해부극장의 특별 제안

### 3.1 퀘스트 목적

해금 퀘스트는 다음 세 사실을 플레이어에게 직접 보여준다.

1. 이터널 로마에는 일반 창관으로 만족하지 못하는 부유한 변태 고객들이 존재한다.
2. 네크로관은 이 고객층을 대상으로 하는 고수익 특수 서비스다.
3. 말리피센트는 고객을 소개할 유통망과 인맥을 가지고 있으며, 플레이어는 그 사업권을 돈으로 산다.

### 3.2 선행 조건

- 창관 Lv.4 이상
- 네크로폴리스의 해부극장 이용 가능
- 네크로관 해금 퀘스트 미완료
- 해부극장의 **기존 요구사항을 충족하는 노예** 제공

해부극장이 요구하는 노예 조건과 기존 처리 결과는 원본 게임 규칙을 그대로 사용한다. 네크로관 퀘스트 때문에 해부극장의 기존 판정이나 노예 처리 결과를 바꾸지 않는다.

### 3.3 진행 흐름

```text
해부극장 요구조건에 맞는 노예 제공
→ 말리피센트가 해부 공연 관람을 권유
→ [거절한다] / [관람한다]
→ 관람을 선택하면 기존 해부 공연 진행
→ 공연 종료 후 말리피센트의 특별 사업 제안
→ 1,000 스파크 계약금 요구
→ 지급하면 네크로관 Lv.1 건설권과 특수 고객 소개망 해금
```

### 3.4 첫 번째 선택: 공연 관람

#### 거절한다

- 해부극장의 기존 노예 처리와 보상은 그대로 진행한다.
- 네크로관 퀘스트는 진전되지 않는다.
- 퀘스트는 영구 실패하지 않는다.
- 이후 다시 해부극장의 요구조건에 맞는 노예를 제공하면 말리피센트가 관람을 다시 제안할 수 있다.

#### 관람한다

- 기존 해부 공연 이벤트를 실행한다.
- 공연 종료 후 퀘스트 단계를 `CONTRACT_PENDING`으로 전환한다.
- 이후 말리피센트가 특수 고객층과 네크로관 사업을 제안한다.

### 3.5 말리피센트의 제안

말리피센트는 해부 공연을 본 플레이어에게, 공연이 끝난 뒤에도 더 극단적인 서비스를 원하는 부유 고객들이 존재한다고 설명한다.

플레이어가 자신의 창관에서 그 취향을 충족할 별도 시설을 마련한다면, 말리피센트는 해당 고객들을 소개하겠다고 제안한다.

그 대가로 말리피센트는 **1,000 스파크**를 요구한다.

이 금액의 설정상 의미는 다음과 같다.

- 특수 고객 명부 접근권
- 말리피센트의 소개와 신용 보증
- 네크로폴리스와 창관 사이의 비공개 사업 연결
- 네크로관 영업권을 여는 일회성 계약금

### 3.6 두 번째 선택: 계약금 지급

#### 1,000 스파크를 지불한다

- 플레이어 스파크 `-1000`
- 퀘스트 상태 `UNLOCKED`
- 시설 관리의 `특별관 → 네크로관 Lv.1` 건설 메뉴 표시
- 말리피센트의 특수 고객 소개망 활성화
- 실제 영업은 네크로관 Lv.1을 별도로 건설하고 운영 상태가 `ACTIVE`가 된 뒤 시작

#### 나중에 지불한다 / 스파크가 부족하다

- 퀘스트 상태 `CONTRACT_PENDING` 유지
- 공연을 다시 볼 필요 없음
- 다른 노예를 다시 제공할 필요 없음
- 이후 해부극장에서 말리피센트에게 1,000 스파크를 지급하면 즉시 해금

이는 이미 노예 제공과 공연 관람이라는 비가역적 단계를 완료한 플레이어에게 같은 비용을 반복 요구하지 않기 위한 규칙이다.

### 3.7 권장 퀘스트 상태

```text
LOCKED
→ SHOW_OFFERED
→ CONTRACT_PENDING
→ UNLOCKED
```

| 상태 | 의미 |
|---|---|
| `LOCKED` | 선행 조건 미충족 또는 공연 미관람 |
| `SHOW_OFFERED` | 적격 노예 제공 후 공연 관람 선택 대기 |
| `CONTRACT_PENDING` | 공연 관람 완료, 1,000 스파크 지급 대기 |
| `UNLOCKED` | 계약금 지급 완료, 네크로관 Lv.1 건설권 해금 |

거절은 `LOCKED`로 돌아가며 영구 실패 상태를 만들지 않는다.

### 3.8 Lv.2·Lv.3 확장

- Lv.1: 위 해부극장 퀘스트와 1,000 스파크 계약이 필수
- Lv.2: 창관 Lv.7 도달 후 시설 강화 가능
- Lv.3: 창관 Lv.10 도달 후 시설 강화 가능

Lv.2·Lv.3은 우선 별도 해금 퀘스트 없이 레벨 조건·강화비·유지비로 확장한다. 후속 퀘스트가 필요해질 경우 말리피센트의 고객망 확대 계약으로 추가할 수 있으나, v0.2 필수 범위에는 포함하지 않는다.

## 4. 권장 대사·지문 초안

대사는 공포나 도덕적 충격보다 말리피센트의 사업가적 태도와 이터널 로마의 퇴폐 시장을 드러내야 한다.

### 공연 전

> 말리피센트는 해부대 쪽을 가리켰다.  
> “물건을 넘기고 바로 가도 상관없어. 하지만 창관을 운영한다면 이번 공연은 보고 가는 편이 좋을 거야.”

선택지:

- `공연을 관람한다`
- `관람하지 않는다`

### 공연 종료 후

> 공연이 끝나자 말리피센트는 관객석에 남아 있던 몇몇 손님을 눈으로 가리켰다.  
> “저들 중에는 공연이 끝난 뒤부터가 진짜라고 생각하는 자들이 있어. 돈은 많고, 평범한 창관으로는 만족하지 못하지.”

> “네 창관에 그들을 받을 시설을 마련해. 손님은 내가 보내주지. 명부와 소개를 여는 값은 1,000 스파크다.”

선택지:

- `1,000 스파크를 지불한다`
- `나중에 이야기한다`

### 해금 결과

> 말리피센트는 스파크를 확인한 뒤 고객 명부 일부와 시설 등록 조건을 넘겼다.  
> 특별관에 `네크로관` 건설 항목이 추가되었다.

이 대사는 구현 시 기존 말리피센트 말투와 해부극장 문체를 원본 QSP에서 확인한 뒤 조정한다.

## 5. 사망 기록 구조

부활과 재사망을 전제로 하지 않는다.

```text
death_record
├─ death_record_id
├─ character_id
├─ name
├─ portrait_path
├─ death_day
├─ death_cause
├─ owner_id
├─ body_state
├─ record_state
├─ available_until
├─ assigned_slot_index
├─ eligibility_reason
├─ migration_source
├─ snapshot
└─ data_version
```

- `death_record_id`: 원본 캐릭터 데이터가 삭제된 뒤에도 기록을 식별하는 단순 고유값
- `character_id`: 원래 캐릭터와의 참조
- 사망 기록은 캐릭터당 한 번 생성
- `death_sequence`, `REVIVED`, 재사망 관련 필드는 사용하지 않음

### 5.1 상태 모델

```text
AVAILABLE → ASSIGNED → EXPIRED
     │          │
     ├──────────┼→ SOLD
     └──────────┴→ LOST
```

| 상태 | 의미 |
|---|---|
| `AVAILABLE` | 기간·소유권·육체 상태가 유효하고 배치 가능 |
| `ASSIGNED` | 네크로관 슬롯 배치 중 |
| `EXPIRED` | 30일 사용기간 만료 |
| `SOLD` | 판매 또는 소유권 이전 |
| `LOST` | 도축·소각·육체 소실 |

시설 유지비 미납은 사망 기록 상태가 아니라 별도 `facility_state = SUSPENDED`로 처리한다.

## 6. 플레이 경험 기준

네크로관은 일반 창관보다 고객 수는 적지만 고객 한 명당 기대수익이 높은 특수관으로 설계한다.

일반 창관이 행동력·회복·성장·반복 고객 관리가 중심이라면, 네크로관은 다음 선택이 중심이다.

- 제한된 1~3개 슬롯에 어떤 사망자를 배치할지
- 남은 30일 중 언제 영업에 투입할지
- 높은 유지비를 감수할 가치가 있는 상품인지
- 생전 외형·Trait·능력·지명 이력을 어떤 고객 요구와 맞출지
- 새 고등급 사망자가 생겼을 때 기존 배치를 해제할지
- 기간 만료 전에 마지막 영업을 할지

네크로관의 핵심 플레이 동기는 **사망한 노예를 끝까지 활용해 투자 손실을 일부 회수하는 비정한 경영 판단**이다.

## 7. 구현 전 확인사항

1. 네크로폴리스 해부극장의 정확한 location과 말리피센트 대사 분기
2. 해부극장이 요구하는 노예 조건과 제공 후 기존 처리 순서
3. 기존 공연 이벤트의 진입·복귀 지점
4. 1,000 스파크 차감에 사용할 실제 화폐 변수와 공통 결제 함수
5. 창관 Lv.4 판정 변수
6. 시설 관리 메뉴에 새 건설 항목을 노출하는 안전한 분기
7. 공연 거절 후 다음 적격 노예 제공 시 재제안 가능한지
8. `CONTRACT_PENDING` 상태에서 반복 결제가 발생하지 않는지
9. 저장·불러오기 후 퀘스트 단계와 해금 상태가 유지되는지
10. 해금비 1,000 스파크와 별도 건설비가 UI에서 혼동되지 않는지
