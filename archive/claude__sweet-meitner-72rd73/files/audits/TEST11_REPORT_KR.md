# 개인실 TEST11 검수

TEST10 누적 내용에 다음 수정 사항을 반영했다.

- 종합정보 진입을 화면 전환(GT)에서 기존 화면 위 렌더링(GS)으로 변경했다. 개인실 경로에서는 원작 main_layout을 실행하지 않는다.
- 원작 종합정보 내용은 현재 개인실 인물로 표시한다. 조회 때문에 인물을 임시 교환하지 않는다. 보상 하위 메뉴에서는 이미 연결된 개인실 대상을 사용한다.
- 종합정보 하단 사진과 사진 클릭 영역을 제거했다. 책 우하단 접힌 모서리에 32×32 닫기 X를 배치했다.
- 새 닫기 버튼은 현재 화면을 다시 표시한다. TEST10의 단일행 조건문 닫기 링크를 제거했다.
- 초상화 마법 표시는 오른쪽 가장자리를 초상화 안쪽 우하단에 고정했다. 글자 폭과 무관하게 오른쪽을 정렬한다.
- 팝업 내용의 줄간격을 명시하여 정보 열과 설명문이 겹치지 않게 했다.

## 검증

- 정적 검사 13/13 통과.
- QSP 5.8 별도 실행: 실제 패키지 종합정보 본문과 bridge 실행. 개인실 1~4에서 기존 화면 문자열이 남는지, 원작 레이아웃 초기화가 발생하지 않는지, 대상 인물 유지, 심리 상태 문자열 보존 확인.
- 실제 출력된 X 버튼의 EXEC 코드를 추출·실행해 팝업만 사라지고 해당 개인실로 유지되는지 확인.
- 보상 하위 메뉴에서도 팝업 닫기 후 메뉴 15와 대상 방 번호가 유지되는지 확인.
- 브라우저 배치: 기존 개인실 UI 유지, 닫기 버튼 클릭 영역이 레이어에 가려지지 않음, 마법 표시 오른쪽 좌표 990, 이미지 누락 0. 미리보기는 실제 게임 캡처가 아니다.
- 설치기 검사 43/43 통과. 이후 CSS 줄간격만 조정했고 최종 패키지 업그레이드·복원을 재검증한다.
- TEST10→TEST11의 246개 QSP 본문 설치와 최초 설치 이전 파일 해시 복원 검사는 test11-upgrade.log 참조.

실제 FastQSP 앱에서 사용자 세이브로 진행하는 플레이 검증은 미실시. G: 게임에 직접 설치하지 않았다.
