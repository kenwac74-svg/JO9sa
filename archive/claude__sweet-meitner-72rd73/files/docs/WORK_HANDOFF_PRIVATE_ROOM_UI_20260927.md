## 0. 시작 규칙

Work는 반드시 `JO9UIpatch` 브랜치 HEAD에서 시작한다. 먼저 `README.md`, `docs/UI_PATCH_HANDOFF.md`, `docs/context-notes.md`, `docs/checklist.md`, `docs/ASSET_INSTALL_POLICY.md`를 읽고 기존 SNKmod 설치/복구 정책을 보존한다.

이번 작업의 목적은 **개인실 UI 정리**다. 개인실 게임플레이 기능 확장은 후속 작업이다. EXE/엔진 아키텍처, generic Actor 구조, slave/assistant/room 전체 리팩터링은 하지 않는다.

완료 정의:

> 개인실을 메인 UI와 일관된 화면으로 정리하고, 특별대우 상태와 맞지 않는 UI는 비활성/숨김 처리하며, 중앙부를 향후 개인실 고유 기능을 위한 공간으로 확보한다.

## 1. 개인실 의미

개인실은 별도 직업/작업 역할이 아니라 **휴양/특별대우 상태**다.

UI 판단 원칙:
- 정보 조회: 유지
- 대화/칭찬/씻기 등 특별대우와 모순되지 않는 기능: 유지
- 압박/사회화/처벌/처분: 구조상 버튼은 남기되 비활성
- 청소/요리 등 업무: 개인실에서는 숨김
- 개인실 전용 신규 기능: 중앙 전용 영역에만 배치

## 2. 우측 패널 구조

### 개인실 노예 카드
메인 UI 노예 카드와 동일한 구조를 사용한다. 별도 개인실용 캐릭터 카드 디자인을 만들지 않는다. 차이는 활성/비활성/숨김 상태만 둔다.

### 중앙 공간
기존 개인실 중복 상세정보 영역은 제거한다. 중앙을 개인실 전용 명령/안내 영역으로 확보한다. 이번 패치에서는 안내 토글과 식사 설정 버튼만 둔다.

### 주인공 카드
유지: 네임바, 초상화, 행동력 바, 상태 텍스트, 우측 정보.  
제거: **행동력 바 아래 기존 주인공 동작 버튼 행 전체**. 버튼 틀도 남기지 않는다. 확보 높이는 중앙 공간에 사용한다.

## 3. 초상화 4귀퉁이 — 확정

메인 UI와 개인실 UI 양쪽에 동일 적용.

| 위치 | 정보 |
|---|---|
| 좌상단 | Ill — 질병 |
| 우상단 | Wound — 상처 |
| 좌하단 | 등급(S+, A+, C+ 등) |
| 우하단 | 문신/마법/인장/없음 등 표식 |

Ill/Wound는 상태가 있을 때만 표시한다. 기존 작은 아이콘을 단순 확대해 흐리게 만들지 말고, 표준 버튼 영역 안에 원본 아이콘을 중앙 정렬하는 방식을 우선한다.

## 4. 임신/생식 슬롯

임신은 초상화 모서리에 넣지 않는다. 기존 정보열의 **생식상태 1개 슬롯**에서 상태별로 교체 표시한다.

- 평시 → `Fer_Normal.png`
- 안전일 → `Fer_PregS.png`
- 배란기 → `Fer_PregO.png`
- 임신중 → `Preg_s.png`
- 불임 → `Fer_PregX.png`

기존 fertility/ovulation/pregnancy 판정은 보존한다. 새로운 생식 시스템을 만들지 않는다.

## 5. 개인실 노예 빠른 동작

행동력 바 아래:
- 보상/칭찬: 활성
- 씻게 한다: 활성
- 처벌: **회색 비활성**
- 청소하기: **숨김**
- 음식 준비하기: **숨김**

처벌은 삭제하지 않는다. 툴팁 의미:
> 개인실에서 특별 대우 중인 노예는 처벌할 수 없습니다.

## 6. 활동지시/회화 메뉴

원작 활동지시 메뉴를 재사용한다.

활성 유지:
- 회화한다
- 섹스한다
- 교육 활동
- 성교육
- 가정교사
- 칭찬

비활성:
- 처벌
- 처분

공통 의미:
> 개인실에서 특별 대우 중인 노예는 처벌 또는 처분할 수 없습니다.

회화 하위:
- 질문: 활성
- 영향 주기: 비활성
- 사회화: 비활성

툴팁 의미:
- 영향 주기: `개인실에서 특별 대우 중인 노예에게는 영향력을 행사할 수 없습니다.`
- 사회화: `개인실에서 특별 대우 중인 노예에게는 사회화 교육을 지시할 수 없습니다.`

큰까마귀 관/아우스펙스 조건으로 네임바에 나타나는 **노예 정보보기 버튼은 그대로 유지**한다.

## 7. 개인실 안내 레이어

중앙 빈 공간에 별도 텍스트 열을 만들지 않는다.

### 열기 버튼
기존 리소스 사용:
`game/content/pic/buttons/debug_button.png`

이 버튼으로 안내 레이어를 열고 닫는다.

### 안내 레이어
- 중앙 공간과 같은 크기의 독립 overlay
- 별도 텍스트 컬럼 금지
- **투명 PNG 한 장에 텍스트를 이미지로 올리는 방식**
- 닫기 버튼은 기존 close 계열 재사용
- 평상시 숨김, debug_button 클릭 시 표시/숨김
- 다른 UI 레이아웃/스크롤에 영향을 주지 않게 구현

표시 내용 요약:
- 메인 UI 캐릭터 카드 구조를 개인실에도 통합
- 초상화 4개 모서리에 핵심 상태정보 배치
- 임신/생식 상태를 기존 정보 슬롯에 통합
- 개인실에서 허용되는 노예 행동만 활성화
- 주인공 카드 하단 동작 버튼 제거

우하단에 반드시 작게:
> `개인실 추가 기능 개발 중 by SAnk`

권장 신규 리소스:
`game/SNKmod/content/pic/ui/private_room_notice.png`

## 8. 식사 설정 버튼

기존 음식 준비하기 버튼과 혼동하지 않도록, 사용자가 승인한 **원형 접시 + 포크/스푼 + 어두운 배경 + 황동 프레임** 디자인을 사용한다.

현재 대화에서 승인된 이미지를 기준으로 기존 표준 액션 버튼과 같은 최종 픽셀 크기로 정리한다.

권장 파일명:
`room_diet.png`

권장 경로:
`game/SNKmod/content/pic/buttons/room_diet.png`

동일 파일명 충돌이 있으면 임의 덮어쓰지 말고 비충돌 이름으로 바꾸고 기록한다.

이번 UI패치에서는 **신규 식단 게임플레이 효과를 구현하지 않는다.** 버튼/배치가 핵심이다. 기존 로직을 깨지 않고 최소 연결이 가능할 때만 원작 식사 UI를 재사용한다. 특별식단의 신규 효과/장기 밸런스는 후속 작업이다.

## 9. 개인실에서 숨길 업무 UI

개인실 화면에서 다음 업무성 UI를 제거한다.
- 청소 메이드
- 요리 메이드
- 주인 목욕 메이드
- 촉수/안개괴물 착정
- 개인실 매춘

이번 UI패치의 핵심은 **표시 제거**다. 일반 상태의 내부 rule 값이나 전체 기능을 파괴하지 않는다.

## 10. 원작 잠자리 명칭 충돌

원작 `sleep_condition = 2`의 표시명:
`개인실` → **`개인 침대`**

내부 값과 기존 수치 효과는 그대로 유지한다.

설명 의미:
> 그녀만을 위해 배정된 편안하고 부드러운 개인 침대는 노예의 기분을 좋게 만들어준다. 충성스럽고 복종하는 노예에게 어울리는 특별대우이지만, 그렇지 않은 노예는 응석을 부릴 수 있다.

중복 정의가 있으면 표시 문구를 모두 일관되게 수정한다.

## 11. 개인실 전용 텍스트 — 이번 패치에서는 보류

후속 기능 개발 규칙만 보존한다.
- 로직/판정/CG는 원작 최대 재사용
- 개인실 문맥 때문에 대사가 어색한 이벤트는 텍스트만 개인실 분기
- 특히 섹스 이벤트는 장면/CG 공유, 대사만 별도 분기
- 초기에는 원작에서 가장 가까운 텍스트를 복사
- 복사한 개인실 전용 문장 맨 끝에 **`#개인실`** 태그를 붙여 나중에 일괄 수정

이번 UI패치에서 섹스 엔진을 복제하지 않는다.

## 16. QA 중점

- Ill/Wound가 얼굴/등급/표식과 겹치지 않는가
- Ill+Wound 동시 표시가 정상인가

- 개인실 1~4가 모두 같은 규칙인가
