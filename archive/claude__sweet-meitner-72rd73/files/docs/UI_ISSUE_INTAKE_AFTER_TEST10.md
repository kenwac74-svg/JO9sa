## 2. 초상화 우하단 마법 표시 위치

상태: 접수. 현재 문제 접수 흐름에 따라 수정·빌드는 보류한다.

사용자 관찰: 개인실 캐릭터 카드의 초상화 위에 있는 '마법' 표시가 우하단 귀퉁이보다 안쪽에 위치한다.

수정 기준:
- '마법' 표시를 캐릭터 초상화 프레임의 우하단 귀퉁이에 맞춘다. 카드 전체나 화면의 우하단을 기준으로 삼지 않는다.
- 표시의 오른쪽·아래쪽 여백을 초상화 프레임 기준으로 정렬하고 테두리를 가리지 않도록 한다.
- 창 크기나 표시 문구 폭에 따라 위치가 밀리지 않도록 확인한다.
- 초상화 크기, 좌하단 등급, 행동력 바, 하단 기능 버튼 위치는 유지한다.

## 1. 종합정보는 개인실 위의 팝업 레이어로 표시

상태: 접수. 이번 요청은 기록만 수행하며 코드 수정·빌드하지 않는다.

사용자 관찰: 종합정보 버튼을 누르면 개인실 배경·캐릭터·좌측 메뉴·우측 카드·하단 설명이 사라지고, 별도 레이아웃 위에 종합정보만 표시된다.

추가 사용자 관찰: 종합정보 창 우하단의 사진은 원작 닫기 버튼인데, TEST10에서는 눌러도 아무 반응이 없다.

최신 디자인 변경: 사진이 닫기 버튼이라는 점을 알아보기 어려우므로 사진을 제거한다. 기존 사진 버튼 복구 요구는 아래의 명확한 닫기 버튼으로 대체한다.

확정 요구사항:
- 종합정보는 화면 전환이나 별도 창이 아니라 현재 개인실 위에 뜨는 팝업이다.
- 개인실 배경, 캐릭터, 좌측 메뉴, 우측 카드와 네임바 버튼, 하단 설명 및 1층 귀가 버튼을 유지한다.
- 종합정보 내용과 책 모양 원작 디자인은 재사용하고 조회 대상은 현재 개인실 인물로 유지한다. 하단 사진 닫기 부분은 최신 요구대로 변경한다.
- 종합정보 팝업은 개인실의 일반 UI보다 높은 레이어에 표시한다. 이전 사용자 지시인 툴팁 최상위 정책도 유지한다.
- 닫으면 팝업만 사라지고 같은 개인실 화면과 상태를 유지한다. 1층 이동이나 다른 인물로의 변경이 없어야 한다.
- 종합정보 하단의 사진 및 기존 사진 클릭 영역을 제거한다.
- 책 모양 정보창의 우하단, 책장이 접힌 효과가 있는 모서리에 닫기 버튼을 배치한다. 화면 전체의 우하단이 아니라 팝업 책 프레임을 기준으로 한다.
- 기존 UI와 어울리는 명확한 닫기(X) 버튼과 '닫기' 툴팁을 사용하며, 정보 본문을 가리지 않도록 한다.
- 새 닫기 버튼을 누르면 팝업만 닫히고 뒤의 개인실 UI를 계속 사용할 수 있어야 한다. 기존 클릭 무반응도 함께 해결한다. 원인은 추후 조사하며 지금 확정하지 않는다.
- 초상화 정보창·소지품창 정책으로 임의 확대하지 않는다. 이번 신고 대상은 종합정보 버튼이다.
