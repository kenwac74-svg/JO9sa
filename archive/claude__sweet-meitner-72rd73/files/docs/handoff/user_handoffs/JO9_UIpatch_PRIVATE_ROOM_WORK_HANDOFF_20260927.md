# 1. 이번 패치의 완료 정의

이번 패치의 개인실 작업은 다음 한 문장으로 정의한다.

> **개인실을 메인 UI와 일관된 화면으로 정리하고, 특별대우 상태와 맞지 않는 UI는 비활성/숨김 처리하며, 중앙부를 향후 개인실 고유 기능을 위한 공간으로 확보한다.**

이번 패치에서 완료해야 하는 것은 **UI 구조, 표시, 버튼 상태, 레이어, 아이콘 재배치**다.

다음은 후속 기능 개발로 남긴다.

- 특별식단의 실제 신규 효과/밸런스
- room1~4용 범용 interaction adapter 확장
- 개인실 전용 섹스 텍스트 본개발
- 조수의 개인실 배치 확장
- 다수 노예 운영 구조 확장
- 개인실 전용 신규 게임플레이 시스템

기존 기능을 유지하기 위해 꼭 필요한 최소 연결 외에는 기능 개발을 이번 패치에 끌어오지 않는다.

# 2. 개인실의 의미 — UI 판단 기준

개인실은 별도 직업/작업 역할이 아니다.

> **개인실 = 노예 또는 조수를 업무·조교 상태에서 빼고 개인 공간과 일부 자유를 제공하는 휴양/특별대우 상태**

따라서 UI 판단 원칙은 다음과 같다.

- 정보 조회: 유지
- 대화/칭찬/씻기 등 특별대우와 모순되지 않는 기능: 유지
- 압박/사회화 교육/처벌/처분: 버튼은 구조상 남기되 비활성
- 청소/요리 같은 업무: 개인실 UI에서는 숨김
- 개인실 전용 신규 기능: 중앙 전용 영역에만 배치

# 3. 우측 패널 전체 구조

## 3.1 개인실 노예 카드

개인실 노예의 초상화/네임바/상태 영역은 **메인 UI 노예 카드와 동일한 구조**를 사용한다.

별도 개인실 캐릭터 카드 디자인을 만들지 않는다.

차이는 오직 다음 세 상태로 처리한다.

- 활성
- 비활성
- 숨김

기존 메인 UI의 크기, 정렬, 상태 텍스트, 행동력 바, 정보열의 시각 언어를 그대로 사용한다.

## 3.2 중앙 공간

기존 개인실의 중복 상세정보 영역은 제거한다.

이 영역은 **개인실 전용 명령/안내용 중앙 공간**으로 확보한다.

이번 패치에서는 중앙부를 기능으로 채우지 않는다. 식사 설정 버튼과 안내 레이어 토글만 배치한다.

## 3.3 주인공 카드

주인공은 다음을 유지한다.

- 네임바
- 초상화
- 행동력 바
- 상태 텍스트
- 우측 정보 아이콘

개인실에서는 **행동력 바 아래의 기존 주인공 동작 버튼 행을 제거**한다.

버튼 틀도 남기지 않는다. 확보된 높이는 중앙 개인실 공간을 넓히는 데 사용한다.

개인실 노예와의 향후 전용 상호작용은 주인공 카드 하단이 아니라 중앙 공간에서 다룬다.

# 4. 캐릭터 초상화 4귀퉁이 — 확정 배치

메인 UI와 개인실 UI 양쪽에 같은 규칙을 적용한다.

| 위치 | 표시 정보 | 규칙 |
|---|---|---|
| 좌상단 | `Ill` | 질병 상태가 있을 때 표시 |
| 우상단 | `Wound` | 상처 상태가 있을 때 표시 |
| 좌하단 | 등급 | S+, A+, C+ 등 기존 등급 |
| 우하단 | 표식 | 문신 / 마법 / 인장 / 없음 등 기존 표시 |

### Ill / Wound

- 현재 작게 표시되는 Ill/Wound를 초상화 상단 모서리로 이동한다.
- 기존 버튼 규격과 시각적으로 맞춘다.
- 원본 아이콘을 억지로 확대해 흐리게 만들지 말고, 표준 버튼 영역 안에 원본 아이콘을 중앙 정렬하는 방식을 우선한다.
- 상태가 없으면 해당 모서리는 비운다.
- 이 변경은 개인실만이 아니라 메인 UI에도 적용한다.

# 5. 임신/생식 정보 슬롯 — 기존 UI에 통합

임신 상태는 초상화 모서리에 넣지 않는다.

기존 정보열의 **생식상태 1개 슬롯**에서 상태에 따라 아이콘을 교체한다.

현재 확정 UI 상태:

1. 평시 → `Fer_Normal.png`
2. 안전일 → `Fer_PregS.png`
3. 배란기 → `Fer_PregO.png`
4. 임신중 → `Preg_s.png`
5. 불임 → `Fer_PregX.png`

실제 변수 우선순위/임신 공개 여부는 기존 fertility/ovulation/pregnancy 판정을 보존한다. UI 패치에서 새로운 생식 시스템을 만들지 않는다.

# 6. 개인실 노예 카드 — 버튼 상태

## 6.1 행동력 바 아래 빠른 동작 버튼

| 기능 | 개인실 처리 |
|---|---|
| 보상/칭찬 | 활성 |
| 씻게 한다 | 활성 |
| 처벌 | **회색 비활성** |
| 청소하기 | **숨김 — 버튼 자체 미표시** |
| 음식 준비하기 | **숨김 — 버튼 자체 미표시** |

처벌 버튼은 삭제하지 않는다. 원본 UI 형태를 유지한 채 비활성 처리한다.

비활성 툴팁 의미:

> 개인실에서 특별 대우 중인 노예는 처벌할 수 없습니다.

## 6.2 노예 활동지시 메뉴

원작 활동지시 메뉴를 재사용한다.

- 회화한다: 유지
- 섹스한다: 유지
- 교육 활동: 유지
- 성교육: 유지
- 가정교사: 유지
- 칭찬: 유지
- 처벌: **비활성**
- 처분: **비활성**

처벌/처분 공통 설명 의미:

> 개인실에서 특별 대우 중인 노예는 처벌 또는 처분할 수 없습니다.

삭제하지 말고 회색 비활성으로 표시한다.

## 6.3 회화 하위 메뉴

원작의 `질문 / 영향 주기 / 사회화` 구조를 사용한다.

- 질문: 활성
- 영향 주기: 비활성
- 사회화: 비활성

툴팁 의미:

- 영향 주기: `개인실에서 특별 대우 중인 노예에게는 영향력을 행사할 수 없습니다.`
- 사회화: `개인실에서 특별 대우 중인 노예에게는 사회화 교육을 지시할 수 없습니다.`

## 6.4 큰까마귀 관 정보보기

큰까마귀 관/아우스펙스 조건으로 네임바에 나타나는 **노예 정보보기 버튼은 그대로 유지**한다.

이는 업무/조교가 아니라 정보 열람 기능이므로 개인실에서도 원작 조건에 따라 정상 동작해야 한다.

# 7. 개인실 안내 레이어 — 확정 UI

중앙 빈 공간에 별도 텍스트 열을 추가하지 않는다.

대신 중앙 영역에 **안내 레이어 열기 버튼 1개**를 두고, 눌렀을 때 중앙 영역 크기의 오버레이를 열고 닫는다.

## 7.1 열기 버튼

신규 아이콘을 만들지 않는다.

기존 리소스 사용:

`game/content/pic/buttons/debug_button.png`

이 버튼을 개인실 변경사항/안내 레이어 토글에 사용한다.

원본 이미지 파일은 이동/삭제하지 않는다. 현재 패치 구조에 맞춰 기존 경로를 참조하거나, 기존 SNKmod 정책상 복제/경로전환이 필요한 경우 기존 정책을 따른다.

## 7.2 안내 레이어

- 중앙 공간과 같은 크기의 레이어
- 별도 텍스트 컬럼을 만들지 않음
- **투명 배경 PNG 1장에 안내 텍스트를 이미지로 올리는 방식**
- 닫기 버튼은 기존 close 계열 UI를 재사용
- 평상시 숨김, debug_button 클릭 시 표시/숨김
- 게임의 다른 텍스트 레이아웃에 영향을 주지 않는 독립 overlay로 구현

이미지 내용은 현재 개인실 UI 변경의 요약이다.

권장 표시 내용:

- 메인 UI 캐릭터 카드 구조를 개인실에도 통합
- 초상화 4개 모서리에 핵심 상태정보 배치
- 임신/생식 상태를 기존 정보 슬롯에 통합
- 개인실에서 허용되는 노예 행동만 활성화
- 주인공 카드 하단 동작 버튼 제거

우하단에는 반드시 작게 다음 문구를 넣는다.

> `개인실 추가 기능 개발 중 by SAnk`

이 안내 레이어는 개발/변경사항 안내용이며 게임 수치나 개인실 기능을 추가하지 않는다.

### 권장 리소스명

`room_diet.png`

### 권장 배치

`game/SNKmod/content/pic/buttons/room_diet.png`

## 이번 패치에서의 기능 범위

식사 설정의 **새 게임플레이 효과는 구현하지 않는다.**

- 버튼/중앙 UI 배치: 이번 패치 범위
- 기존 식사 관련 UI를 한곳에서 접근할 수 있도록 하는 최소 연결: 기존 로직을 그대로 재사용할 수 있는 경우에만 허용
- `특별식단`의 신규 수치/장기 효과: 후속 개발

기존 동작을 깨지 않으면서 팝업 틀을 보여줄 수 있다면 기존 R3의 `sel_button`, `unsel_button`, `ok-icon`, `close_button` 계열을 재사용한다. 신규 효과 때문에 새로운 캐릭터 변수를 만들지 않는다.

# 9. 개인실 중복 UI 제거

개인실은 휴양/특별대우 상태이므로 다음 업무성 UI는 개인실 화면에서 제거한다.

- 청소 메이드
- 요리 메이드
- 주인 목욕 메이드
- 촉수/안개괴물 착정
- 개인실 매춘

이번 UI패치에서는 **표시를 제거하는 것이 핵심**이다.

기존 캐릭터 내부 rule 값을 무조건 삭제하거나 일반 상태의 기능까지 망가뜨리지 않는다. 실제 일일 실행 로직 변경이 필요해지는 부분은 후속 기능 패치에서 다룬다. 단, 현재 개인실 화면을 열었을 때 업무 명령이 노출되어서는 안 된다.

# 10. 원작 `개인실` 잠자리 명칭 충돌

원작 `sleep_condition = 2`의 UI 명칭 `개인실`은 새 room1~4 개인실과 혼동된다.

UI 표시명을:

> `개인실` → `개인 침대`

로 변경한다.

내부 값과 기존 수치 효과는 변경하지 않는다.

설명문은 다음 의미를 유지한다.

> 그녀만을 위해 배정된 편안하고 부드러운 개인 침대는 노예의 기분을 좋게 만들어준다. 충성스럽고 복종하는 노예에게 어울리는 특별대우이지만, 그렇지 않은 노예는 응석을 부릴 수 있다.

중복 정의가 있으면 표시 문구를 모두 일관되게 수정한다.

# 11. 개인실 전용 텍스트 — 후속 개발 규칙만 보존

이번 UI패치에서는 본격 구현하지 않는다.

후속 개발 시 규칙:

- 게임 로직/판정/CG는 원작을 최대한 재사용
- 개인실이라는 상황 때문에 대사가 어색해지는 이벤트는 텍스트만 개인실 분기
- 특히 섹스 이벤트는 **장면/CG는 공유하고 대사만 별도 분기**
- 초기 텍스트는 원작에 있는 가장 가까운 문장을 복사해 연결
- 복사된 개인실 전용 문장의 **맨 끝에 `#개인실` 태그**를 붙여 나중에 일괄 검색/수정 가능하게 함

이번 UI 패치에서 섹스 엔진을 복제하거나 개인실용 섹스 시스템을 새로 만들지 않는다.

# 13. 구현 금지 / 범위 초과 방지

이번 Work에서 다음을 하지 않는다.

- generic Actor 시스템 도입
- slave/assistant/room 전체 구조 리팩터링
- FastQSP/EXE 수정
- 개인실 친밀도 같은 신규 관계 스탯 추가
- 특별식단 장기 밸런스 구현
- 자동 여가시간 보상 추가
- 개인실 전용 섹스 엔진 복제
- 개인실 중앙 공간을 중복 상세정보로 다시 채우기
- 청소/요리 업무 버튼을 비활성 상태로 남기기 — **이 둘은 숨김**
- 처벌/처분 버튼 삭제 — **이 둘은 비활성 상태로 남김**
- 주인공 하단의 쓸모없는 행동 버튼 틀을 placeholder로 남기기

# 14. Work 구현 순서

1. `JO9UIpatch` HEAD와 R3 패키지의 현재 QSP/CSS/UI 파일 확인
2. 메인 UI의 현재 노예/주인공 카드 생성 코드를 기준으로 개인실 카드 구조 비교
3. 개인실 1~4가 중복 구현돼 있으면 공통화는 **레이아웃/표시 수준의 최소 공통화만** 검토하고, 게임 구조 리팩터링은 금지
4. Ill/Wound를 초상화 좌상/우상으로 이동 — 메인 UI + 개인실 공통
5. 등급/표식 좌하/우하 유지
6. 생식 슬롯 5상태 표시 확인
7. 개인실 노예 빠른 버튼의 활성/비활성/숨김 처리
8. 회화/활동지시 메뉴의 비활성 처리와 툴팁 반영
9. 까마귀 관 정보보기 유지 확인
10. 주인공 하단 행동버튼 제거 및 중앙 공간 확장
11. 중앙 안내 토글 `debug_button.png` 연결
12. `private_room_notice.png` 제작/배치/토글
13. `room_diet.png` 표준 버튼 크기로 가공 및 중앙 공간에 배치
14. 원작 `개인실` 잠자리 문구를 `개인 침대`로 변경
15. SNKmod 경로/설치/복구 규칙 반영
16. 빌드/정적 테스트
17. Windows/실게임 수동 QA 항목을 별도 보고

# 15. 완료 체크리스트

- [ ] 개인실 노예 초상화 카드가 메인 UI 카드와 같은 시각 구조다.
- [ ] Ill = 좌상단, Wound = 우상단이 메인 UI와 개인실 양쪽에 적용됐다.
- [ ] 등급 = 좌하단, 표식 = 우하단이다.
- [ ] 임신은 초상화 모서리가 아니라 생식상태 슬롯에서 표시된다.
- [ ] 개인실 노예의 보상/씻기가 동작 가능한 상태로 보인다.
- [ ] 처벌은 보이지만 회색 비활성이다.
- [ ] 청소/음식 준비 빠른 버튼은 개인실에서 보이지 않는다.
- [ ] 활동지시의 처벌/처분은 삭제되지 않고 비활성이다.
- [ ] 회화의 질문은 활성, 영향 주기/사회화는 비활성이다.
- [ ] 큰까마귀 관 정보보기 버튼이 원작 조건대로 유지된다.
- [ ] 주인공 행동력 아래 행동버튼 행이 개인실에서 제거됐다.
- [ ] 중앙 빈 공간이 확보됐다.
- [ ] `debug_button.png`로 안내 레이어를 열고 닫을 수 있다.
- [ ] 안내는 텍스트 컬럼이 아니라 투명 PNG 이미지 레이어다.
- [ ] 안내 레이어 우하단에 `개인실 추가 기능 개발 중 by SAnk`가 있다.
- [ ] 식사설정 버튼은 포크+스푼 디자인이며 음식 준비 버튼과 명확히 구분된다.
- [ ] 신규 UI 이미지는 SNKmod 정책을 따른다.
- [ ] 원작 잠자리 `개인실` 표시가 `개인 침대`로 바뀌었고 기능값은 유지된다.
- [ ] 개인실 기능 확장/새 스탯/EXE 변경이 섞이지 않았다.
- [ ] 기존 R3 설치/복구 흐름을 깨지 않는다.

# 16. QA에서 특히 볼 것

1. 초상화 모서리 아이콘이 인물 얼굴이나 기존 등급/표식과 겹치지 않는지
2. Ill+Wound 동시 발생 시 양쪽 상단이 정상 표시되는지
3. 생식상태 아이콘이 임신/불임/배란 전환 시 한 슬롯에서 중복 없이 교체되는지
4. 개인실에서 숨겨야 할 청소/요리 UI가 다른 경로로 다시 노출되지 않는지
5. 회색 비활성 버튼이 클릭 가능한 interaction을 우회 실행하지 않는지
6. 안내 overlay를 열고 닫아도 중앙/주인공 카드 높이와 스크롤이 흔들리지 않는지
7. debug_button과 식사설정 버튼이 중앙 공간을 침범하지 않고 해상도/스케일에서 정렬되는지
8. 메인 UI의 Ill/Wound 이동으로 기존 우측 정보열이 깨지지 않는지
9. 개인실 1~4 모두 같은 규칙으로 표시되는지
10. 설치 → 게임 실행 → 복구 후 기존 R3 상태로 정확히 돌아가는지
