# 최종 사용자 확정: UI 패치 리소스 분류

2026-09-28. 이 문서가 앞선 인계/진단의 포장 범위 설명보다 우선한다.

1. 순정 원본과 같은 경로이며 SHA256도 같은, 변경하지 않은 자산은 포장하지 않고 순정 참조를 유지한다.
2. UI 패치 작업으로 교체되어 순정과 해시가 다른 자산, UI 패치가 추가한 신규 자산은 패키지에 반드시 포함하고 content/pic/SNKmod 아래로 연결한다. 사용자에게 이전 UI 패치의 변경 파일이 있다고 가정하지 않는다.
3. UI 패치에서 한글 파일명을 영문명으로 바꾼 자산은 내용이 같아도 SNKmod에 포함하고 참조를 바꾼다.
4. 이미지팩이 교체한 자산은 UI 패치에서 제외한다. 이미지팩은 원본 경로를 직접 교체하는 별도 ZIP이며 복구를 지원하지 않는다. UI 패치는 그 자산을 중복 포장하거나 복원 대상으로 삼지 않는다.
5. 따라서 해시 차이 147개는 전부 UI 패치 누락으로 확정된 것이 아니다. 변경 목적/출처를 분류하고 UI 패치 관할분만 포함한다. 사용자가 이미지 원본은 Claude에 이미 전달했으므로 이번 GitHub 인계에서 중복 제공하지 않는다.

## Claude 후속 작업

0.1의 QSP·QSRC·CSS·JSON·기타 참조와 동적 조립 경로를 최종 기준으로 전수 분류하고, 먼저 근거가 있는 결과를 보고한다. 이 인계는 즉시 수정·재빌드·배포 지시가 아니다. 구 R3와 사용자가 준 ref.zip은 비교 자료이며 최신 0.1 구현과 혼동하지 않는다.

QSP가 설치 후 다른 내용으로 바뀐 현상은 리소스 분류와 별도 이슈다. 런처 재컴파일은 아직 가설이며 실제 실행 전후 해시 비교가 필요하다.
