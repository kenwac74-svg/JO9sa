# 이미지 목록 탭 구조 수정

사용자 지정: 처음부터 탭 구조, 선택한 탭만 로드, 기존 기능 보존.

1. 기존 데이터·함수와 체크/교체 호출을 조사하고 원본 해시·복구본 보존.
2. 초기 HTML에 탭과 빈 패널을 선언하고, 탭별 내용을 실행하지 않는 템플릿으로 분리. 서버는 선택한 템플릿만 별도 제공하여 첫 응답에서 타 탭 데이터 제외. 원천 HTML의 데이터 패턴은 기존 분석/쓰기 도구와 호환.
3. 각 렌더러를 정해진 패널에 직접 생성하도록 변경. 로드 후 DOM 이동 및 summary 강제 숨김 제거. 공통 씬 정보는 전체/주석 탭에서 공유. 첫 로드 캐시로 검색/필터/페이지 보존, 비활성 목록 재렌더 차단.
4. 지연 로딩·빠른 전환·실패 재시도·기존 데이터/API/수동검색/체크/교체 연결 검사 후 WORK와 소스 설치. 실제 브라우저에서 무저장 확인.
5. 검증/복구 기록과 사용법을 남기고 재생성 가능한 임시 자료 정리. Full/커밋/푸시 없음.
