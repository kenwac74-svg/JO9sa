# UI 경로 이관 후보 독립 검토

판정: PASS. 경로 전용 후보 QSP `9d2864aba0e6a7306f559a38a5e032fe827acf3edd2eb0fcb39b29511250c85a`만 검토했다. 이후 폰트·로그 표시 변경이 합쳐진 a48c 후보는 이번 검토 범위에서 제외했다.

현재 candidate/jack.qsp에는 폰트 변경이 추가돼 있어, 경로 이관 직후 자동 백업 `candidate/jack.qsp.bak_20261027_175542`의 해시를 확인해 사용했다. CSS도 현재 파일의 앞 239,715바이트가 경로 전용 SHA `03fa87c2bb94effa9e814ef27592b2f40b509e7856c1f3ab61b189167d25f31a`와 정확히 일치하는지 먼저 확인했다.

- 273개 로케이션 중 본문 81개만 변경됐다. 추가·삭제 로케이션과 다른 QSP 필드 변경은 없다.
- 변경된 문자열은 승인 경로 맵의 UI 이미지 경로 치환뿐이며, 추가된 것은 같은 ID의 경계 주석이다. 문자열·주석 밖 실행 코드가 동일하고, 동적 코드 문자열도 승인 경로 변환 외 차이가 없다.
- 전체 참조 치환 수 4,911개를 별도로 재계산해 이관 기록과 대조했다.
- CSS와 jo9_traits_view.js 역시 승인 경로 변환 외에는 바이트 내용이 동일하다.
- menu_icon.json의 키 2,641개와 자료형을 보존했다. 값은 경로 문자열이며 수치 값은 원래 없다. 경로 이외 문자열과 비문자열 값도 변경되지 않았다.
- 2,681개 각각의 옛 WORK 경로·canonical WORK 경로·resources/new 추적 경로가 모두 일반 파일이며 같은 장치·inode를 가리킨다. 크기와 SHA-256도 계획과 일치한다. 옛 저장 캐시용 경로가 모두 남아 있다.
- 미사용 중복 10개는 WORK 원래 경로에서 없어졌고 외부 archive/files/원래상대경로에서 SHA-256을 확인했다. 현재 CSS가 사용하는 ui/루트 활성 사본 10개도 원래 SHA를 유지한다.

재현 스크립트: independent-path-review.cjs. 기계 판정: independent-path-review.json.

이번 검토는 운영 코드·리소스·세이브·배포 폴더를 쓰지 않았다. 보고서와 재현 스크립트만 기록했다. 실제 게임 클릭 및 이후 폰트 훅·페이지 표시 동작 검사는 별도다.
