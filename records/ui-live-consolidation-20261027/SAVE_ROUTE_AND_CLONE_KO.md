## 실제 클릭용 클론 구성 권고

예시 작업 폴더: `G:/Codex/tmp/ui-live-consolidation-20261027/game`.

- `jack.qsp`, `config.xml`, `icon.ico`, `FastQSP.ini`, `css/`, 선택한 `save/`는 **실제 파일 사본**으로 둔다. `save/`는 절대 정션·하드링크로 공유하지 않는다. 세이브를 불러올 때도 클론의 사본 경로를 선택한다.
- 완전한 실행 폴더 분리를 원하면 `engine/`도 실제 사본으로 둔다. 현재 엔진 폴더는70파일·93,090,575바이트여서 이미지 전체를 복제할 필요 없이 실행 기반을 분리할 수 있다. 원본 엔진 바이너리는 수정하지 않는다.
- 이미지와 폰트는 `content/`, `fonts/` 읽기용 정션으로 재사용할 수 있다. `json/`은 순수 읽기 여부를 확실히 구분하기 어렵다면 실제 사본으로 둔다. 읽기용이라는 사용 규칙과 NTFS 쓰기 차단은 다르다.
- 자산 정리·이름 변경·이동·삭제·모드툴 반영은 **클론 정션을 통해 실행하면 WORK까지 변경**된다. 이 클론은 실제 게임 UI 클릭용이며, 공유 리소스를 정리하는 작업 장소가 아니다.
- `config.xml`은 UTF-16LE+BOM이다. 원본 바이트를 복사한 뒤 같은 인코딩으로 창 제목만 `JO9 UI 실제 클릭 시험`처럼 구분한다. UTF-8로 읽고 다시 쓰면 설정이 손상되어 0폭 화면 같은 잘못된 진단이 나온다.
- 실행은 클론의 `engine/jack.exe`에 **클론 jack.qsp의 절대 경로**를 인자로 주고 작업 디렉터리를 클론 `game`으로 둔다. 공유 WORK 엔진을 쓴다면 인자·작업 디렉터리는 동일하게 클론으로 향해야 하며 설정 기록 위치도 별도 확인한다.
- 실행 PID와 구분된 창 제목으로 새 창만 선택한다. 기존 WORK 창을 닫거나 그 창에서 로드하지 않는다. 시험 종료 때도 직접 시작한 PID만 정리한다.

선정한 최신 수동 파일과 GOLD 파일은 `autosave=0`, `decadesave=0`, `autosave_day=0`, `autosave_decade=0`이다. 현재 QSP의 자동저장 명령은 `save/auto_day.sav`, `save/auto_decade.sav`, `save/auto_day_end.sav` 같은 상대 경로다. 클론의 실제 save 폴더와 실행 작업 디렉터리를 함께 분리해야 한다. 설정 화면에서 자동저장을 다시 켜기 전에는 클론에만 기록되는지 파일 변경 시각/해시로 한 번 확인한다. 검토 중에는 자동저장을 끈 상태로 충분하다.

불러오기는 게임의 실제 `Game → Load`를 사용한다. QSP `OPENGAME`은 월드 열기 경로이므로 세이브 불러오기를 대신하지 않는다. 원본과 시험 파일의 후속 변경이 섞이지 않도록 각 비교는 클론 사본을 재로드한다.

세이브에는 저장 당시 화면 HTML도 들어 있다. 불러온 첫 화면만 보고 현재 QSP가 그 UI를 생성한다고 단정하지 말고, 안전한 닫기/뒤로 후 동일 화면을 다시 열어 최신 코드를 거친 화면과 비교한다. 특히 구버전 지역 해금 파일은 ‘현재 미사용 UI’ 판정의 단독 근거로 쓰지 않는다.

## 화면 규격 분류

- **좌측 컷신 계열**: 상점·의료센터·소문·환전. 좌측 이미지와 선택지, 하단 대사, 우측 참고 정보의 관계를 비교한다. 기존 CSS `#bg`는795×595이고 실제 리소스795×596과1px 차이가 있으므로 ‘795×596으로 전역 통일’하지 않는다.
- **인물 정보 계열**: 노예/조수 프로필, 중앙795×595 영역, 특성3열, 아래 설명, 최상위 메시지. body 포털인 확장창과 원래 본문 기준 요소를 구별한다.
- **전면 목록 계열**: 설정·주인 인벤토리·의뢰/목표·마법/물약 목록. 표의 마지막 항목·긴 목록·다중 열·닫기/복귀를 확인한다.
- **전투 계열**: 중앙795×596, 좌우 상태·명령, 하단 기록과 승패 링크. 준비·전투·결과를 각각 한 화면으로 기록한다.
- **전체화면 계열**: 게임오버/메인메뉴. 실제 논리 캔버스1280×800의 원점·가장자리·메뉴 접근성을 따로 비교한다.

이 지도는 조사 순서를 줄이기 위한 준비 자료다. 실제 화면 모양·클릭 가능 여부·사용하지 않는 UI 여부는 root가 별도 클론에서 직접 확인해야 한다.
