# 춘향 주기적 특수기 — 현재 규칙과 턴 계측 조사

기준 WORK a08546afd58aff978c1b29b54ca00dcaf53654981ac8c05d1e7a357e4deceb53. 읽기 전용 소스 조사이며 게임/세이브 변경과 엔진 실행은 하지 않았다.

## 최신 사용자 규칙

능력 비율R은 사용자 확정에 따라 힘·전투 기술·전투 시작 최대체력·정상사기·최대스태미나의 항목별 춘향 대비 비율을 동일비중으로 평균낸다. 실제 전투 초기화를 마친 시점의 시작값을 유지하며 이후 소모/회복은 비율을 바꾸지 않는다. 춘향의 실제 기준 능력치만 아직 미정이다.

| 비율 | 동작 |
|---|---|
|R<70%|전투 시작 시 즉사기 발동|
|70%≤R≤100%|5~10턴마다 즉사 확률 판정, 비율이 높을수록 확률 감소|
|R>100%|주기적 특수기를 일반 피해로 받음|

정확히70%와100%는 확률 판정 구간이다. 직전의 정확히70%도 실패한다는 규칙은 최신 지시로 대체됐다. 기존 조사자의 단순70%조건 제안은 현행 요구사항이 아니다.

사용자 확정: 시작 시 또는 주기 판정의 즉사기 성공도 강제 패배 후 기존CM 결과로 연결한다. CM≤−10만 실제 사망하며 나머지는20만/10만/5만/0 정산 후 복귀한다. 일반 패배와 같은CM 구간을 사용한다. 즉사 확률은 R=70/80/90/100%일 때40/30/20/10% 기본안으로 사용자 확정했다. 이 구간의 선형식은110−R(%). 판정 실패 시 일반 피해 처리의 세부는 최종 설계에서 명시한다.

## 턴을 소비하는 실제 경로

- 일반/특수 공격: атака_игрока549 → ход_противников15 → конец_раунда.
- 방어/휴식: передышка20 → 같은 정산 경로.
- 물약3종: #боевые_предметы1322/1337/1354 → 같은 경로.
- 실제 무기 교체: #dynamic1899/1910/1921 등에서nogoto=0이면 같은 경로.
- 무기/인벤 메뉴 열기, 뒤로, 화면 재표시, 무료 방어 자세 전환은 боевой_интерфейс 복귀로 끝나므로 소비 턴으로 세지 않는다.

별도 라운드 번호는 찾지 못했다. 실제 한 행동의 정산을 소비 턴으로 사용하는 설계가 적절하다. 공격의 длительность는 상태 지속값이다.

## 후속 검증 계획

- 시작 비율70% 직전/정확히70%, 주기 구간100%/100%초과 경계.
- 낮은/높은 비율의 확률 곡선과 난수 최소·최대 경계.
- 물약/공격/휴식/무기 교체는 소비 턴, 메뉴 반복은0턴.
- 간격5·10 경계, 저장/로드 후 남은 턴 유지, 새 결투에서만 초기화.
- 예정 턴에 춘향을 먼저 쓰러뜨리면 승리 보존.
- 확정할 즉사/CM 경로와 금액 정산1회, 생존 시 부상·행동력·전투 상태의 정상 복귀.
