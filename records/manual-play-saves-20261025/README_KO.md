# WORK 수동 플레이 검사 세이브 28개

먼저 짧게 확인하려면 **12 소액 파산 정산**, **01~05 생산 비교**, **20 특성 전체 목록**, **25 우유 5병 판매**, **28 목줄 거부 X/Y**를 권장한다. 알려진 문제는 **19 소문**, **26 재고 목록**, **27 모유 아이콘·개인실 이종성애**, **08 캣파이트 결과 복귀**에서 본다.

현재 WORK에서 원래 메뉴·대화·결과·다음 버튼을 직접 조작하기 위한 독립 시험 세이브다. 지난 패치의 모든 변경·난수·분기·개인 세이브를 검증 완료했다는 뜻은 아니다. 장기 플레이 기록으로 사용하기보다 아래의 한 가지 비교를 마치고 원래 시험 파일을 다시 불러오는 방식으로 사용한다.

## 불러오기와 보존

1. 묶음을 별도 폴더에 푼다. 기존 WORK의 `game/jack.qsp`를 실행하고 원래 불러오기 기능으로 원하는 `.sav`를 선택한다. 이 묶음 때문에 게임 QSP·소스·CSS를 교체할 필요는 없다.
2. `checked` 파일은 `01_검사완료재확인`, `manual` 파일은 `02_수동확인_문제재현` 폴더에 있다. 아래 **재확인/수동** 표시는 이 분류를 뜻한다. 실제 묶음의 파일 경로를 기준으로 한다.
3. 원래 게임과 기존 저장은 보존한다. 진행 중 상태를 남길 때는 `MANUAL_CHECK_12_after.sav`처럼 **별도 이름으로 수동 저장**한다. 시험 원본과 개인 진행 세이브를 덮어쓰지 않는다.
4. 시험 파일의 일일·주기 자동저장은 꺼져 있다. 원래 설정에서 자동저장을 다시 켜면 기존 자동저장 파일이 바뀔 수 있으므로 수동 검사 동안 끈 상태를 유지한다.
5. 역할·난도·분기를 비교할 때는 해당 배포 파일을 다시 불러온다. 한쪽 실행 후 이어서 다른 쪽을 실행하면 행동력·재고·기분·갈망·퀘스트가 이미 달라져 있다.

대부분 성인 원본 에게야(유형2579)와 이사벨라(유형2571), 원래 나이 값2를 사용한다. 13은 개인실4·동면 셀1, 17은 축사·감옥으로 두 인물을 옮겼다. 05·27에는 별도 ID의 성인 에게야 시험 복제 인물이 개인실1에 있다. 자금·시설·특성·기술·퀘스트 단계 등은 항목을 바로 볼 수 있도록 만든 시험값이다.

06~08은 **원래 설정의 전투 무적 옵션 활성값(`cheat_fight_dif=0`)**을 사용한다. 현재 WORK의 원래 치트 설정 메뉴에 활성/비활성 전환이 존재함을 확인했다. 수동 전투 조작과 결과 정산을 보기 위한 조건이며 일반 피해량·패배 밸런스 검사로 해석하지 않는다. 무한 행동력은 해제 상태다.

## 파일별 조작과 기준

### 01_prod-size0.sav — 크기0 생산·행동력0 자동 업무 [재확인]

**조작:** 집의 노예 카드에 있는 생산 그림 버튼을 누르고 결과의 다음 버튼으로 돌아온다. 다시 불러와 노예 능력창의 생활 규칙에서 안개 괴물 업무를 해제하면 조수 카드의 생산 버튼으로 비교할 수 있다. 자동 업무는 재로드 후 아무 생산도 누르지 말고 하루 종료한다.

**기준:** 노예14(+20%), 조수12. 선택한 역할만 행동력 소모: 노예0→-1, 조수5→4. 자동 분기도 시작 크기0의14를 지급하며 보유량·주기 합계에 한 번만 더한다.

**한계:** 훈련5·초기 재고0의 고정 표본이다. 자동 보고 도중 크기1 성장 화면이 나와도 시작 크기의 생산량14가 기준이다. 원래 다음 버튼으로 끝까지 넘긴다.

### 02_prod-size1.sav — 크기1 생산 [재확인]

**조작:** 노예 생산→결과→집 복귀를 진행한다. 조수 비교는 재로드 후 노예의 안개 괴물 업무를 해제하고 조수 생산 버튼을 누른다.

**기준:** 노예23(+30%), 조수18. 선택 역할만 행동력5→4이며 결과를 넘겨도 중복 지급하지 않는다.

**한계:** 한 번 생산하면 갈망 상태가 달라진다. 두 역할을 연속 실행한 결과로 비교하지 않는다.

### 03_prod-size2.sav — 크기2 생산 [재확인]

**조작:** 02와 같은 원래 생산 버튼·다음 버튼으로 노예와 조수를 독립 재로드하여 비교한다.

**기준:** 노예33(+40%), 조수24. 선택 역할만 행동력5→4, 비선택 역할은 보존한다.

**한계:** 훈련5·재고0·생산 전 상태를 맞춘 표본이다. 다른 행동 후의 수치와 섞지 않는다.

### 04_prod-size3.sav — 크기3 생산 [재확인]

**조작:** 노예 생산을 한 번 마치고 집으로 복귀한다. 재로드 후 노예 업무를 해제하고 조수로 같은 경로를 실행한다.

**기준:** 노예96(+50%), 조수64. 선택 역할만 행동력5→4이며 결과 복귀 후 추가 지급이 없어야 한다.

**한계:** 원래 결과 문장과 그림을 그대로 확인한다. 역할별 비교는 같은 초기 파일에서 시작한다.

### 05_prod-size4.sav — 크기4 수동·자동 세 역할 [재확인]

**조작:** 수동 생산은 앞 파일과 같다. 자동 노예는 재로드 후 바로 하루 종료한다. 자동 조수는 노예 업무를 끄고 조수 업무를 켠다. 자동 개인실은 노예·조수 업무를 모두 끄고, 이미 업무가 켜진 개인실1 시험 인물에게 맡긴 뒤 하루 종료한다. 각 분기는 재로드한다.

**기준:** 노예201(+60%), 일반 등급 조수126, 개인실1 201(+60%). 한 역할만 생산하며 원래 보고를 끝까지 넘겨도 보유량·주기 합계가 재가산되지 않는다.

**한계:** 업무 우선순위는 노예→조수→개인실이다. 조수는 일반 등급이므로 과거 최고 등급 조수의201과 비교하지 않는다. 개인실1은 별도 ID의 시험 복제 인물이다.

### 06_fog-hint-ap-fame.sav — 안개 전투 소개·행동력·컬러·목격 명성 [재확인]

**기준:** 선택 단계에서 미리 행동력을 차감하지 않는다. 승리 정산에서 출전자만 최소1 소모하고 비출전 역할·주인은5 유지. 마지막 지구력75 이상이면5→4다. 목격 시 노예 명성39→42, 조수79→80. 출전자 초상은 컬러여야 한다.

**한계:** 목격은 원래20% 확률이다. 메시지 없는 승리는 명성39/79 유지가 정상이다. 추가 도시 이동 비용을 섞지 말고 복귀 직후 비교한다. 무적 활성 표본이다.

### 07_grinch-native-menu.sav — 그린치 전용 준비·퀘스트 복귀 [재확인]

**조작:** 그린치·맥스 전용 소개를 읽고 원래 전투 진입→등 무기→공격·휴식을 진행한다. 승리 뒤 이야기의 다음 버튼을 끝까지 누른다.

**기준:** 일반 안개 소개가 섞이지 않고 전용 준비 메뉴가 열린다. 주인공 승리 후10385 이야기와 퀘스트10단계로 이어지며 원래 다음 날 진행으로 복귀한다.

### 08_catfight-third-return.sav — 세 번째 승리·명성과 기존 복귀 문제 [재확인]

**조작:** 누적2승에서 출전하고 원래 스타일을 선택해 직접 싸운다. 승리 결과를 확인한 뒤 다음 버튼을 끝까지 누른다. 가능하면 ESC로 도시 메뉴에 나가 클럽을 다시 방문한다.

**한계:** 결과의 목적지 `goto_loc`가 없어 클럽 복귀가 막히는 기존 결함은 미수정이다. 정산과 복귀를 따로 기록한다. 막히면 원본 시험 파일을 다시 불러온다. 고유 결과의 행동력-3은 안개 전투 규칙과 다르다.

**한계:** 승패는 원래 난수이며 이 시험 조합의 승리 가능성은2/3이다. 패배 시 명성·우승 이력은 시작값을 유지한다.
