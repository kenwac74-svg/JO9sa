# WORK 수동 검사 세이브 묶음

28개의 일반 QSP 5.7 세이브를 WORK의 `game/save/JO9_MANUAL_20261025` 새 폴더에 추가했다. 기존 검사 재확인24개와 수동 확인·미수정 재현4개로 나누고, 파일별 조작 순서·정상 수치·현재 결함·시험값을 사용 안내에 적었다. 게임 QSP·CSS·JSON·기존 저장·Full·배포 패치는 변경하지 않았으며 커밋·푸시도 하지 않았다.

## 생성 및 데이터 보존

원래 세이브의 전체 변수와 다행 스크립트를 실제 Load 메뉴로 복원하고, 현재 WORK의 데이터베이스로 갱신한 뒤 원래 화면에서 저장했다. 숫자0·긴 문자열을 생략하는 과거 시험 공장 방식은 사용하지 않았다. 기본 슬롯0이 빠졌던 구형 시험 저장의15개 배열은 새 제작용 복사본에서 복원했으며 원본에는 손대지 않았다.

최종 파일에서는 빈 시험 표식을 제거했다. 데이터 갱신으로 초기화된 일반 실내 배경 캐시는 게임의 `interior_restore`와 같은 조회 규칙으로 현재 장식값에 맞췄고, 저장된 화면의 해당 이미지 경로도 함께 복원했다. 상태값이나 환급 이력을 바꾸는 작업이 아니다. 현재 WORK가 직접 저장한 CRC 헤더를 사용했고 추가 진단 로케이션을 호출하는 내용은 넣지 않았다.

독립 검사3개에서 긴·다행 변수440개 보존과 핵심9개 매크로의 현재 원본 일치를 확인했다. 전체 최종28개 검사 결과는 `final-save-inspection.json`에 기록한다.
