## 검증과 남은 범위

- 적용 작업마다 QSP 구조·개행·주석 경계·정확 패치 재생/재적용 및 실제 설치 엔진 검사를 기록했다. 최근 금화 표시도 공식 엔진 9경로와 표시 5경로를 통과했고 사용자 확인을 받았다.
- 대표 기능의 자동 통합 실행과 일부 실제 GUI 검사를 완료했다. 이후 발견된 소문·목록·개인실·약국·파멜라 등의 결함은 후속 수리 기록을 우선한다. 옛 감사표의 미수정을 그대로 현재 상태로 복사하지 않았다.
- 모든 세이브·모든 동적 분기·모든 장기 플레이를 완주했다는 뜻은 아니다. 사용자가 빠르게 할 수 있는 수동 플레이는 사용자 담당이며, 기존 확인용 세이브는 별도로 보존한다.
- 새 3차 패키지 자체의 설치·CRC·파일 누락 검사는 아직 하지 않았다. 이는 실제 빌드 뒤 수행할 검사다.
- 미결정 기획과 미수정·재현 대기는 별도 `PENDING_DECISIONS_KO.md`로 분리했다. 공개용 노트 확정 전에 미결 수리의 포함 여부를 결정한다.

이미 2차에 포함된 절세미인 표시명, 아르곤 선별 대사·NPC 서식, 211 JSON 수리, 구 도나 JSON 번호 정리, 특성 편집 링크색 등을 3차 신규 수정으로 중복 집계하지 않았다. 독립 모딩 도구 변경도 게임 콘텐츠와 구분한다.
