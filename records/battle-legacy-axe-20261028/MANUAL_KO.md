# 격투대회 전용 필살기 UI — 2026-10-28

패치 `ARENA_SPECIAL_TEXT_UI_20261028`. 변경 로케이션은 `боевой_интерфейс` 하나다.

격투대회 `arena_mode=1, combatant=1`의 전용 필살기 분기는 일반 전투 메뉴와 분리돼 있었다. 이 분기에서 `extra_special_active/used`의 옛 아이콘을 그리므로 키메리안 스타일의 녹색 도끼가 나타났다.

UI 스타일별5개 기술의 활성 이미지10곳을 기존 텍스트 메뉴와 동일한 ‘특수 기술’ 링크로, 사용 후 이미지10곳을 회색 ‘특수 기술 (사용 완료)’로 바꾼다. 기존의 잘못 남은 닫는 앵커도 사용 후 표시에서 정리한다. 입력은 기존 arena_mode/combatant/g_type/사용 플래그이며, 반환값이나 신규 상태는 없다. 각 기술의 기존 EXEC href·조건·1회 제한은 그대로다. 물약·무기 변경 등 원래 대회에서 없던 메뉴를 추가하지 않는다.

새 이미지·CSS·JS·의존성·로케이션·세이브 이관은 없다. 결과 화면의 방패/칼·썸업과 일반전투 메뉴도 바꾸지 않는다. 옛 아이콘 파일은 다른 참조와 기존 세이브를 위해 보존한다. 복구는 작업 직전 QSP 백업만 필요하다.

정확한 수정 본문은 mods JSON에, 입력/후보 해시는 candidate.json에, 최종 실제엔진·문법 검사는 별도 보고서에 남긴다. 검사 표본과 모든 게임 플레이를 동일시하지 않는다. WORK와 추적 패치 기록만 반영하며 세이브·배포 폴더·커밋·푸시는 건드리지 않는다.
