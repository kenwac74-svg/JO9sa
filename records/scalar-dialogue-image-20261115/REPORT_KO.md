## 원인

page-flow의 합성 페이지는 그림을 경로 문자열로만 반환해 실제 $bg_path 원문 참조와 사용 장면이 빠졌다. 화면은 새 이미지 지정 버튼을 표시했지만 저장기는 배열형 대사만 받아 거부했다.

## 수정·동작

page-flow.cjs는 해당 결과 분기 내부의 정적인 $bg_path 원문·사용 장면을 제공한다. image-reference.cjs는 기존 조건과 형제 분기를 유지하면서 이 이미지 지정 한 곳만 수정한다. 출력기가 .png를 붙이므로 파일 선택은 PNG 이름으로 하되 QSP에는 확장자 없는 stem을 저장한다. 조건 추가·제거·재지정도 같은 기록 블록을 사용한다. dialogue-image-ui.js는 실제 파일명으로 선택기를 열고, 보조 배경 후보를 선택한 상태에서도 현재 페이지의 실제 이미지 지정으로 연결한다.

사용자는 현재 이미지 아래 ‘새 경로 지정’으로 파일을 고르고 ‘검사·미리보기’ 후 ‘경로·조건 반영’을 누른다. 별도 새 배열 슬롯을 만들지 않는다. 정적 경로와 범위를 확인할 수 없는 복합 명령은 추정해서 수정하지 않는다.
