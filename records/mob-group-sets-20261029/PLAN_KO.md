# 단체 MOB 패배 컷신 연결 계획
- 기존 전체 로스터를 비교하여 단체 식별. 현재 선택 대상/생존 슬롯/skip_to에 의존하지 않음.
- 검은 의사+하인3, 성기사+병사2, 고블린2/3, 가르시드+수인4, 탈옥수5 고정 구성부터 구현.
- 수인4/부랑자5의 무작위 구성은 사용자 선택 대기; 대표 컷신 또는 조합별 슬롯.
- jo9_battle_fate의 group 조회 추가, конец_боя에서 단체 패배 한 장 우선. 없는 그림은 기존 개별 표시 임시 유지.
- 기존 초상/전신/패배 세트에 단체 연결 안내와 별도 단체 컷신 카드 추가. 기존 PIC 적용 API와 백업/패치 원장 재사용.
- 처형 이미지를 별도 생성하지 않음. 기존 붉은 필터/선택 처리/성향 누적 유지.
- 실제 엔진 로스터 순서/선택대상/인원수/실패 분기, 이미지 성공·실패 DOM, 카탈로그 확인, 공식 출고 검사 후 WORK만 반영.
