## 이미지와 사용자 작업
이번 수정은 단체 조회와 이미지 교체 도구 연결이다. 단체 그림 8장은 아직 제작 필요이며 실제 그림을 생성하거나 원본 이미지를 변경하지 않았다.
MOB 세트 상단 단체 카드에서 구성원 초상과 필요 인원수를 확인한 뒤 단체 PNG 추가를 누르면 해당 경로에 기록되고 개인 이미지 패치 원장에 포함된다.
파일 추가 전/이미지 오류 시에는 개별 패배 그림이 임시 표시된다. 단체 이미지 성공 시 개별 그림은 숨겨진다.
처형은 같은 단체 그림 위 기존 붉은 필터. 별도 사망/처형 이미지 슬롯 없음.
일반 개별 세트에도 공유 단체 링크를 표시한다. 기존 개별 이미지와 수동 체크 상태는 보존한다.

## 코드·의존·부작용
MOB_GROUP_SETS_20261029 식별자. jo9_battle_fate(group)는 기존 적 배열과 전체 수를 읽고 경로를 문자열 반환한다. local 카운트만 사용하며 저장 변수는 추가하지 않는다. 사망으로 비활성화된 슬롯도 로스터에 포함한다.
конец_боя에서 승리 시 단체 조회, 패배/알 수 없는 로스터는 기존 개별 조회. 선택처리·처형필터·cruel/mercy 수치는 변경하지 않는다.
그룹 조회 코드를 제거하면 결과 화면 호출도 함께 되돌려야 한다. 파일만 없으면 개별 그림으로 대체한다. 카탈로그 JS는 기존 PIC API/인증/백업/개인 패치 기록을 재사용한다.
