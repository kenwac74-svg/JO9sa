# 안마 수행 제한과 정신질환 품질 상한 — 2026-11-18

사용자 승인: 중상·치명상은 수행불가. 신경쇠약·정신분열은 안마를 수행하지만 품질저하로 회복결과가 없어야 한다.

## 최종 동작

- 노예5412·조수5501이 중상(wounds4) 또는 치명상(5)이면 메뉴를 회색 비활성으로 표시하고 툴팁에 수행불가 이유를 표시한다. 미정의된 회색 이미지 변수는 만들지 않고 기존 메뉴 prefix의 회색 CSS를 쓴다.
- interaction과 interaction_result의 개인실 대상 교환 직후에도 검사해 직접호출·옛 선택지·대기 결과로 우회해도 행동력·칼로리·일일회복flag·완료횟수 변경 전에 반환한다. 개인실 인물도 기존 bridge의 slave 교환 경로로 보호된다.
- 기절·사망은 기존 활동 제한을 유지한다. 보통 부상(wounds3 이하)에는 새 제한이 없다.
- 자아+성격+태도<5인 신경쇠약·정신분열은 기존 계산값을 최대2로 제한한다. 안마를 수락하면 제공자의 행동력1·칼로리1을 소모하되 주인공 행동력은 회복되지 않고 일일 회복flag도 사용하지 않는다. 명령 거부 판정 자체는 기존대로다.
- 그 밖의 인물은 앞선 애무 기술 전용 품질 계산을 유지한다. C 이상부터 당일 첫 회복+1, 도시와 합산 하루1회이며 비용·회복량을 바꾸지 않는다.

## 입력·부작용·유지보수

입력은 기존 actor wounds,ego,temper,pride,petting와 기존 interaction 번호다. 새 저장필드·함수·로케이션은 없다. 기존 안마 템플릿의 새행동 재정의는 앞선 패치 그대로 사용한다.
MASSAGE_INJURY_MENTAL_20261118의 SLAVE/ASSISTANT 마커가 메뉴, GUARD가 실행/결과 진입, MENTAL이 정신질환 품질 상한을 담당한다. 호출자는 menu_form/interaction/interaction_result다. 메뉴 제한만 제거해도 실행검사가 남고, 실행검사만 제거하면 직접호출 우회가 가능하므로 제거할 때 전체5 edit를 현재 후속 변경과 대조해 역적용한다.
일반 안마만 변경했으며 관능적 마사지 보상·다른 업무·도시 안마·전역 근면도 계산은 유지한다.

## 검증

실제 WORK FastQSP5.7에서 노예·조수 양쪽의 행동46상황+메뉴6상황, 286검사를 수행했다. 수정 전54실패, 후보286/286 PASS.
부상3/4/5 경계, 대기 결과 직접진입, 신경합계5/4/2, 두 질환이지만 기존근면도가 높은 경우, 기술0~5, 기존 정상 안마·기분 무관·일일제한·거부·과거 템플릿을 포함한다. 중상 차단은 제공자/주인공 AP·칼로리·일일flag 무변화, 정신질환은 제공자 비용만 발생을 확인했다.
실제 interaction/interaction_result와 원래 비용/성실도 helper를 사용했고 UI는 실제 수정된 메뉴조각의 메뉴호출·툴팁을 검사했다. 주변 UI·특성 callback은 중립대역이며 개인실 전체 전환·개인SAV GUI·게임 화면 육안은 미검증이다.

WORK·추적 QSP·런타임원장·재현mods만 반영한다. Full·개인SAV·음원·기존4차ZIP·커밋·푸시는 변경하지 않는다.
