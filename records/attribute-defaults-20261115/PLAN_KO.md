# 초기값 누락·특성 색상·성기술 배치

요청: 세련됨 등 ‘미설정’ 항목 전체를 초기화 코드와 대조, 특성의 게임 색상 반영, 성기술 3열과 입력평균 문구 제거.

확인한 원인: JSON에는 세련됨/인지도/기분의 최종 등급과 상태 단계가 모두 직접 저장되지 않는다. QSP의 기본 0과 연속값 임계값, 미용 보정, 대분류 합계, 복종도 산식을 표시 화면에서 계산해야 한다. 현재 세이브를 조회하는 도구가 아니므로 공용 초기 상태를 기준으로 하고, 장비·이벤트 효과는 별도임을 표시한다. 추첨·영입 이벤트가 바꾸는 수치를 실제 세이브 값처럼 주장하지 않는다. 기본값은 계산 결과로만 사용하고 원본 JSON/프로필에 자동 저장하지 않는다.

특성은 QSP의 dyneval 색상뿐 아니라 content/js/jo9_traits_view.js의 grade 표와 css/jo9_traits_view.css의 등급·칭호 우선 규칙을 함께 읽는다. 단순 긍정/부정 분류로 새 색을 만들지 않는다.

전용 계산/색상 검사 후 새 임시 브라우저 탭에서 실제 화면을 확인한다. 기존 사용자 탭, WORK 게임 파일, 배포본, 커밋/푸시는 변경하지 않는다.
