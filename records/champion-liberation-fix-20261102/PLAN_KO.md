# 콜로세움 해방 결말 누락 수정

사용자 보고: 우승 후 주인에게 돌아오는 결말이 기본 경기장 배경이고 상금은 $65, 별도 상금 페이지가 남아 있다. 떠나는 결말도 함께 점검·수정한다.

확인 원인: 이전 `1294` 일반 승리만 기존 상금의 두 배·결과 페이지 통합을 적용했다. `interaction_city=1295` 무패 4→5단계 승리의 해방 이벤트는 옛 산식·3페이지가 남았고, 제작한 두 전용 이미지는 시안 폴더에만 있었다. 현재 사용자의 시안 채택 규칙과 이번 수정 지시로 두 컷의 WORK 적용이 승인되었다.

## 수정 범위

1. `interaction_city=1295` 상금도 원래 단계별 산식 → 최소 50 → 최종 2배를 적용한다. 동일 입력의 $65는 $130이 된다. `sparks += purse`는 기존 정산 위치에서 한 번만 실행한다.
2. 해방 선언 1쪽은 유지한다. 귀환 또는 영구 이탈 결과의 2쪽 끝에 상금을 붙이고, 상금만 있는 옛 3쪽 대입을 제거한다. 실제 `$text` 배열을 2쪽으로 만들며 `txt_count` 숫자만 바꾸는 것으로 대체하지 않는다.
3. `moral > fear` 귀환은 `content/pic/scene/champion_return.png`, 동률 포함 나머지 이탈은 `content/pic/scene/champion_departure.png`를 `$special_image_full[2]`에 연결한다. 기존 처형/생존 선택에 따른 선언 1쪽 그림은 보존한다.
4. 이미 제작된 `output/champion-liberation-cutscenes-20261031/*_795x596.png`를 원본 바이트 그대로 사용한다. WORK·추적 이미지·개인 패치 이력·이미지 체크리스트에 두 컷을 반영한다.
5. 이탈의 인물 제거·귀환의 성장 보상·해방 조건은 유지한다. 새 저장 변수·새 로케이션·난도 변경·여주인 복구는 없다. 이미 정산한 저장을 소급 재지급하지 않는다.

## 검증

- 기존 코드의 65 지급·3쪽·2쪽 전용 이미지 없음 재현 후 같은 표본에서 130·2쪽·올바른 795×596 이미지로 수정 확인.
- 처형/생존 × 귀환/영구 이탈, `moral=fear` 경계, 결과 재표시·페이지 전후 이동·정상 복귀의 중복 지급·이전 컷신 잔류를 실제 엔진에서 검사한다.
- 단계가 다른 기존 1294, 대련 1296~1298에 잘못 적용되지 않는지 확인한다. 공식 구조·줄바꿈·패치 재생·멱등성·기본 실제 엔진 9경로 검사도 실행한다.
- 최신 WORK를 시작 직전 다시 읽어 수동 변경을 보존한다. 검증 후보가 통과한 뒤 정확한 mod JSON을 기존 적용기로 WORK에 반영하고 해시를 비교한다.
- 배포본 최종 동기화 중단은 유지한다. ZIP·커밋·푸시는 하지 않는다. 개인 저장·원본은 보존하며 이번 작업의 재생성 가능한 임시 사본만 정리한다.
