# R03-3 아르테미아 특성 요구 연결

2026-11-13 사용자 승인: 기존 요구 최저값1 이상으로 연결해 색정광·정액 중독을 모두 허용한다. 실제 slave_sell_chek는 해당 요구를 읽지 않는다. 설정값이 양수일 때만 보유값과 비교한다. 발견 상태를 추가 조건으로 삼지 않는다.

수정 범위는 기존 납품 함수 한 본문이다. 기존 #npc_base 요구 정의·외모5·기술4/5·평가등급8·가격·캐시·영구 인물 필드·거래/보상/진행은 바꾸지 않는다. 완료 거래를 소급 취소하지 않는다. Full·음원·커밋푸시·마이그레이션 구현은 제외한다.

검증 순서: 성인 합성 인물의 실제 납품 함수에서 -1/0/1/2 및 발견0/2 경계의 RED → 한 곳 수정 → 같은 경계, 외모/기술 거절 유지, 요구 없는 실제 고객(아주라) 거래 및 가격/인물/재산 보존 → 공식 재생/멱등/역검증·구조 → WORK·소스·원장·체크리스트 → 재생성 가능 임시 사본 정리. 실제 개인 SAV·화면·최종 전체 출고 검증은 별도다.
