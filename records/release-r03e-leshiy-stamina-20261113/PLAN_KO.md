# R03-5 레시 체력 최저4

2026-11-13 사용자 승인: 다른 고객의 기존 동작을 유지하며 레시만 체력4이상으로 적용한다. 기존 레시 요구의 >3 비교식을 =4로 바꾸고 실제 납품에서는 레시인 경우에만 해당 최저값을 검사한다. 대소문자가 섞인 실제 Leshiy 식별자도 같은 고객으로 판정한다.

실행 #npc_base의 레시 요구 정의,slave_sell_chek의 공통 건강검사 직후 고객 범위가 명시된 검사,$ongload의 알려진 옛 레시 요구 문자열만 변경한다. 감수성 상한3·다른 기술/특성·전체 평가·가격·다른 고객·인물·재산·진행과 별도 사용자 요구값은 유지한다. 새 인물별 필드·로케이션은 추가하지 않는다.

실제 성인 합성 인물에서 체력3/4 및 식별자 표기,기존 감수성/간호 조건,다른 고객의 기존 거래,옛 요구 캐시2회로드와 수동편집 보존을 RED→수정후 비교한다. 공식 재생/멱등/구조/역검증 후 WORK·소스·원장·체크리스트를 맞추고 이번 임시 사본만 정리한다. 개인 SAV/GUI/전체출고검증·Full·음원·커밋푸시·마이그레이션 구현은 별도다.
