# 펠라게야 이벤트 번호의 복장 연결 · 2026-11-09

사용자가2577의 기존 복장 이미지를 실제 등장 번호2585·2607에도 연결하도록 요청했다. 기존 PNG3개를 그대로 재사용하고, 각 JSON의 fullmade/indpack_maid, fullsecretary/indpack_secr, fullmistress/indpack_dom을 같은 경로로 지정했다. 새 그림·복사 이름·QSP 코드·설명문·능력치·2577 데이터는 변경하지 않았다.

캐릭터 이미지 연결 API의 최신 JSON 해시 검사와 JSON 토큰 편집을 사용했다. 각 반영의 이전 JSON과 이력은 verification.json의 histories에 기록됐다. 추적 소스와 runtime-source-2.4.1.json에는 최신 JSON2개와 공유 PNG3개를 같은 바이트로 보관했다. 복구는 해당 JSON에 후속 수정이 없는지 대조한 뒤 원본 JSON 또는 이전 경로를 사용한다.

전체 JSON을 요청한6개 키만 추가한 예상 객체와 비교했고, 실시간 WORK 조회에서 두 인물의3역할 모두 전용 그림이 존재하며 누락 경로가 없음을 확인했다. PNG 헤더·크기·해시와 소스 동일성을 확인했다. 세이브의 인물 캐시는 강제 변경하지 않는다. 일반 게임을 다시 실행한 뒤 펠라게야의 하녀·비서·도미나 복장을 다시 선택해 시각적으로 확인한다. 실제 게임 화면 확인과 JSON 연결 검증은 구분한다.

설명문 원문은 DESCRIPTION_COMPARE_KO.md에서 비교한다.2577·2585는 동일하며2607은 과거·가족·직업 설명과 자매 관계의 말투가 다르다. 이번에는 모두 보존했다. Full·배포·커밋푸시는 수행하지 않았다.
