# 포털 가디언·바티칸 성기사 테스트 세이브

WORK의 Jack-o-nine-tails.exe에서 불러온다. 두 파일 모두 안개 지역의 일반 메뉴이며 아직 전투 상대를 만나지 않은 상태다. 보통 난이도, 남자 주인공 잭, 행동력 5, 소지금 $10,000, 글라디우스를 준비했다. 성인 에게야가 노예, 성인 이사벨라가 조수다.

| 파일 | 불러온 뒤 진행 | 확인할 내용 |
|---|---|---|
| TC_09_PORTAL_GUARDIAN_EVENT.sav | 포털 지대 → 도입 3쪽 → 경비와 싸운다 | 포털 가디언의 설명·전신 → 싸운다 → 무기 선택·전투 화면 |
| TC_10_VATICAN_PALADIN_EVENT.sav | 포털 지대 → 도입 3쪽 → 성기사와 싸운다 | 바티칸 성기사의 설명·전신 → 싸운다 → 무기 선택·전투 화면 |

교황의 사전 대화를 마친 테스트 상태다. 가디언 쪽은 성기사를 통과한 퀘스트 단계로 설정했다. 앞선 퀘스트 전 과정을 자연 진행한 저장은 아니며, 이벤트 진입과 전투 화면을 바로 확인하기 위한 표본이다.

자동 확인: 설치된 실제 엔진으로 새 게임 초기화와 SAVEGAME, 일반 메뉴의 포털 이동 콜백, 도입 3쪽, 상대별 메뉴 콜백·전투 준비·무기 선택 화면을 확인했다. 도입 다음 버튼은 진단용 선택 입력으로 원래 분기 본문을 실행했다. 실제 마우스 클릭, 일반 exe에서의 SAV 불러오기, 전투 승패 진행과 이미지 구도는 수동 확인 항목이다. 최종 저장에는 실행되는 진단 코드를 남기지 않았고 현재 WORK QSP 체크섬과 저장 형식 왕복을 검증했다. 원본 엔진의 변수 조회를 보존하기 위해 값이 없는 진단용 이름 슬롯 한 개는 그대로 유지했다.

WORK QSP·Full·원본과 기존 세이브는 수정하지 않았다.
