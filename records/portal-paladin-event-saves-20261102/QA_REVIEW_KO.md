## 생성 중 발견하여 최종본에서 막은 사항

1. native `killvar` 후에도 빈 진단 이름 `TC_PORTAL`은 slot 9581에 남았다. 이 이름을 코드로 걸러내면 같은 해시 버킷 뒤의 변수 조회가 끊기므로 빈 슬롯을 원형 보존했다. 값·인덱스는 비어 있고 실행 명령은 없으며 게임 QSP에 진단 변수나 로케이션을 추가하지 않았다. 기존 경매 표본도 독립 대조했으나 그 표본의 삭제 대상은 버킷의 마지막 사용 슬롯이어서 뒤 변수 조회를 가리지 않았다. 경매 표본은 수정하지 않았다.
2. 준비 화면 HTML은 SAV header 8이다. header 11의 표시 플래그를 HTML로 읽던 진단식을 바로잡은 뒤 현재 WORK 이미지 경로의 존재를 확인했다. 퇴역한 `scene/vatican_paladin.png`, `scene/strazhnik.png`는 실제 준비 HTML에 출력되지 않았다.
3. 도시 진입은 주인공 능력치를 rate에서 다시 계산하고 행동력을 정상 상한 5로 제한한다. 정상 rate를 설정하고 행동력 5·half_action 0으로 저장했다. 파생 위상 등급은 원래 계산 결과 6을 유지했다.
