## 원인과 계산

이전 `MERCY_ALLURE_20261113`은 기존 의상·청결·행동력·단장·머리 손질·힘·기분 합산식을 Mercy 단독 등급으로 대체했다. 종합관리 자체는 머리 손질 30·단장 10·청결 0 등을 정상 처리했지만 매력은 Mercy가 낮으면 최저 등급으로 돌아갔다.

현재 `jo9_mercy_allure` 한 로케이션에서 옛 매력 계산식을 그대로 복구해 기본 등급을 0~5로 산정하고, 현재 Mercy의 5/15/25/40/60 기준 보정 0~5를 더한 뒤 최종 0~5로 제한한다. 음수·0 Mercy에는 추가 매력 보정이 없고 기존 음수 CM의 장악력 처리는 유지한다. 최고 등급에서는 더 오르지 않는다.

기존 `$calculate_attributes`, `jo9_cruel_mercy_apply`, `$ongload`, `#help_msg`가 같은 helper를 호출하므로 정상 갱신·CM 변동 직후·저장 불러오기와 도움말에 같은 기준을 적용한다. 별도의 영구 성장값·세이브 이관 플래그·저장 필드는 추가하지 않았다. helper의 임시 변수는 local이다. 비용·관리 지속기간·CM 획득량은 수정하지 않았다.

도움말은 의상·미용·컨디션의 효과와 현재 자비의 추가 보정을 설명하도록 함께 갱신했다. 매력 변화로 매력을 참조하는 기존 대인/장악력 계산에도 원래처럼 영향이 간다.

## 재현과 복구

`prepare.cjs`는 원본 매력 산식을 읽고 격리 후보와 선언형 패치를 만든다. `native.cjs <red|green> <qsp>`는 해당 QSP의 실제 미용실 코드와 helper를 검사하는 진단 사본을 만든다. `install.cjs`는 지정 입력 해시·GREEN·배포 제외를 확인한 뒤 WORK와 추적 소스를 맞춘다. `package.py`는 기존 1차 패치를 재사용하며 출력이 이미 있으면 중단한다. 각 스크립트의 고정 경로·해시는 이 작업 기준이다.

정확한 패치: `mods/2026-11-15_mercy_salon_restore.json` 및 이 폴더 `change.json`. 원본 WORK는 `work.before.qsp.gz`에 있다. 복구할 때 전체 파일을 무조건 덮어쓰지 말고 현재 입력이 수정 후 해시인지 확인하고 해당 로케이션을 역적용한다. 기존 별도 배포 문구 제외는 유지한다.
