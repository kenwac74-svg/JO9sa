# 이미지 패치리스트의 B·C컷 등장조건 설정

2026-11-01. 요청한 기능을 WORK와 추적 소스에 반영했다. 이미지 카드의 **등장 조건 설정**에서 같은 이름의 `(2)`, `(3)` 등 추가 컷을 고르고 cruel & mercy, 보유금 이상/이하, 조합 계급, 평판을 지정한다. 지정한 항목은 AND로 판정하고, 여러 컷이 맞으면 낮은 번호가 우선한다. 반점 단위 누적값을 보존한다. 조건 없는 기존 컷의 수동 선택 방식은 유지한다.

- 반영 후 SHA-256: `78835089f1dc8d0d5272f991926f35fa40e7e26dede5970a3fc03612967c130d`
- 선언형 변경: `mods/2026-11-01_image_cut_conditions_core.json`. 6개 로케이션의 11개 정확한 변경 명세. 위치 수는 기존 277개다.
- 공통 출력 함수는 조건이 없으면 원래 HTML을 반환한다. 집·전투의 기존 전환 버튼 제외 규칙을 유지하면서 조건 대상의 src만 바꾼다. 직접 출력하던 10곳도 연결했다.

- 조건 자료는 QSP의 JSON 주석과 판정 코드에 함께 저장한다. 개인 SAV, 그림 파일, 새 영구 변수, 새 로케이션을 추가하거나 변경하지 않았다.
- Full QSP는 기존 `f87363c…`를 유지했다. 이번 기능의 Full 동기화·ZIP·커밋·푸시는 수행하지 않았다.

## 사용 및 한계

이미지 패치리스트를 새로고침하여 버튼을 불러온다. 저장한 QSP 조건은 실행 중인 게임 메모리에 자동 주입되지 않으므로 게임을 재실행해야 한다. 조건을 만족하는 시점은 해당 이미지가 다시 출력될 때다. 기존 수동 선택된 무조건 컷은 유지될 수 있으며, 미설정 그림을 강제로 A로 덮어쓰지 않는다.

개별 사용자 조건은 임의로 넣지 않았다. 기존 컷을 삭제하거나 외형을 변경하지 않았다. 실제 전체 게임 분기·개인 세이브 GUI 로딩·모든 캐릭터 조합·픽셀 단위 육안 배치까지 검증했다는 뜻은 아니다. 조건 테스트의 집·전투 진입부는 진단 어댑터이며, 별도 필수 9경로와 장면 전환 회귀에서 원래 출력 로케이션을 실행했다.

상세 사용법·입출력·부작용·제거 영향은 `MANUAL_KO.md`, 화면 연결은 `renderer-edits.json`, 검사 근거는 동봉 JSON/로그에 있다. 복구용 변경 전 QSP는 해시를 확인한 `before.qsp.gz`로 보존한다. 진단 QSP·복제 JSON·소유한 진단 SAV 및 링크는 검증 후 정리하며, 재현 코드·보고서·변경 명세를 남긴다.
