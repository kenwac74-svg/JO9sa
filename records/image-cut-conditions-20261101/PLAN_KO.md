# 이미지별 대체 컷 등장조건

사용자가 직접 요청한 기능을 기존 카탈로그와 QSP 전환기에 연결한다. 구현·검증은 WORK와 추적 소스에 수행하며 배포·ZIP·커밋·푸시는 별도 지시 범위를 따른다.

- bg/characters/scene의 이미지 카드에 등장조건 설정 버튼. 기본 이미지에서 같은 이름의 (2),(3)… 가족을 열어 각 대체 컷을 설정한다. 기본 A는 조건 불충족 시의 안전한 기본 그림이다.
- 켠 조건은 AND. cruel&mercy -10~10의 반점 범위, 정수 보유금 이상/이하, 게임의 주인공 계급·평판 드롭다운. 미사용 필드는 평가하지 않는다. 게임 누적 수치는 제한하지 않는다.
- 설정한 조건이 맞는 컷을 자동 우선 표시한다. 동시에 맞으면 낮은 컷 번호 우선. 조건에서 탈락한 컷은 수동 전환에서도 제외한다. 조건 없는 경로와 기존 선택 ID·기본 복귀·mode2 교체 대상 조회는 유지한다.
- 기존 interior_change의 로컬 변수/함수 분기 및 마커 구간만 확장한다. 조건 자료는 그 QSP의 JSON 주석과 생성한 조건 코드에 함께 보존하여 별도 영구 저장 변수·로케이션·세이브 이관을 추가하지 않는다. 추가 컷 재등록은 이 구간을 보존해야 한다.
- 별도 인증 API는 현재 가족과 QSP 해시를 읽고 optimistic hash로 저장한다. 입력은 허용된 네 조건과 실제 가족 파일만, 코드 문자열 입력은 받지 않는다. 선언형 패치·백업·원자적 반영·오류 시 원본 보존을 유지한다.
- 프런트는 기존 카탈로그 HTML/상태 파일과 독립된 추가 모듈을 서버에서 삽입하여 카탈로그 재생성 뒤에도 남는다. 기존 B컷 원본 연결과 편집기 수동 변경을 보존한다.

1. 순수 규칙 검증·컴파일·QSP hook 모듈과 실패/경계 단위 검사를 작성한다.
2. 독립 프런트 모듈과 API 계약을 병렬 구현한다. 프런트: info/save, 모달·드롭다운·범위·정수·해제·오류·키보드 닫기.
3. 백엔드 실제 가족 확인·저장 충돌 방어 및 서버 라우트 연결. 원본/조건 없음/PNG 외 가족도 확인한다.
4. 격리 QSP에서 원래 전환 함수와 새 조건의 경계, 반점, AND, 중복 우선, 조건 변동 후 복귀, 수동 전환, mode2, 추가 컷 재등록을 검사한다. 공식 출고 검사와 실제 엔진/브라우저를 별도로 수행한다.
5. 최신 WORK를 다시 읽어 수동 변경 보존·패치 재현을 확인하고 반영한다. 도구 설치본만 선별 배포·3813 서버 재시작 및 실제 HTTP/브라우저 확인. 개인 SAV와 그림 파일은 쓰지 않는다.
6. 재현 스크립트·핵심 보고·변경 명세를 남기고 이번 임시 진단 사본을 정리한다.
