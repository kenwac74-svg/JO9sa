# 경기 패배 평판 판정의 이미지 등장 조건 갱신

새 PNG와 D행은 추가하지 않고 WORK·seed 카탈로그의 scene 등장 조건 메타데이터만 최신 QSP로 갱신했다. 정식 경기·캣파이트의 처형 결과에는 새 평판 판정의 상위 진입 조건을 연결했고, 생존 결과에는 해당 판정의 else 분기라는 근거를 보완했다. 기존 승리 처형·살려줌 컷신의 2페이지 alias 안내도 보존했다.

모든 D행, 체크 상태, 안정 ID, QSP, 이미지 파일은 보존했다. 정적 조건 분석과 HTTP 검증이며 플레이 테스트는 별도다.

HTTP /catalog 200과 최신 QSP 해시, 관련 PNG 6개의 실제 API 200·해시 일치를 확인했다. 검증 후보는 복구본과 기록 보존 후 정리했으며 전체 metadata.json 복제본은 만들지 않았다.
