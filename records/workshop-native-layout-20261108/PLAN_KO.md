# 대사 편집실 구조 정리

사용자 지정: CSS 덧씌움 대신 실제 코드 구조 수정, 기존 기능 유지.

1. 현재 WORK/소스·CSS/DOM 생성·선택 전달·초안 저장 경계를 조사하고 백업한다.
2. 초기 HTML에 작업 탭, 각본 영역, 공유 검색, 수정/흐름/고급 출력/저널, AI 도크를 선언한다. 기능 모듈은 해당 요소의 동작만 연결한다.
3. 탭 전환은 소유 패널 hidden 상태로 처리한다. 본문/AI는 Grid의 실제 행으로 배치하고 강제 CSS 숨김·고정 도크 보정 여백을 없앤다. AI 접기/높이/설정 값과 기존 저장 키 유지.
4. 기존 CSS 중복을 합쳐 정적 스타일시트로 분리하고 선택 알림은 명시적 이벤트로 연결한다. 비활성 수정 화면 그림은 그리지 않고 수정 탭 진입 때 현재 선택을 표시한다.
5. 구조/탭 상태·초안/미리보기/각본/이모지/변수·조건·AI 설정 연결·복구 경계를 비저장 브라우저와 관련 검사로 검증한다. WORK와 소스만 적용, 게임파일·이미지 체크·Full·커밋푸시는 변경하지 않는다.
