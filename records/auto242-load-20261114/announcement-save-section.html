2.4.1 세이브로 이어하기

2.4.1에서 전투를 끝내고 일반 화면에서 저장한 파일을 지원합니다. 별도 호환기나 사전 변환 없이 게임에서 바로 불러올 수 있습니다.

  1. 원래 게임 폴더와 세이브는 그대로 보관해 주세요.
  2. 사용할 세이브 파일을 새 2.4.2 폴더의 game/save에 복사합니다.
  3. Jack-o-nine-tails.exe를 실행하고 Game → Load에서 불러옵니다. 필요한 이름·이미지·음원 경로 보정은 불러올 때 자동으로 적용됩니다.
  4. 불러온 뒤에는 새 이름으로 한 번 저장해 계속 플레이해 주세요.

직접 지은 이름과 사용자 지정 이미지, 육성·장비·관계·진행 기록을 유지합니다. 전투 중 저장과 다른 버전의 세이브는 이번 지원 범위에 포함되지 않습니다.
