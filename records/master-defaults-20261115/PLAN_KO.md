# 공통 시작 설정 누락 보완

사용자 승인: CM 외 공통 초기값 때문에 빠진 능력치/설정을 전부 대조하고 기존 UI에 추가.

- 현재 QSP의 init_game → init_story_mode → 캐릭터별 코드 → hero_description → start_game 및 init_custom_game/hero_creation/계산 함수를 조사한다.
- 숫자만 표시하던 규칙을 일반화해 문자열·상수 인덱스 배열·공통 기본값·조건/계산 출처도 제공한다. 초기화 전체 원장에는 제외한 임시/메뉴/동적 인덱스의 이유도 남긴다.
- 값은 선택한 캐릭터에서만 변경한다. 기존 계산식과 공통 초기화는 보존한다. 선택 직후/게임 진입 뒤 다시 대입되는 항목은 그 단계 뒤의 캐릭터별 override 블록에 연결한다. 새 런타임 변수는 만들지 않는다.
- 능력치 탭은 기존 격자를 유지하고 여주인/장비/자산/경험치·상태/고급 시작 설정을 접는 구역으로 추가한다. 기본값·직접지정·조건부·자동계산과 원본 위치를 툴팁으로 구분한다. 초기값 편집이며 실시간 SAV 편집은 아니다.
- 원본 변경 충돌, 명시적 재설정/복구, 두 역할 간 복제 보존, 여러 위치 QSP 변경의 원자 저장/원장, 별도 번호 및 기존 사용자 수정 보존을 검사한다.
- 실제 WORK 데이터에 시험 저장하지 않는다. 격리 소형 QSP/HTTP에서 저장을 확인하고 도구 화면만 확인한다. 커밋푸시/Full/배포/개인 SAV 변경은 하지 않는다.

진행: 조사 중. 다음: 초기화 파서·원장 → 실패 검사 → API/저장 단계 → UI → 격리 검증/최종 확인/기록/임시자료 정리.
