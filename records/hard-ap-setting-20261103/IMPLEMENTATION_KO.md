# 게임 설정 하드 — 노예계 기본 행동력 +1 제거

2026-11-03 사용자 승인에 따라 WORK와 추적 runtime에 적용했다. 생성 시 game_difficulty는 변경하지 않는다.

## 입력과 결과

입력은 기존 게임 설정 difficulty_setting과 각 인물의 stamina다. 기본 행동력 상한은 지구력0이하이면0, 양수이면 min(5, stamina + iif(difficulty_setting = 2, 0, 1))이다. 새 변수나 새 로케이션을 추가하지 않았다.

| 지구력 | 쉬움·보통 | 하드 |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 2 | 1 |
| 2 | 3 | 2 |
| 3 | 4 | 3 |
| 4 | 5 | 4 |
| 5 | 5 | 5 |

이는 기본 상한이다. 기존 음수 half_action에 저장되는 별도 보너스를 지우거나 총 행동력을 새 절대 상한으로 제한하지 않는다. 기존5칸 기본 상한과 속성 정상 범위를 유지한다.

## 부작용과 유지 사항

하드에서 지구력1~4의 기본 상한·회복 기준이1 낮아진다. 지구력0·5의 기본 상한은 기존과 같다. 일일 회복은 기존처럼 energy += 회복량이며 완전 충전으로 바꾸지 않았다.

부상 차감, 간호/의료의 엄격한 초과 비교, 음수 AP 누적과 하한, 반 칸 소비/보너스 이동, 음식·약물·마법·휴식 보너스는 원래 코드를 유지한다. 지구력2·부상3·의료 지원 없음이면 하드 회복량은 -1이며, 기존 간호 조건을 충족하면 기존처럼1이다.

게임 설정을 바꾸면 기존 갱신 경로에서 기본 상한을 다시 계산한다. 하드에서 쉬움·보통으로 바꿨다는 이유로 잔여 행동력을 새 최대치까지 무료 충전하지 않는다. 기존 생성 난도에 따른 옵션 선택 가능 범위도 변경하지 않았다.

저장 형식/키/캐릭터 데이터 구조는 같다. 기존 SAV를 변환할 필요가 없는 방식이다. 로드 후 saved_game_loaded → $newloc → $addon update → refresh_database에서 현재 정의를 재로딩하는 기존 경로를 사용한다. 개인 SAV를 GUI로 직접 로드한 검사는 별도로 남아 있다.
