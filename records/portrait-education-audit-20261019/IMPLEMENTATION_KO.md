# 포트레이트 우측 교육 전수 점검과 수정

사용자 지시: 노예·조수 포트레이트 우측 교육 메뉴를 전수 검사한다. 사용자가 다시 지시하기 전에는 커밋·푸시하지 않는다. 이번 게임 반영 대상은 최신 Work이며 Full·기존 ZIP은 갱신하지 않는다.

## 발견한 결함과 원인

1. interaction_result의 조수 교육 성공 분기에서 `dynamic $special_part`와 JO9 MOD START 주석이 한 줄로 붙어 있었다. 조수가 노예를 가르치는 분기의 조건부 대입에도 같은 결합이 있었다. 기존 2.4에도 포함된 결함이며, 최근 임신 아이콘 수정으로 생긴 문제가 아니다. 기존 검사에서 누락한 책임과 실제 발생 원인은 구분한다.
2. 정상 `&!` 주석 뒤에 provenance 표식이 붙은 한 행도 별도 줄로 정리했다. 이 행까지 같은 실행 오류라고 판정하지 않는다. 세 수정은 기존 명령의 식·조건·교과·수치·문구를 바꾸지 않는다.
3. 조수의 특정 수업이 공유 캐시의 노예용 계산을 그대로 호출했다. 기존 대상 치환 패턴을 재사용해 조수의 상태로 계산한다. 새 캐시 키는 만들지 않는다.
4. 같은 수업의 고급 후속 동작이 존재하지 않는 assistant_to_cow를 호출했고, 기존 전환·복귀는 노예만 가정했다. 기존 cow_lesson_in_progress 값 0/1에 조수용 2를 구분하여 전환·거부·두 후속 경로·규칙 적용·원복을 같은 인물에게 수행한다.
5. 조수의 동료 대체 수업 조건이 `slave_state ! no_slave`여서 노예가 없을 때 기존 고용 파트너 수업(6999)이 오히려 숨겨졌다. 원래 주석과 반대역 메뉴에 맞춰 `slave_state ! slave_exist`로 바로잡았다. 기존 비용·기술 조건·수업 본문은 유지한다.

## 수정 위치와 의존성

- 패치 2026-10-19_portrait_education_boundaries: interaction_result의 세 줄 경계를 복원한다.
- 패치 2026-10-19_portrait_assistant_cow_followup: interaction, slave_to_cow, interaction_result, #dynamic의 7개 edit. 기존 swap, 상태 재정의, 경험치/행동력 계산을 재사용하며 표시 원문은 보존한다.
- 패치 2026-10-19_portrait_cow_legacy_action_alias: 예전 수업 중간 상태의 저장된 명령이 호출하던 누락 진입점 assistant_to_cow 하나를 복원한다. 기존 조수용 flag를 설정한 뒤 slave_to_cow로 이동하는 얇은 호환 진입점이다. location 수는 261→262이며 새 영구 변수 키는 없다.
- 패치 2026-10-19_portrait_assistant_partner_gate: menu_form의 상수 한 곳을 교정한다. 유효한 노예가 있으면 기존 수업, 없거나 기절·사망했으면 기존 고용 파트너 수업을 표시한다. 기존 보유금·기술 제한도 그대로 적용한다.

입력은 현재 interaction 번호, 기존 인물·수업 상태와 기존 cow_lesson_in_progress다. 출력은 기존 결과 화면과 후속 활동이며 별도 반환값은 없다. 후속 동작은 실제 수행자의 경험치·행동력·수행 이력을 갱신하고, 끝나거나 거부하면 노예·조수·축사 인물의 원래 상태로 복귀한다. 개인 저장 파일을 직접 변환하거나 저장하지 않는다.

## 분리하거나 제거할 때

줄 경계 복원은 조수 교육 전체의 공통 결과 처리에 필요하다. 후속 수정의 전환·계산·원복·규칙 부분은 한 묶음이다. 전환만 고치거나 복귀 대상만 고치면 인물·경험치가 섞일 수 있다. 호환 진입점을 제거하면 예전 수업의 저장된 pending action이 다시 없는 location을 호출할 수 있다. 마지막 조건 교정을 제거하면 빈 노예 슬롯에서 대체 수업이 다시 숨겨진다. canonical 적용 순서는 위 네 패치의 before/after 해시 순서다.

## 검사 도구의 실제 범위

기존 release-check는 파일 구조·줄바꿈·일부 경계 오류와 기본 실제 엔진 경로를 검사한다. 완전한 QSP 문법 검사기나 게임 전체의 정상 동작 인증이 아니다. 이번에 코드 뒤 START 주석 결합을 탐지하고 문자열·정상 주석은 오탐하지 않도록 보완했다. 회귀 테스트는 수정 전 실패를 확인한 뒤 수정 후 통과했다.

교육 검사는 실제 FastQSP에서 수업 결과·본문·올바른 대상·객체 버튼·페이지 넘김·메뉴 복귀를 별도로 수행한다. 객체 선택은 격리 QSP에서 선택 입력만 주입하고 기존 $objsel 본문을 실행한다. 실제 사용자 창을 클릭하거나 사용자의 플레이를 조작하지 않는다. 서브 메뉴의 정상 조건 부족·기술 상한·적성 발견 팝업을 엔진 오류와 구분한다.

검사 구성에서 발견한 정상 분기(깨끗한 집의 청소 수업 복귀), ADDOBJ를 본문에서 찾던 잘못된 검사, 정상 알림, 디스크 부족으로 실패한 진단도 내부 이력에 보존한다. 이를 게임 오류 또는 통과로 바꾸어 기록하지 않는다. native 5.7과 실제 FastQSP의 명령 지원 차이도 구분하며, LOCAL 지원은 실제 FastQSP의 최소 실행으로 따로 확인했다.

최종 검사 수치·해시·Work 반영 결과는 RESULT.json을 따른다. 실제 저장 선택 UI/CRC 호환 및 모든 인물·감정·장비 조합의 장기 플레이는 이 검사 범위가 아니다. 예전 pending action 검사는 원래 명령 문자열을 주입한 격리 상태이며 실제 예전 세이브 UI 로드를 대신하지 않는다.

최종 조건 수정은 별도로 노예 없음·기절·사망·정상 존재·보유금 없음의 5조건을 실제 FastQSP에서 전후 비교했다. 기존 clear_slave_instance로 실제 노예 슬롯을 비운 6999 수업도 끝까지 실행하여 페이지 넘김·뒤로가기·메뉴 복귀, 조수 신원 보존, 빈 노예 슬롯 유지와 기존 비용 1을 확인했다. 원고·새 영구 키·새 수업은 추가하지 않았다. 최종 후보 해시는 20137b7336f2ec27c419605cbd2ada1a6fab459919c6ceaaedad89a9152f40f5이며 이 후보에 공식 구조 검사·정확 재생·멱등성·기본 엔진 9경로 검사를 다시 수행한다.
