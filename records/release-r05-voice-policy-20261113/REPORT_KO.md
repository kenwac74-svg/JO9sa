# R05 말투 선택·내부 반말 속성 반영

2026-11-13 사용자 승인대로 WORK·추적 QSP·runtime 원장에 반영했다.

일반11직업의 반말 선택을 제거하고 격식직업1/기본2를 유지했다. 지정 유니크8명은 기본 반말이다. 인물의 `jo9_plain_tone` 값1은 반말 켜기, -1은 끄기, 없음/0은 기본 복귀이며 명시 값이8명 기본보다 우선한다. 헌신·사육·인식 등에 따른 자동 전환 수치는 만들지 않았다. 인물 배열의 키1개와 대화 중 임시 화자값을 사용하고 새 영구 전역 배열/버전은 추가하지 않았다.

말투 프로필·실제 화자 전달·완성 문장 교정·고유 소개 호환 가드·알려진 저장 콜백 갱신을 함께 맞췄다. 관계 의미·성격 분류·선택 원고·기존 교정표·육성/진행 수치는 보존했다. 내부 값은 기존 역할 교환과 저장에서 사람과 함께 유지된다.

## 검증

- RED: 일반 직업 반말, 명시적인 켜기/끄기 무시, 화자 플래그 전달과 옛 캐시 미갱신을 실제 엔진에서 재현했다.
- GREEN: 설치 FastQSP3그룹188검사 통과. 프로필120, 실제 화자/평가/교정28, 캐시/역할 이동/로드40이다.
- 11일반직업·10격식직업·8명 기본과 명시ON/OFF, 성격 유형3종과 다른 유니크 대조를 확인했다.
- 실제 `$voice_native`와 `$voice_impression` 경로에서 화자 프로필을 테스트 전용으로 관찰했다. 상대방의 번호/플래그를 쓰지 않았고 임시값을 기존 시점에 정리했다.
- 기존 문장 교정표의 알려진 중립 문장을 ON/OFF로 조회하고 미등록 사용자 문장·알려진 소개 호환 가드도 확인했다. 전체 대사를 새로 읽거나 모든 어미를 증명한 것은 아니다.
- 정확 캐시 갱신2회에 메모/다른 콜백/알 수 없는 사용자 프로필 보존, 실제`$ongload`2회에 정책/필드 유지, 실제 배열 역할 교환2회와 합성SAV 왕복을 확인했다.
- 기존 BGM 로드는 `#dynamic`을 다시 읽는다. 이 기존 전체 초기화를 바꾸지 않았으므로 개별 캐시 갱신기의 사용자 코드 보존과 전체 로드의 기존 동작은 구분한다. 최초 검사의 잘못된 전제를 수정한 기록을 보존했다.
- 공식 재생·재적용 무변경·역적용 원본 복원·구조/CRLF/주석 마커·바이트 왕복을 통과했다. 변경 로케이션4개 외306본문은 동일하다. 새 로케이션0.
- 독립 읽기 전용 코드 검토에서 수정 필요 사항을 찾지 못했다. 엔진 재실행을 별도로 한 검토는 아니다.
