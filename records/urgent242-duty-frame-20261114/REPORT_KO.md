# 2.4.2 긴급패치

업무명 4개를 짧게 표시하고 기존 help 툴팁에 소모량·실제 can/daily 조건을 추가했다. 불가 항목의 why는 기존 help 뒤에 덧붙여 조건·비용도 유지한다. can/set/daily/burn과 수치는 변경하지 않았다. label/help의 지정 구간과 불가 안내 결합 문자열만 변경했다.

실제 엔진 12개 반환 검사 PASS. 최초 진단 표식이 검사기 형식에 맞지 않아 거절되었고, 진단 표식만 고친 뒤 통과했다. 게임 자체 오류는 아니었다. 춘향 3종은 기존 시루 동종 초상의 5px 테두리를 기존 합성 도구로 복사했고 중심 픽셀 동일성을 검증했다. 실제 게임 hover 배치는 사용자 확인 대기다.

WORK와 추적 소스 반영. 배포 game/jack.qsp와 초상 3개, 안내 1개만 ZIP에 포함했고 전체 CRC/원본 바이트 대조 PASS. 풀 ZIP·옛 Kor_Full·SAV·공개 공지는 수정하지 않았다. 커밋/푸시/업로드 없음.

호출: jo9_room_duty label/help. 기존 tooltip-data 표시를 재사용한다. 패치를 제거하면 긴 문구와 기존 불가 사유만 보이는 표시로 돌아가며 저장 형식에는 영향이 없다. 기록된 before.qsp.gz는 이번 수정 직전 복구 자료다.
