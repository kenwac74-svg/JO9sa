## 변경과 사용

조수 보상 5601~5609 중 칭찬·해변/극장/식당·마사지·커닐링구스의 결과 연결을 보완했다. 5605~5607의 정원·온천·황금새장은 앞선 휴식 수정 그대로 유지한다.

- 칭찬: 일반 노예의 기존 보상 등급 2, 매력 기반 효과와 반복·공적·관심 특성 처리를 조수에게 연결한다. 무료 행동이며 기존 야심가 특성 호출도 유지한다.
- 데이트: 기존 성공도와 효과값을 현재 보상 변수로 전달한다. 기분·데이트 무드·공적 대비 응석/인식·보상 약속/횟수 정리가 작동한다. 이미 진입에서 적용하던 성격·헌신과 2/4/8스파크는 다시 적용하지 않는다. 행동력은 기존대로 주인공·조수 각각 1이다.
- 마사지·커닐링구스: 기존 자극값을 조수별 입력에 연결해 기존 자극/절정 helper와 기분·부드러운 보상 무드·공적별 처리를 실행한다. 기존 감수성·헌신·치유·기술 진행치를 중복 가산하지 않는다. 일반 대응 행동과 같이 주인공만 행동력 1을 소모하고 조수는 소모하지 않는다.
- 마사지의 행동력 회복 조건은 원래대로 주인공 애무 3 이상, 조수의 당일 첫 회복, 조수 행동력 5 미만이다. 조건 충족 시 기존 +1이 공통 차감 −1로 상쇄되던 문제를 없앴다. 무조건 회복하는 새 기능을 만들지 않았다.
- 누락된 해당 유형의 위생·집안 어질러짐을 기존 지정값으로 한 번 적용한다. 새 보상 수식·수치·원고·이미지·영구 저장 필드·로케이션은 추가하지 않았다.
