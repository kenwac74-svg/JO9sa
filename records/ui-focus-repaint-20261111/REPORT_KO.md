사용자 첨부2개에서 여러 화면에 얇은 검은 사각 테두리가 남은 모습을 확인했고, 사용자는 현재 WORK에서도 발생한다고 답했다. 최소화된 게임 창을 열어 둔 뒤 실제 화면을 읽었을 때는 선이 보이지 않았으며 사용자도 현재 미발생을 확인했다. 정상화의 원인이나 문제 해결은 증명하지 않았다.
