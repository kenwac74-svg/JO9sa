# 설명별 이미지 보완 및 배포 문서 등록

사용자 요청: 기존 한·영 HTML에 최근 전투/사망/생존 등 주요 이미지 약 10장을 관련 설명마다 넣고 배포 ZIP에 포함한다.

- 기존 색상과 3개 대분류, 모든 본문 및 게시판 TXT를 유지한다. 새 원고나 게임 변경은 추가하지 않는다.
- 도시 도입 1장, 오우거 전투 1장, 선택·패배 결과 4장, 콜로세움 승리 1장, 이사벨라·에게야 2장, 단체 패배 1장으로 총 10장을 사용한다.
- 캣파이트 승리 후 상대의 처형/생존과 콜로세움 출전 노예의 패배 사망/생존을 캡션으로 구분한다. 조건 수치와 고유 이벤트 결과는 공개하지 않는다.
- 현재 WORK의 실제 자산을 읽기만 하며 최대 560px(도입부 640px)의 WebP로 HTML 안에 넣는다. 외부 파일/서버 의존 없이 800KiB 이내를 목표로 한다.
- 설명과 그림을 섹션별로 묶는다. 작은 카드 여러 개를 높이가 불균형한 채 나열하는 대신 항목별 가로 단락과 반응형 갤러리를 사용한다.
- 영어 캡션 대응, 10장 전부 디코딩, 문장/누적항목/TXT 보존, 모바일 넘침/버튼/오프라인 검사를 수행한다.
- 한·영 HTML 2개만 Full 루트에 추가하고 BUILD_MANIFEST에 등록한다. 게임/QSP/세이브/원본 이미지/기존 ZIP은 수정하지 않는다. 아직 ZIP을 생성하지 않는다.
- 기존 배포 기록은 과거 snapshot으로 보존하고 새 illustrated 기록을 별도로 남긴다. 예전 전체 정리/빌드 스크립트는 재실행하지 않는다.
