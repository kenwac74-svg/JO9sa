# 일반 대사 DB와 캐릭터 시뮬레이터 질문 메뉴

사용자가 확정한 구조를 기존 Claude 편집기 UI에 적용한다.

- 01 캐릭터 정보/이름과 02 배경은 모든 질문의 공통 컨텍스트다.
- 시뮬레이터 사이드바 → 질문하기 → 인상/불만/요구/희망사항/기분/과거/조수·노예 평가/성경험. 이는 화면 내 탭과 같은 상태를 사용한다(후속 사용자 확정).
- 시뮬레이터 본문의 같은 질문 탭과 사이드바를 연결한다. 캐릭터나 배경을 바꾸지 않는다.
- 과거 묻기는 기존 배경 DB/고유 배경 원문을 따른다. 독립된 대사 사본으로 분리하지 않는다.
- 성경험 묻기는 기존 인터뷰/섹스토크 UI를 그대로 사용한다.
- 기존 경력·기록 카드는 별도 작업 탭에 보존한다.
- 게임 DB에 일반 대사 DB를 추가한다. 현재 WORK QSP에서 문장과 성격/말투/관계/표현 단계/질문 메타데이터를 읽는다.
- 일반 대사 후보는 메타데이터 조건으로 찾는 편집용 후보다. 게임 실행 결과라고 표시하지 않는다.
- 공통 DB 문장은 명시적 저장 때 QSP와 변경 mods에 기록한다. 이번 개발에서는 실제 WORK 문장을 저장하지 않는다.
- 인물별 질문 편집은 기존 대사집 `lines`의 `general.<질문번호>` 슬롯을 사용한다. 기존 refs는 인터뷰 키 전용이므로 일반 원문 ID는 브라우저에만 보관한다. 대사집 저장 형식이나 게임 런타임 변수를 추가하지 않는다.
- 기존 브라우저 저장 키, 외형/배경/섹스토크 기능과 원본 Claude 소스는 유지한다. 통합 서버의 override만 확장한다.
