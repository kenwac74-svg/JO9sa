# 엘자 사망 장면의 선택지와 후속 컷

대상은 interaction_city=6667792의 엘자 사망 대사다. 기존 대사를 그대로 두고 하단에 #긍정적 선택지, #부정적 선택지 두 항목을 추가한다. 선택하면 각각66677921/66677922의 결과 장면으로 이동하며 #긍정적 선택 결과 / #부정적 선택 결과를 표시한다. 결과 화면의 기존 다음 화살표는 menu_form으로 이어진다.

사용자가 대사를 직접 작성할 수 있도록 선택지 두 문구와 결과 두 문구는 각각 독립 QSP 문자열로 뒀고 대사 편집기의 일반 대사로 인식됨을 확인한다. 선택 문구는 interaction_screen_city, 결과 문구는 interaction_city에 있다. 선택 전 화면에서는 기존 앞/뒤 객체를 비워 선택을 건너뛰지 못하게 하고, 두 결과 화면은 기존 페이지 넘김을 사용한다.

선택 항목은 기존 local 출력 사본 $jo9_gold_result_text에만 붙인다. 기존 $text와 원래 사망 대사는 변경하지 않아 재출력 시 선택지가 중복되거나 세이브 본문을 오염시키지 않는다. 별도 저장 변수나 로케이션은 추가하지 않는다. 원래 사망 분기의 unique_slave 판정과 공통 완료 기록은 그대로이며 새 선택 결과도 기본 공통 완료 기록을 거친다. 전투 종료·보상·행동력·경험치 정산에 재진입하지 않는다. 이번 단계에서는 긍정/부정 선택에 성향이나 능력치 효과를 부여하지 않는다.

추가 컷의 독립 교체 경로는 content/pic/scene/others/erza_dead_after.png이고 긍정/부정 결과가 공유한다. 새 그림을 생성한 것은 아니다. 현재 erza_dead.png의795×596 원본 사본을 임시로 연결했으며 원본은 유지한다. 사용자가 이 파일을 새 그림으로 교체하면 두 결과 장면에 반영된다. 의도된 임시 중복임을 prepared.json에 경로·해시·용도와 함께 기록했다.

실제 설치 엔진 검증은 red-report.json/green-report.json, 공식 문법·구조·재생·필수9경로 검사는 release-report.json에 기록한다. 개인 세이브를 GUI로 불러와 전투 전체를 진행한 검증은 아니다. 원래 장면에서 실제 생성된 링크 클릭, 각 결과 장면과 이미지 표시, 재출력 중복 방지, 기존 다음 객체의 복귀 경로 및 원사망 처리1회 여부를 확인한다.

WORK와 추적 소스에만 반영한다. Full 배포 폴더·ZIP·커밋·푸시는 변경하지 않는다. 게임을 재실행하고 장면을 다시 출력해야 새 QSP가 사용된다.
