# 프로필 표시 보완

WORK 기준 SHA-256은 `a70bd177d8e7ade58243578b2f04745ff00cec3884d26d3b924dfffc8a8d007a`다. 이 폴더의 산출물은 검토용이며 WORK·배포본에는 직접 쓰지 않았다.

`ui-edits.json`은 정확한 old/new/count 방식의 QSP 표시 수정 29건이다. 루트 구현에서 파산 정산 변경과 함께 합칠 수 있도록 최상위 전후 해시는 넣지 않았다. 기존 코드가 달라져 old가 정확히 한 번 나오지 않으면 적용을 중단해야 한다. 문자열 교체는 JavaScript의 치환 토큰이 작동하지 않도록 `replace(old, () => next)` 형태로 수행한다.

## 바뀌는 표시

- 좌측 특성 넘침 링크를 `특성 전체보기`로 줄인다. 제목·하단 설명·기존 중앙 창과 3열 배치는 유지한다.
- 노예와 조수의 기본 속성 묶음 사이를 5px로 맞춘다. 기존 20px 글꼴에서 우측 `line-height:25%` 간격과 같은 기준이다. 묶음 다음의 중복 줄바꿈을 제거하고 나머지 행·이름·등급의 글꼴과 클릭 동작은 유지한다. 상단의 기존 텍스트 여백 `<br>`는 제거하지 않는다.
- 좌측 테두리 원인: `bg_stat.png`에는 왼쪽 세로 테두리가 없다. `base.css`의 공통 `body:before`가 기존 금속 테두리를 재사용하지만 y=45부터 그려 상단 45px가 비어 있다. 노예·조수 프로필에서만 불러오는 `jo9_traits_view.css`에서 y=0부터 높이800으로 잇는다. 이미지·공통 base.css는 바꾸지 않는다.
- 원본 등급 팔레트를 재사용한다: 0 `#cd0000`, 1 `#EA0090`, 2 `#6B0084`, 3 `#0000D8`, 4 `#009FEF`, 5 `#009900`. 새 특성 중 강한 불이익은0, 가벼운 불이익은1, 일반 이점은4, 큰 이점은5로 표시한다. 이미 원본 등급 색이 있는 기존 성향은 유지한다.
- 아레나·경주 챔피언과 다재다능 등 칭호는 좌측과 중앙 모두 짙은 갈색 `#5c351d`로 통일한다. 기존 글꼴 내부 색도 칭호 표시에서만 덮어쓴다.
- 새 특성 설명16종과 천재·백치·미련한 소의 수치 효과를 정성적인 힌트로 바꾼다. 공통 설명과 여성용 정의 양쪽을 수정한다. 미련한 소의 기존 수동 원고는 보존하고 뒤에 붙은 배율 설명만 바꾼다. 업무·교육·성장·가격·전투 계산은 바꾸지 않는다.

## 세이브와 캐시

새 지속값은 표시 문구 버전 `jo9_profile_text_revision=1`뿐이다. `$ongload`와 `$newloc`에서 이전 버전이면 `#static_txt` 설명 정의를 한 번 갱신한다. 실제 특성 부여·삭제·충돌 정리 코드는 호출하지 않는다. 갱신된 세이브는 이미 새로운 문구와 버전을 저장하므로 다음 조회에서 반복 갱신하지 않는다.

## 검사와 남은 확인

작성 단계에서 JS 문법 검사와 QSP의 바이트 왕복·줄바꿈·표식 경계를 검사했다. 이 문서는 네이티브 플레이 통과를 주장하지 않는다.

`native-ui.cjs`는 루트가 병합한 후보 QSP를 받아 임시 폴더에 노예·조수의 실제 DOM 검사를 만든다. 위·아래 테두리 보완의 계산 스타일, 5px 간격, 빨강·분홍·초록과 칭호 갈색, 짧은 링크 문구를 검사하고 기존 제목·특성 링크를 실제 클릭한다. 클릭은 `elementFromPoint`로 다른 레이어가 가리지 않는지 확인한다. 설명은 실제 하단 콜백까지 조회한다. 두 캐시 검사에서는 이미 기존 특성 버전3인 세이브에도 새 문구가 갱신되는지 확인한다.

진단은 CSS 및 `content/js`를 실제 디렉터리로 복사한다. 수정할 파일의 경로가 정션이면 중단한다. 다른 그림·음향 디렉터리만 원본에 읽기용 정션으로 연결한다. 수정한 CSS/JS를 정션을 통해 WORK에 덮어쓰는 작업은 하지 않는다.

5px 묶음 간격의 계산 검사는 작성했지만 우측 묶음과의 최종 시각적 일치·원본 비율별 실기기 화면은 루트의 네이티브 실행과 화면 검토가 필요하다.
