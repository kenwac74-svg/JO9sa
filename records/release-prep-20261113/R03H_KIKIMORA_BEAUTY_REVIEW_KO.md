# R03-8 키키모라 최저 외모 검토

2026-11-13. 현재 WORK 1ec9e14bb0e95716f4041362e25c811351862a5a7c022615663fc9c42f1fa2b4. 아직 수정하지 않았다.

키키모라의 요구 콜백에는 demand['min_beauty'] > 3가 남아 있다. 이 식은 값을 저장하지 않아 실제 납품에서 이 외모 최저값이 적용되지 않는다. 앞선 아르테미아와 같은 결함이다.

기존 부등호 뜻대로 외모4이상을 저장하는 안을 제안한다. 실제 납품의 ‘외모가 최저값보다 낮으면 거절’ 검사에 연결하고,알려진 옛 저장 요구의 해당 구문만 맞춘다. 적용하면 현재보다 납품 요구가 엄격해진다. 다른 요구·기술·분류·대사·가격·인물·재산·진행은 그대로 유지한다. 남아 있는 기술 비교식은 이 승인에 포함하지 않는다.

승인 뒤 외모3/4 경계와 기존 다른 조건·고객 및 저장 요구의 반복 갱신/수동 편집 보존을 실제 엔진으로 검증한다. 인물별 새 영구 필드는 추가하지 않는다.
