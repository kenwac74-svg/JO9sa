# Jack-o-nine-tails 2.4.2 Kor Full — 배포 안내 초안

**검토용 문서입니다. 아직 배포본·설치 완료 안내가 아닙니다.**

2.4.2는 전체 파일을 포함하는 Full 배포를 준비 중입니다. 이전2.4.1 패치를 차례대로 적용하는 방식으로 안내하지 않습니다. 최종 포함 기능은 릴리즈 노트에서 확인하도록 연결할 예정입니다.

## 설치·실행 안내안

1. 기존 게임·세이브·직접 수정 파일을 별도로 보존합니다.
2. 최종 Full 압축파일을 **새 빈 폴더**에 풉니다. 예전 게임 위에 바로 덮어쓰는 안내는 하지 않습니다.
3. 상위 `Jack-o-nine-tails.exe`로 실행합니다. 실제 포장 후 실행기 이름과 폴더 배치를 재확인합니다.
4. 기존 저장 사용은 아래 호환 범위가 확정된 후 이관 안내를 따릅니다.

## 기존 저장

배포용 세이브 이관 도구와 지원 범위는 개발·검증 전입니다. 현재 구세이브 호환 완료를 보장하지 않습니다. 이관은 원본을 보존하고 다른 출력으로 만들며, 플레이어 작명·육성·장비·관계·진행을 유지하는 기준으로 준비합니다. 최종 도구·지원 버전·지원 저장 지점·복원 절차를 검증한 뒤 이 문단을 확정합니다.

## 최종 확정 대기

- 압축파일 이름·크기·SHA-256와 정상 추출/실행 결과
- 세이브 이관 도구와 지원/제한
- 모드툴/열람표 동봉 범위와 실행 방법
- 실제 화면·음원 최종 확인 결과

이 초안에는 개인 세이브·설정·아이디어·편집 백업을 배포 파일로 넣으라는 지시가 없습니다.
