# 실제 EXE 확인 대기표

사용자가 돌아온 뒤 일반 실행기로 확인할 짧은 경로다. 이번 점검에서 화면·청감을 대신 확인했다고 표시하지 않는다. 테스트 전 원본 세이브를 보존한다.

| 순서 | 화면/상황 | 눈/귀로 확인할 것 |
|---|---|---|
| 1 | 새 실행 → 메인/도시/경매/개인실 | 창 제목과 하단 버전이2.4.2, 레이아웃 잘림 여부 |
| 2 | 아르테미아·레시·키키모라 문의/납품 | 승인 최저값에 맞는 목표 문구·실제 거절/허용. 엔진 경계검사는 이미 별도 완료 |
| 3 | 빈 개인실·기존 개인실 | 베이직/스탠다드 배경과 하단 텍스트 여백 |
| 4 | 글로리아 후임 납품 전후30일 | 같은 날 소문/퀘스트, 기존 진행 보존 |
| 5 | 에게야 영입 후29/30일 → 춘향 | 매물/재개장, 대화/결투/출전, 배경 포함 이미지, 영입/소유 툴팁 |
| 6 | 춘향 전투 | 시작 조소, 일반공격의 회피 상성, 무작위 일섬은 회피로 방어, CM정산/치트 경로 |
| 7 | 도나 기존 영입 인물·역할 이동/재로드 | 높은 육성값·작명·진행 유지,1회 갱신 재실행 없음 |
| 8 | 하드 속성 공개0/10/20일·마법 | 단계 공개와 공개 마법 우선, 마법 종료 후 원래 단계 복귀 |
| 9 | 수동 교체 인물 복장·초상 | 특히 Diane/Snezhana·야스민·글로리아·펠라게야의 실제 최신 그림/프레임 |
| 10 | 효과음·BGM | 거주지곡/명성곡 순환, 게임오버 전용음, 콜로세움·안개·몬스터·처형/석방 |

UI의 검은 선/잔상은 사용자 재발 제보 때 재개한다는 보류를 유지한다. 재현되지 않은 상태에서 CSS/엔진을 바꾸지 않았다. D21 최종판의 실제 불러오기→행동→저장→종료→재로드 검증은 별도 필수다.
