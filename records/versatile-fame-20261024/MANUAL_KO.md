# 다재다능 부여 순간 명성 상승

사용자 확정대로 신규 부여 시 개인 명성이 한 단계 오른다. 주인공의 상표·길드·지역 평판과 별개다. 기준 누적값은0·10·20·40·80·160이며 최고 표시5를 유지한다. 다음 등급의 최소값으로 올려 기존 진행을 지우지 않는다.

기존 jo9_traits_value에 grant_versatile 모드를 추가했다. 입력 $args[1]은 기존 인물 역할(slave/assistant/room 등), 반환 result는 기존0이다. 자동 refresh는 모든24기술이A 이상인 기존 조건이 성립할 때 공통 라벨로 이동한다. 편집기 jo9_traits/edit는0→1에만 같은 helper를 호출한다. 자기 자신을 재귀 호출하지 않는다.

부작용은 인물의 jo9_versatile=1과 원천 role_rate[fame]·표시 role[fame] 갱신이다. temp_fame가 있으면 이를 반영하여 기존 재계산과 일치시키며 원천0~200·표시0~5를 유지한다. 새 로케이션·영구키·세이브 형식 이관이 없다. 이미 보유한 기존 인물은 소급하지 않는다. 반복 refresh/판매가 평가에서는 추가 보상이 없다. 편집기로 해제해도 이미 얻은 명성은 회수하지 않으며 다시 부여하면 새 부여로 취급한다. 평생1회 제한을 새로 추가하지 않았다.

기존 기본 가치+25%, 전체 기술A 획득 조건, manual_off, 외모·절세미인 계산은 그대로다. 명성 원천이 판매가에 미치는 기존 영향은 정상적으로 따라온다. helper를 삭제하면 가치·특성의 기존 호출들도 실패하므로 분리 삭제하면 안 된다. 명성 블록만 제거하면 신규 명성 보너스만 사라진다. QSP의 VERSATILE_* 표식과 patch.json으로 변경 지점을 찾는다. 설명문은 jo9_traits/describe에 있으며 매 호출 실행되므로 별도 문자열 캐시 변경이 없다.

실제 FastQSP에서 자동/수동 부여, 명성 경계·임시값·상한, 기존 보유자·반복·24개 조건 누락·수동 해제/재부여·다른 특성 불변·원래 연속속성 재계산·COPYARR·진단 세이브 저장을 검사했다(313조건 PASS). 공식 출고9경로, 구조·줄/주석 경계·정확 패치 재생/재적용 PASS. 기존 GUI 저장파일 불러오기와 모든 게임 화면 플레이를 전수 확인한 결과는 아니다.

기존 사용자 세이브·CSS·이미지·JSON·Full·ZIP은 보존했다. WORK만 적용했고 커밋·푸시하지 않았다. before.qsp.gz와 패치·재현 스크립트·검사 결과를 남기고 임시진단 자료는 정리했다.
