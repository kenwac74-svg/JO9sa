# 마스터 편집과 양방향 역할 복제

2026-11-15 사용자 승인 구현. 기존 Claude 캐릭터 편집 화면을 공통 코드로 재사용한다. 현재 WORK의 남주인공 18명과 여주인공 24명을 읽는다. 게임 QSP·실제 인물·개인 세이브에 운영 시험 저장/복제를 실행하지 않았다. 도구 코드와 기록만 설치했다. 커밋·푸시·Full/배포 ZIP 갱신은 하지 않았다.

## 사용

- 사이드바 **캐릭터 편집 → 노예 편집 / 마스터 편집**. 검색·목록·페이지·외형·대사집·이벤트 편집의 기존 구조를 유지한다. 마스터 목록은 전체/남주인공/여주인공으로 좁힌다.
- **배경·설정** 안의 **노예용 설정 / 마스터용 설정**을 전환한다. 전환만으로 입력을 지우거나 역할을 바꾸지 않는다. 마스터에 없는 노예용 항목은 전환용 보관값이며, 나이 분류는 편집기 초기값 0에서 조정할 수 있다. 현재 마스터의 실제 나이를 추정한 값이 아니다.
- 마스터의 **마스터 원본 저장**은 WORK `jack.qsp`의 `#masters_base` 해당 번호 배열을 수정한다. 이름·소개·난이도 안내·컬러/세피아 초상 경로와 시작 효과 코드를 편집한다. 이미 시작한 세이브의 주인공 값은 바꾸지 않는다. 난이도 안내 문구는 전투 난이도 설정과 별개다.
- **능력치·특성**은 마스터 시작 값과 원본 시작 효과 코드, 노예 전환용 seed 항목을 함께 제공한다. 코드 내 장비·세력·조건·추가 명령을 보존한다. 복수 대입되는 값은 원본 코드로 편집한다. 자동 추론이나 AI 요청은 하지 않는다.
- 마스터 **외형**은 기존 이미지/얼굴 정렬·테두리 도구를 재사용한다. 전신과 옷차림·얼굴을 `content/pic/master/editor/<번호>/`에 편집용으로 보관한다. 게임의 기존 마스터 초상 PNG는 덮어쓰지 않는다. 게임용 초상 경로는 마스터 배경 설정에서 별도 편집할 수 있으며, 시작 메뉴에 직접 적힌 아이콘 경로는 QSP 이벤트에서 다룬다.
- **노예 캐릭터로 복제… / 마스터로 복제…**에서 새 이름·파일명·번호와 가져올 외형/배경/능력치·특성/대사집을 고른다. 마스터로 복제할 때 남주/여주를 선택한다. 대응표에서 정수를 수정하고 **복제 미리보기 → 새 역할로 복제**한다. 원본을 유지한다. 실제 존재하는 이미지 파일은 새 번호의 별도 경로로 복사하여 원본 편집에 영향을 주지 않는다.
- 마스터 번호는 남성 1~99, 여성 101 이상이며 비우면 빈 번호를 고른다. 노예 복제 번호는 비우면 3000 이상 빈 번호를 고른다. 역할별 같은 번호는 별개이며, 같은 역할에서 번호나 파일이 충돌하면 덮어쓰지 않고 오류를 표시한다.
- 새 노예는 무작위 등장 풀에 자동 삽입하지 않는다. 새 마스터는 정의를 만들지만 기존 게임 시작 메뉴 배치를 자동 변경하지 않는다. **시작 메뉴 미연결** 표기와 QSP 이벤트 탭의 연결 코드(`hero_choice = 번호 & gt 'hero_description'`)를 사용해 연결한다. 정의 생성과 게임 메뉴 연결을 구분한다.
- **원본 데이터**는 실제 QSP 배열과 편집용 보관 JSON을 구분하여 보여준다. 노예의 기존 원본 JSON 탭은 유지한다.

열려 있던 화면은 저장 후 새로고침하거나 전용 앱을 재실행한다. 사용자 작업 중 탭을 자동 새로고침하지 않았다.

## 구조·입출력·저장

`master_editor.py` (`MASTER_EDITOR_20261115`): QSP UTF-16 코드 단위 왕복, 문자열 연결과 중괄호 블록을 실행하지 않고 읽는다. `MasterEditor.list/read/save`, `clone_preview/clone`, `talk`, `images`가 공통 계약이다. 기존 노예 UI의 seed_·story·slots·face·book 형태를 재사용한다. QSP의 알려지지 않은 명령과 다른 위치는 보존한다.

- `GET /api/master/chars`, `/api/master/<id>`: 실제 프리셋과 표시용 공통 캐릭터 객체, revision·master·mappings를 반환한다.
- `POST /api/master/<id>/fields`: `{set,unset,story,master,revision,dryRun}`. 변경 목록을 반환하고 dryRun이 아니면 해당 배열 및 편집 보관값만 저장한다. 처음 QSP 저장 전 `jo9_editor/master-patches/before_first_save.qsp`를 한 번 남기고 이후 각 변경의 before/after 해시와 선언형 mods를 기록한다.
- `GET/POST /api/master/<id>/talkbook`: 마스터 보조 JSON의 대사집. 배경 분류와 대사 선택을 복제에서 독립적으로 처리한다. 저장 요청 revision으로 다른 창의 변경을 확인한다.
- `POST /api/master/<id>/images`: 기존 slots/face 계약. 편집 전용 경로에 PNG와 보조 JSON만 저장한다. 현재 마스터 초상 원본을 덮어쓰지 않는다. 해제는 연결만 없애고 파일은 보존한다.
- `POST /api/role/<slave|master>/<id>/clone`: `{targetRole,name,slug,newId,gender,include,overrides,revision,dryRun}`. 미리보기에서는 파일을 쓰지 않는다. 원래 역할에만 있는 값은 보조 프로필에 보관하여 다시 복제할 수 있다. 데이터·이미지·대사집·QSP 정의를 기존 원자적 파일쓰기 도구로 함께 저장한다.
- 노예 `/fields`, `/images` 응답도 역할 보조 설정·revision·mappings를 유지한다. 나머지 API는 원래 서버에 위임한다.

편집기 보관값은 `game/jo9_editor/role-profiles/<master|slave>/<번호>.json`이다. 게임이 seed로 읽는 노예 JSON은 `json/slaves/`에 기존대로 저장한다. 마스터 전환용 설정을 노예 JSON에 가짜 게임 키로 넣지 않는다. 기존 JSON의 미지정 키와 사용자 수동 값은 복제 시 선택한 범위 안에서 보존한다.

`overrides/studio-view.mjs`는 원본 `createStudioView`에 역할 매개변수를 추가한 사본이다. `studio-role.mjs`는 역할별 URL·설정/능력치/복제 폼을 맡는다. `server.py`가 override를 제공하고 `integration.mjs`가 두 화면을 사이드바에 묶는다. 실행기와 서버가 같은 파일 집합으로 빌드 지문을 계산한다. 원래 Claude dist 파일과 기존 이미지 정렬·테두리 모듈은 바꾸지 않았다.

## 검증·리뷰·한계

- Python 서비스: 문자열·중괄호·여러 줄, 원본 보존, dryRun, 충돌·번호·경로, 역할 변환, 이미지 독립성·크기·해제 보존, 배경/대사 독립 복제, 여러 창의 오래된 원본 차단.
- JS: 역할 URL 분리, 정수 변경 시 명령·주석 보존, 미선택 항목 제외, HTML 이스케이프. 기존 얼굴/검색/리소스 관련 6건도 함께 실행했다. 최종 개수는 `verification.json`, `tests.log`를 따른다.
- 격리 HTTP 실제 저장: 마스터 QSP 저장, 노예 seed+마스터 설정 원자 저장, 노예 이미지 저장 후 역할 설정 유지, 양방향 복제. 임시 QSP·JSON·도형 이미지만 사용하고 정리했다.
- WORK 읽기 전용: 42개 정의 전부 읽기 성공. 실제 브라우저에서 여주 24명 필터·바실리사 배경 전환 및 미저장 값 유지, 시작 능력치 변경 미리보기, 양방향 복제 미리보기 확인. 시험 입력은 버렸고 실제 복제 버튼은 누르지 않았다.
- 독립 리뷰의 중요 지적 2건을 재현 후 수정했다: 대사집 저장으로 오래된 마스터 revision이 새것으로 바뀌어 다른 창의 수정을 덮는 경우, 노예 이미지 저장 응답에서 master/revision/mappings가 사라지는 경우. 회귀 검사로 확인했다. 재리뷰를 반복하지 않았다.
- 전용 앱 재실행과 게임 시작 메뉴/새 인물의 실제 플레이는 이번에 실행하지 않았다. 사용자가 코드·수치를 편집한 뒤 게임 기능까지 검증됐다고 간주하지 않는다. 전체 게임 출고 검사는 반복하지 않았다.

## 제거·복구

현재 UI를 유지하기 위해 별도 iframe을 더하지 않았다. 허브의 override/역할 API/사이드바 연결을 함께 되돌리면 원래 편집기 화면으로 돌아간다. 이번 수정 전 `*.before.gz`와 `changes.diff`를 대조한다. 원본 dist, 실제 게임 자료와 사용자 보조 JSON은 삭제하지 않는다. 마스터 원본을 사용자가 저장했다면 QSP 최초 백업과 각 mods를 보존하여 필요한 항목만 역적용한다. 새 게임 메뉴 미연결 상태는 그대로 명시하며 자동으로 다른 캐릭터를 대체하지 않는다.
