# D21 최종 세이브 이관 보존 항목

이번 작업은 이관 도구 구현이 아니다. 기존 인물배열의 jo9_plain_tone(-1/0/1) 값을 역할과 함께 보존한다. -1은 자동 전환 대상도 유지하는 현재 존댓말 상태다. 기존8명·공주출신을 임의로1로 초기화하지 않는다. 인식/헌신/사육/두려움/응석·소유일·육성·관계·진행을 유지한다.

공주출신 일반노예는 런타임 로드에서 직업·설명·경매표기·work_index만 맞춘다. 과거직업에따른육성·처녀상태를다시계산하지않는다. 새필드없음. D21은 모든 코드/리소스 확정 후 마지막에 진행한다.
