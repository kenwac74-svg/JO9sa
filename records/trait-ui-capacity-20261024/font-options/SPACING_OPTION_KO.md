# 속성 그룹 빈 간격만 줄이는 추가 시안 — 2026-10-24

게임 파일은 수정하지 않았다. 앞선 폰트 실측과 동일한 실제 엔진 캡처 HTML·게임 CSS·폰트로 국소 DOM 시안만 측정했다. 기본 속성 글자는20px, 큰 등급 표시는30px, 목록은16px/16px이다. 기존 일반 특성 제목은 남기고 분류 제목은 추가하지 않았다. 인물 기본 정보와 큰 등급 제목의 위치는 유지했다.

## 변경한 빈 간격 5곳

- 큰 등급/속성정보 제목 뒤와 외모 그룹 사이의 빈 줄을5px로 정리.
- 감수성 뒤, 자아 뒤, 체형 뒤의 그룹 간 빈 줄3곳을 각각5px로 정리.
- 기분 그룹과 일반 특성 제목 사이의 빈 간격을5px로 정리.

노예 원문은 그룹 간3곳에 line-height25% div의5px와 추가 br의20px가 함께 있어 각25px였다. 기분 아래는25% div2개가 합10px였다. 큰 제목 뒤20px 빈 줄도 포함하면25×3+10+20=105px를5×5=25px로 줄여80px를 회수한다.

조수·교육 원문은 같은 위치에 div 대신 연속 br가 있고 각 빈 간격은20px였다. 따라서20×5=100px를25px로 줄여75px를 회수한다. 같은 정리 원칙이며 다른 줄이나 기본 폰트를 줄이지 않았다.

## 실제 Edge 대리 측정

| 화면 | 기존 목록 첫Y | 시안 목록 첫Y | 회수 | 특성12+상태8 마지막Y | 패널790까지 여유 |
|---|---:|---:|---:|---:|---:|
| slave | 516 | 436 | 80px | 756 | 34px |
| assistant | 511 | 436 | 75px | 756 | 34px |
| teach | 511 | 436 | 75px | 756 | 34px |

3화면 모두 기본 속성12개 값의 글자 크기20px가 유지됐다. 해당 값들 사이 겹침이 없고,16px 목록20개 명칭의 자동 줄바꿈·행 겹침도 없었다. 인물 정보와 큰 등급 제목 끝의 차트 아이콘 top좌표도 그대로다. 상태 명칭은 별도 상태 감사의 실제8행 표본을 사용했다. 목록은 용량 확인용 특성 이름 표본이며 새 특성 획득·성격 조합을 게임에 적용한 것이 아니다.

## 해석

상단 배치를 유지하면서 목록만 줄였을 때16px로7특성을 제안했던 것은 '빈 간격을 바꾸지 않는다'는 추가 가정 아래의 대안이었다. 실제로 다섯 빈 간격만 줄이면16px에서도특성12+상태8을 넣고Edge기준34px 여유를 확보할 수 있다. 따라서12개 목표에 대해 **16px목록+빈 간격 정리**를 우선 논의할 수 있고, 기존 간격 유지·특성7개안은 대안으로 남긴다. 아직 게임에 적용하거나 특성 상한을 확정한 뜻이 아니다.

QtWebKit 실제 화면은 이전 대리 측정과20~30논리px 차이가 날 수 있다. 이34px 여유는 그 차이를 고려한 설계 후보이지, Qt 실제 화면에서도 통과했다는 검증은 아니다. 적용을 승인받으면 실제 게임 화면과 폰트 상속·기존 저장의 동적 HTML 갱신을 추가 검증해야 한다.
