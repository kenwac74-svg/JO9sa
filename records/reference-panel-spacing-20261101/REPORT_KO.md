# 오른쪽 정보창의 제목·본문 간격 정리

WORK의 NPC·장소 정보창에서 ‘참고 정보:’를 제거하고 첫 실제 글자 위치를 통일했다. 한국어 제목 27곳과 같은 역할의 러시아어 제목 1곳, 조합 게시판의 단독 콜론을 정리했다. 일반 정보 본문 31곳에 공통 출력을 연결했다.

기본 화면에서 기존 제목 글자의 위쪽은 Y156이고 본문의 줄높이는 25px이다. 요청한 두 줄 아래인 Y206에 본문 첫 글자가 오도록 CSS top을 257에서 203으로 바꿨다. 실제 네이티브 창의 원점·글꼴 여백을 포함한 값이다. 본문 높이는 585px, 글자 크기20px/줄높이25px/기존 폭385px를 사용한다. 이름·부제의 글자, 글꼴과 좌표는 유지한다. 여러 줄인 이름도 본문과 겹치지 않는 대표 표본을 검사했다.

설명 앞의 공백·NBSP·빈 BR은 출력용 로컬 사본에서만 제거한다. 태도가 없는 NPC에서 빈 첫 줄이 생기지 않게 했고 경매장의 별도 태도는 정보본문 첫 줄로 모아 중복을 피했다. 본문 내부의 문단, 링크, 서식과 실제 내용은 보존한다. 원본 NPC·장소 정의와 사용자 편집을 이관하거나 일괄 덮어쓰지 않는다. 파산 회계표·소문 안내는 같은 ID를 쓰지만 별도 화면이므로 좌표를 바꾸지 않았다. 암시장의 인물 속성표도 위치와 내용은 유지하고 참고정보 제목만 제거했다.

정적 대조는 소개954개·태도19개, 총973개 리터럴 정의와 동적 장소등록 인수를 검사했다. 이 중 선행 빈 요소가 있는427개에도 동일한 정규식을 대입해 단어·잔여 HTML·본문 내부 문단 손상0을 확인했다. 계산으로 생성되는 모든 문자열이나 모든 기존 SAV를 직접 화면에 띄운 검사는 아니다.

실제 설치 엔진에서는 엘리자베스·바이너·상류신사 모임, 선행BR이 있는 웡, 태도가 없는 바이너, 두 줄 이름인 모르게레나, 도시 경로의 상류신사 모임까지7경로를 비교했다. 첫 글자 Y206, 이름/부제 원형, 가시문자와 내부 문단,20px/25px, 창 안에 들어오는지 모두 통과했다. 긴 엘리자베스 설명의 끝은 Y726으로 본문 경계Y789 안이다. 혼합 공백/BR/NBSP, 서식과 중간BR, 빈본문, 태도만 있는 경우, 로컬 변수 복구도 실제 엔진에서 검사했다.

공식 출고 검사는 파일 구조·CRLF·주석 경계·패치 재생/재적용·인물 ID 등록·설치 엔진9개 경로를 포함한 PASS다. 개인 SAV를 불러와 모든 장면을 수동 플레이한 결과로 확대하지 않는다. 재실행 후 해당 인물·장소 화면을 다시 열어 확인한다. 이미 열린 옛 게임 프로세스나 저장된 화면 HTML에는 과거 출력이 잠시 남을 수 있다.

WORK와 추적 패치·CSS만 반영한다. 배포 폴더·ZIP·커밋·푸시는 이번 작업에서 변경하지 않는다. 전후 해시, 백업과 설치 결과는 prepared.json/installed.json, 문구 대조는 source-audit.json, 화면 근거는 green-report.json/independent-native-summary.json, 공식 검사 결과는 release-report.json에 있다.
