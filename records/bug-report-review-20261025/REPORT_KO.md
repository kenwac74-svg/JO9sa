## 조사 범위와 한계

정적 증거를 독립 assertion으로 다시 확인했다. QSP parse와 입력 SHA256, 높은 레이어/MSG 연결,6개 잘못된 링크와 정상 조수 비교, 메뉴135 호출/허용목록 누락,2개 JSON 오기와 실제 파일 존재 여부를 확인했다. 이는 사용자의 저장 파일에서 실제 GUI 증상을 재현하거나 수정안을 적용/검증한 결과가 아니다. 다른 이미지 누락 전체를 모두 버그로 세지 않았다.

마법낙인 제보는 전달 제보이며 착용 여부를 모른다는 응답 뒤 사용자가 “마법낙인은 추후 테스트로 재현한 뒤 수정하겠어”라고 지시했다. 장비 소지와 착용을 혼동했다고 단정하지 않는다. 현재 이벤트 조건은 명기를 허용한다는 사실만 확인했으며 사용자의 상태를 추정해 수정하지 않는다.

이미지 경로는 actor 캐시에 복사되므로 JSON 교정만으로 기존 세이브의 잘못된 문자열까지 고쳐졌다고 판단할 수 없다. 실제 저장을 일괄 덮어쓰거나 인물의 수치·설정·그림 선택을 임의 초기화하지 않는다.
