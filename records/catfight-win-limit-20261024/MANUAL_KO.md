# 캣파이트 누적 3승 출전 제한 수리

패치: `2026-10-24_catfight_win_limit`. 2026-10-24 사용자 승인으로 WORK만 반영했다. 이번 단계는 승수/출전 제한 수리이며 명성 확장은 포함하지 않는다. 다음 미구현 항목은 결과 보고 후 별도 승인을 받는다.

## 바뀐 동작

- 새 승리는 `0→1→2→3`으로 누적된다. **세 번째 승리까지 가능하고, 3승 달성 뒤 다음 경기는 출전할 수 없다.**
- 패배·도주·기절 후 생존한 인물의 누적 승수를 깎지 않는다. 연승 초기화·기절 패배 기록·상처·기존 패배 결과는 그대로다.
- 승수는 전투 종료의 캣파이트 분기 한 곳에서만 가산한다. 주인공 두 분기의 결과 화면에서는 다시 가산하지 않는다.
- 낡은 경기 직전 링크로 직접 시작하더라도, 3승 이상이면 전투 초기화 전에 기존 클럽 메뉴로 복귀한다. 안내 문구 두 곳도 “세 번 이상”으로 맞췄다.
- 원래 있던 콜로세움식 5승 처리를 캣파이트에서 제거했다. 5에 도달한 승리를 패배 화면으로 보내던 분기도 함께 사라졌다. 저장된 기존 전투 스타일 값은 지우지 않는다.

## 원인

원본부터 `выход_из_боя`에서 +1, `interaction_city`의 주인공별 결과 분기 중 한 곳에서 다시 +1이 실행됐다. 정상적인 무패 기록이 `0→2→4`가 되어 메뉴의 `<3` 조건에 걸렸다. 패배 때 -1이 있어 값이 순수 승리 횟수도 아니었다. 같은 블록에는 입장 상한과 맞지 않는 5승 승급/스타일 처리까지 남아 있었다.

## 기존 세이브

기존 세이브 파일 76개는 변경하지 않았다. 이미 저장된 승수는 부풀려진 가산과 패배 차감이 섞여 정확한 역산이 불가능하므로 초기화·절반 감산·일괄 제한하지 않았다. **기존 값이 3 이상이면 다음 출전부터 제한된다.** 이미 전투 중이던 저장은 결과를 한 번 정산하고 이후 출전이 막힌다. 역할 교환 시 승수는 원래 인물 배열과 함께 이동한다.

저장된 결과 화면만 다시 읽는 경로에서도 승수를 추가하지 않는다. 기존 결과 화면의 상금/성장 전체를 새 멱등 처리로 바꾼 패치는 아니므로, 일반적인 임의 스크립트 재실행까지 중복 보상이 없다고 확대 해석하지 않는다.

## 검사

1. 수정 전 실제 엔진에서 첫 승리의 예상 1승 검사가 실패하는 것을 확인했다.
2. 같은 실제 엔진으로 **62상황·464조건 PASS**. 남/여 주인공, 0/1/2/높은 기존 승수, 도주/기절 후 생존, 상금300과 성장 통계, 직접 결과 진입, 메뉴/시작 3승 경계, 빈 노예/행동력 부족/콜로세움 기존 제한, 다른 인물/명성 보존 및 역할 교환을 검사했다.
3. 낡은 준비 상태 `sp_txt=3`, `skip_to=14`를 주입해 차단 뒤 1/0과 클럽10201로 복귀하는 것도 검사했다.
4. 구조·줄바꿈/주석 경계·정확 패치 재생/재적용·인물 JSON1,126개 등록 및 **공식 실제 엔진9경로 PASS**. 설치 WORK가 그 후보와 바이트 동일함을 확인했다.
5. 관련 검사 도구 회귀 **37/37 PASS**. 일부 로그의 충돌 FAIL은 의도적으로 잘못된 인물 JSON을 넣는 방어 테스트이며 실제 설치 등록 오류가 아니다.
6. 독립 검토에서 세 본문/다른 본문 불변, 원본 콜로세움 분기 불변, 정확 패치 재생, 실제 진단본의 생산 로직 유지 확인. 초기 재현 스크립트의 시험 조건 불일치를 최종본에서 정정했다.

첫 GREEN 시도는 패배의 생존 조건을 고정하지 않아 기존 사망 분기로 인물이 해제되면서 통계 기대값이 실패했다. 게임 코드를 바꾸지 않고 시험 인물의 용기 조건을 고정해 생존 분기를 검사했고, 그 실패 이력도 남겼다. 마지막 PASS 후 동일 후보를 WORK에 적용했다.

기능 검사는 실제 FastQSP에서 상태를 주입해 전투 종료·결과 효과·메뉴 생성·전투 초기화·역할 교환을 실행했다. 최종 그림 출력 끝점만 검사 코드로 바꿨다. 실제 `.sav` 로드 UI, 전투 AI를 포함한 3경기 연속 화면 조작, 모든 동적 분기나 전체 QSP 문법의 정식 증명은 아니다. 공식9경로의 일반 한계도 그대로다. 이전 감사의 오래된 문구 회귀 테스트 및 시험 세이브 생성기 결함은 이번 수리 범위 밖이며 미결로 유지한다.
