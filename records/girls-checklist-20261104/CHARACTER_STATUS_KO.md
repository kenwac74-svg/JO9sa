# 캐릭터별 작업 상태

사용자 최종 지시: 파일별이 아니라 캐릭터 번호별로 8개 상태를 관리한다. 각 카드 제목 아래 한 묶음의 상태 태그를 표시하고, 상단 태그 버튼으로 캐릭터를 모아 본다. 번호 오름차순·내림차순·이름순 정렬도 제공한다.

상태는 catalog_status.js의 characterItems에 저장하며 기존 파일별 items는 유지한다. 같은 그림을 쓰는 캐릭터도 ID별로 독립한다. 태그 체크는 그림·캐릭터 JSON·QSP를 변경하지 않는다. 실제 웹 저장·새로고침·필터와 사이드바 접기/펼치기를 확인했고 검사용 태그는 원래 상태로 되돌렸다.
