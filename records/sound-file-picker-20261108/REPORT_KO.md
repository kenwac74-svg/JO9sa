# 사운드 폴더·파일 선택과 검토 상태 — 2026-11-08

사운드 청취 목록에 폴더 선택, 여러 음원 파일 추가, 개인 음원 청취, 후보별 파일 지정·해제를 추가했다. 기존 Pixabay 후보 46개 링크와 BGM 블록을 보존했으며 후보/BGM별 62개 로컬 배정 영역이 있다.

각 후보 A/B, 지역 BGM, 개인 음원에 재제작·채택·보류 버튼을 붙였다. 한 항목에는 한 상태가 적용되며 같은 버튼을 다시 누르면 해제된다. 상태는 목록의 검토 결과로 저장되며 게임 연결을 실행하지 않는다.

## 사용

열어 둔 청취_목록.html을 새로고침한다. 폴더 선택 또는 음원 파일 추가로 파일을 고른 뒤, 각 후보의 파일 지정/개인 음원 선택으로 배정한다. 재제작·채택·보류로 검토 결과를 표시한다.

브라우저 저장과 설정 JSON에는 이름·상대경로·크기·수정시각·배정·검토 상태만 들어간다. 음원 바이트를 복제하거나 외부에 전송하지 않는다. 다시 열면 목록과 상태를 복원하고, 재생에는 같은 폴더/파일 재선택이 필요하다.

같은 이름이 여러 폴더에 있을 때 BGM을 임의로 고르지 않는다. 명시적으로 배정한 파일이 아직 연결되지 않았을 때 다른 음원으로 자동 대체하지 않는다. 같은 식별 정보의 다른 파일도 기존 File을 조용히 덮어쓰지 않고 안내한다.

## 확인

- 음원 필터·동명 파일·상대경로·설정 복원·배정/해제·상태 토글/복원·스크립트 이스케이프·설정 가져오기 후 파일 정리·동일 파일 정보 충돌·원본 후보 보존 검사 12개 통과.
- 설치 소스로 HTML 재생성 성공. 소스 문법과 생성 HTML의 스크립트 2개 문법 검사 통과.
- 설치 전후 QSP 해시 유지. 게임 음원과 원본 문서는 읽기만 했다.
- 실제 브라우저 파일 선택 대화상자, 음원 디코딩/재생, 재열기 후 UI 복원은 사용자 확인 대기다. 기존 file: URL 정책 차단을 우회하지 않았다.

구현 입력·출력, 저장 비용과 재선택 조건, 빌드·검사는 tools/sound-audition/README.md에 있다. 설치 전 build.cjs와 청취_목록.html gzip 복구본은 installation.json에 기록된 경로에 있다. 최종 소스와 바이트가 같은 staged 7개는 정리했다.
