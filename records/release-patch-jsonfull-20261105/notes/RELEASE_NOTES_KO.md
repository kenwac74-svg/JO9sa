# 2.4.1 추가 패치 — 2026-11-05

잭 오 나인 테일즈 한국어판 **기존 2.4.1용 덮어쓰기 패치**입니다. 하드 난이도의 행동력·판매 경제를 조정하고, 캐릭터 전신과 복장 이미지, 일부 번역과 관리 화면을 정리했습니다. 전체 게임이 포함된 독립 실행판은 아닙니다.

## 주요 업데이트

### 하드 난이도와 판매 경제

- 이번 조정은 **게임 설정의 난이도**를 기준으로 적용합니다. 캐릭터 생성 시 고르는 난이도와는 별개이며, 쉬움·보통의 기본 행동력은 유지합니다.
- 하드에서 노예·조수·개인실 인물의 기본 최대 행동력은 지구력 0~5에 따라 **0·1·2·3·4·5칸**이 됩니다. 쉬움·보통은 기존 **0·2·3·4·5·5칸**입니다. 생성·취득·표시·하루 회복에 같은 기준을 적용하며, 부상·반 칸·추가 보너스는 별도로 계산합니다. 주인공 행동력은 유지하고, 난이도를 보통으로 돌려도 남은 행동력을 즉시 채워 주지는 않습니다.
- 하드에서는 지정된 특성의 판매 프리미엄 **가산분**을 절반 적용합니다. 예를 들어 다재다능의 +25%는 +12.5%가 됩니다. 기본 가격이나 최종 판매금 전체를 절반으로 낮추는 방식은 아닙니다.
- 일반 판매의 **6,000/8,000 강제 지급 상한을 제거**했습니다. 기존 구매자 예산은 유지합니다.
- 하드에만 판매세를 적용하고, 결과 화면에서 총액·세금·실수령을 함께 안내합니다. 쉬움·보통에는 이 판매세가 없습니다.

| 거래 총액 | 세율 | 실수령 예 |
| ---: | ---: | ---: |
| 5,999 이하 | 0% | 5,999 → 5,999 |
| 6,000~9,999 | 5% | 6,000 → 5,700 / 9,999 → 9,500 |
| 10,000 이상 | 10% | 10,000 → 9,000 |

세율은 구간 초과분이 아니라 **거래 총액 전체**에 적용하며 세액의 소수점은 버립니다. 따라서 경계를 넘을 때 실수령이 줄어들 수 있습니다. 새 위탁 거래는 건별 세후 금액으로 정산하고, 기존 저장에 쌓여 있던 미수금에는 소급·이중 과세하지 않습니다.

### 캐릭터와 이미지

- 여러 캐릭터의 전신 구도와 인물 크기를 조정하고, 대응하는 하녀 복장도 크기·위치를 맞췄습니다. 일부 전신·초상·장비 표시용 이미지도 갱신했습니다.
- **펠리시티(2572)**의 기본 전신을 교체하고, 하녀·도미나·비서 복장의 머리 높이와 인물 크기를 새 기본 전신에 맞췄습니다. 기존 기본 전신의 두 호출 주소를 모두 유지합니다.
- 옛 복장 등록과 새 등록 방식의 이미지 조회를 연결했습니다. 상태별 그림이 없을 때는 같은 복장의 유효한 그림을 찾고, 필요하면 기본 전신으로 표시합니다. 등록되지 않은 복장 선택지가 새로 열리는 변경은 아닙니다.
- **이사벨라(2571)**의 현재 외형과 옛 외형을 쓰는 일반 캐릭터 **2323**의 이미지 주소를 구분했습니다. 기존 저장의 공유 주소도 인물에 맞게 처리합니다.
- **루미너스**의 의복 영입 이벤트 이미지를 연결하고, 구매 메뉴에서 츠키로 나오던 이름을 바로잡았습니다.
- **2071의 갈색 장발**, 기존 **2324의 하늘색 단발**, **2340의 금발 단발**을 구분해 전신·초상을 연결했습니다. 2340은 기존 금발 외형을 별도 정의로 등록한 것이며, 새로 그린 원화 한 세트라는 뜻은 아닙니다.
- 출시본 이후 추가된 일반 캐릭터 정의 **2339·2340**을 반영하고, 무작위 생성과 이미지 연결을 정리했습니다. 옛 저장에 필요한 호환 이미지 주소는 보존합니다.

### 번역과 관리 화면

- 일부 인물의 출신·가족·직업·관계 설명과 이름 표기를 한국어로 정리했습니다. 기존 저장에 남은 일부 원문도 표시할 때 한국어로 치환합니다. 모든 미번역 문장을 해결한 패치는 아닙니다.
- 식품·재료·물약·가구/용품 창고를 **4열**로 정리하고 재고 합계를 표시합니다.
- 연금실의 인물 배치, 재료·물약 **2열** 표시와 담당자 숙련도 안내를 정리했습니다.
- 일부 인물·약품·재료 이름을 메뉴·설명·기존 저장 표시에서 일치시켰습니다.
- 세력 영향력 치트의 가문·지역 평판 조절 버튼과 평판·거주권 안내를 보완했습니다.

## 버그 수정과 안내 보완

- 일부 고유 인물의 전신·초상 경로와 하녀 복장 연결을 보완했습니다.
- 윌헬미네의 특성 키 오타를 수정했습니다.
- S+ 승급 안내의 부족 기준을 실제 판정인 **25**에 맞추고, 콜로세움 출전 인물의 갑옷 조건 안내를 명확히 했습니다.
- 카오틱 에센스의 대상 후보와 보호 목록을 정리했습니다. 부정 대상이 없으면 상황형 후보를 확인하며, 모든 부정 특성을 무조건 제거하지는 않습니다.
- 일부 특성의 크기 조건 판정과 성향 누적 연결 오류를 수정했습니다.

## 설치와 기존 저장

이번 ZIP에는 **game/json 전체**가 포함됩니다. **INSTALL_KO.txt**를 확인한 뒤 아래 두 방법 중 하나로 설치하세요. 개인적으로 추가한 JSON이 있다면 설치 전에 게임 폴더 밖에 보관하세요.

### 자동 설치

1. **게임을 종료**하고 ZIP의 압축을 풉니다.
2. 압축을 푼 폴더의 **INSTALL.cmd**를 실행합니다. 기존 게임 폴더를 자동으로 찾지 못하면 설치할 게임 폴더를 한 번 선택합니다.
3. 설치를 마치면 기존 실행 파일로 게임을 시작하고 저장을 불러옵니다.

### 수동 설치

1. **게임을 종료**합니다.
2. 기존 설치의 **game/json 폴더만 삭제**합니다. **game 폴더 전체를 삭제하지 마세요.**
3. 압축 안의 **game 폴더를 기존 게임 실행 파일 옆의 game 폴더와 합쳐 덮어씁니다.**
4. 기존 실행 파일로 게임을 시작하고 저장을 불러옵니다.

세이브 폴더는 삭제 대상이 아니며 별도 저장 변환도 하지 않습니다. 모든 기존 저장과 장시간 플레이를 전부 확인한 것은 아니므로, 문제가 생기면 발생 메뉴·직전 행동·해당 저장 정보를 함께 알려 주세요.

## 기타

이번 안내는 **2.4.1 이후의 추가 변경**을 대상으로 합니다. 이전 2.3→2.4 개편 전체를 다시 나열하지 않았습니다. 독립 모딩 도구의 개선 내역은 게임 패치의 신규 콘텐츠와 구분합니다.

한국어판 개편·이번 패치: **SAnk**. 원작 올드 헌츠맨, Graylor의 FastQSP, 역대 개발진·한국어판 제작진과 리소스 기여자에게 감사드립니다. 상세 크레딧은 기존 게임 내 안내를 따릅니다.

## 확인 범위

최종 QSP는 네이티브 엔진의 필수 9경로 검사를 통과했습니다. 실제 게임 EXE와 기존 SAV를 불러온 화면의 육안 확인은 수행하지 않았습니다.
