# 하드모드 속성 공개 규칙 개정 계획

기준: 2026-11-15 사용자 확정. WORK 전용이며 배포본·음원·개인 SAV·커밋·푸시는 수정하지 않는다.

**목표:** 장비 포함 마법력 A 이상 즉시 전체 공개, B/C는 감수성·태도·자아만 지연, D/F는 기존 6속성만 즉시 공개. 지연 항목은 모두 유효 체류일 10일 후 공개한다. 리벨리스 효과가 있으면 즉시 전체 공개한다.

**상태:** 인물 배열에 `jo9_observation_days` 1개, 기존 인물 전체 공개의 일회 처리를 위해 전역 `jo9_observation_revision` 1개가 필요하다. 기존 실제 소유일수 `age_count`는 유지한다. 기존 저장의 이미 보유한 인물은 누적 10일로 초기화한다. 새 게임은 이 보정을 하지 않고, 새 영입 인물은 0일부터 센다.

**누적 장소:** 노예·조수·개인실 1~4. 감옥·크라이오·외양간(지기/소/닭/돼지)은 누적 중단. 이동해도 쌓인 일수는 유지한다. 기절 여부와 무관하게 장소로 판단한다. 일반/이지에서 보낸 유효 체류일도 기록하되 공개 제한은 하드에만 적용한다.

**수정 파일:** `jo9_attribute_visibility`, `$ongload`, `init_game`, `next_day`의 선언형 패치. WORK/추적 QSP와 runtime 원장을 최종 동기화한다. 기존 출력 84곳과 툴팁은 공통 helper를 재사용한다.

- [ ] 현재 WORK에서 새 마법력 조건·10일 경계·누적·기존 인물 보정 검사의 RED 확인.
- [ ] helper, 기존 저장 한 번 보정, 새 게임 표시, 일일 누적 callback 최소 수정.
- [ ] 실제 FastQSP에서 등급/장비 효과/리벨리스/보유 전/0·9·10일/모든 역할/역할 이동/반복 로드/원값 보존/84 출력식·툴팁 검증.
- [ ] 구조·CRLF·마커·정확 패치 재생/멱등/역적용과 관련 실행 경로 확인 후 WORK/소스/원장 반영.
- [ ] 보고서·사용법·변경 기록 보존. 재생 가능한 진단 QSP·SAV 정리.
