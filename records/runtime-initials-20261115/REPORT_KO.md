# 캐릭터별 실제 QSP 초기값 — 2026-11-15

기본은 게임 난이도 **보통(game_difficulty=1)**, 복종 난이도 **보통(difficulty_setting=0)**이다. 두 값은 게임에서 독립적이므로 선택기도 구분했다. 주인공은 처음에 밀로드이고, 선택한 기준은 브라우저에 보관한다.

## 표시와 편집

캐릭터 편집 → 능력치·특성과 캐릭터 시뮬레이터 상단에서 주인공·난이도·영입 경로·CM을 선택한다. 현재 WORK QSP와 JSON을 읽어 격리 엔진에서 생성, 실제 경로 후처리, 장비·속성·기분·정신·복종도 재계산을 수행한다. JSON 저장 전 변경도 가상 엔진에만 적용한다. 숫자 입력을 마친 change 시점에 다시 계산한다.

01·02번 창은 읽기 전용이다. 일반 산식을 수동으로 이식한 공용 초기값 표시는 제거했다. 계산 전/실패는 값처럼 0으로 표시하지 않는다. 편집 입력은 JSON 지정값, 아래 배지는 QSP 적용 결과로 구분된다. 기존 역할 프로필의 수동 시험값은 삭제하지 않으며 실제 초기값 표시와 섞지 않는다.

랜덤 생성은 옛 표본 파일 대신 현재 generate_stock과 실제 일반 영입 함수를 실행한다. 난이도 변경은 생성 직후의 동일 가상 상태를 다시 사용하므로 이름·추첨 능력치·특성을 다시 뽑지 않는다. 행동력 보정은 현재 QSP의 생성식으로 갱신하되 별도 영입 경로의 고정값은 보존한다. ‘다시 생성’을 누를 때만 새 QSP 난수 추첨으로 넘어간다. 최근 24개 생성 상태를 서버 메모리에 유지하며 만료 상태는 자동 재추첨하지 않고 안내한다.

## 근거와 실행 흐름

정적 기반을 refresh_database 순서로 적재한 뒤 init_game/init_story_mode, 선택 주인공의 $master_version_stats, hero_description의 에너지 설정과 start_game의 9/10번 예외, $calculate_attributes를 실행한다. 난이도는 초기화 뒤 적용한다. 전체 JSON 1,885개의 숫자 접두사 ID와 단일 값 배열을 적재한다(접미사 파일명 포함). 선택 영입 코드의 원문 일치를 확인하고 경로를 실행한다. 마지막에는 $slave_traits → $main_screen_slave_characters의 실제 순서로 $newloc_update_slave → $calculate_attributes를 실행한다. 생성 미리보기(stock)는 해당 stock을 갱신한다. 대상별 장악력은 jo9_supermacy를 호출한다.

고유 영입 경로 115개 후보/106개 ID를 연결했다. 2339·2577·2578·2608은 현재 확인된 영입 대입이 없어 **템플릿 생성 · 게임 영입 경로 아님**으로 표시한다. 일반 모브와 완전 랜덤은 일반 영입이 기본이다. 경로 조각이 현재 QSP와 일치하지 않으면 그 경로를 비활성화한다. 글로리아 가격별 경로 등은 영입 직전 전제조건을 갖춘 결과 미리보기이며, 진행 중 세이브의 모든 퀘스트 변수를 복원하는 기능이 아니다.

## 엔진과 한계

기존 QA에 있던 공식 MIT @qsp/wasm-engine 1.0.0(엔진 5.8.0)을 최소 파일+라이선스로 번들했다. FastQSP 호스트는 5.7.0을 표기하므로 다음 호환 어댑터는 가상 메모리에만 적용한다: FOR→LOOP, 파일 존재 검사→실제 PIC 읽기 전용 목록, 숫자 ID와 충돌하는 미사용 레거시 문자열 타입명 3개 분리. 마지막 어댑터는 실제 교환/퀘스트 조수 코드에서 ID 소실과 복구를 격리 검증했다. 네이티브 FastQSP와 모든 캐릭터의 전체 동등성을 검증한 것은 아니다. 외부 실행·입력·저장/불러오기 콜백은 계산을 중단하며 임의로 성공시키지 않는다.

## 확인

runtime-test-results.json의 8개 집중 검사를 통과했다. 보통→어려움에서 동일 인물의 복종도만 실제 산식에 따라 달라지고 보통으로 복귀하면 수치·단계 전체가 정확히 일치했다. 저장 전 JSON 반영, 퀘스트 조수, 잘못된 경로/만료 상태 차단, 실제 무작위 생성과 명시적 재생성도 확인했다. 대표 경로 이사벨라·시루·글로리아·춘향·퀘스트 조수·직접 영입·랜덤의 실행 결과를 확인했다. 브라우저에서 기본 보통 선택, 실제 이사벨라 상태, 읽기 전용 표시, 기존 색상/3열 기술 구조를 확인한다.

WORK QSP SHA-256은 작업 전후 d9e54998be9b9d2dbb56e69c1d464c582d6e047ea7c44ed9d50c03134b506c33으로 동일하다. 게임 QSP/JSON/세이브/배포본은 수정하지 않았다. 커밋·푸시는 하지 않았다. 기존 사용자 탭은 새로고침하지 않고 별도 배경 탭으로 화면을 확인했다.

재시작 시 TIME_WAIT를 다른 서버 충돌로 오인해 포트가 이동하는 실행기도 수정했다. 실제 LISTEN 중인 포트는 제외하고, HTTPServer와 같은 주소 재사용을 사용하며 명시한 -Port를 우선한다. 원래 7689 주소로 복구했다.

## 유지보수

runtime_initials.py는 로컬 서버의 읽기 전용 POST /api/runtime-initials를 제공하고 숨긴 Node 자식 하나를 직렬 사용한다. QSP/JSON 파일 서명이 바뀌면 가상 엔진을 재시작한다. 종료 시 파이프를 닫고 엔진을 정리한다. runtime-initials.cjs 제거 시 실제 계산이 중단되며 공용값으로 대체되지 않는다. acquisition-routes-runtime.json은 현재 경로 참조이며 QSP 편집 후 원문이 달라진 경로는 별도 재분석해야 한다. 원상복구는 files.json과 before/*.gz를 참고한다. 새 파일은 사용 경로를 제거한 뒤 정리한다.
