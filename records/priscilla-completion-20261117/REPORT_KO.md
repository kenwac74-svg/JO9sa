# 프리실라 신규 보상 장면 완료 효과

사용자 요청에 따라 현재 WORK의 `interaction_city = 6028` 장면 마지막 7페이지에만 완료 효과를 추가했다. 기존 장면 원문, 페이지 수와 이미지 참조는 그대로 보존했다.

- `priscilla_slv = 1` 정수 플래그를 마지막 페이지에 부여한다.
- 기존 기분 등급 5가 `황홀함`이다. `master_mood`는 화면 전환 시 기존 `$moodlets_account`에서 다시 계산하므로 단순 대입 대신 현재 활성 기분 요소를 유지하며 필요한 기존 `master_mood_rate` 최솟값을 계산한다.
- 계산은 `필요 rate = 50 - 활성 긍정 요소 수 × 10 + 활성 부정 요소 수 × 15`, 적용은 `max(기존 rate, 필요 rate)`이다. 기분 요소의 값과 기간을 바꾸거나 기존 rate를 낮추지 않는다. 임시 계산 변수는 모두 local이며, 별도 지속기간 필드를 추가하지 않았다. 기존 `next_day`의 일일 rate 초기화는 수정하지 않았다.
- `$special_action[7]`은 기존 마지막 페이지 표시 콜백이다. 앞의 1~6페이지에서 두 효과가 발생하지 않는다. 재표시해도 rate가 반복 증가하지 않는다.

수정: WORK `game/jack.qsp`, 추적 `assets/runtime/2.4.1/jack.qsp`, 두 QSP 해시 명세, `mods/2026-11-17_priscilla_service_completion.json`, 이 기록. Full·배포 ZIP·개인 세이브는 수정하지 않았고 커밋·푸시는 하지 않았다. 작업 직전 원본 백업과 추적 소스의 이전 본문 차이만 `G:/Codex/tmp/priscilla-completion-20261117`에 보관한다.
