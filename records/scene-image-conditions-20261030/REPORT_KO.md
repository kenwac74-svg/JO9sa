# scene 이미지 재현 조건 표시

현재 WORK의 scene 이미지 1109개를 분석해 이미지 체크리스트 각 카드에 등장·재현 조건을 반영했다. 직접 연결 708, 무작위 258, 동적 후보 4, 이미지 전환용 9, 실행 연결 미확인 130개다. 기존 카드와 상태값을 보존하고 실제 파일이 목록에서 빠졌던 6개만 추가했다.

각 카드에서 상세 조건을 펼치면 진입 메뉴, 메뉴 표시 조건, 이벤트 분기, 이미지 슬롯·페이지, 코드 위치를 확인할 수 있다. 상위 이벤트로 이어지는 소스 조건도 별도로 펼친다. 전체 실행 경로를 보장하는 공략이 아닌 현재 코드의 정적 근거다. ELSE는 그 외 분기로 표시하며 동적 호출·세이브 상태를 모두 실행하지는 않았다. 실행 연결 미확인은 미사용 또는 삭제 가능 판정이 아니다.

12개 자동 검사와 양쪽 HTML의 모든 인라인 JS 문법 검사, 기존 목록 보존, 1,109개 포함 검사를 통과했다. 실제 브라우저에서 콜로세움 종료 조건 펼침, 실행 연결 미확인 표시, 암소 제안 메뉴 조건, 검색 후 표시 유지와 사용자 탭 새로고침을 확인했다. 모든 씬을 플레이로 재현한 것은 아니다.

QSP·체크 상태·대표 기존 세이브 해시는 변경 전과 같다. 이미지·게임 동작은 수정하지 않았다. 배포 폴더·커밋·푸시는 작업 범위에 포함하지 않았다. 도구 입력·출력·의존성과 제거 영향은 tools/scene-image-conditions/README_KO.md에 기록했다. 원본 카탈로그 gzip 복구본은 G:/somi/JO9_work_backups/scene-image-conditions-20261030 에 있다.
