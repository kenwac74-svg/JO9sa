# 잡파 위탁 인물 보관·회수 수리 — 승인 범위

사용자가 2026-10-28 보고된 첫 미수정안에 대해 “반영해”로 승인했다. 위탁 인물 전용 보관 데이터1세트를 추가하고, 반환 성공 후에만 기존 수수료$5와 위탁 기록을 정리한다. 추가 위탁·다음 날 정산은 한 번만 처리한다. 기존 저장에서 동일인 근거가 없으면 인물을 추정 복구하거나 새로 생성하지 않고 무료 회수 불가 안내와 기존 대금 정산을 보존한다. WORK에만 반영하며 다른 미수정안·배포·커밋·푸시는 다루지 않는다.

구현은 기존 $slave_vars 23개 묶음 정의를 사용한다. 기존 swap과 새 노예 초기화는 특성·이력값을 변경하므로 보관/반환에는 copyarr 부분만 재사용해 이름·장비·신규 특성·비표준값을 보존한다. 보관 역할은 일반 소유·일말·파산 자산 목록에 등록하지 않는다.
