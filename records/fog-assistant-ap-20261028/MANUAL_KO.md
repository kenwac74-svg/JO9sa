# 조수 안개전투 행동력 비용

2026-10-28 `10/28 제보부터 다 해결하자` 지시에 따라 앞선 주인공1·조수2 제안을 WORK에 반영했다. 과거 원본의 결함으로 소급 표현하지 않고 조수 선봉 비용 조정으로 기록한다. 기준 f6520ef1 → 결과 e8300284. 설치·직전 백업의 전체 경로와 해시는 `installation.json`을 따른다.

## 동작과 영향

기존 `jo9_fog_relay` 한 로케이션에서 두 블록만 바꾼다. `FOG_ASSISTANT_MIN_TWO_20261028`는 조수의 최종 행동력을 `min(잔여 지구력 환산값, 정산 전 행동력−2)`로 정한다. 예를 들어 AP5·지구력75는 AP3, AP5·지구력55도 AP3, 지구력35면 AP1이다. 이미 큰 손실이 있으면2를 추가 차감하지 않는다. 노예 선봉의 최소1은 유지한다.

`FOG_ASSISTANT_MASTER_ACTION_20261028`는 생존 조수 단회 정산 안에서 장소가 안개 순찰이고, 실제 출전자가 조수이며, 결과가 승리이고 교대하지 않았을 때 `$master_energy_drop`을 한 번 실행한다. 기본 비용은 행동1회이며 기존 황소 반지·반행동·easy 감면·무한행동 치트·오베레그·과로 계산을 그대로 사용한다. 따라서 모든 보정 상태에서 표시 AP가 정수1씩 줄어든다는 의미는 아니다. 조수 공통 비용 helper는 추가 호출하지 않아 기존 반행동·칼로리·체력 추가 비용을 만들지 않는다.

조수가 패배해 주인공이 이어 싸우면 조수의 최소2만 먼저 정산하고, 주인공은 기존 실제 전투 정산을 사용한다. 새 동행비는 붙지 않는다. 기존 `settled`를 먼저1로 기록하는 가드를 재사용하므로 finish/settle을 반복해도 재청구하지 않는다. 이미 정산된 중간 세이브에 새 비용을 소급 청구하지 않는다.

입력은 기존 active/settled/actor/combatant·장소·승패·교대 상태, 조수 행동력, 전투 지구력과 주인공 행동 함수의 기존 보정값이다. 별도 반환값은 없고 기존 인물/주인공 행동 상태를 갱신한다. 신규 로케이션·영구 키·새 세이브 필드는 없다. 정상 호출자는 전투 종료의 finish, 패배 교대의 handoff다. begin·출전 메뉴·적 배열·부상/성장/명성·보상은 수정하지 않았다.

AP>0인 조수의 출전 조건은 유지한다. 따라서 AP1로 출전하면 최소2 비용으로 AP−1이 될 수 있다. 별도의 AP>=2 입장 제한이나 새로운 과로 규칙을 넣지 않았다.

## 검사와 한계

원래 코드에서 조수AP5→4·주인공5 유지가 관찰됐고 새 기대3/4에 대한 정상 RED를 확인한 뒤 수정했다. 기준/후보 각각 실제 엔진4사례·147조건이 통과했다. 비용 경계·AP1·반지/easy/치트·반행동·음수 행동의 힘 누적값, 중복 정산·노예 선봉·실제 begin/handoff와 주인공 출구 비용을 비교했다. 독립 정적 검토와 공식 구조·줄 경계·패치 재생·재적용·설치 엔진9경로도 PASS다. 실제 설치 QSP는 후보와 바이트가 같다.
