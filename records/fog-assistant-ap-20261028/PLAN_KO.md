# 10/28 조수 안개전투 행동력 정산 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 각 단계는 결과를 확인한 뒤 진행한다. 커밋·푸시는 하지 않는다.

**Goal:** 사용자가 제보했던 조수 단독 안개전투 승리의 낮은 비용을 주인공 기본 1회 행동·조수 최소2 행동력으로 조정하고, 교대·재진입에서 중복 차감을 막는다.

**Architecture:** 현재 `jo9_fog_relay`의 단회 `settled` 정산과 기존 지구력→행동력 환산을 재사용한다. 조수 비용은 기존 환산과 AP전−2 중 작은 값으로 하며, 손실에 2를 더하지 않는다. 주인공 비용은 조수가 승리한 경로에서만 기존 행동 비용 함수를 한 번 호출하는 안을 검증한다. 조수 실패 뒤 주인공이 직접 싸우면 기존 주인공 전투 정산을 유지한다.

**Tech Stack:** 기존 compiled QSP, 선언형 mods JSON, 기존 apply_mods.ps1, 원래 설치 엔진의 격리 검사.

**Spec:** 10/28 사용자의 주인공1·조수2 제안과 최신 `10/28 제보부터 다 해결하자` 지시. 별도 D15 조사는 중단한다. 노예 선봉의 수치는 이 조수 제보를 근거로 함께 변경하지 않는다.

## 범위와 보존

- WORK 현재 f6520ef1을 먼저 읽고 수동 변경을 보존한다.
- 조수 AP>0 진입 조건과 음수 행동력·과로 가능성을 임의로 바꾸지 않는다.
- 주인공의 황소반지·반행동·무한행동 치트 등 기존 공통 함수 보정을 유지한다. 따라서 기본1과 모든 보정 뒤 실제 표시1을 혼동하지 않는다.
- 동료 패배·주인공 교대·주인공 직접전투·노예 선봉·명성·보상·적 상태는 보존한다.
- 신규 영구 상태 키·새 QSP location을 만들지 않는 가장 작은 안을 우선한다.
- 기존 세이브·배포·원본·엔진·CSS·JS는 쓰지 않는다. 진단본은 작업별 tmp에만 만들고 검증 후 정리한다.
