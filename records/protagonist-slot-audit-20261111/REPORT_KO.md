## 신규 효과 연결 가능성

가능하다. item_change가 슬롯별 기존 효과 해제·신규 장착·신규 item_property 실행을 이미 갖고 있고, 전투 시작에서 의상 기술/장신구 플래그를 읽는다. 새 아이템은 아이템 정의와 보유 변수·획득 경로·해당 주인공 슬롯의 선택 목록에 등록하고, 장착/해제 효과와 실제 전투 처리에서 읽을 값을 연결하면 된다. 노예용 아이템 정의만 추가해도 이 주인공 메뉴에 자동으로 나타나지는 않는다.

전투 시작 HP/스태미나/사기 보너스, 기존 속성 피해감소, 피격 회복은 기존 처리 지점이 있어 확장 가능하다. 상태저항·특정 특수기 대응·확률 발동 등은 새로 읽을 처리 지점과 적용/해제·저장/로드·전투 시작 초기화를 설계해야 한다. 일반공격 부가상태 <br> 키 불일치 문제와 장비 효과 연결은 별도다.

수치 증가는 시작 자원에 반영하도록 하면 춘향의 시작 능력비율 R에도 연결할 수 있지만, 현재 춘향 자체와 R 판정은 미구현 기획이다. 장비 이름/설명만 추가해서 전투 효과나 춘향 판정이 자동 생성되지는 않는다. 이번에는 조사만 했고 새 아이템·밸런스·전투·세이브를 수정하지 않았다.
