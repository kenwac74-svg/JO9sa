# 이미지 교체 도구 새 경로 추가

요청 확정: 교체 대상 드롭다운에서 새 경로 추가, 폴더 탐색 선택, 투입한 이미지 파일명 사용. 비PNG 입력은 이름의 확장자만 PNG로 바꿈. PIC 안의 하위 폴더 추가는 저장 전 가상 경로로만 준비한다.

구현: 기존 catalog_editor.js 스코프 안의 별도 모듈에서 폴더 선택 UI와 새 파일 매핑을 제공한다. 새 파일은 관련 베리에이션 자동 매칭을 하지 않고 한 경로만 지정한다. 기존 변환/크롭/ZIP/백업 및 PIC apply(createMissing, before:null)를 재사용한다. 새 경로의 실제 파일 충돌은 지정 시와 반영 시 차단한다. 저장 후 일반 등록으로 전환하여 재조회한다.

범위: WORK 및 추적 소스 2곳 catalog_editor.js, 재현 가능한 원본 모듈과 회귀 검사. QSP, 캐릭터 JSON, 기존 이미지, Full, 체크 상태는 수정하지 않음. 새 경로 생성은 사용자가 저장 버튼을 누를 때만 실행한다. 새 이미지를 게임 대사/JSON에 자동 연결하지 않음.

- [ ] 회귀 검사 작성 후 실패 확인: 새 파일명/경로, 잘못된 경로, 단일 대상, 기존 파일 충돌, 문맥 갱신 보존.
- [ ] 폴더 선택/하위 폴더 준비 UI, 기존 선택과 오가는 상태, 새 파일 규격/저장/결과 재조회 구현.
- [ ] 회귀 검사와 기존 PIC/전환 컷 검사, 격리 실제 저장/충돌 검사.
- [ ] WORK 설치 및 중립 이미지로 실제 브라우저 경로/메뉴 확인. 실제 게임 이미지 생성은 하지 않음.
- [ ] 보고서/백업/해시 기록, 재생성 가능한 임시자료 정리. 커밋/푸시 없음.
