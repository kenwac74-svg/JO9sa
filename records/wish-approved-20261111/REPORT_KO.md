## 최종 동작

- oral_affinity>0, anal_affinity>0에 각각 사용자 지정 문구를 추가한다.
- nymphomania=1은 색정광 문구, >1은 정액 중독 문구로 나눈다. 둘이 동시에 선택되지 않는다.
- homosexualism=2는 레즈비언 문구, =1은 양성애자 문구로 나눈다.
- masochism=2, exhibitionism=2, perversion=2 중 하나라도 있으면 지정 공통 문구+😄를 한 페이지로 표시한다. 여러 개를 보유해도 같은 문장은 한 번만 나온다.
- 기존14적성 대사와 마법·물약 원문은 유지한다. 양성 성기술 특성에 해당하지 않으면 새 문구를 만들지 않으며 기존 무희망 응답을 유지한다.
- 실제 페이지의 기존 special_action 콜백에서 다시 보유 조건과 interaction1114를 확인한다. 숨겨지는 기존 성향(nymphomania, homosexualism, masochism, exhibitionism, perversion)은 해당 페이지를 보면 발견 상태2로 표시한다. 공통 페이지는 실제로 보유한 해당3성향만 공개한다.
- oral/anal 특성은 기존 jo9_traits 목록이 발견 플래그 없이 보유값으로 직접 표시하므로 새 공개 필드를 추가하지 않는다. 전체 특성 보유값·능력치·생성 확률·배타 조건을 변경하지 않는다.
