# 잭 오 나인 테일즈 2.4.1 3차 누적 패치

2026-11-07 KST. 2.4.1 본편에 단독 적용하는 누적 업데이트다. 기준은 이전 2차 r4 ZIP과 현재 플레이 폴더의 QSP이며, 최신 [누적 병합 정책](https://github.com/kenwac74-svg/JO9sa/blob/cb0123950a99084f7795de324d6a3a053d219bfe/docs/PACKAGING_POLICY_20261019.md)을 적용했다.

- **2차 r4 기준:** QSP `6ebda9981bf6bc56de46929474de64157969fd324bba8e8be181e002dad1cc7e`, 런타임 1,967개. 1차 필수 이미지와 호환 별칭 23개를 유지했다.
- **현재 WORK 반영분:** QSP `59f5d13fb6846b340db804ffb58de39f5df573c3bd936b7153247610241ff94e`, 시루·펠라게야 JSON 2개 교체, 이미지 23개 추가. 최초 점검표에 없던 파브리카 대체 컷과 빌헬미네 이미지 5개까지 포함했다. 정확한 경로는 [변경 파일 목록](../../tools/release-20261107/overlay.json)에 있다.
- **WORKSHOP:** 이전 11월 4일 복구 ZIP에서 확인한 419개 파일만 옮겼다. 현재 개발 중인 도구 변경과 작업 폴더는 제외했다. 게임 EXE 대신 별도 Node 설치를 요구하지 않는 WORKSHOP 전용 런타임만 포함한다.
- **ZIP:** 게임 QSP 1개, 전체 JSON 1,158개, 게임 PNG 831개, WORKSHOP 파일 419개, 안내·설치 파일 7개. 2,416개 항목, 244,882,200바이트. SHA-256 `7400f619dfad22bd90e3f6363cdea26a6d699b9ee9cdbf69aa36a69dc52ddfb4`. 전체 게임 파일 2,409개의 압축 안 내용과 명세 해시를 확인했다.

미완료 기획과 작업은 [11월 7일 점검 문서](../../docs/modding/UPDATE_AUDIT_20261107_KO.md)의 ‘다음 패치에 남길 작업’을 따른다. 특등급 처녀고기의 획득 이벤트 역시 다음 작업이다.

압축에서 다시 꺼낸 QSP와 JSON으로 [공식 출고 검사](qa/report.md)를 실행했다. 7개 검사와 FastQSP 9개 경로가 통과했다. r4부터 재생·재적용한 QSP가 압축 내용과 정확히 일치했고, 호환 이미지 23개의 내용도 별도로 확인했다. 실제 게임 화면과 사용자 세이브의 로드 여부는 수동 확인 항목이다.

격리된 테스트 폴더에서 자동 설치가 파일 2,409개를 적용했다. 이전 파일명의 JSON이 사라졌고, WORKSHOP 구성과 Node 런타임이 복원됐다. 기존 세이브·게임 실행 파일·INI·`save_config.json`은 보존됐으며 설치 임시 폴더가 정리됐다. 플레이 폴더와 이전 배포 ZIP은 이번 패키징에서 수정하지 않았다.

### 공개 노트 개정

최신 다운로드는 `JO9_2.4.1_Patch_20261107_3차_노트개정_r2.zip`이다. 한·영 공개 노트의 첫 개선 사항은 이지 모드의 초보자 의뢰 안내이며, 첫 신규 사항은 식사 품질을 한 단계 높이는 특별요리 명령이다. 길드와 시장 경매의 대사를 바꾼 이유와 플레이 중 체감할 변화, 시루와 펠라게야의 외형 세트 및 시루의 전용 등장 경로와 과거 이야기를 적었다. 상세 가격, 확률, 등급 기준 및 계산 규칙은 공개 노트에서 제외했다.

게임 QSP·JSON·이미지는 기존 3차 ZIP과 동일하다. 노트 2개를 제외한 2,414개 항목의 경로·길이·압축 길이·CRC와 QSP·설치 명세·설치 도구의 SHA-256을 대조했다. 개정 ZIP은 244,882,909바이트, SHA-256 `bb72539229dd9d4a6b85613ddca801efee855d674ad8833d0947e194b2037bb8`이다. 기존 3차 설치자는 다시 설치할 필요가 없다.

### 3차 r1

최신 다운로드는 `JO9_2.4.1_Patch_20261107_3차_r1.zip`이다. 한·영 공개 노트에 사용자가 제공한 이지 모드 납품 조건 화면과 시루·펠라게야 비서 복장 원본을 넣었다. 색정광과 불감증의 상위 특성도 각각 표시했다.

플레이 폴더와 ZIP의 시루 설정을 갱신했다. 새로 영입한 시루는 정액 중독을 보유하며 특성 목록에 즉시 표시된다. 실제 암시장 영입과 조수 전환을 포함한 격리 FastQSP 검사에서 확인했다. 이미 영입한 시루에게는 해당 세이브가 보유한 상태를 사용한다.

r1은 246,528,332바이트, SHA-256 `30801fcd8fc59ab6b511560852ddac4ed2883c273d69e01e017e16084edaa974`이다. 시루 JSON의 해시는 `54c0e92247a5eb89ae48eaa91fdc14e51410564e4f66dc66aa62f41cd4cb4cf2`다. 배포 명세와 설치기 해시를 맞추고 QSP와 릴리즈 노트 이미지의 해시도 확인했다.

### 3차 r2

최신 다운로드는 `JO9_2.4.1_Patch_20261107_3차_r2.zip`이다. 이미 영입한 시루도 기존 세이브를 불러올 때 정액 중독을 보유하고 표시되도록 보정했다. 보유 인물과 개인실 전환 임시 보관 인물을 확인하며, 인물마다 한 번만 처리한다. 카오틱 에센스 치료 기록을 인정해 다시 붙이지 않는다.

플레이 폴더에 QSP `46e972bf98bc74cd79176312683e398bf7ae639bc7edeecadfcb6efd9a8f54b9`를 적용했다. 이전 QSP는 `game/_backup_before_shiru_existing_20261107_115100_64d6e592/jack.qsp`다. [정확한 패치](../../mods/2026-11-07_zzzzzzzzzz_shiru_existing_save_addiction.json)를 별도로 남겼다.

배포 ZIP에서 추출한 QSP로 공식 출고 검사 7개 및 FastQSP 9개 실행 경로가 통과했다. 기존 보유 위치별 로드 콜백, 반복 적용 방지, 치료 기록 보존, 실제 노예·조수 정보창의 즉시 표시는 별도 네이티브 검사에서 확인했다. 사용자 메뉴에서 실제 저장 파일을 선택해 복원하는 수동 검증은 별도다.

r2는 246,528,794바이트이며 SHA-256은 `720ddc1876c9a5118f65a3d95744ed7f2b36764890f19f6062bcd0329569f4a0`다. [출고 결과](qa/shiru-existing/report.md)와 [포장 검증](qa/shiru-existing/package-verification.json)을 보관한다.

개정된 자동 설치도 격리 폴더에서 통과했다. 파일 적용, 구형 JSON 정리, WORKSHOP 복원과 세이브·설정 보존을 확인했다. [설치 검사](qa/shiru-existing/installer-smoke.json)
