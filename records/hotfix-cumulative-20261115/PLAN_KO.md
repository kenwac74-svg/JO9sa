# 2.4.2 누적 긴급패치 포장 계획

사용자 지시: 지금까지 수정한 내용을 포함해 누적 패치를 만들고, 2.2 대사 복원은 제외한다.

기준은 2.4.2 최초 풀버전과 r2 원장 및 기존 긴급패치 r1~r3 ZIP이다. 현재 WORK를 읽되 직접 수정하지 않고 배포 후보만 따로 만든다. Full·이전 ZIP·개인 저장·음원·커밋/푸시를 변경하지 않는다. 설치기 없는 새 ZIP으로 만든다.

- [x] 현재 WORK QSP·JSON·CSS·그림을 최초/r2 원장과 해시 대조한다. 기존 긴급패치의 필수 경로와 호환 PNG 23개를 합집합에 포함한다. 백업·작업 도구·개인 저장·임시 자료는 제외한다.
- [x] 현재 WORK의 모욕조교 패치에서 복원한 문구 12개만 이전 2.4 문구로 되돌린 배포 QSP를 만든다. 정신상태 분기 수정과 다른 변경은 유지한다. 선언형 제외 패치와 압축 복구본을 남긴다.
- [x] 배포 후보에서 공식 출고 검사(등록부·재생·멱등·실제 엔진 9경로·배포 대조)를 실행한다. 최신 변경의 기능 검사 증거와 포함 여부를 대조한다.
- [x] 게이머용 설치 안내와 누적 변경 목록을 작성하고, 새 ZIP을 배타적으로 생성한다. 모든 ZIP 항목의 CRC·압축 해제 바이트·안전 경로·누적 합집합·금지 파일 제외를 확인한다.
- [x] 최종 SHA-256·파일 목록·배포 기록을 보존한다. 재생성 가능한 임시 진단 사본만 정리한다.

주의: 기존 미사용 파일의 삭제를 강제하지 않는다. 원본 대사는 WORK에 보존되며 제외는 이번 배포 QSP에만 적용한다. 2.2 성적보상 복원은 애초 미적용임을 확인한다. 전체 사용자 저장/게임 분기/시청각 전수 검사는 자동 출고 검사와 구분한다.

최종 사용자 지시: 새 풀버전과 이전 2.4.2에 덮는 변경분 ZIP의 두 형태. 기존 2.4.2 긴급 수정은 모두 포함한다. 검증된 동일 수정본을 공유하므로 포장별 게임 검사를 반복하지 않았다.
