# WORK 음원 형식 통일

사용자 지시: 기존 음원도 BGM은 MP3, 효과음은 WAV로 통일한다.

- 대상: 현재 WORK의 content/snd 102개. 직접 선택한 후보 원본과 사운드 설정 JSON은 보존한다.
- BGM 30개 중 PCM 28개는 MP3 192 kbps로 변환한다. 확장자만 WAV였던 기존 MP3 2개는 재인코딩 없이 올바른 확장자로 복사한다.
- 효과음 72개는 실제 PCM WAV인지 확인하고, 이미 해당 형식이면 재인코딩하지 않는다.
- 변환 전 원본 30개와 수정 대상 파일은 게임 밖에 복원용으로 보관한다. 정상 변환과 참조 검증 후 WORK의 구형 BGM WAV를 제거해 중복 설치를 피한다.
- QSP의 직접 경로, 동적 경로, 이전 세이브에 남는 음악 경로와 청취 도구를 확인한다. 선언형 mods와 최신 런타임 소스를 맞춘다.
- 검증: 전 파일 디코딩, 재생 길이·채널·샘플레이트 확인, 교체 참조 검사, 현재 엔진의 MP3 재생·loop·close 및 기존 저장 경로 갱신을 필요한 범위만 확인한다.
- Full, 기존 배포 ZIP, 보호 원본 JO9O, 개인 세이브, 후보 채택 상태는 변경하지 않는다. 커밋·푸시는 별도 지시 범위다.

거주지·명성 순차 재생은 별도 기능 조사로 유지한다. 귀족 신분 또는 최고 평판의 원본 우선순위를 보존하고, 조건 통과 지역 3곳이면 기본곡 다음에 3곡을 추가한다. 형식 변환 때문에 이 기능을 검증 없이 활성화하지 않는다.
