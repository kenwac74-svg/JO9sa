## 음악 선택과 게임오버 범위

`#dynamic` 본문은 작업 전과 바이트가 같다. 원본의 귀족 신분(`noble_status = 1`) 또는 최고 평판(`brand_reputation >= 5`) 우선 선택을 유지했다. 거주지·명성 순차 재생은 별도 가능성 검토이며, 이번 본체에는 활성화하지 않았다.

게임오버 BGM은 `exit`의 보호 처리와 화면 배치가 끝난 뒤 시작한다. 배경음악은 해당 화면 동안 반복하고 짧은 WAV는 진입 시 한 번 재생한다. 같은 화면을 다시 그려도 다시 시작하지 않는다. 메인 메뉴나 다른 화면으로 나가면 멈추고, 저장 불러오기에서는 불러온 화면의 음악으로 돌아간다. 일반 전투 패배에는 연결하지 않았다. 청취 목록의 기존 `other:defeat` 항목도 ID를 유지하면서 화면 표기를 '게임오버'로 바로잡았다.
