# 파리드 복원

사용자 확정: 잡파는 비공식 도나도나 덮어쓰기 설정으로 제거한다. WORK 실행 본문의 잡파 54곳을 파리드로 복원했고, 파리드 축출 소개 4곳을 원본 러시아어 소개의 한국어 번역으로 교체했다. JO9O도 같은 한국어 덮어쓰기 흔적이 있지만 #npc_base에 남은 원본 러시아어 파리드 소개를 근거로 삼았다.

내부 zappa 키는 저장 호환용 별칭으로 보존하되 표시 이름·소개·초상 공급은 파리드로 통일했다. $ongload 첫 구간에서 캐시된 경매 시작 대사와 NPC 정보를 보정한다. 가격·경매 규칙·거래 진행은 변경하지 않았다. 공식 패치 적용기 구조/줄바꿈/재생 검사 통과. 실제 게임 경매 화면은 사용자 확인 대기. 긴급패치 r2는 기존 업무/초상 수정도 누적 포함한다.
