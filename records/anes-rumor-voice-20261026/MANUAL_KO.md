# 아네스 구매자 소문 말투

아네스의 기존 기본 대화에 맞춰 소문을 해요체로 표시한다. 추천 결과는 “제가 듣기로는 … 상태가 잘 맞아요. … 직접 찾아가 이야기를 들어 보세요.”, 미발견 결과는 “떠오르지 않네요. … 다시 살펴보세요.”로 바꿨다.

호출: jo9_buyer_rumors view 출력 직전, ANES_RUMOR_VOICE_20261026 표식. 기존 페이지를 LOCAL 문자열로 복사하고 아네스일 때 세 문구만 바꿔 하단 대사에 출력한다. 기존 저장 페이지는 쓰지 않아 이전 소문도 추가 결제 없이 이 말투로 표시된다. 스컵스·작크 문구, 추천 판정·대상·가격·할인·이동·인물 정보에는 변경이 없다. 새 로케이션·영구 저장 키는 없다. 이 블록을 제거하면 출력 변수도 기존 페이지 배열로 되돌려야 한다.

실제 설치 엔진에서 아네스 추천/미발견 및 다른 두 안내자 유지, 소문 페이지 원본·보유금 불변을 검사했다. 공식 출고 검사 PASS. 기존 세이브와 Full은 해시로 보존을 확인했다. 실제 신고 세이브 GUI Load/CRC·물리 마우스 검사는 별도다.

패치는 patch.json 및 mods/2026-10-26_anes_rumor_voice.json, 직전 QSP는 before.qsp.gz로 복구 가능하다. WORK만 반영했으며 배포·커밋·푸시는 하지 않았다.
