## 분류와 수량

사용자 최신 기준으로 생성 시 이미 존재하고 나중 발견하는 값은 **선천**, 보유 중 조건·사건으로 새로 부여되는 값은 **성취**로 표기했다. 별도 ‘후천’ 분류는 사용하지 않았다. 성격 7종의 늦은 발견은 모두 선천이다.

현재 목록은 **15개 저장 축 / 표시 변형 23종**이다. 순정에 키가 없는 신규12축(19종), 순정의 비활성 키를 복원·확장한3축(4종)으로 나뉜다. 후자는 oral_affinity·anal_affinity·defiant이며 순정에는 각각 조수 seed 복사 참조2곳씩만 존재했다. 순정에 이미 있었던 키를 전부 새 발명으로 세지 않았다.

강한 복종심은 기존 meekness의 사용자 최신 명칭으로 교차비교에 사용한다. 이는 이 조사에서 게임 문구를 수정했다는 뜻이 아니다.

- 배제: 명기 등 다른 축과 배제 없음. 두 프리미엄이 중첩되는 거래 분기가 있음
- 장기: 성형은 기존 수술 제한을 따름. 단순 보유 일수로 재추첨하지 않음. 선천/성취 출처 전용 필드는 없음

- 해제: 정상 학습에 의한 플래그 교체/해제 경로 미확인; 지성 등급 상승/하락과 플래그가 분리됨

- 장기: 플래그는 고정, 학습 누적과 credit만 증가/소비. 천재가 보유 중 새 성취로 발생하는 경로는 없음
- 근거: generate_stock:1617–1634, jo9_learning_xp:1–34, #static_base:1923–1928

## 장기 누적 판단

- 선천 7개 성격 표시(야심가·일벌레·안분지족·끈기·산만함·옹졸함·너그러움)는 known을 나중에 켤 뿐 새 획득이 아니다.
- 보유 기간만으로 선천 성향을 다시 추첨하는 일반 루프는 확인되지 않았다. 자동 생성 복사본과 수동 치트를 정상 획득으로 세면 안 된다.
- 보유 중 별도 부여 경로가 확인된 축은 전투 특성·다재다능·성형 경로 절세미인이다. 이것은 현 코드 경로 조사이며 향후 성취 종류를 3종으로 확정한다는 제안이 아니다.
- 전투 특성은 enum 1칸이라 3종 누적 불가. 예: 50승까지9회 추첨의 누적 최초 획득 확률은 1-0.91^9 약57.2%이며 종합9%는 매 추첨 확률이다.
- 다재다능은 모든 표시24기술 A 이상이 되어 부여되면 기술이 나중에 낮아져도 유지된다. 자동 refresh가 명성 보상을 반복 지급하지 않는다.
- 절세미인·전투 특성은 양경로 저장값이 같아 기존 세이브의 선천/성취 출처를 확인할 수 없다. 새 출처 필드는 추가 설계안일 뿐 현재 구현하지 않았다.
- 특성 수에 대한 공통 고정 슬롯 상한은 해당 표시 경로에서 확인되지 않았다. 여러 생성 축과 성취 축이 함께 남을 수 있으나, 같은 ±축·전투 enum은 서로 배제된다.

여기서 현 코드의 보유 중 부여 경로를 나열한 것은 향후 ‘성취 특성 3종’을 확정하는 제안이 아니다. 추후 창관 모드의 성취 분류와 세 번째 후보는 별도 설계 사안이며 이 조사에서 추가하지 않았다.

## 겹침·보완 판정 근거

- **노예근성 ↔ 강한 복종심(meekness)**: 기능 구분. 둘 다 현재 생성/프리셋 기반 선천 분류. 신규는 영입 초기화, 기존은 지속 복종·조종성·명망 보정. 현재 상호배제 없음.
- **거센 반항심 ↔ 노예근성**: 명시적 반대·배제. 같은 생성 추첨과 편집/초기화에서 상호배제.
- **반사적 구역질 ↔ 펠라 중독**: 신체 반응과 선호의 서로 다른 축. 동시 보유 가능하고 일부 수용도는 상쇄되지만 XP 이점은 남는다.
- **일벌레/안분지족 ↔ 끈기/산만함**: 부분 중복·보완. 하루 활동 횟수와 같은 분야 연속성이라는 다른 조건을 다룬다.
- **건강체질/약골 ↔ 체력 단계(stamina)**: 이름 유사·서로 다른 메커닉. 전자는 전투 최대치/일부 교육 배율, 후자는 현재 체력 단계와 일일 행동력 등 기본 계산. 자동 배제 없음.
- **천재/백치 ↔ 현재 지성(intellect)**: 초기 연동·장기 분리. 생성 시 지성을5/0으로 맞추지만 이후 현재 지성을 잠그지 않는다.
- **천재 ↔ 미련한 소(cowSK_affinity)**: 혼합 결과. 동시 보유 배제 없음. 천재의 cowSK 성장75%와 미련한 소의 일일 milk_gain1.5배는 별도 경로.
- **건강체질 ↔ 역전의 용사**: 배율 중첩. 전투 HP·스태미나가 각1.5씩 결합하여2.25배 가능. 모듈은 기초값을 재계산하므로 화면 재진입마다 거듭제곱 누적하는 설계는 아니다.

실제 효과만 기준으로 보면 중독처럼 보이는 명칭도 현재는 조건부 XP/수용도 이점만 있을 수 있고, 안분지족은 별도 휴식 보상이 없어 반복 활동에서 불이익만 확인된다. 명칭의 분위기와 계산상의 긍정/부정은 분리해야 한다.

## 검증 한계

정적 소스와 mods 대조다. 게임 플레이·확률 표본 실험·세이브 출처 재구성은 수행하지 않았다. 전투 특성·절세미인의 선천/성취 출처가 현재 따로 저장되지 않으므로 기존 세이브의 경로를 확정할 수 없다. 출처 추적 필드를 새로 만드는 것은 별도 제안과 승인이 필요한 변경이며 구현하지 않았다. 게임 시험 사본이나 임시 추출본은 생성하지 않았다.
