# 특성 체계 검토 — 결정용 요약

> 후속 개별 분류·무작위 소거 제안은 [최신 분류표](../trait-slot-proposal-20261024/CLASSIFICATION_KO.md)와 [설계안](../../docs/superpowers/specs/2026-10-24-trait-slots-and-random-removal-design.md)에 있다. 기존8＋3 확정과 구체 제안 채택은 구분한다.

## 적용한 변경

‘완전한 사육’을 **강한 복종심**으로 바꾸고 설명을 실제 효과에 맞췄다. 목록·편집기와 공통·여주인 설명, 총4곳만 수정했다. 기존 수치·효과·발견·반대 성향은 유지했다. 실제 엔진 출력2경로, 문법·정확 재생/재적용, 공식 출고9경로와 독립 검토를 통과했다. WORK만 반영했으며 기존 세이브·Full·CSS와 배포물은 보존했다. 커밋·푸시는 하지 않았다.

8＋3 슬롯 구분은 사용자 확정 설계다. 개별 분류·새 배제·발생률·세이브 처리 및 실제 제한은 아직 미적용이다.

## 장기 보유 시 누적 문제

많은 특성은 새 획득이 아니라 원래 있던 값의 발견이다. 신규 성격7종도 처음에 결정된다. 오래 보유한다고 천재·백치, 일벌레·안분지족의 양쪽을 모두 얻지는 않는다.

하지만 원본에는 경험치 조건에 따른 **13축·14개 변화 경로**가 있다. 이들은 생성 때도 부여될 수 있다. 전투 직업·다재다능·성형으로 얻는 절세미인도 보유 중 추가될 수 있어 작은 슬롯 예산을 넘길 가능성은 실제로 있다. 같은 축의 단계 상승은 기존 값을 교체하므로 추가 칸으로 세면 안 된다.

기존 저장에는 해당 특성의 획득 출처가 없다. 현재값이나 경험치만으로 ‘생성 때 보유’와 ‘보유 중 획득’을 정확히 역분류할 수 없다. 아레나 칭호도 영입 당시 경력으로 받는 인물과 플레이 중 승급하는 경로가 모두 있다.

## 배제·중복·보완 판단

| 관계 | 현재 상태와 검토안 |
|---|---|
| 천재/백치, 건강체질/약골 | 같은 키의 반대값으로 이미 배제 |
| 일벌레/안분지족, 끈기/산만함, 옹졸함/너그러움 | 같은 키의 반대값으로 이미 배제 |
| 강한 복종심/자유로운 영혼 | 같은 수치축의 양수·음수라 동시 보유 불가 |
| 광전사/성기사/역전의 용사 | 같은 직업축에서 하나만 보유 |
| 노예근성/거센 반항심 | 생성·편집·영입 초기화에서 이미 배제 |
| 노예근성/자유로운 영혼 | 현재 배제 없음. 개념상 배제 후보로 우선 검토 |
| 선천적 벙어리/달변가 | 현재 배제 없음. 음성 재능인지 표현 전반인지 의미를 먼저 정해야 함 |
| 강한 복종심/노예근성 | 지속 복종 보정과 영입 초기 훈련으로 보완 관계 |
| 천재/분야 적성 | 경험치 배율과 성실도·승급 문턱이 달라 부분 중첩, 완전 중복 아님 |
| 역전의 용사/타고난 투사/용감함 | 강한 보완 조합. 용사+용감함의 사기2.25배 등은 별도 균형 검토 대상 |
| 건강체질/운동광/게으름 | 체질과 운동 선호가 달라 자동 배제할 반대쌍은 아님 |
| 야심가/인지욕구 | 성장한 날의 칭찬 반응과 평소 관심 선호로 부분 중첩 |

이름이 비슷하다는 이유만으로 다른 기능을 지우지는 않는 편이 좋다. 명확한 반대는 하나의 축에서 배제하고, 보완 조합은 총량과 실제 배율로 관리하는 안을 권한다. 기존에 충돌하는 값을 가진 세이브는 새 규칙을 불러오는 순간 자동 삭제하지 않는다.

## 긍정 편중과 보유 상한

원본 표시 변형은 게임 효과 기준 긍정24·부정14·상황형34다. 신규·복원은 유리/조건부 유리13·불리/행동 제약9·장단점 혼합1로 요약할 수 있다. 이는 표시 종류 수이며 생성 확률이나 실제 등장 비율은 아니다.

긍정만8개 채우는 자동 보충은 피하는 편이 좋다. 수치 논의를 시작할 구체안으로 **새 일반 무작위 인물의 순수 이점 최대4개**를 검토할 수 있다. 나머지를 억지로 부정 특성으로 채우는 안은 아니다. 정확한 발생률·상한·고정 프리셋 예외는 미확정이다.

보유 상한을 정하면 아직 발견되지 않은 실제 보유값도 포함해야 한다. 화면만 잘라내면 숨은 특성과 효과가 계속 남는다. 생성·입수·새 획득에서 같은 계산을 쓰고, 같은 축의 반대값/상위 단계는 기존 칸을 교체해야 한다. 독립 특성이 추가될 때 만석이면 선택 교체할지 추가를 보류할지는 별도 결정이 필요하다.

## 확정된 슬롯 구조 — 2026-10-24 사용자 선택

**일반 성향 8칸＋칭호형 성취 3칸, 총 11칸**으로 구분한다. 이는 설계 기준의 확정이며 게임의 개수 제한을 적용한 것은 아니다.

- 일반 성향은 생성 때 보유했는지, 보유 중 새로 생겼는지와 관계없이 같은 8칸에서 관리한다. 뒤늦은 발견은 새 획득이 아니다.
- 칭호형 성취는 다재다능 1칸, 향후 창관용 1칸, 미정 1칸을 계획한다. 창관 효과와 세 번째 대상은 아직 결정하지 않았다.
- 같은 축의 단계 상승은 기존 칸을 교체한다. 임신·부상·회복 등의 상태는 특성 슬롯과 별도이며, 이전의 분류 제목을 추가하지 않는 방향도 유지한다.
- 필수 성취가 다른 임의 성향의 누적으로 막히지 않도록 두 묶음을 분리한다. 실제 지급·만석 정책은 구현 전에 별도로 정한다.

현재 전체표의 획득 경로는 원천 조사 사실이다. 획득 시점만으로 칭호 칸을 배정하지 않는다. 투기장·경주 칭호의 통합 여부, 전투 직업·절세미인의 개별 배치, 기존 초과 보유자의 처리와 새 배제 규칙은 미정이다. 기존 세이브에서 특성을 자동 삭제하지 않는다.

일반 후보 49축·다재다능 확정 1축·경계 검토 4축이라는 표의 구분은 **분류 초안**이다. 일반 후보 49개를 한 인물이 모두 보유한다는 뜻이 아니며, 성취가 총 3종으로 이미 확정됐다는 뜻도 아니다.
