# 캣파이트 승리 후 처분 선택 연결

사용자 승인: 캣파이트 클럽에도 처형/살려주기를 연결하고 대사를 맞춘다.

기존 jo9_battle_fate mode2를 재사용한다. 새 로케이션·영구 변수·UI·그림은 추가하지 않는다. 일반 상대 gladiatrix1/2/3과 Start1 복귀에만 적용하며 에게야 영입 결투는 유지한다. WORK만 반영한다.

1. 현재 QSP의 왕복·해시를 기록하고 기존 세이브를 보존한다. 격리 엔진에서 캣파이트 init가 선택 mode0으로 남는 문제를 먼저 재현한다.
2. $catfight_fight_start의 초기화 연결, jo9_battle_fate의 캣파이트 허용 조건, 주인공 지시에 따른 선택 후 문구, interaction_city=103005의 선택별 후속 문구를 선언형 패치로 작성한다. 보상·승수·명성·패배 처리는 수정하지 않는다.
3. 상대3종 × 패배원인4종 × 처분2종을 검사하고 선택 전 사망 미확정, 중복 선택 무시, 잔혹/자비 단1회 반영을 검증한다. 실제 시작 경로와 정산을 검사하고 중복 출구 진입으로 승수·명성·상금이 다시 늘지 않는지 확인한다. 미허용 전투와 기존 안개/아레나 범위도 검사한다.
4. 공식9경로·구조/줄바꿈/주석 경계·패치 재생/재적용 검사 후 후보와 동일한 WORK를 적용한다. 보고서·복구본·재현 스크립트만 남기고 진단 사본을 정리한다. 배포 폴더/커밋/푸시 변경 없음.
