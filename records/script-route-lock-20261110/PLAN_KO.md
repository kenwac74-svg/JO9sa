# 각본 시작·선택 경로 고정 수정 계획

사용자 요청: 시작 대사 한 번 지정 → 화면의 분기 대사를 골라 경로에 고정 → 다음 후보를 계속 선택 → 마무리를 정해 그 루트의 각본을 출력한다. 기존 대사 수정·미리보기·이미지 연결·분기 탐색은 유지한다.

## 확인한 원인

1. 중간 시작 지정은 실제 start를 저장하지 않고 확인 대기만 한다. 다음 대사 선택은 확인 UI를 지워 시작이 사라진 것처럼 보인다.
2. 분기 선택 버튼은 탐색만 하며 각본 choices에 기록하지 않는다.
3. 마무리 지정 때도 choices 전체를 지워 이미 고른 분기를 잃는다.
4. 실제 QSP 변경은 기존 선택을 자동 삭제한다.

## 설계

- 탐색 중인 대사와 각본의 start/end/pins/choices를 분리한다. 시작은 즉시 저장하고 명시 초기화 전에는 바꾸지 않는다.
- 이전 시작/예상 끝 안내는 이미 고정한 선택을 취소하지 않는 보조 안내로 둔다.
- 각본 모드의 '이 대사 선택'은 현재 대사를 열고 `/api/script/boundary`가 검증한 selected.at로 기존 backend의 선택 키를 저장한다. 다음 단계는 기존 장면 흐름에서 표시한다.
- 같은 분기를 다시 열면 유지한다. 이전 분기를 다른 변형으로 바꾸면 그 뒤의 고정과 끝만 정리한다.
- 마무리 지정·탐색·탭 왕복·새로고침은 고정을 유지한다. QSP가 실제 바뀌면 고정을 보존하고 출력을 잠가 알린다.
- 각본 요약·고정 경로·출력 버튼을 장면 흐름 상단에 실제 마크업으로 배치한다. 중복된 지정 도우미는 접힌 추가 도구로 유지한다. CSS로 기존 UI를 가리는 방식은 쓰지 않는다.
- 기존 range API와 export map을 사용한다. 동적 게임 조건을 추정·실행하지 않는다.

## 작업 파일

- `tools/text-workshop/script-range.js`: 고정 상태, 선택 키, 저장/복원, stale 잠금.
- `tools/text-workshop/index.html`: 경로 고정 버튼 연결, 요약 위치, 표식.
- `tools/text-workshop/workshop-ui.js`: 고정 대사의 표식 판정.
- `tools/text-workshop/workshop.css`: 새 경로 요약·고정 표식의 기본 스타일.
- `tools/text-workshop/script-route-ui.test.cjs`: 실제 UI 이벤트의 실패 재현과 회귀.
- `tools/text-workshop/script-route-contract.test.cjs`: selected.at와 기존 backend export의 실제 분기 계약.
- 기존 range-output 검사와 사용·인계 기록 갱신.
