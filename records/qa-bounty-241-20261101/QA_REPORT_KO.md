# 2.4.1 독립 QA·버그 바운티

2026-11-01. 개발 담당과 별도로 새 QA 전담을 배정하고, 게임 로직·이미지 조건 편집기·배포 구성 검토자를 분리했다. 최신 파일을 읽어 TC를 설계하고, 소스 후보는 실제 엔진 또는 격리 HTTP/브라우저에서 재현했다. 생산 코드 수정·Full 동기화·ZIP·커밋·푸시는 수행하지 않았다.

## 결론과 조치 순서

**신규 확정 제품 버그 1건, 확정 문서 불일치 1건, 화면 영향 미확인 자원 후보 1건**을 기록했다. 전투·정산 helper와 배포 파일 검사는 아래 범위에서 통과했다. 전체 게임이나 모든 TC가 통과했다는 뜻은 아니다.

1. **Q241-CUT-003 / P2 — 조건 컷의 실제 수동 전환이 B↔C에 갇힘.** WORK 전용 신규 기능이다. 같은 가족의 A/B/C/D가 있고 B에 보유금 ≥100 조건을 붙이면 처음 B가 자동 표시된 뒤, 실제 이미지 전환 버튼이 C→B→C→B로 반복하여 A·D에 도달하지 못한다. 조건이 없는 대조군은 A→B→C→D→A로 정상이다. 엔진의 원래 `jo9_html`과 `jo9_toggle`을 실행해 재현했다. 조건이 1개 또는 2개인 재현군 모두 실패했다.
2. **R-DOC — 연습 성향의 오래된 안내.** 10/31 연습 매뉴얼은 +1로 적혔으나 최신 11/01 승인 규칙과 현재 코드는 0이다. TC 기대는 0으로 정했다. 게임이 +1을 지급한다는 버그로 집계하지 않는다.
3. **PKG-C01 — CSS `content/a.jpg` 주소 부재.** 10개 배경 선언에서 주소를 사용하지만 파일이 없다. 초상화 본체는 별도 IMG이므로 실제 화면 손상은 아직 확인하지 못했다. 원본 대응 경로도 없어 이번 배포 누락으로 단정하지 않았다. 사람의 초상화 주변 확인 대상으로 남긴다.

확정 버그의 원인은 수동 전환이 현재 선택 검증을 위해 부른 `jo9_path(mode0)`에서 새 자동 B 우선 선택이 다시 적용되는 것이다. 기존 선택 C가 B로 바뀌어 다음 mode1 순환을 생략한다. **그 호출 한 곳만 mode3 검증으로 바꾸는 미적용 수정안**을 준비했고, 격리 후보에서는 5시나리오·29판정이 통과했다. 기존 순환, 두 조건 충족, 조건 상실 후 기본 복귀, 새 화면의 자동 B 우선을 확인했다. 후보 해시는 `05f5726d…`다. 승인 전 WORK에는 반영하지 않았다. 세부 명세와 범위는 `conditions/fix-proposal.json`을 따른다.

## TC와 사람에게 인계할 항목

`lead/tc.json`은 변경묶음별 사전 상태·절차·기대 결과·우선순위·담당·근거를 담는다. 원래 46개 계획에 새 확정 회귀 1개를 추가하여 **47개(자동 담당 39·사람 담당 8)**로 정리했다. 실제 수행 상태는 `lead/execution-map.json`에서 따로 관리한다. 부분 helper 통과를 장면 전체 통과로 올리지 않는다. 현재 정적만 통과 5, 미실행 18, 엔진 부분 통과 12, 소스 스냅샷만 1, 동일 결함을 포함한 부분 실패 1, 서비스 계약만 통과 1, 사람 미실행 8, 신규 확정 실패 TC 1로 합계 47개다. 부분 실패 TC와 신규 실패 TC는 같은 버그여서 두 결함으로 세지 않는다.

`lead/HUMAN_HANDOFF_KO.md`는 기존 공개 SAV 7개로 실행할 수 있는 핵심 수동 항목과 선택적 설치 환경 검사를 정리한다. 주된 인계는 컷신·효과·프레임 배치, 팝업의 앞뒤 순서, 대사 연결, 실제 저장·불러오기, 다른 PC·DPI·소리다. 재현 상태가 부족한 9묶음은 준비되지 않았다고 표시했다. 전용 상태 없이 사용자 개인 저장을 임의로 읽거나 ‘완료’로 처리하지 않는다.

우선 수동 확인은 캣파이트 결과→집 생활, 전투 UI/긴 기록, 안개 단체전, 파산 정리 연쇄다. 오류가 나면 TC ID, 누른 메뉴, 기대/실제, 반복 여부와 화면을 남긴다. 기존 공개 TC를 덮어저장하지 않는다.

## 진단 오류·보류·파일 보존

- 이미지 순환 첫 두 진단 계획은 검사기 `name` 규칙 불일치로 조건군이 실행되지 않았다. 허용 규칙을 읽어 `one-rule`/`two-rules` 이름과 별도 underscore marker로 고친 새 폴더에서 세 진단 모두 완료 마커를 확인했다. 앞의 미실행을 제품 오류로 세지 않았다.
- 금화 재현 첫 실행은 공개 TC의 2.4.0.0 버전 값을 가져와 정상 업데이트 안내 MSG에서 중단됐다. 소유한 진단 값만 2.4.1로 맞춰 금화180판정과 6진단 전체 301판정 통과를 확인했다. 원래 공개 SAV는 그대로다.
- 일반 XML 파서는 config 제목의 원래 `&`를 거부한다. 엔진의 기존 형식과 실행 기록을 구분하여 새 게임 버그로 단정하지 않았다.
- 워크숍·Show HTML, 마법낙인 실제 재현, 포커스 검은 잔상, 장기 개인실 임신, 난도·칭호 보류는 해결됐다고 적지 않는다.
- 문서·TC·변경 제안·재현 스크립트·작은 원시 로그를 남긴다. 이번 소유 진단 QSP·복제 JSON·합성 진단 SAV·정션만 경로 확인 후 정리한다. 생산 원본·그림·개인 SAV·배포 명세·기존 복구 자료는 건드리지 않는다.
