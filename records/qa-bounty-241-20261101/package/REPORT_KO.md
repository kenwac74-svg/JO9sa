# 2.4.1 배포 폴더 독립 QA — 파일 구성·이식성

2026-11-01 Full 실파일을 새로 읽고 검사했다. 배포 명세와의 누락·추가·크기·SHA-256 불일치는 **0건**이다. 필수 실행 구성, 공개 TC 7개 및 의도된 이미지 호환 주소도 보존되어 있다. 별도로 **누락된 CSS 배경 주소 후보 1건**을 찾았다. 실제 플레이 화면 손상은 아직 재현하지 않았으므로 게임 버그 확정 건수에 합산하지 않는다.

## 검사 대상과 기준

- 대상: `G:/somi/Jack O Nine Tails v2.4 Kor_Full`.
- Full QSP: `f87363c3050547ae6b7a5387ae9870425fdc4d68cb2e07855e4550df29664168`.
- 현행 명세: `BUILD_MANIFEST.json`, SHA-256 `db3c1ce8790526fea0693d2cba88e6d344e3107e8d613e7169e88d044c0a75fb`.
- 현행 명세와 실제 payload: **42,941파일 / 17,167,244,409바이트**. 명세 자체를 더하면 총 42,942파일이다.
- 과거 `full-prezip-20261101/DELIVERY.json`의 `a11…`는 이전 스냅샷이다. 이번 판정에는 현재 Full의 명세와 `work-full-sync-20261101/verification.json`의 `f873…`를 사용했다.
- 이후 WORK만 바뀐 기능은 Full 누락·자동 동기화 필요로 판정하지 않았다.

## 추적 후보 PKG-C01 — 존재하지 않는 장식 배경 주소

**확정된 사실:** Full의 `game/content/a.jpg`가 없으며, `game/css/base.css`에서 이 주소를 배경으로 지정하는 선언이 10개 남아 있다.

- `#rider1_pic`~`#rider6_pic`: CSS 3285·3295·3305·3315·3325·3335줄.
- `#combat_ui_pic`: CSS 3485줄.
- `#ally_pic`, `#enemy_pic`, `#enemy_maxpic`: CSS 7958·7968·7978줄.
- 현행 Full QSP의 `ride_interface` 185~190줄, `боевой_интерфейс` 223·237줄, `конец_боя` 182·195줄에서 앞의 두 종류 컨테이너를 생성한다. 컨테이너 안의 인물 `<img>`는 별도의 `$rider_ava`·`$combatant_ava`·`$аватара_моба` 주소를 사용한다.
- 나머지 세 ID의 직접 생성은 현재 컴파일본에서 찾지 못했다.

**판정:** 정적으로 끊어진 CSS 주소는 확인했다. 인물 그림이 사라지거나 게임 진행이 막히는 현상은 확인하지 않았다. 보호 원본에서 확인한 대응 주소도 없어 이번 패키징 중 새로 누락되었다는 근거는 없다. `PKG-M06`으로 실제 화면 영향을 먼저 확인해야 한다. 대체 그림 제작, 원본 복사, CSS 삭제는 수행하지 않았다.

증거는 `css-candidate.json`에 현재 QSP 해시·선언·로케이션 본문 줄과 함께 남겼다.

## 보존한 불확실성과 검사 한계

- 엔진·GUI를 이 감사에서 시작하지 않았다. 기존 엔진 검사 9경로/91/163판정을 이번 새 검사 수에 합산하지 않는다.
- `config.xml`의 제목에는 원형 그대로 `&`가 들어 있어 일반 XML 파서는 거부한다. 로컬 엔진 조사 문서는 제목을 정규식으로 읽는다고 기록한다. 이 형식 차이를 실행 장애로 확정하지 않았다.
- `.pngbk` 두 파일·`jack-sheet.ods`·예약 이미지 `manifest.csv`는 현재 명세에 포함되어 있다. 확장자만으로 미사용·삭제 대상으로 판정하지 않았다.
- PE import 검사는 현재 감사 PC의 시스템 DLL 존재도 이용한다. Windows N/구버전·미디어 구성·그래픽 드라이버 차이는 깨끗한 PC 실행으로 별도 확인해야 한다.
- 동적 QSP/JSON의 모든 리소스 선택, 개인 SAV CRC/복원, 모든 UI·퀘스트·무작위 결과의 완전 검증은 하지 않았다.
- 실제 게임 폴더 수정·WORK→Full 동기화·ZIP 제작·커밋·푸시·개인 SAV 열람은 하지 않았다. 임시 게임 복사본도 만들지 않았다.

재현 스크립트는 `audit-package.py`와 `css-candidate.cjs`, 기계 판정은 `package-report.json`, PE/CSS/글꼴/호환 상세는 `runtime-dependencies.json`이다.
