# 이미지 교체 상태

이전 점검본에서 공통 그림으로 임시 연결했던 coldef1.png, coldef2.png, coldef3.png, catfdef1.png, catdef2.png는 현재 WORK에 모두 존재합니다. 다섯 파일 모두 795×596이며, 이전 공통 대체 그림과 SHA256이 다릅니다. 따라서 이 다섯 주소를 ‘사용자 공급 전 임시 컷’으로 안내하던 문구는 제거합니다.

이 판정은 파일 경로·PNG 크기·해시 비교 결과입니다. 그림의 내용과 구도는 수동 플레이로 확인해야 합니다. 현재 WORK의 파일을 그대로 포함하며, 이전 공통 그림으로 되돌리지 않습니다.

미채택 시안과 제작 원본은 실행 이미지로 자동 추가하지 않습니다. 출처가 다른 이미지나 삭제 표시가 있으면서 실행 참조가 남은 파일은 별도의 의존성 조사 결과에 따릅니다.
