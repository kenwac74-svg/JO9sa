# 채택 없는 사운드의 새 후보

> 2026-11-08 후속: 두 역할 모두 사용자 선택 완료. 가르시드는 gsid.mp3, 둔기는 승인 후 제공한 blunt.mp3로 채택했다. [후속 적용 기록](../sound-adoption-20261108/REPORT_KO.md). 아래는 선택 전 비교 기록이다.

기준: 사용자가 마지막으로 지정한 `JO9_사운드_설정 (3).json`. 설정 해시 `a27d57d6eda08f284c166fbb56306752d05ca973881a3743f31689e7bca273cd`.

기존 목록 45개 역할 그룹 중 41개에 채택이 있다. 채택 곡이 있는 지역과 몬스터는 다른 후보 칸이 비어 있어도 다시 찾지 않았다. 미채택처럼 보이는 별도 `victory`는 이미 채택한 전투 승리 역할과 겹쳐 제외했다. `chinatown`은 사용할 장소가 정해지지 않은 기존 곡이므로 새 곡을 더 찾는 대상으로 보지 않았다. 새로 요청한 게임오버 BGM은 사용자 지정 파일이 있어 새 후보 탐색 대상에서 제외했다.

새 후보가 필요한 역할은 가르시드 등장음과 둔기 타격음 두 가지다. 기존 보류·채택·파일 지정은 변경하지 않았다. 아래는 원본 페이지의 제목·태그·길이를 확인한 제안이며, 실제 청취 판정이나 자동 채택 결과가 아니다.

픽사베이 원본은 MP3로 제공되지만, 실제 채택해 게임에 설치할 때는 사용자 지정 형식인 PCM WAV로 변환한다. 이번 후보 제안에서는 다운로드·변환·게임 연결·설정 변경을 하지 않았다. 게임오버 전용으로 확정된 기존 `gameover.mp3`만 별도 지시에 따라 WAV 설치본을 만들었다.

재생 페이지의 현재 길이를 기준으로 적었다. 검색 목록에 표시된 반올림 길이와 차이가 있을 수 있다. 설정별 대조는 `settings3-audit.json`에 남겼다.
