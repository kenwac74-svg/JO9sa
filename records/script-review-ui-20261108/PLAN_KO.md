# 각본 탭에서 수정본 검토·반영

사용자가 지정한 별도 입력란 방식. 기존 import UI를 각본 탭에 정적으로 이동하고 동일 백업/승인/apply 경로를 재사용한다. 원본TXT·수정본TXT 불러오기와 원본ID를 표시한다. 구분선의 역슬래시만 정규화하고 빈/중복/누락/모르는 블록을 검사한다. 치환변수의 누락·추가를 반영 전 차단한다. QSP 해시가 다르면 사용자가 선택한 원문 재대조로 동일 위치 종류·동일 원문 유일 일치만 허용하며 원문 변경/중복은 거부한다.

원문/수정문 비교와 폭720·높이480·글자18px의 텍스트 영역 미리보기에서 실제 브라우저 줄바꿈·넘침을 측정한다. 치수 변경 시 재검토 필요. 이는 텍스트 박스 분량 검사이며 엔진 전체 실행/이미지 배치 검증과 구분한다. 입력·설정이 바뀌면 승인을 무효화한다. 검토 응답이 늦게 도착해도 오래된 입력을 승인하지 않는다. 적용 버튼은 확인한 입력에만 연결한다.

검사: 파서 역슬래시 보존/0블록, 변수와 구문, 재대조 충돌, UI배치/입력 무효화/분량 계산, 임시 QSP에서 반영·복구. 실제WORK에서는 검토까지만 하고 사용자가 버튼으로 채택한다. Full/음원/커밋푸시 없음.
