# 자산 처분 모듈 계약 — 현재 설치 상태 기준

사용자 최신 확정: 정가가 있는 자산은 현재 설치 상태의 정가 50%로 처분한다. 구입 이력이나 실제 구입 금액을 저장하지 않는다. 변동 가격의 구입 이력은 이 모듈에 필요하지 않다.

## 호출과 반환

- `gs 'jo9_liquidation_assets', 'quote'`: `jo9_lq_value[key]` 현재 환급액, `jo9_lq_available[key]` 실행 가능 여부, `$jo9_lq_reason[key]` 불가 사유를 갱신한다. 스파크·입주자·반복 방지 상태는 변경하지 않는다.
- `gs 'jo9_liquidation_assets', 'sell', key`: 현재 상태를 다시 견적한 뒤 조건에 맞을 때만 실행한다. `jo9_lq_sold=1` 성공, `jo9_lq_paid` 지급액. 임대 시설은 0스파크 해지도 성공이다.
- `gs 'jo9_liquidation_assets', 'decor_change', room`: 실제 장식 구입 또는 교체 후 해당 방의 중복 처분 표시만 0으로 되돌린다. 금액을 전달하거나 저장하지 않는다.

키는 `decor`, `room1`~`room4`, `lab`, `boudoir`, `dungeon`, `barn`, `pen`, `stasis`, `house`, 보호 판정용 `move`다. 장식별 소계는 `decor_study` 등이다.

## 장식

실제로 존재하는 7종 방의 현재 스타일을 67개 정가표와 대조한다. 자가·임대·초기 기본 장식·구입 경위를 추정하지 않는다. 없는 방이나 정가표에 없는 스타일은 0이다. 방별 정수 계산으로 소수점은 버린다.

지속 상태는 `jo9_lq_decor_state[room]` 한 배열뿐이다. 0은 현재 장식이 미처분, 1은 이미 처분되었다는 뜻이다. 판매 시 최저 스타일로 바꾸고 표시를 1로 잠근다. 주방이나 연구실처럼 최저 장식에도 정가가 있어도 반복 환급되지 않는다. 구입 또는 교체 선택지 67개는 표시만 0으로 돌린다. 무료 기본 스타일은 환급액 0이므로 수익이 생기지 않는다.

처분 후 7종 방의 스타일은 모두 `basic`이다. 배경·장소 설명을 직접 갱신한다. `new_estate`는 이 표시를 초기화하지 않는다. 따라서 무료 기본 장식 재생성·반복 이사로 이미 환급한 방을 재환급할 수 없다. 새 게임만 이 배열을 초기화한다. 장식 구입가 배열과 소유권 추정 상태, 새 집 초기화 후크는 제거했다.

## 개인실·시설·주택

개인실은 가장 높은 번호이며 해당 상태가 정확히 `CONST_INT['no_slave']`일 때만 한 칸 철거한다. 4·3·2·1번 환급은 5000·2500·1000·2500스파크로 공사 정가의 절반이다. 기절·사망은 빈 방으로 보지 않는다. 인물 배열을 지우거나 이동하지 않는다.

시설은 원본상 임대이다. 파산은 지난 10일의 후불 결산 경계에서 발생하므로 미사용 선불 기간이 없다. 빈 시설 해지는 환급 0이며 다음 비용만 중단한다. 감옥 `prisoner`, 외양간 4개 인원, 냉동 전체 `iced_1`~`iced_18`은 어떤 상태든 한 슬롯이라도 남으면 해당 시설을 해지하지 못한다. 괴물 우리도 비어 있어야 한다. 외부 은행 구좌 해금 수를 바꾸지 않는다. 인물 해제·이동은 사용자가 직접 한다.

자가 주택은 현재 지역의 정가 `75 * estate_cost_main[$estate]`의 절반을 환급한다. 예: 비용 단위 19인 집은 712스파크다. 임대 주택 해지는 집값을 지급하지 않는다. 개인실·비휴대 인원·별도 임대 시설을 먼저 정리해야 한다. 빈 기본 포함 시설과 주방·욕실은 집과 함께 정리한다. 매각 또는 해지 후 빈민가로 이동하며 메인 노예·조수·외부 은행 구좌는 유지한다. 주택 이동 직후 음식 재고를 직접 삭제하지 않으며 주방 없는 집의 이후 음식 규칙은 원본 그대로다.

## 기존 UI 보호와 의존

`assets-replacements.json`은 장식 교체 67개와 미납 중 기존 해지·이사 보호 16개, 총 83개 후크다. 모든 앵커가 원본에 정확히 1회 있는지 검사했다. 기존 UI 보호는 `jo9_lq['active']=1`일 때만 적용한다. 미납 중 원래 부동산 주택 매각도 모듈에 위임하여 새 50% 금액과 동일하게 지급하며 원래 매각 코드를 이어 실행하지 않는다. 다른 플레이 구간의 기존 취소·이사 동작은 바꾸지 않는다.

장식 교체 후크를 빼면 교체한 장식의 반복 방지 표시가 풀리지 않는다. 새 게임의 표시 초기화를 빼면 이전 게임의 표시가 남을 수 있다. 모듈만 분리해도 기존 인원 배열과 세이브 형식 자체는 바꾸지 않는다. 후크 83개가 호출하는 새 로케이션이므로 모듈과 후크를 함께 유지해야 한다.

## 검증

네이티브 최종 10/10 통과: 현재 정가 50%, 실제 재교체 후 환급, 최저 주방·연구실 반복 환급 차단, 무료 이사 후 처분 표시 유지, 개인실 단계별 공사비 절반, 감옥·외양간·괴물 우리·냉동 18슬롯의 생존·기절·사망 점유 보호, 오래된 견적 재검사, 빈 주택 50%와 메인 인원 보존, 반복 주택 매각 차단, 비용 단위 19의 정수 반올림. 증거: `native/assets-final-links/client-results.json`. 실제 `#estate_base` 기준 7종 방의 기본 배경·큰 배경·장소 설명이 모두 일치하고 비어 있지 않음도 검증했다. 전체 빌드와 기존 UI 후크는 ROOT 통합 검증 대상이다.
