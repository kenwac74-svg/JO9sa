- 진행 6묶음: 같은 턴 수동 자금 마련, 자금 확보 후 한 번 정산·복귀, 이미 끝난 구제 화면과 처분 버튼을 눌러도 정상 화면으로 복귀, 실제 결산 1회·축사 수익 1회·청구액 고정, 노예와 조수의 이름/타입 변경 거절 및 한 번 매각·재실행 지급 0.
- 긴급 급매 3묶음: 원래 가격 함수가 계산한 현재 기본 가격과 50% 가격 일치(노예·조수 모두), 무인장·실신·부상·행동력 부족·정신 붕괴 상태의 살아 있는 소유 인물 매각 허용, 사망·빈 칸·타인 소유 거절, NPC 진행·관계·평판·수요·활성 의뢰·길드·대출 수치 불변, 미납 해제·가격 변경·중복 실행의 지급 거절, 모든 반환 경로의 임시 가격 계산 복사본 정리.

구현 전 새 함수 호출 두 개는 실패하고 엔진 대조군은 통과했다. 초기 반복문/다중 초기화 local 문법은 설치 엔진에서 허용되지 않아 기존 label/jump와 단일 local 방식으로 바꿨다. 가격 비교 검사는 조수의 다재다능 25% 보너스 누락을 실제로 잡았다. 중첩 FUNC가 호출자의 LOCAL 배열을 읽지 않는 엔진 동작을 독립 대조군으로 확인하고, 계산 중에만 보이는 임시 복사본과 모든 경로의 정리로 고쳤다. 수정 후 원래 가격 함수의 정확한 절반과 임시 데이터 정리를 함께 통과했다.

WORK 설치 전 1256개 입력 파일(세이브 57, JSON 1193, CSS 4, WORK 및 Full QSP 각 1)의 바이트 해시가 모두 그대로다. 원본 세이브·이미지·JSON은 쓰지 않았다. WORK 설치는 ROOT가 별도로 수행한다.

## 재현과 한계

 scripts/native-prepare-assets.cjs, native-prepare-full.cjs, native-prepare-lifecycle.cjs, native-prepare-quick.cjs가 진단 사본을 만들며 tools/qa/run-client-smoke.ps1로 설치 엔진을 실행한다. 이 스크립트에는 실제 인물 상태나 세이브 내용이 들어 있지 않고, 로컬 세이브 경로를 참조한다. G 임시 작업 루트에 복구용 before.qsp와 source/를 다시 준비하고 후보 QSP를 지정해 재현한다.

기존 세이브는 그대로 읽어 변수 상태를 재구성했다. 직접 OPENGAME 스크립트 호출은 변경 전 대조군부터 파일을 열지 못했으므로 GUI 세이브 로드와 CRC 허용을 통과했다고 주장하지 않는다. 기존 버전 상태의 조회·날짜·가격 검사는 UI_TEST_MENU를, 화면 복귀 검사는 정상적인 버전 업데이트 안내 팝업을 피하도록 현행 auto_day_end를 썼다. 결산 검사에서는 원래 안내 MSG 세 개만 진단에서 생략하고 실제 계산 함수를 호출했다. 화면 픽셀 비교와 모든 이벤트·향후 모드·수동 편집 세이브까지 검증한 것은 아니다.
