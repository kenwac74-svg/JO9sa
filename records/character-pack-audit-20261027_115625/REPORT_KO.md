# 캐릭터 이미지팩 도입 전 중복·충돌 조사

조사일: 2026-10-27. 게임 파일은 변경하지 않았다.

비교 대상:

- 팩 이미지: `G:/somi/잭오나v2.4 캐릭터 정리/game/content/pic/girls`
- 팩 JSON: `G:/somi/잭오나v2.4 캐릭터 정리/json/slaves`
- 기준: 현재 `G:/somi/Jack O Nine Tails v2.4_work/game`
- Kor_Full 배포 폴더는 이번 비교·반영 대상이 아니다.

## 결론

이 팩의 이미지 대부분은 현재 WORK에 이미 있다. 이미지 전체를 다시 도입할 실익은 작고, JSON 전체 덮어쓰기는 최근 수정과 충돌한다. 필요한 이미지와 연결 필드만 선별 검토하는 방식이 적합하다. 이번 조사는 적용 승인이 아니며 실제 반영하지 않았다.

## 이미지 중복과 충돌

팩은 PNG 12,324개, 1,764,148,566바이트(약 1.64GiB)다. 얼굴 5,353개와 전신·의상 6,971개로 구성돼 있다. 숫자로 된 캐릭터 하위 폴더는 54개이며, cloth·maid 같은 공용 폴더도 별도로 포함한다.

| 구분 | 얼굴 | 전신·의상 | 합계 | 의미 |
|---|---:|---:|---:|---|
| 같은 경로·동일 SHA-256 | 5,259 | 6,936 | 12,195 | 기존 파일과 바이트까지 같음 |
| 같은 경로·다른 내용 | 66 | 26 | 92 | 덮어쓰면 기존 이미지가 바뀜 |
| WORK에 없는 경로 | 28 | 9 | 37 | 새 파일 경로가 추가됨 |
| 전체 | 5,353 | 6,971 | 12,324 | |

동일 이미지 비율은 파일 수 기준 98.95%다. 92개 충돌은 모두 디코딩한 픽셀도 달랐다. 압축 방식이나 PNG 메타데이터만 다른 경우는 없었다. 이것은 픽셀 차이의 확인이며 그림의 우열·인물 동일성을 판정한 것은 아니다.

서로 다른 경로까지 비교하면 새 경로 37개 중 10개는 이미 WORK의 다른 경로에 같은 바이트가 존재한다. 나머지 27개는 WORK의 girls 전체에서 동일 SHA-256을 찾지 못한 내용이다. 유사 그림이나 재압축본까지 모두 서로 다른 그림으로 단정한 것은 아니다.

- 차이 129개(92 교체 후보 + 37 추가 후보)의 원본 파일 용량 합계는 10,753,386바이트, 약 10.26MiB다. ZIP 예상 크기나 확정 반영량이 아니다.
- 동일 12,195개는 1,753,395,180바이트다.
- 추가 경로 37개는 2,856,334바이트다. 그중 다른 경로와도 해시가 겹치지 않는 27개는 1,955,957바이트다.
- 팩 내부에도 2,206개의 동일 해시 그룹이 있으며, 첫 파일을 제외한 반복 사본은 2,252개·423,630,012바이트(약 404MiB)다. 의상·상태별 필수 주소일 수 있으므로 삭제 가능한 용량으로 해석하면 안 된다.

92개 충돌은 23개 인물 번호·이름 계열에 걸친다. 이사벨라 8개, 에게야 얼굴 3개를 포함한다. 나머지는 일반 캐릭터의 얼굴·전신 교체이며 전체 경로는 `images.json`에 있다. 새 경로 37개 중에는 과거 정리한 1179 녹색 경로와 176 오기 경로를 다시 추가하는 사본도 포함한다.

JSON 구문 판독 실패는 없었다. 동일한 번호를 서로 다른 JSON 파일명으로 중복 선언하는 추가 충돌은 이번 팩과 WORK 비교에서 발견하지 못했다. 다만 과거 퇴역한 정의를 복원하는 문제는 별개다.

144개를 전부 능력치 변경으로 해석해서는 안 된다. 주요 차이는 머리색 필드 104개, 체형 부위 이미지 필드 71개, 가슴 수치 57개, 이름 11개, 배경 설명 등이다. 실제 가격·콘텐츠 조건에도 관련되는 값이 섞여 있다. 변경된 외모 수치의 기획적 적합성은 이번 파일 비교로 승인하지 않았다.

## 이미지 연결 주의사항

현재 실행 QSP 273개 로케이션을 판독해 `display_fullimage`와 `jo9_seed_role_images`의 개별팩·역할 의상 연결을 확인했다. 숫자 폴더가 있다는 사실만으로 자동 적용되는 것이 아니라 JSON의 해당 이미지 필드와 연결돼야 한다. 파일명만 보고 미사용 또는 적용 완료로 판단하지 않았다.

기본·얼굴·복장·개별팩 필드의 고정 경로 검사에서는 팩과 WORK를 합쳐도 없는 참조 552개가 나왔다. 이 중 544개는 현재 WORK와 같은 기존 정의이므로 이번 팩이 새로 만든 문제로 계산하지 않는다. 개별팩 우선 표시나 다른 대체 경로가 있을 수 있어 552개의 실제 표시 오류라고 보고하지 않는다.

변경된 장면 이미지 필드까지 확장하면, 새 값에 정확히 대응하는 파일이 팩·WORK 모두에 없는 변경은 7개 JSON·11개 필드다. 세부는 `changed-missing-exact-paths.json`에 있다.

- 1257: 변경된 하녀 이미지 주소 1개.
- 1447: 옛 금발 얼굴 주소 3개.
- 2194: 다른 캐릭터 번호의 얼굴 주소 3개.
- 2217: 변경된 비서 이미지 주소 1개.
- 3003·3015·3018: 변경된 고유 장면 주소 각 1개.

이 수치는 정확한 파일 경로의 부재다. 실제 분기의 도달 여부와 대체 이미지 처리까지 플레이로 재현한 버그 수가 아니다.

## 도입 권고와 검증 범위

1. 12,195개 동일 파일은 다시 복사하거나 패치에 넣을 필요가 없다.
2. 92개 교체 후보는 현재 WORK 그림과 대조한 뒤 채택한다. 특히 사용자 제작·최근 교체한 이사벨라와 에게야는 일괄 덮어쓰지 않는다.
3. 새 경로 37개는 실제 새 내용 27개와 기존 내용의 별칭 10개를 나눠 검토한다. 과거 오기 경로나 퇴역 경로를 복원할 필요가 있는지는 별도로 판단한다.
4. JSON은 통째로 교체하지 않고 승인된 이미지 연결만 현재 WORK 정의에 병합한다. 이름·수치·설명·최근 교정은 보존한다.
5. 연결 누락과 최근 수정의 역행을 제거한 후 실제 반영 목록을 확정한다.

이미지 해시와 92개 충돌의 픽셀 비교, JSON 구문·필드 비교, 집계 합계, 비교 전후 입력 메타데이터·JSON 해시 및 QSP 보존을 확인했다. 전체 PNG의 화질 평가나 전체 게임 플레이·기존 세이브 재현을 완료한 것은 아니다. 원본·WORK·세이브·배포 폴더의 파일을 복사·교체·삭제하지 않았으며, 조사 보고서만 저장했다. 커밋·푸시하지 않았다.
