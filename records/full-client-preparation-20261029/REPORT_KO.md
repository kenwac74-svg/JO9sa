# 통합 풀 클라이언트 준비 — 2026-10-29

사용자 최신 지시: ZIP은 아직 만들지 않는다. WORK와 추적 소스만 반영한다. 배포 폴더·기존 ZIP·사용자 세이브·커밋·푸시는 변경하지 않는다.

## 완료

- 추가 이미지팩 27명(1451–1462, 2324–2338)을 일반 무작위 생성에 연결했다. 기존 세이브에 저장된 범위도 대응한다. 누락 번호 1450은 재추첨하며, 지정 인물 생성은 유지한다.
- 기존 2,681개 UI 관리 경로를 재검사했다. 남아 있던 제목 13장과 디버그 닫기 그림 5장의 관리 경로를 `content/pic/ui/titles`, `content/pic/ui/debug`로 모았다. 이전 디버그 관리 경로 5개는 폐기했다. 현재 호환 원장 2,694개를 대조했다.
- 미사용 UI 10개와 컷신 2개, 총 4,216,627 bytes를 WORK 밖에 보관한 뒤 실행 폴더에서 제거했다. 원본 bytes·옛 경로·카탈로그 ID·복구 journal은 남겼다. 네 종류 타격 SVG, 옛 세이브가 사용하는 UI, 원본컷 및 B/C컷, 인덱스 영향을 확정하지 못한 파일은 제거하지 않았다.
- 추가 팩 설치 상태와 무작위 등장 완료 안내를 카탈로그와 추적 seed에 반영했다.
- 풀 클라이언트 입력 계획을 만들었다. 런타임 42,864개, 16,780,628,916 bytes. 세이브·작업 원본·도구·백업 등 1,634개, 8,783,898,707 bytes는 ZIP 입력에서 제외한다. 이 자료는 디스크에서 지운 것이 아니다.

## 아직 남은 이미지

단체 패배 8세트가 아직 없다: 검은 의사 무리, 성기사 무리, 수인 4인조, 부랑자 5인조, 고블린 2인조·3인조, 가르시드 무리, 탈옥수 무리.
전투 전신 4개가 아직 없다: 에게야(egeya), 성기사(vatican_paladin), 포탈 가디언(strazhnik), 엘자(erza).
기존 개별 패배 이미지 미완성 슬롯도 제작 목록에 남아 있다. 누락 시 fallback이 있다는 것과 이미지 완성을 혼동하지 않는다. 이번 정리에서 미승인 시안을 게임 이미지로 덮어쓰지 않았다.

최종 ZIP은 만들지 않았으며, 위 이미지 상태와 새 플레이어용 릴리즈 노트·배포 기본 설정을 확정한 뒤 별도 빌드한다.

## 용량 해석

4.22MB는 제거한 경로의 파일 크기 합계다. 같은 볼륨의 외부 보관과 하드링크가 있으므로 디스크 여유 공간이 그만큼 늘었다는 뜻이 아니다. 8.78GB는 개발용 자료가 풀 클라이언트에 섞이지 않도록 제외한 양이며, 이전 배포 ZIP 대비 절감량이 아니다. ZIP은 아직 없으므로 압축 절감량도 측정하지 않았다.

UI의 옛 경로는 세이브 호환용으로 남긴다. WORK에서는 하드링크라 이미지 본체를 중복 저장하지 않지만, ZIP은 별도 파일로 저장하므로 경로 통합 자체가 압축 용량 절감은 아니다.
