# 각본 비교 창 직접 편집

오른쪽 수정문을 일반 div로 표시해 비교하면서 고칠 수 없었다. 실제 textarea로 바꾸고 페이지 ID에 해당하는 본문만 전체 각본 입력란/세션 초안에 동기화한다. 다른 페이지·화자 표기·조건·대체문·분기·구분선·CRLF를 보존한다. 다른 카드와 제외 체크를 유지하고 편집 즉시 기존 검토와 승인을 무효화한다. 잘못된 번호/구분선 삽입은 안내하고 바로잡을 때까지 검토/반영을 막는다. 반영 중 카드 입력도 잠근다.

사용: 카드 오른쪽 수정 → 구문·화면 검토 → 확인 체크 → 각본 반영. 기존 백업·QSP 해시 검사·실제 반영 경로를 유지한다. 카드 편집만으로 게임에 저장하지 않는다.

관련26개 검사 통과(새6개). 구분선/조건/다른 판본과 빈 페이지 보존, 번호 오류, 실제 UI 모듈의 여러 카드 동기화/재검토/승인 무효/오류복구/제외 선택을 확인했다. 최종 빈 마지막 페이지 보완 후 새6개 재확인. 실제 브라우저의14개 카드에서 시험 문구 입력·전체각본 반영·카드 유지·승인 해제·시험 문구 원복·재검토를 확인했고 오류 로그0이다. 스크린샷 참조.
