# 옷차림별 얼굴 선택·전체 이미지 다시 읽기 — 2026-11-15

## 얼굴 원본 선택

캐릭터 외형 편집의 기본·타이틀·하녀·비서·도미나 슬롯에서 모두 얼굴 파일을 선택하거나 현재 옷차림을 불러와 얼굴 상자를 만들 수 있다. 얼굴 상자의 이동·비율 유지 크기 조절·화살표는 이전 수정과 같다. 얼굴 미리보기에 원본 옷차림 이름을 표시한다. 다른 슬롯으로 이동해도 이미 고른 얼굴의 원본을 유지하며, 그 슬롯에서 새 얼굴 상자를 선택할 때만 원본을 바꾼다.

저장 계약은 그대로다. 기본 슬롯은 원래의 `face: {mode:'box',box}`를 사용한다. 다른 옷차림은 화면 정렬을 적용한 캔버스에서 151×150 PNG를 만들고, 이미 존재하는 `face: {mode:'file',src}` 경로로 전달한다. 파일 선택도 동일한 기존 경로다. 얼굴만 선택할 때 옷차림 전신을 변경 목록에 넣지 않는다. 가이드·하단 표시선은 잘라낸 얼굴에 포함하지 않는다. 캐릭터 JSON에 새 필드를 추가하거나 서버의 저장 API를 바꾸지 않았다. 새 캐릭터 생성의 기본 전신 필수 조건도 유지한다.

변경 파일: `tools/modding-hub/overrides/studio-look.mjs`. 원본 클로드 편집 모듈은 유지했다.

## 전체 이미지 갱신

‘현재 상태로 동기화’의 실제 동작은 `original-sync-plan`으로 기준 버전을 확인하고 `original-sync`로 원본 B컷 등록·보관 선택을 WORK QSP에 반영하는 것이다. 그림 새로 읽기가 아니므로 **원본 B컷 연결을 QSP에 반영**으로 이름을 명확히 바꿨다. 이 기능의 동작은 변경하거나 실행하지 않았다.

전체 이미지에 **폴더 이미지 다시 불러오기**를 추가했다. 실제 PIC 폴더를 재탐색하고, 화면에 표시된 파일의 현재 크기·수정 시각을 다시 읽어 새 URL로 그림과 링크를 갱신한다. 현재 폴더·검색·쪽·체크 선택과 원본/WORK 구분을 보존한다. 전체 이미지 탭으로 다시 돌아올 때도 표시 파일을 읽으며, 이때는 불필요한 전체 폴더 탐색을 생략한다. 새로 찾은 파일을 역사적 비교 목록에 자동 등록하거나 QSP 조건을 재분석하는 기능은 아니다.

기존 파일 갱신 로직은 `catalog_local_pic.js`의 교체기 연결·포커스/이벤트 갱신에 들어 있었다. 교체기 모듈이 자동으로 로드되는 경우도 확인했으므로, ‘반드시 교체를 누른 뒤에만 로드된다’고 단정하지 않는다. 이번 수정은 그 모듈의 로드 상태·포커스·갱신 타이밍과 별개로 전체 이미지에서 직접 읽도록 분리한다. `/catalog-tab/gallery`가 새 모듈을 항상 연결한다.

새 `catalog-refresh.js`는 기존 `pic/index?rescan=1`과 `pic/revisions`만 호출한다. 후자에는 기존 version/work 값에 bytes/lastModified만 더했다. 원본 B컷 병합·체크 저장·이미지 교체 API를 호출하지 않는다. 화면 행의 파일 크기만 메모리에서 갱신하며 저장된 카탈로그 HTML·상태 파일을 재작성하지 않는다. 이전 QSP 조건 분석 경고는 유지한다.

변경 파일: `tools/text-workshop/{catalog-refresh.js,pic-local.cjs,server.cjs}` 및 활성 카탈로그/seed의 `catalog_cuts.js` 버튼 문구. WORK 도구 설치본과 소스를 맞췄다.

- 관련 검사 6개 통과. 다섯 슬롯의 얼굴 파일 UI·원본별 crop, 탭 전환 후 원본 유지, 원래 base box 계약, 전신 미저장, 전체 이미지 URL 강제 갱신·원본 열 유지·재그리기 후 개수 표시, 폴더 추가/파일 교체 감지, QSP·체크 기록 보존을 확인했다.
- 실제 브라우저의 전체 이미지에서 **폴더 PNG 41,505개 확인 · 화면 그림 106개 갱신** 확인. 파일 개수는 당시 실행값이며 고정 기준이 아니다. 새 버튼과 QSP 반영 버튼이 분리되어 표시됐다. 검색 값이 재그리기 뒤 유지됐다. QSP 반영 버튼은 누르지 않았다.
- 실제 캐릭터 2588의 하녀 슬롯을 기존 이미지 정렬로 불러와 얼굴 상자를 열었다. 원본 표기가 ‘하녀’, 변경 목록이 ‘얼굴’만인 것을 확인했다. 시험 선택은 버리고 탭을 닫았다. 실제 이미지/JSON은 저장하지 않았다.
- 구문 및 HTTP 제공, WORK 설치본과 소스 해시 일치 확인. 전체 게임/엔진 검사와 배포 패키징은 하지 않았다.

## 적용·제거

편집 중인 내용을 보존한 뒤 화면을 새로고침한다. 전용 앱은 저장 후 다시 연다. 얼굴 상자는 선택한 옷차림의 **기존 이미지 정렬/이미지 선택 → 얼굴 상자로 만들기** 순서로 사용한다. 전체 이미지에서는 **폴더 이미지 다시 불러오기**를 누른다.

갱신 모듈의 입력은 현재 이미지 DOM/행 목록과 읽기 API, 반환은 갱신 그림 수/폴더 PNG 수다. 실패 시 오류를 표시하며 체크/QSP 저장으로 대신 처리하지 않는다. 제거할 때는 gallery script 삽입·정적 제공 목록과 새 파일을 함께 제거한다. `bytes/lastModified` 필드는 부가 정보이므로 기존 클라이언트와 호환된다. 얼굴 변경을 되돌릴 때는 이번 override의 차이만 되돌려 앞서 추가한 손잡이·가이드 기능을 보존한다.

게임 QSP·세이브·실제 이미지·캐릭터 JSON·배포 ZIP은 변경하지 않았다. 커밋·푸시하지 않았다.
