# 8명 전용 반말 연결 — 2026-11-12

사용자 확정: 캐릭터별 지정·관계/복종 변화와 무관하게 항상 반말. 대상은 루미너스3002·바실리사2610·라나2620·리아스3010·다이아나3021·이리스3023·캬루2621·에키드나3012 전체다. 번호3021의 실제 표시 이름은 다이아나다.

## 반영

- `#dynamic`의 `$voice_profile`에 선택 인물 번호를 전달하고 8명은 반말3으로 고정한다. 성격9유형·관계/공포/기분·감정 깊이·응답의 사실 선택과 성공/거절 조건은 유지한다.
- `$voice_impression`과 `$voice_native_actor` 양쪽에 연결한다. 노예/조수 대화는 실제 화자의 타입을 사용한다. 다른 인물의 타입으로 조수 말투를 바꾸지 않는다.
- 기존 반말3 원고에도 존댓말이 섞여 있었다. `jo9_plain_voice`에 2,406개 완성 문장의 교정 대응표를 둔다. 개발용 `voice-copy.cjs`로 어미·자칭 교정 후보를 생성하고 잔여 존댓말 및 표시 토큰을 점검했다. 게임에서는 알려진 완성 문장의 정확 일치만 조회하며 어미를 임의 치환하지 않는다. 원고와 교정본은 `plain-copy.json`에서 대조할 수 있다. 다른 인물과 미등록 직접 편집문은 그대로 반환한다.
- 공용 원고를 전역 수정하거나 별도의 반말 배열을 세이브에 저장하지 않는다. 교정 함수는 QSP 로케이션에 있다. QSP는 689,518바이트 증가했다. 임시 화자 타입은 대화 조합 후 제거한다. 기존 대화 이력 관리만 유지한다.
- `interaction`1111~1118 진입 시 새 마커가 없는 옛 대사 함수 캐시를 다시 읽는다. 개인 SAV를 직접 수정하지 않는다.
- 캬루·이리스 JSON의 세계/가족/직업 소개 각3필드, 합계6필드를 반말로 고쳤다. 나머지6명은 현재 반말 원고를 유지했다. 알려진 예전 한국어 소개문과 현재 소개문을 인물·분류별로 정확 대조해 표시만 호환하며, 직접 편집한 소개는 덮어쓰지 않는다. 기존 `jo9_json_ko`의 영문→한국어 표시는 먼저 거친다.
- 특성 발견 희망사항의 직접 출력 문장도 같은 8명 전용 교정 조회를 거친다. 발견 조건·특성 공개·수치·플레이어가 승인한 응답 내용은 보존한다.

## 사용·입출력·의존성

일반 EXE에서 해당 인물 선택 → 일반 대화(과거/생각/요구/희망/불만/기분 및 상대 인물 평가). 새 게임만 요구하지 않는다. 관계가 변해도 반말을 유지하되 반항/두려움/헌신의 내용 차이는 유지한다. 일반 NPC 사건 전체를 새로 각색하는 작업은 포함하지 않는다.

`$voice_profile`의 추가6번째 인수는 화자 번호다. 기존5개 인수는 그대로다. `$voice_pick_fragment`는 선택·조건 판정을 마친 뒤 등록된 문장만 교정 함수에 전달한다. `jo9_plain_voice`는 `(화자번호, 원문)`을 받고 교정문 또는 원문을 반환한다. 대응표 조회는 문장 길이로 묶어 불필요한 비교를 줄였다. 능력치나 퀘스트 상태에 쓰지 않는다.
