## 수정과 검수

기존 배경 치환은 이진 마스크로 배경색만 바꿨기 때문에 머리카락과 장비 외곽의 반투명 경계가 끊겨 도트와 검정 잔색이 보였다. 파일 규격·프레임·마스크 외 픽셀 보존이 통과해도 이 육안 결함은 해결되지 않았다는 사용자 지적을 기준으로 수정했다.

27개는 G:/somi/JO9resource/mob_body의 같은 캐릭터 투명 전신을 찾아 기존 초상의 얼굴 위치에 정합했다. RGBA를 프리멀티플라이 상태로 축소한 뒤 원래 알파와 색으로 황토색 배경에 합성하고, 기존 초상의 불투명 얼굴·몸통 내부를 복원했다. 옛 검정 매트 RGB를 새 알파로 이중 합성하지 않았다. 모든 정합은 같은 인물·표정·장비로 육안 확인했고, 중앙 얼굴 RGB 오차는 최대 약3.79/255였다. 이 오차가 최종 얼굴 변경량을 뜻하지는 않는다. 최종 얼굴 내부는 기존 WORK 픽셀을 유지했다.

## 입력·출력·의존성

입력은 이번 수정 직전의 황토색 초상, 최초 배경 교체 전의 초상, 투명 전신 원본27개, 사용자 첨부 RGB 원본1개, 원본 황토색 템플릿과 프레임 영역 명세다. 출력은 같은 위치의 150×150 불투명 PNG30개다. 얼굴·의상·포즈·무기나 전투 계산을 변경하는 기능은 추가하지 않았다.

원본은 두 단계로 보존한다. 최초 검정 매트 초상은 G:/somi/JO9_work_backups/mob-portrait-backgrounds-20261030/original, 이번 수정 직전 초상은 G:/somi/JO9_work_backups/mob-portrait-edge-fix-20261030/original에 있다. 관련 메타데이터 원본은 새 백업의 metadata-*.gz다. 사용자 첨부 파일과 투명 전신 원본은 수정·이동·삭제하지 않았다.

재현은 source-alignment/align_sources.py로 정합 RGBA를 만든 뒤 prepare.py를 실행한다. prepare.py는 반영 후에는 이번 수정 직전 백업을 입력으로 사용하여 G:/Codex/tmp에 후보를 만든다. Pillow·NumPy와 기존 프레임 영역 명세가 필요하다. 검수용 중간 RGBA는 재생성 가능하다.
