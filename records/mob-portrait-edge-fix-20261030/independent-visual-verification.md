# 독립 초상 경계 검수

최종 후보 명세 SHA256 `8abff80d74d3d815df15cce95eed46800cbd1128e32f2de24d4cb660d1f91d21` 기준 PASS.

저장된 PNG 30개를 각각 원래 크기150×150로 확인했고, 연락표2개와 문제 표본6개(아마존·보병1·코르부스·새 여교관3·와그·모리건)를3배 확대해 원본과 대조했다. 원본 RGBA를 정합한27개는 종전 이진 마스크의 검은 도트와 거친 가장자리가 정리됐으며, 가는 머리·장비 외곽이 자연스럽게 보인다. 현재 후보에서 눈에 띄는 새 전경 구멍·검은 매트 테두리·피사체 손상은 관찰하지 못했다.

와그 상단 오른쪽에는 처음 검정 조각이 남아 있어 반려했다. 원래 RGB 초상과 확대 대조하니 털이 아닌 검정 배경 공백이었다. 해당 중성 검정 영역을 다시 배경으로 분류한 후 최종 후보를 재검사했으며, 눈에 띄는 검정 조각과 황토색 구멍이 사라진 것을 확인했다. 이 새 배경 교체 범위가 change-band에 누락된 문제도 수정된 후 다시 검사했다.

독립 기술 검사도30개 모두 통과했다. 후보PNG해시·150×150규격, 원래 프레임, protected-core의 현재 전경 픽셀이 정확히 일치한다. 실제 변경 픽셀은 모두 기록된 change-band 안에 있다. 비대상68개와 QSP해시는 그대로다. 독립 재검사 스크립트는 prototype-agent/independent_technical.py, 결과는 independent-technical-verification.json이다.

와그·모리건·새 여교관3은 원래 알파가 없는 입력이므로 경계 알파 추정이다. 이3개를 무손실 알파 복원이라고 판단하지 않았다. 이번 검수는 저장 이미지와 픽셀 검사이며 게임 플레이 검증은 수행하지 않았고 WORK·원본은 변경하지 않았다.
