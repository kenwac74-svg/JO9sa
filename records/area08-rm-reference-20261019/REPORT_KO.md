## 자료를 읽을 때의 기준

- 이 RM 폴더의 표시문은 영어와 러시아어가 섞여 있다. 러시아어 변수 이름을 러시아어 원문 대사라고 부르지 않는다. 예를 들어 방어구·게랄트의 해당 원문은 영어다.
- `.qsrc`와 실행 QSP가 모든 위치에서 같지 않다.18개 추출 위치 중11개 본문이 일치하고7개는 다르다. 특히 적 사전과 도시 상호작용의 NPC 범위가 다르다. 소스 전체가 더 최신이거나 실행본 전체가 동일 원문이라고 가정하지 않았다.
- 대조한 전투9레코드의 RM compiled는 이전 RM 보관본과 같다. 전체 QSP 해시는 다르므로 폴더 전체를 같은 버전이라고 단정하지 않는다.
- RM에도 잘못되거나 구현과 어긋나는 태그가 있어 실제 효과와 함께 판단한다. 출혈·대지 진동 태그 등에서 원문 글자 그대로와 현재 게임 효과를 구분한다.
- 누가 언제 Work의 돌려차기 사전값을 바꿨는지, 요정 사슬갑옷의 빈 효과 덮어쓰기가 의도적이었는지는 이번 정적 비교로 확인하지 않았다. 번역·코드·기획의 출처를 추측하지 않는다.
