# RM 장비 원문 대조

확인한 RM의 해당 설명은 **영어**다. 러시아어는 `колющий`, `рубящий`, `верткость` 등의 코드 식별자·효과값이다. 아래 RM 줄번호는 모두 `rm-compiled/#боевые_предметы.txt` 기준이며, 같은 위치의 RM source·현재 compiled·previous compiled 본문도 일치했다.

|---|---|---|---|

RM 원문 서술의 내용도 유지해야 한다. 가죽973의 “megalodon’s chemically treated skin”, 요정 사슬1000의 “fine titanium rings”와 이동 유연성, 기사 사슬1028의 조밀한 강철 짜임과 cutting/thrust 방어, 레이피어376의 양날·찌르고 베는 용도는 각 수치나 피해 타입 표기의 정정과 별개다. 각 원문 전체 문자열과 장착/해제·효과 closure는 `findings.json`에 원문 줄별로 저장했다.

권고를 **텍스트 정정**과 **효과 활성화**로 나눈다. 상어가죽·기사 사슬의 숫자를 공통 RM/Work 코드와 맞추고, 요정 사슬의 근거 없는 둔기2 표시를 정리하며, 레이피어 분류를 관통으로 맞추는 것은 텍스트 정정 후보다. 게임 메커니즘을 복구할 증거는 없다. 레이피어 설명행404는 직전36건의 범위 밖이므로 별도 검토한다.

회피3은 앞선 실제 선언이 있으므로 의도 후보의 근거는 된다. 그러나 바로 뒤 빈 closure도 RM에 실제로 있으며, 영어 원문은 회피3이라는 숫자를 보장하지 않는다. 마지막 빈 closure를 제거하면 RM와 Work의 최종 선언 상태를 모두 바꾸므로 **자동 복구하지 않는다**. 현재 상태에 맞춰 설명을 정정할지, 회피3을 작동시키도록 동작을 바꿀지는 별도 설계·승인 항목이다. 정적 초기화 순서만 검증했으며 런타임 장착 실험은 하지 않았다.

관련 장착/해제·효과·타입·기본피해 선언11종은 RM와 Work의 내용을 공백 정규화하여 비교했으며 모두 동일했다. RM 복사 QSP 해시는 `7736930bffbb6adef8a92535f63e0cf2bb8048e5f5863cbf84e35e9ca524138d`, 현재 Work 해시는 `ae591ef904a5fe0f4cbac3454815ac36cd1475464689869bb75c94e3e7fe7826`으로 확인했다.

RM 원본·게임·저장·저장소·소스는 변경하지 않았다. 이 폴더의 보고서·JSON·검토 스크립트만 작성했다.
