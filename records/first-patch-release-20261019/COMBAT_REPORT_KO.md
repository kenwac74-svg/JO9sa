## 연결 수리와 호출 영향

에게야는 실제 전투 시작부가 읽는 러시아어 결과3키를 넣고 영어3키를 별칭으로 보존한다. 엘자는 사망/기절/항복 결과키를 기존 생존·사망 후속 장면과 양립하게 추가한다. 입력은 기존 적ID이며 반환은 적의 최종 라운드 로그 문자열이다. 승리 보상/획득 분기 자체는 추가하지 않는다. 호출 경로는 `начать_бой` 결과문 복사 → `конец_раунда` 종료상태 로그 → `конец_боя` 표시다.

돌려차기 사전은 RM과 같은 올바른 배열×2로 정리한다. `атака_игрока`의 정상 실행×2 입력은 보존한다. 안면강타는 사전 텍스트를 고정 기술키에 등록하며 정상 실행 직전 재등록은 보존한다. 아우게아스는 자신의 출발선 키에 기존 점수 공식을 등록하므로 안젤리카와 아우게아스가 각자 기존 점수를 받는다. 다른 경주 구간/수식은 보존한다. 이 변경은 사전 재로딩 또는 새 전투/경주에서 사용된다.

요정 사슬갑옷은 실제 남아 있는 성능으로 설명만 맞췄다. 둔기방어·회피를 활성화하지 않았으며 회피 closure가 빈 closure로 덮이는 현 상태를 유지한다. 레이피어의 별도 잔여 분류 문구도 범위에 넣지 않았다.
