# 출신 02 선별 패치 독립 검토

**결론: 작성자 수정이 필요한 오류나 출고 차단 사항을 발견하지 못했다.** 게임·저장·원고·패치는 수정하지 않았다. 검토 산출물은 이 문서와 `review-independent.json`뿐이다.

검토 대상은 `origin02-selected.patch.json`, `row-dispositions.json`, `fragment-comparison.json`, `prepare-origin.cjs`, `verify-origin.cjs`다. 별도 보존 원본 `before-combined.qsp`의 SHA-256 `81a4198501a45faa6c4f21f25894b0963dcdbb8d70ee3fe9bdbed5d963d2dab4`에서 독립 재생했다. 출신 패치만 적용한 메모리 결과는 작성자 검증값 `9072ef71a7b8e163d9a6e5a7867acd1693be472b6fa5aebf5b863d99320d54e2`와 같다.

## 승인·문장 검토

- 승인표 155행을 그룹·키·판정·사유로 대조했다. 채택 27·병합 92·현행 유지 34·보류 2가 일치한다. 세계 40·가족 55·직업 60의 누락이나 중복 매핑이 없다.
- 일반 배경 152개는 reserved/direct/hesitant × t1/t2/t3의 9조합을 모두 유지한다. 총 1,368개 값에 빈 문장이 없고 조각 키·순서·문두 연기 지시·보호된 표시 토큰이 보존된다. 62배경×9=558개 값만 바뀌며 나머지 90배경은 그대로다.
- 채택 27행은 전부 문구 수정에 포함된다. 병합 92행은 일반 문구 수정 35행·현재 핵심 사실 충족으로 유지 55행·신규 clone 직접문 2행으로 구분된다. 현행 유지 34행은 일반 33행과 clone 직업 1행이다. 따라서 병합 행의 ‘변경 없음’을 미처리 항목으로 숨기지 않았다.
- 세계·가족·직업별 사실 차이와 기존 말투를 남기는 작은 표현 이식이다. 새 현재 관계 평가·복종 보장·고정 감정 결말이나 모든 배경을 같은 생활 수준으로 만드는 수정은 발견하지 못했다. 기존 추측·제한된 기억·조건부 전승을 새 확정 사건으로 바꾸지 않는다. 이미 승인된 새 생활 세부는 원문 복구로 오인하지 않도록 처분표에 구분되어 있다.
- `rich_wife`, `time_plice`는 각 9개 값 모두 원본과 같다. 미확정 고유명·명칭 통일·과거 저장문 일괄 변환도 추가하지 않았다.

## 실행·저장 검토

- 561개 수정은 각각 적용 직전 원문이 고유하게 1회 존재한다. 재생 결과는 위 준비 해시와 일치하고, 역재생하면 원본 전체 바이트와 같다. 적용 후 재적용 판정 실패는 0이다. 실제 패치는 기록된 순서를 유지해야 한다.
- 변경 필드는 `#txt_man.body`, `#dynamic.body`, `generate_clone.body` 세 개뿐이다. `#txt_man`은 1,368개 대상 문자열 값을 가린 뒤의 전체 실행·메타데이터·관계·Wayward 코드가 전후 완전히 같다. `#static_txt`, 일반 생성기, 복사·표시·새 로드 경로와 저장 식별 기본문은 그대로다. 새 함수·위치·지속 키·마이그레이션은 없다.
- 사업가 alias는 기존 `#dynamic:6895`의 한 조건에만 canonical `businessman`과 legacy `buissinesman`을 OR로 연결한다. 기존 그룹 `1111_family_family_buissinesman` 및 단일 `matches+=1`은 유지된다. 배열 키를 바꾸거나 기존 저장문을 재작성하지 않는다.
- **사업가 조건은 실제 QSP 5.7.0에서도 7개 경우를 통과했다.** 실제 패치된 `$voice_native_stored` 전체 함수와 실제 canonical 정적 저장문을 사용했다. canonical만·legacy만·같은 두 값·서로 다른 두 값에서 각 저장문·미식별 fallback·빈 사전을 확인했고 엔진 오류는 0이다. 표시 조합기 `$voice_native`만 선택 그룹을 반환하는 대역으로 바꾸어 분기와 fallback을 검사했으며, 게임·저장 파일은 쓰지 않았다.
- clone은 원본 `generate_clone:82–83`의 두 직접 저장문만 바뀐다. 직업 저장문인 84행과 나머지 생성 코드는 같다. 앞으로 생성되는 clone에만 새 표현이 저장되고, 기존 clone의 고정 저장문을 자동 변환하는 경로는 없다.
- 공식 `inspectWorld` 통과: 261개 위치, QSP 전체 바이트 왕복 일치, 줄바꿈·마커 경계 문제 0.

## 남은 검증 범위

통합 후보의 실제 저장 로드, 기존 관계 조각과 9개 말투의 화면 조합은 이 독립 검사에서 실행하지 않았다. 별도 통합 엔진 검사가 필요하다. `source_sha256`은 근거 원본 해시이며 공식 적용기의 강제 해시 필드가 아니므로, 다른 승인 패치와 합칠 때에도 고유 원문 검사와 최종 후보 해시 봉인을 유지해야 한다.

기계 검사 결과와 행별 매핑은 `review-independent.json`에 기록했다.
