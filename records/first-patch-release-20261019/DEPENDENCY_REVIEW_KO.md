# 2.4 이후 1차 패치 — 자원 의존성 검토

읽기 전용 감사다. 게임·JSON·CSS·이미지·원고는 수정하지 않았다. baseline은 최종 Full ZIP의 검증 추출본이고 현재 Kor_Full과 QSP/CSS/JSON이 일치한다. Work QSP는 `81a4198501a45faa6c4f21f25894b0963dcdbb8d70ee3fe9bdbed5d963d2dab4`이다. CSS/JSON 1156개만 해시 비교했고 이미지 전체 해시는 읽지 않았다.

## 권고 선별안

최신 Work QSP와 `css/base.css`를 포함하고, JSON은 2.4 baseline을 유지하는 안을 권고한다. CSS/JSON을 확장자로 일괄 제외하는 판단이 아니다. 확인된 JSON 변경31개가 모두 제외 대상 외부 이미지팩 등록에 속하며, 이번 코드·기능 패치에 필요한 독립 JSON 변경은 없기 때문이다. 이 안의 **필수 신규 이미지 목록은 0개**다.

| 대상 | 실제 차이 | 권고 |
|---|---|---|
| `css/base.css` | 가정교사 전용 `.snk_room_tutor` 배치 블록 | 최신 QSP 클래스와 함께 포함. 신규 그림 참조 없음 |
| 기존 인물 JSON29개 | 외형 경로·팩 metadata만 변경. 4개는 metadata만 변경 | 이번에는 baseline 유지. 외부팩 갱신과 함께 보관 |
| `1160.json` | baseline에 없는 얼굴·전신72개 등록 | baseline JSON/기존 전신 fallback 유지. Work JSON을 넣으려면72개 15053005바이트 필요 |
| `2323.json`·성인상한2323 | 구 이사벨라를 새 랜덤 템플릿으로 추가 | JSON+상한+얼굴/전신/장면266개를 함께 보류. 일부만 포함하지 않음 |

기존 28개 JSON(1160을 제외한 기존 파일)은 등록된 정적 경로가 baseline에 있어 기술적으로는 새 이미지를 넣지 않아도 된다. 그러나 외부팩 버전/등록 갱신이며 독립 게임기능 변경은 없어 이번 코드 패치에서 보류할 수 있다. `2571_isabella.json`은 pack_ver만 바뀐다. baseline JSON을 유지하면 기존 2571 외형을 사용하며 인물 정체성과 새 코드 동작은 보존된다.

## 동적 장면과 메이드 컷신

`display_pic:198..203`은 인물ID+행동의 `picMax`가0이 아닐 때만 인물 전용 풀을 쓴다. 없으면 `206..233`의 외형/나이/일반 풀로 가며 `339..394`에서 비어 있지 않은 풀을 선택한다. 인덱스는 `398..430`에서 그 풀의 picMax로 뽑는다. 바뀐 JSON29개에는 장면 수나 picMax 배열 필드가 없다. 따라서 새 장면6,381개를 제외한다고 metadata가 없는 그림 번호를 직접 강제하는 구조는 발견되지 않았다. 새 패키지의 실제 파일을 기준으로 엔진 이미지 등록을 확인해야 하며 기존 Work 세이브의 사전/캐시는 별도 통합 검증 대상이다.

메이드 수정은 room1~4의 `main_actor_type`을 실제 roomN_type으로 고치는 연결 수리다. 기존 end_day 작업과 공용 display_pic을 사용하며 메이드만을 위한 새 파일명을 추가하지 않는다. 15개 외형 연결도 인물의 기존 indpack 등록 또는 원래 fullimage를 읽는다. baseline JSON으로 선택하면 새 인디팩 자원을 요구하지 않는다.

## 직접 경로 검사와 예외

최신 QSP의 baseline 대비 변경은36개 로케이션이며 새 `content/pic/...` 정적 파일 경로는0개다. 변경 JSON31개에 든 정적 등록 경로2,224개를 확인하니 baseline에 없는 실제 신규 경로는1160의72개와2323의72개다. 이외6개 legacy fullimage/fullmade 경로는 baseline과 Work 모두 원래 없으며 이번 패치로 새로 생긴 누락이 아니다. 실제 배포에서 fallback도 기존 등록으로 해결되는지 검사할 대상이다.

선택적으로2323을 유지하려면 사전에 합의한 원형 묶음266개(140186768바이트)를 모두 포함해야 한다. 이미지를 뺀 채 상한2323만 올리면 신규 생성이 없는 자원을 선택할 수 있다. 현재 Work에서2323을 생성해 저장한 파일이나 새 경로를 복사한 저장은 설치된 외부 이미지 업데이트에 계속 의존한다. baseline용 1차 패치는 그 저장을 다른 외형으로 변환하지 않는다.

정확한 JSON 필드 차이·파일 해시·신규경로·선택 묶음의 모든 상대경로/바이트는 `dependency-review.json`에 있다. 감사 코드는 `dependency-audit.cjs`다. 선택안의 실제 패치와 엔진 검사는 여기서 만들거나 실행하지 않았다.
