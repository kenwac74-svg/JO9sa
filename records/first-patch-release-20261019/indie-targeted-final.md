# 인디 대상 최종 독립 대조

Work와 Kor_Full의 2323 일반 템플릿, 2571_isabella 정의, slave_index JSON은 모두 바이트 동일하다. JSON에 포함된 확장자 없는 이미지 참조를 실제 PNG 경로로 해석해 152개 참조의 양쪽 실존과 SHA-256 동일성을 확인했다.

명시적 얼굴·indpack 외형의 공통 72필드는 2323과 2571의 경로가 분리되어 있다. 대표 얼굴·제목 그림·기본 전신의 내용 해시도 서로 다르다. 같은 내용의 보존용 외형 필드는 별도 경로로 유지하며 상세 필드명은 JSON에 기록했다. 일반 랜덤 범위에 2323이 포함되어 있고 Work·Full 인덱스는 같다.

6,381은 기존 장면 추가 기록의 수치이며 JSON 인물 ID가 아니다. 기존 세이브·registry 복구, 실제 화면·생성·CRC 호환은 이번에 검사하지 않았다. 이미지 총수 재산정이나 카탈로그·게임·세이브 수정도 하지 않았다. 원문 데이터값과 개인 세이브는 산출물에 포함하지 않았다.
