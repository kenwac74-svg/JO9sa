# 05·07·09 선택 패치 독립 검토

검토 대상은 `build-remaining.cjs`, `patch.json`, `selection.json`과 `before-combined.qsp` → `remaining-integration/candidate.qsp`다. 검토 중 게임·저장·원고·패치·후보 QSP는 수정하지 않았다.

**결론: 출고를 막는 오류나 승인 범위를 넘은 새 실행 변경을 발견하지 못했다.** 이 검토는 아래 두 해시의 257개 수정에 한정된다.

- 전: `81a4198501a45faa6c4f21f25894b0963dcdbb8d70ee3fe9bdbed5d963d2dab4`
- 후: `be1effaadef7c329f4999c46baa71c26a650bb83e373656e83d4f9ea594eac94`
- 05: 승인 26행과 라파엘 실제 출력 2곳, 총 28개. 07: 178행 중 176개 적용·2개 보류. 09: 기존 출력·표시 교정 53개. 합계 257개, 변경 위치 13개, 나머지 248개 위치는 그대로다.

## 확인한 사항

1. **재생과 중복 문맥:** 각 수정 직전 `old`는 정확히 1회 존재한다. 순서대로 메모리에서 재생한 결과가 후보 전체 바이트와 같고, 역순 복원 결과가 원본 전체 바이트와 같다. 실제 `apply_mods.ps1`의 적용·재적용 판정식을 그대로 재현했을 때 재적용 대상과 판정 실패가 모두 0이다. 이 산출물은 기록된 수정 순서를 유지해야 한다.
2. **여성 분기:** 원본 `#sex_texts:313`의 바깥 `else`부터 마지막까지 21,751자가 후보에도 완전히 같다. 남녀 중복 키가 있는 176개 수정 모두 남성 분기 안에서만 이루어졌다. 여성 분기 UTF-8 SHA-256은 전후 모두 `46871c9cd87275b10cac3a6ced25e050787bb05ad01f9f7c18ff4ec2ca8d7800`이다.
3. **보류:** 원본 `#sex_texts:271`의 `$sex_urination[2]`, 281의 `$sex_analfisting[5]` 대입문은 그대로 남아 있다. 승인되지 않은 반응·행동 변경을 해당 두 값에 적용하지 않았다.
4. **실행식:** 새 주석과 표시 문자열을 제외한 실행 골격은 모두 동일하다. `#sex_texts`의 일부 줄 끝 공백 제거만 있으며, 분기·첨자·연산식·호출·상태 쓰기는 추가되지 않았다. 표시 안의 네 완료 키는 승인된 현재 세션의 `sex["girl_age"]`·`sex["girl_anal_stretch"]` 참조로 보정되었다. 다른 표시 표현식의 이름 추가/명사 중복 제거 3건도 별도 JSON에 기록했다.
5. **05:** `$Redlight_whore_a[1]`의 기존 여러 줄 리터럴 전체를 선택했고, 새 값은 닫힌 리터럴 1개다. 두 가격 표시는 실제 3스파크와 일치한다. `$rafael_win[1]`, `[2]`는 사전과 `interaction_city`의 직접 출력이 각각 일치한다. d[3]은 기존 담당자 배치와 나머지 문장을 보존하고 시간 표현만 ‘약 30분 더’로 바꾼다. 강한 거래 어조가 새 거래 조건이나 폐기 동작으로 바뀌지 않았다.
6. **07:** 기존 양방향 동작·체형 조건·별도 보조 동작의 범위를 남기는 절충이 반영되었다. 무조건적인 반응, 시간대, 선행 동작을 추가하는 형태의 새로운 조건·수치 보장은 발견하지 못했다. 도움말의 경계와 예외도 승인된 검토표와 맞는다.
7. **09:** 기존 영어 출력 번역, 화자·갤러리·메뉴 표시 이름, 기존 교육 설명의 사실 교정이다. 새 장면·분기·이미지 경로·등장 인물 생성은 없다. 알료샤 선택 ID `12041`과 호출 구조, 인접 다자레헤셰 문자열의 `<<a>>` 보상 참조는 유지된다.
8. **정적 검사:** 공식 `release-check.cjs`의 `inspectWorld` 통과. 261개 위치, 전체 바이트 왕복 일치, 줄바꿈·마커 경계 문제 0.

## 검증 범위

실제 QSP 엔진에서 장면을 실행하거나 기존 저장을 로드하지 않았다. 이 검토의 정적 검사와 실제 257개 수정 재생은 엔진의 문자열 평가 및 화면 출력 검증을 대신하지 않는다. 최종 08·출신 통합 뒤에는 최종 후보에 대한 공식 엔진·저장 검사를 별도로 확인해야 한다.

근거 파일: `review-remaining.json`, `review-remaining-detail.json`, `review-remaining-semantics.json`. 재현 스크립트는 같은 이름의 `.cjs` 세 개다. 모두 검토 산출물만 기록한다.
