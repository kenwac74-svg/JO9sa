# 아르곤 02 선별 반영 준비

게임·저장소 파일은 수정하지 않았다. 기준은 Work `81a4198501a45faa6c4f21f25894b0963dcdbb8d70ee3fe9bdbed5d963d2dab4`이다. 승인된 채택 27·병합 92·현행 유지 34·보류 2의 방향을 현재 활성 조각과 대조했으며, 전체 기본문으로 덮지 않았다.

| 대상 | 검토 행 | 승인 분류: 채택/병합/유지/보류 | 실제 문구 변경 |
|---|---:|---:|---:|
| 세계 | 40 | 8 / 25 / 7 / 0 | 일반 27×9조각 + 신규 clone 직접문 1 |
| 가족 | 55 | 19 / 33 / 3 / 0 | 일반 23×9조각 + 신규 clone 직접문 1 |
| 직업 | 60 | 0 / 34 / 24 / 2 | 일반 12×9조각 |
| 합계 | 155 | 27 / 92 / 34 / 2 | 일반 62×9=558조각 + clone 2문 |

실제 패치는 문구 560곳과 기존 사업가 selector 조건 1곳, 총 561개 exact edit이다. 채택 27행과 일반 병합 35행에 승인된 세부를 현재 문장 안에서 이식했다. 병합 중 55행은 현재 조각이 승인된 핵심 사실을 이미 충족하여 유지했고, 나머지 병합 2행은 clone의 직접 저장문이다. 일반 152배경 중 90개는 문구를 그대로 유지한다. 행별 사유와 교정 범위는 `row-dispositions.json`, 정확한 전후문은 `fragment-comparison.json`에 있다.

- 적용 원고: `origin02-selected.patch.json`. 각 편집은 `location/field/old/new/count:1`을 포함한다. `source_sha256`은 원본 근거이며, 다른 승인 패치와 합칠 때는 각 exact old의 일치 여부를 검사해야 한다. 변경에는 `JO9 MOD START/END ORIGIN02_*` 식별자가 있다.
- 일반 배경: `#txt_man`의 기존 1,368조각 중 558개 값만 변경한다. reserved/direct/hesitant × t1/t2/t3의 9조합과 문두 연기 지시, 역할·관계 메타데이터, Wayward 및 현재 관계 조합 로직은 보존한다. 고유 사건·가족 구성·직무·화자의 제한된 지식과 조건부 전승을 새 고정 관계 평가로 바꾸지 않는다.
- 저장 식별문: `#static_txt`의 기존 배열과 저장 필드를 보존한다. 일반 배경은 저장된 기본문을 기존 `$voice_native_stored(category, storedText)`가 식별한 뒤 현재 조각을 화면에 조합한다. 인자는 world/family/occupation과 저장문이고, 반환은 현재 조합문 또는 미식별 저장문 그대로이다. 기존 임시 선택 변수의 용도와 생명주기는 바뀌지 않는다.
- 사업가 가족: 실제 배열·생성 키는 `businessman`, 기존 표시 그룹은 `family_buissinesman`이다. `#dynamic:6895`의 기존 한 분기에서 양철자 배열 값을 OR로 허용하여 한 번만 일치하도록 한다. 승인된 자동차 부품 도매업 조각은 이미 있으므로 문구를 다시 만들지 않는다. 기존 조선공학 부품 저장 기본문은 식별용으로 보존한다. 과거 저장문도 해당 배열 값과 같을 때 인식하며, 알려지지 않은 커스텀/과거 문장은 기존 fallback으로 남는다. 배열 키를 정규화하거나 저장문을 재작성하지 않는다.
- clone: `generate_clone:82`의 ‘창조된 세계’를 ‘만들어진 고향 세계’로, `:83`의 액체를 배양액으로 명료화한다. 제한된 기억·기술 범위를 유지한다. `:84`의 신경 인터페이스·데이터/이데오운동 기술은 원문대로 둔다. 이후 새 clone 생성에만 반영되며 기존 인물에 저장된 고정 배경은 바꾸지 않는다.

기존 로드 경로 `$newloc:91–93 → $addon:5–9 → refresh_database:19,21,38`가 기존 정적 배열·동적 selector·조각을 다시 읽는다. `interaction:591,594,598`은 기존 저장 배경을 selector에 넘긴다. 따라서 새 함수·새 로케이션·지속 상태·자동 마이그레이션·추가 캐시 갱신 훅을 넣지 않았다. selector alias를 제거하면 canonical 사업가 배경은 다시 저장 기본문 fallback으로 돌아가며, 조각 교정만 제거하면 기존 조합 구조 안에서 이전 문구가 표시된다.

`rich_wife`, `time_plice`는 9조각씩 전부 그대로 보류한다. 진리성/진리부 명칭 통일, 검증되지 않은 전문 용어·고유명 교정, 기존 clone 고정문/미식별 과거 배경의 자동 갱신도 이번에 확대하지 않는다. 모든 보류 사항은 다음 패치 전에 항목별 승인이 필요하다. 새 성적 장면이나 기존 장면의 상세 확장은 작성하지 않았다.

검사는 `verify-origin.cjs`와 `validation.json`에 있다. 메모리 안에서만 패치를 적용하여 QSP 재직렬화·재파싱, 261로케이션 유지, 일반 152개 실제 저장 키의 유일한 표시 그룹 연결, 양철자/동일값 중복 방지/미식별 fallback, 1,368조각과 조건·관계 코드 보존, 보호 항목·clone 경로를 검사한다. `source-audit.json`에는 원문 중복 대신 식별자·위치·해시를 기록한다. 실제 엔진 실행 및 기존 세이브 화면 확인을 대신한 검사는 아니다.

통합 후 수동 확인은 기존 세이브의 배경 대화와 말투/어조 변화, 사업가 배경 표시, 모르는 고정 저장문의 fallback, 새 clone과 기존 clone의 차이, 보류 2항목 보존에 집중하면 된다. 재현 순서는 `inspect-origin.cjs → prepare-origin.cjs → verify-origin.cjs`이며, 세 스크립트 모두 게임은 읽기만 하고 이 작업 폴더의 준비물만 작성한다.
