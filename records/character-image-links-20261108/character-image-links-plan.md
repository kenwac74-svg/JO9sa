# 캐릭터 이미지 수동 연결과1448시루 경로 정리

- 확정: 체크리스트의 기본 전신/초상/복장/상태별 항목에서 기존 PNG를 폴더 탐색으로 선택하고 JSON 연결을 저장한다. 기존 PNG 교체 기능은 유지한다.
- 원인:1448·2577의 실제 WORK JSON에는 역할 경로가 있으나 내장 원장은 예전 JSON을 보유한다. 로딩/상태 새로고침 시 실제 JSON 등록을 다시 읽는다.
- 역할 일반 그림은 새·옛 엔진 조회 모두 일치하도록 fullmade/indpack_maid, fullsecretary/indpack_secr, fullmistress/indpack_dom을 함께 지정한다. 상태별 그림·기타 의상은 해당 키만 변경한다. 초상 경로 prefix와 확장자 생략 규칙을 유지한다.
- JSON은 최신 해시를 확인하고 선택한 키만 편집한다. 외부/잘못된 PNG/예약 폴더/중복 ID를 거부하고 JSON 원본과 연결 이력을 보존한다. 이미지 자체·SAV·QSP는 변경하지 않는다.
-1448은 같은 폴더에서1448_shiru(+gray/sepia)7개 이름을 새 기준으로 연결한다. PNG 바이트는 유지하고 옛 경로는 세이브 호환 사본으로 보존한다. JSON 파일명/ID/능력치/설정문은 바꾸지 않는다.2577은 실제 등록을 읽어 표시하되 현재 JSON을 불필요하게 수정하지 않는다.
- 회귀 검사→격리 서버/중립 PNG 실제 선택·저장·상태 갱신→시루 참조 감사/적용→WORK/추적 소스 동기화→엔진 경로 조회 검증→인계/임시 정리. Full·배포·음원·커밋푸시 제외.
