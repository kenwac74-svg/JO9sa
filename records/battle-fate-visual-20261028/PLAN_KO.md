# 전투 결과 화면 표시 보완

사용자 요청: 처형·생존 선택지를 전투 메시지와 동일한 폰트로 표시하고 붉은색·녹색으로 구분한다. 별도 계속 링크 없이 기존 썸업으로 진행한다. 기존 붉은 전투 배경은 처형 순간 연출로만 쓰고, 첨부한 795×596 이미지를 투기장 배경으로 쓴다. 패배한 적의 준비된 패배 이미지를 결과 화면에 연결한다.

- [x] 현재 WORK와 기존 수동 변경의 해시를 보존하고 표시 경로를 조사한다.
- [x] 실제 엔진 DOM 검사에 폰트·색·링크 수·배경·패배 포즈·프레임 고정 기준을 추가하고 기존 상태의 실패를 확인한다.
- [x] 결과 렌더러와 기존 helper만 최소 수정한다. 새로운 QSP 로케이션이나 영구 인물 상태를 추가하지 않는다. 생사·보상·특수전 제외 범위는 유지한다.
- [x] 기존 검토 이미지 중 패배 포즈 연결에 필요한 준비된 이미지와 첨부 배경만 복사한다. 원본 이미지와 검토 원본을 보존한다. 보류 대상의 새 이미지를 만들거나 대체하지 않는다.
- [x] 선택 콜백·썸업·중복 정산과 표시를 실제 엔진에서 검사하고 공식 문법·패치 재생·실행 검사를 수행한다.
- [x] WORK와 추적 소스만 동기화하고 보고서·변경 명세·복구 자료를 남긴다. 세이브·배포 폴더·Git 커밋·푸시는 건드리지 않는다.
