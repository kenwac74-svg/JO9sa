# 개인실 임신 후속: 격리 실제 엔진 확인

**개인실1~4의 임신 상태 계산·대상 연결은 이번 격리 검사에서 모두 통과했다. 현재 제보의 원인은 미확정이다.** 실제 제보 세이브가 없으므로 수정하지 않았다. 개인실 일반 동침 보너스를 비활성으로 두는 기존 기획도 변경하지 않았다.

검사 QSP는 WORK SHA256 `e620353d0db6374ae293c6919d511966c31e2bb68ebd1763bb5a956bec069ba0`다. 원래 게임 엔진으로5개 격리 사례를 실행했다. 공통 계산의62개 조건검사와4방의 별도 bridge 왕복/행동 번호 연결이 PASS다. 원문 장면을 실행·출력하지 않았으며 발견·진단의 표시 문자열은 QA 문구로 격리했다.

| 확인한 흐름 | 실행 결과 |
|---|---|
| 개인실1027~1030의 원래 상호작용 타입→원래 대상 선택→각 room 배열 | 4방 모두 해당 역할 선택 |
| 원래 공통 상태 함수→`$inseminate` | 대상의 `inseminated`가 정상 범위3~5, 다른 주 노예·조수는 불변 |
| 원래 목록 순회→일일 주기/임신 함수 | room1~4 모두 처리됨 |
| 배란 전날이 아닌 정상값 | 배란까지 값2→1, 비임신 유지 |
| 불임값-1/-3 | 표식은 일일 감소하나 임신은 시작하지 않음 |
| 기존 임신30일, 아직 미발견 | 31일로 진행하고 미발견 유지·아이콘용 라벨은 빈 값 |
| 자연 발견 경계119→120 | 발견값1, 임신 라벨 활성 |
| 원래 방별 병원 진단 조건 | 9일은 미발견,10일은 발견값2 및 진단 선택 상태 활성 |
| 비활성 역할 및 유효 표식0 | 각각 일일 계산 생략·새 임신 없음 |
| 실제 bridge enter→원래 스키마 교환→공통 표식 저장→leave/room_sex |4방 모두 원래 주 노예 복원, 방 인물의 임신31일·표식 보존, 원래1027~1030으로 연결 |

정상값 예시는 성인 `age=2`, 남성 주인공 `hero_choice=13`, 일반 비특수 타입1435, 정상 생식값0, 주기값20·배란까지1로 설정했다. 원래 helper의 `rand(3,5)`와 일일 감소·원래 임신 난수를 그대로 사용했다. 방마다12회 중 임신/비임신은 각각 **7/5,6/6,5/7,5/7**이었다. 이는 정상 범위에서 두 결과가 모두 나온 실행 예시이며 임신율 통계나20~30일의 자연 플레이 재현이 아니다. 성공·실패 횟수를 통과 조건으로 강제하지 않았다.

결정적으로 임신 분기를 확인한 대조군은 원래 코드가 별도 처리하는 **type2572**를 사용했다. 원래 생성 범위의 표식이 일일 감소한 뒤에도 해당 타입의 비교값1보다 커서4방 모두 임신1일이 됐다. 임의로 표식 범위를 초과시키지 않았다. 이 특수 타입의 결과를 일반 타입이 반드시 임신한다는 근거로 사용하지 않는다.

실행은 성공한 관련 상호작용 이후의 비묘사 상태 계산을 좁게 다뤘다. 공통 함수의 무관한 주인공 능력 갱신은 QA 카운터로 격리했고, bridge의 원래 배열 교환은 그대로 실행하되 표시용 텍스트 갱신 세 곳은 QA 카운터로 바꿨다. bridge 왕복 진단은 `$update_slave_features_list`도 빈 코드로 두었으므로 해당 특성 목록 갱신·repair와의 결합은 검사하지 않았다. 병원은 원래 방별 진단 조건과 상태 대입을 그대로 실행하고 문장만 QA로 바꿨다. 수술·출산·신규 관계·보상·밸런스 변경은 없다. 추출한 실제 본문의 위치·행·해시는 `plan.json`에 있다.

실제 제보 캐시나 저장된 동적 함수, GUI 로드·물리 클릭·상호작용 수락/거절·병원 전체 동선·하루 전체 사건을 검증한 것은 아니다. 따라서 “개인실 전부 임신 불가”라는 계산 결함은 이번 검사에서 재현되지 않았지만 사용자의 실제 상태에서 문제가 없다고 단정하지 않는다. 실제 제보 세이브의 역할·생식값·주기·표식·임신/발견값과 저장된 함수 캐시가 다음 확인 대상이다. 주변 원본 코드의 다른 오기는 제보 원인에 연결하지 않았다.

처음 두 진단은 완료 시간초과였으며 검사 실패 메시지는 없었다. 반복 표본을 줄이고 진단 비교식을 QSP 원래 연산자로 맞춘 마지막 실행은5/5 통과했다. 초기 기록을 `initial-native-results.json`, `second-native-results.json`에 보존했으며 이를 게임 결함 증거로 취급하지 않았다.

`native-results.json`과5개 로그가 최종 실행 근거이고, `qa-summary.sav`는 합성 상태·통과 수·방별 관찰 결과를 담은 검사용 SAV다. 실제 플레이 세이브가 아니다. WORK·보호 원본·기존27번 세이브는 전후 SHA256 동일하다. `G:/Codex/tmp/jo9-private-pregnancy-followup-20261028`의 생성 QSP·임시 파일은 정리했다. 최종 SAV와 의미가 같은 중간 체크포인트는 중복 제거했다.
