# 우유 팻말 숫자 가독성 — 2026-10-24

현재 가격 숫자가 흰색이며, 원본 팻말의 왼쪽 '리터당'과 겹쳐 있음을 실제 PNG와 CSS로 확인했다. 앞선 가격 값 출력 검사는 이 가독성을 검증하지 못했다.

WORK와 저장소 base.css의 #milk_sign_writing 한 선택자만 수정했다. 위치 x1005/y486, 상자56×40, 글자36px·줄높이38px·굵게·가운데 정렬·검정색(#000000)이다. 팻말 원본(x930/y400, 200×133)과 오른쪽 패널·보유금·메뉴 배치는 그대로다. 숫자는 '리터당'과 '스파크' 사이 빈칸에 들어간다. 가격 계산·QSP·이미지·세이브는 변경하지 않았다.

입력은 shop_general이 출력하는 milk_sign_writing의 실제 milk_price 숫자이고, 결과는 동일 값의 시각적 위치와 표현 변경뿐이다. 호출·반환·게임 상태 변경은 없다. 새 함수나 세이브 의존성도 없다. CSS 표식 MILK_PRICE_LABEL_20261024와 css-patch.json으로 찾고 복구할 수 있다. 이 선택자만 되돌리면 값은 동일하나 기존 흰색·겹침이 돌아온다.

이전 실제 FastQSP에서 추출한 HTML의 소스 QSP 해시가 현재 WORK와 동일함을 확인했다. 그 HTML의 가격 숫자만1~7로 바꾼 브라우저 표본에서 원본 크기와64% 축소 총14사례를 검사했다. 수정 전14실패 → 수정 후14통과: 검정·굵게, 빈칸 안의 글자 범위, 값 보존, 보유금 원위치를 확인했다. 전후 PNG를 직접 확인했다. CSS 고정 문구 검사와 WORK/원천 동일 바이트도 확인했다. QSP 미수정이므로 실제 엔진 검사를 재실행한 결과로 표현하지 않는다. 게임 GUI 시각 점검 및 다른 모든 축척은 별도다.

WORK와 원천 CSS만 반영했고 Full·배포 ZIP·커밋·푸시는 변경하지 않았다. 작업용 HTML과 브라우저 프로필은 정리하고, 전후 CSS 차이·PNG·배치 결과·재현 스크립트만 보관한다.

초기 진단에서는 글꼴 전체 줄 상자를 글자 획으로 취급해 후보를 실패 판정했다. font-line-box-diagnostic.json에 보존했다. 최종 검사는 실제 글꼴을 먼저 로드하고 Canvas TextMetrics의 실제 숫자 획 범위로 검사하여 14사례를 통과했다. 독립 CSS 차이·PNG 시각 검토도 PASS다.
