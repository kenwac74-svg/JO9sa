# 판매 상한 B안 구현 계획

사용자 선택: 상인·공개경매 최종 지급6000 / 개인 고객8000. 모든 옵션 난도에 같은 상한을 적용하며 난도별 산식·희귀 평가 배수·고정납품·파산 급매는 유지한다.

1. 현재 WORK를 바이트 왕복 검사하고 압축 복구본을 보존한다.
2. 기본 상인 견적·희귀 재제안·경매 최종 낙찰/지급·개인 흥정/정가/할인/지급에서 최종 금액만 제한한다. 공통 base_price, 휴면 판매, 일반 수입·환전·대출·정액 의뢰는 변경하지 않는다.
3. 예전 웡의 초과 견적은 기존 재견적 경로로 안내한다. 개인·경매의 이미 저장된 초과 대사에는 조회 전용 지급 한도 안내만 붙이며 상태/콜백은 재실행하지 않는다.
4. 격리 진단본에서 기존본 RED와 후보 GREEN, 경계/난도/희귀/옛 견적/고정의뢰 보존을 검사하고 공식 구조·개행·마커·패치 재생/재적용·실제 엔진9경로를 확인한다.
5. 통과한 후보만 WORK에 적용하고 릴리즈 노트를 갱신한다. Full·ZIP·개인세이브·커밋·푸시는 변경하지 않는다.

수동 플레이는 사용자 담당이며 이번 검사는 자동 엔진 경로만 실행한다. 진단 사본은 결과 추출 후 링크 대상을 따라가지 않고 정리한다.
