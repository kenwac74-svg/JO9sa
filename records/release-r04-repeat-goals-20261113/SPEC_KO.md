# 반복 구매자 목표 등록 확정 명세

2026-11-13 사용자 승인. 색상 강조 복합요구를 등록하고, 전문 종류/등급만 요구하면 제외한다. 단 대사/지문이 별도 이벤트 분기 또는 특별 보상을 직접 알리면 포함한다. 글로리아 부동산 납품은 간접 이벤트 트리거이므로 제외한다.

이번 확인 대상9개는 모두 실제 조건 대사의 색상 강조 복합요구에 해당한다. 아네스/에르멜린다/노에미/캡/엘리자베스5종. 전문 등급의 단순 색상 유무로 자동 판별하지 않고 확인된 장면 목록만 연결한다. 기존 특별 보상/퀘스트 의뢰는 유지한다.

문의 시 기존 jo9_goal_offer_seen[repeat_고객ID]에 기록한다. 목표 목록/상세에 납품가능 또는 기존 no_slave_count에 따른 재납품 대기일을 표시한다. 옛 저장은 다시 문의하면 등록된다. NPC의 진행·거래조건·보상·대기 계산을 변경하지 않는다. 기존 문의 전역배열을 재사용하므로 새 배열/캐릭터 필드는 없다. 개인SAV/Full/음원/커밋푸시는 변경하지 않는다.
