# 일반 안마 품질을 애무 기술 기준으로 변경 — 2026-11-18

사용자 승인: 신경쇠약·정신분열만 예외로 하고 그 밖의 안마 품질은 애무 기술만 사용한다. 일일 제한·비용은 유지. 수행 불가 상태는 제안만 한다.

## 변경과 사용
노예5412·조수5501이 주인공에게 해주는 일반 안마의 공통 템플릿 한 곳을 수정했다.
정상인물의 품질은 min(5,1+max(0,petting))이다. 애무F/D/C/B/A/S → 품질1/2/3/4/5/5, 기존 회복 기준은3이므로 C 이상이면 당일 첫 회복으로 주인공 행동력+1이다.
기분·온순함·두려움·슬퍼함·우울증·헌신·응석·성실도·피로·생산성 특성이 정상인물의 품질을 낮추거나 높이지 않는다. 기존 명령 수락/거부 판정은 바꾸지 않는다.
화면과 동일하게 ego+temper+pride<3이면 정신분열, 합계3~4면 신경 쇠약이다. 합계5 미만인 이 두 경우만 기존 근면도·생산성 보정 품질 계산을 유지한다. 두 질환을 무조건 행동 불가로 만든 것은 아니다.
성공 수락 시 안마한 인물의 행동력1·칼로리1 소모, 주인공 비용0, 품질3 이상일 때 회복1, 도시와 합산 하루1회, 거부 시 무소모를 그대로 유지했다. 품질 부족/당일 이미 회복인 경우에도 기존 제공자 비용은 유지한다.
조수에게 해주는 관능적 마사지5608은 별도 경로이며 변경하지 않았다. 도시 안마·다른 서비스·전체 성실도 계산도 유지한다.

## 캐시·부작용·제거 영향
입력은 petting,ego,temper,pride와 기존 상호작용/일일flag다. 새 저장값·함수·로케이션은 없다.
마커 MASSAGE_SKILL_QUALITY_20261118가 품질 계산을, 동일 _CACHE 마커가 기존 세이브의 안마 템플릿 재정의를 담당한다. 5412/5501 호출 때만 템플릿을 다시 준비하므로 게임을 완전히 재실행·로드 후 새 안마부터 적용된다. 이미 열린 과거 결과 페이지는 소급 변경하지 않는다.
호출자는 interaction, 결과와 비용은 기존 interaction_result다. 제거하려면 mods의 두 edit를 역순 대조해 되돌리며, 오래된 전체QSP로 덮지 않는다. 품질만 되돌리면 구버전 캐시와의 불일치가 생길 수 있어 두 부분을 같이 관리한다.

## 검증
수정 전 실제 WORK 엔진34상황·168검사 중42실패 → 후보 동일34상황·168검사 모두통과.
애무0~5, 정상 정신상태/두려움/슬퍼함/우울증/온순함, 낮은기분·낮은헌신·높은응석, 정신합계 경계5/4/2, 당일이미회복, 거부, 구형캐시를 노예와 조수 양쪽에서 확인했다.
실제 interaction/interaction_result 본문과 근면도·행동력 helper를 사용했다. UI·텍스트은행·특성무드 callback은 중립 대역이며 개인 SAV GUI와 화면은 미검증이다.
공식 적용기의 변경location 격리입력에서 DryRun/정확재생/재적용건너뜀 PASS. 컨테이너왕복·역적용은 원래바이트와 같고 다른320본문/모든 원래필드는 보존했다. 기존 다른 원고의 줄바꿈은 정규화하지 않았다.

## 추가 예외 제안 — 적용 안 함
- 기절·의식없음·사망: 기존 활동 제한 유지.
- 중상4·치명상5: 추가 수행불가 후보. 일반 상처·멍은 제한하지 않는 편을 권고.
- 가벼운 피로/행동력0·기분저하만으로 새 금지조건을 추가하지 않는다. 음수행동력의 기존 과로비용은 유지한다.

WORK와 추적 QSP·런타임원장·mods만 반영한다. Full·기존4차ZIP·음원·개인세이브·커밋·푸시는 변경하지 않는다.
사용자 EXE 확인: 완전종료·재실행 후 정상정신/애무C이상인 노예 또는 조수에게 하루 첫 안마를 시켜 주인공+1/제공자−1인지 확인한다. 같은날 두번째 회복 없음도 확인한다.
