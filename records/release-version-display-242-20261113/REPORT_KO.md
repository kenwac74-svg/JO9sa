# R10-1 확정 버전 표시2.4.2

사용자가2.4.2 Full을 확정한 범위에서 제목/화면 버전11곳(10본문)을2.4.2로 맞췄다. code_rev 참조4곳을 확인했고2곳은 버전 대입,2곳은 제목 문자열 구성뿐이었다. 게임 판정·캐시 이관·인물·가격·진행은 바꾸지 않았다.

문구 수정 정책에 따라 구조/CRLF/마커·바이트 왕복·정확 공식 재생·재적용 무변경·역적용 복원을 확인했다. 실제 화면 확인과 전체 엔진 출고 검사는 별도이며 이 기록은 실제 엔진 PASS가 아니다. 일반EXE 완전재시작 후 제목과 경매/개인실의2.4.2 표시를 확인한다.

입력은 기존 표시 문자열이고 반환/부작용은 화면과 제목뿐이다. 저장된 버전값도 위치 이동 시 현재 표시로 갱신되지만 호환 여부 판정값으로 사용되지 않는다. 제거할 때는 해당 mod의 문자열 편집만 역검토한다. 수정 직전 복구자료 baseline.qsp.gz와 manifest.before.json.gz를 보존한다.
