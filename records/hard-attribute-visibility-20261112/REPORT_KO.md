# 하드모드 속성 단계 공개 WORK 반영

사용자 지정: 기본6속성은 경매장/획득부터 보이고, 체력·성격·지성은 소유10일, 감수성·태도·자아는20일 후 공개. 전체 공개 마법이 있으면 기간과 무관하게 공개.

## 실행 기준·범위

게임 중 difficulty_setting=2인 하드모드에 적용한다. 캐릭터 생성의 game_difficulty와는 별개다. spell_revelio=1이면 표시 제한을 우선 해제한다. 기존 레벨리오/해당 공개 효과 아이템이 이 플래그를 쓰므로 그대로 호환한다. 마법이 끝나면 다시 현재 보유일수 기준으로 판단하며 영구 공개 이력은 추가하지 않았다. 일반·이지 모드는 이전처럼 보인다.

기존 age_count를 사용한다. next_day의 전체 소유 인물 갱신은 기절/극저온 보관도 포함해 매일1 증가한다. 역할 이동 뒤에도 같은 인물의 소유기간을 사용한다. 새 타임스탬프·마이그레이션 필드·영구 revision 변수는 없다. 구매 전 stock와seed 프리셋 화면은 기존 값이 있더라도 보유일수0으로 취급한다. 다른 표시 역할은 해당 역할의 기존 소유일수를 읽는다. 기존 저장의 기록된 소유일수도 사용한다.

표시 문자열과 툴팁만 바꾼다. 숨겨진 값은 회색 미확인으로 표시하고 실제 수치/색/등급과 툴팁 숫자를 제거한다. 상점/경매, 획득 장면, 인물 정보·교육, 조수 개인실, 감옥·축사·동면관, 초기 선택/검은시장, 파리드 위탁 미리보기를 포함한14본문84출력식을 연결했다. CSS/JS로 가리는 방식이 아니다.

주인공 속성·MOB 전투 수치·치트 편집기·기술·고유 특성·게임 내 대사/행동 결과로 가능한 간접 추론은 이번 숨김 대상이 아니다. 외모·독특함·체형·세련됨·인지도·기분의 기존 출력은 수정하지 않았다. 실제 능력치·훈련/전투/가격 계산과 상태값은 유지한다.

## 코드 사용·의존성·복구

새 jo9_attribute_visibility는 (mode, role, attribute, originalText)을 받는다. visible은 공개 여부 숫자, text는 기존 HTML 또는 회색 미확인, tooltip은 기존 설명 또는 기간 안내를 반환한다. 역할 이름은 호출 코드가 지정한다. 읽는 상태는 difficulty_setting/spell_revelio/해당 인물 age_count뿐이다. 인물 값을 쓰지 않는다. UI 래퍼가 아닌 실제 수치 조회에는 호출하지 않는다.

QSP에서 숫자 result와 문자열 $result를 같은 반환 경로에 함께 쓰면 숫자 결과가 유지되지 않는 현상을 진단에서 확인해 반환 모드를 분리했다. 문자열 모드는 visible 숫자 판정을 읽고 원문 또는 대체 문자열을 반환한다. 최종 후보로 전체 검사를 다시 통과했다.

모드 mods/2026-11-12_zzzzzz_hard_attribute_visibility.json. 14본문과 새 로케이션1개. 표식 HARD_ATTRIBUTE_VISIBILITY_20261112/HARD_ATTRIBUTE_VISIBILITY_HELPER_20261112. 기존 함수 캐시를 가공하는 형태가 아니라 해당 출력식에서 직접 새 함수를 호출한다. 동면관의 dynslave 템플릿은 기존 역할 치환과 함께 처리된다. 함수를 제거할 때14개 호출 본문도 같이 되돌린다. 복구 자료는 baseline.qsp.gz와 모드의 전후본문, manifest 이전 gzip이다. 후속 작업 뒤에는 전체 예전 QSP 덮어쓰기를 피한다.

## 검증과 한계

- 실제 설치 FastQSP 1275단언 통과. 하드모드0/9/10/19/20/35일,7종 역할,마법 유무,일반·이지,항상 보이는6항목,숨겨지는6항목,시장 구매 전 규칙,84개의 실제 교체 출력식을 QSP HTML 보간에 넣은 결과와 툴팁 누출,인물 원값/소유일수 불변을 확인했다.
- 이전에 항상 표시하던 동작을 대조용 함수로 모델링한 기준 fixture는 실패, 실제 추가 함수는 통과. 기준 fixture를 수정 전 전체 게임의 화면 재현으로 보고하지 않는다.
- QSP 구조/CRLF/왕복,공식 적용기 재생·재적용 무변경,역적용 시 기준본 바이트 일치. WORK/추적 QSP/manifest 일치 및 JSON manifest 해시 보존.
- 14개 전체 장면의 실제 GUI 렌더·개인 SAV UI 로드는 하지 않았다. 실제 교체식/조건 검증이며 게임 전체 출고 인증이 아니다. 기존 소유일수 기록 자체의 신뢰성과 행동으로부터의 간접 추론은 별도다.
