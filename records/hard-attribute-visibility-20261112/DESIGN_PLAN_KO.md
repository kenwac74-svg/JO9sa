# 하드모드 속성 단계 공개

사용자 기준: 외모/독특함/체형/세련됨/인지도/기분은 획득 전 경매장부터 공개. 체력/성격/지성은 획득10일, 감수성/태도/자아는20일 후 공개. 전체 공개 마법 효과가 있으면 전부 공개.

기존 게임 중 난이도 difficulty_setting=2, 공개 효과 spell_revelio=1, 소유일수 age_count를 재사용한다. 새 영구 변수/타임스탬프/마이그레이션 필드는 없다. stock와seed 구매 전 화면은 소유기간0으로 취급하고 다른 인물 역할은 기존 소유일수로 판단한다. 기존 세이브도 기록된 소유기간을 사용하며 새 카운트를 시작하지 않는다.

실제 값·훈련/전투/가격 계산은 건드리지 않고 출력 HTML과 툴팁만 미확인으로 교체한다. 숨겨진 수치의 색/등급/숫자가 툴팁에 남지 않게 한다. 치트 편집기·주인공 능력·MOB 수치·고유 특성·기술·행동 결과나 간접 추론은 이번 범위가 아니다.

1. 기존 출력84곳과 연결 툴팁에 공통 출력 함수를 적용.
2. 실제 엔진에서10/20일 경계·마법 우선·일반/이지·시장 및 각 출력 식을 검증.
3. 공식 재생/재적용/역검증 후 WORK·추적 QSP·manifest 적용.
4. 기존 화면 GUI와 전체 출고 검사는 별도 표시.
