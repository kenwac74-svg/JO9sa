# MOB 세트 목록 및 연결

사용자 승인 범위: 이미지 패치리스트에 전투 MOB의 초상/전신/패배를 묶고 부족분 확인 및 직접 교체 지원. WORK만 갱신, 배포/세이브/커밋/푸시 제외.

1. 현재 QSP의 적 정의와 패배 sprite 매핑에서 목록 추출. 경주 전용은 적 정의에 없는 항목으로 별도 표기. 미확인 경로는 미확인으로 남김.
2. 현재 연결되지 않은 적은 defeated/동일파일명.png로 연결. 파일 누락 시 원래 전신을 보이는 HTML fallback 유지. 공유 탈옥수는 기존 개별 예외 보존.
3. 기존 catalog HTML에 MOB 세트 패널 삽입. 현행 인증 PIC API로 선택 PNG를 미리보기 후 명시적으로 반영. 크기 규약/변경 전 해시/백업/패치 원장 재사용. 임의 이미지 생성/교체 없음.
4. 모든 대상 경로, 누락/공유/연결 상태, QSP 변경 범위 검사. 격리 네이티브 sprite 테스트 및 공식 출고 검사 후 적용.
5. 보고서/원장/재생 스크립트 보존. 재생성 가능한 진단 사본 정리.
