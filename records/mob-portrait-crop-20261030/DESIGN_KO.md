# MOB 포트레이트 얼굴 선택·자동 프레임

요청: MOB 세트의 포트레이트 교체 시 전체 이미지를 축소하는 대신 사용자가 얼굴 영역을 고르고, 배정된 바깥 프레임을 자동 적용한다.

기존 PNG 교체 → PNG 선택 → 정사각형 얼굴 영역 이동·모서리 조절·크기 슬라이더 → 프레임이 적용된 실제 150×150 미리보기 → WORK에 반영/취소 흐름으로 구현한다. 시작 위치는 상단 중앙 추천 범위이며 얼굴 인식 결과라고 표시하지 않는다. 선택한 원본의 배경·투명도와 얼굴 그림을 유지한다.

구현 선택: 현재 포트레이트를 잘라 프레임으로 재사용할 수도 있지만 원본 누락·기존 잘못된 프레임에 취약하다. 이미 추출·검증된 원본 프레임 5종을 재사용한다. 기존 frameClass로 기본/언데드/중고위급/콜로세움/경주를 결정한다. 별도 서버 API나 이미지 생성·배경 색 추출은 추가하지 않는다. 분류와 QSP는 그대로다.

프레임 데이터는 얼굴을 포함하지 않는 투명 PNG 오버레이이다. 얼굴을 프레임 구멍 크기로 고품질 축소한 뒤 프레임 외곽 픽셀을 원본 RGBA로 복원해 경계에 이전 얼굴이 섞이거나 프레임 픽셀이 변하지 않게 한다.

기존 PIC apply API의 현재 해시 확인·원본 백업·패치 원장·카탈로그 갱신을 사용한다. 편집 중 취소/ESC에는 저장 요청을 하지 않는다. 기존 전투 전신/패배/단체 컷의 795×596 교체는 유지한다. 실제 게임 PNG 교체는 사용자가 마지막 반영 버튼을 눌렀을 때만 수행한다.

검증: 격리 브라우저 실제 파일 선택·드래그·슬라이더·취소·최종 저장, 5종 외곽 픽셀 동일성, 투명 이미지에서 옛 얼굴 미노출, 없는 초상 추가, 동시에 바뀐 원본 거부, 기존 원본 백업·원장 기록을 확인한다. 운영 도구 설치는 카탈로그 UI와 소스만이며 게임 이미지·QSP·세이브·배포/ZIP·커밋·푸시는 변경하지 않는다.
