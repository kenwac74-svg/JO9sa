# R03-10 키키모라 young형 전용 납품

2026-11-13 사용자 승인대로 WORK·추적QSP·runtime 원장에 반영했다. 키키모라의 납품 검사만 young형(분류값0)을 수락한다. 다른 고객의 분류 조건과 no_loli 대체 규칙은 유지한다.

## 변경

공용 agree_age는0을 미지정으로 취급하므로 키키모라의0 지정이 실행되지 않았다. 공용 규약을 바꾸지 않고 slave_sell_chek의 키키모라 전용 gate를 추가했다. young형이 아니면 기존 분류 거절코드 sl_txt=100을 사용한다. NPC ID의 대소문자 차이도 처리한다.

다른 고객의 요구/선호 콜백, 키키모라의 기존 최저능력/기술·외모/상태 조건,가격·평가·진행·완료거래·소유인물은 변경하지 않았다. 새 저장값·캐시·로케이션은0이다. 반말 수치/자동 전환 코드는 추가하지 않았다.
