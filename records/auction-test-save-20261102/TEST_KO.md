# 공개경매 난이도 비교 세이브

파일: TC_08_AUCTION_DIFFICULTY.sav

WORK의 일반 exe에서 이 파일을 불러온다. 보통 설정, 시작 소지금 $1,000, 길드 화면, 낙인 보유 S+ 성인 에게야가 준비되어 있다. 경매 계산표나 입찰자 예산은 바꾸지 않았다.

1. 길드의 낙인 노예 경매 → 확인 → 경매를 끝까지 넘긴다. 보통은 $28,850 지급, 잔액 $29,850을 확인한다.
2. 같은 파일을 다시 불러온다. 게임 설정에서 쉬움으로 바꾸고 길드의 같은 경매를 진행한다. 잔액 $29,850과 세금 문구가 없는지 확인한다.
3. 같은 파일을 다시 불러와 게임 설정에서 하드코어로 바꾸고 진행한다. 낙찰가 $28,850은 유지되며 마지막 경매 메시지에 세금징수원 문구가 한 번 나오고 잔액은 $7,000이어야 한다.

같은 날짜에서 비교해야 한다. 중간에 날짜를 넘기거나 인물·복장·능력치를 바꾸면 낙찰가가 달라질 수 있다. 세이브는 미정산 경매 직전이며 이전 판매를 재지급하지 않는다.

저장 형식 왕복과 현재 WORK의 체크섬 일치, 실제 엔진의 동일 표본 경매 3개 난이도 정산을 확인했다. 실제 GUI 불러오기 클릭은 사용자가 확인한다. 게임 본체·기존 세이브·배포본은 바꾸지 않았다.
