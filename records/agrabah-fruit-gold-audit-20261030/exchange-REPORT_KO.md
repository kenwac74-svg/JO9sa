# 아그라바 환전·보수·금화 초기화 정적 조사

2026-10-30 현재 WORK QSP 2b81e781d0ab56f10cb77aa340db27ee4dab7d707bafe857853ad600d474417e를 원본 JO9O QSP 26e15aaf30b6226a2883c6b532a6ee4eed34791110618597d234bb7d6fa3e052와 메모리에서 비교했다. WORK·QSP·세이브는 변경하지 않았다. 실제 제보 세이브나 현재 엔진 실행으로 재현한 결과가 아니라 정적 코드 조사다.

## 확정한 흐름

- 아그라바 통화는 숫자 변수 gold, 일반 통화는 sparks다. 환전·보수·과일 지불이 gold 하나를 공통 사용한다. 서로 다른 gold 변수/철자 때문에 적립과 구매가 분리된 흔적은 찾지 못했다.
- interaction_city 302110:26827~26828은 sparks100을 차감하고 gold10을 적립한다. 302111:26840~26841은250→25, 302112:26853~26854은500→50, 302113:26866~26867은1000→100이다. 환율은 스파크10:금화1이다.
- 역환전302114:26879~26880은 sparks += gold*10 후 gold=0이다. 금화를 직접0으로 만드는 다른 대입이나 gold를 지정한 killvar는 현재 코드에서 찾지 못했다. 전체 변수 삭제 killall은 새 게임 초기화 Start:6, start_refresh:8에 있다.
- 쟈스민 첫 보수302141:26942는 gold +=85이다. 반복302142:27027~27029는 분기별45~60 또는35~44를 a에 정하고 gold +=a 한다.
- gold 대입/가감65개의 순서와 귀속 interaction_city ID 및 계산식은 원본과 완전히 같다. 이름 표기 수정이나 후속 모드 때문에 금화 계산이 달라졌다는 근거는 없다.
- #event_base의 $event['Akabur_quest'] 값도 현재/원본이 동일한 러시아어 HTML 문자열이다. 이 문자열이 active 배열의 키로 사용되는데, 이번 비교에서는 번역으로 키가 바뀐 흔적이 없다.

## 과일 구매와 분리해야 할 조건

현재 #options:7088~7091은 금액만 확인하지 않는다. Akabur_quest 진행값11, 해당 과일 상자 미보유, 금액 조건을 함께 요구한다. 작은 과일은 금25 또는 sparks250, 연회용은 금1000 또는 sparks10000이다. 이미 갖고 있거나 해당 준비 단계가 아니면 금이 있어도 살 수 없다.

실제 지불30212:26892~26897은 gold25 이상이면25를 차감하고 그렇지 않으면 sparks250를 차감한 뒤 fruits_minibox=1이다. 30213:26910~26915는 gold1000 또는 sparks10000으로 같은 방식이다. 이 계산도 원본과 같다.

환전 메뉴의 스파크1000은 금100이다. 연회용 과일의1000을 스파크1000과 같은 단위로 읽으면 충분히 환전했다고 생각해도 실제 가격에는 모자란다. 이는 가능한 오해 경로이며 제보 원인으로 확정한 것은 아니다. 퀘스트 단계·보유 플래그 조건도 가능성을 구분해야 한다.

## 검증 한계

현재 읽은 QSP와 원본의 해시는 조사 전후 동일하다. 제보 SAV 자체가 없으므로 특정 세이브의 현재 gold 값이나 퀘스트 값, 클릭 실패를 부정하지 않는다. root 담당자가 현재 엔진에서 환전→구매 및 로드 전후를 별도 재현해야 한다. 10/26 과거 보고서는 환전과 금화 보수·독립 진단 SAV의 GUI 재로드가 정상으로 기록돼 있으나, 과거 검증을 현재 과일 구매의 실행 확인으로 대신하지 않는다.
