# 게임 UI 크기 각본 미리보기

사용자 요청: 현재 텍스트 영역 표시를 실제 게임 UI 이미지와 같은 크기로 보여 분량을 판단한다.

현재 WORK config.xml의 1280×800, _layout의 grimdark/bg.png, base.css의 #text(740×185, 18px/130%, 경기천년제목 Medium)를 직접 읽는다. 기본 미리보기는 축소하지 않는 실제 UI 캔버스와 대사창이다. #bg_blue_script의 종이 전체 표시도 선택할 수 있고 기존 사용자 크기 모드는 유지한다. 게임 글꼴 파일을 먼저 로드한 뒤 측정한다. 수정 원고·제외 선택·승인 검토 절차는 유지하며 게임 QSP·CSS·이미지·글꼴 원본은 수정하지 않는다.

- [x] 프로필 읽기와 글꼴 경로 제한을 실패 시험으로 재현하고 구현한다.
- [x] 미리보기의 실제 크기·위치·줄간격·UI 배경을 구현한다. 보이지 않는 미리보기는 계산하지 않고 현재 탭이 열리면 측정한다.
- [x] 기존 직접 편집·재검토·각본 출력 검사를 함께 확인한다.
- [x] WORK에 설치하고 사용자 입력 보존, 글꼴 로드, 1280×800/740×185 DOM 실측, 긴 시험 대사 넘침을 브라우저에서 확인한다.
- [x] 복구·검증 기록을 보존하고 재생성 가능한 시험 자료는 정리한다.

선택한 장면 상태·이름 치환·QtWebKit의 최종 렌더링을 실행하지 않는 도구다. 실제 게임과 다른 변수가 있으면 그 한계를 표시한다. 커밋·푸시·Full·음원 변경은 포함하지 않는다.
