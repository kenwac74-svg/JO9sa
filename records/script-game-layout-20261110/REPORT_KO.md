# 게임 UI 실제 크기 각본 미리보기

사용자 요청: ‘텍스트 영역 내 표시’를 실제 게임 UI 이미지와 같은 크기로 보여 분량을 확실하게 판단한다.

## 구현과 사용

기본 미리보기는 WORK config.xml의 1280×800 캔버스다. _layout의 현재 UI 스타일 2가 지정한 grimdark/bg.png를 그대로 표시한다. base.css의 일반 #text는 x30/y615 + 위 여백6, 740×185, 18px/130%, 경기천년제목 Medium이다. 실제 게임 글꼴 파일을 로드한 뒤 측정한다. #bg_blue_script의 종이 전체 대사 770×575도 선택할 수 있다. 기존 사용자 크기 입력은 별도 모드로 보존했다. 좁은 창에서는 축소하지 않고 가로 이동한다.

대사창은 원래 좌표 y621에 185px 높이이므로 800px 캔버스 안에 보이는 높이는 179px다. 넘침 비교는 실제 본문 높이와 이 가시 높이를 비교한다. 대사창에 임의 20px 패딩을 더하지 않는다. 그림 영역은 795×595 자리로 표시하며 해당 장면 상태나 세이브를 실행하지 않는다. 변수는 표기 상태이고 이미지 자리표시는 [그림]으로 남는다. 허용된 글자 강조·색·줄바꿈은 표시하되 원문의 스크립트·실행 링크를 실행하지 않는다. QtWebKit의 최종 줄바꿈·실제 이름 치환·특수 장면 전용 레이아웃은 실제 게임 확인 대상이다.

화면 종류 선택 → 수정문 재검토 → UI 크기와 넘침 확인 → 확인 체크 → 각본 반영 순서다. 화면 종류를 바꾸어도 원고와 제외 선택은 유지한다. 현재 사용자 수정문 4개는 이 기준에서 모두 영역 안에 표시되었다. 실제 각본 반영은 수행하지 않았다.

## 입출력·연결·제거 영향

- script-game-layout.cjs load(game,doc,token): 현재 게임 설정/CSS/글꼴과 UI 파일 존재를 읽어 canvas/profiles/자원 URL을 반환한다. UTF-8/UTF-16 LE BOM을 지원하며 누락 정보를 정상 크기로 추정하지 않는다. fontFile은 두 프로필에 속한 설치 글꼴만 허용하고 경로 이탈을 거부한다.
- server.cjs: 기존 /api/script/preview에 gameLayout과 실제 게임 문자열 previewText를 추가한다. 인증된 /api/script-layout-font에서 게임 글꼴을 읽기만 한다. 레이아웃 정보를 못 읽으면 layoutError를 보내며 사용자 크기 참고 화면임을 표시한다.
- script-review.js: loadGameFonts를 기다린 후 실제 크기 DOM을 그리고 본문을 측정한다. UI 원본 파일은 복사·편집하지 않는다. 원문 태그는 허용된 글자 표시만 새 DOM으로 구성한다.
- script-import-ui.js/index.html/workshop.css: 실제 마크업으로 화면 모드와 게임 캔버스를 추가했다. 기존 비교/직접 편집/제외/재검토/반영 절차를 유지한다. 관련 UI와 backend 파일을 함께 설치한다.
- Start-JO9-Tools.ps1: 기존 설치 선택이 CSS를 제외하던 문제를 고쳐 .css도 배포한다. 설정/초안/키/기록은 기존처럼 제외한다.

새 라이브러리나 게임 변수·세이브 형식을 추가하지 않았다. 이 모듈만 제거하면 실제 UI 정보/글꼴을 불러오지 못하므로 before의 관련 파일을 함께 대조한다. 게임 QSP·CSS·이미지·글꼴·Full·음원은 변경하지 않았다. 커밋·푸시·배포도 하지 않았다.

## 검증과 한계

관련 Node 검사 31개 통과. WORK 설정/CSS 읽기, UTF-16 설치본, 글꼴 경로 제한, 픽셀 넘침, 기존 각본 입력·검토·저장·편집·공유 흐름 포함이다. CSS 배포 선택 검사는 이전 실행기에서 실패하고 수정 뒤 통과했다. 실제 실행기도 WORK 서버 소유 확인 후 정상 재시작했다.

별도 기존 tools/local-workspace/launcher.test.ps1은 수정 전·후 모두 격리 모의 PID/포트 검사에서 ‘The editor port does not belong to the recorded process.’로 실패했다. 이 전체 실행기 검사를 통과로 보고하지 않는다. 실제 서버 시작과 새 CSS 선택만 별도로 검증했다.

브라우저에서 1280×800 캔버스/740×185 대사창/x30 y621, 실제 1280×800 배경 이미지·게임 글꼴 로드, 사용자 원고·ID·검색어 보존을 확인했다. 중립 시험에서 짧은 대사 70px/179px는 정상, 긴 대사 1428px/179px는 넘침 경고, 종이 전체는 770×575/x30 y26을 확인했다. 브라우저 예시는 사용자 원고를 바꾸지 않은 별도 읽기 전용 페이지다.

browser-fixture.cjs는 원본을 읽어 중립 시험 페이지를 잠시 여는 재현 코드다. verify-css-deployment.ps1은 실제 실행기 함수만 읽어 임시 폴더에서 CSS 선택을 검사한다. before는 변경 전 코드이고 regression.log/browser-verification.json/verification.json에 결과를 남긴다. 임시 시험 서버와 재생성 가능한 임시 폴더는 종료·정리했다.
