# R03-1 아르테미아 최저 외모5

2026-11-13 사용자가 외모5이상으로 수정하도록 승인했다. 기존 잘못된 비교식 demand['min_beauty'] > 4를 해당 고객에 한해 =5로 바꾸고, $ongload에서 알려진 옛 요구 콜백의 그 구문만 갱신한다. 다른 조건·NPC·가격·프리셋·거래 완료·개인SAV·진행은 수정하지 않는다.
