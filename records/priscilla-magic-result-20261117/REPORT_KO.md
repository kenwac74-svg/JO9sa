## 확인 범위

기존 상태에서는 설명문·겹침 효과·집 복귀 3조건이 실패함을 확인했다. 후보에서는 실제 QSP WASM의 학습 helper, 도시 결과 렌더러, 화살표 오브젝트 처리와 집 복귀 분기 6조건이 통과했다. 이미지 숨김/인접 보상에서 효과 없음, 습득 시 비용·즉시 위치 변경 없음, 다음 뒤 집 상태·기본 메뉴와 비용 불변을 포함한다. 집 메뉴 본문·귀가 이벤트·레이아웃은 격리 대체했으며 네이티브 게임의 최종 겹침 외형은 사용자 확인 대상이다.

수정 위치만 마커·CRLF·직렬화 왕복·역변경과 공식 최소 mod dry-run을 확인했다. 다른 위치/필드 및 새 보상 원고 불변, 기존 PNG 경로/795×596도 확인했다. 전체 배포 검사나 기존 주문 191확인은 반복하지 않았다.

게임DB는 해당 마법 한 행의 현재 코드/출처 해시만 갱신했다. 다른 DB 행은 보존했다. Full·배포ZIP·커밋푸시는 변경하지 않았다.

## 사용과 재현

게임을 재실행해 마법 선택 → 습득 설명·효과 → 다음 뒤 집 복귀를 확인한다. 편집기는 `interaction_city`에서 `Duplicato Essentia`를 검색하면 이 결과의 한 페이지가 나온다. 세부 원고는 이 문자열을 편집하면 된다. 겹침 효과는 게임 렌더러에서 추가하므로 편집기의 일반 이미지 칸은 기본 프리실라 그림만 표시할 수 있다.

`prepare.cjs`/`verify.cjs`/`install.cjs`는 해시를 검사하는 재현 자료다. 기록의 `mod/patch.json`은 당시 WORK 기준 최소 변경, `source-patch.json`과 `mods/2026-11-17_priscilla_magic_result.json`은 사용자 수동 변경까지 보존한 추적 소스 기준 최소 변경이다. 복구할 때 이후 사용자 원고가 있는 전체 QSP를 과거 파일로 덮어쓰지 말고 각 범위의 역변경을 검토한다. 화면 효과만 제거할 때는 `PRISCILLA_MAGIC_OVERLAY_20261117` 블록을 제거하면 되고, 습득 설명·복귀·마법 자체와는 독립적이다.
