# 아그라바 특수 식재료 — 확정 범위

- 표시명: 신선한 과일 / 아그라바 와인.
- 작은 과일 바구니와 와인병만 상시 반복 구매. 기존 가격·결제 통화 유지. 연회용 묶음은 기존 퀘스트 조건과 일회 구매 기록 유지.
- 작은 상품 구매 1회에 독립 특수 재고 1 증가. 기존 Fruits_minibox/vine_butle 구매 기록은 그대로 1로 유지하며 퀘스트 단계는 바꾸지 않는다.
- 식품 저장고의 일반 재료 아래 한 줄 띄워 두 수량을 표시. 일반 식량·창고 용량·식사·열량·양조·능력치 효과에는 연결하지 않는다. 주방이 없어도 보유한 특수 재고는 표시한다.
- 기존 세이브의 과거 구매 플래그는 유지한다. 과거 플래그는 수량·사용 여부를 기록하지 않으므로 임의 수량으로 이관하지 않는다. 새 보관 수량은 기본 0에서 이번 기능 적용 후 구매로 증가한다.
- 기존 보조 툴팁 아이콘을 재사용한다. 상품 설명은 짧게, 비활성 연회 주문은 의뢰 필요/이미 주문/자금 부족을 구분한다. 일반 와인의 희소성을 주장하지 않고 아그라바산 특제 상품으로 설명한다.
- 바뀌는 런타임 범위: #options 동적 메뉴 2개, interaction_city 작은 구매 2개, master_stat 재고 2행. 재고 칸이 프레임 안에 들어오도록 이 칸에만 CSS 높이 적용. 새 함수·로케이션 없음. 새 지속 값은 조합 배열의 재고 2개뿐.
- 수동 저장·배포 폴더 보존. QSP mods·원본 백업·실제 엔진 검사·UI 툴팁/범위 검사 후 WORK 반영. 커밋·푸시·ZIP 제작 없음.
