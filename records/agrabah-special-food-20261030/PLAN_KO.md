# 아그라바 특수 식재료 구현 계획

기준: DESIGN_KO.md의 사용자 확정 범위. QSP 직접 수정은 mods JSON으로 기록하며 WORK와 추적 소스만 반영한다.

1. 원본 QSP·CSS·대표 세이브 해시를 고정한다. 기존 엔진에서 상시 구매/재고/툴팁 검사가 실패하는지 확인한다.
2. #options의 두 상점 동적 메뉴에 기존 goto·location_gray_tooltip을 적용한다. 소형만 상시 판매하고 연회용은 기존 주문 조건을 유지한다.
3. interaction_city의 작은 구매 두 곳에서 기존 결제와 플래그를 유지하고, 자금 부족 재호출을 막으며 특수 재고를 하나씩 더한다. 구매 대사는 짧은 상품 안내로 맞춘다.
4. master_stat에 독립 재고 2행과 한 줄 간격을 추가한다. 해당 칸만 CSS 높이를 늘린다. 일반 식사·용량·양조 코드는 바꾸지 않는다.
5. 실제 엔진의 메뉴/거래/기존 세이브 상태/저장고 검사, 브라우저 툴팁·글자 범위 검사, 독립 변경 검토와 출고 검사 후 WORK에 적용한다.
6. 보고서와 재현 스크립트·유일한 복구 자료를 남기고 중간 진단 파일을 정리한다. 배포·ZIP·커밋·푸시는 하지 않는다.
