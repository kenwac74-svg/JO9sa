실행
이 폴더의 ‘게임 실행.cmd’를 실행하세요. 동봉된 게임 엔진을 올바른 작업 폴더에서 시작하는 파일이며, 설치·패치·백업 작업은 하지 않습니다.
기존 ‘Jack-o-nine-tails.exe’도 원형 그대로 보존했습니다. 이 실행기는 시작 작업 폴더의 영향을 받으므로, 바로가기나 다른 프로그램에서 실행할 때도 ‘게임 실행.cmd’를 권장합니다.
Windows용입니다. 전체 폴더 구조를 유지하세요. 모드툴 서버나 제작자의 외부 리소스 폴더를 연결할 필요가 없습니다.

구성
현재 WORK에 등록된 원본·개인 제작·올걸·인디·추가 이미지팩과 게임 코드, 인물 JSON, UI, 효과, 글꼴, 소리를 통합했습니다. 구 이미지팩이나 구 QSP 패치를 이 폴더에 다시 덮어씌우지 마세요.
작업 원화, 모딩 도구와 개인 설정, 백업, 진단 사본, 개인 세이브는 배포 구성에서 제외합니다.

저장과 점검
기존 개인 SAV는 따로 보관한 뒤 game/save에 복사해 사용하세요. 원래 저장 파일을 덮어쓰지 말고 새 슬롯에 저장하는 것을 권장합니다.
동봉된 TC_로 시작하는 일곱 세이브는 PLAYTEST_KO.md의 점검 전용입니다. 새 게임 시작용 세이브가 아닙니다. 기존 저장의 모든 진행 상황과 화면 복원이 검증됐다는 뜻은 아닙니다.
이 폴더는 ZIP 압축 전 수동 점검용입니다. 자동 검사 결과와 남은 확인 범위는 VALIDATION_KO.md를 참고하세요.
