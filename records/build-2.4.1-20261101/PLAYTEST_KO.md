# 짧은 수동 플레이 점검

아래는 사용자가 직접 확인할 항목입니다. 자동 검사의 완료 목록이 아닙니다. 각 항목은 세이브를 새로 불러와 시작하고, 두 선택지를 비교할 때는 같은 세이브를 다시 불러오세요. 결과를 기록할 때 파일명·누른 메뉴·보이는 증상을 함께 알려주세요.

1. **단독 실행:** ‘게임 실행.cmd’로 시작해 창 제목의 2.4.1 표기와 제작진 감사 목록의 세 항목을 확인하고, 새 게임의 첫 화면과 저장·불러오기 메뉴가 열리는지 확인합니다. 폴더를 옮겨 확인할 때도 전체 폴더를 함께 옮깁니다.
2. **집·특성·복장 — TC_01_HOME_TRAITS.sav:** 노예·조수의 정보와 특성 전체보기를 열고 항목을 누릅니다. 중앙 목록과 하단 설명, 닫기, 원래 인물 복귀 및 역할별 복장이 올바른지 봅니다.
3. **캣파이트 소개·전투 UI — TC_02_CATFIGHT_INTRO.sav:** 참가 후 현재 노예의 이름이 소개되는지 확인합니다. 전투의 좌하단 행동, 우하단 무기 기술, 타격 효과와 기록이 프레임 밖으로 벗어나거나 사라지지 않는지 봅니다.
4. **캣파이트 승리 — TC_03_CATFIGHT_VICTORY.sav:** 두 결과 선택을 각각 확인합니다. 선택에 맞는 컷신과 같은 페이지의 상금 $100 안내, 실제 잔액 증가, 클럽 복귀를 확인합니다. 한 결과를 여러 번 넘겨 보상이나 승수가 다시 증가하지 않는지도 봅니다.
5. **금화·특수 식재료 — TC_04_AGRABAH_FRUIT.sav:** 환전 전후 보유 금화를 비교하고 소형 과일·와인을 구매합니다. 구매 툴팁, 결제 통화, 식품 저장고의 ‘신선한 과일’·‘아그라바 와인’ 수량을 확인합니다. 연회용 묶음에는 별도 조건이 남아 있습니다.
6. **파산 위기 — TC_05_BANKRUPTCY_CHAIN.sav:** 제시된 자산 정리 단계를 진행합니다. 같은 처분을 반복해도 수입이 중복되지 않고, 이주 뒤 주거·시설·보관 인물 상태가 안내와 맞는지 봅니다. ‘직접 방법을 찾는다’로 나갔다가 돌아와도 미해결 청구가 사라지면 안 됩니다.
7. **안개 단체전 — TC_06_FOG_GROUP.sav:** 전투 전후를 진행해 적이 보이고 승리 뒤 단체 패배 그림이 한 장만 나오는지 봅니다. 개별 패배 그림이 겹치거나 바뀐 UI 프레임이 잠깐 나타나지 않는지 확인합니다.
8. **에게야 이벤트 — TC_07_EGEYA_EVENT.sav:** 결투 수락 안내, 전투 전신, 글라디우스에 맞는 메시지와 전투 종료 후 복귀를 확인합니다. 별도 장면이 없는 상태에서 빈 화면으로 진행이 멈추면 안 됩니다.

이 일곱 세이브는 이전에 공개 점검용으로 생성한 합성 상태입니다. 모든 개인 세이브·퀘스트·무작위 결과의 호환성을 대표하지 않습니다. 워크숍·Show HTML, 마법낙인 제보의 재현, 포커스 변화에 따른 잔상은 이번 표의 통과 대상으로 계산하지 않습니다.
