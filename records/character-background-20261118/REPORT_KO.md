# 캐릭터 세계·출신·직업 분류의 게임 연결 — 2026-11-18

사용자 확정: 세 항목은 설명문의 내용과 별개인 캐릭터 분류값이며 게임에서도 사용할 수 있어야 한다.

## 사용

통합 캐릭터 편집기에서 인물 → **배경·설정 → 노예용 설정 → 배경 분류**를 연다. 세계·출신·직업의 소분류를 고르면 게임 캐릭터 JSON과 대사집에 함께 저장한다. 분류 저장은 기존 능력치·특성·배경 설명문·육성 기록을 재추첨하지 않는다. 상단의 미저장 능력치·원고 변경도 유지한다.

예전에 대사집에만 저장한 선택은 **게임 분류로 적용**으로 옮긴다. 읽기만으로 과거 선택을 바꾸지 않는다. 대분류만 선택한 경우 시뮬레이터의 무작위 그룹 설정은 유지하지만, 게임의 구체적인 분류는 미지정이다. `비우기`는 해당 분류를 명시적으로 해제한다. 마스터 편집에서는 노예 전환용 분류로 보관하며 마스터 시작 수치를 변경하지 않는다.

## 저장과 게임 변수

- `seed_world`, `seed_family`, `seed_occupation`: 기존 배경 DB의 분류 ID 문자열. 표기와 철자를 정규화하지 않는다.
- `seed_background_fixed=1`: 직접 지정한 분류다. 세 문자열이 모두 비어 있어도 명시적 해제이므로 적용한다.
- 게임 인물에는 기존 `$slave_world`, `$slave_family`, `$slave_occupation` 등 동일한 역할별 문자열을 사용한다. 예를 들어 `$slave_family='princess'`처럼 조건에서 사용할 수 있다.
- 설명문은 별도 `seed_*_description` 세 항목이다. 설명문만 바꾸어도 분류를 추론하거나 재생성하지 않는다.
- `world_index`, `nation_index`, `family_index`, `work_index`는 기존의 광역 문명·계층 값이다. 이 작업에서 다시 산정하지 않는다. 유니크의 분류 지정만으로 일반 무작위 생성 전용 성장·직업 특성 보정을 활성화하지 않는다.

게임에서는 생성기의 마지막에 분류 문자열만 연결한다. 이미 소유한 인물은 화면 전환 콜백 `$newloc`에서 현재 등록된 JSON 분류로 갱신한다. 노예·조수·감옥·개인실·외양간·냉동 보관·매물·개인실 임시 보관을 포함한다. 실행 중인 게임의 JSON 캐시는 즉시 바뀌지 않으므로 편집 후에는 게임을 완전히 재실행하고 세이브를 불러온 뒤 화면을 전환한다. 사용자 세이브 파일을 직접 수정하지 않는다.

## 구현과 제거 영향

`background_metadata.py`는 분류 검증 및 캐릭터 JSON/대사집의 원자적 저장, `overrides/background-metadata.mjs`는 선택 우선순위와 저장 순서를 담당한다. 분류 ID 목록은 `data/background-classifications.json`에 둔다. `server.py`가 기존 API와 연결하고, 대사집도 수정 버전에 포함하여 오래된 탭의 덮어쓰기를 막는다. `master_editor.py`의 복제에서 네 키를 배경 항목으로 취급한다. Python·PowerShell 실행기의 지문 목록은 동일한 53개 파일이다.

QSP는 `generate_stock` 마지막과 `$newloc`에 짧은 호출을 추가하고 `jo9_character_background` 한 로케이션을 추가한다. 기존 동적 캐시를 교체하거나 인물 전체를 다시 생성하지 않는다. 제거하려면 두 호출과 새 로케이션을 함께 제거한다. 그러면 이미 저장된 분류 문자열은 남지만 JSON 수정의 자동 연결은 끝난다. 편집기의 분류 저장 모듈을 제거할 때도 서버·화면·버전 목록을 함께 되돌려야 한다.

## 확인 범위

편집기 관련 Python 11개·JavaScript 5개, 기존 마스터 편집 회귀 11개를 통과했다. 분류만 저장할 때 기존 원고·수치 보존, 부분 지정·전체 해제, 수정 충돌, 빠른 연속 선택, 복제를 포함한다. 게임의 실제 설치 엔진에서는 변경 전 전달 누락을 재현한 뒤 수정 후보의 31개 역할에 대해 71개 검사를 통과했다. 이 검사는 실제 수정된 생성 마지막/화면 전환 호출과 합성 등록값을 사용한다. 실제 사용자 세이브 선택 UI와 전체 영입 파이프라인을 플레이한 결과는 아니다.

수정한 원본 로케이션은 두 개이며 나머지 317개 본문과 모든 기존 설명·기본 행동은 그대로다. 역적용하면 작업 직전 바이트로 복원된다. 기존 패치 적용기는 수정 대상만 담은 격리 QSP에서 정확 재생·멱등성을 확인했다. 원본의 다른 수동 원고에 있던 줄바꿈은 보존했으며 이 작업에서 전체 출고 검사를 통과했다고 표시하지 않는다.

WORK와 추적 런타임 소스만 맞춘다. Full·기존 패치 ZIP·음원·사용자 세이브와 모든 캐릭터의 분류 선택은 일괄 변경하지 않는다. 커밋·푸시는 하지 않는다.
