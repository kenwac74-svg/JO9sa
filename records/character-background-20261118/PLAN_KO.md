# 캐릭터 배경 분류 게임 연결

사용자 확정: 세계·출신·직업은 배경 설명문의 내용과 별개인 캐릭터 분류값이며 게임에서도 사용할 수 있어야 한다.

## 설계

기존 `world`·`family`·`occupation` ID와 게임 인물의 동명 문자열 필드를 재사용한다. JSON에는 `seed_world`, `seed_family`, `seed_occupation`과 명시적인 미지정/해제 구별용 `seed_background_fixed=1`을 저장한다. 설명문 3개는 그대로 둔다. 대사집은 편집 보조 자료로 유지하며 게임에서 새 대사집 로더를 만들지 않는다.

분류를 생성기 앞단에 주입하면 기존 세계·출신·직업의 스탯·특성 보정이 다시 실행되므로, 생성이 끝난 뒤 분류만 연결한다. 기존 소유 인물은 현재 JSON을 읽은 뒤 분류 문자열만 갱신한다. 기존의 광역 문명·계층 인덱스와 성장·육성·퀘스트·관계 기록은 보존한다. 지정하지 않은 값은 빈 문자열(미지정)로 두며 임의 추론하지 않는다.

기존 편집기의 분류 선택 UI를 유지한다. 소분류 지정·해제는 캐릭터 JSON과 대사집을 함께 저장하고, 대분류만 고른 무작위 선택은 시뮬레이터 메타데이터로 유지한다. 과거 대사집의 선택은 읽는 것만으로 변환하지 않으며 명시적 적용 동작을 제공한다. 읽기/저장 경쟁은 기존 수정 버전 확인과 순차 저장으로 막는다.

## 구현 계획

- [x] 편집기 후보: 분류 저장·해제, 오래된 선택 표시, 수정 충돌·복제·시뮬레이터 연결을 집중 검사한다. 모딩툴 후보는 별도 폴더에서 준비한다.
- [x] 게임 후보: 현재 WORK를 바이트 왕복 확인하고 생성 마지막/소유 인물 갱신의 최소 지점에 분류 전용 함수를 연결한다. 과거 QSP 변경·수동 원고를 보존한다.
- [x] 게임 집중 검사: 지정/부분 지정/전체 해제/미지정, 새 인물/이미 영입한 노예·조수·개인실을 확인한다. 수치·특성·설명문·관계값 불변을 비교한다. 실제 수정 함수와 콜백은 엔진에서 검사한다.
- [x] 현재 WORK 재대조 후 정확 치환 기록과 함께 WORK·추적 소스에 적용한다. Full·ZIP·사용자 세이브·커밋푸시는 범위 밖이다.
- [x] 도구 실제 화면의 표시·저장 연결을 확인하고 사용법/변경 원장을 남긴다. 진단용 복제본은 결과 보존 뒤 정리한다.

## 확인 한계

모든 캐릭터에게 배경 분류를 새로 추측해 부여하는 작업이 아니다. 선택한 분류를 근거로 능력치나 특성을 다시 추첨하지 않는다. 공주 출신 같은 기존 분류 조건은 저장한 코드로 판정 가능하지만, 이번 작업이 모든 후속 콘텐츠를 자동 구현하는 것은 아니다.

완료 범위: 변경 전후 합성 상태를 이용한 설치 엔진 집중 검사와 실제 편집기 표시를 확인했다. 실제 사용자 세이브 선택 UI·전체 영입 플레이는 미검증이며 REPORT_KO.md에 명시했다.
