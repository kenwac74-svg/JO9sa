# R03-6 레시 무명 요구

2026-11-13 사용자 승인: 인지도0 ‘무명 노예’만 허용하고1이상은 거절한다. 기존 unknown=1 요구가 실제 납품에서 무시되므로 이 요구가 있을 때 기존 fame값이0인지 검사한다. 현재 이 요구를 가진 고객은 레시다.

실제 납품 함수 한 본문만 변경한다. 요구 정의와 저장 콜백은 이미 존재하므로 새 캐시 갱신을 추가하지 않는다. 인지도·체력·감수성·기술·평가·가격·특성·인물·재산·진행은 수정하지 않는다. 다른 고객과 별도 사용자 요구값을 유지하고 새 인물별 필드를 만들지 않는다.
