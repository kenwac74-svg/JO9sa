# 희망사항에서 밝힌 적성 공개·마법 대사 복구 — 2026-11-11

사용자 승인: “수정해. 희망사항에서 밝힌 특성은 목록에 뜨게 하고, 대사도 실제 특성에 맞게 고쳐.” 새 성기술 대사는 컨펌 후 붙이도록 별도 지정했고, 후속으로 마법 적성은 마법에 맞는 대사를 요구했다.

## 반영 내용

`chose_answer`의1114 희망사항 분기만 수정했다. 기존14개 양성 적성(운동·언변·애완·브로니·젖소·간호·가사·요리·검투·마법·미술·음악·무용·비서)은 대사를 생성할 때 해당 페이지의 기존 `$special_action`에 공개 콜백을 지정한다. `interaction_screen`의 원래 페이지 콜백 실행 시 해당 보유 적성의 `_revealed`를2로 바꾸고 기존 `$update_slave_features_list`로 목록을 다시 만든다.

준비만 된 다음 페이지의 적성은 미리 공개하지 않는다. 특성의 보유값·학습률·배타 조건·생성 확률은 바꾸지 않으며 없는 특성을 새로 주지 않는다. 콜백은 interaction=1114 및 해당 적성>0을 다시 확인한다. 새 상시 변수나 저장 형식을 추가하지 않고 기존 페이지 콜백과 기존 발견 필드를 쓴다. interaction 진입부의 기존 killvar로 페이지 콜백이 정리된다.

마법(`enchanter_affinity`) 분기는 성기술로 잘못 각색된 `voice_native` 대사를 호출하지 않고 기존 `$enchanter_like`를 사용한다. 남성 주인공의 마법·약물 제조 대사와 여성 주인공의 마법·물약·부여 대사가 각각 기존대로 나온다. 이 항목의 성격별 대체 말투는 사용하지 않는다. 새 말투 변형을 원하면 마법 의미를 지키는 별도 원고로 검토해야 한다. 오연결 문구 데이터 자체를 삭제하지는 않았지만 이 희망사항 분기에서는 더는 선택하지 않는다.

## 승인 대기 원고

`DIALOGUE_CANDIDATES.json`은 보유한 성기술 관련 특성에 맞춘 희망사항 원고9종이다. 펠라/애널 중독, 색정광/정액 중독, 피학 성애자, 노출 집착증, 이상성욕 선호, 레즈비언/양성애자를 실제 키·값에 맞춰 구분했다. 아직 QSP·대사 데이터·페이지 선택기에 넣지 않았다. 컨펌 후 실제 보유 조건으로 선택하고 숨겨진 관련 특성은 해당 페이지에서 공개하도록 연결할 예정이다. 생성 확률·성향 단계·학습 효과를 바꾸는 승인은 아니다.

## 검증·범위

- 수정 전 실제 FastQSP 격리 실행에서 발견 처리·마법 대사 검사가 실패했다.
- 수정 후142시나리오 통과:14적성 × 보유값(-1/0/1) × 발견상태(0/1/2)=126,14페이지 순차공개, 대화종류 변경·보유특성 제거 후 콜백2개 방어. 반복 실행의 발견 상태 유지와 원 보유값 보존도 검사했다.
- 진단은 원래 `chose_answer`를 실행하며 voice_native와 목록 재생성 함수는 대역을 사용했다. 실제 성격별 문장 렌더링·최종 게임 UI 전체를 확인한 시험은 아니다. 남녀 기본 마법 문자열은 운영 코드에서 확인했다.
- QSP 바이트 왕복·location/줄/주석 구조·공식 적용기 재생·재적용 무변경 통과. 바뀐 location은 chose_answer 하나다. WORK·추적 QSP·런타임 원장 일치.
- 세이브 파일·캐릭터 JSON·이미지·음원·Full·커밋·푸시는 변경하지 않았다. 새 게임이나 세이브 마이그레이션은 필요하지 않다. 기존 저장에서 희망사항을 다시 듣고 해당 적성을 발견할 수 있다.

## 사용·입출력·의존성·복구

일반 EXE를 재실행하고 기존 세이브를 불러온다. 젖소녀/브로니 희망 대사가 있는 캐릭터로 희망사항을 듣고, 해당 페이지를 본 뒤 특성 목록을 확인한다. 마법 희망은 마법·물약 관련 대사가 나오는지 확인한다. 다음 페이지를 보지 않고 종료한 경우 그 페이지의 적성은 숨김을 유지한다.

입력은 기존1114 대화 상태·보유 적성·발견 필드다. 출력은 기존 페이지 콜백·발견상태2·갱신된 특성 목록이다. 호출자는 chose_answer 및 interaction_screen의 기존 special_action 실행부이며 #static_base의 `$update_slave_features_list`에 의존한다. 코드 제거 시 희망 발언을 통한 공개가 다시 누락되고 마법 대체 문구 오연결이 돌아온다. 이미 공개된 특성은 코드 제거만으로 숨겨지지 않는다.

선언형 기록은 mods/2026-11-11_wish_trait_discovery.json, 전후 해시와 압축 복구 위치는 prepared.json/verification.json, 실패/통과 근거는 native-before/after 로그에 있다. task.cjs는 이번 고정 범위의 재현 기록이다. 이후 변경이 있는 상태에서 전체 QSP를 옛 백업으로 덮어쓰지 말고 해당 패치만 비교·역치환해야 한다. 검사 후 재생성 가능한 진단 QSP·설정·중복 적용 백업은 정리하고 압축 원본·원장·검사 기록을 보존한다.
