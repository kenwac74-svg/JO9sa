# 전투 표시 후속 수정

사용자 요청과 확정: 선택지의 옅은 박스를 없애고 5px 위로 이동. 누락된 안개전투 전신 18개 적용. 실제 무리 구성원의 패배 포즈를 한 결과 장면에 함께 표시. 콜로세움 공용 종료 그림은 전용 크기로 표시하되 주인공용 신규 그림은 보류. 후속 대사는 제안만 하고 아직 반영하지 않음. 실제 피해 유형별 타격 효과 4개를 적용. 처형 연출은 중앙 전투 그림 최상위의 투명도70%(불투명도30%) 지속 필터로 변경.

- [x] 최신 WORK·원본 세이브 해시와 변경 전 백업 확보.
- [x] 수정 전 표시 결함 재현 및 손상 없는 후보 빌드.
- [x] 실제 전투의 자원 감소와 피해 종류로 타격 효과 표시. 기존 전투 수치·판정·정산 보존.
- [x] 슬롯별 실제 몬스터 구성의 전투/패배 경로와 반복 출현·다음 전투 복귀 검사.
- [x] 결과 UI·지속 필터·컷신 크기 실제 엔진 검사와 공식 문법/재생/실행 검사.
- [x] WORK와 추적 소스 반영, 미승인 대사 및 주인공 그림 보류 유지. 세이브·배포 폴더·커밋·푸시는 변경하지 않음.
- [x] 재생성 가능한 진단 사본115개(7,617,560,876바이트)만 정리하고 최종 기록 보존. 모든 백업·원본·세이브·폴더·링크 보존.
