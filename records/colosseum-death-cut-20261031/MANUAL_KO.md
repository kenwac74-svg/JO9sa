# 내 노예의 부상 사망 컷신

사용자 제공 arena_defeat_death_v3_795x596.png를 기존 content/pic/scene/coldef1.png에 바이트 그대로 등록했다. 원본795×596을 보존했고 생성·편집·크롭·재인코딩하지 않았다. WORK에는 해당 주소가 없었고 Full에는 이전 kikudef 공통 컷의 임시 사본이 있었다. 옛 Full 그림은 외부 backup에 보존했다. WORK·Full·resources/new의 새 PNG는 원본과 SHA256이 같다.

기존 QSP의 interaction_city1291이 이 주소를 이미 사용한다. 정식 경기에서 치명상을 입고 사망 판정을 받은 노예의 결과이며, 처형1292/coldef2와 생존1293/coldef3와는 별도다. QSP는 변경하지 않았고 두 QSP·원본·다른 결과 이미지의 해시를 보존했다.

실제 설치 엔진에서 시험 인물의 지구력을낮춰 기존 치명상 사망 판정이 확실히 발생하도록 구성하고, 실제 전투 복귀→1291 결과를 실행했다. 노예 제거·PNG 로딩·자연 및 표시크기795×596·하단 설명 범위를 확인했다. 이는 격리 진단이며 사용자 마우스 플레이나 모든세이브검증은 아니다. 기존SAV7개·수치·확률·보상·패널티를 바꾸지 않았다.

QSP의 바이트 불변과 구조, 진단 QSP 줄바꿈 검사를 확인했다. 새 코드 변경이 없으므로 이번에 새 코드 출고9경로를 돌렸다고 주장하지 않는다. source/targets/prior/복구그림의경로와해시는 verification.json에 있다. 목록·등장조건·HTTP확인은 하위catalog기록이다.
