# 전용 버튼 실제 실행 검증

WORK와 바이트가 동일한 QSP를 격리된 FastQSP 클라이언트에서 열고 기존 16/17 세이브 복사본을 실제 Game → Load로 불러왔다. 로드 뒤 노예·조수 각각의 전용 촉수 그림을 육안 확인하고 실제 마우스로 눌렀다. Game → Save로 새 결과 파일을 저장한 뒤 콜백 59/45, 해당 인물 행동력 5→4, 미실행 인물 행동력 5 유지, 재고 증가를 검증했다.

slave.png와 assistant.png는 브라우저 미리보기가 아닌 실제 Qt 게임 창 캡처다. 엔진 결과 세이브는 .sav.gz로 압축 보존했고 원본 해시를 result.json에 기록했다. 테스트 전용 클라이언트의 버전 검사 무시 설정을 사용했다. 기존 소스 게임 인스턴스에는 입력하지 않았고 원본 QSP·설정·76세이브 총79파일 해시를 대조하여 보존을 확인했다. 정적 구조·줄·주석 검사도 통과했다. 전체 게임의 모든 분기와 문법을 증명하는 검사는 아니다.

게임 코드·리소스 추가 변경, 배포 폴더 반영, 커밋·푸시 없음.
