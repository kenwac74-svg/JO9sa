# 특수기술 무기 UI 조사

현재 ARENA_SPECIAL_TEXT_UI_20261028은 일반 전투와 별도인 arena_mode1/combatant1 공용 분기에서 활성 아이콘10곳과 사용 후 아이콘10곳을 텍스트로 치환한다. 캣파이트도 이를 공유해 아이콘이 없다. 당시 녹색 도끼 제거를 새 그림 연결이 아닌 전체 텍스트 전환으로 처리한 결과다.

새 도끼는 content/pic/ui/buttons/heavy_active.png 및 heavy_used.png에 존재하지만 현재 QSP 직접 참조가 없다. setup은 여전히 buttons/legacy/heavy_*를 설정하며 renderer는 해당 이미지 변수를 읽지 않는다. 그물·채찍·쌍검·방패 큰 전용 아이콘은 좁은 조사 범위에서 legacy에만 확인됐다.

사용자 요청은 원인 확인이다. 이번 컷신 버그 수정에서 무기 UI를 임의 복구하거나 옛 녹색 도끼를 다시 연결하지 않았다. 후속 수정은 사용하려는 아이콘을 확인한 뒤 기존 콜백·1회 제한·사용 완료 동작을 유지해야 한다.
