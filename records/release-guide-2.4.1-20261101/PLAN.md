# 2.4.1 플레이어용 독립 HTML 제작 계획

목표: 2.4.1을 처음 받는 사람도 2.3 이후의 누적 변화를 이해할 수 있는 홍보·설명 문서. 최종 결과물은 이미지가 내장된 HTML 한 파일이다.

## 구성과 표현

1. 업데이트: 2.4.1 핵심 변화를 먼저 소개하고, 2.3 → 최종 2.4.0 전체 누적 변화는 분야별 목록으로 이어 쓴다. 수정 전 수치·명칭은 최신 합의로 정리한다.
2. 버그 패치: 전투, 거래, 인물·개인실, 진행, 표시로 묶고 플레이어가 겪는 증상과 달라진 동작을 쓴다.
3. 그외 변경: 제작·검수·표기·도구의 작은 개선을 간결하게 나열한다. 제작 도구를 게임 본체 동봉 기능으로 오인시키지 않는다.

다크 판타지 게임과 맞는 먹색·양피지색·금색의 정적인 문서로 만든다. 웹사이트나 외부 서비스는 만들지 않는다. 이미지 네 장은 기존 WORK 일러스트를 축소·압축해 내장한다. 새 그림을 생성하거나 게임 리소스를 고치지 않는다.

## 근거와 범위

- 최초 2.4 변경 내역 + 1차 r3 + 2차 최종 r4 + 3차 r1과 10/28~11/1 개별 적용 기록을 대조한다.
- 신규 업데이트와 기존 기능의 후속 수정을 구분한다. 정확한 숨은 수치·획득 조건·고유 이벤트 결말은 공개하지 않는다.
- 미결정·보류·미재현 문제를 수정 완료로 광고하지 않는다. 모든 저장·모든 플레이가 검증됐다는 문구를 쓰지 않는다.
- WORK를 설명문의 최신 내용 기준으로 삼되 Full의 자동 동기화·ZIP 제작·커밋·푸시는 하지 않는다.
- 기본 실행 방법을 언급한다면 EXE 직접 실행으로 안내한다.

## 제작 순서

1. 두 버전의 전체 변경 항목과 출처를 수집하고 공개용 문장으로 묶는다.
2. 원문 항목의 누락과 최신 명칭·규칙 충돌을 독립 검토한다.
3. CSS·이미지 모두 내장한 `JO9_2.4.1_업데이트안내.html`을 만든다. 이미지 최대 폭은 640px, 전체 파일은 가능하면 600KB 이내로 만든다.
4. 오프라인 file://로 열어 데스크톱·모바일 폭에서 이미지, 가로 넘침, 내부 링크, 접기/펼치기, 외부 요청 0건을 검사하고 화면을 확인한다.

## 검토 초점

- 2.4.1 신규와 2.4.0 누적의 중복·잘못된 분류.
- 옛 특성 명칭·확률·일반 이사와 파산 이주의 혼동.
- 제작 전용 사항이 일반 플레이 기능처럼 보이는 문장.
- 이미지 누락·대형 원본 내장·외부 파일 의존.
- 좁은 화면의 긴 한국어 문장·메뉴·카드 넘침.

산출물: 독립 HTML, 내부용 출처/흡수표, 재생성 스크립트, 크기·화면 검증 기록. 공개 HTML 안에는 로컬 작업 경로나 개발 로그를 넣지 않는다.
