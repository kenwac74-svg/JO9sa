# 영문 안내와 게시판 본문 추가

사용자 요청: 기존 설명문의 영문 독립 HTML 1개, 게시판용 한글·영문 TXT 각 1개.

- 확정된 한국어 원고의 2.4.1 주요 5개·후속 2개, 2.4.0 누적 7분야 48개, 버그 36개, 그외 11개를 1:1로 유지한다.
- 아그라바 특수 재고는 개발 중 항목으로 그외 변경에 둔다. 영문 안내가 영문판 게임 제공으로 읽히지 않게 한다.
- TXT는 모든 접힌 항목을 펼친 일반 텍스트로 생성한다. 이미지·HTML·로컬 경로·접기 버튼은 넣지 않는다.
- 영문 HTML은 기존 단독 문서의 레이아웃과 축소 이미지 3장을 재사용하고 외부 의존을 넣지 않는다.
- 한국어 HTML과 게임·배포 폴더는 수정하지 않는다. 새 공개 파일은 저장소 릴리즈 문서에 추가한다.
- 영어 문안 검수, 항목 수·본문 일치, 오프라인 표시·버튼·모바일 넘침·외부 요청 0건을 확인한다.
