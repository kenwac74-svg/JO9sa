# 조수 휴식 효과 누락 수정

2026-11-17 사용자 승인: “수정해”. 감수성의 기존 성장 공식을 먼저 조사한 뒤, 조수 휴식 3종에서 정의된 효과가 실행되지 않는 문제를 수정했다.

## 동작과 범위

`interaction`의 정원(5605)·온천(5606)·황금새장(5607)은 `assistant_rest` 유형이며, 기존 `$special_part`에 감수성 진행치 +2를 비롯한 효과가 들어 있다. 하지만 `interaction_result`에는 해당 유형을 실행하는 분기가 없었다. 일반 행동 완료·행동력 차감만 실행되고 휴식 효과는 빠졌다.

`interaction_result`에 분기 하나만 추가했다. 성공 결과에서 기존 `$special_part`를 한 번 실행하고 정의된 위생 변화와 `free_time`을 적용한다. 정원·황금새장은 조수 행동력 2, 온천은 1이다. 주인공 행동력은 소모하지 않으며 공통 자동 차감을 차단해 중복 소모를 막는다. 기존 무한 행동력 치트를 유지한다.

거부 결과에서는 효과·위생·행동력 처리를 건너뛴다. 온천 2·황금새장 5스파크는 기존 정의 진입 시의 차감을 그대로 사용하며 새 환불 규칙을 넣지 않았다. 종료 전에 기존 `free_time`을 0으로 정리한다.

감수성 +2와 출신별 성장 보정, 자아·헌신·불안 등 원래 효과는 바꾸지 않았다. 사용하지 않던 `praise_potence`를 새 보너스로 연결하거나 노예의 다른 보상 공식을 복제하지 않았다. 새 영구 저장 필드·로케이션·캐시 초기화는 없다. 일반 노예 휴식과 다른 조수 보상 유형은 변경하지 않았다.

## 입력·출력과 의존성

입력은 기존 행동 유형, `interaction_assistant['res']`, `$special_part`, `add_assistant_hygiene`, `free_time`, `cheat_inf_en`이다. 성공 시 기존 조수 속성·진행치·휴식 무드와 행동력에 정의된 효과가 적용된다. 기존 공통부가 완료 횟수를 한 번 기록하며 기존 화면을 표시한다.

호출자는 `interaction`이며 성장값은 기존 `jo9_origin_growth`를 사용한다. 표식 `ASSISTANT_REST_EFFECTS_20261117`을 제거하면 조수 휴식의 실제 효과 실행이 다시 누락된다. 전체 QSP 구버전 복사 대신 선언형 패치의 해당 블록만 현재 본문과 대조해 역적용한다.

## 검증

- 수정 전 기대 동작 15조건 중 11조건이 효과 미실행으로 실패함을 확인했다.
- 수정 후보는 실제 `interaction`·`interaction_result` 전체와 기존 행동력·성장 helper를 사용한 WASM 5.8 검사 15조건을 통과했다. 주변 기능과 화면은 중립 대역이다.
- 실제 FastQSP 5.7 격리 진단에서 정상 3종·무한 행동력·거부·출신 보정·일반 노예 대조 등 11시나리오, 105검사 통과. 개인 SAV·실제 화면의 육안 검사는 하지 않았다.
- 공식 `apply_mods.ps1 -DryRun`으로 변경 로케이션의 패치 재생과 재적용 건너뜀을 확인했다. 이 전용 입력의 줄바꿈·마커 경계가 정상이다.
- 전체 컨테이너 왕복·역패치 바이트 일치와 다른 로케이션/필드 보존을 확인했다. 다른 사용자 원고의 기존 lone LF는 정규화하지 않았다. 전체 게임 출고 검사를 반복하거나 전체 게임 PASS로 표현하지 않는다.
