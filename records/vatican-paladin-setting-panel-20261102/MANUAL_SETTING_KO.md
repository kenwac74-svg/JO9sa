# 바티칸 팔라딘 우측 설정

사용자의 최종 지시로 이미지 자동 교체와 신규 이미지 경로 연결은 제외하고, 전투 전 선택 화면 우측 이름·소제목·소속·설정만 WORK에 반영했다.

바티칸 팔라딘 / 교황청 직속 관문 수호자 / 바티칸

바티칸의 명을 받들어 차원 관문을 지키는 정예 성기사. 관문을 지나는 물자와 사람, 노예의 행렬은 모두 그녀의 허락 아래 움직인다. 허가 없는 접근자와 안개에서 밀려드는 이계의 괴물 앞에, 축복받은 검은 망설임 없이 내려온다.

성유물로 강화한 갑옷과 끝없는 금욕 훈련은 공포와 고통마저 신앙 아래 짓누른다. 회유와 뇌물로 길을 열려는 자는 차가운 침묵과 검날을 마주할 뿐이다.

팔라딘이 수호하는 것은 교황청이 정한 신성한 질서다. 관문 너머에서 누가 쇠사슬에 묶여 오든, 바티칸의 인가와 통행세가 갖춰진 행렬은 방해받지 않는다.

## 표시 조건과 부작용

shop_general에서 $place=fogs_battle1, interaction_city=6215, sp_txt=6215, get_weapon=0, $враг[1]=vatican_paladin일 때 표시한다. 기존 jo9_reference_panel과 공통 제목 형식을 쓴다. 같은 준비 화면을 저장 후 로드한 경우 $ongload가 shop_general만 다시 그린다(skip_to=6215도 허용). 62171이나 전투 초기화를 다시 호출하지 않아 배우·퀘스트·소지금·보상은 유지한다. 무기 선택901, get_weapon=1, 가디언6216 및 일반 상점은 기존 표시를 유지한다.

새 변수·로케이션·저장 형식은 없다. 해당 표시 분기를 제거하면 준비 화면 우측이 다시 빈 곳으로 돌아가며, 로드 분기만 제거하면 옛 저장의 기존 HTML은 다음 표시 전까지 유지될 수 있다.

## 수동 이미지 교체 경로

- 선택 화면: content/pic/bg/vatican_paladin.png
- 전투: content/pic/mob/vatican_paladin.png
- 패배: content/pic/mob/defeated/vatican_paladin.png

위 경로와 이미지 파일·카탈로그는 이 작업에서 변경하지 않았다. 파일 교체 후 새 그림 확인은 일반 WORK EXE를 완전히 종료하고 다시 실행한다.

## 검증

구조·줄/주석 경계·패치 재생/역재생, literal 이미지 경로/기존 렌더 구간/선택 콜백/전투·퀘스트 코드 보존을 확인했다. 실제 설치 엔진 준비화면·로드핸들러2회·무기·가디언·일반상점24판정과 공식9경로 PASS. 패널 넘침 없음. 실제 GUI 세이브 불러오기 클릭은 별도 수동 확인이다.

Full·원본·CSS·기존 SAV·이미지·카탈로그는 쓰지 않았다. 배포 최종 동기화와 ZIP·커밋·푸시는 기존 보류 상태를 유지한다.
