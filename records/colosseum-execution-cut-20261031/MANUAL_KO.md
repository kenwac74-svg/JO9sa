# 내 노예가 처형된 콜로세움 결과 컷신

사용자가 마지막으로 지정한 “로마 콜로세움의 승리한 검투사_795x596.png”를 기존 content/pic/scene/coldef2.png에 바이트 그대로 등록했다. 앞서 올린1402×1122원본 대신 확정된795×596파일을 선택했으며 두 원본 모두 modworkpic에 보존했다. 생성형 편집·크롭·재인코딩은 하지 않았다. WORK에는 해당 주소가 없었고 Full은 kikudef 공통 컷의 임시 사본이었다. 옛 Full 그림만 외부 backup에 보존하고 WORK·Full·resources/new를 같은 PNG로 맞췄다.

QSP는 interaction_city1292에서 이미 이 경로를 사용하므로 코드 수정이 없다. 기존 정식 경기 패배 뒤 상대/관중에게 처형되는 분기다. 생존 후송coldef3·사망coldef1·연습 승패그림은 유지했다. 원본과대상·복구PNG·두QSP 해시는 verification.json에 기록했다.

실제 설치 엔진에서 도주·기절·치명상에서 첫 사망 판정을 버틴3패배로부터 처형1292까지 실제 복귀를 실행했다. 시험 인물의 기질을 낮춰 기존 처형 분기를 고정하고, 결과 로케이션·노예 제거·새PNG 로딩·자연크기와표시크기795×596·하단 글자 범위를 확인했다. 이는 격리 진단 실행이며 사용자의 마우스 수동 플레이나 전체 게임 검증은 아니다. 코드·확률·상금·패널티·기존SAV7개를 바꾸지 않았다.

QSP는바이트그대로이며구조와진단QSP줄바꿈검사를통과했다. 이번에는새코드출고9경로검사를했다고주장하지않는다. 기존이미지주소가그대로라세이브경로이관이필요없고다시표시할때같은주소의새그림을읽는다. 이미지목록·등장조건·HTTP확인은하위catalog기록이다.

Fullmanifest와출고명세·릴리즈노트·간단TC를실제파일에맞췄으며미교체원화는사망coldef1한개만남는다. 원복은prior.backup의옛그림을사용한다. ZIP·커밋·푸시는하지않았다.
