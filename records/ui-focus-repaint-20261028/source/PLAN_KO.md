# D15 일반 UI 포커스·검은 잔상 조사

사용자의 다음 미결 자동 조사 지시를 따른다. D15는 3차 패치 이후 우선 조사로 지정된 항목이며, 10/27 완료된 전투 타격 애니메이션 프레임 겹침 수리와 다르다. 후자를 다시 수정하지 않는다.

기준은 현재 WORK QSP f6520ef1, Workshop 연동 엔진 f75032d7이다. 읽기 대조에서 현재 엔진의 생성자 hook은 순정 바이트와 같고 과거 전체 화면 재도색 setter가 없는 것을 다시 확인했다. 이것만으로 일반 UI 잔상의 원인을 확정하지 않는다. 옛 엔진의 단순 덮어쓰기는 Workshop 연결을 잃을 수 있으므로 수행하지 않는다.

- [x] 최근 제보 완료·개인실 실제 재현 대기·밸런스 보류와 D15의 우선 조사 조건을 대조한다.
- [x] 독립 읽기 검토에서 D15 미완료와 별도 조사 범위를 확인한다.
- [x] 현재 엔진·과거 재도색 빌더·Qt DLL·이전 결과를 대조한다.
- [ ] 현재 QSP/CSS/엔진을 사용하는 격리 성인 정보 화면 fixture를 한 개 만든다. 원본 게임·기존 세이브·배포본에는 쓰지 않는다.
- [ ] Computer Use로 일반 속성·특성 도움말을 누르고 포커스를 게임의 메뉴 영역으로 이동했을 때 잔상 변화가 있는지 관찰한다. 새 화면 내용 변경과 단순 재도색을 구분한다.
- [ ] 실제 재현 여부와 추가 비교 필요성을 기록한다. 재현하지 못하면 엔진 원인 확정·수정 완료로 표시하지 않는다.

새 운영 엔진 교체·게임 QSP/CSS 수정·세이브 변환·설정 변경·배포·커밋·푸시는 범위 밖이다. 복제 QSP와 설정은 별도 tmp 하위에만 만든다. 링크는 읽기용 자원 참조이며 정리 시 외부 대상을 따라가지 않는다. 합성 화면은 실제 개인 세이브·모든 UI의 재현을 대신하지 않는다.
