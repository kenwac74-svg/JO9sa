# 발화 불가 특성의 행동 제한

입력: 인물 배열의 `jo9_voice_trait`. `0`은 기존 동작, `1`은 선천적 발화 불가, `2`는 혀 손실이다. 등록·설명·편집·생성은 별도 특성 모듈이 담당한다.

`voice-transform.cjs`는 기존 `interaction` 위치만 수정한다. 새 위치·함수·저장 변수·상태 이력은 만들지 않는다. 재갈과 침묵 규칙의 값을 변경하거나 재사용하지 않는다.

## 행동

| 현재 대상 | 차단되는 항목 |
|---|---|
| 노예, 또는 개인실에서 `slave` 자리로 옮겨진 메이드 | 질문 `1111`–`1117`; 수사학 수업 `1231`, `4131`, `1731`, `5610` |
| 조수 | 질문 `1118`, `1126`, `1138`; 수사학 수업 `5015`; 조수가 교사가 되는 `4131` |
| 노예나 조수 중 한 명이라도 발화 불가 | 서로 앞에서 생각을 말하게 하는 `854` |

입력 시 기존 행동별 초기화를 마친 뒤, 실제 행동 처리 전에 발화 가능 여부를 확인한다. 차단되면 현재 인물 이름과 `말을 할 수 없어 이 대화에 답할 수 없습니다.` 또는 수업·참여 안내를 기존 `interaction_screen` 한 페이지로 표시한다. 행동력·비용·수사학 경험치·관계 변화·행동 완료 횟수를 새로 적용하지 않는다. 상태값이 `0`이면 원래 코드로 이어진다.

설득·격려·위협·이름 변경·일반 업무처럼 명령을 이해하고 수행할 수 있는 행동은 그대로 남긴다. 음악은 악기 연주를 포함하므로 일괄 차단하지 않는다. 수사학 점수를 이용하는 비언어 공연에도 임의의 능력치 페널티를 추가하지 않는다.

고립 명령 `941`과 `841`은 기존 명령 효과를 유지한다. 원문의 ‘뜻을 따르겠다고 말한다’ 4줄만, 발화 불가 인물일 때 말을 이해했다는 듯 고개를 끄덕이는 서술로 표시한다. 정상 인물의 기존 문구는 그대로 출력한다.

## 범위 확인

`interaction`의 실행 가능한 `talk`/`talk_assistant` 분기 32개를 추적했다. 질문은 위 목록이며, 나머지는 지시·사회화 또는 `854`다. `special_talk`인 병원·의사 이벤트 `9911`–`9917`, 임신 경과 안내 `9951`/`9952`, NPC 안젤리카 이벤트 `9900`을 발화 불가 때문에 중단하지 않는다. 기존 이벤트가 진행되며 의사나 NPC가 말할 수 있어야 한다.

게임 전체의 무작위 사건·개별 인물 이벤트에 포함된 모든 기존 문장을 발화 불가용으로 새로 각색한 것은 아니다. 이 구현은 인물 공통 질문과 수사학 행동을 연결하는 기능이다.

## 의존 및 제거

- `interaction_screen`, 기존 인물 배열, `snk_room_bridge`에 의존한다. 개인실은 기존 전환을 그대로 사용한다.
- `ARGON_VOICE_ACTION_GUARD`를 제거하면 발화 불가 특성이 있어도 기존 질문·수사학 수업을 실행한다.
- `ARGON_VOICE_ACK_SLAVE_1/2`, `ARGON_VOICE_ACK_ASSISTANT_1/2`를 제거하면 고립 명령에서 원래의 발화 확인 문장이 다시 나온다. 업무 효과에는 영향이 없다.
- 특성 자체의 저장·표시 코드는 이 모듈과 분리돼 있으므로, 이 모듈을 제거해도 값이나 기존 세이브 구조를 복구할 필요가 없다.
