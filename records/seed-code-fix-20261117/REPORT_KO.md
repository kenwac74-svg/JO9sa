# 통합툴 seed_age 분류 제한 제거 — 2026-11-17

사용자 지시: 산식·계수에서 seed_age를 실제 나이로 잘못 판단해 추가한 제한을 제거한다. 기존 계수·프로필·대사·배경 연결은 보존한다.

## 수정

- 분류 코드1을 `excludedAges`로 제외하던 계산 조기 종료를 제거했다. 수치 공식과 난수는 그대로다. 코드0·2의 결과는 원본과 일치한다.
- 산식·계수에서 제외 배지와 정책 거부 문구를 제거하고 발육·외형 분류임을 표시한다. 코드 입력 범위는 기존 요청대로0~99 정수다. 등록하지 않은 코드의 계수100은 기존 계산 기본값이다.
- 과거 저장 공식에 `[1]`이 있어도 그 항목만 적용하지 않는다. 다른 계수와 사용자 추가 항목을 보존하며, 읽을 때 저장소를 다시 쓰거나 초기화하지 않는다. 다음 수동 저장 때 호환 필드 `excludedAges`는 빈 배열로 남는다.
- API의 잘못된 자동 생성 금지 플래그와 대사집의 결과 가져오기 축소·안내를 제거했다. 기존 대사집과 수동 대사를 자동 덮어쓰지 않는다. 실제 저장은 원래 버튼으로 한다.
- 뽑기 분포의 코드1 선택을 허용했다. 기존 표본 파일은 그대로라 그 코드의 표본이 없으면 결과가 비어 있다는 사실만 안내한다. 표본을 임의로 만들지 않았다.
- 사용자가 정한 배경 연결·허용/제외 조건과 실제 개별 과거 설정은 변경하지 않았다.

## 구조

클로드 원본 dist는 보존하고 통합툴의 기존 overlay 제공 방식을 사용했다. 새5개 모듈은 `past-history.mjs`, `sim-data.mjs`, `coef-view.mjs`, `sim-view.mjs`, `pillow-talk.mjs`이며 기존 `character-view.mjs`, `studio-view.mjs`의 관련 제한도 제거했다. 새 저장 키는0개다.

`server.py`는 일반 URL과 `/v/<build>/` URL에 같은 overlay를 제공한다. 기본 공식은 원본을 읽어 분류 제외만 비우고 코드1의 기존 기본 계수100을 제공한다. 캐릭터 대사집 응답도 분류 코드 때문에 자동 생성 금지로 표시하지 않는다. `Start-Modding-Hub.ps1`과 `build_id()` 양쪽에 모듈을 등록해 브라우저·전용 앱의 재사용 판정이 일치한다.

입출력은 기존 공식·계수 JSON과 동일하다. 호출자와 소비자는 기존 캐릭터 시뮬레이터·산식·뽑기 분포·대사집이며 게임 QSP에 자동 적용하지 않는다. 제거하려면 새 모듈 등록과 기존 UI 수정·서버 제공 경로를 함께 되돌려야 한다. `before/*.gz`는 실제 수정 전 파일이며 무조건 덮어쓰기 전에 후속 수동 변경을 대조한다.

## 검사
