# 이사벨라 술집 컷신 반영

사용자가 2026-11-01 정한 승인 기준에 따라 10월 31일 제작 후 시안으로 남아 있던 술집 컷신을 채택했다. 재작업·취소·보류 없이 다음 지시가 이어지면 결과물 채택 승인으로 간주하는 기준을 저장소 AGENTS.md 27번에 기록했다.

실제 interaction_city 이벤트 610의 isabella_meeting 배경 경로인 content/pic/bg/isabella_meeting.png 한 개를 795×596 불투명 PNG로 교체했다. 생성 원본은 그대로 보존하고 확대·축소 외에 다시 그리거나 구도를 자르지 않았다. WORK·seed 이미지 목록은 bg-0609 한 행만 갱신했고 기존 ID와 체크 상태를 보존했다.

원인: 이전 작업은 review-only 저장으로 끝났으며 별도의 영입 거래 화면 캐릭터만 교체되어 있었다. 이번에 술집의 실제 배경 파일을 반영했다. characters의 같은 이름 옛 그림은 이번 호출 경로가 아니므로 변경하지 않았다.

검증: PNG 해독·크기·불투명 형식, 설치 후 해시, 두 목록에서 한 행만 변경, 인라인 JavaScript 문법을 확인했다. QSP·세이브 형식은 변경하지 않았고 배포본의 QSP와 해당 그림도 보호 해시가 동일했다. 실제 게임 내 페이지 재생은 하지 않았다. HTTP 결과와 이전/최종 해시 및 복구 경로는 asset-change.json에 기록했다.

최종 재검증: 목록 HTTP 200과 새 bg-0609 행을 확인했다. 최초 연결 중단 기록은 보존하고 final-verification.json에 재확인 결과를 분리했다. WORK에서 수동으로 추가된 2행을 포함한 41,330행과 seed 41,328행의 각 기존 행 수를 그대로 보존했으며 각각 목표 한 행만 변경했다.
