## 최종 동작

- `interaction_city=6026`의 사용자 작성 1~8페이지를 그대로 보존하고 9페이지에 두 선택지를 추가했다. 사용자가 지정한 24547행의 원고는 수정하지 않았다.
- 「프리실라에게 마법을 요구한다」 → `6027`, 마법 입력용 1페이지.
- 「프리실라에게 끝내주는 섹스 봉사를 하라고 말한다」 → `6028`, 사용자 입력용 4페이지. 기존 보상 장면의 후반 4페이지 수와 같다.
- 선택 페이지에서는 다음/이전 화살표로 선택을 건너뛸 수 없다. 다른 일반 대사의 화살표는 유지했다.
- 마법의 이름과 효과는 아래 설계 문서에 기록 중이며 **아직 마법 지급·시전·특성 복사는 구현하지 않았다**. 현재 마법 결과는 입력 자리다.

기존 길드 보상 `6025`와 그 수령 조건은 그대로다. 새 귀환 분기가 기존 `witch_talk` 보상을 소모하지 않으며, 돈·행동력·마법력·책·의뢰 완료값을 변경하지 않는다. 신규 영구 변수는 없고 기존 방문 기록에는 새 장면 번호가 남는다.

기존 그림을 독립 파일로 복사했다. 원본과 연결을 공유하지 않으므로 나중에 각각 교체할 수 있다.

- 마법: `content/pic/scene/Witch/priscilla_return_magic/magic_01.png`
- 별도 보상: `content/pic/scene/Witch/priscilla_return_service/service_01.png` ~ `service_04.png`

## 변경 위치와 복구

`interaction_city`는 두 선택지와 결과를, `interaction_screen_city` 및 `interaction_screen`은 `data-jo9-choice`가 있는 페이지의 필수 선택을 처리한다. `JO9 MOD START/END`와 `mods/2026-11-16_priscilla_reward_choices.json`에 기록했다. 직전 수동 원고는 `mods/2026-11-16_priscilla_preserve_manual.json`로 별도 보존했다.

수정 후 WORK/소스 QSP SHA256: `2aa069810a88ddd6a21c7b305f894591f7a68baad9bd4697f89b67a3f45df20b`.

제거할 때는 선택지 mod의 역변경과 새 그림 5개의 참조를 함께 검토한다. 사용자 수동 원고 보존 mod까지 되돌리지 않는다. 이후 수동 수정이 있으면 전체 QSP를 과거 백업으로 덮어쓰지 않는다. `prepare.cjs`, `verify.cjs`, `install.cjs`는 해당 기준 해시를 검사하는 재현 자료다.

## 확인한 범위

실제 QSP WASM의 경로·결과·화면 출력·오브젝트 선택 처리에서 6/6조건 통과. 두 목적지의 분리, 선택 건너뛰기 차단, 일반 화살표 유지, 사용자 1~8페이지 원문 보존, 금액·행동력·기존 보상 상태 보존을 확인했다. 테스트 저장의 5개 진입 버튼과 새 9페이지/기존 22페이지 넘김도 통과했다. 레이아웃 helper는 격리 대체했으므로 네이티브 게임 화면과 글자 넘침은 사용자 확인 대상이다.

범위 한정 mod dry-run, 직렬화 왕복/역변경, 변경 위치 밖의 필드 보존, 변경 위치의 CRLF와 마커 경계를 확인했다. 이미 확인한 생성기 상한·결과 저장 UI 수정을 보존했다. 전체 배포 검사를 반복하지 않았다.
