# 환전 화면 보유 금화

입력은 기존 gold이며 출력은 환전 화면 하단의 “보유 금화: N개”다. shop_general의 GOLD_BALANCE_MENU_20261026은 발삼 환전 메뉴(sp_txt=2)에서만 로컬 대사 문자열을 설정한다. interaction_screen_city의 GOLD_BALANCE_RESULT_20261026은 발삼 환전 결과302110~302114에서 기존 대사 뒤에 잔액을 덧붙인다. 역환전 후에는 0개를 표시한다. 기존 div#text와 폰트·배치를 사용하며 새 UI·CSS·저장 변수·금액 변경은 없다. 기존 세이브의 메뉴 캐시도 그대로 사용한다. 삭제하려면 patch.json의 두 블록을 역적용하면 된다.

공식 출고 검사 PASS(실제 엔진9경로, 구조/개행/주석 경계, 패치 재생/재적용), 별도 실제 엔진5경로(0/양수 메뉴, 0/양수 결과, 일반 대화 제외) PASS. 이 검사는 DOM 문구와 통화 불변을 확인하며 물리적 화면 배치·실제 플레이는 사용자가 확인한다. 기존 확인용 세이브는 변경하지 않았다. WORK QSP만 반영, Full·ZIP·커밋·푸시 없음.
