# 지난 패치 이후 실제 플레이 검사 결과

마지막 배포본인 2차 r4와 현재 WORK를 비교해 변경 32묶음을 확인했다. 현재 WORK의 격리 사본을 실제 FastQSP 엔진으로 실행했으며, 원래 메뉴·선택지·전투·일일 보고·복귀 경로를 검사했다. 일부 저장 불러오기와 화면 전환은 물리 마우스·키보드로도 확인했다. 이번 작업은 검사만 수행했으며 게임 코드는 수정하지 않았다.

## 확인된 문제

| 항목 | 실제 관찰 | 구분 |
|---|---|---|
| 소문 메뉴 3곳 | 링크가 잘려 상담 화면이 열리지 않음. 후속 결제·추천 동선도 차단됨 | 이번 추가 기능 |
| 카오틱 에센스 재고 행 | 종이 패널 아래로 24px, 하단 설명 영역으로 14px 침범 | 이번 추가 기능 |
| 캣파이트 결과 복귀 | 결과 뒤 돌아갈 goto_loc 로케이션이 없음 | 배포 r4에도 있던 결함 |
| 노예·개인실 모유량 | 일반 노예와 개인실1의 아이콘을 눌러도 수량 메시지가 안 뜸. 조수는 정상 | 기존 제보 재현 |
| 개인실 이종취향 | 얼굴→프로필→이종취향을 누르면 개인실1로 돌아감. 인물 소유·ID 복원은 정상 | 기존 제보 재현 |

큰까마귀관 종합정보의 정신상태 메시지 가림은 현재 표본에서 재현되지 않았다. 노예·조수 모두 메시지를 닫은 뒤 종합정보 복원과 입력 가능한 상태를 확인했다. 이 결과가 사용자 세이브의 모든 조건을 보증하지는 않는다.

## 통과한 주요 동선

- 자산 처분: 장식 환급 460에서 청구 100을 한 번 차감해 360이 남고, 기본 인테리어로 복귀했다. 실제 저장 후 다시 불러와도 잔액 360이 유지됐다.
- 파산 방지: 입주자가 있는 개인실·동면 장치 처분을 막았고, 직접 자금 마련을 선택해 화면을 나가도 미납이면 다음 날로 진행하지 못했다. 자산을 모두 처분해도 청구액에 못 미치면 원래 파산 엔딩으로 이동했다. 무낙인 급매는 두 인물 각각 202·204로 처리됐으며 수집한 NPC·퀘스트·평판 상태가 유지됐다.
- 전투·명성: 안개전투의 행동력 정산, 목격 보상과 상한, 그린치 전투 후 퀘스트 복귀, 캣파이트 3승 제한과 10+3+3 보상, 랠리 80 상한을 확인했다. 캣파이트의 기존 종료 복귀 문제는 별도로 남아 있다.
- 생산: 수동 10경로와 자동 4경로에서 실제 작업·지급·보고·메인 복귀를 확인했다.
- 육성·경제: 의료센터 결제·취소·중복 방지, 난도별 상인 실제 지급가, 에센스 구매·사용·보호 조건, 행동력·영양·성장·과로 보정을 확인했다.
- 특성·관계·화면: 전체보기 3열·하단 설명·닫기·개인실 인물 복원, 특성 충돌 정리, 다재다능 명성 1회 지급, 영입 조건, 반복 대화, 이사벨라 3외형과 일일 알림 후 정상 배경 복귀를 확인했다.
- 우유 가격판: 실제 Qt 엔진에서 가격 1~7의 검정 숫자·위치·가림 여부, 원래 5병 판매의 대금과 재고를 확인했다.

## 한계와 보존

32묶음의 대표 동선을 검사한 결과다. 모든 난수·대사·세이브·분기를 완주한 것은 아니다. 에드워드는 현재 이미지 자체만 확인했고 인게임 선택 전환은 미실행이다. 번역 선택지 일부는 부분 검사이며, 소문 후속 동선은 진입 결함 때문에 확인하지 못했다. 이미지 0접두 참조 2건은 기존 정적 확인 상태다. 마법낙인 재현 등 사용자 보류 항목은 활성화하지 않았다.

공식 구조·행끝·왕복·표식·인물 JSON·정확 패치 재생 검사와 설치 엔진 기본 9경로는 통과했다. 동적 QSP 코드 전체를 증명하는 완전 문법 검사기는 아니다.

실제 원본 SAV는 **76개**다. 저장 폴더의 84항목에는 안내문·보고서·미리보기·백업 등 8항목도 포함된다. 이를 구분해 기록했다. 원본 SAV와 WORK·CSS·설정 등을 포함한 **96개 보호 파일의 해시가 불변**이다. Full·배포 ZIP·사용자 세이브를 수정하지 않았으며 커밋·푸시도 하지 않았다. 재생성 가능한 대용량 진단 사본은 정리하고 핵심 로그·수치·HTML·재현 스크립트만 보존했다.
