# 통합 Full 폴더 빌드 계획 — 2026-10-31

목표: 최신 WORK를 기준으로 G:/somi/Jack O Nine Tails v2.4 Kor_Full에 ZIP 전 단계의 독립 실행 빌드와 수동 TC·전용 SAV를 납품한다. 사용자는 질문 없이 완료하도록 승인했다.

1. 기존 입력 계획을 재사용하지 않고 최신 파일·QSP·체크 상태를 다시 인벤토리한다. WORK/원본/기존 SAV는 읽기 전용으로 유지한다.
2. 로컬 도구·개인 설정·개인 세이브·원화·중첩 압축·백업·진단 사본은 제외한다. 호환 별칭·B/C컷·런타임 동적 풀은 보존한다. icon.ico도 포함한다.
3. 삭제 예정 5개를 실행 참조와 대조한다. 안전하게 원본으로 되돌릴 수 있는 교체본은 Full에서 원본으로 대체한다. 원본 자체가 필수인 경로는 무리하게 빼지 않고 예외·추후 결정으로 기록한다. WORK는 변경하지 않는다.
4. 사용자가 공급할 5개 결과 컷은 Full만 기존 공통 결과 컷으로 임시 호환 사본을 둔다. 새 그림으로 표현하지 않으며 경로와 교체 대상을 기록한다. 추가 아트 제작은 하지 않는다.
5. 빈 배포 경로를 확인 후 파일을 실제 복사한다. 하드링크·외부 심볼릭 링크 없이 해시 목록을 작성한다. 게임 구동 파일·라이선스·글꼴·JS·JSON·SND를 포함한다. 기존 문서의 잘못된/노후 수치 설명은 새 플레이어용 변경 내역으로 대체한다.
6. 현재 QSP를 그대로 포함한다. 최신 작업 직전 백업과 최근 패치를 고정해 정확한 패치 재생·멱등성·문법 경계·JSON 등록·배포 QSP 일치·Full 엔진 9경로를 검사한다. 별도 위치에서 실제 배포 구조 실행도 확인한다.
7. 기존 개인 세이브는 포함하지 않고 격리 엔진에서 전용 TC SAV를 생성한다. 수동 조작/기대 결과를 짧게 기록한다. 에이전트 검증과 미검증 수동 플레이를 구분한다.
8. 독립 리소스·배포 검토 결과를 반영하고 전파일 해시·제외 목록·출처와 임시자료 정리를 확인한다. ZIP·커밋·푸시는 하지 않는다.

주요 회귀 방지: 오래된 QSP 덮어쓰기, 필요한 호환 PNG 제외, 게임 아이콘 제외, 외부 원본컷 junction 의존, 삭제표시만 보고 활성 랜덤 풀 제거, 개인/API 설정 혼입, 세이브 원본 덮어쓰기, 이미지 미제공을 완성으로 오기, STATIC_PASS를 엔진 PASS로 오기.
