## 동작

- 확인창의 대상 변경 검사는 기존 type·선택적 ID·이름·초상 경로로 만든 길이 구분 문자열을 사용한다. 새 영구 변수·세이브 필드·마이그레이션은 없다. 서로 다른 정상 ID0 인물의 유형/이름/초상이 바뀌면 오래된 확인 링크는 거부한다. 모든 정보가 완전히 동일한 별도 인스턴스의 구분까지 보장하지 않는다.

- 조수 재능은 보존하며 수혜자는 발견 상태로 받는다. 기존 상충 특성 처리도 유지한다.
