# 선택지 서식 편집 · 2026-11-18

대사편집기의 기존 편집·검색·각본 UI를 유지하고, 「대사 수정·반영 → 선택지 서식」 패널을 추가한다. 현재 페이지의 선택지 하나를 고른 뒤 글꼴, 글자 크기, 자간, 줄 간격, 문단 간격 보정, 색상을 편집한다. 빈 값은 해당 항목의 직접 지정을 제거하며, 「게임 기본 서식으로」는 이 도구가 다루는 서식을 초기화한다.

## 사용

1. 대사를 검색해서 선택하고 「대사 수정·반영」을 연다.
2. 「선택지 서식」에서 같은 페이지의 대상 선택지를 고르고 값을 입력한다. 문단 간격은 기존 줄바꿈을 유지하는 아래 여백 보정(px)이며 음수는 좁히고 양수는 넓힌다.
3. 「선택지 서식 미리보기」를 확인하고 기존 승인 체크·반영 버튼으로 저장한다. 변경 기록에서 최신 수정부터 되돌릴 수 있다.

이 작업으로 운영 QSP 선택지의 서식을 일괄 지정하지 않는다. 사용자가 반영할 때만 해당 선택지의 HTML 서식이 QSP에 저장된다. EXEC 실행문, 게임 조건, 목적지, 문구, 원래 줄바꿈은 유지한다. 작성 중인 본문·대사 추가·선택지 추가 초안은 보존한다.

## 입력·출력·연결

- `choice-format.cjs`: QSP 문서와 원문 위치·해시로 현재 페이지의 HTML EXEC 선택지를 조회한다. 원문/선택지 인덱스/변경한 서식만 받아 선택한 anchor의 style만 바꾼 새 QSP 바이트와 최소 패치 조각을 반환한다. 게임 상태를 실행하거나 조건을 평가하지 않는다.
- `server.cjs`: `/api/choice-format/options`, 기존 `/api/preview`의 `choice-format` 작업과 `/api/apply`를 연결한다. 저장 직전에 다시 해시를 검사하고 기존 백업·최소 mods·되돌리기 경로를 사용한다.
- `choice-format-ui.js`와 `choice-format.css`: 패널·참고 미리보기·선택지별 세션 초안·승인 무효화·반영 후 화면 갱신을 담당한다. 미리보기는 현재 WORK의 게임 글꼴과 기본 크기를 읽으며 링크를 실행하지 않는다.
- `core.cjs`: 선택지 서식 전용의 줄바꿈 보존 옵션을 추가했다. 기존 문구 편집의 기본 동작은 유지한다.
- `choice-editor.js`: 미저장 서식도 통합 작업실의 편집 중 검사에 포함한다.
- `script-review.js`: 각본 검토에서 글꼴·자간·여백 등 새 서식도 안전한 미리보기에 전달한다.

숫자 필드는 px 또는 배수로 입력하며, 기존에 em·normal 등으로 작성된 다른 서식은 변경한 항목 외에는 유지한다. 문단 여백을 위해 도구가 삽입한 `display:inline-block`은 `data-jo9-choice-gap-display="1"`로 구분하므로 초기화할 때 작성자 지정 display를 제거하지 않는다. 기존 `data-jo9-choice`는 그대로 보존한다.

## 범위와 보존

설치 대상은 저장소 `tools/text-workshop`와 WORK의 `game/modtools/text-workshop`이다. Full, 배포 ZIP, 세이브, 게임 이미지·CSS, 운영 QSP는 수정하지 않는다. 이번 설치 전 코드와 파일별 해시는 `before/`와 `manifest.json`에 남긴다.

되돌릴 때는 원래 있던 파일을 `before/`에서 복원하고 이번 신규 모듈·CSS의 참조를 함께 제거한 뒤 도구 서버를 재시작한다. 서식 기능을 나중에 제거해도 이미 QSP에 저장된 서식은 일반 HTML/CSS이므로 유지된다.

## 검사

최종 검사 및 운영 화면 확인 결과는 `verification.json`을 따른다. 실제 게임 실행기의 최종 줄 배치와 시스템 글꼴 대체 결과는 이 편집기 기능 검사로 확정하지 않는다. 사용자가 실제 게임에서 해당 장면을 다시 열어 시각적으로 확인한다.
