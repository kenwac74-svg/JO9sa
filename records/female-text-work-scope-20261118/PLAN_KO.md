# 여주인공 텍스트의 작업 범위 제외

사용자 확정: 게임에 있는 여주인공 자료는 제거하지 않는다. 대사 전체 개편 등 기본 작업에서 제외할 수 있도록 한다. 게임 QSP·세이브·Full은 변경하지 않는다.

기본 대상은 남주인공과 공용 대사다. 확인된 여주 전용 모듈·현재 여주 번호101~124 전용 조건·전용 표/변수·여주 상태 문구는 기본 검색과 편집에서 제외한다. 혼합되거나 아직 전용 여부가 불확실한 항목은 구분 표시하고 자동 일괄 작업에서는 보류한다. 사용자가 제외 체크를 해제한 경우 해당 요청에서만 명시적으로 포함한다.

- 별도 분류 모듈과 규칙 JSON: 문서 해시별로 재분류하고 현재 소스의 조건·대입 대상을 사용한다. 과거 행 번호/오프셋만으로 보호하지 않는다.
- 서버: 검색·장면·각본/일괄 치환에 기본 범위를 적용하고, 실제 반영 직전에도 같은 범위를 검사한다. 기존 해시·백업·복구 규칙을 유지한다.
- UI: 기존 보기 옆 「여주인공 전용 제외」를 기본 체크한다. 범위 변경은 미리보기 승인을 무효화하되 본문·추가 원고·각본 초안은 보존한다.
- 프로젝트 지침: 직접 QSP 개편과 신규 작업에서도 같은 제외 원칙을 읽도록 기록한다.
- 별도 요청한 탐색 경로: `K:\doing\242JO9`는 비활성 2.4.2 백업 탐색용으로만 등록하며 자동 이동하지 않는다.

확인할 항목은 여성 NPC/노예 공용 문구의 오분류 방지, 여주 조건의 ELSE·고정 인물번호·동적 정의, 새 QSP/문구 변경 후 재분류, 일괄·각본 경로의 우회 차단, 명시 포함과 초안 보존이다. 운영 QSP/세이브 보존 해시를 확인한다.
