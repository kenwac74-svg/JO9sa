## 확정 구현
- 수치 변수 jo9_cruel_mercy 하나. 0=중립, 음수=cruel, 양수=mercy. 별도 상하한 없음.
- init_game에서 새 게임 시작시 0. 기존 세이브는 미정의 숫자 기본값 0을 사용. 불러오기 때 누적값을 초기화하지 않음.
- jo9_battle_fate의 choose에서 기존 승리/모드/phase/count/선택값 검증 통과 후, phase=2로 잠근 다음 1회 누적.

- 안개 일반전투의 처형도 -1. 비활성 살려주기 요청은 기존 규칙대로 거절되어 누적 없음.
- 화면 출력/지배력/매력/기타 보상 효과 없음. 가중치와 능력 보정은 미정.
- 안개경계에서 획득한 노예 해방은 향후 연계 대상으로 기록, 이번 구현에는 포함하지 않음.
- 이미 끝낸 과거 선택의 소급 누적 없음. 저장 파일 직접 수정 없음.

실제 사용자 세이브 UI 저장/불러오기 왕복과 모든 전투 화면 클릭은 미검증.

## 유지보수
입력: 기존 choose 호출의 args[1]=1 또는2. 반환값과 기존 전투처리는 그대로이며 영속 숫자만 변경.
의존: 기존 jo9_fate phase와 승리 검증. 새 로케이션이나 중복 방지 변수를 만들지 않음.
변경 위치: init_game 초기화, jo9_battle_fate choose의 choice 기록 직후.
초기화 블록만 제거하면 같은 프로세스 새 게임의 수치가 남을 수 있음. 선택 블록만 제거하면 기존 값은 남지만 추가 누적은 중단됨.
배포 폴더, 기존 세이브, 커밋/푸시는 변경하지 않음.
