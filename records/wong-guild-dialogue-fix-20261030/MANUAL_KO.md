## 최종 변경

`end_day_screen`의 웡 항의 분기만 변경했다. 기존 방문 서술과 항의·추가 안내를 공통 하단 화면이 읽는 `$text[0]`에 모아 전달한다. 두 번째 문구 끝에 단독으로 남아 있던 `</div>`는 표시 문자열에서만 제거하여 뒤의 추가 안내가 패널 밖으로 빠지지 않게 했다. 원래 문구 자체는 배열 1·2·3에 그대로 두었다.

유충 감염 재범의 원래 게임오버 분기는 기존 방출 안내인 `$text[3]`을 `$death`에 직접 전달한다. 원래 결말 여부나 발생 조건을 바꾸지 않는다.

## 입력·출력과 부작용

- 입력: 기존 `$text[1]`, `[2]`, 선택적인 `[3]`, 기존 질병·기생체 및 방문 상태. 입력 상태의 계산식과 제재는 이번 패치에서 수정하지 않는다.
- 출력: 정상 항의에서는 하단 패널용 `$text[0]`, 재범 결말에서는 `exit`에 전달되는 기존 방출 문구.
- 부작용: 설명이 표시되는 변화뿐이다. 평판 차감, 주인공 수치, 카운터 초기화, 재경고 표시, 당일 방문 완료 처리, 다음 날 초기화는 원래 코드와 같다. 새 저장 변수·로케이션·이미지·CSS·공통 버튼 처리를 추가하지 않는다.
- 호출: 하루 종료 `end_day_screen`의 감염 납품·재매입 후속 처리. 표시 소비자는 같은 로케이션의 `:loop`에 있는 `<div id="text">`다. 결말은 기존 `#dynamic`의 `$death`가 `exit`로 전달한다.
- 의존성: 기존 배열 1·2·3을 준비하는 항의 본문, QSP `$replace`, 기존 `:loop` 출력과 `$objsel`의 진행 버튼. 이 패치는 다른 이벤트의 대사 배열을 일반적으로 변환하지 않는다.
- 분리·철회: `WONG_GUILD_NOTICE_TEXT_20261030`을 제거하면 일반 항의가 다시 빈칸이 된다. `WONG_GUILD_NOTICE_FATAL_TEXT_20261030` 인자 수정을 제거하면 재범 결말의 사유가 다시 빠질 수 있다. 롤백할 때는 정확한 패치 역변환 또는 설치 직전 `before.qsp`를 사용하고 이후 다른 수정이 있는지 확인한다. 질병·평판 처리나 공통 진행 버튼은 철회 대상이 아니다.

## 저장 호환과 범위

전후 로케이션은 275개로 같고, `end_day_screen` 외 본문·설명·로케이션 행동은 동일하다. 원래 SAV 파일을 수정하지 않았다. 같은 사건을 재무장하거나 이미 차감된 평판을 돌려주는 처리는 넣지 않았다. 따라서 이미 지나간 사건의 누락된 대사를 소급 복구하지는 않는다.

바로 뒤의 안젤리카 항의에도 같은 표시 불일치가 있으나 이번 승인은 웡 복구이므로 변경하지 않았다. 관련 범위 조사는 별도 `dialogue-slot-mismatch-audit-20261030`에 기록한다. 새 거래 없이 매일 방문한다는 별도 제보 원인은 이번 표시 수정으로 해결됐다고 주장하지 않는다.

## 검증

수정 전 실제 FastQSP의 웡 사건에서 하단 DOM 글자 수 0과 정상 제재 실행을 확인했다. 표시를 요구하는 회귀 검사는 이 기존 결과에서 실패했다.

수정 후보의 질병 1건·3건, 유충 첫 경고 1건·3건, 질병과 유충 동시의 5사례에서는 하단 서술·항의·필요한 추가 안내가 모두 보인다. 129~177자의 문구가 기존 740×185 패널을 넘지 않으며 원래 평판·카운터·방문 상태도 일치했다. 재경고 결말 1사례에서는 기존 방출·Game Over 문구와 day=0을 확인했다.

재경고 첫 진단의 timeout은 후보 결함이 아니라 sparse 저장값 priming의 동적 함수 슬롯 복원 문제였다. 원래 SAV의 DEATH[0]은 정상 함수이고 EGEYA 대사는 index 1이다. 진단은 여러 줄 0번 함수를 건너뛰고 별칭만 복원해 첫 슬롯 위치가 달라졌으므로, 그 단독 fixture에서 원래 `#dynamic`을 다시 호출한 뒤 실제 `$death`→`exit` 경로를 검사했다. 초기 실패·보정 근거·원시 로그를 모두 남겼으며 게임 코드의 동적 함수나 전역 namespace는 바꾸지 않았다. 이 검사를 실제 SAV의 전체 UI 불러오기 검사로 표현하지 않는다.

독립 코드 리뷰는 웡 이외 범위 불변, 원래 문구 보존, 제재·상태·분기 불변을 확인했다. 출고 검사기는 구조·왕복·CRLF·주석 경계·선언형 패치 재생/멱등성과 실제 FastQSP 주요 9경로를 통과했다. 전체 게임의 모든 동적 분기를 증명하는 검사는 아니다.
