# 대사별 이미지 연결 계획

확정: 새 페이지를 추가하지 않고, 선택한 대사의 해당 단계에 표시할 이미지를 지정한다. 이미지 교체기의 새 경로 저장은 자료 등록 기능으로 유지하고 대사 편집기에서 연결한다.

- 선택 대사/사용 장면/단계와 연결할 이미지를 미리 보여 준 뒤 명시적 반영 버튼을 제공한다.
- 기존 PIC 폴더 탐색으로 이미지를 고르거나, 기존 이미지 교체기를 빈 대상으로 열어 새 이미지를 등록한다. 등록 성공은 이미지 선택까지만 하며 QSP는 연결 반영 때 바뀐다.
- 현재 장면의 해당 단계 $special_image_full만 설정한다. 다른 단계/대사/선택지/효과/소리/배경을 수정하지 않는다. 같은 대사 배열의 다른 사용 장면을 변경하지 않는다.
- 흐름 분석으로 해당 페이지와 실제 출력기를 확인한다. 정적으로 확인되지 않는 별도 출력기/중첩 페이지 연결은 이유와 위치를 표시하고 잘못된 범위를 추측해 기록하지 않는다.
- 기존 QSP 미리보기 해시/백업/변경 기록/되돌리기/최소 mod 내보내기를 재사용한다. 실제 WORK QSP는 개발 중 반영하지 않는다.

순서: 회귀 검사 실패 확인 → 연결 준비 모듈/미리보기/반영 API → 기존 흐름 이미지 조회 확장 → HTML 선언/클라이언트 연결 → 격리 API 및 실제 브라우저 검증/엔진 핵심 검사 → WORK 도구/소스 설치 및 서버 재시작 → 보고/인계/임시자료 정리. Full/음원/배포/커밋푸시 제외.
