## Global Constraints

- 원본 JO9O·Full·사용자 세이브·기존 ZIP은 변경하지 않는다. 커밋·푸시하지 않는다.
- WORK의 현재 수동 변경을 보존하고 추적 소스/원장만 최신 현물에 맞춘다.
- 모드툴·작업 원화·백업·미승인 기획은 게임 패치에서 제외한다.
- 기본 전신23개와2071 분리 호환6개는 해시 중복 여부와 관계없이 주소를 유지한다.
- JSON 이름 변경25개는 정확한 수동 정리 명세와 검증을 제공하며 설치기나 삭제 스크립트를 추가하지 않는다.
- 새 버전 번호를 만들지 않고 2.4.1 추가 패치, 2026-11-05로 표시한다.
