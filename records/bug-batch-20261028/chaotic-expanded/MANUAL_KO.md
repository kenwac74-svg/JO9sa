# 카오틱 에센스 우선순위 확장 — 후보, WORK 미적용

사용자 승인 범위에 맞춰 부정 일반 특성이 있으면 그중 하나를 무작위 제거하고, 없을 때만 상황형 일반 특성 중 하나를 제거하도록 준비했다. 가격900·성공 시1회분 소모는 유지한다. 대상은 기존 slave/assistant 두 역할이며 상태·칭호·확실한 긍정 특성을 보존한다.

패치는 `2026-10-28_chaotic_priority.json`이다. 기준 WORK 해시는 `dbe2948f7c827d8fc82ccd32b2c3453626d181a59eb744e015fa66a3846280ae`, 단독 후보 해시는 `1d70c6af8345a1822f7d8e2995816d9c9fc0858f06d4c3ba18977ad0c94b90b6`. 다른 승인 패치와 통합하면 전체 후보 해시는 달라진다. 이 파일을 저장소 mods 및 WORK에 반영하지 않았다.

## 후보 분류

기존23개 부정 축을 유지하고 불감증의 표준값 `nymphomania=-1`을 추가해24축으로 만든다. 선택된 불감증은 `nymphomania_xp`와 발견 상태를 함께 정리한다. 발견 여부와 관계없이 실제 보유값이 후보다.

상황형은 아래10축·21표시 변형이다. 기존 일반/칭호 분류와 실제 효과를 확인했으며 현실의 가치판단으로 분류하지 않았다. 한 축의 여러 표시 변형은 동시에 여러 후보로 넣지 않는다.

`passion_fame=1`은 기존 관심추구 통합의 별칭이므로 새 상황형 후보로 중복 등록하지 않는다. 기존 활동 통합도 기존 긍정/부정 판정을 사용한다. 현재 효과에 맞춰 통증 내성·피학 성향의 양수, 노출 성향2, 양성애1, 환경 기호/내성의 양수는 긍정으로 보존한다.

**천재는 명백한 고가치 긍정 특성으로 보존한다.** 특정 분야 보정 하나를 이유로 상황형으로 내리지 않는다. 절세미인·명기·건강체질·전투 특성·긍정 적성·긍정 성격도 삭제 후보가 아니다. 기존 일반/칭호 분류표가 일반 항목으로 다루더라도 이번 도구의 긍정 보호가 우선한다.

`arena_level`, `has_ride_win`, `jo9_versatile`, 승수·초기화·반항 해결 이력과 임신·상처·문신·수유 등의 상태는 보존한다. 일반 성향에는 선천 보유와 보유 중 XP 획득 양쪽 경로가 있지만 출처 저장값이 없다. 따라서 이 변경은 기존 성취·칭호 키를 보호하며, 일반 성향의 획득 이력을 추측해서 별도로 보호하는 새 설계가 아니다.

## 함수와 보조값

기존 `jo9_chaotic`의 `count(role)`, `apply(role)`, `use(role)` 인터페이스를 유지한다. 새 location과 영구 상태 키가 없다.

- `count`: 현재 우선순위에서 선택 가능한 후보 수를 반환한다. 부정이 있으면 부정 수, 없으면 상황형 수다. 인물·재고를 바꾸지 않는다. 기존 노예·조수 메뉴가 같은 helper의 `>0`을 사용하므로 표시와 실행 범위가 같다.
- `apply`: 성공1/무처리0. 부정 후보 배열을 먼저 만들고, 그 수가0일 때만 같은 local 배열에 상황형을 넣는다. 선택된1축만 중립으로 바꾸고 필요한 발견값·발현 XP를 정리한 뒤 재고1을 차감한다. 둘 다 없거나 재고가 없거나 대상이 유효하지 않으면 무소모다.
- `use`: 기존 apply를 호출하고 제거된 특성명·남은 수량 또는 무소모 안내를 표시한다. no-eligible 안내도 부정·상황형 범위로 바꿨다.

선택된 원본 축의 `_revealed`, nymphomania/perversion의 대응XP, homosexualism의 `lesbian_xp`, compassion의 `compassion_xp`를 정리한다. 기존 관심추구/활동 통합 제거 helper, 산만함·옹졸함의 보조값 정리는 유지한다. 다른 기술XP·현재 지성·기초 능력·실제 부정 기억·칭호·승수는 초기화하지 않는다. 기존 발현 경로로 나중에 다시 생기는 것을 막는 영구 면역은 만들지 않는다.

metabolism은 본체값3과 발견값0으로 돌린다. 실제 `$indep_atr`에 포함되지 않고 별도 metabolism rate/XP 원천도 없다. 미사용 rate 키를 새로 만들지 않는다. 실제 일일 열량 함수와 속성 재계산 뒤에도3이 유지되는 것을 두 역할에서 검증했다.

비표준 값은 후보로 삼지 않는다. 기존 부호형 부정 판정도 표준 -1만 허용하도록 좁혔다. 보류된 voice2 등은 그대로 둔다. 관심추구 통합의 본체값이 비표준이면 기존 통합 remover가 그 값을0으로 덮지 않도록 해당 통합축을 건너뛴다. 그 외 별칭의 미확인 값 역시 제거 helper가 수정하지 않는다.

## 변경과 의존성

7개 편집은 `jo9_chaotic`, `menu_form`, `pharmacy` 세 location에만 있다. `CHAOTIC_PRIORITY_20261028` 표식과 패치 ID로 찾을 수 있다. 메뉴·상품 설명은 “부정 우선, 없으면 상황형; 확실한 긍정/성취·칭호·상태 보존”으로 맞췄고 세부 효과 수치를 상품 설명에 추가하지 않았다. 구매의900차감·재고1추가·사용 후 연구실 공간 재계산은 기존대로다.

menu_form/pharmacy의 편집은 각 상품·사용 문구 주변만 치환한다. 다른 소문 메뉴 변경과 통합할 때 baseline 전체 menu_form을 덮어쓰지 않는다. helper만 분리하면 메뉴의 대상 수와 실행 결과가 다시 예전 부정 전용 범위가 되므로 세 위치를 한 변경으로 반영해야 한다.
