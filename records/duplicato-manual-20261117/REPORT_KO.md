# 듀플리카토 에센티아 설명서 항목

사용자 요청에 따라 기존 마법 설명서 왼쪽 열의 센텐티아 베리타스와 뒤로 사이에 듀플리카토 에센티아를 추가했다. 기존 전용 아이콘 `content/pic/ui/legacy_overhaul/Duplicato_Essentia.png`를 사용한다. 왼쪽 6행, 오른쪽 기존 7행이며 기존 항목과 배치를 유지한다.

설명은 기존 도움말의 2페이지 진행 방식으로 나누었다. 1페이지는 효과·시전 조건·비용, 2페이지는 사용 제한·상충 특성과 재능 목록이다. 표시 본문은 각각 180자와 266자다. 조수에게서 발견한 긍정 재능 한 가지를 노예에게 복사하는 효과, 조수 재능 보존, 마법력 B등급 이상, 900스파크, 세 참가자 각각 행동력 1, 두 인물의 상호 친밀도 각각 40 이상, 하루 한 번과 수혜자 평생 한 번, 기존 동일 긍정 재능 중복 불가, 상충 특성 제거 및 사전 확인창을 기재했다. 실제 지원하는 14종을 기존 게임 표시명으로 나열했으며 예민한 미각도 포함했다. 스토리 습득 경로는 밝히지 않았다.

기존 세이브는 `$spell_book` 메뉴를 캐시하므로 설명서를 열 때 그 메뉴만 새로 읽는다. 기존 `#options`의 선택적 메뉴 재생성 방식과 동일하게 `jo9_duplicato_spellbook` 진입점으로 해당 블록에 바로 이동한 뒤 끝에서 반환한다. 다른 대화·상점·도서관 메뉴를 재생성하거나 저장값을 추가하지 않는다. 상세 설명은 `interaction=62111`의 기존 도움말 페이지 방식으로 표시한다. 기존 마법의 사용 조건·비용·캐릭터·습득 또는 사용 기록은 바꾸지 않는다.

수정 로케이션: `#options`, `interaction`. 현재 WORK의 수동 편집과 앞서 추가한 프리실라 완료 효과를 보존했다. WORK와 추적 QSP 및 두 해시 명세, 선언형 mods와 이 기록만 저장했다. Full·배포 ZIP·개인 세이브·이미지 파일·도구는 수정하지 않았다. 커밋·푸시는 하지 않았다.

검증: QSP 바이트 왕복, 변경 역적용과 선언형 패치 재생, 다른 모든 로케이션 보존, 수정 로케이션의 CRLF와 주석 경계 검사. QSP WASM 5.8.0에서 기존 캐시를 가진 설명서 진입→메뉴 재생성→실제 메뉴 포맷터를 실행해 새 링크·아이콘·기존 항목을 확인했다. 새 도움말 분기의 실제 문자열과 비용·습득·사용 기록 불변도 확인했다. 목표 검사 2개 통과, 엔진 오류 0. 게임 EXE 육안 배치와 전체 플레이는 확인하지 않았다.

일반 EXE 확인 경로: 집의 주인 마법 목록 → 마법 설명서 → 듀플리카토 에센티아. 새 항목의 아이콘과 설명을 확인하고 뒤로가 기존 설명서로 돌아오는지 확인한다.

결과 SHA-256: `6c55e459be43359b50660344c936a4843c3a470c8fc89ba96d3927d27620cda6`.
