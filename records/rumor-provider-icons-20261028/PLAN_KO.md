# 소문 제공자별 기존 메뉴 아이콘 연결

**Goal:** 소문 듣기·이전·다음 메뉴에 스컵스/바텐더/아네스의 기존 메뉴 아이콘을 표시한다.

**Architecture:** jo9_buyer_rumors의 기존 provider 인수를 기준으로 지역 LOCAL 아이콘을 선택하고3개 $menu 호출의 이미지 인자만 바꾼다. 구 저장에서 이미 열린 바텐더/아네스 결과 화면은 $ongload 끝에서 view로만 다시 표시해 구매·추천을 반복하지 않는다. 새 로케이션·영구 저장 키·PNG·JSON·UI는 없다.

**Spec:** 사용자 승인 “진행해”. skups→menu_item_services, barman→menu_item_preferencesbar, anes→menu_item_anes.

**Baseline:** f0911bef8f53ef1464edc3d107beccaca3af90c7f0368a4b7df92f7a6082e1b2.
