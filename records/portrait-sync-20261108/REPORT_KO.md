## 제작과 적용

사용자가 선택한 “전신 얼굴 크롭·테두리 코드 합성” 방식으로 처리했다. AI로 얼굴을 다시 그리지 않았다.

-31명: 현재 전신의 얼굴·머리 부분을 추출하고 컬러·흑백·세피아3종을 같은 크롭으로 생성했다. 원래 경로와 각 파일의150×150 또는151×150 크기를 유지했다. 경로별 원본 프레임이 있으면 바깥5px를 그대로 보존했다.
- 테두리 기준은 기존 게임 초상의 프레임3종이다. 새 프레임은 참조 초상에서 바깥5px만 복사했다. 배경·필터는 기존 이미지 편집기와 같은 어두운 배경/흑백/세피아0.8 기준을 사용했다.
- 프레임만 보완한15개는1447·1448·1450·2339의 초상3종과 wilhelmine 초상3종이다. 바깥5px 외 중앙 픽셀은 완전히 동일하다. 이미 있던 파일에 프레임만 넣었으며 새 인물 번호를 등록하거나 등장 범위를 바꾸지 않았다.
- WORK `game/content/pic/...`와 저장소 `assets/content/pic/...`를 맞추고 개인 이미지 패치 원장, runtime-source 명세, WORK/seed 체크리스트의 크기·해시를 갱신했다. WORK 목록에서 빠졌던2339 초상3행은 시드의 기존 행을 사용해 복원했다.
- 전신 이미지, 인물 JSON, QSP, 저장 파일, 사용자 체크 태그는 수정하지 않았다. Full·정식 배포 ZIP·커밋·푸시는 작업하지 않았다.
