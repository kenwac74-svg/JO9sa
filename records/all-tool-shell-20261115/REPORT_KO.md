# 공백 제거·전체 도구 화면 통합 — 2026-11-15

사용자 요청: 대사 편집 제목 아래 불필요한 공백을 없애고 다른 도구도 같은 방식으로 통합한다. 후속 지시로 이미지 작업의 최상위·하위 탭 구성은 유지한다.

## 반영

- ‘별도 창에서 열기’를 각 도구의 전용 줄에서 공통 페이지 제목 옆으로 옮겼다. 대사 화면은 제목 영역 끝과 내용 시작이 모두 y=143이며 별도 빈 툴바 높이는 0이다.
- 모든 공통 페이지의 제목 여백·설명 간격을 줄이고 반복되는 부제·바닥글을 정리했다. 프레임 테두리는 없앴다. 스타일 로딩·제목/탭 크기 변경 뒤 높이를 다시 맞춰 화면 하단에 계산 오차로 공백이 남지 않게 했다.
- 이미지 체크리스트·이미지 교체·폴더 비교·게임 DB·작업 일정·사운드 목록을 통합 편집기의 회색/금색 팔레트로 맞췄다. 도구 안의 중복 제목을 숨기고 버튼·입력·표·스크롤 색상을 맞췄다. 체크리스트의 고정 파란 배경·흰 입력창도 통합 화면에서만 재정의했다. 경고·저장 상태는 유지했다.
- 이미지 상위 3개 도구 탭과 체크리스트 내부 5개 탭의 이름·순서·선언은 그대로다. 선택 탭은 금색이다. 이미지의 각 도구는 프레임을 따로 보존해 오갈 때 화면 상태가 사라지지 않게 했다. 이미지 교체기는 숨겨진 프레임도 연결을 유지해 초기 무접속 종료를 방지한다.
- 기존 카탈로그 원문 디자인은 유지하고 열람 화면 바깥의 중복 제목·링크 줄만 정리했다. 캐릭터·산식·인터뷰 등 원래 통합 디자인인 화면은 공통 제목 간격만 맞췄다.

## 구성·데이터 보존

`tools/modding-hub/integration.mjs`는 공통 헤더 링크, 빈 툴바 제거, 각 이미지 도구의 프레임, 화면 높이 조정을 담당한다. `integration.css`는 공통 여백/프레임 스타일이다. `embedded-tools.css`가 다른 도구의 공통 통합 팔레트 원본이고 `update-embedded-skins.py`로 HTML/폴더 비교 CSS/대사 도구의 피부 사본에 반영한다.

대사 서버의 `embedded-shell.cjs`는 체크리스트와 일정의 HTML 응답에 표시용 CSS/클래스 설정만 삽입한다. 기존 검색·저장·승인·API 처리와 원본 데이터는 유지했다. 폴더 비교는 기존 app.js 끝에서 표시 클래스만 설정한다. 독립 창에는 workspace 질의가 없으므로 원래 UI가 나타난다. 일정 HTML을 내보내 다시 여는 경우에도 표시 클래스는 현재 주소에 맞춰 해제된다. 사운드 목록은 등록된 파일의 응답만 꾸미며 원본 파일은 그대로다.

WORK/modtools에는 도구 코드만 동기화했다. 체크리스트 상태, 일정 JSON, DB 아이디어, 게임 QSP·JSON·이미지·SAV·배포 ZIP은 수정하지 않았다. QSP 변경 경고를 이유로 동기화를 실행하지 않았다. 작성 중인 창은 강제 새로고침하지 않았다. 기존 전용 앱은 내용을 저장하고 닫았다 다시 열면 새 서버/화면을 함께 사용한다. 커밋·푸시는 하지 않았다.

## 확인

JS/Python 구문 확인. 메뉴와 이미지 탭 선언 동일. 공통 스킨을 제거하면 DB/이미지 교체 HTML의 원래 본문이 그대로이고, 대사 서버의 표시용 래핑을 제거하면 기존 서버 코드와 동일하다. WORK QSP는 매력 수정 후 f2bb7224… 그대로다.

브라우저에서 대사/체크리스트/이미지 교체/폴더 비교/게임 DB/일정/사운드 목록 표시를 확인했다. 공통 배경 rgb(19,21,23), 체크리스트 입력 배경 rgb(19,21,23)·글자 rgb(233,233,229), 안쪽 중복 제목 숨김을 확인했다. 이미지의 3개·5개 탭은 유지했다. 데스크톱 1000px 높이에서 이미지 내용 하단 988px로 12px 여백을 유지한다. 임시 브라우저 크기는 원래대로 복구했다. 스타일 작업이라 게임 전체·저장·파일 교체 실행을 반복하지 않았다. 데이터 변경 버튼과 외부 API 전송은 누르지 않았다.

화면: `dialogue-compact.jpg`, `image-compact.jpg`. 상세 `verification.json`. 전후 해시·소스 차이·원본 gzip을 보존했다. 복구는 변경 후 사용자 수정을 대조해 해당 표시용 블록만 역적용한다. 공용 CSS/모듈을 지울 때에는 호출과 정적 연결도 함께 제거해야 한다. 재현 가능한 임시 편집 사본은 정리했다.
