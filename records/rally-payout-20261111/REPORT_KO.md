# 랠리 캐릭터별 배당 감소 반영 — 2026-11-11

사용자 승인 배당표를 현재 WORK와 추적 QSP에 반영했다. Full 배포본·음원·커밋·푸시는 변경하지 않았다.

## 동작과 사용

에로살롱의 기존 랠리 메뉴를 사용한다. 메뉴에 선택한 캐릭터의 다음 회차와 우승 순이익이 표시된다. 기존 저장 메뉴 문자열은 `$ongload`에서 해당 줄만 갱신한다.

| 실제 참가 회차 | 우승 순이익 | 패배 순손실 |
|---|---:|---:|
| 1~3 | 300 | 100 |
| 4 | 275 | 100 |
| 5 | 250 | 100 |
| 6 | 225 | 100 |
| 7 | 200 | 100 |
| 8 | 175 | 100 |
| 9 | 150 | 100 |
| 10 이상 | 125 | 100 |

실제 경기 추첨 직전에 참가금100을 한 번 차감한다. 우승하면 참가금100과 표의 이익을 돌려주고, 패배하면 추가 차감하지 않는다. 10회 이상 고숙련 경로의 기대 순이익은 `(125×2−100)÷3=50`이다. 기존 네 경로의 승률·명성 계산·체력 및 기타 결과 효과는 유지한다.

승패 모두 실제 참가 횟수를 올린다. 관람·경기 전 이탈은 올리지 않는다. 기존 복종 거절의 참가금100 손실은 유지하고 참가 횟수에는 넣지 않는다. 구세이브의 과거 참가 횟수는 복원할 자료가 없어0부터 시작한다. 결과 재진입은 돈·명성·체력 효과를 반복하지 않는다.

일반 EXE 확인: 에로살롱에서 선택 캐릭터의 랠리 회차/금액 표시 → 참가 결과의 실제 잔액 → 다른 캐릭터로 바꿨을 때 독립 회차를 확인하면 된다. 실제 GUI·사용자 기존 SAV 파일은 직접 확인하지 않았다.

## 입력·반환·저장 상태

신규 `jo9_rally` 로케이션은 `FUNC`로 호출한다. `GS`로 호출하면 호출자에게 RESULT가 반환되지 않으므로 반환을 읽는 호출을 바꾸면 안 된다.

| 명령 | 반환 | 효과 |
|---|---|---|
| quote_round / quote | 현재 예약 경기 또는 다음 회차 / 순이익 | 조회만 |
| prepare | 0 불가, 1 준비, 102117~124 미정산 결과 | 자격 검사·개별 번호 부여·새 경기 준비 |
| draw, 102113~116 | 0 불가 또는 확정 결과 | 참가금·횟수·배당·승패를 한 번 확정 |
| pay, 결과번호 | 1 최초 정산, 0 거부/중복 | 우승금 반환, 결과 화면의 기존 부수효과 실행 허가 |
| refuse | 1 최초 거절, 0 중복/불가 | 기존 거절 비용 한 번 차감 |

`slave['jo9_rally_entries']`와 `slave['jo9_rally_serial']`은 캐릭터 배열에 저장한다. 템플릿 ID나 이름이 같은 인물을 구분하기 위해 개별 serial을 사용한다. 기존 전체 배열 복사 방식으로 조수 등 역할을 이동하면 함께 이동한다. 전역 `jo9_rally_next_serial`은 번호 발급기, `jo9_rally_match`는 참가자·회차·순이익·결과·단계(0 준비,1 미정산,2 정산,3 거절)를 보관한다. 진행 중인 다른 캐릭터의 경기는 덮어쓰지 않는다. 참가금으로 잔액이0이 되어도 본인의 미정산 결과를 재개할 수 있다.

호출자는 `interaction_city`의 신청102102·거절102103·추첨102113~116·결과102117~124, `#options` 메뉴, `$ongload`의 두 메뉴 캐시다. 기존 `jo9_contest_fame`에 의존한다. 참가기록을 수동으로 지우면 배당이 초기화된다. 기능 제거 시 호출부와 저장 상태를 함께 정리해야 하며, 미정산 참가금과 결과를 먼저 처리해야 한다. 차기 전체 마이그레이션 설계 시 이 필드도 유지/정리 범위를 검토한다.
