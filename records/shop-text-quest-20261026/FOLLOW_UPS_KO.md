# 추가 관찰 — 동작 변경 미승인

이번 수리에서는 아래 원본 동작을 바꾸지 않았다. 사용자 보류 결정으로 표시하지 않으며 후속 검토가 필요한 관찰이다.

- 랠리의 낮은 복종 거절 코드를 뒤의 독립 기술 구간 if가 덮어쓴다. 보호 원본 두 스냅샷에도 같다.
- 정상 등급 밖인5 초과 기술값 일부 조합은 랠리 분기에서 빠질 수 있다. 현재 정상 생성 범위를 벗어난 값의 실제 플레이는 미재현이다.
- 랠리 참가 메뉴의 행동력 조건2와 결과 소비3이 다르다. 우승 잔액 변화는+300, 패배는-100으로 별도의 참가 시점 차감은 해당 경로에 없다.
- 기적의 연고 메뉴 가용 조건은 보유금>1200이지만 구매 실행은>=1200이다. 이번에는 아이콘 표시만 고쳤다.
- 관련 옛 남성 상태3문구의 제목 형식과 정신붕괴 성별 설명 차이는 별도 기록이다. 실제 공백 소실은 JS 표시 경로에서 수리했다.
