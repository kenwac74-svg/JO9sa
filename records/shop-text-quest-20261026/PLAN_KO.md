# 상점·설명·아그라바 제보 확인

- 현재 WORK를 새로 읽고 직전 QSP 및 변경 대상 자원을 백업한다. 기존 세이브·원본·Full·엔진을 보존한다.
- 우유 메뉴의 중복처럼 보이는 가격 표기만 제거하고 원래 질문 동작을 유지한다.
- 물약상점의 회색 아이콘 누락을 실제 자원/생성 문자열부터 고치고 기적의 연고 계열의 기존 효과를 보고한다.
- 집 마법약 두 열 첫 행과 우유 보유량 숫자를 기존 UI 범위 안에 정렬한다.
- 하단 설명의 실제 공백 렌더를 수정하고 입수처·보상 수치 스포일러를 문구에서 제거한다. 성장·보상·랠리 확률은 바꾸지 않는다.
- 랠리 우승 조건/확률을 실제 소스에서 별도 보고한다.
- 아그라바 tolerant 조건과 파멜라 검은 화면 제보는 우선 조사·재현한다. 퀘스트 조건 완화나 새로운 교육은 임의 구현하지 않는다.
- 수정 경로의 실제 엔진 검사, 공식 출고 검사, 정확 재생/재적용을 거쳐 WORK만 반영한다. 커밋·푸시·배포 동기화는 하지 않는다.
- 핵심 보고서·변경 명세·재현 스크립트를 보존하고 재생성 가능한 진단 사본을 정리한다.
