# 명성 TIP 장소 안내 후속 수정 — 독립 리뷰

결론: 조치가 필요한 발견사항은 없다. 최종 후보는 기존 서두와 장소 안내까지만 남기며, 질적인 반복 보상 설명과 3승 출전 제한 설명도 제거한다. 명성 지급·성장·승률·퀘스트 조건은 변경하지 않는다.

검토 대상은 `tip-final.json`, `tip-patch.json`, `tip-place-only.cjs`와 그 manifest가 가리키는 기준·후보 QSP다. 다른 작업 범위의 검사를 추가하거나 네이티브 실행을 시작하지 않았다. 작성한 파일은 이 문서 하나다.

| 대조 항목 | 독립 확인 결과 |
|---|---|
| 기준 SHA-256 | `8d388588aaebe33ba34dbcdde66f55a4b29beeb12467ba48b3638cda9802238c` |
| 최종 후보 SHA-256 | `79f17f61720224779583bdbb6d974ec432f2da7423fdd4d89b38b0cd3c387b21` |
| 변경 필드 | `$ongload`, `#help_msg`의 본문 2개만 변경 |
| 로케이션 | 273→273, 이름·순서 동일 |
| 고정 패치 | old 블록 각각 정확히 1회 일치, 두 조각의 메모리 재생 결과가 후보 전체 바이트와 동일 |
| 왕복 | 후보 parse/serialize가 후보 바이트와 동일 |
| 실행 코드 | 변경 조각에서 JO9 MOD 주석 및 문자열 리터럴을 제외한 코드가 전후 동일 |
| 구조 | 새 로케이션·영구 키·revision·호출 없음 |

최종 TIP은 다음과 같다.

> [로마 인지도 TIPS]  
> 인지도가 전부는 아닙니다. 이것에 개의치 않고도 훌륭한 노예를 육성할 수 있습니다.  
> 명성을 알릴 수 있는 곳: 콜로세움의 경주와 투기 대회, 동부 구역의 캣파이트 클럽과 아마란스 살롱의 랠리, 안개 경계 순찰.

`#help_msg`의 기존 `$слава_совет` 대입 문자열만 위 문구로 교체한다. 장소 목록은 그대로이며, `랠리는 우승으로…` 문장과 캣파이트의 보상·3승 설명이 남지 않는다. 두 변경은 `FAME_PLACES_ONLY_20261026_0/1` 표식으로 구분되고 기존 바깥 표식은 보존된다.

`$ongload`의 기존 캐시 조건은 `if instr($слава_совет, '명성을 알릴 수 있는 곳:') = 0: gs '#help_msg'`다. 이전 숫자 TIP과 중간 `8d3885…`의 `명성을 쌓을 수 있는 곳:` 문구에는 새 표식이 없으므로 기존 초기화 경로로 갱신된다. 최종 TIP에는 새 표식이 있어 이 조건 때문에 매번 다시 초기화하지 않는다. 검사 함수, 비교값0, 호출 대상 `#help_msg`는 같다.

명성 보상·성장·랠리 확률·퀘스트 조건을 실행하는 본문은 이번 2개 변경 외에 바이트 차이가 없다. 문자열을 제외한 실행 코드도 그대로여서 새 수치 조정이나 조건 완화가 포함되지 않았음을 확인했다.

이는 독립 정적 리뷰 결과다. GUI 저장·불러오기나 최종 합본의 공식 9개 엔진 점검, 새 native-cache 실행 결과를 통과한 것으로 주장하지 않는다. 해당 실행 결과는 root의 별도 기록을 따른다. 현재 WORK 반영 여부도 이 읽기 전용 리뷰에서 변경하지 않았다.
