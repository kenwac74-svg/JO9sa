## 검증

고정된 최종 근거는 `final-validation.json`이다. 현재 후보와 최종 CSS를 사용한 관련 10경로는 실제 엔진 80판정·실패 0, Qt DOM 10관측이다. 소개·시험 전후 강의 선택·소녀 선택의 로드 핸들러 4경로는 28판정·실패 0, Qt DOM 4관측이다. 핸들러를 두 번 실행해 저장된 이름·능력치·소지품·선택·페이지·강의·시험 값과 원 HTML의 보존을 확인했다.

17행 메뉴의 실제 Qt 행은 x26/x361 두 열, 330×62이며 마지막 행이 y771 이내다. 버튼 클릭 영역이 행과 일치하고 줄 넘침이 없다. 물약 메뉴의 공통 직접 자식 열 배치도 별도로 확인했다.

원본과 후보의 강의 선택·수업·설정 세 화면에서 보이는 문구, 27개 실제 링크와 콜백 순서, 날짜·돈·배우·선택·페이지·강의·시험 값을 대조했다. 정적 비교에서도 원래 444개 콜백과 103개 대사 대입을 보존했다. 선언형 패치를 역으로 적용하면 원래 QSP 바이트가 재현된다.

공식 출고 검사는 이번 패치 1개, 직전 백업, 공개 TC09 상태의 복사본, 현재 cache revision 3으로 실제 엔진 9경로 모두 PASS다. 구조·문법 줄 경계·표식 경계·패치 재생 및 재적용·입력 해시 보존 검사도 PASS다. Full은 동기화 대상이 아니므로 mirror 검사는 생략했다.

초기 후보의 27개 정상 실행 관측은 별도의 과거 근거이며 최종 108판정에 합산하지 않는다. 그 뒤 독립 리뷰에서 발견한 메뉴 재대입과 물약 래퍼 문제는 최종 후보에서 관련 경로를 다시 검사했다. 초기 비동기 로드 진단의 세 미완료 건은 보존 HTML의 검사 스크립트 재실행 문제였다. 검사 코드를 원 렌더러 뒤의 동기 핸들러 실행과 분리하고 콜백 nonce를 즉시 소비해 검증을 완료했다. 프로덕션 코드에 검사 스텁은 넣지 않았다.

실제 GUI의 SAV 불러오기, CRC 호환, 저장된 모든 스크립트의 복원은 미검증이다. `OPENGAME`을 실제 SAV 로드 성공으로 세지 않았다. 실제 Qt DOM·이미지 디코딩과 root의 별도 정적 검토 PNG는 다른 근거다. 모든 게임 분기나 동적 코드 전체를 검증했다는 뜻은 아니다.
