# 의상·장비 목록 침범 수정

긴 목록이 하단 설명창을 덮어 가려진 항목을 클릭할 수 없는 문제를 수정했습니다. 게임 엔진의 div 기본값이 display:table이어서 기존 height를 넘겨 목록이 늘어났습니다. 기존 #center_text_column_2 블록 자체를 display:block·높이 560px·세로 스크롤로 변경했습니다. 화면 하단 설명창 위에 여백을 두고, 툴팁은 목록 왼쪽에 고정 표시합니다.

WORK 및 추적 CSS에 같은 내용을 적용했습니다. QSP·선택 조건·장비 효과·세이브 구조는 변경하지 않았습니다. 원본은 base.css.before.gz, 정확한 교체 블록은 css-edit.json입니다.

실제 FastQSP에서 원본 실패를 재현했고 수정본은 45개/3개 목록의 영역·마지막 항목 hit-test·합성 EXEC 클릭 검사를 통과했습니다. 툴팁은 진단에서 표시 상태를 강제해 배치를 검사했습니다. 사용자 세이브, 실물 장비 장착, 실제 마우스 휠·hover의 육안 검증은 하지 않았습니다.

일반 EXE에서 의상·장비 정보 → 긴 의상 목록을 열고 목록 위에서 스크롤해 마지막 의상 선택 및 하단 설명을 확인합니다. 파일을 다시 읽도록 게임을 재실행해야 합니다.

이 선택자는 주인공·노예·조수의 장비 선택 및 장비 효과 목록에 사용됩니다. 이 CSS를 제거하면 엔진의 table 기본값으로 돌아가 긴 목록 침범이 재발할 수 있습니다. 복원 시 교체 후 해시를 확인하고 원본 gzip을 풀어 두 CSS 및 manifest를 함께 되돌립니다.
