# 성애 스킬 기본값과 속성 카드 축소

- 성애 스킬의 미입력 세부값은 0/F로 표시한다. 실제 QSP get_stock_seed가 seed_sub_* 값을 그대로 가져오고, 대분류는 하위값의 정수 평균으로 계산하는 구조를 확인했다. 편집기에서는 미입력 하위값에 0을 넣어 입력 평균을 표시한다. 게임의 후속 연관 기술 보정 전 미리보기라는 기존 안내는 유지한다.
- 기본 속성의 제목과 값을 가로 한 줄에 배치했다. 기존 색상·툴팁은 보존했다. 실제 브라우저에서 12개 카드가 한 줄 배치이며 높이는 32.5px였다.
- 관련 JS 검사 6건 통과. 실제 UI의 성애 대분류에서 ‘미설정’이 사라지고 기본 F가 보이는 것을 확인했다.
- 실제 게임 JSON/QSP, 배포본, 커밋·푸시는 변경하지 않았다. 기존 사용자 탭은 다시 불러오지 않고 새 임시 탭에서 확인 후 닫았다.
