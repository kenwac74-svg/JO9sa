# 실제 브라우저 확인

통합 서버 `http://127.0.0.1:7689/`, 새 임시 탭에서 기존 이사벨라(2571)를 열었다. 기존 사용자 탭은 다시 불러오지 않았다.

- 기본속성 숫자칸 68px. 외모/독특함 3은 실제 게임의 B색상 rgb(0,0,216), 체력5는 S색상 rgb(0,153,0), 감수성2는 C색상 rgb(107,0,132)였다. 툴팁에 등급·숫자·키가 함께 있었다.
- 편집기 전체 능력치 카드 86개에서 중복된 seed 입력칸이 없었다. 제목·숫자·표시명이 각각 카드 안에 정렬됐다.
- 시뮬레이터 01·02 내부의 input/textarea/select/button은 각각 0개였다. 애무 대분류를 펼치면 하위 기술 4개와 각 게임 등급이 보였다.
- 헌신 단계에 시험값12를 입력해 보내자 02에서 ‘헌신 등급3 / 단계12’로 보였다. 12.5 입력 후 변경 보기를 누르면 ‘정수를 입력하세요.’로 거절했다. 시험값은 저장하지 않고 지운 다음 다시 보내 원복했다.
- 최종 캐릭터 초상과 상태 요약 화면은 simulator-status.jpg에 기록했다. 기존 게임 JSON/QSP 또는 프로필에는 브라우저 시험값을 저장하지 않았다.

게임을 실행해 보는 플레이 검사는 하지 않았다. 02는 실행 중인 게임 세이브 조회창이 아니라 편집기/시뮬레이터 설정 표시창이다.
