# 게임 속성 표시·편집기 정렬 개선

## 반영 내용
- 시뮬레이터 01: 기본 속성 12종을 읽기 전용 카드로 표시한다. 마우스·키보드 포커스에서 등급, 원래 숫자와 변수명을 확인한다. 특성/상태 삭제 버튼을 제거했다.
- 성기술: 게임의 9개 대분류 아래 세부 기술을 펼친다. 0도 숨기지 않는다. 대분류 값이 없고 하위값이 모두 있으면 ‘입력 평균’을 별도로 표시하며, 게임의 연관 기술 보정 전 값임을 안내한다.
- 시뮬레이터 02: 이름·초상, 기분/흥분 등급·단계, 성교육계, 정신 상태, 복종도, 두려움/절망/응석, 장악력, 헌신/사육/습관/인식 등급·단계 및 추가 지표 공간. 설정되지 않은 값은 0으로 꾸미지 않고 미설정으로 표시한다.
- 과거·세계·출신·직업의 원고 편집은 질문하기 → 과거 묻기에 유지했다. 01/02에는 입력·저장·삭제 버튼이 없다.
- 편집기: 기본 속성의 제목·수치·게임 표시를 각 카드 안에 정렬했다. 보통 숫자칸은 68px, 진행 단계칸은 88px. 두 자리 수 제한이나 새 min/max는 추가하지 않았다.
- 편집기의 속성·기술·관계/상태와 마스터의 인식 가능한 능력치에도 공통 게임 색상·설명을 적용했다. 태도 역순, 체형의 개별 색상, 외모6과 기분의 별도 색상표를 처리한다.

## 저장 위치·입출력
`/api/game-presentation`은 현재 WORK의 #variative / #static_base / debug_info / get_stock_seed를 읽는다. QSP를 실행하거나 수정하지 않는다. 경로·수정시각·크기가 바뀌면 캐시를 갱신한다. 폴더 연결 전에는 일반 표시로 실행하고 폴더를 연결할 때 재시도한다.

실제 get_stock_seed가 읽는 관계 초기등급 6종(헌신·사육·습관·인식·절망·응석)은 기존 seed 키를 통해 게임 JSON으로 저장한다. 그 밖의 기분·흥분·두려움·각 진행 단계·현재 복종도·장악력·정신 상태의 시험값은 기존 `jo9_editor/role-profiles/<slave|master>/<id>.json`의 `simulation` 객체에 보관한다. 이는 대사 시험용 설정이며 진행 중인 게임 세이브를 편집하지 않는다. 새 게임 저장 항목·마이그레이션은 추가하지 않았다. 프로필 저장은 기존 revision 대조와 묶음 쓰기를 사용한다.

캐릭터 편집 → 시뮬레이터로 보내기는 저장 전 입력도 전달한다. 캐릭터를 새로 만들거나 무작위 생성/JSON 적용/파일 불러오기를 하면 이전 인물의 관계 단계를 비운다. 마스터↔노예 복제에서는 ‘능력치·특성’을 포함한 경우에만 simulation도 복제한다. 모듈을 제거하면 이 정보의 편집·표시가 없어지며, 기존 게임 효과에는 변화가 없다.

## 확인
- Python 27건, JS 10건 통과. 색상 역순·별도 기분표·정수 처리·설정 보존/복제·읽기 전용 구조·기존 과거묻기 초안과 질문별 대사 편집을 확인했다.
- 격리된 HTTP 서버에서 마스터/노예 프로필 저장·미리보기·동시수정 거부·잘못된 항목 거부와 QSP/캐릭터 JSON 보존을 확인했다. 실제 WORK에는 시험 저장하지 않았다.
- WORK QSP 최초/최종 해시: `d9487a0799d46ea8dbfd28385533395b955150614e29c90224849a92cfb8affb` (동일).
- 실제 브라우저의 카드 정렬·숫자 폭·색상·툴팁과 시뮬레이터 연결은 별도 UI 기록/화면으로 남긴다.

기존 사용자 탭의 미저장 입력을 보호하기 위해 해당 탭은 다시 불러오지 않았다. 실제 게임 세이브 로드와 플레이 검사는 이 편집기 UI 작업 범위에 포함하지 않는다. 커밋·푸시·배포본 동기화 없음.
