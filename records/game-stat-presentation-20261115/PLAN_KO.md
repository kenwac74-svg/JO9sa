# 게임 속성 표시와 편집기 정렬

1. WORK QSP의 색상·표시명·세부 기술 분류를 읽는 공통 메타데이터를 만든다.
2. 시뮬레이터 01은 읽기 전용 속성 카드/기술 트리, 02는 관계·상태 지표로 바꾼다. 과거 묻기의 편집은 유지한다.
3. 편집기에는 동일한 색상과 설명을 적용하고, 작은 숫자칸을 카드 안에 정렬한다. 진행 단계는 기존 role-profile의 simulation 객체로 보관하며 게임 세이브를 수정하지 않는다. 실제 로더가 읽는 초기 등급은 기존 seed 키를 쓴다.
4. 색상 예외·상태 저장·읽기 전용 범위·레이아웃을 한 번씩 검사한다. 기존 사용자 탭은 새로고침하지 않는다.

현재 WORK의 QSP/JSON 및 배포본, Claude 원본 도구, 커밋/푸시는 변경하지 않는다.
