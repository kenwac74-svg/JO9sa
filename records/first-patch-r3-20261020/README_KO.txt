잭 오 나인 테일즈 2.4 알파 · 1차 누적 패치 r3 (2026-10-20)

적용 대상
배포된 2.4 알파 풀버전 또는 2.4 간소 패치까지 적용한 게임입니다.
이전 1차 패치를 사용 중이어도 이 ZIP만 다시 적용하면 됩니다.
2.3·2.25에는 먼저 2.4를 적용하세요. QSP를 바꾸는 다른 모드와는 호환되지 않습니다.

적용 방법
1. 게임을 완전히 종료합니다.
2. ZIP의 game 폴더를 기존 게임 실행 파일 옆의 game 폴더와 합칩니다.
3. 같은 이름의 jack.qsp와 css/base.css를 덮어씁니다.
4. 게임을 다시 실행합니다.

기존 game 폴더를 통째로 삭제하지 마세요.
세이브·개인 설정·사용 중인 이미지 팩과 추가 B컷은 그대로 유지합니다.
설치기·설치 스크립트·자동 백업 기능은 없습니다. 백업은 사용자가 직접 관리합니다.

r3 추가 수정
- 노예·조수 교육 중 빈 화면이 나오는 공통 구문 오류를 수정했습니다.
- 조수의 일부 수업 계산 대상과 고급 후속 활동의 대상·복귀 처리를 바로잡았습니다.
- 노예가 없을 때 조수의 기존 대체 수업이 표시되지 않던 조건을 수정했습니다.
- 이전 수업 도중 저장된 명령을 위한 누락 진입점을 복원했습니다.

2.4 이후의 기존 1차 패치 변경과 임신 아이콘 수정도 모두 포함합니다.
새 이미지·외부 이미지팩·JSON·실행 파일·세이브는 포함하지 않습니다.
변경 내역과 확인 범위는 CHANGELOG_KO.md를 참고하세요.
