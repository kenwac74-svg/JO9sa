# 2.4 알파 1차 누적 패치 r3 — 2026-10-20

이전 1차 패치와 r2의 변경을 모두 포함합니다. 기존 2.4에 적용하는 QSP·CSS 패치입니다.

## r3 추가 수정

- 노예·조수 교육의 성공 처리에서 명령과 주석이 붙어 빈 화면으로 멈추던 오류를 수정했습니다.
- 조수 수업이 노예용 계산을 읽던 대상 참조와 일부 고급 수업 후속 동작·복귀 처리를 바로잡았습니다.
- 이전 고급 수업 도중 저장된 명령이 호출하던 누락 진입점을 복원했습니다.
- 노예가 없을 때 조수의 기존 고용 파트너 수업이 표시되지 않던 조건을 수정했습니다.
- 같은 종류의 명령·주석 결합을 찾는 검사와 교육 경로 실행 검사를 보강했습니다.

## 기존 누적 변경

- 거주지별 개인실 증축 한도를 1~4실로 나눴습니다. 빈민가는 증축할 수 없으며 이사해도 기존 방과 입주자는 유지됩니다.
- 개인실 인물 외형 연결과 가정교사 메뉴의 두 번째 열 배치를 수정했습니다.
- 공용업무는 노예·조수의 지정을 우선하고, 개인실 메이드의 중복 수행·행동력 낭비와 장면 수행자 표시를 정리했습니다. 개인실에서는 공용 잠자리·식단·분량의 효과를 끄고 개인실 설정을 사용합니다.
- 특성 연결·명칭·수업 참조를 보완하고 전투 특성의 확률 획득·신규 전사 배경의 선천 확률을 반영했습니다.
- 안개에서 직접 승리한 인물의 자아·기질 성장 누적값을 각각 5 추가합니다.
- 승인된 출신 원고를 기존 말투별 대사 조합에 선별 반영하고, 사창가·홍등가·침실 문구와 현재 상대 참조를 교정했습니다.
- 전투·경주 문구와 장비 설명, 일상·수업·도시 안내, 이름·갤러리 표제를 교정·번역했습니다.
- 임신 아이콘의 경로·29px 표시 크기·노예와 조수의 우측 상태열 위치를 정리했습니다. 기존 2.4 이미지를 사용합니다.

## 확인 범위와 기존 저장

대표 조건에서 교육 133개 경로, 메뉴·후속 활동·추가 조건을 실제 FastQSP 엔진으로 검사했습니다. 기본 엔진 9경로, QSP 구조·줄 경계, 정확 패치 재생·재적용, ZIP 무결성과 추출 후 파일 일치를 확인합니다.
이는 모든 능력치·장비·진행 조합이나 기존 저장의 선택 화면·CRC 호환을 보장하는 검사는 아닙니다.
저장된 출신 배경을 임의로 다시 생성하지 않습니다. 복제인간의 직접 저장문 교정은 새로 생성하는 인물부터 적용됩니다.

여성 신규안, 혀 손실·명령 확장, 안개·동부 부동산 소개와 별도 인디 이미지 업데이트는 이번에 포함하지 않습니다.
