# R03-7 레시 감수성 최저1 연결

2026-11-13 사용자 승인: 기존 감수성3이하에 원본 최저1을 추가해1~3만 허용한다. 기존 demand['min_sensitivity']=1을 레시 납품에서만 읽는다. 감수성0과4이상은 거절하고 인물값은 수정하지 않는다.

실제 납품 함수 한 본문만 변경한다. 현재 요구값은 이미 저장돼 있으므로 새 캐시/영구 필드/로케이션을 추가하지 않는다. 다른 고객의 동작,체력4이상·인지도0·다른 기술·평가·가격과 인물/재산/진행을 유지한다. 별도 사용자 최저값도 덮어쓰지 않는다.

실제 성인 합성 인물에서0/1/3/4 경계,기존 체력/인지도/간호 거절과 다른 고객,기존 요구의2회로드 및 수동 편집을 RED→수정후 비교한다. 공식 재생/멱등/역검증·구조 후 WORK·소스·원장·문서를 맞추고 이번 임시 사본만 정리한다. 개인 SAV/GUI/전체출고검증·Full·음원·커밋푸시·최종 마이그레이션은 별도다.
