# 게임 화면형 본문·선택지 통합 편집

사용자 요청에 따라 별도 「선택지 서식」 패널을 제거하고 원문 옆 「선택지 포함」 체크로 같은 편집창에서 본문과 선택지를 고치도록 변경했다. 게임의 종이 배경·글꼴·대사창 크기를 읽어 원문/수정문에 표시한다. 좁은 패널은 가로 스크롤을 사용하고 게임의 글자 크기를 임의 축소하지 않는다.

기존 B/I/U·색상·줄바꿈·이모지 도구에 글꼴/px 크기/자간/문단 간격과 게임에서 쓰는 기본9색 프리셋을 함께 둔다. 선택 영역에 적용하며 본문과 선택지를 모두 선택하면 함께 바꾼다. 코드 보기에서는 기존 원문 편집 방식을 유지한다. 각본 시작/마무리 도구와 기존 여주 작업 제외도 유지한다.

장면 흐름은 장면 그림과 게임식 대사창으로 표시하며 선택지 클릭은 편집기 내 다음 장면 탐색이다. 실제 게임 명령을 실행하지 않는다. 편집용 내부 정보는 기존 주변 조건/연결 도구로 확인한다.

## 반영과 보존

`inline-page.cjs`는 현재 페이지에서 서버가 확인한 본문·선택지 원문만 함께 수정한다. 선택지 EXEC 명령은 원문과 비교하며 조건은 편집하지 않는다. 같은 위치의 여러 수정을 최소 문맥 패치로 합치고, 다른 위치의 선택지는 각 위치별로 기록한다. 기존 승인·파일 해시·백업·여주 범위 검사와 되돌리기를 재사용한다. 승인 후 갱신된 주 원문 위치를 반환한다.

`inline-game.js`는 실행되지 않는 링크 표시, 게임식 편집, 단축 서식, 세션 초안, 장면 탐색을 담당한다. 게임 이미지에 대한 표시 경로를 도구 API로 바꾸되 저장할 때 원래 경로를 사용한다. `inline-game.css`는 이 영역에만 적용한다. 게임 QSP와 SAV를 자동 변경하지 않는다. 운영 검사에서는 저장하지 않았다.

## 확인

- 작은 문서에서 본문/선택지 동시 수정·실행문 변경 거절·오래된 원문 거절·최소 패치 재생을 확인했다.
- 분리된 임시 HTTP 서버에서 미리보기·미승인 반영 거절·동시 반영·새 원문 반환·정확한 되돌리기를 확인하고 임시 QSP를 정리했다.
- 실제 WORK 브라우저에서 같은 편집창의 본문+선택지2개, 게임 배경/글꼴, 기본9색, 줄바꿈/내부 스크롤, 선택지 다음 장면 이동과 콘솔 오류0을 확인했다. 색상 변경은 미리보기까지만 수행했다.
- 구문과 UI 연결·소스 모드 보존 검사를 통과했다. 사용자 실제 게임 실행기에서 적용 후 최종 배치를 확인하는 것은 별도다.

## Avast 경고 조사

파일 감시 보고서의 04:22:03 탐지 대상은 `AMSIProcess:...powershell.exe:SCRIPT`, 탐지명은 `Script:SNH-gen [Drp]`였다. 실제 편집기 JS 파일을 감염 파일로 특정한 기록은 아니었다. 같은 시각 작성한 수정 코드 및 설치 코드를 검토했으며 외부 다운로드/설치/자동 실행 등록/백신 설정 변경 동작은 없었다. UI의 `document.execCommand`는 브라우저 서식 편집 API다.

로그에는 정확한 서명 매칭 부분이 없어 원인을 확정할 수 없다. PowerShell 안에 긴 JS 수정 코드를 넣은 작업 방식과 관련된 것으로 추정한다. 차단 명령은 재실행하지 않았으며, 이후에는 검토 가능한 파일 패치와 별도 파일 실행을 사용했다. 백신을 끄거나 예외를 추가하거나 격리 자료를 복원하지 않았다. 최종 확인 때 파일 감시 보고서에 새 AMSI 탐지 줄은 없었다. 이것을 전체 시스템 악성코드 검사 통과로 해석하지 않는다.

## 사용

대사 수정·반영에서 「선택지 포함」을 체크하고 종이 편집창의 글자를 선택해 기존 도구/프리셋을 사용한다. 「변경 미리보기」 후 승인·반영한다. 현재 사용 중인 캐릭터/이미지 편집 화면은 강제로 새로고침하지 않았으므로 작업을 저장한 뒤 통합 작업실을 새로고침한다.
