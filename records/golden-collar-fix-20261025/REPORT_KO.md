# 금장 목줄 거부 정지 — A안

사용자 승인 “A안으로”에 따라 WORK에 적용하는 수정이다. 다른 제보·경제 A/B안은 승인 범위에 포함하지 않는다.

원인은 날짜 정산 후 복귀 주소가 지워진 상태에서 메뉴가 장비를 재계산하고 거부 질문을 먼저 여는 순서였다. 원본에도 같은 순서가 있었다.

복귀 주소를 재계산 전에 설정했다. 금장 목줄 Y/X는 질문 순번·역할·ID·유형·현재 착용 및 기존 거부 조건을 확인하고 양쪽 콜백을 먼저 소비한다. 따라서 같은 선택을 다시 실행해도 피해·목줄 반환을 추가 처리하지 않는다. 기존 주 노예의 반격 조건은 유지한다. 문구의 잘못된 장비 이름 “장식 목걸이”를 “금장 목줄”로 맞췄다.

구형 저장 질문은 같은 역할의 금장 목줄 승인/반환 코드가 함께 일치할 때만 복구한다. 미응답이면 갱신하고, 이미 강제 착용했거나 반환했으면 효과 없이 메뉴로 복귀한다. 무관한 질문은 보존한다. 날짜 진행·청구 함수를 다시 호출하지 않으며 새 영구 인물 필드를 만들지 않는다. 질문 순번 전역 변수 하나가 저장될 수 있다.
