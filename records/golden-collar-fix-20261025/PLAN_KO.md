# 금장 목줄 거부 화면 A안

승인: 사용자 “A안으로”. WORK만 적용하며 세이브·배포본·커밋·푸시는 변경하지 않는다.

1. 작업 직전 QSP와 보존 대상 해시를 기록하고 최소 복구본을 보관한다.
2. 기존 소스에서 빈 복귀 주소 및 중복 반환을 실패 검사로 확인한다.
3. 메뉴의 복귀 주소 설정을 재계산 앞으로 옮긴다. 기존 금장 목줄 Y/X를 대상·질문별 한 번만 실행하고, 선택 전에 콜백을 소비한다. 기존 강제 착용·반격 규칙을 유지한다.
4. 저장된 구형 금장 목줄 질문만 식별해 갱신한다. 이미 승인·취소된 상태는 재처리하지 않는다. 날짜·정산 함수를 다시 부르지 않는다.
5. 실제 엔진에서 역할별 반환·피해·중복·대상 변경·구형 질문·클릭을 검사한다. 공식 9경로와 패치 재생·멱등성 검사 뒤 독립 검토한다.
6. WORK에 적용하고 보존 해시를 대조한다. 설명서·근거를 남기고 재생성 가능한 시험 사본만 정리한다.
