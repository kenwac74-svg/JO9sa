# 성경험 질문지 JSON 입출력

2026-11-15 사용자 요청으로 통합 편집기 character-view.mjs만 수정.

위치: 캐릭터 시뮬레이터 → 질문하기 → 성경험 묻기.
질문지 JSON 내보내기: 현재 질문지 전체를 jo9-questionnaire.json으로 저장.
질문지 JSON 불러오기: 파일 전체를 검증한 후 현재 질문지 전체를 교체하고 현재 브라우저의 시뮬레이터 저장 공간에 보관. 새로고침 후 유지. 개별 캐릭터 답변, 원문 DB, QSP는 변경하지 않음.

형식: format=jo9-questionnaire, version=1, questions 배열.
각 항목: id(고유 영숫자/하이픈/밑줄), label(표시명), question(질문 문구), level(헌신 0~5), topics(DB 주제 키 문자열 배열). 배열 순서가 질문 표시 순서.
기존 답변 연결은 id를 기준으로 하므로 기존 질문의 id는 유지할 것을 권장. 신규 id는 자동 답변 생성 규칙이 없으면 빈 답변으로 표시하며 직접 작성 가능. 해금·거절 공통 조건은 기존 규칙 유지.

부작용: 질문지 설정은 현재 브라우저의 캐릭터들에 공통 적용. 브라우저 데이터 삭제시 내보낸 JSON으로 복구 가능. 저장 실패나 검증 실패는 기존 상태 유지.
호출: 카드 버튼 → 파일 다운로드 또는 숨김 파일 입력 → parseQuestionnaire → localStorage → SLOTS 교체 → render.
원본은 character-view.before.mjs에 보존. 후속 편집이 있으면 전체 덮어쓰기 복구 대신 이번 변경만 검토할 것.

검사: node --check 통과. 질문지 왕복, 잘못된 버전/중복ID/소수 등급/잘못된 주제 타입/ID 형식/빈 질문지 거절, UI 이벤트 연결 확인 통과. 브라우저 실제 클릭은 미확인.
사용자 화면 확인: 새로고침 후 질문지 내보내기 → 문구 변경 → 불러오기 → 질문 문구와 재새로고침 후 유지 확인.

게임 파일·배포본 변경 및 커밋푸시 없음.
