# 통합 작업실 직접 시작

요청: 과거 화면을 로드하고 CSS·메뉴를 나중에 덧입히는 구조를 없앤다. 디자인·기능·저장 형식은 유지한다.

현재 server.py는 원본 index.html을 반환하고 원본 app.mjs 뒤에 integration.mjs를 붙인다. 이 때문에 폐기한 v0.11 화면을 생성·계산한 후 새 도구를 모두 초기화하고 해시를 되돌린다.

구현은 통합 전용 HTML·bootstrap·라우터로 한다. head에서 기존 디자인 CSS와 통합 CSS를 함께 로드하고 처음부터 통합 메뉴만 표시한다. 현재 해시에 해당하는 화면만 초기화하고 나머지는 최초 선택 때 기존 기능 모듈을 생성한다. 모듈은 같은 버전 URL에서 한 번만 import해 공유 상태를 유지한다.

backgrounds는 기존 workbench의 배경 기능을 사용하되 폐기한 JSON·traits·옛 시뮬레이터 패널은 생성하지 않는다. 기존 기능 모듈의 nav 추가는 통합 모드에서 생략한다. 노예·마스터 편집이 필요할 때는 공유 charView 의존성부터 준비한다.

저장키·파일·포트·WebView2 프로필은 유지한다. 전체 설정 import/export·질문 메뉴·게임DB·이미지 검색 이동·역할 복제 이벤트·기타 산출물·독립 도구 프레임을 유지한다. 게임 QSP·세이브·배포는 변경하지 않는다.

1. DOM/API 의존성 조사와 회귀 RED 확인.
2. 새 shell·라우터·bootstrap과 배경 전용 초기화 작성.
3. 새 HTML/모듈 서빙, 빌드 해시 연결, 옛 app 합성 제거.
4. 라우터 동시 전환·중복 초기화·재시도·저장 보존·주요 메뉴 검증.
5. 같은 포트에서 재시작하고 기존 화면이 생성되지 않는 직접 진입 확인, 재생성 가능한 임시 사본 정리.
