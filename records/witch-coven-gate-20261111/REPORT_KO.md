# 마녀들의 모임 첫 진입 조건 — 2026-11-11

사용자 승인: 빈민가 주거구역의 마녀들의 모임에 귀족 신분과 베네라·펠라게야의 일반 의뢰 완료 조건을 적용한다. 현재 WORK를 기준으로 반영했다.

첫 입장에는 다음 세 조건이 모두 필요하다.

- `noble_status = 1`: 귀족 신분
- `npc_progress['Venera'] = 2`: 베네라 일반 의뢰 완료
- `npc_progress['Pelageya'] = 2`: 펠라게야 일반 의뢰 완료

미충족 메뉴는 회색으로 표시하고 “귀족 신분을 얻고 베네라와 펠라게야의 일반 의뢰를 모두 완료해야 합니다.”라는 툴팁을 제공한다. 이전 화면에 남은 링크나 직접 호출에도 같은 조건을 적용하며, 거부되면 기존 주거구역 메뉴(6031)로 돌아간다.

이미 마녀를 만난 기록(`witch_text = 2`)이 있거나 특별 의뢰14·15의 진행값이 양수이거나 `revolution = 1`인 세이브는 계속 입장할 수 있다. 특별 의뢰가 진행되면 일반 의뢰 메뉴가 가려질 수 있어 기존 진행의 단절을 피하기 위한 처리다. 첫 입장에 특별 의뢰14·15 완료를 요구하면 선행 순서가 순환하므로 요구하지 않는다.

원본 조사에서는 WORK와 순정 JO9O 모두 진입 메뉴가 무조건 실행되는 것으로 확인했다. 주석 처리된 옛 `Unknown House` 항목에도 별도 진입 조건은 없었다. 관련 근거는 `records/witch-coven-entry-audit-20261111`에 있다.

## 검증

- 실제 설치된 WORK `engine/jack.exe`에서 수정 전 조건 미충족 메뉴 활성화를 재현했다(`native-before.json/log`). 이 실패는 예상된 회귀 재현이다.
- 같은 엔진의 격리 진단에서 신분2종 × 일반 의뢰 진행3종씩 × 기존 진행8종, 총144상태를 검사했다. 활성 링크·잠금 안내와 각 상태의 6021~6024 진입576건, 첫 방문/재방문 대사 선택이 통과했다(`native-after.json/log`).
- 예전 메뉴 문자열의 로드 보정, 관련 없는 메뉴 보존, 반복 로드의 동일성, 보정 후 잠금 동작을 검사했다. 최종 이동의 `shop_general` 화면 전환은 진단용 반환으로 대체했으며 실제 GUI 플레이 검사를 뜻하지 않는다.
- 공식 `tools/apply_mods.ps1`로 작업 직전 백업에 이번 패치만 재생해 후보와 바이트 단위로 일치했고, 재적용에도 동일했다(`replay.json/log`, `replay-again.log`). WORK 적용과 재적용에서도 같은 해시를 확인했다.
- 296개 로케이션 구조·바이트 왕복·CRLF·주석 경계 검사 통과. 변경 본문은 `$ongload`, `interaction_city`, `#options` 세 곳뿐이다.
- WORK와 추적 QSP, 런타임 원장의 해시를 맞췄다. 이미지 체크 상태·일정 데이터·춘향 JSON의 해시는 보존했다.

진단 중 테스트 주석의 닫히지 않은 작은따옴표로 완료 신호가 나오지 않았다. 테스트 주석을 수정한 뒤 통과했으며 게임 코드의 조건은 변경하지 않았다. 최초 적용 후 보고 스크립트의 예상 로케이션 순서도 실제 순서로 바로잡고 최종 범위를 재검증했다. 최초 적용 로그 일부의 한글 출력 인코딩은 깨져 있으나 해시 기록은 유효하며, 재생 로그와 보존 스크립트는 UTF-8 출력을 사용한다.

전체 배포 전 검사를 이번에 실행한 것은 아니다. 실제 사용자 SAV를 일반 EXE의 불러오기 버튼으로 여는 과정, 툴팁 배치와 외형은 미확인이다. Full·이미지·음원·개인 세이브·커밋/푸시는 이번 작업 범위에 포함하지 않았다. 이미지 패치리스트의 이전 QSP 분석 표시는 사용자 지시대로 별도 동기화하지 않았다.

## 사용과 확인

게임을 다시 실행해 기존 세이브를 불러온 뒤 빈민가 → 주거구역으로 간다.

1. 첫 방문이며 조건이 부족하면 회색 메뉴와 조건 툴팁을 확인한다.
2. 귀족이며 두 일반 의뢰가 완료된 세이브에서는 메뉴가 활성화되어 첫 대사로 이어지는지 확인한다.
3. 이미 마녀를 만난 세이브에서는 기존 진행으로 계속 들어가는지 확인한다.

실행 중이던 게임은 디스크의 새 QSP를 자동으로 다시 읽지 않는다.
