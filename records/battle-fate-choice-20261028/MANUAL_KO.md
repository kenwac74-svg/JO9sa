## 동작

일반 안개전투에서는 쓰러진 적에 대해 처형 선택만 활성화하고 살려주기는 링크 없는 회색 문구로 표시한다. 일반 투기장의 인간 여성 상대(정규 경기20종, 콜로세움 공개 상대5종)에게는 두 선택을 모두 제공한다. 여러 적이 있는 안개전투는 한 번의 선택으로 그 전투에서 대기 중인 적 전체를 처리한다. 일반전의 적이 의지를 잃은 경우도 사용자 문안에 맞춰 쓰러진 상태로 표시한다.

고유 챔피언 도전, 캣파이트, 소유 노예 훈련, 영입·퀘스트 상대는 범위 밖이다. 등록되지 않은 상대가 섞인 전투도 기존 처리를 유지한다. 콜로세움 공개 경기는 원본이 sparring으로 주석 처리했더라도 최신 사용자 요청의 일반 경기 범위에 포함한다. 현재 메뉴의1–5/11–15/31–35와 원래 지원하던 옛 조수 범위21–25를 보존한다.

선택 전에는 기존 사망·기절 누계와 트로피를 더하지 않는다. 선택 뒤 해당 슬롯마다 한 번 기록한다. 처형은 사망으로, 살려주기는 체력1 이상·전투 체력0인 생존 전투불능 상태로 남긴다. 이후 계속 또는 활성화된 기존 결과 아이콘을 누르면 원래의 보상·경기 결과·복귀 처리를 한 번만 실행한다. 선택 전 출구 직접 호출은 선택 화면으로 돌아오고, 확정 후 출구 재호출은 중복 실행하지 않는다.

전투 중 플레이어가 패배하거나 도망가면 대기 중 적은 원래 원인에 맞게 기록한 뒤 기존 패배/안개 교대 흐름을 따른다. 상대를 살려주는 선택을 안개에서 직접 호출해도 상태를 바꾸지 않는다.

## 구성과 입력·반환

추가 로케이션은 jo9_battle_fate 1개다.

- init(source): 새 전투 상태를 지우고 현재 장소·상대ID·인원·경기 모드로 적용 범위를 판별한다. source는 normal(공통 전투) 또는 arena(정규 검투 경기)다. 반환 숫자는0기존/1안개/2투기장이다.
- stage(slot,cause): 활성 적 슬롯에 원인1HP/2KO/3상태 패배/4의지 소진을 한 번 기록한다. 적의 전투 참여만 끄고 쓰러짐 수와 새 대사를 더한다. 사망/KO/트로피는 아직 더하지 않는다. FUNC 반환1이면 기존 라운드 처리 분기를 건너뛴다. GS 뒤 RESULT를 읽는 방식으로 바꾸면 중복 집계 위험이 있다.
- result: 승리와 대기 슬롯이 있으면 선택 단계1로 진입한다. 패배면 fallback을 호출한다.
- choose(choice): 단계1·승리 상태에서1처형 또는2살려주기를 한 번 확정한다. 안개에서2는 거부한다. 숫자 반환은 허용1/거부0이며, 반환을 읽을 때는 FUNC를 사용한다.
- fallback: 패배·이탈 때 대기 슬롯을 원래 사망/KO/의지 원인대로 기록하고 새 UI를 해제한다. 의지 소진의 기존 무트로피 흐름은 여기서 유지한다.
- choices: 선택 HTML을 $jo9_fate['choices']에 만든다. 화면은 저장 문자열을 출력한다.
- apply(choice): 실제 선택 링크의 진입점이다. choose 후 render로 이동한다.
- render: 최초 결과 HTML 사본을 재출력하고 선택 확정 메시지·활성 계속 링크·적 HP/전투 체력 표기를 교정한다. 캐시에 있던 직전 타격/피격 태그를 제거해 다시 재생하지 않으며, 처형 효과는 첫 재표시에만 추가한다. 원래 끝난 전투 로케이션을 재호출하지 않아 갑옷 해제를 반복하지 않는다.

## 상태와 호출 위치

jo9_fate에는 mode, phase(0진행/1선택/2확정/3보상 진입), count, choice, HP/체력 이전표시, FX표시 여부와 짧은 HTML 캐시를 보관한다. jo9_fate_enemy에는 최대5개 적 슬롯의 대기 원인만 저장한다. 모두 다음 전투 시작에 초기화한다. 기존 세이브 파일을 쓰거나 이관하지 않는다. 이전 전투 중 세이브에 이 초기화 정보가 없으면 해당 전투는 원래 방식으로 마무리하므로 이미 기록된 사망을 되살리지 않는다.

기존 로케이션6개 연결: раскладка_бой(초기화), начать_бой/\$gladiator_fight_start(범위 판별), конец_раунда(쓰러짐 보류), конец_боя(선택 화면·캐시), выход_из_боя(출구 잠금·단1회 보상). 패치 JSON에 각 원문과 변경문, 이전·이후 SHA가 있다.
