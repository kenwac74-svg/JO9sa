# 도나도나 기존 보유 인물 갱신 설계·실행 계획

사용자 승인: 기존 육성/진행 보존 + 기존 영입 인물 1회 갱신.

전체 프리셋 덮어쓰기는 육성을 지우므로 제외. 변경된 초기 능력/기술만 max(현재,새 기준), 지정 특성은 최신 설정으로 적용하고 비대상 특성은 보존한다. 일반 공개 단계와 강화 단계는 낮추지 않는다. 기분/성격 기준 문자열 psy_basic은 보존. 외모 등 수치도 낮추지 않아 기존 외모5는 유지된다. 동일 키의 배타적 특성은 새 설정이 우선하며 기존 충돌 정리만 사용한다. 발견 완료는 잠재로 되돌리지 않는다.

기술 선택: QSP 새 로케이션 1개, $ongload/$newloc 선두 호출. 이전 세이브의 seed 캐시가 오래됐어도 현재 WORK JSON에서 확정한 값을 코드에 기록해 사용한다. 개인SAV 파일 직접 수정 없이 게임 불러오기/장면 이동 시 동작. 전체 보유 30역할(공식29+개인실 parked), 생존·점유 상태>0 및 ID8877~8899만 대상. 상점/선택 임시 복사본 제외.

저장 비용: 캐릭터 배열에 jo9_dohna_preset_rev 정수1개. 같은 배열의 원래 swap/copy에 따라 이동하여 역할 변경 후 반복되지 않는다. 전역 완료표시는 쓰지 않아 다른 세이브/이후 새 영입도 정상 처리한다. 이름/이미지/장비/인벤토리/나이·소유일/헌신/관계/퀘스트/현재 자원은 쓰지 않는다.
