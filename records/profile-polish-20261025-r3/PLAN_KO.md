# 표시 문구·프로필 다듬기

사용자가 다섯 가지 결과를 직접 지정했다. 기존 UI와 게임 산식·조건·식별자를 보존하며 표시만 수정한다. WORK만 반영하고 기존 세이브·배포본·ZIP·커밋·푸시는 보존한다.

- [x] 현재 WORK 바이트 왕복·백업·보호 파일 해시 기록.
- [x] 파산 엔딩의 한글 단어 중간 줄바꿈 방지. 속성 그룹 및 마지막 그룹과 특성 사이 10px. 좌측 특성 목록만 80%, 중앙 전체보기는 현재 크기.
- [x] 통화 표시를 숫자·동적 가격 토큰 단위로 `$10`에 통일. 추상 화폐명과 QSP `$변수`, 수치 계산·매매 조건은 보존. 범위·음수·중첩 코드·HTML 속성은 별도 검토.
- [x] 기존·신규 특성 설명을 `[제목]<br>설명`으로 통일. 주목욕구 표시명만 관심종자로 바꾸고 관심을 받으려는 성향 설명을 자연스럽게 각색. 이름에 대응하는 내부 저장 키와 효과는 유지.
- [x] 기존 설명 캐시만 현재 정의로 갱신. CSS/JS 리소스 버전 갱신.
- [x] 정확 패치 재생·재적용·줄과 주석 경계·실제 엔진 9경로. 별도 실제 QtWebKit에서 글자 크기·간격·줄바꿈·제목/본문·통화 출력 점검. 대표 세이브 실제 불러오기.
- [x] 독립 검토 후 WORK 설치·재검증. 간단 매뉴얼·패치·결과 보존, 검증용 임시 복사본 정리.

기능 추가나 효과 조정은 하지 않는다. 상세 수치가 없는 설명 원칙도 유지한다. 일반 화폐 서술을 전부 '$' 기호로 치환하거나 매입·정산 수식을 재작성하지 않는다.
