# 장면 흐름을 보면서 각본 구간 지정 복구

원인: navigation을 수정 전용 패널에 넣고 renderPreview를 edit 모드에서만 실행해 각본 모드에서 기존 장면/분기/그림을 볼 수 없었다.

공유 검색 다음에 기존 navigation을 공용으로 배치한다. 현재/다음/앞뒤/처음/마지막/전체 흐름과 분기·그림을 보면서 대사에 시작·마무리를 지정한다. 지정한 대사에 명시적 표식을 붙이고 요약에 단계 번호를 보인다. 수정 화면·AI·초안·반영/복구는 보존한다. CSS로 가리지 않고 정적 구조·렌더링·이벤트를 고친다. 게임 파일/오디오/체크상태/Full/커밋푸시는 이번 범위에 없다.
