## 사용

HTML을 내려받아 Chrome 또는 Edge에서 직접 연다. 편집·검증·승인 기록은 브라우저에 자동저장되며, 편집 중 초안도 보존한다. 다른 PC로 이동하거나 브라우저 데이터를 정리하기 전에 JSON 백업 또는 현재 데이터를 포함한 HTML을 내보낸다.

‘작업 폴더 연결’은 선택한 폴더의 파일을 읽어 목록과 JSON 연결을 검사한다. Git·QSP·DryRun의 실행 근거는 ‘실행 상태 등록’ 또는 내장된 PowerShell 수집기가 만든 JSON으로 등록한다. 수집기는 화면의 안내에서 별도 저장할 수 있으며, 선택적 DryRun은 기존 `tools/apply_mods.ps1 -DryRun`을 사용한다.
