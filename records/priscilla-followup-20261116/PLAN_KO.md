# 승인한 프리실라 후속 분기 구현 계획

사용자 승인: 포털 후 원고 반영, 기존 보상 장면 재사용, 반란 완료 후 야만왕 재촉 제거. 책 인계·전달·의뢰 최종 완료는 후속 개발로 보존한다.

1. 현재 WORK·추적 QSP 해시 일치를 확인하고, 현재 원고·이미지 연결을 그대로 읽는다.
2. 반란 전 원래 경로, 반란 후 보상 전/후 안내, 포털 장면 진행 중, 엔딩 통과 뒤 새 대화, 후속 대화 재방문, 구 화면 캐시, 책·돈·퀘스트 상태 보존을 실제 본문 회귀로 검사해 실패를 먼저 기록한다.
3. interaction_city에 6026 한정 분기를 추가한다. 기존 장면 기록6220과 임시 grand_final=0을 함께 확인한다. 최초 귀환 방문은 승인한 대화11페이지 뒤 상황에 맞게 새로 쓴 후반4페이지를 연결한다. 사용자 추가 지시에 따라 원본6025의19~22페이지 원고를 복사하지 않고, 그림3종만 독립된 새 파일명으로 WORK·assets에 바이트 복사한다. 재방문은 책 보관 안내. 기존 보상 수령값 witch_talk만 재사용하며 새 저장 필드·배열·로케이션은 만들지 않는다. 새 장면 방문으로 기존 이력 배열에 통상적인6026 항목 하나가 기록된다.
4. 반란 후6021~6024의 낡은 안내를 현재 단계 안내로 바꾼다. 이전 화면에 저장된 대사도 표시 시 한정 보정하고 보상·선택을 재실행하지 않는다.
5. 수정안에서 회귀, 공식 변경위치 재생, 구조·마커·왕복·역적용·무관 본문 보존을 확인한 뒤 현재 해시가 그대로일 때 WORK·추적 소스와 원장을 맞춘다. 수정 밖의 기존 수동 문자열 줄바꿈은 보존한다. 설치본 핵심 검증 후 임시 QSP가 남지 않도록 정리한다.

Full·배포 ZIP·개인 세이브·커밋·푸시는 이번 범위에 없다. 기존6025 원고 자체와 프리실라의 최종 의뢰 완료 조건은 변경하지 않는다.
