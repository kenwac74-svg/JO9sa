# 이사벨라 영입 거래 화면 외형 수정

이 화면은 컷신 한 장이 아니라 slums_street 배경 위에 center_Isabella의 투명 PNG를 겹치는 구조다. #options의 $isabella_options[1]이 예전 PNG를 직접 호출하고 있었다.

현재 2571 title PNG를 기존 호출 경로에 그대로 복사했다. WORK와 2026-10-31 제작 배포본에 적용하고 이미지 목록의 해당 파일 용량만 갱신했다. QSP·조건·JSON·세이브 형식은 변경하지 않았다. 구2323의 별도 이미지도 유지했다. 의도된 중복과 향후 교체 주의사항은 호환 원장에 기록했다.

검증: 두 대상과 현재 원본의 SHA-256 일치, 보호 파일 해시 불변, 목록 인라인 JavaScript 문법 통과. PNG 무결성·치수·투명도 검사는 image-verification.json 참고. 실제 GUI/사용자 세이브 재생은 이번 검사에 포함하지 않았다.
