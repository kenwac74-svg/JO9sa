# Helper 웹 대시보드 통합 — 2026-11-18

사용자 요청에 따라 통합 모드 작업실의 **게임 DB → 웹 대시보드**에 기존 JO9 Helper의 웹 화면을 연결했다. 사용자 최종 확인: 연결 문제는 백신 때문이었으며 현재 이상 없음. 이에 추가 원인 조사와 반복 검사는 중단했다.

## 사용 방법과 의존성

기존 모딩툴 실행기로 열고 게임 DB에서 웹 대시보드를 선택한다. 저장 파일 선택, 인물·퀘스트·공략 보기와 기존 계산 기능을 유지한다. 저장된 세이브를 읽는 기능이므로 게임 메모리의 실시간 상태와는 다를 수 있다. 기존 Helper의 공략·계산 데이터는 원래 프로그램의 자료이며 현재 WORK QSP와 동일한지 전수 대조한 결과는 아니다.

원본 `JO9_Helper_v1.0.0/JO9_Helper.exe`를 WORK 설치 폴더 아래에 유지해야 한다. 필요할 때만 비표시 백엔드를 실행하며, 통합 작업실의 같은 출처 URL로 중계한다. 원본 프로그램의 창·트레이·브라우저 자동 열기는 사용하지 않는다. 원 제작자 표시는 유지했다.

## 변경 구성과 동작

- `helper_dashboard.py`: 원본 EXE에서 웹 문서만 읽고, 전용 백엔드의 시작·중계·종료를 담당한다. 외부 API 임의 접근과 경로 이탈을 차단한다. 전용 Job에 정지 상태로 프로세스를 먼저 배정한 뒤 실행하여 작업실 종료 시 자식 프로세스도 정리된다.
- `helper_dashboard_html.py`, `helper-dashboard.css`: API 주소를 통합 경로로 연결하고 제목 중복과 데스크톱 전용 버튼을 제거한다. 기존 세이브 선택·모달·툴팁·환경설정을 유지한다. 중복 상태 요청을 합치고 오류 응답을 정상 상태로 표시하지 않도록 한다.
- `server.py`: `/workspace/helper/` 및 문서·스타일·읽기 API를 제공한다. 기존 캐릭터·대사 API는 유지한다. 통합 화면에서 원본 프로그램 종료/창 제어 POST는 중계하지 않는다.
- `integration.mjs`: 기존 게임 DB 하위 탭에 웹 대시보드를 추가한다.
- `Start-Modding-Hub.ps1`: 관련 파일을 버전 계산에 포함한다. Python과 PowerShell의 파일 목록 순서가 일치한다.

연동을 제거하려면 게임 DB 탭·서버 경로·관련 버전 목록 항목을 함께 제거해야 한다. 원본 EXE를 없애면 웹 대시보드만 사용할 수 없으며 게임 QSP나 세이브 형식은 바뀌지 않는다.

## 확인한 범위

관련 단위·HTTP 검사 17개 및 요청 합치기 JavaScript 확인 3개를 통과했다. 실제 원본 백엔드 HTTP 응답에서 저장 파일 88개와 대상 11개를 확인했다. 전용 프로세스 종료 후 소유 포트가 남지 않음을 확인했다. 관련 Python·JavaScript·PowerShell 구문과 버전 파일 목록 49개의 일치를 확인했다. 통합 화면과 작업일정 탭을 열었으며 사용자가 정상 작동을 확인했다. 전체 게임 플레이나 원본 Helper 공략의 정확성을 검증했다는 의미는 아니다.
