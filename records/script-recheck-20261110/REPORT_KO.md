# 직접 수정문 재검토 안내

사용자 보고: 카드의 수정문을 직접 편집한 뒤 확인 체크를 누르지 못해 각본을 반영할 수 없음.

원인: inlineChanged가 전체 각본을 갱신하면서 이전 검토·승인을 무효화한다. 새 검토가 필요하지만 실행 버튼은 긴 카드 목록 위에 있었고 확인 체크 아래에는 잠긴 이유나 다음 동작이 없었다. 검증을 건너뛰는 결함으로 바꾸지 않고 반영 행에 수정문 재검토 버튼과 상태 안내를 추가했다.

script-import-ui.js의 recheckHint는 검토 상태와 편집 오류·busy를 받아 새 버튼의 표시/활성 및 안내를 갱신한다. 기존 clear/render/preview/lock에서 호출하거나 상태를 함께 갱신한다. 버튼은 기존 preview(false)를 재사용해 사용자의 제외 선택을 유지한다. 재검토 성공 후에만 확인 체크가 열리고, 수정하거나 검토가 실패하면 반영을 잠근다. index.html의 실제 반영 행에 버튼과 상태 요소를 추가했다. 두 파일은 함께 설치한다. 새 API·게임 변수·세이브 변경은 없다.

사용법: 직접 편집 → 아래 수정문 재검토 → 변경 내용과 경고 확인 체크 → 각본 반영. 재접속 후 저장된 수정문에도 재검토 버튼이 표시된다. 구분선 편집 오류를 바로잡기 전에는 두 검토 버튼 모두 비활성화된다.

관련 검사 24개 통과. 브라우저에서 현재 수정문 4개 검토, 넘침 0개, 새로고침 뒤 전체 수정문·각본 ID 보존을 확인했다. 확인 체크를 눌렀을 때 반영 버튼 활성화를 확인하고 체크는 다시 해제했다. 실제 게임 반영은 실행하지 않았으며 QSP 해시는 작업 전과 같다. before는 관련 코드의 수정 전 복구 자료다. verification.json과 regression.log에 검사 결과를 남긴다.
