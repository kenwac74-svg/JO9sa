# 54개 특성의 일반·칭호 분류안

일반 51축·90표시 변형, 칭호 관련 기존 3축·5표시 변형이다. 한 인물의 최대 보유 숫자가 아니며, 여러 단계/반대값은 같은 축 한 칸이다. 일반8＋칭호3 구조는 확정됐지만 아래 개별 배치는 제안이다.

칭호 세 칸은 다재다능 / 향후 창관용 / 경기 챔피언을 제안한다. 마지막 항목은 투기장·경주의 기존 두 저장값을 한 줄에 묶는 표시안이다. 기존 등급·승수·장비 조건을 합치거나 초기화하지 않는다.

향후 창관용 성취는 아직 미구현이어서 54개 기존 저장 축에 더하지 않았다. 일반 중 숨은 보유도 집계/삭제 추첨에 포함하며, 임신·문신 없음 등의 상태와 기본 속성은 처음부터 이 표 밖이다.

등록값의 부호나 표시 유무만으로 활성 여부를 판정하지 않는다. metabolism의 중립은3이고, 일부 성향의 중간값1 또는2에도 효과가 있다. 보류된 voice=2와 해석 불명인 값은 자동 처리하지 않는다.
