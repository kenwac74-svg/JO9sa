## 범위와 상태

이번 패치는 식사 준비·청소·안개 괴물 관리의 담당자를 선정하고 해당 인물의 기존 처리와 컷신을 연결한다. 목욕·기상 보조의 실제 참여 인원에 관한 사용자 확인은 별도로 대기한다. 이 세 업무 패치를 두 항목까지 완료한 것으로 보고하지 않는다.

## 입력·선정·반환

새 함수 `jo9_household_worker`는 `func('jo9_household_worker', 작업[, 제외할 역할])`로 호출한다.

- 작업 `cook`: 본인의 `cooks_rule=1`, 기존 주방/식사 필요 조건, 의식/행동력 조건을 충족하는 인물의 원래 `cook` 값 비교.
- 작업 `clean`: 본인의 `cleans_rule=1`, 오염도>1 및 기존 의식/행동력 조건을 충족하는 인물의 `service` 비교.
- 작업 `tentacle`: 본인의 `tentacle_rule=1`, 기존 시설/괴물 상태/행동력 조건을 충족하는 인물의 `sub_tentacles` 비교.
- 후보: 주 노예 `slave`, 조수 `assistant`, 메이드 `room1`~`room4`. 행동력은 원본처럼 0도 허용하며 대기 소비 처리도 보존한다.
- 기존 주 노예의 복종 조건, 조수의 괴물 관련 숙련도 최저 조건 등 역할별 가능 조건은 유지한다. 다른 인물의 체크를 물려받아 일하던 요리 fallback과, 청소 체크 없이 일하던 fallback은 후보에서 제외한다.
- 최고값이 같은 후보는 균등한 확률로 하나 선택한다. 매 업무 직전에 현재 상태로 새로 선정한다.
- 반환은 해당 역할 문자열 또는 빈 문자열이다. 모든 내부 작업 변수는 `local`이며 새 영구 배치표·직업·저장 데이터는 추가하지 않는다.

## 실제 처리와 컷신

`next_day`의 각 기존 업무 영역이 함수로 한 명을 정하고, 해당 역할의 원본 효과 블록만 실행한다. 식사·청소·괴물 업무의 기존 원래 비용·학습·상태 변화는 보존하며, 미선발 인물은 그 작업으로 행동력을 쓰거나 작업 성장 효과를 받지 않는다. 주 노예의 괴물 업무 거부 판정은 실제 선정되었을 때 한 번만 실행한다. 거부하면 주 노예를 제외해 다시 선정하므로 다른 인물의 체크가 후보 전체를 막지 않는다.

기존 `역할_auto_작업` 실행 플래그와 `end_day_screen`의 인물별 컷신 블록을 그대로 사용한다. 그날 해당 작업의 플래그를 먼저 초기화하고 실제 담당자만 플래그를 받으므로 작업 효과와 표시 인물이 일치한다. 괴물 업무의 뒤늦은 만족도·집계 처리도 기존 담당자 컷신 경로를 유지한다.

`display_pic`의 개인실 1~4 분기에서 `main_actor_type=assistant_type`을 각각 `roomN_type`으로 수정했다. 이전에는 메이드의 컷신도 조수의 유형별 이미지로 갈 수 있었다. 배경·일반컷·전신 표시나 이미지는 추가/교체하지 않는다.

기존 주인공의 비상 요리·청소 fallback은 유지한다. 여섯 명 중 지정 인원이 중복 수행하는 문제와 별개인 원본 주인공 처리다. 개인실 메이드의 다른 생활 규칙 전체를 새로 완성한 패치는 아니다.
