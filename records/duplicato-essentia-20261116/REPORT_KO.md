# 듀플리카토 에센티아 (Duplicato Essentia)

2026-11-16 사용자 확정 사양을 WORK·추적 소스에 반영했다. 배포 ZIP/Full·커밋푸시는 하지 않았다.

## 게임에서 사용하는 순서

1. 프리실라 포털 귀환 대화의 마지막 선택지에서 **마법을 요구한다**를 고르면 한 페이지에서 습득한다. 기존 보상과 사용자 수동 대사는 그대로다.
2. 집의 **주인: 마법 목록 → 듀플리카토 에센티아**를 연다. 받을 노예와 줄 조수가 모두 활동 가능한 상태이고 서로의 친밀도가 각각 40 이상이어야 한다.
3. 조수에게서 발견한 긍정 재능을 하나 선택한다. 삭제될 상충 특성과 비용을 확인한 후 승인하면 복사한다. 취소하면 변하지 않는다.

| 조건 | 적용 |
|---|---|
| 마법력 | B 이상(내부값 3), 장비 보정 포함 |
| 금액 | 900스파크 |
| 행동력 | 주인공·노예·조수 각각 1 |
| 하루 제한 | 대상이나 조수를 바꿔도 마법 전체 하루 1회 |
| 받는 인물 | 평생 1회 |
| 주는 조수 | 재능은 유지하며 다른 날 다시 제공 가능 |
| 발견 | 발견값 2 또는 현재 리벨리스로 드러난 재능 |
| 충돌 | 확인 화면에서 알린 기존 특성을 지우고 새 재능 부여 |

행동력의 반칸 잔여는 보존한다. 반지나 쉬운 활동 감면은 적용하지 않으며, 기존 무한 행동력 치트는 유지한다. 복사는 원본 재능을 빼앗거나 원본 기술 등급을 옮기는 기능이 아니다. 새로 얻은 재능은 발견된 상태로 표시한다.

대상은 운동광·달변가·순종적인 동물·순종적인 말·미련한 소·타고난 간호사·타고난 하녀·예민한 미각·타고난 투사·타고난 마법사·타고난 미적감각·절대음감·춤·보좌관, 총 14키다. 춤은 대상의 기존 조건에 따라 발레리나/이국적인 댄서로 표시한다. 성격·기질(겁쟁이·무모함·용감함 포함), 종족, 칭호, 학습, 전투 특성은 복사하지 않는다.

## 구현과 저장 영향

- `menu_form`: 기존 마법 메뉴에 항목 추가, 재능 선택 하위 메뉴 `62110` 연결. 기존 메뉴 디자인·취소 버튼을 재사용한다.
- `interaction_city=6027`: 한 페이지에서 습득. 기존 6026의 수동 원고 1~8과 선택지, 6028의 독립 4페이지, 6025의 기존 보상은 보존했다.
- 새 `jo9_duplicato`: 조건 사유, 목록, 기존 yes/no 확인 화면, 시전, 습득. 최종 클릭 시 인물 ID·조건·자원·삭제 목록을 다시 검사한다.
- 새 `jo9_duplicato_traits`: 14재능의 후보·표시명·충돌 미리보기·부여. 원본 조수 배열과 무관한 수동 특성은 변경하지 않는다. 워커홀릭 제거에는 기존 `jo9_activity_stage`를 사용한다.

학습 여부는 `npc_progress['Priscilla_duplicato']`, 수혜 기록은 인물의 `jo9_duplicato_received`에 저장한다. 일일 사용은 기존 가구 공용 `already_done_today['jo9_duplicato']`로 기록하며 기존 일일 초기화를 사용한다. 별도 선택용 영구 변수나 인물 복제본은 없다.

인물 이동은 기존 전체 배열 교환을 사용하므로 개인실·감방·냉동 보관·조수 전환과 DB 외형 갱신 후에도 수혜 기록을 유지한다. 제공자로 쓰일 때에는 본인의 과거 수혜 기록을 검사하지 않는다. 기존 세이브의 누락값 0은 미학습/미수혜로 동작한다.

## 검증과 한계

기존 마법 입력 페이지가 습득값을 주지 않는 실패를 먼저 확인했다. 실제 QSP WASM 5.8에서 습득 1페이지, 주문 경로 30조건, 재능 helper 161확인, 오류 0을 확인했다. 관련 범위는 친밀도 39/40, B 미만/이상, 899/900스파크, 각자의 반칸/1AP, 발견·중복·상충, 취소·오래된 확인·대상 변경, 전역 하루 제한·수혜자 평생 제한·조수의 다음 날 재제공, 기존 엔진 저장/불러오기다.

화면 출력과 yes/no·결과 화면은 실제 코드를 실행했고 집/레이아웃 helper는 격리 대체했다. 네이티브 EXE의 최종 줄바꿈과 버튼 위치는 확인하지 않았다. 사용자 확인은 위 순서대로 **습득 한 페이지 → 삭제 내역 확인/취소 → 실제 시전 후 세 사람 행동력과 하루/수혜 제한** 세 가지면 된다. 이미 켜 둔 게임은 새 QSP 코드를 읽도록 재실행한다.

최소 mod dry-run에서 새 location 2개와 본문 수정 2곳, 역변경/직렬화 왕복, 변경 위치의 CRLF·마커 경계, 다른 location/필드 불변을 확인했다. 전체 배포 검사는 반복하지 않았다.

## 재현과 제거

`mods/2026-11-16_duplicato_essentia.json`에 최소 변경과 새 location 본문이 있다. `prepare.cjs`는 직전 해시를 검사하고, `test-traits.cjs`/`test-spell.cjs`는 격리 엔진을 실행하며, `install.cjs`는 동일 검증 해시만 설치한다. 테스트가 실패하면 이전 주문 검증 JSON을 지워 오래된 통과 기록을 쓰지 않는다.
