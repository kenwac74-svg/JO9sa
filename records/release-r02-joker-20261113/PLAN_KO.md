# R02 조커 재구매 차단 수정 계획

2026-11-13 사용자 승인: 검사 키를 실제 구매 기록과 맞추고 기존 세이브의 메뉴 캐시도 갱신하며 재구매 차단을 검증한다.

현재 #options는 jokr=0, interaction_city6244는 joker=1을 쓴다. WORK 전체에서 jokr를 구매 완료로 설정하는 실행문은 없다. 실제 기록 joker를 기준으로 통일한다. jokr의 저장값을 구매 기록으로 추측 이관하거나 삭제하지 않는다.

1. 기존 실행 메뉴에서 joker=1/jokr=0이어도 구매 링크가 남는 RED를 실제 엔진으로 확인한다.
2. #options의 조커 검사만 수정한다. 별도 모드의 캐시 갱신은 알려진 옛 조건문만 바꾸고 사용자 메뉴 문구·다른 조건은 보존한다.
3. interaction_city6244 입구에서 기존 메뉴와 같은 미구매·3000이상·빈 노예 칸을 확인한다. 실패 시 쿨라 구매 메뉴로 돌아가고 생성·교환·차감을 실행하지 않는다.
4. $ongload에서 저장된 조커 조건만 갱신하고 현재 쿨라 구매 화면은 거래를 실행하지 않고 다시 그린다.
5. 실제 메뉴·첫 구매·두 번째 링크·빈칸 없음·금액 경계·과거 캐시·재호출을 실제 엔진에서 확인한다. 가격·프로필·생성·역할 교환·다른 구매자 본문은 보존한다.
6. 정확 mod·공식 재생/재적용·역적용·WORK/추적/manifest 일치를 검증하고 R02를 완료로 갱신한다. R03 등 다음 수정은 별도 확인한다.
