# 파산·특성 UI 테스트 세이브 갱신

사용자 요청은 이번 WORK 변경의 즉시 테스트용 세이브다. 기존 28개 묶음과 ZIP은 보존하고 새 폴더·ZIP으로 추가한다. 게임 코드와 실제 플레이 파일의 상태를 변경하지 않는다.

1. 최신 WORK 해시와 기존 세이브·설정·Full을 기록한다.
2. 기존 완성 세이브 11·12·13·20을 실제 네이티브 Load로 복원해 새 9개 상태를 만들고 원래 화면에서 저장한다. `primeState`로 완성 세이브를 대체하지 않는다.
3. WORK와 바이트 동일한 격리 호스트에서 네이티브 Save를 해 현재 CRC를 얻고 최종 파일에 연결한다. 제작용 콜백·변수·스크립트는 남기지 않는다.
4. 독립 파일 검사와 실제 Load·원래 선택지 클릭으로 시작 화면과 결과를 확인한다. 검증용 저장은 별도 파일에만 한다.
5. 새 세이브 폴더·사용 안내·ZIP을 설치하고 파일 해시와 ZIP 내용을 대조한다. 최소 보고서·레시피·재현 스크립트만 보존하고 재생성 가능한 진단 사본은 정리한다.

Full 동기화, 배포 패치, 커밋·푸시는 하지 않는다. 기존 사용자 세이브 파일을 덮어쓰지 않는다.
