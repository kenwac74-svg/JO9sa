## 확인한 범위

9개 모두 실제 Game → Load로 원본 세이브를 복원한 뒤 제작용 별도 호스트에서 네이티브 Save로 만들었다. 제작용 콜백과 변수는 최종 파일에서 제거했다. 원래 로드 콜백·전체 문자열·다중 행 스크립트를 보존했고, 현재 WORK에서 직접 저장한 CRC를 사용했다.

독립 검사 9/9 통과: 바이트 왕복, 변수·인덱스, 성인 표본, 이미지 ID, 현재 인테리어 경로, 진단 코드 제거, 진입 화면과 조건, 원본 보호 해시. 최종 02·05·07·08·09는 WORK와 동일한 격리 호스트에서 버전 검사 생략을 끈 채 경고 없이 실제로 불러왔다.

실제 클릭 결과:

## 재현 자료와 의존성

`recipes.json`은 시험 입력·진입 화면·기대값, `prepare.cjs`는 기존 완성 세이브 11·12·13·20의 별도 제작 호스트 준비, `stage.cjs`는 최종 진단 상태 제거와 현재 인테리어·CRC 정리, `inspect.cjs`는 읽기 전용 검사다. 이들은 `G:/somi/JO9sa/tools/text-workshop/core.cjs`, `tools/qa/save-codec.cjs`를 이용한다. 원본 게임에 추가 함수나 저장 변수를 설치하지 않는다.

UI 표본의 네이티브 제작 결과에 남은 동일 이름의 빈 임시 `J9_KEY` 레코드는 모두 빈 값임을 확인한 뒤 중복만 정리했다. 최종 07·08 파일의 엄격한 네이티브 로드와 클릭까지 확인했다. 원본 세이브나 게임 구현에는 손대지 않았다.

`native-*.json.gz`는 위 세 가지 실제 정산 결과의 차이 데이터다. 설치한 대응 세이브를 기준으로 `native-evidence.cjs --restore 차이파일 기준세이브 새출력파일`을 실행하면 실제 저장 결과를 바이트 동일하게 복원한다. 압축 전후 복원 해시를 확인했다. 중복된 47MB 검증 세이브 대신 각 약 150KB 차이 데이터만 보존한다.

`GUI_VERIFICATION.json`은 실제 화면·클릭과 저장 상태 증거, `manifest.json`은 최종 9개 해시, `protected-inputs.json`은 기존 파일 보호 해시, `archive.json`과 `FINAL_RESULT.json`은 설치·ZIP의 전 항목 해시 검증 결과다. `install.cjs`·`package.py`는 새 경로만 만들고 기존 대상이 있으면 중단한다.

이 파일들은 인위적 시험 상태이므로 장기 육성용으로 사용하지 않는다. UI 표본의 많은 상태·특성은 표시 검사를 위한 것이다. 보류 중인 밸런스 기획·마법낙인 재현은 이번 범위에 추가하지 않았다.
