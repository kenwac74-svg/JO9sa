# cruel / mercy 지정 행동 누적 — 2026-11-01

사용자가 확정한 행동별 점수를 WORK에 연결한다. 숨겨진 주인공 수치이며, 이번 변경은 지배력·매력의 새 가중치나 새 표시 UI를 추가하지 않는다.

## 확정 규칙

| 경로 | 행동 | 변화 |
|---|---|---:|
| 콜로세움 정식 경기·캣파이트 | 상대 처형 / 생존 | −1 / +1 |
| 안개경계 | 전리품 강제행위 / 데리고 감 / 외양간 전환 | −0.5 / +0.5 / −0.5 |
| 안개경계 | 스파크용 도축 / 고기용 도축 | 각각 −1 |
| 안개경계 | 크라이오 / 경매 | 0 |
| 식품점 도축장 | 돈을 받고 처분 / 도축 후 손질 | 각각 −1 |
| 배제구역 사파리 | 풀어줌 / 판매 / 죽임 / 데려감 | +1 / 0 / −1 / +0.5 |
| 명시적 제외 | 안개괴물 강제 처형 / 콜로세움 연습 종료 | 각각 0 |

목록에 없는 감방·이벤트 선택지 등에는 점수를 붙이지 않는다. 경기에서 패배한 내 인물에게 NPC가 내리는 판정에도 선택 점수를 붙이지 않는다. 기존 ±5 판정과 대사는 유지한다.

## 저장 구조와 함수 계약

- 기존 `jo9_cruel_mercy`는 그대로 유지한다. 새 정수 필드 `jo9_cruel_mercy_half` 하나로 반점 잔여분을 저장한다. 실제 점수는 `whole + half / 2`이며, half는 −1·0·1 중 하나다. QSP의 정수 계산 때문에 필요한 표현이다.
- `jo9_cruel_mercy_apply(args[0])`의 입력은 반점 단위다. −2는 −1점, −1은 −0.5점, +1은 +0.5점, +2는 +1점이다. 반환값 없이 위 두 필드만 변경하고 임시 계산값은 local로 복원한다.
- 새 게임은 두 필드가 0이다. 기존 세이브에 잔여 필드가 없으면 엔진의 기본 0을 사용하므로 기존 정수 점수를 재배율하거나 지우지 않는다. 음수·양수 교차 때 0 방향으로 정규화해 기존 ±5 비교가 정확히 유지된다.
- 기존 완료 선택을 불러와 다시 그려도 과거 선택을 재정산하지 않는다. 이번 정책을 적용하기 전 이미 누적된 점수를 소급 추정하거나 수정하지 않는다.
- 새 대기 플래그나 저장 이관 버전은 추가하지 않는다. 돈·능력치·재료량 산식, 기존 서술·이미지·CSS는 변경하지 않는다.
