# 전투 UI 시험판 v01

사용자 승인 시안과 2026-10-27 테스트 버전 제작 요청을 실행한다. WORK에만 반영한다. 배포 폴더와 기존 세이브는 수정하지 않는다. 커밋·푸시하지 않는다.

1. 기존 jack.qsp와 css/base.css를 날짜별 외부 백업하고 해시를 확인한다. 완료.
2. 몬스터 795×596, 같은 폭의 하단 기록, 좌우 상단 상태와 하단 행동/무기기술 배치를 구현한다.
3. 결과 화면은 좌측 기존 특수 아이콘, 가운데 결과와 기록, 우측 기존 thumb 복귀 링크를 유지한다.
4. 공통 전투 진입에서 화면용 HP 비교값만 초기화하고, 실제 HP 감소 시 타격 SVG/플래시를 표시한다.
5. 원본 구조에서 새 레이아웃 검사가 실패하는 RED를 확인하고, 후보의 실제 QtWebKit DOM·콜백·7개 기술·효과·누락 이미지 fallback을 확인한다.
6. 공식 출고 검사(구조·줄바꿈·패치 재생·멱등성·엔진 9경로)와 변경 검토 후 WORK에 반영한다.
7. 보고서와 재현 스크립트, 백업은 보존하고 진단 QSP/리소스 복사본은 정리한다.

결정: 기존 본체 그림은 불투명하므로 중앙 전장에 채워 표시한다. 투명 배틀러로 변환하거나 원본 그림을 덮어쓰지 않는다. 본체 누락 시 이미지 onerror는 그 그림만 숨겨 기존 전장 배경을 남긴다.

결정: ui_style=2를 원본 공통 진입에서 강제한다. 특정 스타일만 바꾸면 실제 플레이에서 시험판이 보이지 않으므로 두 기존 명령 래퍼를 모두 범위 한정 CSS로 지원한다.

결정: 기존 엔진의 div 표시 규칙이 빈 패널 높이와 기술 목록을 변형했다. 새 root 내부 div만 block으로 지정하며, 기술명 뒤 효과 문구는 기존 inline 흐름을 유지한다.

검증 한계: 기록창은 원본이 재구성하는 최근 행동 묶음이다. 누적 전체 전투기록 기능은 추가하지 않는다. 보상과 전투 밸런스는 변경하지 않는다. CSS 효과는 수치 감소 감지에 따른 시험 연출이며 기술별 전용 애니메이션은 아니다.
