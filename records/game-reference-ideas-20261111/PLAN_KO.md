# 마법 DB와 개인 아이디어 기록

승인: 2026-11-11 사용자 요청. 현재 특성·아이템 열람표에 WORK 마법 목록을 추가하고, 향후 추가할 특성·아이템·마법의 개인 아이디어를 기록한다.

- 게임 DB 3탭(특성/아이템/마법)과 내 아이디어 탭. 기존 검색·분류·키보드 탭·단독 HTML 열람 유지.
- 마법은 WORK의 실제 spell_cast 정의와 연결 메뉴를 추출한다. 이름·효과·소모·조건·출처·확인된 연결을 표시하고 조건/효과 코드를 펼쳐 볼 수 있게 한다.
- 개인 아이디어는 종류·이름·내용·효과·조건·가격/소모·메모. 추가/수정/삭제/분류·검색, JSON 내보내기와 새 ID 추가 가져오기. 기존 ID는 유지한다.
- HTTP 모드: WORK/modtools/game-reference/runtime/ideas.json에 원자적 저장. CAS 충돌 시 초안 보존, 외부 Origin 쓰기 거부. launcher는 개인 파일을 복사/초기화하지 않는다.
- file 모드: 브라우저 저장 + JSON 백업. 생성 HTML에는 개인 기록을 넣지 않는다.
- 저장 실패/손상 파일을 빈 목록으로 덮지 않는다. 불러오기·탭 전환은 작성 중 양식을 보존한다. 출력은 textContent로 처리한다.
- QSP·세이브·이미지·사운드·Full·배포 ZIP·커밋푸시 변경 없음.

실행은 현재 세션에서 진행하고 격리 작업 사본으로 검사한다. 사용자가 이미 기능 추가를 승인했으므로 재승인을 요구하지 않는다.
