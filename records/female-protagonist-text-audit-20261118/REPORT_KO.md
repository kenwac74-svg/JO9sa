# 여주인공 텍스트 보존·작업 범위 조사

2026-11-18 사용자 결정: 제거 실익이 작으므로 게임 자료는 유지한다. 여주 전용 대사는 기본 개편 작업에서 제외한다. QSP·세이브는 수정하지 않았다.

## 측정

원본 WORK QSP는 52,174,068바이트,321개 위치다. `metrics.json`의 원본 SHA256과 원본 보존 검사를 기준으로 한다.

| --- | ---: | ---: | ---: |
| 확인된 여주 화면 문구만 비움 | 50,189,326 | 1,984,742 | 3.804% |
| 전용13개 모듈 본문을 같은 이름의 빈 본문으로 유지하고 공유 위치의 여주 문구도 비움 | 49,283,386 | 2,890,682 | 5.540% |

두 비교안은 위치 이름·순서·개수를 유지하고, 변경한 문자열/본문을 백업 데이터로 되돌려 원본 바이트와 일치했다. 실제 후보 QSP 파일은 만들지 않았다. 컨테이너 구조/복원을 확인한 것이며 실제 엔진의 게임 플레이·로딩 속도 검증은 아니다. 전용 모듈 제거안은 대사 외 로직도 비우므로 여주 플레이 호환을 보장하지 않는다.

동일한 deflate level9에서 원본4,241,715바이트 대비 대사안3,770,475바이트, 모듈안3,691,533바이트다. ZIP 배포물 전체가 이 비율로 줄어든다는 뜻은 아니다.

대표 남성 세이브4개를 원본 변경 없이 읽었다. 현대 세이브에서 여성 메타데이터·표시표·전용 동적 코드까지 별도로 정리하는 가정의 감소량은 약102,222바이트(약0.18%)다. 기존 큰 VOICE_FRAGMENT 캐시23.5MB는 남성 대사 데이터이므로 여주 제거 효과에 포함하지 않는다. 소스 대입문만 없애면 기존 세이브의 문자열이 자동으로 지워지지도 않는다. 자세한 값·상태 보존·실측 한계는 `save-impact/REPORT_KO.md`와 측정 JSON을 따른다.

## 백업 범위

`FEMALE_TEXT_BACKUP.json`에 원문, 위치/행/문자 오프셋, 따옴표, 유효 조건, 분류 이유와 전용13개 위치의 전체 본문을 보존했다. 주인공 번호는 현재 메타데이터의 남주1~18/여주101~124를 사용했다. ELSE 부정 조건·고정 인물번호·표시표의 연결 문자열·동적 정의·여주 상태 문구도 포함한다.

총19,729개 문자열 레코드 중 확인된 범위는18,994개, 혼합/동적/장면 소유권 검토 레코드는735개다. 이 숫자에는 코드 키·경로도 포함되므로 대사 수가 아니다. 화면 문구 비교 대상으로 판정한 것은7,023개다. 여주 표시표6개29문구, 원문 오프셋·내용, 수치 조건 증명과 의심 범위의 실제 IF/ELSE/END 경계를 별도로 확인했다.

이 백업은 **전이 장면까지 완전히 분류한 전체 명세가 아니다.** 사용자가 보존을 결정해 추가 연결 추적을 멈췄다. 항구/대출 장면 후보는 `supplemental-scopes.json`에 미확정으로 남겼으며 제거량에는 포함하지 않았다. 검토 후보는 자동 개편에서 보류하고 공용 대사와 구분한다.

여주 은행과 남주 은행은 변수 이름을 상당수 공유한다. 이름이 같다는 이유로 변수 레코드를 통째로 삭제하거나 남주 쪽 정의를 없애면 안 된다. 여주 전용 원문 위치를 분리하는 방식으로만 작업 범위를 제한한다.

## 보존 결론

게임 내용은 유지한다. 로딩 개선은 입증되지 않았고 크기 절감은 QSP 약4~5.5%, 대표 세이브 약0.18%여서 제거/호환성 작업의 실익이 작다. 편집기와 프로젝트 기본 작업 범위에서 제외하는 방식으로 불필요한 개편 작업을 줄인다.
