# 듀플리카토 목록 수정·300스파크 — 2026-11-17

사용자 테스트에서 별도 테스트 세이브를 불러온 뒤에도 ‘복사할 재능 없음’이 표시됐다. 저장값은 미스티의 cook_affinity=1, 발견값=2, Galateya=0으로 정상이었다. 기존 웹 엔진 검사만으로 설치된 게임 엔진의 동작을 대신할 수 없었던 사례다.

## 원인과 변경

실제 설치 엔진 `game/engine/jack.exe`의 QSP 5.7.0에서 같은 값을 넣어 재현했다. 개별 재능 설명과 조건 문구는 정상이지만 숫자 판정은 0, 목록은 빈 값이었다. 재능 함수가 시작할 때 숫자 RESULT와 문자 $RESULT를 모두 초기화했던 것이 원인이었다. pair/eligible/apply는 숫자 반환만, 나머지는 문자 반환만 초기화하도록 바꾸자 같은 엔진에서 eligible=1, list=cook_affinity가 됐다.

목록과 선택 화면의 토큰 순회는 INSTR 2인자와 명시적인 $MID/$STR로 통일했다. 특히 INSTR 선택 시작 위치 인자는 구버전과 신버전의 순서가 달라 사용하지 않도록 했다. 해당 차이는 [공식 전환 문서](https://dev.qsp.org/ru/blog/2026/01/01/transition-570-at-59x/)에도 명시돼 있다.

추가 승인에 따라 실제 스파크 검사·차감·버튼 가격·확인문·설명서 가격을 900에서 300으로 변경했다. 마법력 B 이상, 양방향 친밀도 각 40, 참가자별 행동력 1, 하루 1회와 수혜자 평생 1회, 발견한 긍정 재능 14종 및 상충 특성 처리 규칙은 유지했다. 새 세이브 항목은 없다.

변경 위치는 `jo9_duplicato`, `jo9_duplicato_traits`, `interaction`의 설명서 가격 한 곳이다. 프리실라 원고·컷신·다른 마법은 그대로다. 설명서 메뉴 추가와 두 설명 페이지는 앞선 records/duplicato-manual-20261117 기록을 따른다.

## 검증

- 실제 설치 엔진 5.7.0: 후보와 같은 두 함수로 21항목 통과. 대상 없음, 발견한 요리 재능 하나, 여러 재능의 순서, 실제 확인→시전 이동과 300스파크·각 1행동력, 제공자 보존·수혜 기록·일일 기록을 검사했다.
- 웹 엔진 5.8.0: 11개 기능 검사 통과.
- 최종 배치본은 실제 엔진에서 검사한 두 함수의 바이트 해시와 일치한다. 설명서 가격만 합친 선언형 패치 재생·역변환·다른 위치 보존을 확인했다.
- 전달한 테스트 세이브의 실제 값으로 최종 WORK 마법 코드를 다시 실행한 검사 5개도 통과했다. 전달 파일은 사용 전 상태이고 원본 22talk.sav는 보존됐다.
- 실제 게임 EXE에서 전체 세이브 로드와 육안 화면 확인은 사용자가 수행한다. 숨긴 격리 엔진 검사를 전체 게임 진행 검증으로 표현하지 않는다.

QSP 결과 해시는 prepared.json·applied.json에, 실제 엔진 로그와 함수별 해시는 native-stderr.log·manifest.json·verification.json에 남겼다. WORK와 추적 QSP 및 해시 명세를 맞췄고 Full·배포 ZIP·기존 세이브·커밋·푸시는 변경하지 않았다.

## 사용

게임을 완전히 종료하고 WORK를 다시 실행한 뒤 `save/듀플리카토_친밀도테스트_20261117.sav`를 불러온다. 조수는 미스티, 노예는 Galateya이며 양방향 친밀도는 80이다. 마법 목록 → 듀플리카토 에센티아 → 예민한 미각으로 시험한다. 정상 행동력 소모를 확인하도록 이 테스트 복사본의 무한 행동력만 해제했다. 재시험은 사용 전 테스트 파일을 다시 불러오면 된다.

## DB 갱신 범위

마법 DB와 화면의 듀플리카토 가격도 300으로 갱신한다. 전체 DB 생성은 기존 특성 생성기의 vampire 검증에서 중단됐으므로, 이번에는 마법 자료만 현재 QSP로 추출한다. 기존 특성·아이템·적·MOB 자료와 각 자료의 출처 해시·사용자 아이디어는 보존한다. 이 기존 생성기 문제는 별도 점검 대상으로 남기며, 전체 DB가 이번 QSP로 재검증됐다고 표시하지 않는다.
