# 전투 이펙트 독립 표시와 배경 경로 복구

적용 범위는 WORK와 추적 CSS다. 배포 폴더·원본 세이브·엔진·설정·기존 ZIP 및 커밋·푸시는 변경하지 않는다. 설치 결과는 `installation.json`과 최종 검사 JSON이 기준이다.

## 확인한 사실과 변경

최신 수정 전 파일에서 이펙트 없음/적 타격/아군 피격/동시 발생을 25·120·350·650·1100ms에 측정했다. 이 표본에서는 UI의 좌표·글꼴·스크롤 변화가 재현되지 않았다. 첨부된 그림과 최신 폰트 수정본을 같은 버전이라고 단정하지 않는다. 또한 DOM 지표가 동일하다는 사실로 실제 QtWebKit 재도색·잔상 문제가 해결됐다고 주장하지 않는다.

기존 효과는 전투 root의 일반 패널과 같은 직접 자식이었다. 사용자 요청대로 전용 `#jo9_battle_fx_layer`를 항상 출력하고, 모든 타격·피격 연출을 그 안에만 배치했다. 이 층은 root 기준 절대 위치 0,0 / 1280×800이며, 자신의 영역 밖을 자르고 클릭을 받지 않는다. 따라서 이펙트가 일반 배치 흐름에 들어가거나 버튼 입력을 가로채지 않는다. 기존 슬래시·플래시의 위치·시간·키프레임과 전투 계산은 유지한다.

직전 UI 이미지 경로 정리에서 실제 UI 파일 `content/pic/bg.png`의 확장자 없는 stem을 일반 장면 폴더 `content/pic/bg/`와 혼동했다. 정규식 대안 전체를 묶지 않아 경계 조건이 마지막 대안에만 적용된 것이 원인이다. 이 때문에 잘못 바뀐 44개 본문의 디렉터리 접두사 280곳을 원래 장면 폴더로 복구했다. 실제 UI 파일 `content/pic/ui/frames/legacy/bg.png`와 나머지 정식 UI 경로·옛 세이브 호환 별칭은 보존한다. 이번 수정은 사용자 그림의 모든 증상을 이 경로 문제 때문이라고 단정하는 내용이 아니다.

## 구성·입출력·의존성

- 패치 `mods/2026-10-27_zzz_battle_effect_isolation.json`은 현재 WORK a48c3817…를 기준으로 한다. QSP 구조와 CRLF를 보존하고 `tools/apply_mods.ps1`로 적용한다.
- `BATTLE_EFFECT_ISOLATION_20261027`: `боевой_интерфейс`, `конец_боя`의 기존 `$jo9_bui_fx` 출력에 wrapper를 추가한다. 입력은 기존 체력 비교로 이미 만든 연출 문자열이며, 반환값·새 상태 변수·새 로케이션·새 저장 키는 없다.
- CSS의 같은 식별자 블록은 wrapper 한 개의 위치·클립·입력 투과·쌓임 순서만 정의한다. 기존 `.jo9-battle-hit`, `.jo9-battle-player-hit`는 이 안에서 기존대로 애니메이션한다. 다른 화면의 CSS와 전투 UI 글꼴·좌표는 바꾸지 않는다.
- `BG_DIRECTORY_PREFIX_FIX_20261027`: 배경과 전환 목록의 잘못된 폴더 접두사만 교정한다. 대사·선택지·전투 피해·보상·소유권·조건·링크는 보존한다.
- wrapper의 QSP와 CSS를 따로 제거하면 CSS 분리 규격이 사라지거나 적용 대상이 없어진다. 롤백은 원래 두 파일을 함께 복구한다. 배경 경로 복구는 별도 식별자로 구분되므로 후속 변경 시 이를 다시 잘못된 경로로 되돌리지 않는다.

## 검증

`baseline-observation-results.json`은 최신 수정 전 기하 변화 미재현 관측이다. `baseline-contract-results.json`은 전용 연출층이 없어 분리 계약이 실패한 결과다. 이를 실제 화면 흔들림 재현으로 표현하지 않는다.

최종 `native-effects-results.json`은 연출층 소유·클립·입력 투과와 이펙트 전·중·후의 UI 불변을 검사한다. 기본 엔진 9경로, 구조·줄 경계·패치 재생·재적용 검사는 `official-report.json`에 남긴다. 잘못된 폴더 접두사 0건 검사는 `scripts/check-bg-paths.cjs`로 재현한다. 의미상 경로 감사는 `semantic-path-regression-audit.json`과 후속 보고서를 함께 본다.

Windows 게임 창 캡처는 바탕화면만 반환했고 재선택 후 활성화도 `failed to activate captured window`로 실패했다. 이전 좌표로 클릭하지 않았다. 사용자에게 PC 조작을 다시 요청하지 않으며, 실제 화면 재도색 품질 검증은 별도 한계로 남긴다. 실제 엔진 내부 DOM·합성 입력 검사와 데스크톱 연속 플레이는 구분한다.

## 복구와 재현

백업은 `candidate.json`의 `backup` 경로다. 원본 QSP와 `css/base.css`를 보존했다. 새 이미지는 없으며, 기존 세이브를 다시 쓰거나 이관하지 않는다.

`scripts/prepare-candidate.cjs`는 지정된 수정 전 해시에서만 후보를 만든다. `scripts/battle-effect-native.cjs`, 공식 출고 검사, `scripts/check-bg-paths.cjs`로 후보를 검사한 뒤 `scripts/install-final.cjs`로 반영한다. 이미 적용된 WORK에 과거 이관 스크립트를 재실행하지 않는다. 과거 패치 JSON은 당시 바이트 재현 기록으로 보존하고, 이번 후속 패치까지 포함해야 정상 경로가 된다. 새 경로 치환 도구를 만들 경우 대안 전체를 그룹화하고 파일 stem 뒤의 폴더 구분자·다른 파일명 접미사를 구분해야 한다.
