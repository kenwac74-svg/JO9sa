# 혀 손실 — 주인공·노예 명령어 확장 시 검토

상태: **현재 구현 제외, 차기 업데이트 검토 대기**.

사용자 지시(2026-10-19): “7. 구현 제외하고 차기 업데이트에서 반영할 요소로 기록할 것. 주인공과 노예 명령어 확장 시 검토할 것으로 기록”.

대상은 앞선 특성 표의 7번 ‘혀 손실’이다. 1~6번 확정 명칭은 펠라 중독, 반사적 구역질, 애널섹스 중독, 애널섹스 혐오, 거센 반항심, 선천적 벙어리다.

주인공 또는 노예의 명령어를 확장하는 작업이 시작되면 구현 전에 이 보류 항목을 사용자에게 알리고 연계 방식을 검토한다. 정해진 날짜의 자동 알림은 아니다.

현재는 생성·설명·목록·편집기·발화 제한에서 제외했다. 기존 세이브에 남은 `jo9_voice_trait=2`는 효과 없는 값으로 보존한다. 재도입 시 이 값을 자동 활성화하지 말고 처리 방식을 먼저 확인한다.

향후 검토할 것은 연결 명령, 상태의 획득·해제, 기존 세이브와의 관계, 발화·교육·다른 행동과의 연결이다. 구체적인 새 명령어·수치·이벤트는 아직 확정하지 않았다. 선천적 벙어리(`jo9_voice_trait=1`)의 현재 동작과 구분한다.
