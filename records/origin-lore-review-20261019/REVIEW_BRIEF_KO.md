# 02번 출신 원고 — 설정 판단 기준

사용자 확정: 기존 설정과 대사 조합 구조를 유지하는 방향으로 검토하되, 설정이 달라지는 부분은 어느 쪽이 게임에 더 어울리는지 판단한다. 직전의 ‘아직 적용하지 말고 항목별 논의’는 유지한다. 이번에는 비교·권고안만 만들며 게임 파일을 수정하지 않는다.

범위: `02_area4_origin_brothel_execution_table.txt`의 세계40·가족55·직업60, 합계155행. 현재 Work 기준 SHA256은 `ae591ef904a5fe0f4cbac3454815ac36cd1475464689869bb75c94e3e7fe7826`이다.

판단 순서:

1. 현재 실제 화면용 조각, 기반 배열, 2.3의 별도 한국어 설명, 인물 생성 코드의 출신·가족·직업·능력치를 대조한다. 기반 한국어 문장의 글자 그대로를 원작 설정이라고 가정하지 않는다.
2. 명백한 오역·불일치를 바로잡는 수정, 기존 설정과 양립하는 세부 보강, 직업·사회제도·인물 경험을 바꾸는 변경, 화자의 평가/말투 변경을 구분한다.
3. 생성되는 출신과 맞는 보강은 채택 후보로 삼는다. 서로 다른 출신 세계의 특징을 지우는 일반화는 줄인다. 고향이 풍족했던 인물과 비참했던 인물의 차이도 배경의 일부다.
4. 과거 이력은 장기 배경으로 두고, 현재 주인공에게 느끼는 복종·공포·만족·증오는 현재 관계의 조각이 담당하게 한다. 현재 상태를 고정하는 새 결말을 과거 설명에 무조건 넣지 않는다.
5. 원어 의미나 연결된 설정이 확정되지 않으면 ‘불확실’로 남긴다. 별도 한국어 자료의 일치나 생성기 정합성은 추천 근거지만 러시아어 원문 검증이라고 표현하지 않는다.

예를 들어 사업가 가족의 ‘조선공학 부품’과 ‘자동차 부품’은 새 설정으로 단정할 수 없다. 2.3 `#txt_woman.qsrc:81`과 현재 출신 조각에는 자동차가 있고, 생성기상 현대·사이버펑크 가족으로 배정된다. 자동차 쪽을 권하지만, 현재 가족 키 `businessman/buissinesman` 불일치로 인한 실제 선택 경로는 문구 판단과 별도로 다뤄야 한다.

복제인간의 훈련 데이터도 ‘운동/신체 제어 기술을 다운로드받았다’와 ‘복종이 강제되는 코드가 완성돼 있다’는 의미가 다르다. 현재 `generate_clone`은 자존심4·습관5·헌신1로 생성한다. 과거의 교육 이력과 현재 관계 수치를 서로 대체하지 않는다.

권고안은 사용자 확정 또는 실제 게임 반영 상태와 구분해 기록한다. 외부 원본 및 여성 전용 코드는 참고 자료로만 읽으며 여성 모드를 다시 활성화하지 않는다.
