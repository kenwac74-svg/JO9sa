# 체력별 기본 행동력 개편

패치: `2026-10-24_ap_curve`. 사용자 확정표 및 2026-10-24 진행 승인에 따라 WORK에만 반영했다. 다음 미구현 작업은 결과 보고 후 별도 승인을 받는다.

| 체력 | 내부 단계 | 기본 행동력 |
|---|---:|---:|
| 죽어감 | 0 | 0 |
| 쇠약함 | 1 | 2 |
| 평범함 | 2 | 3 |
| 건강함 | 3 | 4 |
| 강인함 | 4 | 5 |
| 근육질 | 5 | 5 |

기본 상한 식은 `iif(stamina > 0, min(5, stamina + 1), 0)`이다. 주인공은 기존 별도 체계를 사용한다. 노예·조수·개인실 1~4·수감자·젖소녀·외양간 담당의 공통 동적 정산에 적용된다.

## 실제 동작

- 상한 정산, 다음날 행동력 회복, 신규 생성의 초기 행동력, 영입 시 상한, 기존 UI 9곳의 잠금 칸/툴팁을 같은 곡선으로 맞췄다.
- 일반 다음날 회복은 **새 기본 행동력 - 부상 단계**를 현재 잔량에 더한다. 기존 의술·간호 최소 회복과 마지막 상한 정산을 유지한다. 피로를 없애고 무조건 가득 채우는 방식이 아니다. 예: 쇠약함에서 행동력 -3이면 부상 없는 다음날 -1로 회복한다.
- 기존 세이브의 현재 행동력·반칸·휴식 적립·당일 행동기록에 충전량을 더하지 않는다. 0AP/반칸0 상태는 반복 화면 갱신과 캐시 재적재에도 0이다.
- 낮은 체력의 기존 잔량은 그대로이며, 늘어난 여유는 정상 회복 이후 쓸 수 있다. 신규 생성 캐릭터는 생성 직후부터 새 곡선을 따른다.
- 이미 저장된 음수 `half_action`은 보너스 행동력이므로 보존한다. 기본 칸으로 옮겨 표시될 수 있지만 `2*energy-half_action` 총량을 새로 지급하지 않는다. 죽어감의 **기본** 상한0과 별도 보너스 처리도 구분한다.

근육질 과로 페널티 완화율, 지성별 소비 할인, 의료센터 체질개선, 경제 조정은 이번 기본 곡선 단계에 포함하지 않았다. 1회/반 회 행동 비용·음수 행동력의 체력 손상·운동 한계·보너스 다음날 이월량·휴식 성장·마법 보너스·식비/영양·전투 체력 계산식은 바꾸지 않았다. 행동 여유가 늘어 기존 활동을 더 실행할 수 있게 되는 것은 이 개편의 의도한 효과다.

## 기존 세이브·캐시

원래 로드 흐름인 `$ongload → $newloc → $addon update/full → refresh_database → #static_base`가 저장된 동적 정의를 교체한다. 제품에 새로운 전체 로드 체계나 충전 이관을 넣지 않았다. 다른 장소에 저장된 화면은 기존처럼 다음 전이 때 갱신될 수 있다.

시험에서는 수정 전 `$update_slave_energy_stars` 정의를 주입한 뒤 실제 기존 `$addon update/full`을 실행해, 9역할의 0AP 보존과 쇠약함 상한2가 적용되는 것을 확인했다. 이는 실제 세이브 파일을 UI로 불러온 검사가 아니라 구형 정의를 주입한 엔진 검사다.

기존 세이브 76개와 Full·CSS·설정은 바꾸지 않았다. 최신 WORK를 다시 실행해 세이브를 불러오고 다음 화면으로 이동하면 새 정의가 적용된다. 이미 소모한 행동력이 즉시 채워지지는 않는다.
