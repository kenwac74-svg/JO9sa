# 유니크 고정 등장 경고

캐릭터 편집 화면의 제목 바로 아래에 붉은 경고를 표시한다. 모든 편집 탭에서 보이며, 저장을 차단하거나 캐릭터 설정을 자동 변경하지 않는다.

- 기존 고유 인물 목록은 번호를 기준으로 보존한다. 이름을 지워도 고유 인물 판정이 사라지지 않는다.
- 현재 WORK의 일반 등장 범위와 QSP의 개별 제외 판정을 함께 읽는다. 일반 등장 범위에 들어간 고유 인물이 보호되지 않으면 경고한다. 읽을 수 없는 판정은 확인 불가라고 표시한다.
- 기존에 일반 등장하도록 설계된 민족·농장 템플릿은 유니크 경고 대상에서 제외한다.
- 새 캐릭터에서 이름·파일명·번호를 작성한 뒤 고유 캐릭터를 끄고 일반 등록을 켜면, 저장 전에 경고한다.
- 정상 유니크는 ‘유니크 · 일반 등장 제외’로 표시한다.

구현은 `tools/modding-hub/spawn_warning.py`, `spawn-policy-registry.json`, `overrides/spawn-notice.mjs` 및 기존 서버·캐릭터 화면·통합 CSS·실행기 연결이다. 경고용 자료는 도구에서만 읽으며 게임 JSON·QSP·세이브에 추가 필드를 쓰지 않는다.

기존 Tk 이미지 도구의 유니크 체크는 기존 인물의 이름/파일명/스토리 변경 옵션이다. 이를 해제한 것만으로 일반 등장 등록이 변경되는 근거는 없었으므로 이 체크만으로 경고하지 않는다.

선택한 인물을 다시 열거나 저장한 뒤 반환된 캐릭터 정보를 기준으로 재확인한다. 외부에서 QSP를 바꾼 뒤에는 작성 내용을 보존하고 캐릭터를 다시 열어 확인한다.

제거하려면 서버의 SpawnPolicy import/생성과 decorate_slave 연결, 새 모듈 제공 경로 및 실행기의 빌드 목록, 화면의 spawnNotice 호출과 import, CSS 경고 블록을 함께 되돌린다. 게임 동작과 저장 형식에는 영향이 없다.
