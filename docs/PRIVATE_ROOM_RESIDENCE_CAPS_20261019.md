# 개인실 증축 지역별 상한 — 2026-10-19

사용자 지정으로 백색도시 저택에만 있던 개인실 증축을 아래 8개 거주지로 넓힌다. 수량은 별도 개인실 room1~room4의 총수이며, 기존 임대 시설 boudoir와 구분한다. 적용 대상은 최신 work의 QSP 하나다. 배포 동기화·커밋·푸시는 작업 종료 시 별도로 진행한다.

| 거주지 | 새로 증축할 수 있는 개인실 총수 |
|---|---:|
| 배제구역·추방자 구역 | 1개 |
| 홍등가·뱀자리 구역 | 2개 |
| 황소구역·네크로폴리스 | 3개 |
| 백색도시·중앙구역 | 4개 |
| 빈민가 | 증축 불가 |

기존에 만든 방과 입주자는 그대로 둔다. 상한이 낮은 지역으로 이동해도 방 수를 깎거나 입주자를 삭제·이동하지 않는다. 현재 거주지 상한 이상이면 추가 증축만 막는다. 원래 게임의 이사 조건과 임대 시설 처리는 변경하지 않는다. 개인실 공사 단계는 기존 전역 kulaconstruct를 계속 사용하며, 집마다 별도로 건설 기록을 저장하는 시스템을 추가한 것이 아니다.

## 실제 동작과 비용

- 기존 증축 서비스에서 현재 거주지 한도와 보유 개인실 수를 안내한다. 1개째 5,000$, 2개째 2,000$, 3개째 5,000$, 4개째 10,000$의 기존 가격을 유지한다.
- 거래 실행 시에도 현재 방 수가 바로 전 단계인지, 현재 집에 그 방까지 만들 수 있는지, 돈이 충분한지 확인한다. 허용되지 않은 호출은 방 수와 돈을 바꾸지 않는다.
- 개인실로 가는 버튼과 네 방의 포트레이트를 백색도시 밖에서도 표시한다. 이미 만든 방은 거주지가 있으면 기존 수만큼 접근할 수 있다. ‘2층으로’라는 버튼 이름은 ‘개인실로’로 고쳤다.
- 기존 세이브가 쿨라 상점 안에서 저장된 경우, 정상 데이터 갱신 시 그 상점의 개인실 서비스 메뉴 복사본(7번)도 교체한다. 다른 상점이나 다른 쿨라 메뉴는 건드리지 않는다.

## 코드·입출력·의존성

패치: mods/2026-10-19_private_room_residence_caps.json. 원래 QSP 259개 로케이션의 본문 중 #options, interaction_city, menu_form, main_screen 4곳만 바꾸며, 새 순수 계산 로케이션 jo9_private_room_cap 1개를 추가한다. 원본을 qsrc로 재빌드하지 않는다.

- jo9_private_room_cap: 입력은 현재 $estate. 반환은 숫자 result(0~4). 문자열 대소문자를 정규화해 기존 혼용 표기를 받는다. 저택 없는 상태·빈민가·미지원 거처는 0이다. 저장 데이터·구매 수·입주자는 수정하지 않는다. 안정 표식 PRIVATE_ROOM_CAP_LOOKUP.
- #options의 $KulaShop_options[7]: 위 함수를 호출해 메뉴를 만들고 $sp_text[7], $text_display를 갱신한다. $place가 kulashop인 경우에만 $display_options[7]을 새 정의로 갱신한다. 기존 데이터 재갱신 경로 refresh_database → #options를 사용한다. 새 저장용 리비전이나 이행 플래그는 만들지 않는다. 안정 표식 PRIVATE_ROOM_CAP_MENU.
- interaction_city의 951011~951014: 위 함수·kulaconstruct·sparks를 확인한 뒤 허용된 단계에서만 방 수와 돈을 바꾼다. 기존 npc/장소/복귀 설정과 결과 화면 경로는 유지한다. 안정 표식 PRIVATE_ROOM_PURCHASE_1~4.
- menu_form과 main_screen: 기존에 구입한 방 수를 그대로 읽어 이동과 포트레이트를 표시한다. 안정 표식 PRIVATE_ROOM_ACCESS, PRIVATE_ROOM_PORTRAIT_1~4.

함수와 호출부는 한 묶음으로 유지한다. 함수만 제거하면 메뉴·결제 호출이 실패한다. 메뉴만 되돌리면 비백색도시에서 증축이 다시 막히며, 결제 가드만 제거하면 잘못된 호출의 비용·단계 검사가 사라진다. 접근 경로만 되돌리면 방과 입주자는 남아 있지만 백색도시 밖의 버튼이 사라진다. 식단, 입주자 인물 데이터, 일일 작업·식비, 기존 이사 제한, 임대 시설, 바이커 차고 조건은 수정하지 않았다.
