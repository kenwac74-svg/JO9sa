# 대사 추가 기능

대사 편집실에서 원문을 선택하고 **＋ 대사 추가**를 펼친다.

- **선택한 대사 뒤에 다음 페이지 추가**: 독립된 `$text[n]`에 새 페이지를 삽입한다. 뒤에 있는 대사와 이미지·소리 배열의 숫자 인덱스를 함께 이동한다. 기존 게임의 다음 화살표를 사용한다.
- **현재 대사 끝에 문단 추가**: 선택한 문자열 끝에 `<br><br>`와 새 문단을 붙인다.

추가 미리보기 → 승인 체크 → 선택한 위치에 반영 순서로 저장한다. 기존 자동 백업, 변경 기록, mods JSON 내보내기, 되돌리기를 그대로 사용한다. 새 페이지에 별도 이미지나 효과를 지정하는 기능은 포함하지 않는다.

2026-10-09 보완: 페이지 번호를 직접 참조하거나 페이지별 실행 동작이 있어도, 고정 번호로 연결된 조건·전체 페이지 수·이미지·소리·실행 처리를 함께 조정한다. 기본 도시 이벤트의 결과 처리 연결도 지원한다. 계산식이나 조건별 배열 생성 등 해석하지 못한 연결은 구체적인 분석 대상을 안내한다. 자동으로 새 선택지나 분기를 만들지 않는다. [보완 내역](DIALOGUE_PAGE_INSERTION_20261009.md).
