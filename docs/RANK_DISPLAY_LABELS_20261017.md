# 등급 표시 이름 정리 — 2026-10-17

사용자 조건: 숫자값이나 내부 구분값이면 유지하고, 화면용 텍스트라면 익숙한 이름으로 정리한다. 최신 플레이 QSP를 기준으로 표시 문자만 수정했다. 배포 폴더와 보호 원본은 변경하지 않는다.

## 계산과 분리된 값임을 확인한 근거

`$skill_grade`, `$full_grade`, `$rating`의 문자열 사용처를 조사했다. 이 문자열로 조건 비교·배열 키 선택·동적 실행 분기·저장 데이터 판별을 하지 않는다. 실제 승급, 가격, 의뢰 조건은 숫자 `rating`과 각 능력치 값으로 판정한다. `#static_base`의 `$vb_cycle_rank`는 색상 HTML과 전달받은 표시 문구를 합친다.

`$coach='S'`의 S는 내부 구분값이므로 변경하지 않는다. 변수명, 배열 키, 숫자, 함수 인수의 수치, 연산자, 조건식, 이미지 경로와 EXEC 실행 링크는 유지한다. 게임 저장 형식과 특성 효과도 바꾸지 않는다.

## 적용 범위와 수정 표시

QSP 255개 로케이션 중 13개의 표시 문구를 수정했다. 기본 등급 배열뿐 아니라 개별 속성·기술 이름 끝에 직접 적힌 등급, 성적표, 교육 안내, 길드 계약명, 기존 퀘스트 요구 설명을 맞췄다. 총 609개 기존 표시 줄과 등급 안내 표를 변경했다.

대상: `$newloc`, `interaction`, `interaction_city`, `guild`, `#var_base`, `#help_msg`, `#variative`, `#food_base`, `#quest_base`, `#static_txt`, `#txt_woman`, `#txt_man`, `snk_rm_dialogue_info`.

수정 영역은 `JO9 MOD START RNL001`~`RNL137`, 안내창은 `RANK_LABEL_GUIDE`로 표시한다. `_`로 연결된 대입문은 같은 대입문 전체 밖에 주석을 배치하므로 원래 대사 줄이 함께 포함될 수 있다. 그 안에서도 등급 문자 외 문구는 유지했다. 원래 작성자의 주석은 보존했다. 정밀한 기존 행 번호·원문·변경문·영역 ID 대응은 작업 산출물 `changed-lines.json`에 있다.

트레잇 카탈로그의 천재·백치 요약도 지성 S / F로 맞췄다. 게임의 천재·백치 설명은 기존에 최고·최저 등급으로 표현되어 있어 그 설명과 효과는 변경하지 않았다.

## 사용과 복구

입력은 기존 숫자값이다. 출력만 새 등급 문자로 바뀐다. 기존 세이브는 기존 숫자를 그대로 사용하며 게임의 기존 데이터 갱신 경로가 표시 배열을 다시 정의한다. 게임을 완전히 종료한 뒤 다시 실행하고 저장을 불러와 확인한다.

주석 표식만 지워도 게임 효과는 변하지 않는다. 배열 정의나 대입문 전체를 삭제하면 화면 문구가 빠질 수 있으므로 원래 표시로 복구하려면 백업 또는 선언형 패치의 역변환을 사용한다. 새 함수·로케이션·게임 상태 변수·마이그레이션은 추가하지 않았다.

명기 상태의 부여·해제, 발견 조건, 효과, 편집기 선택 상한은 이번 표시 이름 작업에 포함하지 않았다.

## 검증

- 적용 전 최신 플레이 QSP를 읽고 바이트 왕복 일치 확인. 변경된 각 줄에서 문자열 밖 토큰이 동일함을 확인.
- 독립 검수에서 안내문을 제외한 변경 영역의 실행 코드, EXEC, S++, `_` 연결문 표식 위치를 확인. 선언형 패치를 역적용하면 원본과 바이트 단위로 일치하여 범위 밖 수동 편집 보존 확인.
- `tools/apply_mods.ps1` 적용본과 후보 QSP 바이트 동일. 로케이션 수·이름·설명 필드 유지.
- QSP 5.7.0 엔진에서 등급 정의와 실제 출력 문구 검증. 남녀 주인공 분기, 개별 6단계, 종합·귀족·음식·수태율 11단계, S++, 연결문 성적표를 확인.
- 최종 안내 표는 Headless Edge에서 확인 버튼과 겹치지 않도록 확인했다. 실제 게임 클라이언트 실행·화면 점검은 수행하지 않았다.
