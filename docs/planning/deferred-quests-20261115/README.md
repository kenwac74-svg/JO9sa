도축장 문서는 미성년 인물과 연결된 성적 설정을 재작성하지 않은 부분 문서다. 원안 전체의 복원이나 대체 기획 승인으로 간주하지 않는다. 펠리시티 문서는 원안 누락을 표시한 인계이며 완성 기획서가 아니다.

통계·캐릭터 생성 공식·하사 VIP·기존 펠리시티 이미지 작업과 분리한다. 도축장 상세 설정·대사와 이벤트 생성기 조율은 후속 작업이다. “기획 보관”을 게임 반영 또는 구현 재개로 표시하지 않는다.
