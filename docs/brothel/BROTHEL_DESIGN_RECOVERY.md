# JO9 창관 경영 모드 (Brothel) — 복원 기준 문서

- 저장 브랜치: `brothel`
- 작성일: 2026-10-06
- 목적: 과거 「재고나 창관모드」 기획 대화와 기존 기획서에서 합의된 내용을 다시 미정으로 되돌리지 않기 위한 기준 문서.
- 원칙: 과거 기록에서 확인되는 사항만 **확정**으로 적는다. 세부 원문을 아직 회수하지 못한 사항은 **복원 필요**로 분리한다.

## 1. 모드의 기본 방향 — 확정

- JO9 안에 별도의 **창관 경영 콘텐츠**를 추가한다.
- 비프로스트식 창관 경영의 핵심 구조를 참고하되 JO9의 기존 시스템과 데이터를 최대한 재사용한다.
- 단순 소모형 콘텐츠가 아니라 **유지·성장형 창관**이다.
- 창관은 지도상의 실제 장소/부동산으로 취급하며, 구매 후 방문·운영한다.
- 방문과 영업에는 JO9의 기존 행동력 체계를 사용한다.
- 새로운 전용 능력치를 무분별하게 추가하지 않고 JO9의 기존 캐릭터 데이터, 상태, 명령 가능 판정 등을 우선 재사용한다.

## 2. 코어 영업 루프 — 확정

기본 루프:

1. 창관 방문
2. 당일 고객/고객 큐 생성
3. 고객의 요구와 상태 확인
4. 접객 가능한 종업원 선택
5. 기존 JO9 능력치/특성 기반으로 매칭 및 접객
6. 고객 상태와 만족도 변화
7. 지불액/수익 산출
8. 누적 만족도와 창관 성장에 반영
9. 고객 큐 소진 또는 강제 폐점 시 영업 종료

### 행동력

- **고객 1명 접객 = 행동력 1 소모**를 기본 단위로 한다.
- 종업원 스태미나가 0인 상태에서 추가 접객 시 **추가 행동력 0.5**가 걸리는 것으로 과거 기록에서 복원된다.
- 종업원 정신력 0은 기분/정신 관련 페널티와 연결한다.
- 기존 JO9의 행동력·피로·기절/위험·기분 시스템을 재사용한다.
- 사용자가 2026-10-06 다시 확인한 과거 합의: **그룹 고객은 약 1.5명 상당의 처리 단위/보정**을 사용했다. 정확히 어떤 항목에 1.5배를 적용했는지는 원 대화 회수 후 문구를 보강한다.

## 3. 종업원 — 확정

- JO9에서 기존 규칙상 **명령 가능한 노예**를 창관 종업원으로 배치한다.
- 창관 레벨에 따른 종업원 **최소 등급 제한은 두지 않는다**.
- 등급과 기존 능력치는 배치 제한이 아니라 매칭/접객 결과와 만족도에 영향을 준다.
- 창관 Lv.1의 기본 종업원 슬롯은 **1명**, 레벨이 오를 때마다 **+1명**으로 복원되어 있다.
- 별도의 창관 전용 캐릭터 스탯을 대량 추가하지 않는다.

## 4. 고객 상태 모델 — 확정된 골격

고객은 JO9의 기존 상태 개념을 활용한 임시 스테이터스를 가진다.

- **HP = 고객 예산/지불 가능한 금액의 기반값**
- 접객 과정의 HP 감소량은 실제 **지불액**과 연결된다.
- **고객 스태미나 0 = 착정/육체적 완료 상태**
- **고객 정신력 0 = 만족도 보너스 상태**
- **스태미나와 정신력이 모두 0 = 최상 결과**

고객 만족도는 단일 수치만이 아니라 **육체 만족 / 정신 만족의 이중 구조**를 사용한다.

## 5. 고객 요구와 매칭 — 확정된 방향

- 비프로스트식 **요구 슬롯 매칭**을 핵심으로 한다.
- 고객 요구를 보고 적합한 종업원을 선택하는 것이 플레이의 중심이다.
- JO9 기존 등급, 성기술, 외모·체형, 취향, Trait 등 기존 데이터를 가능한 범위에서 매칭 판정에 재사용한다.
- 완벽히 맞는 종업원이 없더라도 접객 자체가 불가능해지는 구조로 만들지 않는다.
- 만족도 중심으로 결과와 창관 성장이 이어진다.

## 6. 그룹/다인 고객 — 확정된 골격

- 그룹 고객은 개별 고객 여러 명을 UI에서 따로 굴리는 대신 **하나의 group 객체**로 취급하는 구조가 과거 기록에서 확인된다.
- 그룹의 HP/스태미나/정신력은 **인원수에 따라 증가/배수 처리**한다.
- 그룹 접객 시 종업원 능력치/효율에는 별도 보정이 들어간다.
- 행동력/처리량 측면에서는 사용자가 다시 확인한 **약 1.5명 상당 규칙**이 존재한다.
- 정확한 그룹 인원별 배율표와 1.5 규칙의 적용 대상은 원 대화 추가 복원 대상이다.

## 7. 창관 성장 — 확정

- 고객 만족도를 누적해 창관이 성장한다.
- 창관 레벨은 **Lv.1 ~ Lv.10**.
- 레벨업은 단순 돈 지불이 아니라 **고객 만족도 누적**을 핵심 성장축으로 한다.
- 종업원 슬롯은 Lv.1 1명에서 시작하여 레벨당 +1명으로 복원되어 있다.

## 8. 시설/확장 — 확정된 방향

# 2026-10-08 통합 확정사항 (대화 재정리)

## 고객 요구/선호
- 고객 요구는 처음부터 전부 공개.
- 핵심요구는 고객 등급별 고정 개수: 하급 1 / 중급 2 / 상급 3.
- 핵심요구 후보: 외모등급, 외형/체형, Trait, 상태조건. 상태조건은 하급에는 없고 중급부터 등장, 상급에서 확률 증가.
- 성적 능력/서비스 능력은 핵심요구가 아니라 추가선호.
- 추가선호는 0~3개. 모든 등급에서 가능하나 고등급일수록 2~3개 확률이 높음.
- 핵심요구와 추가선호는 동일 조건 중복 및 서로 모순되는 조건 조합을 금지한다.
- 핵심요구는 같은 카테고리에서 여러 개 나올 수 있다.
- 핵심요구 미충족이어도 배정 가능.
- 단계형 핵심요구: 요구 방향으로 1단계마다 +20%, 반대 방향으로 1단계마다 -20%, 최대 ±2단계(±40%). 단계형이 아닌 핵심요구는 O/X, 미충족 -20%.
- 외모등급 요구는 최소등급 방식.
- 추가선호는 전부 O/X. 충족 1개당 +20%, 미충족 페널티 없음.
- 총 매칭 보정치에는 상한을 두지 않는다. 완벽 매칭이면 기본 만족도/수익 효과가 2배 이상 가능.

## 고객 돈/지속성
- 고객에게 별도 행동력 스탯을 만들지 않는다. 대화에서 '고객 행동력'이라 표현해도 구현상 고객 잔여 보유금이다.
- 고객 카드는 이름, 초상, 등급, 핵심요구, 추가선호, Trait, 잔여 보유금을 하나의 지속 객체로 유지한다.
- 고객 최초 보유금 = 등급별 최소 기본금 + 랜덤 추가금. 기본금은 최소 보장. 하/중/상 금액구간은 서로 겹치지 않게 별도 테이블로 설계.
- 매 방문 현재 창관 레벨의 입장료를 먼저 잔여금에서 차감한다.
- 서비스 이용료는 입장료 차감 후 잔액의 일정 %이며 만족도 등급별 고정 테이블, 등급 한 단계마다 균등 증가.
- F = 서비스 이용료 0 + 공통 실패 이벤트. 입장료는 이미 지급됨.
- S에서 서비스료율은 100%. S+는 경제효과가 S와 동일하고 고객 멘트만 다름.
- 잔여금이 현재 입장료보다 큰 고객만 다음 방문 가능.
- 잔여금 <= 현재 입장료가 되면 실질적 '착정완료/소진'으로 보고 단순 이탈, 카드 폐기 후 신규 고객 생성. 반드시 잔액 0일 필요 없음.
- 창관 레벨업으로 입장료가 상승해 기존 고객 잔액이 입장료 이하가 된 경우도 동일하게 소진 처리.
- 같은 고객은 잔액이 남는 동안 동일 카드/요구/선호를 유지하며 재방문한다.

## 만족도/연장전
- 만족도 표시는 JO9 기존 등급체계를 그대로 차용하며 S+까지 사용.
- F는 낙제/완전불만족이며 F 이하 공통 실패 이벤트 1종.
- S/S+는 일반 요구 매칭만으로 자동 도달하는 특별 보상이 아니다.
- 1차 서비스에서 A 이상이면 연장전 확률 판정 자격이 생긴다.
- 연장전 확률은 핵심요구/추가선호 만족 개수와 단계형 핵심요구의 초과충족 %에 연동.
- 연장전은 별도 화면 페이즈가 아니라 같은 고객+같은 종업원의 연속 서비스. 종업원 행동력은 추가로 소모.
- 연장전에서 동일 종업원 고정.
- S는 연장전 맥락에서 발생하는 최상위 만족 결과이며 S+는 시스템상 S와 동일, 멘트 차이만 둔다.
- 고객 카드 소진(착정완료)은 만족도와 별개. 낮은 만족도라도 잔여금이 입장료 이하가 되면 소진된다.

## 지명
- 일반 고객은 과거 만족도를 누적 기억하지 않는다.
- 신규 지명은: 1차 A 이상 -> 실제 연장전 발생/완료 -> 방문 최종 종료 시 33% 확률.
- 연장전이 없으면 신규 지명 판정도 없음.
- 지명은 UI에 별도 핵심요구 슬롯으로 표시하지 않는 숨은 판정 보정.
- 지명 접객원 배정 시 핵심요구 충족 개수 +1 효과(원래 핵심요구 개수 상한을 넘지 않음).
- 단계형 핵심요구가 있으면 가장 개선폭이 큰 조건 하나를 최대 충족(+40%) 상태로 보정. 단계형이 없으면 미충족 O/X 하나를 자동 충족. 이미 전부 충족이면 추가효과 없음.
- 지명 보정은 최종 만족도와 연장전 확률 계산에 모두 포함.
- 기존 지명자를 다시 이용: 최종 A 이상이면 유지, B 이하이면 철회하고 그 페이즈에서는 신규 지명 재판정 없음.
- 다른 접객원을 이용해도 기존 지명은 자동 철회되지 않음. 다른 접객원에게 신규 지명 조건이 성립하고 33% 판정에 성공할 때만 새 접객원으로 지명 교체. 실패/B 이하이면 기존 지명 유지.
- 한 고객의 현재 지명은 최대 1명.

## 고객 등급/창관 등급
- 고객 기본 등급은 하/중/상 3단계. '부자(가칭)'는 4등급이 아니라 추후 설계할 고객 Trait.
- 부자(가칭)의 현재 개념: 같은 등급보다 예산이 높고 높은 만족도에서 팁 보너스가 큼. 명칭/전체 Trait 체계는 후속 설계.
- 창관 Lv.1~3: 하급 고객 100%.
- Lv.4~6: 하급 25% / 중급 75%.
- Lv.7~10: 중급 25% / 상급 75%.
- Lv.4/Lv.7 승급 시 기존 고객 풀도 즉시 새 등급 구성으로 재편하며 지명 고객도 보호하지 않는다.
- 활성 고객 카드 풀 크기는 창관 레벨에 따라 증가한다. 정확한 슬롯 수 표는 아직 미정.

## 종업원 행동력
- 일반 1:1 서비스 1회는 종업원 행동력 1을 소모한다.
- 그룹 접객 등 특수상황만 별도 보정.
- 과거 복원 문서의 '스태미나 0에서 추가 행동력 0.5' 문구는 현재 확정안과 충돌하므로 폐기/재검증 대상으로 본다.

## 설계 진행 원칙 추가
- 이후에는 사용자가 모든 수치를 하나씩 설계하도록 질문하지 않는다.
- 비프로스트 원본 소스 + 기존 JO9 기획 + 확정사항을 비교하여, 충돌 없는 부분은 기획자가 자동 결정한다.
- 사용자 질문은 서로 충돌하거나 게임 경험을 크게 바꾸는 핵심 선택지만 묶어서 제시한다.
