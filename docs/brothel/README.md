# JO9 창관모드 문서 색인

이 폴더는 `brothel` 브랜치의 창관모드 기획·분석·프로토타입 문서를 보관한다.

## 문서 우선순위

1. 사용자의 최신 명시적 결정
2. 기능별 최신 상세 명세
3. 통합 확정사항 문서
4. 복원 기준 문서
5. 초기 v0.1 기획 자료

과거 문서와 최신 기능 명세가 충돌하면 최신 기능 명세를 우선한다.

## 현재 문서

- `NECRO_WING_SPEC_v0_1.md`
  - 네크로관의 현재 기준 명세
  - 사망 기록 스냅숏, 구형 세이브 변환, 30일 사용 기간, Lv.4·7·10 해금, 슬롯 1·2·3명, 비용 배율, 상태 전이, 페이즈 사용 제한, UI와 테스트 기준
  - 과거의 접객 횟수 기반 보존수명 차감안과 Lv.10 일괄 해금안을 대체

- `BIFROST_COMPARISON_AND_DECISIONS.md`
  - 비프로스트 원형 비교, 고객·매칭·연장전·Trait·경제 설계

- `BROTHEL_DESIGN_RECOVERY.md`
  - 과거 대화와 기획서에서 복원한 창관모드 결정사항

- `PROTOTYPE_SPEC_v0_1.md`
  - 독립 수직 슬라이스 프로토타입 명세

- `QSP_INTEGRATION_STATUS.md`
  - 실제 QSP 통합의 준비 상태와 소스 버전 차이

## 현재 구현 상태

네크로관은 설계 명세만 확정된 상태이며 QSP에는 아직 구현되지 않았다. 실제 구현 전에는 `NECRO_WING_SPEC_v0_1.md`의 구현 전 검증 항목을 원본 QSP에서 확인한다.
