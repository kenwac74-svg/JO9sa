사용자가 237f6e1 적용 후에도 개인실2의 체크가 일반식에서 바뀌지 않고 팝업의 작은 글꼴·넘침도 남는다고 확인했다. 이전 브라우저 검사는 클릭 링크와 배치만 검증해 실제 QSP 변수 갱신 경로를 놓쳤다. 이전 수정만으로 선택 문제가 해결됐다는 판단을 철회한다.
