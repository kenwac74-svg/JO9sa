# 안개지역 순차 교대 전투 — 2026-10-17

최신 플레이 QSP를 직접 읽은 뒤 만든 패치다. 배포본과 순정 원본은 변경하지 않는다. 변경 블록은 `JO9 MOD START/END FOG_*`로 표시한다.

## 확정 동작

- 일반 안개 순찰 14종의 기존 전투 선택지를 `혼자 전투에 돌입한다 / 노예와 전투에 돌입한다 / 조수와 전투에 돌입한다`로 교체한다. 기존 회피 선택지는 그대로 둔다.
- 현재 정상 상태이며 행동력이 남은 노예/조수만 선택지에 표시한다. 별도 동행 UI와 포트레이트를 추가하지 않는다.
- 노예 또는 조수 중 한 명이 선봉. 해당 인물이 패배하면 주인공만 이어받는다. 다른 동료로 추가 교대하지 않는다.
- 출전자마다 기존 장비 선택 화면을 사용한다. 교대 중 적은 행동하지 않는다.
- 적의 남은 체력·지구력·사기, 적별 상태, 쓰러진 적, 남은 대상과 적의 특수기 사용 이력을 유지한다. 교대 출전자의 상태만 초기화한다.
- 주인공부터 시작하거나 교대 뒤 주인공이 패배하면 기존 패배/죽음 처리를 그대로 따른다.

## 사용자 승인 수치

| 동료 결과 | 처리 |
|---|---|
| 체력 0 이하 | 인물 데이터를 기존 `clear_slave_instance`로 제거. 사망 메시지. 자동 매각·도축 보상이나 재생성 없음 |
| 지구력 0 이하 | 해당 인물의 `_rate['wounds'] += 80`. 무상처 기준 중상(4단계). 회복·흉터는 기존 시스템 |
| 사기 0 이하 | 해당 인물의 `_rate['moral'] -= 10`, `_rate['mood'] -= 10`. 실제 도망·인물 상실 없음 |

판정 우선순위는 체력 → 지구력 → 사기다. 둘 이상이 동시에 0이면 위쪽 한 가지를 적용한다. 기존 전투 엔진은 적 전멸을 먼저 승리 판정하므로, 마지막 적과 동료가 동시에 쓰러졌을 때에도 별도 정산에서 동료의 사망/기절을 반영한다. 적이 모두 쓰러졌으면 빈 전투를 주인공에게 넘기지 않는다.

헌신 −10은 누적값 감소이며 무조건 등급 −1을 뜻하지 않는다. 기존 누적값과 현재 등급의 하락 문턱에 따라 달라진다. 기분 누적값 −10은 기본 계산상 기분 −1에 해당한다.

부상 +80은 기존 투기장 패배 부상 40~80의 상단이며, 무상처 기준 `중상` 문턱 80에 맞춘 값이다. 이미 부상이 있으면 합산되며 기존 최대값 제한이 적용된다. 자연 회복과 흉터 발생을 새로 정의하지 않는다.

동료의 행동력은 기존 전투의 잔여 지구력 환산 구간을 재사용하고, 전투 전 행동력보다 높아지지 않게 한다. 지구력 소진 시 −4로 정산한다. 별도의 전투 경험치나 보상 재분배는 이번 범위에 추가하지 않았다. 기존 안개지역 전리품·퀘스트·주인공 보상 계산을 유지한다.

## 코드 지도

새 로케이션은 기능용 **1개**, `jo9_fog_relay`다. `menu`(선택지), `begin`(선봉 설정), `handoff`(교대), `settle`(동료 정산), `finish/close/reset`(종료·정리)로 구분했다. 페널티 세 값은 `begin` 설정 구간에 모았다. 추가적인 연령·행위·성격 필터는 없다.

| 기존 로케이션 | 변경 이유 |
|---|---|
| `#options` | 일반 순찰 선택지 호출. 교대 전투의 빈 장비 슬롯 화면이 선택하지 않은 다른 인물의 팔뚝·허벅지 장비값까지 지우지 않도록 보호 |
| `$newloc` | 기존 세이브에 남은 선택지 캐시를 1회 갱신 |
| `$combat_variable_reset` | 순찰 시작·전투 종료 시 교대 임시값 정리 |
| `начать_бой` | 교대 재개 시 적 상태/체력 초기화 생략. 새 출전자 상태만 정리 |
| `конец_боя` | 동료 패배 시 기존 최종 종료 대신 교대 |
| `конец_раунда` | 적 3명 이상 전멸 시 원본이 사기를 변경하기 전에 동료의 실제 사기를 보관하여 정산 누락 방지 |
| `выход_из_боя` | 동료 승리 정산, 주인공 전용 부상·행동력 계산과 구분 후 임시값 정리 |

기존 로케이션 7곳, 치환 작업 24개, 새 로케이션 1개. 패치 JSON은 정확한 old/new와 전후 해시를 가진다. 역치환으로 기존 모든 로케이션 원문 복원을 검사했다. 장비 선택의 기존 버그를 광범위하게 수정하지 않고 새 교대 전투에서만 다른 인물의 슬롯 삭제를 막았다.

`jo9_fog`는 현재 전투용 저장값이며 전투가 끝나거나 다음 순찰을 시작하면 초기화된다. 기존 세이브에 일괄적인 인물 데이터 변경을 하지 않는다. `jo9_fog_revision`은 선택지 캐시 갱신 여부만 기록한다.

## 검증과 한계

- QSP 읽기/쓰기 바이트 일치, 후보 재파싱, 따옴표/중괄호 전처리 상태 확인.
- 실제 신규 QSP 및 통합 블록을 제한된 문장 실행기로 검사: 100개 제어 흐름 사례. 양쪽 동료, 사망/기절/사기/승리, 교대 후 적 유지, 교대 1회 제한, 중복 정산 방지, 상태별 선택지, 마지막 적과 동료 동시 소진, 선택하지 않은 인물 장비 보존 포함. 독립 코드 검수에서 발견한 3명 이상 적 전멸 시 원본 사기 덮어쓰기와 동료 정산의 충돌을 재현하고 수정했다.
- 공식 저장소의 `apply_mods.ps1`로 사본에 재적용한 바이트가 후보와 동일. 재적용 시 이미 적용됨으로 건너뛰는지 검사.
- 설치 시 최신 플레이 해시 재확인, 날짜 백업 검증, 쓰기 후 해시 확인. 배포 QSP 해시 불변 확인.
- **네이티브 클라이언트 실행과 실제 플레이는 자동 수행하지 않았다.** 제한 실행기는 전체 QSP 엔진을 대체하지 않으며 장비 화면·세이브 UI·전리품 연결은 사용자 플레이 확인이 필요하다.

## 플레이 확인 순서

1. 클라이언트를 완전히 종료한 뒤 플레이 폴더에서 다시 실행하고 기존 세이브를 불러온다. 안개지역에서 새 순찰을 시작한다.
2. 혼자/노예/조수 선택지와 각 출전자의 장비 목록이 맞는지 확인한다.
3. 동료 패배 후 주인공 장비 화면이 나오며, 적의 깎인 체력과 쓰러진 적이 유지되는지 확인한다.
4. 체력 소진은 동료 상실, 지구력 소진은 부상, 사기 소진은 헌신·기분 저하인지 확인한다.
5. 동료 단독 승리 및 주인공 교대 승리 모두 기존 전리품 처리가 한 번만 나오는지 확인한다.

커밋·푸시와 배포본 동기화는 수행하지 않았다.
