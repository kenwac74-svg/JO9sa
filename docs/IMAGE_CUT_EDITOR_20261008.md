전환 컷 편집 흐름 수정 — 2026-10-08

- 별도 `jo9CutDialog`를 제거했다. 체크리스트와 자동 감지 워크샵 모두 기존 작업 영역의 드롭박스와 구도·비교 편집기를 사용한다.
- 전환 컷 추가를 누르면 드롭박스 위에 실제 저장 파일명과 모드가 표시된다. 변환한 결과 카드의 `새 컷 저장`으로 저장한다. 일반 A컷 교체 버튼은 이 작업을 처리하지 않는다.
- 현재 화면의 A컷과 같은 폴더·파일명 계열의 B/C/D컷을 함께 표시한다. 기존 물리 컷은 `작업 영역에서 편집`으로 불러오고 `이 컷에 저장`으로 백업 후 교체한다.
- JO9O 경로에 연결된 원본 B컷은 `새 작업 컷으로 편집`으로 불러오고 다음 C 이상 번호로 저장한다. JO9O 원본을 덮어쓰지 않는다. 원본 없는 B 예약은 표시할 이미지가 없으며 C부터 저장하는 기존 규칙을 유지한다.
- 여러 입력 이미지는 사용 중인 임시 컷 번호를 피해서 번호를 배정한다. 번호 순서대로 저장해야 하며 서버는 오래된 번호와 A컷 변경을 검사한다. 기존 컷 편집 모드에서 새 파일을 넣으면 같은 입력 카드가 갱신된다.
- 컷 목록 탐색은 QSP를 읽거나 변경하지 않는다. 새 컷 저장은 기존 검증된 등록기를, 기존 컷 저장은 기존 백업·패치 작업 기록기를 사용한다.
- 게임에 적힌 파일명의 대소문자와 실제 Windows 경로 표기가 다른 경우 실제 디렉터리 항목을 확인한다. 다른 폴더나 서로 다른 철자의 파일명은 합치지 않는다.

검증:

- 실제 내부 브라우저: 별도 컷 창 없이 기존 드롭박스에 시험 입력·변환, 일반 교체 저장 비활성 확인. 시험 입력은 저장하지 않고 제거했다.
- 실제 주안수 A/B 목록과 다음 C 파일명 표시, B를 기존 구도·비교 편집기로 불러오는 흐름 확인.
- 자동 검사 5개: 경로/대소문자, 실제 B/C 목록, JO9O 가상 B 보호, 기존 B 저장 시 원본 백업과 A/QSP 보존 및 오래된 저장 거부, 다중 입력 번호와 입력 갱신.
- 별도 시험 게임에서 기존 B/C 등록·QSP 왕복·원본 연결·번호 충돌 회귀 검사 통과.
