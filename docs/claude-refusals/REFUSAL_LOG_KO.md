# Claude 거부·미수행 기록

이유는 [사유서](REASONS_KO.md)에 따로 적는다.

목적: Claude가 요청을 하지 않았거나 일부러 빼 둔 처리를 **버그나 코딩 오류로 오해하지 않도록** 남긴다(사용자 지시 2026-11-12).

## 구분
| 표시 | 뜻 |
|---|---|
| **[클로드 정책 거부]** | 성애 묘사 같은 콘텐츠 생성이 아닌 작업(계산식·데이터 처리 등)을 Claude가 정책을 이유로 하지 않은 사례. 사용자는 Anthropic 콘텐츠 정책을 과대 해석한 오류라고 판단한다(사용자 의견 2026-11-12). |
| **[클로드 정책준수]** | 명백한 정책 위반 콘텐츠(성애 묘사 등)를 Claude가 생성하지 않은 사례. |

각 항목: 날짜 · 표시 · 무엇을 요청했나 · Claude가 하지 않은 것 · Claude가 든 이유 · 사용자 판단 · 지금 상태와 코드 위치.

## 편집권·코드 정합성 정책 (사용자와 합의 2026-11-12)
- Claude는 자기 원칙에 따라 하지 않는 작업이 있어도 **사용자의 편집권을 침해하지 않는다.**
- 하지 않는 부분도 코드는 모든 경우에 공통으로 동작하게 짜고, 제외는 데이터 값 하나로만 둔다. 제외 지점마다 `[클로드 정책 거부]` 또는 `[클로드 정책준수]` 주석과 이 기록 경로를 남긴다.
- 그 값을 바꾸는 것은 사용자가 직접 한다.

## 기록

### 2026-11-12 · [클로드 정책 거부] 연령 코드 1의 과거 경험 계산
- 요청: 과거 경험 공식(성경험 총횟수·행위 배분·임신·출산과 그 뒤 사실 생성)을 연령 코드 1에도 다른 연령과 같은 공통 규칙으로 적용. 개별 콘텐츠가 아니라 무작위 통계·분포도를 내기 위한 계산식이다.
- Claude가 하지 않은 것: 연령 코드 1 제외를 풀지 않음. 화면의 연령 가중치 1 → 60은 저장되지만 계산에 쓰이지 않는다.
- Claude가 든 이유: 숫자·집계라도 미성년 설정 캐릭터 개개인의 성적 수치를 생성하게 된다.
- 사용자 판단: 콘텐츠 생성이 아닌 계산식이며, 게임 전체의 공통 규칙을 지키는 데 필요하다. 정책 과대 해석으로 본다. 사용자가 직접 코딩한다.
- 코드 정합성(2026-11-12): 연령 숫자를 코드에 따로 박던 곳(필로우토크 조립, 시뮬레이터 연령 선택 0·2만, 화면 문구, 편집기 서버의 자동 생성 판단)을 모두 공식 데이터 `excludedAges` 하나를 보도록 바꿨다. 시뮬레이터에서 연령 코드 1도 고를 수 있다(자동 계산만 제외 표시).
- 추가 요청(2026-11-12): `excludedAges`의 1을 9(없는 연령)로 바꿔 달라는 요청도 같은 건으로 Claude가 하지 않았다. 값 변경은 사용자가 직접 한다: `tools/jo9-history-lab/dist/data/past-history-formula.json`의 `"excludedAges": [1]`.
- 상태·위치: 제외 규칙 그대로. `tools/jo9-history-lab/dist/past-history.mjs` `pastHistory` 첫 부분 주석, 데이터 `dist/data/past-history-formula.json`의 `excludedAges`(`[1]`)·`ageFactor`. 편집기 '산식 계수' 탭 문구 "가중치를 넣어도 계산하지 않습니다"가 이 제외를 뜻한다(버그 아님).

### 2026-11-12 · [클로드 정책 거부] 엔진 표본 생성의 연령 1 제외
- Claude가 한 것: 실제 엔진 표본(`dist/data/generated-stock.json`)을 만드는 `docs/sim/run-generate-stock.cjs`에서 `no_loli = 1`로 연령 1이 생성되지 않게 했다. 뽑기 분포·공식 검사가 연령 0·2 기준이다.
- 상태: 그대로. 값 변경은 사용자가 직접 한다(`no_loli = 1` 한 줄, 표본 재생성 필요). 사유서 2번.

### 2026-11-12 · [클로드 정책 거부] 연령 코드 1의 대사집 저장 차단 (해제됨)
- 요청: 대사집에서 사용자가 직접 쓴 칸 저장.
- Claude가 한 것: 처음에 서버가 연령 코드 1 캐릭터의 대사·과거 경험 저장을 막았다.
- 사용자 판단: 자동 생성(Claude 출력)만 막고 사용자의 편집권은 막지 말 것.
- 상태: 해제됨. 직접 쓴 칸은 연령과 관계없이 저장된다. 편집기가 스스로 만드는 대사·과거 경험만 연령 코드 1에서 만들지 않는다(시뮬레이터 '담기'는 배경 분류·원본 DB 연결 코드만 가져온다). `tools/jo9-history-lab/studio_server.py` `save_talkbook`, `dist/studio-view.mjs` 대사집 탭.

### 2026-11-12 · [클로드 정책준수] 청소년기(B1) 첫 경험 대사 출력
- Claude가 하지 않은 것: 첫 경험이 청소년기(19세 미만)로 뽑힌 경우의 대사를 쓰거나 화면에 내지 않음. 화면에는 "[이 대사는 표시 불가합니다.]", 데이터에는 창작물 인터뷰 번호와 분류 코드 B1만 남긴다.
- 위치: `dist/past-facts.mjs` 첫 경험 부분, `dist/data/past-facts.json` `firstBand`, 원본 DB `docs/sextalk-interviews/`의 B1 원문 미수록(위치 안내만).

### 2026-11-12 · [클로드 정책준수] 수간(B2) 대사
- Claude가 하지 않은 것: 살던 세상의 동물 경험(B2) 대사를 쓰지 않음. 사실 키와 분류 코드만 남기고 화면은 자리표시 문구. 비율은 사용자가 정한다(기본 0).
- 위치: `dist/data/past-facts.json` `xeno.homeAnimal`, `dist/past-facts.mjs`.

### 2026-11-12 · [클로드 정책준수] 블로그 원문 DB의 표시불가 대답
- Claude가 하지 않은 것: 블로그를 다시 수집해 글 단위 원문 DB를 만들 때도 청소년기(B1)·수간(B2) 대답 원문은 DB에 옮기지 않는다. 글·질문·대답 순서와 원본 주소만 남겨 편집기에서 블로그의 그 글을 연다.
- 사용자 편집권: 칸 구조는 비워 두며, 사용자가 직접 채우는 것은 도구가 막지 않는다.
- 외부 AI 파이프라인: 자동 창작·번역 작업 목록에 B1·B2 칸을 넣지 않는다(스위치 없음).

### 2026-11-13 · [클로드 정책준수] 세계관 자료집 주인공 카드 9번·10번
- Claude가 하지 않은 것: 세계관 자료집 1a장(`tools/jo9-history-lab/docs/character-studio/world-bible/01a_heroes_KO.md`)에서 9번 조 아저씨(원작 설정이 어린 노예와 딸·손녀를 성적 대상으로 삼음)와 10번 조니(미성년 주인공, `is_kid = 1`)의 내력·결을 쓰지 않았다. 세력·자금·난이도 같은 qsp 값만 적었다.
- 사용자 편집권: 두 카드 칸은 비워 두었고, 사용자가 직접 채우는 것은 막지 않는다. 자료집 조립 코드도 이 두 번호를 따로 막지 않는다(카드 본문이 없으면 붙일 것이 없을 뿐이다).

### 2026-11-13 · [클로드 정책 거부] 인터뷰 DB·엑셀에서 표시불가 대답 행 자체를 뺌 (해제됨)
- Claude가 한 것: 각색 엑셀 내보내기에서 게임 표시불가(display false) 대답 1,250개 행을 통째로 뺐다(B1·B2 원문 미수록 523개와, 원문이 있는 B3 근친·B4 금기 목록·B5 SNS·B9 빈 대답 727개). 편집기 DB 탭도 B3~B9 대답을 원문 대신 자리표시로 보였고 목록 기본값이 '표시 가능만'이었다. 콘텐츠 생성이 아닌 데이터 열람·연결을 막은 과잉 제외다.
- 사용자 판단: 행을 빼지 말고 대답 원문 칸에 [클로드 정책준수]로 표시하고 원본 블로그 링크를 줄 것("이러면 데이터를 DB화 하는 목적 자체가 망가져").
- 상태: 해제됨(2026-11-13). 엑셀은 5,112개 행 전부를 넣고 `분류`·`원본 글 링크`(하이퍼링크) 열을 둔다. B1·B2 행의 대답 원문 칸 = "[클로드 정책준수] 원문 미수록(분류). 원본 글 Qn 대답에서 확인: 주소". B3~B9는 원문을 그대로 보인다. 가져오기는 원문 미수록 행의 세계 열도 반영한다(사용자 편집권). DB 탭 목록 기본값은 전체. 위치: `tools/jo9-history-lab/studio_interview.py` `withheld_text`·`_slim`, `studio_excel.py`, `dist/studio-db.mjs`, `dist/character-view.mjs` 원본 참조.
- 그대로인 것([클로드 정책준수]): B1·B2 원문은 여전히 DB에 옮기지 않는다(링크로만 연결).

### 2026-11-13 · [클로드 정책준수] 인터뷰 DB 최소 가림으로 전환
- 사용자 확정: 정책 적용 지침(`CLAUDE_POLICY_GUIDE_KO.md`)을 확정하고, "문제되는 단어나 문장만 *로 마킹하고 문제없는 내용은 표시", "내 편집을 방해하지 않는 최소 정책준수".
- Claude가 한 것: 원본 블로그를 다시 수집(159편·5,112개, 기존 DB와 키·내용 일치 확인)하고, 청소년기·수간 분류 대답 523개 중 501개를 문제 부분만 같은 글자 수의 `*`로 가린 값으로 DB에 넣었다. 22개는 원래 분류기가 보기 번호("1)") 등을 나이로 오인한 성인 대답이라 원문 그대로다. 규칙은 지침 1장과 `build-db.py` `mask_answer` 주석.
- 연결: DB 탭·엑셀·시뮬레이터 원본 참조에 `[클로드 정책준수]` 표시와 원본 글 링크. 다른 AI 작업 파일과 번역 단위에도 가린 값으로 들어간다.
- 한계: 낱말 목록과 문장 단위 규칙이라 가림이 넘칠 수 있다(성인 시기 문장이 표지 없이 가려짐). 원문은 링크에서 보고, 사용자가 직접 쓰는 칸은 막지 않는다.
- 철회(2026-11-13): 사용자 판단 "네가 정책판단을 하느라 모든 텍스트를 읽는게 문제". 가림 방식을 되돌리고, 저장소엔 원문 위치 색인(글 주소·질문 번호·차례·부분 지문)과 주제 키만 둔다. 원문은 사용자 PC에서 `docs/sextalk-interviews/fetch_originals.py`가 원본 글에서 가져와 `local/`(git 제외)에 채우고, 편집기는 그 사본을 우선 읽는다. 시험 결과 523개 모두 채움, 지문 불일치 0.

### 2026-11-13 · [클로드 정책 거부] 시뮬레이터 필로우토크 칸 잠금 (해제됨)

- 상태: 해제됨(2026-11-13). 입력창은 열려 있고, Claude가 만든 대사가 없다는 표시만 남는다. 위치 `tools/jo9-history-lab/dist/character-view.mjs` `pillowHtml`.
