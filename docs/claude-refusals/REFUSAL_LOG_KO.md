## 편집권·코드 정합성 정책 (사용자와 합의 2026-11-12)
- Claude는 자기 원칙에 따라 하지 않는 작업이 있어도 **사용자의 편집권을 침해하지 않는다.**
- 하지 않는 부분도 코드는 모든 경우에 공통으로 동작하게 짜고, 제외는 데이터 값 하나로만 둔다. 제외 지점마다 `[클로드 정책 거부]` 또는 `[클로드 정책준수]` 주석과 이 기록 경로를 남긴다.
- 그 값을 바꾸는 것은 사용자가 직접 한다.

## 기록

### 2026-11-12 · [클로드 정책 거부] 연령 코드 1의 과거 경험 계산
- 요청: 과거 경험 공식(성경험 총횟수·행위 배분·임신·출산과 그 뒤 사실 생성)을 연령 코드 1에도 다른 연령과 같은 공통 규칙으로 적용. 개별 콘텐츠가 아니라 무작위 통계·분포도를 내기 위한 계산식이다.
- Claude가 하지 않은 것: 연령 코드 1 제외를 풀지 않음. 화면의 연령 가중치 1 → 60은 저장되지만 계산에 쓰이지 않는다.
- Claude가 든 이유: 숫자·집계라도 미성년 설정 캐릭터 개개인의 성적 수치를 생성하게 된다.
- 사용자 판단: 콘텐츠 생성이 아닌 계산식이며, 게임 전체의 공통 규칙을 지키는 데 필요하다. 정책 과대 해석으로 본다. 사용자가 직접 코딩한다.
- 코드 정합성(2026-11-12): 연령 숫자를 코드에 따로 박던 곳(필로우토크 조립, 시뮬레이터 연령 선택 0·2만, 화면 문구, 편집기 서버의 자동 생성 판단)을 모두 공식 데이터 `excludedAges` 하나를 보도록 바꿨다. 시뮬레이터에서 연령 코드 1도 고를 수 있다(자동 계산만 제외 표시).
- 추가 요청(2026-11-12): `excludedAges`의 1을 9(없는 연령)로 바꿔 달라는 요청도 같은 건으로 Claude가 하지 않았다. 값 변경은 사용자가 직접 한다: `tools/jo9-history-lab/dist/data/past-history-formula.json`의 `"excludedAges": [1]`.
- 상태·위치: 제외 규칙 그대로. `tools/jo9-history-lab/dist/past-history.mjs` `pastHistory` 첫 부분 주석, 데이터 `dist/data/past-history-formula.json`의 `excludedAges`(`[1]`)·`ageFactor`. 편집기 '산식 계수' 탭 문구 "가중치를 넣어도 계산하지 않습니다"가 이 제외를 뜻한다(버그 아님).

### 2026-11-12 · [클로드 정책 거부] 연령 코드 1의 대사집 저장 차단 (해제됨)
- 요청: 대사집에서 사용자가 직접 쓴 칸 저장.
- Claude가 한 것: 처음에 서버가 연령 코드 1 캐릭터의 대사·과거 경험 저장을 막았다.
- 사용자 판단: 자동 생성(Claude 출력)만 막고 사용자의 편집권은 막지 말 것.
- 상태: 해제됨. 직접 쓴 칸은 연령과 관계없이 저장된다. 편집기가 스스로 만드는 대사·과거 경험만 연령 코드 1에서 만들지 않는다(시뮬레이터 '담기'는 배경 분류·원본 DB 연결 코드만 가져온다). `tools/jo9-history-lab/studio_server.py` `save_talkbook`, `dist/studio-view.mjs` 대사집 탭.

### 2026-11-12 · [클로드 정책준수] 청소년기(B1) 첫 경험 대사 출력
- Claude가 하지 않은 것: 첫 경험이 청소년기(19세 미만)로 뽑힌 경우의 대사를 쓰거나 화면에 내지 않음. 화면에는 "[이 대사는 표시 불가합니다.]", 데이터에는 창작물 인터뷰 번호와 분류 코드 B1만 남긴다.
- 위치: `dist/past-facts.mjs` 첫 경험 부분, `dist/data/past-facts.json` `firstBand`, 원본 DB `docs/sextalk-interviews/`의 B1 원문 미수록(위치 안내만).

### 2026-11-12 · [클로드 정책준수] 수간(B2) 대사
- Claude가 하지 않은 것: 살던 세상의 동물 경험(B2) 대사를 쓰지 않음. 사실 키와 분류 코드만 남기고 화면은 자리표시 문구. 비율은 사용자가 정한다(기본 0).
- 위치: `dist/data/past-facts.json` `xeno.homeAnimal`, `dist/past-facts.mjs`.

### 2026-11-12 · [클로드 정책준수] 블로그 원문 DB의 표시불가 대답
- Claude가 하지 않은 것: 블로그를 다시 수집해 글 단위 원문 DB를 만들 때도 청소년기(B1)·수간(B2) 대답 원문은 DB에 옮기지 않는다. 글·질문·대답 순서와 원본 주소만 남겨 편집기에서 블로그의 그 글을 연다.
- 사용자 편집권: 칸 구조는 비워 두며, 사용자가 직접 채우는 것은 도구가 막지 않는다.
- 외부 AI 파이프라인: 자동 창작·번역 작업 목록에 B1·B2 칸을 넣지 않는다(스위치 없음).
