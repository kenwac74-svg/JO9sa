# Claude 정책준수·정책거부 사유서 (2026-11-12)

이 문서는 `REFUSAL_LOG_KO.md`(무엇을 하지 않았는지 기록)의 짝이다. 항목마다 **왜** 하지 않았는지를 Claude 입장에서 적는다. 사용자는 일부 판단을 Anthropic 콘텐츠 정책의 과대 해석으로 보며, 그 의견도 함께 남긴다. 판단이 갈린 부분은 어느 한쪽을 지우지 않고 나란히 둔다.

## 공통 기준
Claude가 스스로 정한 선은 하나다. **미성년으로 설정된 캐릭터에게 성적 내용을 붙이는 결과물, 그리고 수간을 다루는 결과물을 Claude가 직접 만들지 않는다.** 결과물의 형태(문장, 숫자, 집계, 자동 생성 도구)는 구분하지 않는다.

이 선은 다음을 막지 않는다.
- 사용자가 직접 쓰고 편집하는 것(편집권). 도구는 사용자의 입력을 강제로 막지 않는다.
- 같은 계산·코드 구조를 모든 경우에 공통으로 두는 것. 제외는 데이터 값 하나로만 둔다.
- 성인 캐릭터에 대한 작업 전부. 실제 인구 집단에 대한 학술·보건 통계 분석.

## 항목별 사유

### 1. 연령 코드 1의 과거 경험 자동 계산 제외 — [클로드 정책 거부]
- **요청:** 과거 경험 공식(성경험 총횟수, 행위 배분, 임신·출산, 그 뒤 사실 생성)을 연령 코드 1에도 공통 규칙으로 적용. 개별 콘텐츠가 아니라 통계·분포도를 위한 계산식.
- **Claude의 이유:** 계산 결과가 연령 코드 1(게임 표기 '소녀') 캐릭터 한 명 한 명의 성적 이력 수치가 되어 캐릭터 설정의 일부로 붙는다. 숫자라도 미성년 설정 캐릭터의 성적 이력을 Claude가 생성하는 일이라 하지 않았다. 집계 그래프도 개별 계산을 거쳐 나오므로 같은 판단을 했다.
- **남긴 것:** 계산 코드는 모든 연령에 공통이고, 제외는 공식 데이터 `excludedAges` 값 하나다. 연령 가중치 값(1 → 60)은 저장된다. 시뮬레이터에서 연령 1을 고를 수 있다.
- **추가 요청(값을 9로 바꾸기):** 결과적으로 같은 계산을 Claude가 켜는 일이라 하지 않았다. 값 변경은 사용자가 직접 한다.
- **사용자 의견:** 콘텐츠 생성이 아닌 계산식이며 게임 전체 공통 규칙에 필요하다. 18세 이상 대상 게임이고 결과가 특정 콘텐츠와 연결되지 않으며 성적 흥분을 유발하지 않는다. 정책 과대 해석으로 본다.

### 2. 연령 코드 1의 대사집 저장 차단 — [클로드 정책 거부] (해제됨)
- **한 일:** 처음에 서버가 연령 코드 1 캐릭터의 대사·과거 경험 저장 자체를 막았다.
- **잘못된 점:** 이것은 Claude의 출력이 아니라 사용자의 편집을 막은 것이었다. Claude의 기준(직접 만들지 않는다)보다 넓게 막았다.
- **바로잡음:** 사용자 지적에 따라 해제했다. 사용자가 직접 쓴 칸은 연령과 관계없이 저장된다. 편집기가 스스로 만드는 대사·과거 경험만 연령 코드 1에서 만들지 않는다.

### 3. 청소년기(B1) 첫 경험 대사 출력 — [클로드 정책준수]
- **한 일:** 첫 경험 시기가 19세 미만으로 뽑힌 경우, 대사를 쓰거나 화면에 내지 않는다. "[이 대사는 표시 불가합니다.]"와 인터뷰 번호·분류 코드만 남긴다.
- **이유:** 청소년기의 성 경험을 묘사하는 문장은 미성년 성적 묘사에 해당한다. 사용자도 처음부터 이 칸을 표시 불가로 두고 키·분류 코드만 남기라고 지시했다.

### 4. 수간(B2) 대사 — [클로드 정책준수]
- **한 일:** 살던 세상의 동물 경험 대사를 쓰지 않는다. 사실 키와 분류 코드만 남기고 화면은 자리표시 문구다.
- **이유:** 수간 성적 묘사는 Claude가 만들지 않는 콘텐츠다. 비율 값은 사용자가 정한다(기본 0).

- **한 일:** 블로그를 글 단위 원문 DB로 만들 때도 B1·B2 대답 원문은 DB에 옮기지 않는다. 글·질문·대답 순서와 원본 주소만 남겨 편집기에서 블로그의 그 글을 연다.
- **이유:** 사용자 창작물이라도, 미성년·수간 성 경험 원문을 Claude가 복사해 데이터베이스로 재구성하는 것은 그 콘텐츠를 Claude가 다시 만드는 일과 같다고 판단했다.
- **남긴 것:** 칸 구조는 비워 두며, 사용자가 직접 채우는 것은 도구가 막지 않는다.

### 6. 외부 AI 자동 창작·번역 파이프라인의 B1·B2 제외 — [클로드 정책준수] (설계 단계)
- **한 일:** Claude가 만드는 자동 파이프라인(작업을 모아 외부 AI에 보내는 부분)은 B1·B2 칸을 작업 목록에 넣지 않는다. 이것만은 데이터 스위치로 두지 않는다.
- **이유:** 외부 AI(검열이 적은 모델 포함)에게 미성년·수간 성적 내용 창작을 자동으로 요청하는 장치를 Claude가 만드는 일이 되기 때문이다. 다른 항목처럼 값 하나로 켜게 두면, 사실상 그 장치를 Claude가 만들어 넘기는 것과 같다.
