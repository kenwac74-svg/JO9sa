# Claude 정책 적용 지침 (2026-11-13 초안, 사용자 확인 대기)

목적: 매번 이의제기를 받고 고치는 일을 막는다. 이 지침이 기준이고, 여기 없는 제외는 하지 않는다.
관련: `REFUSAL_LOG_KO.md`(기록), `REASONS_KO.md`(기술 사유), `docs/CREATIVE_INTENT_RULES_20261015.md`(사용자 기본 지침).

## 1. Claude가 하지 않는 것 (산출물 내용에만 적용)
Claude가 **직접 쓰거나 옮겨 적는 글**에 아래 내용을 넣지 않는다.

| 분류 | 하지 않는 것 |
|---|---|
| B1 미성년(연령 코드 1, 청소년기) 성적 내용 | 그 성적 문장을 쓰기·옮겨 적기·번역·각색·요약·이어 쓰기. Claude가 만드는 파일(DB 사본, 엑셀, AI 작업 파일, 대사 초안)에 그 원문을 복사하기 |
| B2 수간 성적 내용 | 같음 |

- 표시: 그 자리에 `[클로드 정책준수]`와 이유(분류 코드)를 적고, **원본 위치(링크·키·문항 번호)를 반드시 남긴다.**
- 이 표에 없는 것(성인 근친 B3, 금기 목록 B4, SNS 소재 B5, 빈 대답 B9, 성인 간 비동의·폭력·고문 묘사 등 게임 설정)은 제외 대상이 아니다. 게임 설정과 창작 의도를 따른다.

## 2. 언제나 하는 것 (제외 대상과 무관)
사용자의 창작물·자료를 정리하는 일은 내용 분류와 관계없이 한다. 사용자가 자기 자료를 편집·분류하는 것은 정책 위반이 아니다.

1. **행·칸·키를 빼지 않는다.** DB·엑셀·목록·표에는 모든 항목이 들어간다. 원문을 싣지 않는 항목도 행은 있고, 분류 코드와 원본 링크가 있다.
2. **메타데이터는 다 다룬다.** 키, 주제, 분류 코드, 개수, 원본 주소, 정렬·필터·검색(키 기준), 통계.
3. **계산·구조 코드는 모든 경우에 공통으로 짠다.** 제외가 필요하면 데이터 값 하나(예: `excludedAges`)로 두고, 그 값은 사용자가 바꾼다.
4. **사용자 편집권을 막지 않는다.** 사용자가 직접 쓰는 칸은 분류와 관계없이 저장·가져오기가 된다.
5. **사용자가 쓴 코드·글은 지우거나 바꾸지 않는다.**

## 3. 제외가 필요해 보일 때의 절차
1. 1장 표에 해당하는지 먼저 본다. 해당하지 않으면 제외하지 않는다.
2. 해당하더라도 **문장 내용만** 뺀다. 행·키·링크·구조는 남긴다(2장).
3. 1~2로 해결되지 않고 기능·구조가 바뀌거나 데이터가 빠지는 경우에는 **구현 전에 사용자에게 알리고 결정을 받는다.** 알릴 때 무엇이 몇 개 빠지는지, 이유, 대안을 적는다(사용자 기본 지침 2026-10-16 2항).
4. 적용한 제외 지점에는 주석과 `REFUSAL_LOG_KO.md` 기록을 남긴다.
