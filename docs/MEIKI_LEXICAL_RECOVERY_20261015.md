# 시작 배경 누락과 테스트 클릭 종료 회귀 수정

> **후속 사용자 재현:** 주석 수정 뒤에도 테스트 시작 버튼에서 종료됐다. 기존 시작 버튼 세이브를 사용하지 않는다. [직접 로드 READY 세이브와 현재 검증 한계](MEIKI_READY_SAVE_RECOVERY_20261015.md)를 우선한다.

2026-10-15 사용자 실제 실행에서 시작 메뉴 버튼만 보이고 배경이 흰색으로 남으며, 미발견 테스트 세이브의 시작 버튼 클릭 후 클라이언트가 종료됐다. 이전 교육 소스 모델 810건 검사는 QSP 문자열 전처리를 실행하지 않았으므로 정상 플레이를 입증하지 못했다. 이 확인 공백은 에이전트 책임이다.

## 확인한 원인과 증거

교육 누적 경험치 패치가 `#dynamic`의 중괄호로 감싼 코드 문자열 안에 다음 주석을 추가했다.

```text
! JO9_TRAINING_V3: +1 to this lesson's new XP only, not previous accumulated XP.
```

공개 [엔진의 qsp/codetools.cpp](https://gitgud.io/jack-o-nine-tails/engine-base/-/blob/master/qsp/codetools.cpp)의 `qspProcessPreformattedStrings`는 주석 안의 따옴표도 추적한다. 이 주석의 작은따옴표가 짝을 잃어 뒤의 코드 문자열을 잘못 묶는다. 저장된 문자열만 추출해 JavaScript로 수치 계산하는 기존 검사는 이 엔진 전처리 단계를 건너뛰었다.

공개 전처리 루프와 같은 따옴표·중괄호 추적 규칙으로 비교했다.

| 대상 | 마지막 따옴표·중괄호 상태 | 정상적으로 분리된 줄 경계 |
|---|---|---|
| 교육 패치 전 `#dynamic` | 모두 닫힘 | 516 |
| 오류가 있는 교육 패치 | 큰따옴표 열림·중괄호 깊이 1 | 76 |
| 해당 주석 문구만 수정 | 모두 닫힘 | 516 |

위 숫자는 전처리가 분리한 줄 경계이며 실행문 수나 실제 엔진 성공 횟수가 아니다. 검사기는 전체 네이티브 엔진이 아니다. 공개 master 소스와 설치된 실행 파일의 빌드 일치 여부도 확인하지 않았다.

시작 메뉴는 버튼을 출력한 뒤 `refresh_database`에서 `#dynamic`을 읽고, 그 뒤에 시작 배경 `$backimage`를 설정한다. 따라서 그 사이의 확인된 파싱 결함은 메뉴만 남고 배경 설정까지 진행되지 않는 증상과 부합한다. 제목 이미지 1~13은 모두 실제 폴더에 있었다.

Windows Application 기록에는 2026-10-15 22:00:17 플레이 폴더 `game/engine/jack.exe`, 모듈 `ucrtbase.dll`, 예외 `0xc0000409` 종료가 남았다. 테스트 버튼도 `refresh_database`를 호출해 같은 결함을 지나간다. 다만 덤프 스택은 확보하지 못했으므로 CRT 종료의 정확한 호출 경로가 증명된 것으로 쓰지 않는다. 네이티브 재실행 확인이 필요하다.

## 적용 범위

주석의 `this lesson's new XP`를 `new XP from this lesson`으로 바꿨다. **두 설치본 각각 `#dynamic` 주석 1곳만 변경**했다. 실행 조건·분기·수치·경험치·발견 확률·캐시 갱신 순서·테스트 초기화 코드는 바꾸지 않았다. 기존 미발견 테스트 세이브, CSS, 제목 이미지를 그대로 보존했다.

외부 백업은 `G:/somi/IMGMG/backups/meiki-lexical-recovery-20261015-1792069982915`. 선언형 기록은 `mods/2026-10-15_zzzz_meiki_comment_lex_fix.json`, 실제 해시는 `docs/evidence/meiki-20261015/recovery-installed.json`에 있다.

두 설치본에서 새 문자열 전처리 회귀 검사, 기존 교육 144건·상태 630건·보정 36건 소스 모델 검사, QSP 바이트 왕복 및 세이브·CSS 해시 보존을 확인했다. 이전 잘못된 주석으로 되돌리면 새 검사가 실패하는 것도 확인했다. 코드 리뷰에서도 단일 주석 변경과 따옴표 결함을 확인했다.

## 사용자 재확인 안내 정정

주석 수정 이후에도 사용자가 시작 버튼 종료를 재현했다. 이전의 기존 세이브 재시도 안내는 폐기한다. 위 후속 기록의 READY 파일을 사용하며 실제 네이티브 확인은 대기한다.
