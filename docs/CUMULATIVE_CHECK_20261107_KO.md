## 판정

**3차 r2는 2.4.1 본편에 적용하는 누적 패치다.** 2차 r4 최종 필수 경로 1,967개 중 3차 원장에 빠진 경로는0개다. 마지막에 추가한 엘사 이미지도 동일 해시로 들어 있다.

| 구성 | 2차 r4 | 3차 r2 |
|---|---:|---:|
| QSP | 1 | 1 |
| 전체 JSON | 1,158 | 1,158 |
| 게임 이미지 | 808 | 831 |
| 동봉 WORKSHOP | 0 | 419 |
| 게임/도구 필수 파일 합계 | 1,967 | 2,409 |

- 기존808장 게임 이미지는 모두 같은 경로·해시로 유지됐다. 추가 게임 이미지는23장이다.
- 기존 파일 중 내용이 바뀐 것은 QSP와 시루·펠라게야 JSON2개다.
- WORKSHOP의419개 파일은 UI 이미지·스크립트·실행 런타임을 포함한다. 이미지 파일을 압축 전체에서 세면 도구 이미지까지 포함되어 게임 컷신 수보다 많다.
- 3차 원장의 PNG/JPG/WebP 수는 게임831장과 도구357장을 합한1,188개다. 릴리즈 노트에 넣은 스크린샷3장은 게임 런타임 원장과 별도다.
- 1차 필수 이미지와 호환 PNG23개 보존은 2차 누적 기록 및 3차 출고 보고에도 명시돼 있다. 이전 차수 ZIP을 순서대로 다시 설치할 필요가 없다.
