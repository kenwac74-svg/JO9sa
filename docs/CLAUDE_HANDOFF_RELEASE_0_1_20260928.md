## 설치 및 자산 정책

- 게임은 포터블 폴더형. 고정 설치 경로를 요구하지 않는다. APPLY.cmd 실행 후 실제 `game/jack.qsp` 선택.
- 처음 설치할 때 `game/_JO9_SNKmod_STATE`에 변경 전 원본을 자동 백업. 기존 백업 폴더/이전 UI 패치가 없어도 설치 가능.
- CHECK는 읽기 전용, RESTORE는 설치 전 파일 복원. 원래부터 있던 다른 패치의 백업이 없으면 그 이전 상태를 재생성할 수는 없다.
- UI 자산의 최종 경로는 `game/content/pic/SNKmod/{ui,buttons,bg,...}`. 예전 `game/SNKmod/content/pic`가 아니다.
- 이미지 교체기는 PIC 아래에서 파일명으로 찾는다. 기존 파일명 보존.
- 일반 캐릭터/배경/세이브는 패치 설치 대상이 아니다. 수정된 이미지·패치 파일이 발견되면 파일 목록을 알리고 Y/N 확인. 무조건 중단하는 정책은 폐기되었다.
- JSON/CSS/QSP와 조건에 맞는 엔진을 백업 후 적용. Qt 해시가 맞지 않으면 엔진만 건너뛴다.
- installer의 상태 탐색은 구 `JO9_UI_SNKMOD`와 신 `JO9 UI_overhaul_SNKmod` 모두 인식한다.

## 개인실 UI 확정 사항

- 우측 카드 제목은 `개인실N:이름`. 중복 상단 개인실 제목 없음.
- 행동 하위 메뉴에서도 우측 카드·네임바 버튼·상태 아이콘·기능 버튼·하단 설명·1층 돌아가기 유지. 바뀌는 것은 좌측 행동 목록.

- 사회화·영향 버튼은 숨김. 청소/음식 준비 업무도 숨김.
- 개인실은 휴식·특별 포상 공간: **안개 괴물 착정 업무는 명시적으로 제외**.
