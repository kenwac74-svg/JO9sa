# 테스트 시작 버튼 종료 재현과 직접 로드 세이브

2026-10-15 사용자는 주석의 따옴표 결함을 고친 뒤에도 **테스트 시작 클릭 시 클라이언트가 종료됨**을 보고했다. Windows Application 기록의 22:18:32 종료는 플레이본 `game/engine/jack.exe`, `ucrtbase.dll`, 예외 `0xc0000409`다. 이전 22:00:17 기록과 같은 종류지만 정확한 내부 호출 스택은 확보하지 못했다. 주석 파싱 수정만으로 이 종료가 해결됐다고 볼 수 없다.

## 이번 조치

실행 중 데이터베이스 갱신·새 인물 생성·일행/개인실 초기화를 한꺼번에 실행하는 기존 `EXEC` 시작 버튼을 사용하지 않는 **직접 로드용 복사 세이브**를 만들었다. 기존 버튼은 정상 세이브에서 비어 있던 `$onnewloc`도 강제로 켰다. 원본 `menu_form`이 이미 `gs '$newloc'`를 호출하므로 이 추가 콜백은 필요하지 않았다. 다만 이 콜백이나 긴 명령 자체를 종료의 단독 원인으로 확정하지 않는다.

이번에는 정상 홈 화면의 `auto_decade.sav`를 오프라인으로 복사·편집했다. 기존 화면·액션·현재 위치·타이머·`$ongload`·`$onnewloc`는 그대로 보존했다. 별도 시작 버튼이나 초기화 명령을 주입하지 않았다. **게임 QSP, CSS, 엔진 및 발견 확률은 이번 작업에서 변경하지 않았다.**

| 항목 | 새 파일 |
|---|---|
| 파일명 | `JO9_MEIKI_READY_20261015.sav` |
| 위치 | 플레이 및 배포 폴더 각각 `game/save/` |
| 현재 대상 | 기존 성인 이사벨라, 기존 연령 값 2·유형 2571 그대로 |
| 테스트 상태 | 상태 0, 발견·판정 이력·초기화 이력 0 |
| 기술 | 지정 기술 6개와 해당 XP 0에서 시작 |
| 환경 | 홈 화면, 개인실 연결 없음, 메뉴 열기·행동 가능하도록 테스트 복사본 값 조정 |
| 자동저장 | 복사본의 일/순 자동저장 꺼짐. 수동 저장은 별도 이름 사용 |

테스트 준비를 위한 조건·수치 변경은 복사 세이브에만 한정된다. `SLAVE`의 대상 상태/기술/일부 태도·행동 수치, 대응하는 기존 `SLAVE_RATE` 값, `MASTER_ENERGY`, `MENU_FORM`, 자동저장 옵션이다. 각각의 전후 값은 `docs/evidence/meiki-20261015/ready-save-manifest.json`에 기록했다. 원본 세이브는 덮어쓰지 않았다.

## 사용 방법과 남은 확인

1. 게임의 불러오기에서 **`JO9_MEIKI_READY_20261015.sav`**를 직접 선택한다. 별도의 **테스트 시작** 버튼을 누르는 방식이 아니다.
2. 기존 `JO9_MEIKI_UNDISCOVERED_TEST_20261015.sav`는 사용하지 않는다. 해당 파일은 증거 보존을 위해 지우거나 덮어쓰지 않았다.
3. 먼저 홈 화면과 이사벨라 메뉴를 클릭해 종료 여부를 확인한다. 이 단계가 통과한 뒤 기존 게임 메뉴에서 발견 테스트를 진행한다.
4. 판정 확률은 기존 **5%**다. 실패했다면 새 READY 파일을 다시 불러온다. 보장 발견이나 확률 상향은 하지 않았다.

기존 결함 파일을 검사했을 때는 빈 로드 콜백 때문에 회귀 검사가 실패했고, 새 파일은 통과했다. 두 설치본의 파일 해시 일치, 바이트 왕복, 기존 헤더·변수 슬롯 순서·대상 외 데이터 보존, 원본 세이브/QSP/CSS 해시 보존을 확인했다. **이 검사는 데이터 구조 검사이며 실제 클라이언트 로드·클릭·발견 성공을 입증하지 않는다. 네이티브 재검증은 사용자 담당으로 대기한다.**
