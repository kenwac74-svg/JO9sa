# 발견 시 기술 보장과 교육 경험치 보정

2026-10-15 사용자 수정안에 따라 S++ 확장과 하위 기술 각각 +1 등급 보정은 취소했다. 기존 노예 기술 상한 S+(5)를 유지하면서, 발견 시 기술 보장과 지정 교육의 누적 경험치 +1을 두 게임에 각각 반영했다. 합의한 기술 구현 항목은 반영했으며 실제 QSP 실행·발견·교육 확인은 사용자 테스트 대기다. 정책 지원 제한 및 나중에 만들 특수 이벤트는 기존 범위를 유지한다.

등급 부여 여부는 기존 `jo9_meiki_initialized`의 버전 2로 기록한다. 새 배우 속성 필드는 만들지 않았다. 이미 알려진 특성에 대해서도 패치 적용 뒤 최초 비복원 상태 확인 시 한 번 보장한다. 이후 다른 원인으로 기술이 낮아졌다고 매번 다시 올리지는 않는다.

기존 `skill_adv_mul`, 누적 XP, 승급 기준, 성실도·기분·성향 계산을 그대로 사용한다. 경험치 +1은 기존 새 경험치 계산이 끝난 뒤 한 번만 더한다. 기존 경험치 전체에 배수를 적용하거나 성공점수를 올리지 않는다. +1은 전역 성장 배수와 무관한 실제 XP 1점이다.

3. 기존 게임 메뉴의 수락되는 성인 상호작용으로 최초 전환을 진행한다. 발견 확률은 **그대로 5%**다. 강제 발견·RNG 조작·확률 상향은 없다. 실패했다면 이 테스트 파일을 다시 불러오고 시작 버튼을 누른다. 한 번 전환한 인물에게 반복 행동해도 재추첨하지 않는다.
