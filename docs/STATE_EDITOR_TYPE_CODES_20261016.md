# 상태 편집기 0.2.1 — 유형 코드 직접 입력

사용자 지시로 성숙 전용 정의를 없애고 생성 초기값 메뉴에 '적용할 유형 코드' 텍스트 입력란을 추가했다. 유형 드롭다운·datalist·사전 정의된 코드 목록으로 제한하지 않는다. 규칙이 없는 원본은 빈칸이며 milf는 예시 placeholder다. 초기 상태 목록은 기존 상태 축을 그대로 사용한다.

- 실제 조건은 기존 $age[stock['age']] 문자열과 입력 코드의 비교다. 미정의 코드를 숫자 0으로 바꿔 다른 유형에 적용하지 않는다. 미래 유형은 게임에 추가된 코드와 맞춰 입력할 수 있으며, 입력만으로 새 유형을 정의하거나 새 저장 변수를 만들지 않는다.
- 초기 상태가 기존 규칙 유지(-1)이면 코드 입력은 프로젝트 초안에만 저장한다. 활성 상태 0~3에서는 코드가 필요하다.
- 기존 성숙 규칙은 code=milf로 읽고, no-op은 바이트를 보존한다. 기존 프로젝트의 초기 상태 식별자는 호환을 유지한다. source에 규칙이 없는 옛 프로젝트는 코드를 사용자가 입력해야 하며 자동으로 milf를 주입하지 않는다.
- 고유 프리셋 제외, 기존 세이브 비소급, 사건별 후속 덮어쓰기 유지 등 적용 범위는 이전과 같다.

검증: 자체 51개 포함 총119개 중118pass/0fail/1환경skip. 직접 입력·미정의 미래 코드 초안 저장/불러오기·미리보기·두 사본 적용/정확 복원, 기존 브라우저 회귀, 3개 폭×5개 메뉴를 확인했다. 독립 검토에서 추가 조치 없음. repo와 Work/Full 도구10개 제품 파일 동기화 및 실서버32필드/입력칸 확인.

이번 작업은 QSP·세이브를 쓰지 않았다. 사용자가 직전 편집기에서 변경한 Work QSP(76f61280…db1b81da)와 Full 기존 QSP를 그대로 보존했다. 게임 실행은 사용자 담당이다. 현재 주소: http://127.0.0.1:5284/
