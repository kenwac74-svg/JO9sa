## 자동 검사 결과

- 최신 Play→Full 동기화 전 원본을 백업했고, 직전 배포 체크포인트에서 6개 실제 패치 사슬의 결과를 바이트 단위로 재현했다.
- 실제 Full mirror 검사와 재추출 Full의 실제 엔진 검사 모두 PASS. 지정 실행 경로 9개, QSP 구조·줄바꿈·패치 재적용·입력 불변을 확인했다.
- 간소 설치기: 독립 수신자에서 DryRun→설치→재설치 PASS. 1,067 payload, 원본 238·실물 B 238·별칭 111·등록 504 경로, 외부 NPC/index/세이브와 복구 백업을 확인했다.
- 선택 도구: 기존 포터블 실행기·WORKSHOP·원본 B 기능을 보존하면서 단어 일괄 치환만 병합했다. 단위/회귀 59개와 실행/HTTP 29개 PASS.
- 지정 세이브 1~7을 Full/game/save 및 간소 included-saves에 포함하고 Play와 SHA를 대조했다. 간소 설치기는 기존 저장을 자동 덮어쓰지 않는다.
- 게임 리소스 31,946파일을 플레이 기준과 대조했다. 미반영 신규 공개 리소스가 없고 제작 백업·추가 개인 저장·API 설정은 제외했다.

## 반영 범위와 복구

입력은 최신 Play QSP·기존 깨끗한 RC 스테이지·승인된 SAnk 자원·휴대용 도구 후보다. Play는 수정하지 않았다. Full QSP와 선택 도구 런타임 5파일만 백업 뒤 갱신했고, 새 배포물은 별도 디렉터리에 만들었다.

QSP 동기화는 기존 apply_mods.ps1과 이번 통합 배포 패치로 수행했다. 이 통합 대안과 구성원 6개 패치를 같은 적용 디렉터리에 중복 배치하지 않는다. 개별 게임 기능의 입력·효과·의존성은 해당 원래 구현 문서가 기준이다. 배포 기록의 수동 등급·원고 문구 수정은 게임 규칙 변경이 아니다.

Full QSP 백업 및 도구 원본의 위치·이전/이후 SHA는 DELIVERY.json에 있다. 복구가 필요하면 게임을 종료하고 해당 백업 파일을 원래 상대 위치에 복원한다. Play나 보호 원본 JO9O를 대신 복구 대상으로 삼지 않는다. 새 ZIP은 이전 RC ZIP을 덮어쓰지 않았다.

실행에는 압축을 푼 게임과 Windows 런타임이 필요하다. 선택 도구는 번들 Node를 사용하며 게임 폴더 옆에 합쳐 설치한다. 간소 패치는 기존 게임과 안내된 외부 리소스가 전제다.

## 남은 사용자 확인

기존 저장의 게임 UI 불러오기·CRC 복원, 새 게임에서 인물 선택 뒤 진입, 실제 화면과 장시간 밸런스는 자동 진단과 구분한다. USER_PLAY_CHECKLIST_KO.md에 실제 확인한 항목만 체크한다. 이후 이미지 6개·다운로드 링크 3개를 넣고 게시한다.

**배포할 것은 위 세 ZIP이다. stage 원본 폴더, verified 재추출본, diagnostics 수신자 fixture는 내부 검사용이며 업로드 대상이 아니다.**
