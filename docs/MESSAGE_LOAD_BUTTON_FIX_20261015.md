# 구버전 세이브의 알림 확인 버튼 복구 — 2026-10-15

증상: 이전 모딩 버전 세이브를 불러오면 버전 업데이트 알림의 확인 버튼이 없어 진행 불가. 순정 세이브에서는 같은 문제가 발생하지 않는다는 사용자 보고.

원인 근거: 배포 폴더의 세이브를 읽기 전용으로 해독·왕복 확인했다. 1.sav·7.sav는 MSG_OK_IMAGE가 현재 존재하는 content/pic/buttons/ok-icon.png이고, JO9_TEST_ALL_REGIONS.sav는 폐기된 content/pic/SNKmod/buttons/ok-icon.png다. 이 대표 모딩 세이브의 버튼 좌표 250/340은 순정과 같았다. 사용자 스크린샷의 실제 로드 파일명은 특정되지 않았으므로 모든 모딩 세이브가 같은 경로라고 단정하지 않는다.

기존 흐름은 로드된 MSG 설정을 유지한 채 $newloc → $addon(update/full)에서 버전 알림을 띄운다. 올바른 설정을 기록하는 _layout은 이후 화면 표시 과정에 실행되므로 최초 업데이트 알림을 구하지 못한다. 버튼 파일 자체는 양쪽 현재 게임에 존재한다.

수정: $ongload에서 saved_game_loaded 플래그·화면 이동 전에, $addon의 full 갱신에서는 interior_restore 뒤·버전 알림 전에 현재 MSG 배경·확인 버튼·서식·좌표를 복원한다. _layout과 같은 값: 확인 버튼 content/pic/buttons/ok-icon.png, 좌표 250/340, 본문 80/40/370/400, 알림 X=200. 버전 알림을 없애거나 진행 데이터를 건너뛰지 않는다. 세이브 원본은 수정하지 않는다.

패치: mods/2026-10-15_refresh_message_ui_before_save_upgrade.json.

## 사용자 확인

게임 완전 종료·재실행 후 기존 원본 세이브를 불러온다. 진행 중인 알림을 강제로 닫거나 그 상태를 저장해 해결하려 하지 않는다.

- [ ] 문제가 발생했던 이전 모딩 세이브: 업데이트 알림에 확인 버튼 표시, 클릭으로 닫고 정상 진행.
- [ ] 순정 구버전 세이브: 알림과 진행 정상 유지.
- [ ] 일반 알림 및 같은 세이브 재저장/재로드: 확인 버튼 정상.
- [ ] 두 대상에서 초기 메뉴 테두리 및 선택창 캐릭터 정렬 확인.

자동 게임 클라이언트 조작은 하지 않았고 실제 화면은 사용자 확인 대기다. 배포 폴더의 QSP는 반영됐으며 기존 압축 배포 ZIP은 재생성하지 않았다.
