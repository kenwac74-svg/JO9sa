# JSON 말투·호칭·명명 정리

사용자가 제시한 구체적 규칙을 그대로 실행하는 소규모 편집 작업이다. 승인된 수정과 추가 컨펌 대상을 구별한다.

**대상:** C:/MOVE/Jack O Nine Tails v2.4.1_Kor_Full/game.

**설계:** JSON 표시 문자열과 QSP 표시 문자열 표만 수정한다. 숫자 파일명 25개는 같은 숫자 ID를 유지한 채 영문명 접미사를 붙인다. 조건·관계·성격 수치·생성 분기는 변경하지 않는다. 기존 영어 원문 호환표를 유지하고 수정 전 한국어 17문구의 정확 일치 대응을 추가해 이미 저장된 문구도 표시할 때 수정한다.

- [x] 현재 WORK의 영향 파일과 QSP를 읽고 변경 전 백업을 남긴다.
- [x] 여주인님 호칭을 주인님으로 통일하고 중복 나열·호칭 관련 연결 대사를 자연스럽게 정리한다.
- [x] 승인된 엘자의 설명 3개를 격식 있고 강경한 어투로 수정한다.
- [x] 이름이 고정된 숫자 JSON 25개의 영문명을 확인하고 파일명을 변경한다. 숫자별 중복·직접 경로 참조를 확인한다.
- [x] 도나도나 23명, 고유 설정 보완 7명, 말투 승인 후보를 근거와 함께 별도 기록한다. 미승인 문장은 유지한다.
- [x] JSON 구조·변경 필드·비대상 보존, QSP 왕복·CRLF·따옴표·표시 문자열 외 코드 보존과 패치 재생/재적용만 확인한다. 전체 엔진 검사·진단 사본은 반복하지 않는다.
- [x] WORK에 선별 적용한 뒤 내용·파일명과 추적 소스가 일치하는지 확인한다. 승인 질문과 실제 화면 미확인을 보고한다.

수정 추적은 새 레코드에 기록하고 기존 번역 결과의 원문·이력은 덮어쓰지 않는다. 이미지/세이브/배포 ZIP, 별도 배포 폴더와 Git 공개는 이번 요청에 없다.
