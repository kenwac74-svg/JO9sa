# 암시장 네 계열의 일부 속성·특성 재추첨

사용자 승인: 이름·출신·직업 추첨에 이어 신규 구매 2586~2597에만 적용한다. 감수성·성격·지성·자아는 각각 1~5 균등 추첨한다.

- 외모·체력 기본값 2/3/4/5: 40/30/20/10%.
- 태도 2 의존적/1 솔직함/0 개방적: 45/30/25%.
- 독특함 기본값 1/2/3/4/5: 35/30/20/10/5%. 사용자가 든 명칭은 기존 도움말의 1~5 정의에 대응한다. 실제 표기 데이터의 번역 차이는 이번 작업에서 전역 변경하지 않는다.
- 체형은 비만 5를 제외한 0~4 균등 추첨한다.
- 일반 무작위 인물의 기존 공통 특성 추첨 및 현행 특성 등록부 추첨을 사용한다. 고정 프리셋의 해당 특성은 초기화한다. 고유 인물·종족·획득 칭호는 임의 추첨하지 않는다. 지성을 0/5로 강제하는 별도의 천재/백치 추첨은 추가하지 않는다.
- 세련됨·인지도·기분, 이미지·세계, 기술·성애기술의 현재 레벨/경험치/경력, 고정 판매가격, 기존 보유 인물은 유지한다. 체력은 사용자가 별도로 재추첨을 요청한 속성이므로 예외이다.
- 기존 체형의 외모·체력 보정, 정신 상태 판정, 특성 효과는 유지한다. 확률은 보정 전 기본값의 확률이며, 기존 게임 규칙이 계산한 표시값을 강제 고정하는 기능이 아니다.

기존 `jo9_background_b`에 3개 모드와 기존 생성 위치에 호출을 추가한다. 새 저장 필드·위치는 없다. 분리하려면 이번 mods를 역적용하면 된다. 기존 이름·배경 추첨은 별도 패치로 보존한다.

검증: 실제 엔진에서 확률 경계 1~100 전체 검사, 12개 프리셋 반복 생성, 보존 대상 레벨·경험치/이미지/세계/세련됨·인지도·기분 비교, 범위 밖·복제 방어, 특성 배척 및 소유 이전을 검사한다. 공식 정적 출고 검사·역적용·WORK/소스/원장 해시를 확인한다. 전체 출고·개인 세이브 GUI 검사는 이 작업의 완료 조건과 구분한다.
