# 경기 우승 명성 구현 계획

Goal: 승인된 랠리 10/1/0.25·80상한과 캣파이트10+3+3을 WORK에 적용한다.
Architecture: 기존 경기 결과 확정 경로와 전투 정산 토큰을 재사용한다. 랠리만 작은 helper 하나와 개인 첫승·사분점 두 키, 일시적 참가표식을 사용한다.
Tech Stack: QSP 선언형 mods, FastQSP 실제 엔진, Node.js 검증.

- [x] 기존 결과에서 명성 부여가 없는 실패 재현, 정확 복구본·76세이브 보존.
