# 기존 특성 목록 전체보기 구현 계획

> 실행: 승인된 2026-10-25 시안을 이 채팅에서 구현·검증한다. 커밋·푸시는 하지 않는다.

**Goal:** 기존 좌측 혼합 목록과 전공 조건보기의 중앙 UI를 재사용하여 특성·상태·칭호 전체보기와 하단 설명을 제공한다.
**Architecture:** 기존 목록 생성은 재실행하지 않고 출력된 HTML을 읽는다. 한 QSP 보조 로케이션은 기존 설명과 현재 화면의 UI 상태만 다루고, ES5 스크립트는 실제 DOM 높이·표시 순서·3열 배치를 담당한다.
**Tech:** 현재 WORK QSP / FastQSP QtWebKit / 기존 CSS·양피지 / 선언형 패치·출고 검사.
**Spec:** artifacts/native-trait-overview-20261025 시안 및 사용자 승인. 일반 성향 획득 제한과 칭호 설계는 이번 구현 범위가 아니다.

## 제약과 점검

- 최신 WORK를 매 단계 다시 확인한다. 동시에 바뀌는 master_stat 등 무관한 수동 변경은 보존한다.
- 상태 먼저, 나머지 기존 상대 순서 유지. 숨겨진 성향은 표시하지 않는다. 초과 보유를 삭제하지 않는다.
- 제목은 항상 밑줄 링크, 실제 넘침 때만 하단 파란 밑줄 전체보기. 글꼴·색과 상단 속성 위치 유지.
- 중앙 1→2열은 상태·특성, 3열은 칭호. 기존 page_blank/프레임을 재사용한다.
- 특성/상태/칭호 설명은 하단, 기존 기본 속성 설명은 엔진 메시지창을 유지한다.
- 새 위치로 GT하지 않는다. 개인실 교환·인물·자금·행동력과 저장된 특성 값을 보존한다.
