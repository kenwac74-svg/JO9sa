# 다음 패치 일정판 구현 계획

요청한 HTML 일정판을 기존 모드툴 서버에 붙인다. 다음 패치 36항목, 수동 확인3항목, 완료 이력9개와 폐기2개를 담는다. 상태는 완료·보류·재파악·폐기·진행중만 사용한다. 날짜 미확정 항목에 임의 마감일을 넣지 않고 작업 차수와 시작/목표일 편집을 제공한다.

선택한 방식은 기존 편집기 서버의 별도 HTML 경로와 공통 JSON 저장이다. 브라우저 저장만 쓰면 PC/브라우저가 바뀔 때 상태를 놓칠 수 있어 오프라인 보조 기능으로만 둔다. 독립 서버는 추가하지 않는다. 기존 서버에는 페이지와 인증된 상태 API만 추가한다. QSP·이미지·세이브·Full은 변경하지 않는다.

- [ ] 상태 저장·완료/이전상태 복원·일정 검증·충돌 방지의 실패 테스트를 먼저 작성한다.
- [ ] 기존 체크리스트를 고정 ID 데이터로 옮기고 완료·폐기 이력을 구분한다.
- [ ] HTML에 상태별 접기, 체크박스, 검색/차수 필터, 날짜·메모, JSON/HTML 내보내기와 가져오기를 만든다.
- [ ] 서버와 두 실행 경로에 일정판 열기를 추가한다. 서버 설치본이 소스와 달라 전체 덮어쓰기 대신 같은 작은 연결만 각각 적용한다.
- [ ] 저장 재불러오기·동시 창 충돌·일정/상태 필터를 관련 테스트와 브라우저로 확인한다.
- [ ] 모드툴 열기 지침과 인계에 이번 사용자 규칙을 남긴다. 게임 전체 출고 검사는 실행하지 않는다.

검사 우선순위는 상태 유실, 완료 취소, 다른 창 덮어쓰기, 날짜 역전, 잘못된 가져오기다. 현재 설치본의 수동 변경을 보존하고 실제 사용 중인 편집기 서버만 식별한 뒤 재시작한다. 임시 자료는 이번 작업의 재생성 가능한 사본만 정리한다.
