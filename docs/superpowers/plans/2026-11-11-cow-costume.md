# 젖소 코스튬 일반 의상 추가

사용자 승인: 기존 젖소녀 장비와 별개의 일반옷. 독특함+1, 사육 상승, 젖소녀 교육 상승, 세련됨-1. 지성/자존심 감소 없음. 벼룩시장 판매. 고급 훈련의 기존 cow_gear 요구는 유지한다.

구현 판단: 새 ID cow_costume, 표시명 젖소 코스튬, 기존 cow_gear와 같은25스파크. 일일 사육누적+1, 교육보너스+2. 기존 cow 이미지를 공유한다. 원본 cow_gear를 수정하거나 효과를 복제한 뒤 일부만 제거하는 대신, 명시한 네 효과만 독립 정의한다. 새 이미지 파일·지속 상태 필드는 추가하지 않는다.

1. 최신 WORK 구조·해시를 확인하고, 판매/착용/로드 캐시 등록 위치를 추적한다.
2. 새 아이템의 효과·착탈·이미지키·판매·기존 장비 및 고급 훈련 조건 보존을 확인하는 관련 범위 검사를 만들고 미구현 실패를 확인한다.
3. mods JSON으로 새 정의·벼룩시장 구매·착용선택·기존그림 선택 및 구세이브 초기화를 추가한다.
4. 후보에서 설치 엔진의 구매/효과/해제 및 캐시 복구 검사, QSP 구조/줄경계, 공식 재생·재적용을 확인한다.
5. WORK와 추적 QSP/원장 및 아이템DB를 맞추고 사용·검증·복구 기록을 작성한다. Full·음원·커밋·푸시는 변경하지 않는다.
