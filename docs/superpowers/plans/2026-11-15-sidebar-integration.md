# 모드툴 사이드바 통합 실행 계획

사용자 승인: 2026-11-15. 클로드 편집기 디자인과 기존 기능을 유지하고 기존 ‘모드툴 열어’ 도구를 통합한다. 기타 산출물은 맨 아래에서 그간 만든 열람용 HTML을 골라 본다. 미정 기능·산식·변수·대사 확장·새 DB 구조는 구현하지 않는다.

기존 클로드 서버/화면은 수정하지 않고 서버 확장 모듈과 사이드바 모듈을 덧붙인다. 현재 7689 주소와 브라우저 저장소를 유지한다. 각 기존 웹 도구는 원래 서버 주소를 프레임으로 열어 저장 위치와 기능을 유지한다. URL은 기존 실행기가 확인한 실제 주소를 전달한다. 기존 모듈의 API 및 자료 파일을 변경하지 않는다.

- [x] 현재 코드와 저장 경로 기록, 실제 실행 주소 및 카탈로그 조사.
- [x] HTML 목록/원본 열람 경로를 구현하고 경로·목록 분류의 핵심 회귀를 검사.
- [x] 기존 스타일을 재사용한 사이드바와 기존 페이지·도구 연결. 캐릭터 아래 배경 목록, 게임 DB 아래 기존 특성 편집/인터뷰 DB, 기타툴 아래 기존 분포·AI·세이브 등을 유지. 기타 산출물은 마지막.
- [x] 기존 실행기에 통합 화면 시작을 연결. 서버 재사용·사용자 저장 상태 보존.
- [x] 브라우저에서 메뉴·기존 화면·실제 도구 연결·카탈로그 및 대표 이미지 확인. 게임 엔진/저장/산식 기능의 재검사는 하지 않음.
- [x] 사용·변경·검증·복구 기록을 남기고 임시 시험 자료만 정리. 커밋/푸시/배포/게임 데이터 변경은 하지 않음.

새 코드: tools/modding-hub/{server.py,registry.py,integration.mjs,integration.css,Start-Modding-Hub.ps1,README_KO.md,tests/test_registry.py}. 실행 설정은 git 제외 runtime/에 저장한다. 변경: tools/local-workspace/Open-Modding-Tools.ps1의 통합 진입 연결. 클로드의 별도 실행 사본은 그대로 보존한다.
