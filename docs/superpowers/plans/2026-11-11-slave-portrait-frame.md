# 노예 초상 자동 테두리

사용자 요청: 노예 이미지 탭의 포트레이트에 자동 테두리 만들기 기능을 추가한다.

- 컬러·흑백·세피아 초상 카드 각각에 버튼을 넣는다. 현재 PNG와 테두리 합성 미리보기를 비교한 뒤 적용한다.
- 기존 게임의 대응 프레임 바깥5px를 재사용한다. 원래150×150/151×150 크기와 중앙 얼굴 픽셀을 유지한다. 알려진 기존 프레임은 건너뛰며 불확실한 경우 미리보기에 표시한다.
- 새 서비스는 현재 캐릭터 JSON·PNG·참조 프레임의 버전을 확인한다. 기존 pic-local writer를 통해 원본 백업·패치/카탈로그 기록을 재사용한다.
- 현재 연결 경로·이름·능력치·QSP·세이브·작업 태그를 임의 재설계하지 않는다. 공유 파일은 영향을 받는 인물을 표시한다.
- PNG 합성/보존 알고리즘, 미리보기의 쓰기 없음, 오래된 JSON/PNG/프레임 거부, 이미 테두리 있음, 취소/실패, 기존 UI 보존을 관련 범위에서 검사한다.
- 소스와 WORK 도구에 설치하고 새 서버가 필요하면 알려진 로컬 도구만 재시작한다. 운영 이미지는 설치만으로 변경하지 않는다. 커밋/푸시·Full은 별도 요청 대상이다.

구현: 새 portrait-frame helper(위임), 새 character-portrait-frame 서비스/테스트, 기존 server route와 girls checklist의 실제 카드/대화상자 구조. 대형 HTML의 데이터/기존상태는 보존하고 해당 UI 스크립트만 갱신한다.
