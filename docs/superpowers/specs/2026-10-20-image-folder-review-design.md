# 이미지 폴더 비교·선택 도구 설계

작성일: 2026-10-20

## 목적과 합의한 사용 방식

장면팩마다 경로가 고정된 비교표를 새로 만들지 않고, 사용자가 원본 폴더와 비교 폴더를 등록하여 반복 사용할 수 있는 도구를 만든다. 두 폴더의 이미지를 번호별로 대조하고 무엇을 남길지 기록한다.

사용자는 그룹 전체 선택과 파일별 개별 선택을 모두 요구했다. 각 번호의 선택값은 **원본 유지 / 비교본 유지 / 보류** 중 하나다. 그룹 전체에 적용한 뒤 개별 파일의 선택만 다시 바꿀 수 있다. 미검토와 사용자가 선택한 보류는 구별한다.

이 단계의 결과는 선택 기록이다. 원본·비교 이미지의 복사, 덮어쓰기, 이동, 삭제를 실행하지 않는다. 기존 게임과 이미지 카탈로그도 수정하지 않는다. 커밋·푸시 보류 지시는 유지한다.

## 구현 방식 비교와 권장안

1. **독립 로컬 웹 도구 — 권장:** Python 로컬 서버가 폴더를 읽고 Pillow로 썸네일을 생성한다. 기존 브라우저 작업 방식과 맞고 대량 이미지를 업로드하거나 복사하지 않아도 된다. 폴더 선택 때 Windows 폴더 선택창을 사용한다.
2. **브라우저에서만 실행:** 서버는 필요 없지만 브라우저별 폴더 접근 권한과 재시작 후 재연결의 차이가 크다. 현재 사용 중인 인앱 브라우저에서도 같은 동작을 보장하기 어렵다.
3. **네이티브 데스크톱 창:** 폴더 선택은 간단하지만 썸네일 갤러리와 확대 비교 화면을 별도로 구축해야 한다. 현재 도구들과 사용 방식이 달라진다.

권장안은 독립 로컬 웹 도구다. 기존 게임 서버를 확장하거나 게임 설치 폴더에 의존하지 않는다.

## 화면과 기본 흐름

1. 상단에서 원본·비교 폴더를 각각 선택한다. 경로 직접 입력도 지원한다. 폴더쌍에 이름을 붙여 등록하고 다음 실행에 다시 연다.
2. 하위폴더까지 검사하여 그룹 목록을 만든다. 파일명 검색, 양쪽 존재/한쪽만 존재, 미검토/보류/선택 완료 필터와 진행 개수를 보여준다.
3. 그룹 카드 안에 번호별로 원본을 왼쪽, 비교본을 오른쪽에 표시한다. 썸네일 아래에 파일명과 이미지 크기를 보여준다. 없는 쪽은 ‘파일 없음’으로 표시한다.
4. 각 번호 행에 원본 유지·비교본 유지·보류 선택 컨트롤을 둔다. 그룹 상단에 같은 세 가지 전체 선택을 둔다. 그룹의 개별 선택이 서로 다르면 ‘혼합 선택’으로 표시한다.
5. 썸네일을 누르면 두 이미지를 크게 대조한다. 화면 맞춤과 원본 크기 확대를 지원하며 전체 경로를 확인할 수 있다.
6. 선택은 즉시 자동 저장한다. 저장 중·저장 완료·저장 실패를 구분한다. 선택 목록을 JSON/CSV로 내보낼 수 있다.

## 그룹과 대조 규칙

- 상대 하위폴더와 파일명 기본 이름을 그룹의 기준으로 삼는다. 다른 하위폴더의 동명 파일은 섞지 않는다.
- `dt_pink_short_milf_3.png`, `dt_pink_short_milf_4.png`는 `dt_pink_short_milf` 그룹의 3번과 4번이다. 번호는 문자열 순서가 아닌 수치 순서로 정렬한다.
- 파일명 앞이나 중간의 숫자는 유지한다. 번호가 없는 기본 파일도 같은 그룹에 별도 행으로 표시한다.
- Windows의 `이름 (2).png` 복사본도 같은 기본 이름 그룹 안에 표시하되 `_2.png`와 같은 파일로 합치지 않는다. `_2`와 `_02`, 기본 파일과 `_1`도 각각 보존한다.
- 두 폴더의 같은 상대파일명을 먼저 대응한다. 그다음 같은 상대폴더·같은 기본 이름·같은 번호 표기에서 남은 후보가 양쪽에 한 개씩일 때만 확장자가 달라도 같은 행에 대조한다. `_2`, `_02`, ` (2)`는 서로 다른 번호 표기이므로 자동 대응하지 않는다. 같은 쪽에 같은 번호 표기의 PNG/JPG 등 여러 파일이 남으면 각각 별도 행으로 표시한다. 모호한 후보를 임의로 짝짓거나 숨기지 않는다.
- 한쪽 파일이 없으면 존재하는 쪽의 유지 또는 보류만 선택할 수 있다. 그룹 일괄 적용에서 없는 쪽을 유지하라는 선택은 건너뛰고 건너뛴 수를 표시한다. 보류 일괄 적용은 모든 행에 적용한다.
- PNG/JPEG/WebP/GIF/BMP/TIFF 등 지원되는 이미지 형식을 검사한다. 파일명이나 내용에 따른 숨김 목록은 두지 않는다. 읽기 실패·지원되지 않는 형식·건너뛴 링크는 검사 결과에서 확인할 수 있다.

## 자동 썸네일과 대량 폴더 처리

파일 목록을 먼저 표시하고 썸네일을 백그라운드에서 자동 생성한다. 화면에 보이는 항목을 우선 처리하고 캐시를 재사용한다. 수천 장을 한꺼번에 브라우저 메모리에 올리지 않도록 목록을 나누어 표시한다.

썸네일은 EXIF 회전을 반영하고 비율·투명도를 유지한다. 손상된 파일 한 개 때문에 전체 검사가 멈추지 않는다. 폴더 등록 취소나 접근 권한 오류에는 원인을 표시하며 기존 프로젝트를 유지한다.

## 선택 기록과 재검사

- 데이터와 썸네일은 이미지 폴더 밖의 도구 작업 폴더에 저장한다.
- 폴더쌍마다 별도 프로젝트를 사용한다. 원본·비교 폴더가 뒤바뀌거나 다른 폴더쌍으로 바뀌면 기존 선택을 자동 적용하지 않는다.
- 결정에는 양쪽 상대파일명과 검토한 파일 버전을 기록한다. 판단한 행의 양쪽 파일은 해시를 보관하여 재검사 때 같은 크기·수정시각의 내용 변경도 확인한다.
- 바뀌지 않은 대조 쌍의 선택은 유지한다. 새 파일은 미검토로 표시한다. 기존 판단에 포함된 파일이 바뀌거나 없어지면 이전 기록은 남기고 현재 상태를 재검토로 표시한다. 새 파일 추가 때문에 기존 대조 쌍의 구성이 바뀐 경우에도 재검토로 표시한다.
- 저장은 임시파일 작성 후 교체하여 중간 실패에 의한 기록 손상을 줄인다. 실패를 성공으로 표시하지 않는다.

## 배치와 의존성

- 도구 소스: `G:/somi/JO9sa/tools/image-folder-review/`
- 사용자 프로젝트·썸네일: `G:/somi/IMGMG/folder-review/` (실행 옵션으로 변경 가능)
- 실행: 전용 실행 파일로 로컬 서버를 시작하고 브라우저에 연다. 실행 중인 동일 서버가 있으면 재사용한다. 게임 실행·설치·동기화 작업을 호출하지 않는다.
- 의존성: 현재 설치된 Python 3.12, Pillow, Windows 폴더 선택 기능. 서버는 `127.0.0.1`로 제한하고 등록된 폴더 안의 이미지에만 접근한다.

## 완료 기준과 검증

자동 검사는 `_3/_4`, `_9/_10`, 번호 없는 기본 파일, Windows 복사본, 앞·중간 숫자, 같은 번호의 여러 확장자, 다른 하위폴더, 한쪽 누락, 손상 이미지, 취소·권한 오류를 포함한다. 개별 선택과 그룹 일괄 선택, 일괄 적용 후 개별 수정, 재시작 후 복원, 프로젝트 간 분리, 변경·삭제 후 재검토도 확인한다.

소규모 테스트 폴더에서 기대 결과를 먼저 검증하고 실제 대량 폴더로 등록·진행 표시·썸네일 생성·검색·확대·저장을 점검한다. 원본 이미지가 변경되지 않았는지 확인한다. 내부 검사 결과만 통과시키고 완성된 도구 화면을 사용자에게 연다.
