# 파산 전 자산 처분 설계 — 2026-10-23

사용자가 대화 설계를 승인하고 WORK 구현을 요청했다. 새 NPC나 상시 UI 버튼을 추가하지 않는다. 비용 부족 시 장식, 비입주 시설, 비어 있는 개인실·수용 시설, 주택, 보유 노예·조수의 순서로 페이지를 넘기며 처분을 선택한다. 각 페이지는 실제 회수액과 남은 부족액을 보여준다. 비용이 충당되면 추가 처분 없이 한 번 정산한다.

- 최초 결산 비용·날짜를 저장한다. 결산, 축사 수익, 주기 증가는 한 번만 수행한다.
- 다른 방법으로 자금을 마련하는 동안 기존 도시·판매·대출 경로를 이용할 수 있으나 다음 날 진행은 미납 해결 전 막는다. 기력 고갈에 의한 강제 하루 진행도 같은 경계에서 차단한다.
- 시설은 모든 관련 인원이 비어 있어야 한다. 해제·이동은 사용자가 직접 한다. 냉동 인원이 있으면 동면 장치를 해지하지 않는다.
- 장식은 현재 설치된 종류의 카탈로그 정가 50%, 개인실은 현재 단계의 공사비 50%를 환급한다. 장식 처분 후 7종 상태와 일반·확대 이미지·설명은 모두 basic으로 바꾼다. 구입가 이력과 소유권 추정은 사용하지 않고 방별 처분 여부 한 배열만 남긴다. 새 장식을 선택·구입하면 그 방의 표시만 초기화하며, 무료 이사 재초기화로 처분 표시를 지우지 않는다. 미존재 방·이미 처분한 장식은 제외한다. 재구입 전에는 재환급하지 않는다.
- 자가 주택은 현재 지역별 정가(75 × 지역 기본 임대료)의 50%를 적용한다. 임대는 소유 자산으로 팔지 않는다. 10일 결산 시점의 임대시설에는 실제 선불잔액이 없으므로 해지는 향후 유지비를 중단하며 허구의 매각대금을 생성하지 않는다. 고정액 지원금은 도입하지 않는다.
- 주택 이주는 수용 인원·동면·개인실 등이 비어 있음을 확인한다. 소지품·음식 재고를 자동 폐기하지 않는다.
- 노예·조수 선택지 처분은 노예 납품 의뢰를 노리는 경쟁 노예상에게 현재 기본 평가액의 50%로 급매하는 것이다. 기존 NPC와 직접 거래하거나 그 NPC의 퀘스트·납품·평판·관계 보상을 처리하지 않는다. 통상 구매 조건으로 정상 매각이 막힌 소유 인물도 급매 가능하다. 살아 있는 소유 인물만 대상으로 하며 빈 슬롯·사망·타인 소유 계약 인물은 자산으로 처분하지 않는다. 직접 찾아가는 기존 정상 거래는 변경하지 않는다. 조회와 확정에서 가격·역할·인물을 다시 확인하고 대금과 해당 역할만 정산한다.
- 기존 세이브·Full·JSON·CSS·이미지 원본은 수정하지 않는다. 새 상태는 기본 0으로 기존 세이브에서 비활성이다. 커밋·푸시·배포 동기화는 금지한다.
