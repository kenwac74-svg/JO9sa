# Windows 복사 이름 이미지 전환 — 2026-10-18

사용자 확정 방식으로 플레이본과 2.4 배포 작업본에 적용했다. 현재 QSP SHA-256은 `244d02c997a5ae58a01a79f397dc1d318cb3ab8180522a93f04b62f927d2afcd`이다. 기존 원본 B 238개는 기준 그림과 같은 폴더의 실제 `(2)` 파일로 배치했다. 이전 원본 보관 경로도 복구·구버전 연결을 위해 유지했다.

## 사용하는 방법

기준이 `picture.png`라면 추가 그림도 같은 파일명·확장자로 같은 폴더에 복사하고 Windows의 두 파일 유지 기능을 사용한다. 게임이 확인하는 이름은 `picture (2).png`, `picture (3).png`, `picture (4).png`다. 괄호 앞 공백도 이름의 일부다. 원본 B가 있는 묶음은 실제 `(2)`가 있으므로 다음 복사 파일을 `(3)`, `(4)`로 둘 수 있다.

정해진 번호 중 있는 파일만 다음 표시·전환에서 인식한다. 중간 번호가 비어 있어도 건너뛴다. 선택한 파일이 삭제되면 A로 복귀하며 한 장만 남으면 전환 버튼을 비활성화한다. A도 없으면 남은 첫 후보를 사용한다. 모든 파일이 없으면 원래 기준 경로를 반환하므로 삭제한 기준 그림 자체를 복구해야 한다. 숫자 괄호로 끝나는 이름에 다시 `(2)`를 붙이는 중첩 이름은 만들지 않는다.

이번 QSP 교체 후 게임을 한 번 다시 시작해야 새 코드가 적용된다. 이후 `(2)`~`(4)` 추가·삭제는 같은 실행 중 다음 표시·전환에서 확인한다. 이 범위는 WORKSHOP이나 실행 전 파일 검색 프로그램을 요구하지 않는다. 기존에 등록된 E컷 이상은 유지한다. 새 `(5)` 이상은 기존 WORKSHOP 등록 방식으로 추가할 수 있다.

## 코드의 입출력과 저장 영향

수정은 `interior_change.body`의 세 구간이다. 패치는 `mods/2026-10-18_windows_image_slots.json`이며 안정적인 표식은 `WINDOWS_IMAGE_SLOTS_PATH`, `WINDOWS_IMAGE_SLOTS_DISABLED`, `WINDOWS_IMAGE_SLOTS_TOGGLE`이다. 로케이션 수는 259개로 같다.

- `func('interior_change','jo9_path',기준경로,모드)`는 `$result`로 선택 경로, `jo9_image_count`로 현재 존재하는 후보 수를 돌려준다. 모드 0은 현재 선택 검사, 모드 1은 다음 유효 선택, 모드 2는 삭제되었을 수 있는 화면의 이전 선택 경로를 저장값 변경 없이 반환한다.
- `jo9_html`은 기존 출력 HTML의 그림을 처리한다. `jo9_toggle`은 모드 2로 이전 화면 경로를 확보한 뒤 현재 파일 상태를 검사하여 마지막 해당 그림만 교체한다. 삭제된 C가 화면에 남아 있어도 A로 바꾼다. 기존 컷신 보기·UI 복원 처리는 보존했다.
- 기존 저장 배열 `jo9_cut_choice[정규화한 기준경로]`를 재사용한다. 기존 249개 등록 묶음의 선택 ID는 유지한다. 미등록 자동 슬롯 ID는 10002, 10003, 10004이며 편집실이 추가하는 새 5번 이상도 명시적 ID를 쓴다. 후보 배열과 존재 플래그는 지역 변수이며 새 영구 키·저장 캐시·로케이션·백그라운드 프로세스는 없다.

현재 잭오나 FastQSP의 `%경로%` 존재 확인 확장을 사용한다. 실제 엔진 SHA-256은 `f75032d79ecb58eeb7b969cd3f774d66b091fca38a360acdabd782e03a46c6e6`이다. 표준 QSP/WASM 엔진에서 같은 확장이 있다고 가정하지 않는다. 새 발견 경로는 Windows 파일명 대소문자 비구분에 맞춰 정규화한다.

## 편집 도구와 설치기의 연결

`tools/text-workshop/image-cuts.cjs`, `original-cuts.cjs`, `pic-local.cjs`도 물리 B컷에 맞췄다. 동일 B가 가상 항목과 중복 표시되지 않고, 원본은 읽기 전용으로 구분한다. 현재 `(2)`가 보존 원본과 다르면 자동 덮어쓰지 않는다. 새 등록 목록 갱신은 기존 경로와 선택 ID를 보존한다. Full의 원본 경로 override는 유지했다.

간소 패치의 `tools/release/Install-Patch.ps1`은 수신자의 원본 보존 뒤 `original-mirror-map.json`의 238개 연결로 실제 `(2)`를 만든다. 원본 그림 바이트를 간소 패치에 동봉하지 않는다. 기존 `(2)`가 다르면 게임·백업에 쓰기 전에 중지한다. 변경될 기존 파일은 설치 폴더 밖에 백업하고 복구 journal을 남긴다. 외부 NPC 정의·인덱스·기존 세이브는 자동 덮어쓰지 않는다. 요청된 세이브 1~7은 풀팩의 `game/save`, 간소 패치의 별도 `included-saves`에 포함한다.

원본 보존 맵, 물리 B 맵, 경로 이전 맵과 설치·복구 설명은 `docs/release/2026-10-18/`에 있다. 맵을 누락하면 필요한 물리 B가 생성되지 않으므로 출고 검사는 238행 포함을 별도 확인한다. 등록 경계 `JO9 WINDOWS IMAGE SLOT REGISTRY START/END`는 편집실 갱신의 의존 표식이며 제거하면 도구가 안전하게 갱신할 수 없다. 경로 선택부만 복구하면서 새 전환 호출을 남기면 삭제 파일/슬롯 ID 처리가 맞지 않으므로 세 패치 구간을 함께 왕복 검증해야 한다.

## 검증과 한계

실제 엔진 기능 15개, 같은 실행 중 파일 추가·삭제, 실제 편집실이 생성한 10005 등록을 확인했다. 새 후보·실제 적용본의 출고 검사에서 구조/행 경계/정확 재생/재적용/엔진 9경로와 배포 QSP 일치가 통과했다. 편집실 회귀 80개 통과·기존 호스트 파일 symlink 권한 항목 1개 제외, 설치기 회귀 32개는 정션 검사 포함 모두 통과했다. 간소 패치를 재추출하여 기존 원본 238개를 물리 B로 복원하고 전체 payload·504개 등록 경로·기존 NPC/인덱스/저장 보존을 확인했다.

기존 세이브를 실제 UI로 불러오기, 모든 장면의 시각적 배치, 전체 플레이와 모든 비정상 파일 조합은 별도 범위다. 자동 엔진 진단은 검사기가 만든 숨김 프로세스만 종료했으며 기존 사용자 게임 창을 조작하지 않았다. 출고 기록은 `docs/qa/2026-10-18_windows-image-slots.json`과 마무리 기록을 따른다. 아르곤 추가 원고와 장기 대화 확장까지 완료했다는 뜻은 아니다.
