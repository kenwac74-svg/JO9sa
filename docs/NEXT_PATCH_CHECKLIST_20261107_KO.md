# 다음 패치 후보 체크리스트

2026-11-07 조사. 논의 뒤 중단되거나 다음으로 넘긴 작업을 모았다. 체크되지 않은 항목 전체가 이번 패치의 구현 승인 범위라는 뜻은 아니다. 항목마다 남은 결정과 재개 조건을 유지한다.

## 조사 기준

- 최신 공개 패치는 **2.4.1 3차 r2**다. `codex/release-2.4.1-update3-20261107`의 커밋 `1c3f76ddcf5c8da0a92cea1908ef3cdb1627af4f`에 있는 출고·인계 기록을 우선했다.
- 사운드는 위 브랜치와 갈라진 뒤 갱신된 `main`의 `336bff54d0bb4e189293bde3024b99ca3bf0a750` 기록까지 함께 확인했다. 기존 BGM 보존·재배치 지시가 우선한다.
- 최초 취합 시 이 PC의 WORK는 2차 r4였다. 일정판 연결 단계에서 재확인한 현재 WORK QSP는 3차 r2 해시 46e972bf98bc74cd79176312683e398bf7ae639bc7edeecadfcb6efd9a8f54b9다. 일정판 작업에서 QSP를 덮어쓰거나 두 브랜치를 병합한 것은 아니다.
- 조사 범위는 보류 등록부, 인계, 변경 명세와 출고 기록이다. 최신 3차 ZIP의 모든 게임 분기를 새로 실행한 조사는 아니다.
- `기획 필요`는 구현 전에 내용을 정할 항목, `재현 필요`는 아직 확정 버그로 세지 않을 항목, `명시 보류`는 별도 재개 지시가 필요한 항목이다.

작업 상태·일정의 최신 기록은 모드툴의 /patch-schedule에서 관리한다. 이 문서는 조사 당시의 근거 목록으로 보존한다.
