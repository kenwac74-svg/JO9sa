# JO9 UI 패치 작업 인계

갱신일: 2026-09-25 (Asia/Seoul)
작업 브랜치: `JO9UIpatch`

## 현재 기준: 사용자가 직접 제공한 FIX6

사용자가 “fix6 버전이다”라고 정정하고 원본 ZIP을 직접 첨부했습니다. 이제 이 첨부본을 기준으로 후속 UI 패치를 누적합니다. 이전 문서의 FIX5 원본 요청 및 FIX5만을 기준으로 고정했던 상태는 종료합니다.

파일: `JO9_UI_v1_9_14_AllInOne_R2_FIX6.zip`
크기: 9,073,868 bytes
SHA-256: `254dc8c5cce2c9f5442f34b6de0cdbb029893eb544c76635d76b8b2e2fc0bc82`

같은 이름으로 다른 크기의 파일이 이전 Library 목록에 있었으므로, 파일명만으로 동일 버전의 바이트라고 판단하지 않습니다. 이번에 직접 첨부된 위 해시를 기준으로 합니다.

## 실제 확인한 범위

- ZIP CRC 검사 통과, 내부 파일 128개.
- PNG 115개를 실제 디코딩: 오류 없음.
- manifest Files 117개와 Payload 119개를 실제 SHA-256과 대조: 모두 일치.
- qsp-patches.json의 대상은 `sjm_UI_UIadds`, `main_screen`, `slave_stat`, `city_screen`, `#food_base`의 5개 location.
- 원본 소스, CSS, 이미지, 엔진, 설치/복구 스크립트를 수정하지 않음.
- Windows PowerShell 설치/복구 및 실제 게임 화면 시험은 하지 않음.

패키지 README/BUILD_REPORT는 FIX6가 상세 정보 창의 레이어와 두 곳의 1px 정렬을 수정한 CSS 누적 패치라고 설명합니다. FIX5 원본과의 재비교를 이번 작업에서 수행했다는 의미는 아닙니다.

## 보존 범위

현재 FIX6 패키지의 모든 파일을 원형대로 보존합니다. 기존 누적 리소스인 bg_trophy.png, Trophy.png, trophywall.png, slave_psychology 1~7 및 버튼 파일을 유지합니다.

패키지에 포함된 실제 엔진 정책은 검증된 순정 엔진에 한해 포함된 재도색 수정본으로 교체하고, 이미 수정된 엔진은 유지하며, 별도 커스텀/알 수 없는 jack.exe는 교체·백업·복구 대상에서 제외하는 방식입니다. 이번 보관 작업은 그 정책이나 엔진 파일을 변경하지 않습니다.

`sex_scenes`, 게임 이벤트 내용·조건·수치, 세이브, 다른 모드를 UI 작업에 포함하지 않습니다. 전체 게임 소스가 아니라 제공된 UI 패치 패키지를 보관하는 작업입니다.

## 작업 분리와 사용자 지시

- `main` 및 다른 브랜치를 변경하거나 병합하지 않습니다.
- SNmod와 이미지편집툴은 잭오나이미지편집툴 채팅으로 이관되었습니다.
- UI 이미지 참조 카탈로그 확장 작업은 취소되었습니다.
- 새 설계 결정은 한 번에 하나씩 사용자에게 확인받습니다.
- 별도 JO9_UI_buttons.zip은 PNG 24개의 보충 묶음입니다. FIX6에 들어 있는 버튼과 구분하며 임의로 통합하지 않습니다.

## 저장 상태와 다음 단계

FIX6 원본과 내부 파일은 현재 작업 공간에서 확보·검증했습니다. GitHub에는 이 문서, 검증 기록 및 원본 가져오기 절차가 저장되어 있지만, 원본 ZIP/128개 파일 전송은 아직 완료되지 않았습니다.

`releases/JO9_UI_v1_9_14_AllInOne_R2_FIX6.zip`에 위 원본을 업로드하면 이 브랜치 전용 워크플로가 해시를 검사하고 패키지를 분리 저장하도록 구성했습니다. 임포트 스크립트는 로컬에서 정상 가져오기·재실행·변경된 파일 덮어쓰기 차단을 시험했습니다. Actions 실행과 후속 커밋 확인 전에는 GitHub 전체 저장 완료로 표시하지 않습니다.
