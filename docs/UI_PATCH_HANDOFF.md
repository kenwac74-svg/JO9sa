# JO9 UI 패치 작업 인계

기록일: 2026-09-25 (Asia/Seoul)
작업 브랜치: `JO9UIpatch`

## 작업 범위와 사용자 지시

- 이 브랜치는 잭오나 UI 패치 작업용이다.
- 사용자는 이 브랜치에 소스와 산출물을 모두 저장하도록 요청했다.
- `main`과 다른 작업 브랜치를 변경하거나 병합하지 않는다.
- SNmod는 잭오나이미지편집툴 채팅으로 이관됐다. SNmod와 이미지편집툴의 구현 파일 및 핸드오프 문서는 이 브랜치의 저장 대상에서 제외한다.
- UI 이미지 참조 카탈로그 확장 작업은 취소됐다. 재개하거나 선행 작업으로 추가하지 않는다.
- 새 설계 결정은 한 번에 하나씩 사용자에게 질문하고 확인받는다. 기존 파일 저장 요청 자체에 추가 승인을 요구하지 않는다.

## 이어받은 UI 패치 기준

아래는 이전 대화에서 이어받은 기준이다. 이번 저장 작업에서 FIX5 원본을 확보하거나 재검증했다는 뜻이 아니다.

- 기준 패키지: `JO9_UI_v1_9_14_AllInOne_R2_FIX5.zip`
- 이전 대화에 기록된 SHA-256: `74e9fe608cccc01588ed8e0a34265ef3d81fdfa80df4e6eba687eb517b68938c`
- 이후 UI 변경은 FIX5에 누적한다. 이전 버전을 다시 조립해 FIX5인 것처럼 취급하지 않는다.
- 보존 대상: `bg_trophy.png`, `Trophy.png`, `trophywall.png`, `slave_psychology/1.png`부터 `7.png`, FIX5에 포함된 버튼 16종.
- QSP 변경 허용 location으로 인계된 항목: `sjm_UI_UIadds`, `main_screen`, `slave_stat`, `city_screen`, `#food_base`.
- 커스텀 `jack.exe`를 교체하거나 UI 패치의 백업 대상으로 넣지 않는다.
- `sex_scenes`와 게임 이벤트 내용·조건·수치 변경은 UI 패치 작업에 포함하지 않는다.

## 상태 구분

문서 저장, 바이너리 파일 전송, 패치 설치, 게임 실행 검증은 서로 다르다. 현재 문서는 작업 기준과 실제 확보 상태를 보존한다. UI 패치 전체 소스가 저장됐거나 새 패치가 구현·설치·검증됐다고 보고하지 않는다.

FIX5 원본이 확보되면 기록된 해시와 실제 SHA-256을 대조하고, 패키지 내부 경로를 유지해 소스·설치기·복구기·리소스를 저장한다. FIX6와 별도 버튼 파일은 기준 패키지를 덮어쓰지 않고 버전과 출처를 구분한다.
