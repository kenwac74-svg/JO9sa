# 임신 아이콘 연결·상태열 배치 수정

사용자 지정: 첨부한 z_pregnant.png를 노예·조수의 우측 상태 아이콘 열 하단에 기존 아이콘 크기로 표시한다.

## 원인과 변경

메인 상태창 sjm_UI_UIadds의 네 출력은 예전 buttons/z_pregnant.png를 읽었고, 개인실은 새 ui/z_pregnant.png를 읽고 있었다. 첨부 파일과 Work·Full·2.4 배포 기준본의 새 ui 이미지가 SHA-256 9544a8bdc718d90bd9e9b12e768bd2a17a2e7be791487c189b42edb34dacfc24로 동일하다. 이미지 재생성·추가·덮어쓰기는 필요하지 않다.

QSP 패치 2026-10-19_pregnancy_status_icon은 sjm_UI_UIadds의 네 이미지 경로와 해당 변경 표시 주석만 바꾼다. 임신일수·공개 상태·불임·기생체·의료 숙련도에 따른 기존 표시 조건과 툴팁, interaction_city 331 진료 연결은 유지한다. 새 함수·로케이션·영구 변수·세이브 변환은 없다.

CSS PREGNANCY_STATUS_COLUMN은 노예·조수 상태열의 기존 다섯 29px 행 사이 여백만 없애고, 임신 표시를 각각 x=1243, y=478/728의 29×29px 상자에 배치한다. 원본 그림은 비율을 유지하며 이 상자 안에 맞춘다. 조수 임신 표시의 끝 y=757은 기존 괴물 아이콘 시작 y=757과 맞닿으며 겹치지 않는다. 주인공 마법 아이콘 열의 간격은 바꾸지 않는다.

## 입력·출력과 의존성

입력은 sjm_UI_UIadds가 이미 읽는 현재 인물 상태다. 출력은 기존 상태창 HTML이며 반환값이나 수치 효과는 바꾸지 않는다. main_screen 등 기존 호출과 개인실의 기존 ui 경로를 유지한다. 필요한 리소스는 content/pic/ui/z_pregnant.png, 표시 크기·좌표는 css/base.css의 해당 블록이다.

QSP 수정만 제거하면 메인 화면이 다시 예전 아이콘을 읽는다. CSS 수정만 제거하면 새 그림은 예전 작은 상태 배지 자리로 돌아간다. 두 변경을 함께 유지해야 한다. 원본 이미지의 고해상도 파일 크기와 실제 화면 표시 크기는 별개이며, 여기서는 표시만 제한한다.

## 검증 범위

실제 QSP 5.7 엔진에서 두 역할의 표시 유무·새 이미지 경로·진료 연결을 26회 검사했다. 수정 전은 새 이미지 경로 5회 실패, 후보는 26회 통과하며 엔진 오류는 없다. 화면 배치는 실제 CSS를 사용하는 격리 브라우저에서 별도로 확인한다. 실제 게임 창·기존 세이브 UI 불러오기·진료 클릭 결과는 이 자동 검사의 범위가 아니다.

설치·공식 출고 검사·ZIP 결과는 최종 검증 기록을 참조한다. 이전 ZIP과 원본 이미지는 보존한다.
