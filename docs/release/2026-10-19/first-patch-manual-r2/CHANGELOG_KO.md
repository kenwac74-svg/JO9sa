# 2.4 알파 1차 누적 패치

2.4 배포 이후 현재 Work에 적용한 변경과, 사용자 검토를 마친 아르곤 원고를 통합했습니다.

- 거주지에 따라 개인실 증축 한도를 1~4실로 나눴습니다. 빈민가는 증축할 수 없으며, 이사해도 기존 방과 입주자는 유지됩니다.
- 개인실 등의 인물 외형 연결과 가정교사 메뉴의 두 번째 열 배치를 고쳤습니다. 외부 인물 이미지 교체 팩 자체는 포함하지 않습니다.
- 노예·조수 상태창의 임신 아이콘 연결을 고치고, 29px 상태열에 맞춰 아이콘의 위치·크기를 정리했습니다. 기존 2.4 이미지를 사용하며 새 이미지 파일은 추가하지 않습니다.
- 공용 가사업무는 메인 노예와 조수의 지정을 우선합니다. 개인실 메이드의 중복 업무·불필요한 행동력 소모를 막고 실제 담당자가 장면에 표시되도록 정리했습니다. 개인실에서는 공용 잠자리·식단·분량 설정의 효과를 끄고 개인실 설정을 사용합니다.
- 특성 6종의 연결·명칭과 수업 대상 참조, 조수 상점·일부 안내를 보완했습니다.
- 전투 특성은 실전 개인 승수 10·15·20…회마다 각 3%, 총 9%로 한 번 추첨합니다. 안개에서 본인이 승리하면 자아·기질의 성장 누적값을 각각 5 추가합니다.
- 신규 무작위 전사 배경에는 아마존·바이킹 가문 50% 광전사, 기사 가문 50% 성기사, 그 외 가문 25% 역전의 용사를 적용합니다. 기존 인물과 이미 가진 특성은 재추첨하지 않습니다.
- 승인된 출신 배경을 말투별 대사 조각에 선별 반영했습니다. 출신별 사실과 현재 관계를 구분하고 기존 대사 조합을 유지합니다. 사업가 가문 키의 두 철자를 호환하도록 고쳤습니다.
- 라파엘·일반 사창가·홍등가 및 남성 침실 문구를 승인 범위에 맞춰 교정했습니다. 실제 출력 경로, 서비스 가격과 현재 상대의 참조를 맞췄습니다.
- 전투·경주 문구와 장비 설명을 실제 효과 및 RM 자료에 맞춰 정리했습니다. 에게야·엘자 종료문, 돌려차기 사전의 2배 계수, 안면 강타 사전키와 아우게아스 출발키를 고쳤습니다.
- 청소·간호·비서 수업, 근면도와 기존 일상·도시 안내, 인물 이름 및 갤러리 표제를 교정·번역했습니다.

## 기존 저장과 확인 범위

저장된 고정 배경문을 임의로 재생성하지 않습니다. 현재 대화는 갱신된 조각을 사용합니다. 복제인간의 직접 저장문 수정은 새로 생성하는 인물에 적용됩니다.

## 후속 보류 항목

이번에 보류한 항목은 다음 패치에 포함하기 전에 항목별로 사용자 승인을 받습니다. 보류가 자동 해제되거나 휴면 경로가 새로 열리지 않습니다.
여성 신규안, 혀 손실·명령 확장, 안개·동부 부동산 소개와 별도 인디 이미지 업데이트는 이번 범위에 포함하지 않습니다.
