잭 오 나인 테일즈 2.4 알파 · 1차 누적 패치
덮어쓰기용 ZIP

적용 대상
배포된 2.4 알파 풀버전 또는 2.4 간소 패치까지 적용한 게임입니다.
2.3·2.25에는 2.4를 먼저 적용해 주세요.
QSP를 변경하는 다른 모드와는 호환되지 않습니다.

적용 방법
1. 게임을 완전히 종료합니다.
2. 이 압축 안의 game 폴더를 기존 게임 실행 파일이 있는 폴더로 복사합니다.
3. 기존 game 폴더와 합치고, 같은 이름의 파일을 덮어씁니다.
4. 게임을 다시 실행하고 기존 세이브를 불러옵니다.

바뀌는 게임 파일은 두 개입니다.
- game/jack.qsp
- game/css/base.css

기존 game 폴더를 통째로 지우거나 교체하지 말고 파일을 합쳐 주세요.
세이브·개인 설정·현재 사용하는 이미지 팩과 추가 B컷은 그대로 유지합니다.
별도 실행이나 자동 백업 절차는 없습니다. 백업은 사용자가 직접 관리합니다.

변경 내용은 CHANGELOG_KO.md를 확인하세요.

- 29px 상태열에 맞춰 임신 아이콘의 위치와 표시 크기를 정리했습니다.
