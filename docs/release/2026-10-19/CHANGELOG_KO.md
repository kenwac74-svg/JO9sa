# 잭 오 나인 테일즈 한국어판 2.4 변경 내역

2.3을 바탕으로 전투 출전 방식과 특성, 대화 구성을 확장하고 UI·설명·기존 진행 오류를 정리한 버전입니다.

## 안개 전투에 노예·조수 출전

일반 안개 순찰 14종에서 혼자 싸우기, 노예와 싸우기, 조수와 싸우기를 선택할 수 있습니다. 정상 상태이고 행동력이 남은 동료 한 명이 먼저 싸우며, 그 동료가 패배하면 주인공이 이어받습니다.

교대해도 적에게 입힌 피해와 쓰러뜨린 적, 적의 남은 스태미나·사기와 특수기 사용 이력은 유지됩니다. 장비는 각 출전자 차례에 기존 장비 선택 화면에서 고릅니다. 교대 중에 적이 한 번 더 행동하지는 않습니다.

동료의 패배 결과도 구분합니다.

| 소진된 자원 | 결과 |
| --- | --- |
| 체력 | 동료 사망 |
| 스태미나 | 부상 누적 +80. 부상이 없었다면 중상에 해당 |
| 사기 | 헌신·기분 누적 각각 −10 |

둘 이상이 동시에 소진되면 체력→스태미나→사기 순으로 한 결과만 적용합니다. 부상의 회복과 흉터는 기존 게임 규칙을 따릅니다. 동료 한 명 다음에 주인공이 이어받는 방식이며, 세 명을 모두 차례로 내보내는 전투는 아닙니다.

## 신규 특성 16종

교육 속도뿐 아니라 반복 업무, 칭찬, 나쁜 경험, 체질과 실전 경험에서도 인물 차이가 나타나도록 특성을 추가했습니다. 경험치 보정은 새로 얻는 양의 경험치에 적용됩니다.

| 특성 | 효과 |
| --- | --- |
| 천재 | 초기 지성 최고 등급. 양의 경험치 ×2. 육체단련은 제외 |
| 백치 | 초기 지성 최저 등급. 양의 경험치 ×0.5, 최소 1. 육체단련은 제외 |
| 야심가 | 기술 등급이 오른 날의 첫 칭찬에 기분 누적 +5 |
| 일벌레 | 하루 두 번째 업무·교육부터 수행할 때마다 기분 누적 +2 |
| 안분지족 | 하루 두 번째 업무·교육부터 수행할 때마다 기분 누적 −2 |

| 역전의 용사 | 전투 최대 체력·스태미나·사기 ×1.5 |

천재·백치는 신규 무작위 인물에게 각각 3%, 건강체질·약골도 각각 3%로 생성됩니다. 반대되는 특성끼리는 함께 붙지 않으며 고정 인물과 기존 인물을 다시 추첨하지 않습니다. 일부 성격은 실제 효과가 처음 발동할 때 드러납니다.

광전사·성기사·역전의 용사는 해당 인물이 직접 실전 10승을 쌓으면 셋 중 하나를 얻습니다. 연습과 다른 인물이 마무리한 승리는 포함하지 않습니다. 세 전투 특성은 서로 배타적이며, 기존 **타고난 투사**의 교육 효과와는 함께 보유할 수 있습니다.

기존 **용감함**에는 최대 사기 +50%, **겁쟁이**에는 최대 사기 −50%가 추가됩니다. 기존 처벌·저항 효과는 유지합니다. **천재 연설가**는 **달변가**로 표시 이름을 정리했습니다.

건강체질·약골의 효과는 전투 자원과 운동 교육에 적용됩니다. 치료 속도나 흉터 발생 규칙을 바꾸는 특성은 아닙니다.

## 명기·경국지색과 인물 가치

### 명기 발견과 육성

명기는 발견 조건을 충족한 첫 경험에서 5%로 한 번 판정합니다. 한 번 발견한 이력은 상태 복원·역할 이동·저장 후에도 유지하며, 기존의 비처녀 인물을 소급 재추첨하지 않습니다.

발견 시 관련 주 기술 S와 단체 하위 기술 5종 B를 한 번 보장합니다. 지정 주 교육에서 승급에 미달해 경험치를 쌓는 경우에는 회당 경험치 +1이 붙습니다. 기존 지원 경로의 결과 보정도 유지하되, 원래 성공·거절 판정을 모두 무시하는 효과는 아닙니다.

### 경국지색과 성형 대성공

경국지색은 기존 최고 외모의 신규 무작위 인물 중 1%로 생성됩니다. 같은 최고 외모의 인물이 성형수술을 받으면 5% 대성공으로 후천 획득할 수도 있습니다. 이미 최고 외모인 인물도 수술을 고려할 이유가 생깁니다.

외모는 최대 **S++**를 열지만 종합등급 상한은 **S+**로 유지합니다. 흉터·멍·체형으로 인한 외모 불이익도 그대로입니다. 기존에 받을 수 있던 양의 NPC 호감도와 주인공 명성 보상에는 +50%가 붙으며, 원래 없던 보상을 새로 만들지는 않습니다.

### 판매 혜택

| 거래 | 명기 또는 경국지색 하나 | 둘 다 보유 |
| --- | --- | --- |
| 잡파 특별 재협상 | 최초 제시가 ×10 | 최초 제시가 ×15 |
| 길드 경매 추가 입찰 | 기존 최종가 ×2 | 기존 최종가 ×3 |

잡파의 원래 제안은 남아 있고 별도 재협상을 선택하는 방식입니다. 길드 경매에서는 기존 입찰이 끝난 뒤 가면 쓴 수집가가 추가 가격을 제안합니다. 원래 낙찰자를 특정 인물로 고정하지 않습니다.

적격 고객과 흥정할 때에는 현재 능력으로 가능한 최고 결과를 선택하되 고객 자금 상한과 기존 인수 조건을 지킵니다. 명기는 관련 능력을 요구하는 고객이 대상입니다. 정가·할인·고정 보수 의뢰까지 모두 같은 배수로 바꾸지는 않습니다.

다재다능의 기본 가치 +25%는 이러한 특별 거래 배수보다 먼저 적용합니다.

## 대화 방식과 답변 구성

대화 개선은 인상 묻기 한 항목에서 끝나지 않도록 넓혔습니다. **과거, 인상, 요구, 하고 싶은 일, 싫어하는 것, 현재 기분, 노예와 조수의 서로에 대한 평가**에 조각 조합 방식을 연결했습니다.

- 9개 성격 유형과 3개 말투, 현재 관계와 감정 상태에 맞춰 핵심 발화와 보충을 조합합니다.
- 최근 두 번 나온 조각을 우선 피합니다. 후보가 부족하면 최근 한 번 제외, 이후에는 반복을 허용해 답변이 비지 않도록 합니다.
- 거절되거나 실제로 보이지 않은 답변은 출력 이력으로 소비하지 않습니다. 같은 화면을 다시 표시하는 것도 새 대화로 세지 않습니다.
- 최근 사건에 대한 반응은 현재 주인공과의 관계 안에서 표현합니다. 적대적인 인물이 칭찬 한 번 때문에 갑자기 다정해지는 식의 조합을 줄였습니다.
- 일반 원문 대사도 조합 방식에 연결하되 고유 인물 사연, 직접 작성한 배경, 식별할 수 없는 저장 사연은 보존합니다.

이번에 채택한 대사 원고는 **9,120개 조각**입니다. 독립 이벤트 9,120개를 추가했다는 뜻은 아니며, 모든 상황에서 매번 다른 답변을 보장하지도 않습니다.

### 길었던 인상 묻기 정리

태도와 최근 경험, 두려움과 권위, 따르는 이유와 감사처럼 같은 맥락의 발화를 한 페이지에서 이어 말하도록 묶었습니다. 완결된 발화 경계에서 다음 페이지로 넘기며 문장 중간을 잘라내지 않습니다.

인상에 몰려 있던 조각 중 **99개를 부탁 15개·하고 싶은 일 12개·현재 기분 72개로 재분류**했습니다. 대표 상태에서는 8페이지가 3페이지로 줄었지만 모든 답변을 3페이지까지만 남기는 제한은 없습니다. 뒤로·다음 이동도 보완했습니다.

### 다른 인물을 평가하는 말

조수나 노예를 평가할 때 같은 감정 지문이 두 번 붙거나, 서로 다른 판단이 상태표처럼 나열되던 부분을 다듬었습니다. 170개 발화를 구어체로 정리하고 실제 조합을 잇는 45개 연결 문장을 적용했습니다.

> 그녀는 교양이라고는 하나도 모르는 야만인 같아요. 하지만 그녀가 살던 세계의 문화는 익숙하네요.

관계 점수와 기존 시기·멸시·무관심은 유지합니다. 부정적인 평가를 호의적인 말로 일괄 바꾸는 수정은 아닙니다.

## 장소·NPC·의뢰 안내 등 설명 확충

비어 있거나 일반적인 문구만 있던 참고 정보를 보완했습니다. 이번 월드 설명 정비 228건은 장소 87개, NPC 119명, 지역 평판·약국·의뢰·고유 인물 대사 등 22건입니다. 기존 원문이 있는 곳은 그 내용을 보존·증강했습니다. 기존 특성의 설명문도 별도로 보완했습니다.

같은 시설을 두 번 설명하는 경우에는 방문 단계에 맞게 나눴습니다. 크라이오 입구에는 시설의 설립 배경, 보관 셀 화면에는 고객 이용 설명이 나오며, 캣파이트 클럽 소개와 에게야와 직접 결투하는 설명도 구분합니다.

식료품점과 정육 거래에서는 우측 재고를 그대로 두고 비어 있는 하단에 장소 설명을 표시합니다. 이미 대사가 나오는 상황에서는 그 대사를 우선합니다.

## 화면과 생활 관리

### 크라이오 보관소

보관 인물의 얼굴과 이름을 셀 안에 표시합니다. 한 화면에 **3열×5행, 15셀**을 보여 주고 나머지는 다음 페이지에서 확인합니다. 18셀이 열렸다면 15개와 3개로 나뉩니다. 우측에 중복되던 얼굴도 정리했습니다.

현재 실제 한도 **18셀**, **3셀 해금 300$**, **점유 셀당 하루 1$**는 유지합니다.

### 괴물 상태

괴물의 갈망·만족을 조수 개인 상태에서 분리해 포트레이트 아래의 독립 아이콘으로 표시합니다. 갈망은 붉은색, 만족은 촉수가 안으로 오므라든 청록색입니다.

성장 종류는 툴팁, 클릭하면 기존 성숙도 안내를 볼 수 있습니다. 괴물 기분 2상태와 성장 5단계는 별개이며 성장·먹이 계산은 바꾸지 않았습니다.

### 등급과 정보 표시

- 개별 속성·기술: **F → D → C → B → A → S**.
- 종합등급: **F → D → D+ → C → C+ → B → B+ → A → A+ → S → S+**.
- 물음표로 여는 속성정보 등급 설명표의 제목과 정렬도 맞췄습니다.
- 임신 상태는 확인·중기·후기·만삭으로 구분해 표시합니다. 노예 표시에서 조수의 발견 여부를 잘못 참조하던 부분도 고쳤습니다.

등급 문자 정리는 표시 이름 변경입니다. 내부 숫자와 승급·가격·의뢰 판정은 그대로이며 경국지색 외모 S++는 앞서 설명한 별도 확장입니다.

### 개인실·장비·편집기

네 개인실의 식단을 각각 고르고 유지할 수 있도록 수정했습니다. 일반식 **2$/일**, 고열량식 **4$/일**, 특별식단 **8$/일**이며 기존 일일 효과와 가격은 유지합니다. 2~4번 방이 1번 방 식단을 따라가던 오류를 고쳤고, 작은 체크 표시 외에 행 전체를 눌러 선택할 수 있습니다.

개인실 이동과 포트레이트 탐색, 장비·보관함 설명과 이모지, 기존 쿠라 관련 표시를 복구·보완했습니다. 치트·주인공·노예 편집기는 글자와 증감 버튼, 하단 이동 버튼을 정렬했습니다. 신규 특성 편집에서는 노예·조수의 특성을 추가하거나 해제할 수 있습니다. 명기 상태를 바꿔도 즉시 원상복구되던 문제도 수정했습니다.

헐렁함 전용 상시 아이콘은 정리했지만 신체 상세와 관련 효과는 유지합니다. 메뉴·전투 로그·무기 선택의 글자, 선택창 캐릭터의 높이, 시작 테두리·게임오버·알림 확인 버튼과 본문 첫 빈 행도 손봤습니다.

## 이미지 전환과 컷신 보기

## 거래와 기존 진행 오류 수정

- **메뉴 가격:** 툴팁에만 있던 비용을 메뉴에서도 확인하도록 정리하고 실제 차감액과 맞지 않던 표시를 고쳤습니다.
- **누락 결제:** 조수와 해변·극장·식당·온천·황금 새장, 셋이 해변·식당 등 확인된 7개 경로에서 정확히 한 번 결제하도록 했습니다.
- **구매 안전:** 식료품 7종, 유료 인테리어 62종과 지정 시술에서 실제 가격·잔액·주방·보관 공간을 다시 확인합니다. 구매 취소는 차감하지 않습니다.
- **암시장:** 1000/1250/1500$ 상품의 메뉴 조건을 실제 가격과 맞추고, 잔액 부족이나 동행 칸 점유 시 생성·차감하지 않도록 했습니다. 구매 인물의 일반 능력치 보정 순서도 수정했습니다.
- **생성·배경:** 야만족 공주의 신규 생성 직업 보정을 보완하고 경찰관 집안의 잘못된 출신 값과 옛 저장 갱신을 고쳤습니다. 기존 호감·적대 누적값은 지우지 않습니다.
- **친족·고유 인물:** 친족 ID 보호와 저장된 관계 사연, 프리렌·센세 전용 인식을 유지·보완했습니다.
- **레시:** 첫 만남의 빈 화면과 대사 연결을 고쳐 첫 방문·복귀·재방문 진행을 보완했습니다.
- **베네라:** 구매 기록을 남기고 옛 저장도 확인해, 동행 칸을 비운 뒤 다시 구매할 수 있던 문제를 막았습니다.
- **크리스마스:** 카롤라인 전달로 진행 단계가 역행해 이후 경매·그린치 선택지가 닫히던 문제를 수정했습니다.
- **기존 안내:** 러시아·후타랜드 평판, 약국 상품, 파멜라의 엘사 재안내와 고블린 의뢰 설명을 보완했습니다.
- **시작·불러오기:** 누적 수정 과정에서 발생한 줄바꿈·동적 코드 경계·옛 캐시 문제와 특정 NPC 장면이 다른 장소에 남던 회귀를 수정했습니다.

주택의 기존 생활비·기분·성장 규칙과 적 AI, 기존 고정 보수·퀘스트 구조는 유지합니다. 주택 소유만으로 기분 보너스를 강제하거나 구매자 요구를 전면 강화하는 변경은 넣지 않았습니다.

기존 육성·납품·전투 흐름 위에 특성·대화·표시와 진행 수정을 더했습니다. 기존 개인실·보관·출산 기능은 유지하며, 신규 내용 검토의 중심은 남성 주인공입니다.
