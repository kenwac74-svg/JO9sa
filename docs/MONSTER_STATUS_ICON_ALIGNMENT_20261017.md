# 괴물 아이콘 우측열 정렬

요청: 괴물 아이콘을 조수 패널 우측 세로 아이콘 열과 정렬한다.

- 변경은 CSS의 가로 좌표 하나다. `#jo9_house_monster`의 left를 1236px에서 1241.5px로 보정한다.
- 기존 우측열은 left 1243px, 폭 29px이므로 중심이 1257.5px다. 32px 괴물 아이콘도 같은 중심을 사용한다.
- 아이콘 크기 32×32, 높이 좌표 757px, 상태별 그림, 툴팁 및 클릭 동작은 유지한다. QSP는 수정하지 않는다.
- 표식: `MONSTER_STATUS_COLUMN_ALIGN`, ID `2026-10-17_monster_status_column_align`.

플레이 `game/css/base.css`와 저장소 `assets/css-2.4/base.css`만 같은 배치 규칙으로 갱신한다. CSS 원천 manifest에 이력을 추가한다. 배포본과 보호 원본은 변경하지 않는다.

새 규칙은 기존 CSS 뒤에 붙은 가로 좌표 보정이다. 표식 구간 전체를 제거하면 이전 위치로 돌아가며 게임 계산이나 HTML 구조에 영향을 주지 않는다. 새로운 변수·함수·로케이션·이미지는 추가하지 않는다.

첨부 HTML의 스크립트를 실행하지 않고 우측 아이콘 열과 괴물 아이콘 div만 추출해 검사했다. 중심선 차이가 -5.5px에서 0px이 되었고, 클릭 영역·이미지 로딩·기존 링크·툴팁 보존과 겹침 없음을 확인했다. 게임 클라이언트는 실행하지 않았다. 적용 시점의 백업과 해시는 작업 폴더의 installed.json에 기록한다.
