# 대사 편집실 변수 코드 확인

2026-10-09 사용자 결정: 변수 변경·추가는 AI에게 지시하고, 편집실에서는 변수 코드를 확인만 한다. 변수 편집 입력란·정의 버튼·실행 기능은 만들지 않는다.

- 선택 대사 수정 영역 하단에 기본 접힘인 **변수·조건 코드 확인**을 추가했다.
- 펼칠 때 선택 대사의 `<<…>>` 치환 코드와 장면의 조건·대입 코드, 관련 변수의 원문 설정 위치를 읽는다. 문자열/숫자 구분과 위치명·행을 표시한다.
- 공용 대사 배열은 `flow.usage`가 연결한 실제 게임 장면까지 따라간다. 같은 이름의 배열은 다른 인덱스 설정도 포함할 수 있다.
- 직접 대입과 특수 행동·dynamic·EXEC·중괄호의 지연 실행 코드를 구분하고 조건을 함께 표시한다. 일반 대사와 다중행 주석 속 가짜 코드는 제외한다.
- 설정 후보는 현재 세이브의 값이 아니다. 코드 실행·세이브 평가·변수 의미의 임의 추정은 하지 않는다.
- 최대 80개 변수, 변수별 12개 설정 후보를 표시한다. 긴 원문 코드는 800자에서 줄이고 생략 표시를 붙인다. 확인 내용 복사 버튼으로 요청에 필요한 코드를 전달할 수 있다.

구현: `variable-inspector.cjs`, `variable-inspector.js`, 인증이 필요한 읽기 전용 `POST /api/variables`. 기존 선택 해시·원문 검사를 거쳐 조회하며, QSP를 변경하거나 반영 미리보기를 생성하지 않는다. 문서가 바뀌면 캐시를 무효화한다.

검증: 편집실 전체 54개 테스트 통과. 변수 조회 전후 QSP 바이트 동일, 인증 없는 조회·오래된 선택 거부, 조건별 설정·배열 사용 장면·주석·지연 실행·출력 상한 확인. 실제 QSP 읽기 조회는 첫 인덱스 약 4초, 이후 같은 문맥 조회 13ms였다. 내장 브라우저에서 현재 선택한 추가 대사의 변수 확인창을 펼쳐 확인했다.
