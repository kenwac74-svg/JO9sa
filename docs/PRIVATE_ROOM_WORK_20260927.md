## 최소 대상 연결

새 helper 두 개: `snk_room_bridge`, `snk_room_menu_screen`.

원작 `$swap_slave_instances`와 `$slave_vars` 목록으로 선택한 방 인물을 원작 `slave` 대상 자리에 잠시 둔다. 기존 활동 노예는 임시 보관 슬롯에 보관하고 선택한 방 슬롯은 작업 중 비운다. 완료/뒤로/다른 화면 이동 시 변경된 인물을 해당 방으로 돌리고 기존 활동 노예를 복원한다. 이름, 문자열/숫자 배열, 재고, 누적/당일 이력을 원작 교환 목록대로 옮긴다.

원작 메뉴의 승인된 하위 메뉴 26개를 추적했다. 새 전역 `$onnewloc` 후크를 도입하지 않고 기존 location 진입부에 조건부 guard를 생성했다. 방 작업이 없으면 원래 본문을 그대로 실행한다. 작업 중에는 원작 교육·결과·성교육 화면, 임시 cow 수업 대상, 반발 전투의 무기 선택/결과/게임오버 경로를 처리한다. 조건 미충족 교육의 원작 안내는 개인실로 전달한다.

이 방식 때문에 개발본 QSP 패치는 기존 243개 location의 진입 guard와 helper 2개를 포함한다. 원작 상호작용 판정 본문은 guard 아래에서 변경하지 않는다. 다른 QSP 수정 모드와의 호환을 보장하지 않는 기존 정책도 유지한다.
