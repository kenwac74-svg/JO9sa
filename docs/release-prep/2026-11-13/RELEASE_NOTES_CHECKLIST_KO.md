- 이미지 체크리스트를 실제 탭 구조로 바꾸고 선택한 탭만 불러오도록 했다. 전체/노예/추가팩/MOB/처리주석을 구분하고 검색 버튼 또는 Enter로 검색한다. 추가팩 미리보기는 현재 WORK를 읽는다.
- 캐릭터 JSON은 번호 범위와 무관하게 감지하며 번호 없는 이름도 목록에 표시한다. 수동 복장 파일 연결, 기본 알몸/옷 입은 타이틀 분리, 단방향 공유와 공유 해제를 지원한다. 캐릭터 복제는 새 ID로 만들고 원본을 보존한다. 복제본을 기존 이미지 공유 그룹에 자동 포함하는 기획은 별도 보류다.
- 전용 캐릭터는 full/face/sex_scenes 각 번호 폴더를 유지하고, 일반 캐릭터는 characters의 타이틀과 full/하녀·비서·도미나 하위폴더를 구분한다. 규칙과 다른 연결은 경고하며 기존 파일을 자동 이동·삭제하지 않는다.
- 대사 편집기는 기존 장면/앞뒤 대사 안내를 유지하면서 시작 대사와 선택한 분기 경로를 고정한다. 시작·끝을 잘못 잡으면 예상 지점을 안내하고 선택 구간을 한 각본 파일로 추출한다.
- 각본 저장 위치·저장본 목록·미리보기를 연결하고, 수정 각본 입력·차이 검토·직접 편집·문법/경고 확인 후 선택 반영을 지원한다. 경고 확인 체크가 편집 뒤 풀리는 조건을 보완했으며 실제 게임 대사창 크기의 미리보기를 추가했다.
- 선택한 대사에 표시할 이미지를 파일 선택으로 지정하고, 기존 그림의 표시 경로를 새 경로로 바꾸거나 조건을 편집한다. 새경로는 폴더·파일 선택 흐름으로 다루고 게임 안의 기존 파일을 사용할 수 있다.
- 이미지 교체기에서는 선택한 이미지들에 일괄 테두리를 적용한다. 노예 초상에도 자동 테두리 기능을 제공하고, 필요한 초상/썸네일의 원본 프레임 유지·공유 이미지 보존을 다룬다. 매 이미지마다 버튼을 추가하는 방식으로 바꾸지 않았다.
- 사운드 목록은 사용자가 폴더·파일을 지정하고 재제작/채택/보류를 기록한다. 현재 모드툴 실행에서 사운드 설정 파일을 자동으로 열지 않고 목록/경로만 제공한다. 음원 파일 Git 업로드 금지와 게임 배포 시 필요한 음원 동봉은 구분한다.
- 특성·아이템·마법 열람 DB에 획득·발현·치료 조건 설명, 개인 기획 아이디어, 적 전투 특성·특수기·MOB 탭을 추가했다. 특수기는 구사 적과 공용 기술 이름을 표시한다. 원래 DB 반입/읽기서버/ZIP 이력과 후속 DB 확장을 각각 보존했다.
- 일정판에 상태·완료 취소·차수·날짜·메모·기획 아이디어를 저장한다. 모드툴 실행 때 일정판도 열며, 저장된 사용자 상태를 초기 예제로 덮지 않는다.
- QSP 변경 경고만으로 자동 병합하지 않는다. 동기화 명령 시 현재 WORK와 저장 수정자료를 대조하고 버전 통일 기준을 확인한다. 기존 체크1826+최신9 복구와 원본 B컷/일반 B컷 관리 이력도 기록한다.

**도구에서 확인된 잔여 차이:** DB 소스 HTML과 WORK 설치 HTML이 다르며, 일부 원천 메타데이터 해시도 스냅샷과 다르다. 최신 소스의 설명을 WORK의 옛 설치본으로 되덮지 않았다. Q05에서 설치·동봉할 DB 버전을 맞추고 메타데이터를 재생성해야 한다. 실행기의 전체 자동 검사 실패/TIME_WAIT 한계 기록은 정상 완료로 바꾸지 않았다.
