# 전투 특성 획득 밸런스 — 2026-10-19

사용자 요청: 실전 10승 확정 획득을 없애고 누적 10·15·20…승마다 광전사·성기사·역전의 용사를 각각 3%로 추첨한다. 비보장일 경우 안개 전투에서 콜로세움 일반 승리 성장 보상의 절반을 주라는 앞선 요청도 적용한다.

## 실제 변경

- 전투 특성이 없고, 본인이 이긴 누적 실전 승수가 10 이상이며 5의 배수일 때만 한 번 추첨한다.
- `rand(1,100)`의 1~3은 광전사, 4~6은 성기사, 7~9는 역전의 용사, 10~100은 미획득이다. 독립된 세 번의 추첨이 아니므로 총 획득률은 정확히 9%다.
- 특성 보유자는 추첨하지 않는다. 기존 특성과 누적 승수를 보존한다. 10승을 이미 지난 인물에게 소급 추첨하지 않으며 다음 5승 단위에 판정한다.
- 안개 전투에서 살아 있는 출전자 본인이 승리하면 해당 노예 또는 조수의 `ego`·`temper` 성장 누적값을 각각 5 더한다. 등급 자체를 5 올리는 것은 아니다.
- 개인 패배 후 주인공이 이어서 이긴 경우에는 동료에게 성장 보상을 지급하지 않는다. 기존 `settled` 상태로 반복 호출 지급도 막는다.
- 선천 특성은 배경 후보와 생성 빈도 검토만 했다. 이 패치에는 생성 확률이나 배경 매칭을 추가하지 않았다.

## 입력·출력과 호출

| 위치 / 패치 ID | 입력·역할 | 변경·반환 |
|---|---|---|
| `jo9_traits_combat / COMBAT_TRAIT_CHECKPOINT_ROLL` | 기존 `finish`가 검증한 출전자 역할, `jo9_real_wins`, `jo9_combat_trait` | 승수 1 증가 뒤 체크포인트에서만 확률 획득. 반환값 없음 |
| `jo9_traits_combat / COMBAT_TRAIT_ROLL_CLEANUP` | 내부 계산 종료 | 일시 변수 `jo9_trait_combat_wins`, `jo9_trait_combat_roll` 삭제 |
| `jo9_fog_relay / FOG_VICTORY_GROWTH_SLAVE` | 기존 출전자1 생존 정산과 전투 결과 | 승리한 노예의 자아·기질 누적값 각각 +5 |
| `jo9_fog_relay / FOG_VICTORY_GROWTH_ASSISTANT` | 기존 출전자2 생존 정산과 전투 결과 | 승리한 조수의 자아·기질 누적값 각각 +5 |

`выход_из_боя`는 원래처럼 특성 승리 처리 후 안개 정산을 호출한다. `jo9_traits_combat`의 기존 `finish`는 연습전·패배·동료 패배 후 주인공 승리·중복 정산·출전자 ID 변경을 제외한다. 이를 우회하여 내부 `win`을 직접 호출하는 외부 기능을 추가하지 않았다.

새 함수·로케이션·인물 영구 필드는 없다. 추가한 두 숫자 임시변수는 기존 `clean` 경로에서 제거한다. 이미 저장된 승수·특성을 사용하므로 기존 인물의 수치를 일괄 변환하지 않는다. 안개 정산은 기존 `$dyn_calc_slave_attrs`에 성장 등급 계산을 맡긴다.

## 의존성과 분리

추첨 블록은 기존 승수 증가와 `finish`의 중복·출전자 검사를 전제로 한다. 블록을 옮겨 호출하면 연습전 또는 같은 승리에서 여러 번 추첨할 수 있다. 정리 블록을 빼면 임시변수가 남으므로 함께 유지한다. 안개 성장 블록은 기존 생존·`settled` 분기 안에 있어야 하며, 밖으로 옮기면 반복 호출 또는 주인공 교대 승리에서 잘못 지급할 수 있다.

특성 획득과 안개 성장 보상은 서로 독립된 변경이다. 추첨만 되돌리면 기존 10승 보장 획득으로 돌아가고, 성장 블록만 빼면 안개 승리의 자아·기질 추가가 사라진다. 기존 특성의 능력치 효과·콜로세움 보상·패배 페널티는 변경하지 않았다.
