사용자가 승인한 시범 범위만 플레이 폴더에 적용했다. 전체 대화·지문 시스템 확장은 아직 하지 않았다. 기존108개 문장을 보존하고 같은 상황·유형·말투의 대안216개를 추가했다. 화제 선택, 거절 처리, 기분·헌신·공포 등 기존 수치 처리는 유지한다.

## 게임에서 달라지는 점

인상 묻기에 실제로 대답할 때 같은 인물의 최근 두 발언 변형을 피한다. 상황이 달라져도 같은 유형·말투의 변형번호를 공유하여 복합 대답의 일부가 곧바로 되풀이되는 것을 줄인다. 후보가 세 개라 같은 상황에서 오래 반복하면 세 변형이 순환할 수 있다. 장기 기억이나 무한한 대사 생성 기능은 아니다. 화면을 다시 그리거나 상태창을 여는 것만으로 발언 이력이 바뀌지 않는다.

### 선택기의 입력·반환·저장

- `$args[0]`: 출력 항목의 이름. 이번에는 `'1112'`.
- `$jo9_voice_candidates`: 완성된 대답 후보 배열.
- `$jo9_voice_candidate_ids`: 각 후보와 같은 인덱스의 변형ID 배열.
- `dynslave`: 기존 동적 문자열 치환 관례로 실제 인물 배열 이름을 넣는 자리. 별도 인물 변수가 아니다.
- 반환: 선택한 대답 문자열. 유효한 후보가 없으면 빈 문자열을 반환하고 이력을 바꾸지 않는다.
- 저장: 해당 인물 배열의 문자열 키 `jo9_voice_last1_1112`, `jo9_voice_last2_1112`. 새 세이브 로케이션·날짜·리비전 플래그는 추가하지 않았다.

먼저 최근 두 ID를 피하고, 후보가 부족하면 최근 하나만 피한다. 그래도 없으면 유효한 후보를 허용한다. 빈 문장이나 빈ID는 선택하지 않는다. 선택기의 작업 변수와 호출부 후보 배열은 실행 후 제거한다. 이 도우미는 전역 임시 배열을 쓰므로 호출 중 다른 호출로 끼어드는 중첩 사용을 전제로 하지 않는다.

`$voice_impression`은 이제 결과를 만드는 동시에 최근ID를 저장한다. 미리보기나 화면 렌더러에서 호출하면 대화하지 않았는데도 이력이 바뀐다. 실제로 발언이 확정되는 곳에서만 호출한다. 현재 연결은1112의 기존 `$special_part`뿐이다. 노예·조수 교체에는 기존 `$swap_slave_instances`가 인물 배열 전체와 함께 두 키를 옮긴다.

### 기존 세이브

두 이력 키가 없으면 사용 이력이 없는 것으로 시작한다. 기존 세이브에 예전 동적 함수 정의가 남아 있어도 새 선택기가 없으면 현재 `#dynamic` 정의를 보충한다. 추가 대사 배열이 없으면 기존 데이터 전용 경로를 불러온다. 인물 이력을 초기화하거나 별도 세이브 변환을 수행하지 않는다.

## 분리하거나 제거할 때

태그는 설명 경계이며 모든 구간이 독립적으로 삭제 가능하다는 뜻은 아니다.

- 선택기 정의만 지우면 이를 부르는 `$voice_impression`에 의존성이 남는다. 반복 억제를 제거하려면 원래 조립부와1112의 보충 조건도 함께 되돌려야 한다.
- 추가 대사 데이터만 지우면 대안 후보가 비거나 보충 호출이 반복될 수 있다. 대안 조립과 데이터 보충 조건을 함께 검토한다.
- 1112 보충 조건만 지우면 새 게임에서 정의가 이미 준비된 경우와 달리, 예전 세이브의 코드 캐시에서 새 선택기·대사 정의가 빠질 수 있다.
- 두 저장 키만 지우면 다음 발언부터 이력을 새로 쌓는다. 문법상 다른 실행 블록을 지울 필요는 없다.
- 전체 시범을 되돌리려면 이 패치의 네 치환을 역순으로 정확히 역치환한다. 빌드 때 원본과 바이트 단위로 정확히 복구됨을 검사했다. 이후 사용자가 바꾼 내용이 있으면 현재 파일에 다시 맞춰 검토해야 한다.
