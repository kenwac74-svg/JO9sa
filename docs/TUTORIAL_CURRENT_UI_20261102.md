# 튜토리얼 최신 UI 적용

WORK의 튜토리얼 소개·강의·실기 선택·설정 화면을 기존 최신 공통 UI로 맞췄다. demo_layout은 기존 _layout을 재사용하고 튜토리얼 초기화·인물 선택의 스타일값은 2로 통일한다. 기존 저장 위치가 소개·인물 선택이면 레이아웃만 갱신하고, 옛 강의선택 HTML은 임시 local 문자열로 보존해 표시용 래퍼 안에 다시 출력한다. 인물 생성이나 대사 분기를 재실행하지 않는다.

실기·강의의 구형 #under 메뉴는 튜토리얼 전용 CSS 범위에서 최신 bar 자산·330×62px·20px 글꼴을 쓴다. 교사 메뉴17의 17개 항목은 2열로 보여 마지막 선택지까지 화면에 들어간다. 이미 최신인 물약 메뉴의 직접 자식 배치는 유지했다. 일반 화면 CSS의 기존 바이트는 보존하고 추가 선택자는 튜토리얼에만 적용한다.

사용되는 값은 기존 ui_style/현재 위치/강의·메뉴 상태이며 새 영구 게임 변수·로케이션·저장 형식은 없다. 임시 local 문자열 하나가 추가된다. 새 자산이나 경로 이동은 없다. CSS와 QSP를 함께 사용해야 하며 CSS만 되돌리면 메뉴 모양이 맞지 않는다. 선언형 mods와 작업 직전 압축본으로 복원할 수 있다.

원문 대사·444개 선택 콜백·진행 조건·인물 생성 코드는 보존했다. 원본과 실제 출력3화면의 문구·27개 링크·날짜·돈·시험/배우 상태를 대조했다. 최종 후보 실제 엔진 메뉴80/로드핸들러28판정 및 공식9경로 PASS. 로드핸들러는 원HTML과 인물/진행값을 두 번 호출에도 유지했다. 실제 EXE의 저장파일 불러오기 클릭과 튜토리얼 전체 자연 완주는 별도 수동 확인이다.

수동 확인: WORK 일반 EXE를 완전히 닫고 다시 실행한다. 새 게임의 튜토리얼 소개에서 금속 테두리와 양피지 정보판을 보고, 강의 선택→실기 인물 선택→교육17개 목록→설정·물약→복귀를 확인한다. 예전 튜토리얼 저장도 불러와 이름·인물·날짜·돈이 유지되는지 확인한다.

배포 폴더·원본·기존 SAV는 수정하지 않았다. 최종 배포 동기화/ZIP 작업은 기존 보류 상태를 유지한다.

튜토리얼 전용 뒤로/이동불가/앞으로/강의종료 화살표4개도 현재 공통 버튼 그림으로 맞췄다. 기존 demo_* 파일명과 오브젝트 HTML은 그대로 유지하므로 서로 다른 $objsel 콜백과 옛 저장의 버튼 식별은 보존된다. 원본/추적 소스의 교체 전 PNG는 해시별 압축본으로 보관했다. 같은 그림의 중복은 이 식별을 유지하기 위한 의도된 사본이며 navigation-assets.json에 기록한다.
