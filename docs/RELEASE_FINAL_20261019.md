## 문서 구분

POST_KO.md는 게시판용 짧은 원고다. 변경점 요약·현재 작업과 향후 계획·전후 비교 스크린샷의 세 부분으로 구성했다. 신규 특성은 목록, 대화 변경은 클로드 인계 설계의 개념과 구현 흐름으로 설명하며 비교 이미지4개와 다운로드 링크2개를 넣는다.

CHANGELOG_KO.md는 전체 게임 요소별 상세 변경 내역이며 두 게임 ZIP에 동봉했다. 게임에 포함된 치트 편집기 개선은 남기고, 별도 브라우저 편집 도구 소개는 제외했다.

## 검사와 한계

두 ZIP의 전 파일을 빈 폴더에 다시 풀어 SHA-256·manifest와 대조했다. 간소는 세이브0개, 설치목록1067개다. 한국어 실행기는 경로·오류·원본/기존 자료 보존 등13개 회귀 검사와 폴더 변경UI검사를 통과했다. 실제 배포 stage와 재추출 위치에서도 검사→재설치가 정상이고 독립 수신자 및 기존 백업이 그대로였다.

Full은 문서2개와manifest만 바뀌었다. 게임33199파일, 엔진·QSP·JSON·승인 세이브는 이전 실제 엔진9경로PASS 대상과 동일하며 실행코드가 바뀌지 않아 엔진 검사를 반복하지 않았다. 기존 저장UI/CRC와 최종 플레이·시각 검수는 USER_PLAY_CHECKLIST_KO.md로 별도 확인한다.

기존 첫 EXE는 Avast 격리 기록과 일치하는 파일 소실이 확인되어 출고하지 않았다. 최종 v2.4.0.2의 일반 스크립트 파일 호출은 재추출본까지 정상 실행과 파일 보존을 확인했다. 격리 복원이나 백신 설정 변경은 하지 않았다. 전체 보안 제품 호환성을 인증한 결과로 해석하지 않는다.
