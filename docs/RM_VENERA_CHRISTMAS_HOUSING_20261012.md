# RM 이식 검토와 테스트 — 2026-10-12

## 적용 범위

- 베네라 구매(6540): 메뉴는 `unique_slave["venera"]`를 확인하지만 구매에서는 `venera = 1`만 기록했다. 생성·인수 공통 함수에도 이 고유 획득 기록이 없으므로 빈 동행 칸으로 돌아오면 재구매 가능하다. 구매 완료 시 고유 기록을 추가하고, 메뉴는 옛 세이브의 `venera`도 확인한다. 실행 입구에서 중복·동행·퀘스트·10000$ 잔액 조건을 재검사한다. 가격, 낙인, 대사는 유지했다.
- RM의 `venera2` 관련 변경은 야만왕 보상 경로다. 현재 버전은 보상에서 `venera2 = 1`을 기록하고 메뉴도 같은 변수를 확인하므로 그 경로는 이미 일관되어 있다. RM 변경을 그대로 복사하지 않았다. RM 최신본의 일반 베네라 구매 6540에도 고유 기록 누락이 남아 있어, 이번 수정은 우리 코드에서 확인한 원인을 직접 해결한다.
- 크리스마스(10375): 카롤라인 전달은 NPC 완료 기록과 3500$ 보상만 처리해야 한다. 기존의 이벤트 단계 6 대입은 단계 8의 경매와 단계 9의 그린치 최종 선택지를 닫는다. RM처럼 해당 대입만 제거했다. 고블린 의뢰의 수사학 조건 제거 등 난이도 변경과 번역은 포함하지 않았다.

## 주택 기분 효과 판단 — RM 변경 미적용

`moodlets`의 부정적 부 효과는 현금 잔액 하나가 아니라 생활 수준 `master_wealth`, 평판 `brand_reputation`, 성격 `master_cha`로 결정된다. 주거 효과는 집·가구 품질과 청결도도 반영한다. `billing`에서 소유권은 본채 임대료만 없애며 부속 시설 임대료와 생활비는 남는다. 구매 안내 또한 임대료 면제만 약속한다. `next_day`의 성격 성장·감소도 같은 생활/주거 수준 조건을 사용한다.

RM은 소유자에게 부·주거 긍정 효과 100을 강제하고 부정 효과를 억제하지만 일일 성격 감소 조건은 그대로 둔다. 이는 오류 수정으로 보기보다 소유 보너스와 밸런스 변경에 해당한다. 이번에는 현행 기분·청구·성장 코드를 모두 보존했다. 집을 샀다는 이유만으로 경제적 불만이 사라지는 것으로 안내하지 않는다.

## 테스트 세이브

게임 `save` 폴더의 다음 파일을 불러온 뒤 시작 버튼을 누른다. 원본 `7-1.sav`는 변경하지 않았다. 테스트 복사본은 실제 플레이에서 이어 사용할 목적이 아니다. 시작 버튼은 현재 QSP 코드로 캐시를 갱신한다.

1. `RM_TEST_CHRISTMAS_STAGE8.sav`: 카롤라인을 게임 자체 생성기로 준비하고 조건에 맞춰 슐랴프킨 전달 분기로 들어간다. 대사 종료 후 **경매** 메뉴가 남는지 확인한다. NPC 완료 기록과 3500$ 지급도 확인한다.
2. `RM_TEST_CHRISTMAS_STAGE9.sav`: 같은 전달 뒤 **그린치를 만난다**가 남는지 확인한다. 퀘스트 전체를 완료한 세이브가 아니라 단계 역행을 재현하는 조건 조합이다.
3. `RM_TEST_HOUSE_BEFORE.sav`: 백색 도시 주택 구매 확인창으로 진입한다. 시작 버튼이 현재 난이도의 주택 비용 표를 갱신하고 구매가+1$를 준비한다. 구매가는 본채 임대료의 75배이며 난이도에 따라 달라진다. 결제 후 잔액 1$, 소유권 및 본채 임대료 면제를 확인한다. 취소하면 결제가 없어야 한다. 구매 전 기분 확인 버튼도 있다.
4. `RM_TEST_HOUSE_AFTER.sav`: 시작 버튼으로 소유권 1과 잔액 1$의 비교 상태에 들어간다. 실제 구매를 기록한 파일이 아닌 비교용 조건 복사본이다. BEFORE에서 실제 구매한 결과와 기분 표시를 비교한다. 부정적 부 효과가 남는 것은 이번 판단상 정상이다.

크리스마스 시작 버튼은 테스트 복사본의 동행 노예를 카롤라인으로 바꾼다. 고유 슬롯을 임의로 삽입하지 않고 게임 생성기를 사용한다. 주택 AFTER의 소유권 역시 버튼에서 게임 엔진이 설정한다. 크리스마스 단계 8·9와 주택 두 비교 상태의 로드·진행은 사용자 정상 확인을 받았다.

- [ ] `RM_TEST_VENERA_BEFORE.sav`: 밀수업자 소굴에서 ‘베네라를 산다 (10000$)’ 선택. 소지금 20000$ → 10000$, 베네라 획득 확인. 대사 종료 후 시설로 보내 동행을 비운 다음 밀수업자 소굴 재방문 → 구매 메뉴가 없어야 한다. 시설 이동은 실제 게임 메뉴를 사용한다.
- [ ] `RM_TEST_VENERA_AFTER.sav`: 구매 기록 두 플래그가 설정된 비교 상태. 동행이 비어 있고 잔액 20000$여도 구매 메뉴가 없어야 한다.
