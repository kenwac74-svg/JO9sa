# 대사 편집실 저널 호출 키워드

- Kindroid Narrator에 실제 등록하고 대조한 NPC 소개 227개·장소 설명 60개에서 이름과 ID만 가져온다. 동일 이름은 하나의 키워드 항목으로 묶었다(280개 이름).
- 대사 선택 시 해당 대사의 본문·장면·조건·이미지 경로에서 등록 이름 또는 정확한 QSP ID가 확인되면 키워드를 추천·선택한다. 이름을 검색하거나 직접 추가할 수 있고 ×로 제외한다.
- 선택은 브라우저 세션 내 대사 위치별로 유지한다. 다른 대사에는 그 대사의 추천을 사용한다.
- 선택된 키워드는 ‘각색 요청 전송’의 사용자 요청과 ‘각색 요청 복사’에 `저널 호출 키워드: …`로 들어간다. 본문 저널 전체를 붙이지 않는다. 원문의 사건·분기·화자를 유지하도록 함께 요청한다.
- 서버 재시작 없이 제공되는 dialogue-ai.js와 index.html에 반영했다. 현재 실행 소스 및 게임 modtools 설치본의 기존 두 파일은 적용 전 .bak_journal_ 날짜 파일로 백업했다. QSP·키·모델 설정 변경 없음.
- 검증: 추천 ID 경계·중복 제거·빈 선택·두 요청 경로·스크립트 문법 검사 3개 통과. 기존 Kindroid 연결 회귀 검사 통과. 실제 편집기에서 보 아저씨 자동 선택, 데티네츠 검색/추가/제거, 복사한 요청의 두 키워드 및 원문 포함 확인. 실제 유료 각색 요청은 보내지 않았다.
