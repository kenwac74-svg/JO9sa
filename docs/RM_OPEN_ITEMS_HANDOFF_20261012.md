## 안개 순찰 보상은 조건별 차이만 확인

사용자는 노예 획득 후 선택지가 정상이라고 확인했다. **보상 선택지 전체 누락**으로 등록하거나 정상 경로를 다시 고치지 않는다. RM에서 확인했던 성별별 선택지 배열 차이에 한해 우리 코드에 누락되는 조건이 있는지 확인한다. 문제가 재현되는 성별·결과·슬롯 조건을 찾지 못하면 해당 안건을 종료한다.
