## [신규 업데이트]

- 자금이 부족할 때 보유 자산을 정리하며 위기에 대응할 수 있는 선택지를 추가했습니다.
- 일반 매입 평가와 판매대금 상한을 정리해 거래 방식에 따른 차이를 조정했습니다.
- 지역별로 보유 인물에게 맞는 구매자 소문을 들을 수 있도록 했습니다.
- 체력에 따른 행동력과 체질·과로·성장 효과의 균형을 조정했습니다.
- 일부 성향을 추가하고 중복되거나 충돌하는 특성의 처리 규칙을 정리했습니다.
- 특성 관리용 신규 물약을 추가했습니다.
- 특성 전체보기와 하단 설명 표시를 추가하고 목록의 글꼴·색상·간격을 정리했습니다.
- 희귀 특성을 처음 발견했을 때 기존 특성 발견 팝업으로 알려주도록 했습니다.
- 일부 특성의 성장·생산 효과와 신규 획득 효과를 보완했습니다.
- 경기와 안개경계 활동의 개인 명성 획득을 확장하고 반복 보상을 조정했습니다.
- 안개경계에서 전투 전에 적의 특징을 짐작할 수 있는 대사를 보완했습니다.
- 일부 고유 인물의 복장과 프로필 지원을 확대하고 관련 이미지를 갱신했습니다.
- 환전 화면과 거래 결과에서 보유 금화를 확인할 수 있도록 했습니다.

## [버그 수정]

- 안개전투에서 동료의 행동력 소모가 누락되던 문제를 수정했습니다.
- 일부 이벤트 전투의 진입 메뉴가 정상적으로 열리지 않던 문제를 수정했습니다.
- 캣파이트 승수의 중복 집계와 출전 제한 판정을 수정했습니다.
- 랠리 참가 조건이 실제 행동력 소모량과 맞지 않던 문제를 수정했습니다.
- 관계 대상을 잘못 판단하거나 같은 답변이 반복되던 문제를 개선했습니다.
- 특정 장비 착용 질문 뒤 진행이 막히던 문제를 수정했습니다.
- 개인실의 일부 교육 메뉴와 보유량 확인 링크가 작동하지 않던 문제를 수정했습니다.
- 자원이 소진된 뒤 일부 작업에서 보상을 반복해서 얻을 수 있던 문제를 수정했습니다.
- 구매자 소문 메뉴의 위치와 잘못 연결된 이동·복귀 링크를 수정했습니다.
- 일일 알림과 역할별 화면에서 잘못된 이미지를 선택하던 문제를 수정했습니다.
- 전투 초상이 세피아로 표시되거나 작업 버튼에 다른 그림이 연결되던 문제를 수정했습니다.
- 우유 가격판·보유금·재고 수량의 겹침과 위치를 수정했습니다.
- 상점 아이콘 누락, 약품 선택 목록의 정렬과 보관함 목록 넘침을 수정했습니다.
- 일부 이벤트 재방문 중 화면이 멈추던 문제를 수정했습니다.
- 누락된 선택지 번역, 상태 설명의 중복 제목과 일치하지 않는 내용을 정리했습니다.
- 설명문의 띄어쓰기·줄바꿈과 일부 UI 테두리 표시를 수정했습니다.
- 랠리에서 참가를 거부했는데도 경기가 진행되던 문제를 수정했습니다.
- 정상 범위를 벗어난 기술값에서도 랠리 결과 분기가 정상적으로 선택되도록 보완했습니다.
- 일부 인물의 얼굴·복장 이미지 참조 오류를 수정하고 기존 저장의 이미지 경로 호환을 보완했습니다.
