# 크라이오 보관소 페이지형 UI (2026-10-15)

사용자 확정: 화면당 15개씩 표시하고 각 셀에 소형 얼굴을 넣는다. 오른쪽 중복 썸네일은 제거한다. 셀이 30개로 늘어도 페이지를 나눌 수 있는 배치로 한다. 가격·보관 기능은 유지하는 간단한 변경이다.

## 원인과 수정

기존 #options의 $stasis_options[2]가 18개 셀을 두 열로 나열해 9번째 행과 뒤로 메뉴가 배경 아래 본문을 침범했다. 별도로 shop_general이 cryo_ava_1~18을 오른쪽 설명 좌표에 절대 배치해 겹쳤다.

shop_general의 해당 썸네일 출력 블록만 교체했다. 저장된 $display_options가 옛 코드여도 화면 출력 직전에 현재 보관 상태로 목록을 재생성한다. 3열×5행, 화면당 최대 15개, 1부터 시작하는 페이지를 유효 범위로 보정하며 마지막 페이지에는 남은 셀만 그린다. 현 게임의 18개는 15+3이다. 현재 저장 한도는 18개 그대로이며, 30개 보관 기능을 추가한 것은 아니다. 표시 계산은 30개 및 그 이상도 페이지로 나눌 수 있다. 향후 실제 슬롯 확장은 보관/인출 이벤트·요금·세이브 로직과 함께 별도 작업해야 한다.

보관된 셀의 얼굴은 기존 ava_gray, 없으면 ava, 둘 다 없으면 빈 얼굴을 쓴다. 얼굴 클릭은 기존 stasis_cell 정보 화면으로 이동하고 옆의 꺼내기/임대는 기존 interaction_city 332012~332029를 호출한다. 빈 셀은 캡슐 아이콘이다. 동반 캐릭터가 없으면 빈 셀 임대는 비활성이다. 페이지 변경·추가 해금·뒤로는 고정 푸터에 둔다. 숨기기 버튼에 계속 반응하도록 menu 클래스를 유지하고, 숨겨진 구 페이지의 숫자 단축키가 동작하지 않도록 기존 menu_links를 지운 뒤 현재 활성 셀만 등록한다.
