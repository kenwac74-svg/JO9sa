# 잭 오 나인 테일즈 2.4 알파 · 1차 누적 패치

2.4 배포 이후의 수정과 승인된 아르곤 대사를 묶었습니다. 기존 2.4에 적용하는 QSP·CSS 소형 패치입니다.

- 거주지별 개인실 증축 한도를 조정했습니다. 이사해도 기존 방과 입주자는 유지됩니다.
- 메이드의 중복 업무·행동력 소모와 개인실 잠자리·식단 설정의 적용을 고쳤습니다.
- 개인실 외형 연결·가정교사 메뉴 배치와 임신 아이콘 연결·상태열 위치를 정리했습니다.
- 특성 연결·명칭·수업 참조, 전투 특성 획득 확률과 신규 무작위 전사 배경의 선천 특성을 반영했습니다.
- 출신 배경을 기존 말투별 대사 조합에 선별 반영하고, 사창가·홍등가·침실 문구와 상대 참조를 교정했습니다.
- 전투·경주 안내와 장비 설명, 일상·수업·도시 안내, 인물 이름과 갤러리 표제를 교정·번역했습니다.

게임을 종료한 뒤 ZIP의 `game` 폴더를 기존 2.4의 `game` 폴더에 합쳐 같은 파일을 덮어쓰세요. 기존 폴더를 통째로 삭제하지 마세요. 세이브와 사용 중인 이미지 팩은 그대로 유지됩니다.

QSP를 변경하는 다른 모드와는 호환되지 않습니다. 미승인·보류 원고, 휴면 기능 활성화, 별도 인디 이미지 업데이트는 포함하지 않았습니다.

다음 업데이트 예고: 인디 리소스 업데이트를 준비 중입니다. 트로피 이미지 14종, 몹 이미지 계속 작업 중입니다. 보류 대사는 다음 패치 전 검토·승인 후 순차 반영하겠습니다.
