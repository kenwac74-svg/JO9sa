`0` 또는 미지정은 일반 인물이다. 하나의 부호 있는 값으로 저장하므로 두 특성이 동시에 부여되지 않는다. 생성 추첨은 `generate_stock`의 기존 프리셋·배경 계산이 끝난 다음 한 번만 수행한다. `special_stock > 0`인 고정 프리셋은 추첨하지 않는다. 생성할 때 지성 경험치 카운터도 0으로 맞춘다. 이후 지성은 기존 규칙으로 변화하며, 지성의 지속적인 상·하한은 추가하지 않는다. 자아는 변경하지 않는다. 기존 인물에 특성을 소급 부여하지 않는다.

## 추가 함수 1개

`jo9_learning_xp`는 계산만 수행한다.

- `args[0]`: 이번에 새로 더하려는 경험치. 누적 경험치를 넣지 않는다.
- `args[1]`: 해당 인물의 `jo9_learning_trait` 값.
- `$args[2]`: 성장 항목명. 경쟁 교육의 기존 전체 변수 참조도 전달할 수 있다.
- 반환값 `result`: 보정한 경험치 증가량.
- 특성이 0이거나, 증가량이 0 이하이거나, 육체단련이면 입력값을 그대로 반환한다.
- 인물 상태·누적 경험치·등급·자아를 직접 변경하지 않는다. 연령·상호작용 종류·관계값 검사는 추가하지 않는다.

## 연결 범위

- 공통 `$dyn_skill_rise`: 일반 교육과 이 함수를 사용하는 일일 작업. 난이도 배율까지 계산된 새 증가량을 보정한다.
- 분야별 기술 경험치 및 지성 경험치의 직접 증가 경로: 일일 활동, 전투, 요리 등.
- 하위 기술의 직접 경험치와 공통 교육 함수. 기존 누적 경험치는 재배율하지 않는다.
- 기존 교육 추가 경험치가 있는 경우 이번 기본 획득분과 합산한 뒤 한 번 배율을 적용한다. 기존 추가 경험치의 적용 조건 자체는 유지한다.
- 지식 강의와 두 인물의 경쟁 교육: 인물별 특성을 사용하며 육체단련은 제외한다.
- 고정 등급 지정, 최초 등급 획득, 성공 판정, 비용, 기분, 실패/감소량은 기존 규칙을 유지한다. 배율은 경험치 증가량에만 적용한다.
- 특성 목록, 신규 생성 목록, 동결 인물의 간략 목록에 이름과 설명 링크를 추가한다.

## 캐시와 세이브

`$newloc`의 `jo9_learning_revision` 1회 갱신에서 기존 동적 정의와 설명문을 디스크의 현재 정의로 다시 읽는다. 동결 인물 목록 캐시도 다시 정의한다. 기존 인물의 특성값이나 지성은 이 갱신에서 바꾸지 않는다.

## 변경 구분과 편집

추가·변경 범위는 `JO9 MOD START/END COG_*`로 표시했다. 기존 조건과 증가량 식은 그대로 두고 경험치 함수 호출로 감쌌다. `mods/2026-10-16_innate_learning_traits.json`에는 모든 변경 전후 코드가 있다. 본 작업은 별도의 정책 조건을 추가하지 않는다.

함수만 삭제하면 호출 위치에서 오류가 발생한다. 원복하려면 패치 기록의 호출부 변경도 함께 되돌려야 한다. 생성·표시·계산은 각각 별도 태그로 구분했다. 함수의 배율·생성 확률·초기 지성을 조정하는 것은 서로 다른 편집 지점이다.
