# 인상 묻기(1112) 재조립 — 2026-10-17

사용자 합의: 원문 대사의 내용과 맥락을 유지하면서 우리 대사 조립 방식으로 재구성한다. 장기 설정은 배경·타고난 설정, 중기는 현재 주인공과의 관계, 단기는 최근 사건이며 단기 반응이 현재 관계를 벗어나면 안 된다. 이번 작업은 기존1112 응답 한 곳에 한정한다.

## 화면에서 달라지는 점

기존 관계·복종·상태 설명과 시범 추가 대사를 여러 이름표로 이어 붙이던 것을, 이름 한 번과 한 답변으로 묶는다. 관계 설명과 그 관계로 받아들인 최근 사건을 앞에 두고, 원래 선택되던 복종·상태 정보를 다음 문단에 이어 놓는다. 원문의 선택된 문장은 정보 조각으로 재사용하며, 말풍선 HTML을 벗기고 합니다체에서는 지정된 종결형을 정리한다. 원문 전체를 새 문장으로 재집필한 것은 아니다.

적대 상태에서 칭찬을 받았다는 사실은 말할 수 있지만 그 사실만으로 상대를 좋아한다고 답하지 않는다. 두려운 상태는 칭찬 뒤에도 경계가 남고, 무너진 상태는 사건 사실만 짧게 말한다. 헌신적인 관계에서만 인정받은 기쁨을 표현한다. 기존 원문 자체가 여러 서로 다른 수치에 관해 말하는 복합적인 태도는 보존하며, 새로운 게임 수치로 그 태도를 교정하지 않는다.

새 장기·중기·단기 이력 저장소를 만든 것은 아니다. 이번 해석의 재료는 기존 직업/성격 profile, 현재 psy_status와 헌신 수치, 기존 오늘/최근 행동 기록이다. 전체 대화·지문 시스템 확대는 이번 범위가 아니다.

## 원문 보존

현재 Play의1112 `$special_part`에서 원래 `$text`에 담던 선택 코드 전체를 그대로 가져와 `$jo9_vc_parts`에 담도록 이름만 바꿨다. 원래 배열 데이터는 수정하지 않았다.

| 정보 | 유지한 조건 |
|---|---|
| 관계 | 현재 `$slave_psy_status`에 대응하는 기존 관계 문장 |
| 복종 | obedience의0/10/20/30/40 경계 및 집안일 수용 예외식 |
| 반항 | 기존 rebell 판정이 뒤의 obed 값을0으로 만드는 처리 |
| 그 밖의 상태 | broken에서 생략하는 원래 분기 |
| 욕구 | 기존 obed>0 및 sex_sum>0 조건과 arousal 상한 선택 |
| 공포 | 기존 fear와 moral의 보정식 |
| 합리화 | 기존 obed·오늘 보상 기록·rational의 상한 선택 |
| 본능·습관 | 기존 min(obed+2, 해당 수치) |
| 응석·헌신 | 기존 obed>0 조건 및 원래 인덱스 |

원문 문장 안의 강한 표현과 설정은 새 판단으로 삭제하지 않았다. 원문 배열을 수정하지 않으므로 다른 질문·다른 원문 호출부에도 영향이 없다. 원문 자체가 전달하는 정보와 현재 관계의 복합성까지 임의로 단순화하지 않는다.

## 구성과 입출력

패치 `2026-10-17_zzzzzzzzzzzz_voice_compose`: 세 로케이션에 세 치환. 새 로케이션0, 추가 함수0, 추가 인물 이력 키0. 기존 함수 `$voice_impression`의 반환 내용이 ‘덧붙일 사건 문장’에서 ‘1112 전체 답변 본문’으로 바뀐다. 현재 연결된 호출부도 함께 바꿨다.

| 위치 / 표식 | 역할 |
|---|---|
| `#dynamic` / `VOICE_COMPOSE_1112` | 원래 정보 선택, 현재 관계별 사건 해석, 세 완성 답변 후보 조립, 기존 선택기 호출 |
| `interaction` / `VOICE_COMPOSE_CALL` | 기존 talk 및 repulse=-10 유지. 기존 세이브의 예전 정의 보충 후 이름 한 번과 답변 본문을 `$text[1]`에 넣음 |
| `#txt_man` / `VOICE_COMPOSE_DATA` | profile별 시작말81개, 관계별 사건 반응288개, 종결형 치환 쌍 데이터 |

`$voice_impression`은 인자 없이 현재 slave의 기존 값과 원문 배열을 읽어 본문 문자열을 반환한다. 해당 인물이 실제 대답하는 경로에서 한 번 호출한다. 최근 두 변형ID는 기존 `$slave['jo9_voice_last1_1112']`, `$slave['jo9_voice_last2_1112']`를 계속 사용한다. 화면 다시 그리기에서는 호출하지 않는다. 후보 선택 뒤 작업 배열과 임시 변수를 지운다. 기존 선택기의 입력 임시 배열·반환·인물 치환 계약은 유지한다.

새 상수 배열은 `$voice_1112_composed`, `$voice_1112_formal_from`, `$voice_1112_formal_to` 세 개다. 인물의 사건 이력을 추가로 쌓는 배열이 아니다. 이전 시범의 `$voice_1112`108개·`$voice_1112_variant`216개는 호환과 기록을 위해 보존하지만 새1112 조립에는 사용하지 않는다. 원문 내용은 기존 `$slave_*_description` 배열이, 시작말/최근 사건 반응은 새 `$voice_1112_composed`가 담당한다. 편집할 때 이 차이를 구분한다.

## 관계 반응의 선택

psy_status를 먼저 사용한다. 헌신 수치가 높다는 이유로 적대·공포·체념 상태의 반응을 덮어쓰지 않는다.

| 현재 상태 | 사건 해석 |
|---|---|
| reluctant / arrogant / hateful / resistant / hysteric | 적대: 칭찬을 받아도 기존 반감을 유지 |
| lachrymose / frightened | 두려움: 칭찬 뒤에도 경계가 남음 |
| depresive | 막막함: 사건에 곧바로 기뻐하지 않음 |
| broken | 짧은 사실 확인 |
| optimistic | 기대와 유보가 섞인 반응 |
| obedient / servile / horny | 헌신4 미만은 맡겨진 일 중심,4 이상은 친밀한 반응 |
| soft / docile 및 그 밖의 상태 | 현재 마음과 사건을 구분하는 중립 반응 |

이 표는 사건 문장을 해석하는 출력 규칙이다. psy_status·moral·기분·공포·복종·행동 기록을 변경하는 코드가 아니다. A/B/C/D 화제의3회 문턱, 동률 처리, 최근과 오늘이 반대일 때의 순서도 이전 시범과 같다. 최근 사건이 없어도 원래 정보로 답변을 구성하므로 답변 변형 이력은 진행한다.

## 기존 세이브와 테스트 세이브

1112 호출부가 캐시된 `$voice_impression`에 `VOICE_COMPOSE_1112` 표식이 있는지 확인한다. 예전 함수이면 현재 `#dynamic` 정의를 읽는다. 새 시작말 데이터가 없으면 기존 `#txt_man,'jo9_voice_1112_data'` 전용 경로로 상수만 보충한다. 새 리비전 플래그나 세이브 변환은 추가하지 않는다. 원래 남주/여주 대사 배열을 이 데이터 보충 호출로 덮어쓰지 않는다.

`spete.sav`, `spete_dialogue_test.sav` 및 다른 사용자 세이브는 수정하지 않았다. 게임을 재실행한 뒤 기존 테스트 세이브를 불러와1112를 다시 선택하면 된다. 세이브에 저장된 예전 화면의 문장이 로드 직후 보일 수 있으므로 새 질문을 실행해 비교한다. 기존 테스트 세이브의 설정은 오늘 칭찬 기록1이 있으나 관계·헌신·기분은 원래대로다.

## 분리/되돌리기

- 호출부만 옛 덧붙이기 코드로 바꾸고 새 함수를 남기면, 기존 답변 뒤에 전체 답변을 또 붙일 수 있다. 함수와 호출부의 반환 계약을 함께 맞춘다.
- 함수만 제거하고 호출부를 남기면 원래 정보나 대사 정의가 빠진다. 데이터만 제거하면 시작말/사건 후보가 비거나 보충을 반복할 수 있다.
- 전체 되돌리기는 이번 세 치환의 정확한 역패치다. 기준 파일과 바이트가 같아지는 것을 검사했다. 이후 수동 수정이 있으면 현재 파일에서 재검토한다.
- 두 최근ID 키를 비우면 다음 발언부터 다시 기록한다. 전체 기능을 분리하는 작업과 다르다.
- 이전 시범 패치까지 무조건 통째로 재생하지 않는다. 해당 작업 직전 기준과 선택한 패치만 지정한다.
