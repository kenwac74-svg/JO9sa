# 인상 묻기: 두 답변씩 묶기와 질문 재분류 비교

**A안은 같은 내용을 더 적은 페이지로 읽는 안이고, B안은 질문에 맞게 내용을 옮기는 안입니다.** 아래는 현재 채택 대사에서 고른 실제 문장입니다. 게임에 반영하지 않은 검토용 샘플입니다.

## 비교 조건

한 인물에게 동시에 선택될 수 있는 상태를 사용했습니다. 심리 상태 `soft`, 직업 `farmer`, 성격·감수성·자아·자존심 각 3, 복종도 15, 두려움 3, 도덕성 2, 이성 2, 본능 3, 적응 3, 응석 0, 오늘 보상·처벌 및 최근 행동 횟수 0입니다. `farmer`는 보통 말투(tone 2), 성격 합계는 `plain` 유형이 됩니다.

- 복종 단계는 2, 두려움 문안은 `max(1, 3-2/2)=2`, 이성 문안은 `min(2,2)=2`, 적응 문안은 `min(2+2,3)=3`, 헌신 문안은 `min(2,2)=2`입니다. `rebell['soft']=0`이므로 복종 단계가 초기화되지 않습니다.
- 아래 여섯 답변의 core/detail은 모두 이 상태에서 허용되는 level 0 문안입니다. 실제 선택에는 다른 변형도 있으므로, 이 여섯 문안이 매번 고정 출력된다는 뜻은 아닙니다. 이번 비교에서는 같은 변형을 고정했습니다.
- **답변 하나는 core와 detail을 합친 완결 발화**입니다. A안의 ‘2개’는 조각 두 개가 아니라 이 완결 답변 두 개입니다.
- 이 상태에는 `instinct_3`, `spoil_0`도 함께 나올 수 있습니다. 아래에서는 여섯 답변만 비교하며, 그 둘의 생략은 샘플 범위를 줄인 것이지 삭제 제안이 아닙니다. 별도 도입문·인물명·HTML 장식도 비교 양쪽에서 공통 생략했습니다.

B안에서 다른 질문으로 옮긴 페이지는 다음과 같습니다. 아래 ‘이유’와 출처 표시는 검토 설명이며 게임 대사에 넣는 문구가 아닙니다.

| 이동한 질문 | B안에서 읽을 한 페이지 | 원문과 달라지는 점·이유 |
|---|---|---|
| **1113 · 나에게 부탁할 것이 있나?** | 제발… 저한테 온갖 끔찍한 짓들은 시키지 말아 주세요. | `obed_2` detail의 원문 ‘하지만 제발…’에서 ‘하지만’만 제거한 제안문입니다. 주인 평가가 아니라 행동을 삼가 달라는 직접적인 부탁이므로 옮깁니다. ‘따르겠다’는 core는 인상에 남습니다. |

`custom_3` detail의 ‘처지를 바꾸고 싶다’만 떼어 1114(하고 싶은 일)로 옮기는 선택도 가능하지만, 이 샘플에서는 **익숙함과 미련이 공존하는 원래 답변을 유지**했습니다. 1115(싫은 것)로 억지로 옮긴 항목은 없습니다. 주인이 두렵다는 말은 주인에 대한 인상이므로 남겼습니다.

## 원문 출처와 남김·이동 기준

모든 ID는 `outputs/argon-integration-20261018/accepted.json`의 `fragment_id`입니다. 접두사 `q1112_body_`는 아래 표의 모든 ID에 공통입니다. 실제 런타임 선택 조건은 현재 `$voice_impression`의 원래 의미 선택식과 대조했습니다.

| 의미 | core / detail ID (공통 접두사 뒤 부분) | B안 판단 |
|---|---|---|
| 관계 `relation_soft` | `relation_soft_core_reserved_t2` / `relation_soft_detail_a_t2` | **1112 유지.** 주인이 자신을 어떻게 대하고 복종을 기대하는지에 대한 관계 응답입니다. |
| 복종 `obed_2` | `obed_2_core_reserved_t2` / `obed_2_detail_a_t2` | **core는 1112, detail은 1113.** 복종 의사와 부탁을 구분합니다. |
| 두려움 `fear_2` | `fear_2_core_reserved_t2` / `fear_2_detail_a_t2` | **1112 유지.** 주인을 두려워하는 이유까지 한 답변입니다. |
| 이성 `ratio_2` | `ratio_2_core_reserved_t2` / `ratio_2_detail_a_t2` | **1112 유지.** 보상해 주는 대우가 주인을 따를 이유가 되었다는 설명입니다. 새 보상을 요구하는 부탁과 다릅니다. |
| 생활 적응 `custom_3` | `custom_3_core_reserved_t2` / `custom_3_detail_a_t2` | **전체 1116 이동.** 현재 생활에 대한 심정을 원문 그대로 보존합니다. |
| 감사 `moral_2` | `moral_2_core_reserved_t2` / `moral_2_detail_a_t2` | **1112 유지.** 자신을 돌봐 주는 주인에 대한 감사·평가입니다. |

`urge_0..5`와 `spoil_1..5`는 이미 1113에 분리되어 있으므로 이 비교에 포함하지 않았습니다.

## 페이지 수와 내용량은 별개

| 범위 | 현재 | A안: 두 답변씩 | B안: 재분류만 |
|---|---:|---:|---:|
| 위 여섯 답변의 인상 질문 | 6페이지 | **3페이지** | **5페이지** |
| 위 여섯 답변의 이동분까지 전부 읽기 | 6페이지 | **3페이지** | **7페이지** = 인상 5 + 부탁 1 + 기분 1 |
| 위 상태의 본능·응석도 포함한 인상 질문 | 8페이지 | **4페이지** | **7페이지** |

**두 안 모두 대사의 뜻을 삭제하지 않습니다.** A안은 페이지 전환만 줄이고 한 페이지를 길게 만듭니다. B안은 인상 질문의 내용 일부를 다른 질문으로 옮기므로, 인상에서 읽는 내용은 줄어도 모든 질문을 읽는 총량은 줄지 않습니다. 부탁절을 별도 질문에 분리하면 총 페이지 수는 늘 수도 있습니다. 두 안을 함께 쓸 수도 있으며, 이 여섯 답변 예시에서는 남은 인상 5항목을 두 개씩 묶으면 인상 3페이지와 이동한 두 질문 각 1페이지가 됩니다.

## 실제 엔진 확인과 길이

현재 게임 복사본 `before.qsp`(SHA-256 `e49bceb154990f94f582941ad4f7d3aa9c58483e027178586d2e28f0c0b7080a`)를 QSP WASM 엔진 5.8.0으로 열고, 실제 1112 질문 선언과 실제 `$special_part`를 실행했습니다. 실행 중 메모리의 조각 검색 목록만 위 12개 core/detail로 한정해, 여섯 완결 답변이 **한 번의 같은 인상 대화에서 모두 실제 선택·출력됨**을 확인했습니다. 샘플 밖의 `instinct_3`, `spoil_0`도 원래 대사 fallback으로 남아 전체 8페이지가 출력됐습니다. 엔진 오류 0건, 검사 6개 통과이며 게임 파일 해시는 실행 전후 동일했습니다. 재현 코드는 `sample-check.cjs`, 결과는 `sample-check.json`입니다.

| A안 페이지 | 현재 두 답변의 각각 길이 | 합친 길이 | 공백 제외 |
|---|---:|---:|---:|
| 관계 + 복종 | 83자 + 68자 | **153자** | 116자 |
| 두려움 + 복종할 이유 | 66자 + 69자 | **137자** | 100자 |
| 생활 적응 + 감사 | 86자 + 96자 | **184자** | 136자 |

합친 길이에는 두 문단 사이 줄바꿈 2자와 지문을 포함했습니다. 공통 인물명·선택적 도입문·HTML 장식은 제외했습니다. **픽셀 렌더링, 실제 클라이언트 창 크기·글꼴·넘침은 검증하지 않았습니다.** 위 수치는 텍스트 길이 비교이며 화면에 맞는다는 보증은 아닙니다. A안의 묶음 화면과 B안 재분류는 구현한 결과가 아니라 검토용 배치입니다.
