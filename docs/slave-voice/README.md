## 지금까지 확정된 것
1. 대사 출력 1차 범위: 질문하기 7종(1111~1117)과 포트레이트 정보 화면을 열 때의 대사(노예·조수). 규칙 칸은 제외.
2. 새 상태 변수는 최소로 하고 기존 잭오나 변수·문법을 활용한다. 기억 3층은 `already_done_today/recent/total`과 무드렛·등급으로 대신한다.
3. 기억 층의 역할: 장기는 태도·말씨·털어놓는 깊이, 중기는 감정의 온도와 요즘 화제, 단기는 구체 사건·몸·순간 반응.
4. 일상 대사는 존댓말만 쓰고, 반말은 사건 통 대사 전용이다.
5. 말투 3종(합니다체, 해요체, 투박한 해요체). 하옵니다체 제외. 말투는 역할이 아니라 직업으로, 어휘는 가족 계층으로 정한다(초안). 귀족가 하인·궁정 출신은 어휘로 구분한다.
