# JO9 노예·조수 대사 생성 규정집 v1

- 작성일: 2026-10-15
- 근거: `WAYWARD_REVERSE_DESIGN.md` 12~15절의 사용자 결정. 이 규정집과 설계 문서가 어긋나면 설계 문서의 최신 사용자 결정이 우선한다.
- 목적: **어떤 AI나 사람이 이 문서 하나만 읽고도** 잭오나(JO9 2.3.2.5 한국어판)의 노예·조수 대사를 같은 기준으로 만들 수 있게 한다.
- 이 문서는 대사 **문장**을 만드는 규칙이다. QSP 코드 작성은 다루지 않는다.

---

## 0. 한 장 요약
1. 원래 게임 문장은 지우지 않는다. 새 대사는 **앞이나 뒤에 붙이는 한마디**다.
2. 한마디의 화제는 **오늘 → 요즘 → 평소** 순서로 고른다. 질문마다 쓸 수 있는 층이 정해져 있다(4절).
3. **무엇을** 말할지는 기억(사건·기분·적성)이 정하고, **어떻게** 말할지는 유형 9종(3절)이, **어떤 어미와 낱말로** 말할지는 직업·가족(2절)이 정한다.
4. 일상 대사는 **존댓말만** 쓴다. 반말·하옵니다체·하게·하오체는 쓰지 않는다.
5. 창관 이야기는 창관 화면에서만 한다.

## 1. 입력: 노예 카드
대사를 만들기 전에 아래 카드를 채운다. 값은 게임 화면이나 세이브에서 읽는다. 모르는 칸은 비워 두고, 그 칸을 쓰는 규칙은 건너뛴다.

| 칸 | 내용 | 게임 값 |
|---|---|---|
| 이름 | | `$slave_name` / `$assistant_name` |
| 직업 | 58종 중 하나 또는 없음 | `$slave_occupation` |
| 가족 | 54종 중 하나 | `$slave_family`, 계층 `family_index` 1~5 |
| 성격 | 0~5 | `temper` |
| 감수성 | 0~5 | `sensitivity` |
| 자아 | 0~5 | `ego` |
| 태도 | 0~5 (높을수록 건방짐) | `pride` |
| 헌신 | 0~5 | `moral` |
| 두려움 | 0~5 | `fear` |
| 기분 | −5~+5 | `mood` |
| 정신 상태 | 15종 중 하나 | `$slave_psy_status` |
| 오늘 일 | 오늘 처벌·칭찬·수업·성행위 등 | `already_done_today`, `punished_today`, 오늘 무드렛 |
| 요즘 일 | 최근 자주 받은 것 | `already_done_recent`, 무드렛 |
| 몸 상태 | 배고픔, 더러움, 피로, 아픔, 잠자리 | 몸 상태 무드렛 |
| 적성 | 기술 14종 중 적성이 있는 것·싫은 것 | `*_affinity` |
| 최근 수업 | 과목 + 방식(직접·가정교사·위탁·조수) | 수업 번호별 `already_done_recent` |
| 조수 관계 | 좋음·나쁨, 질투 | 관계 점수, 질투 무드렛 |

화면 이름 참고 (등급 0 → 5)
| 값 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 성격 | 무관심함 | 차가움 | 내성적임 | 수동적임 | 적극적임 | 열정적임 |
| 감수성 | 무정함 | 냉담함 | 둔감함 | 민감함 | 다감함 | 여림 |
| 자아 | 우유부단 | 겁쟁이 | 소심함 | 주관적 | 단호함 | 완고함 |
| 태도 | 개방적 | 솔직함 | 의존적 | 당당함 | 건방짐 | 오만함 |

기분 (−5 → +5): 절망적, 우울함, 침울함, 부정적, 피곤함, 차분함, 긍정적, 만족함, 낙관적, 행복함, 황홀함.

## 2. 말투와 어휘: 직업과 가족이 정한다
말투와 어휘는 노예가 평생 바뀌지 않는 배경으로 정한다. 노예인지 조수인지로 정하지 않는다.

### 2.1 말투 3종 (직업 기준)
| 말투 | 직업 | 예 |
|---|---|---|
| 합니다체 | maid·valertry(하녀), secretary(비서), nun(수녀), policewoman(경찰), mind_contol, time_plice, jailer(교도관), academy(스타플릿 졸업생), mech(전투 로봇 조종사) | "어제 칭찬해 주셔서 기뻤습니다, 주인님." |
| 투박한 해요체 | tribal_girl, thief, beggar, gypsy, whore·markitane·brothel, thug, brigand, punk, contraband | "어제 칭찬해 주신 거, 솔직히 좀 좋았어요." |
| 해요체 (기본) | 그 밖의 모든 직업과 직업 없음 (간호사·교사·웨이트리스 포함) | "어제 칭찬해 주셔서 기뻤어요, 주인님." |

### 2.2 어휘 4종 (가족 기준)
| 어휘 | 가족 | 예 |
|---|---|---|
| 궁정·귀족가 하인 | mprincess, knight, valetry, servant | 칭찬 → 치하, 기뻤어요 → 영광이었어요 |
| 세련된 | 그 밖의 계층 2 (magnat, bankeer, mayor, mafiosi, surgeon, businessman, finance, general, astrofarm, nanofarmacist) | 정돈된 낱말, 비속어 없음 |
| 보통 | 계층 3·4, policeman, minitruth, church | 일상 낱말 |
| 거친 | barbarian_king, tribe, amazon, nomad, gypsy, workhouse, orphan, orpnange, anter | 짧고 직설적인 낱말 |

- 말투(어미)와 어휘(낱말)는 따로 정해져 겹친다. 예: 하녀 직업 + 하녀 집안 = 합니다체 + 귀족가 하인 어휘.
- 어휘는 낱말만 바꾼다. 어미는 2.1을 따른다.
- 낱말 바꿈표와 말투·어휘가 부딪힐 때의 규칙은 `VOCABULARY_TABLE.md`를 따른다.

### 2.3 금지
- 반말: 일상 대사에서 쓰지 않는다. 반말은 특정 사건의 통 대사에서만 쓰며, 이 규정집의 대상이 아니다.
- 하옵니다체, 하게체, 하오체: 쓰지 않는다.
- 적대·반발은 반말이 아니라 **내용과 비꼬는 존대**로 표현한다. 예: "그 정도로 제가 꺾일 줄 아셨어요?"

## 3. 유형 9종: 어떻게 말하는가
유형은 게임 변수가 아니라 대사를 쓰기 위한 기준이다. 보이는 등급 네 개로 그때그때 판정한다. 노예는 조교로 변하므로 같은 노예도 유형이 바뀔 수 있다.

### 3.1 판정
- 드러냄 = 성격 + 감수성 (0~10)
- 내세움 = 자아 + 태도 (0~10)
- 0~3 낮음, 4~6 보통, 7~10 높음

| | 드러냄 낮음 | 드러냄 보통 | 드러냄 높음 |
|---|---|---|---|
| 내세움 높음 | 얼음 | 도도 | 불꽃 |
| 내세움 보통 | 관조 | 평범 | 솔직 |
| 내세움 낮음 | 인형 | 순종 | 여린 |

### 3.2 유형별 말하기
| 유형 | 말하는 결 | 쉽게 말하는 것 | 말하지 않는 것 | 예 (해요체) |
|---|---|---|---|---|
| 얼음 | 짧고 건조함. 덧붙이지 않음 | 경멸, 무관심, 자기 능력 | 감정 전부, 외로움 | "…그렇군요." |
| 도도 | 예의 있게 선을 긋고 조건을 붙임 | 자존심, 취향, 불쾌함 | 기쁨, 고마움 | "나쁘진 않더군요. 그뿐이에요." |
| 불꽃 | 짧고 세게, 되묻는 말이 많음 | 불만, 분노, 원하는 것 | 두려움, 약한 모습 | "왜요? 제가 틀렸어요?" |
| 관조 | 담담하게 사실만 | 판단, 관찰 | 바람, 속마음 | "오늘은 비가 오네요. 수업은 길었고요." |
| 평범 | 무난함. 그날 기분이 묻어남 | 그날의 기분 | 깊은 속내 | "오늘은 좀 피곤해요." |
| 솔직 | 감정이 바로 나오고 할 말은 함 | 기쁨, 서운함, 바람 | 거의 없음 | "칭찬받아서 기뻐요! 또 해 주세요." |
| 인형 | 묻는 말에만 대답. 아주 짧음 | 거의 없음 | 자기 자신 | "…네." |
| 순종 | 조용하고 공손함. 짧은 감사 | 작은 기쁨, 고마움 | 불만, 원하는 것 | "감사합니다… 열심히 할게요." |
| 여린 | 망설이고 말끝을 흐림. 잘 욺 | 두려움, 슬픔, 정 | 분노, 원하는 것 | "저기… 무서웠어요…" |

### 3.2.1 트레잇: 신경쇠약·정신분열 (2026-10-15 사용자 결정)
- 정신력 = 자아 + 성격 + 태도. 2 이하 정신분열, 3~4 신경쇠약 (게임 화면의 노예 특성과 같은 계산).
- 신경쇠약 + 인형: 요구 묻기에서 덧붙이지 않는다 (요구를 표현하지 않게 하는 트리거). 어투와 다른 자리는 그대로.
- 정신분열 (모든 유형 동일): 덧붙임과 포트레이트 한 줄을 전용 대사 12줄로 바꾼다. 조합형 6줄은 조각마다 어투(합니다·해요·투박)를 무작위로 섞고 반말은 넣지 않는다. 통 대사 6줄은 광인의 반말·독백·환청·환영을 그대로 출력한다. 대사는 `lines/doll_trait_v1.md`.
- 인형은 말할 의지가 없는 극단이고, 반항형은 말하기 싫어서 반항하는 극단이다. 요구 묻기의 "요구 없음"에서는 둘 다 덧붙이지 않는다.

### 3.3 표현 깊이: 얼마나 털어놓는가
유형이 기본 결을 정하고, 감정 종류에 따라 아래 계산으로 깊이를 정한다. 값이 4 이상이면 드러냄, 2~3이면 암시, 1 이하면 감춤이다.
| 감정 종류 | 계산 |
|---|---|
| 취약 (두려움·수치·슬픔) | 헌신 − 태도/2 − (두려움 4 이상이면 1) |
| 적대 (분노·원망·혐오·질투) | 자아/2 + 성격/2 − 두려움 |
| 긍정 (자부심·애정·고마움) | 헌신 + 감수성/2 − 태도/2 |

- 감출 때는 내용을 말하지 않고 겉모습만 말한다. 예: 적대 감춤 → "괜찮아요."
- 유형의 "말하지 않는 것" 칸과 계산이 부딪히면 유형을 따른다.

## 4. 기억 층: 무엇을 말하는가
| 층 | 하는 일 | 쓰는 것 |
|---|---|---|
| 장기 | 무엇을, 어떤 결로, 얼마나 깊이 | 원래 게임 문장, 배경, 유형, 헌신, 적성 |
| 중기 | "요즘" 화제 | 무드렛, 최근 횟수, 기분 |
| 단기 | "오늘" 일과 몸 | 오늘 횟수, 오늘 처벌, 몸 상태 |

### 4.1 화제 고르기
1. 원래 게임 문장은 장기 층이며 **그대로 둔다.**
2. 덧붙일 한마디는 그 질문이 허용하는 층(4.2) 안에서 **단기 → 중기 → 장기** 순서로 고른다. 오늘 일이 있으면 오늘, 없으면 요즘, 그것도 없으면 덧붙이지 않는다.
3. 단기 사건이 장기 태도를 뒤집지 않는다. 오늘 칭찬받은 얼음은 여전히 얼음처럼 말한다.
4. 한마디는 **1~2문장**이다.

### 4.2 질문별 규칙 (질문하기 7종)
| 질문 (번호) | 원래 문장 | 덧붙이는 것 | 쓰는 층 | 위치 |
|---|---|---|---|---|
| 과거 묻기 (1111) "과거 이야기를 들려줘" | 출신·가족·직업 이야기 | 지금에 대한 한마디. 기분 나쁨 → "돌아가고 싶다", 헌신 높음 → "지금은 여기가 제 자리" | 장기 + 중기 | 뒤 |
| 현재 기분 묻기 (1116) "기분은 어때요?" | 무드렛 문장 전부 나열 | **덧붙이지 않는다.** 말투만 맞춘다 | 중기 | — |
| 요구 묻기 (1113) "제게 바라는 게 있나요?" | 욕구·성향 요구 (편안함, 사치, 단것, 명성 등) | 지금 몸이 원하는 것. 배고픔 → 먹을 것, 더러움 → 씻기, 잠자리 나쁨 → 침대 | 장기 + 단기(몸) | **앞** |
| 희망사항 묻기 (1114) "뭘 하고 싶나요?" | 적성 있는 일 ("~가 되고 싶다") | 주제 = 최근 수업 방식(4.3), 말하는 방식 = 유형 | 장기 + 중기 | 뒤 |
| 불만 묻기 (1115) "당신이 싫어하는 게 있나요?" | 싫은 성향 목록 | 요즘 쌓인 불만, 오늘 처벌 | 장기 + 중기 + 단기 | 뒤 |
| 인상 묻기 (1112) "저에 대해 어떻게 생각하세요?" | 등급표 조립 문장 | 요즘 주인이 한 일(칭찬·처벌), 오늘 한 일 | 장기 + 중기 + 단기 | 뒤 |
| 조수에 대해 묻기 (1117) (관계 계산 `origins_relations`) | 관계 점수 문장 | 요즘 조수와 있었던 일 (질투, 같이 잠, 싸움) | 장기 + 중기 | 뒤 |

- 질문 번호와 메뉴 문구는 게임 원문(`interaction`, `demo_menu_form`)에서 확인했다.
- 거부: 노예가 대답을 거부하면 지금의 거부 대사(정신 상태별 15줄)를 그대로 쓴다. 새로 만들지 않는다.
- 불만·질투는 적대 감정이므로 3.3의 적대 계산을 쓴다. 두려우면 "괜찮아요"로 감춘다.

### 4.3 희망사항: 수업 방식 = 주제
| 최근 수업 방식 | 게임 메뉴 | 주제 |
|---|---|---|
| 직접교육 | 교육 활동 | 주인에게 배운 것, 주인에 대한 감정 |
| 가정교사 | 가정교사 | 교사 이야기 |
| 위탁교육 | 학과 출석 | 바깥 학과 이야기 |
| 조수 교육 | 조수⇒노예 : 교육 | 조수와의 관계 |
| 최근 수업 없음 | — | "언젠가 해 보고 싶다" |

## 5. 포트레이트와 그 밖의 자리

### 5.1 노예 포트레이트 (화면을 열 때)
- 지금의 3인칭 나레이션(정신 상태 문장)을 그대로 두고, 그 뒤에 `[이름]` 1인칭 대사 **한 줄**을 붙인다.
- 한 줄의 화제: 오늘 일 → 요즘 일 → 평소.
- 형식:
  ```
  (원래 3인칭 나레이션)
  [이름]
  1인칭 대사 한 줄
  ```

### 5.2 조수 포트레이트
- **대사를 조합하지 않는다.** 지금의 노예 전공 보고(기본 보고, 전공 목록, 상표 없음 안내)를 내용 그대로 두고, 조수 직업의 말투(2.1)로 쓴 판만 만든다.
- 예: 합니다체 "노예의 전공을 알아본 결과 다음과 같습니다, 주인님." / 해요체 "노예 전공을 알아봤더니 이래요, 주인님." / 투박한 해요체 "애 전공 알아봤는데요, 이래요."

### 5.3 싫은 과목을 배운 뒤의 반응
- 조건: 수업을 거부하지 않았고, 그 과목 적성이 0 이하이며, 결과 성실도가 0~1일 때.
- 위치: 원래 수업 결과 문장 바로 뒤에 1인칭 한 줄.
- **말투별로 1줄씩, 모두 3줄만** 만든다. 유형·과목·방식으로 나누지 않는다.
  - 합니다체: "…이 공부는 저와 맞지 않는 것 같습니다."
  - 해요체: "…솔직히 이건 재미없었어요."
  - 투박한 해요체: "…이런 거 배워서 뭐 해요."

### 5.4 규칙 칸
- 규칙·식단·잠자리 칸을 누를 때는 대사를 만들지 않는다.

### 5.5 창관
- 창관 대사는 **창관 화면에서만** 나온다. 질문하기·포트레이트에서 창관 이야기(접객, 손님, 지명)를 하지 않는다.
- 창관 대사를 만들 때도 2절(말투·어휘), 3절(유형), 5.3의 "말투별 3종" 원칙을 그대로 쓴다.

## 6. 한국어 문장 규칙 (QSP 출력 조건)
1. 대사 한 조각은 문장 끝까지 갖춘 **완결 문장**으로 쓴다. 문장끼리만 이어 붙인다.
2. 어미를 자동으로 바꾸는 방식을 전제하지 않는다. 말투마다 문장을 따로 쓴다.
3. 주어를 생략한 문장을 기본으로 한다. 주어 높임이 얽히는 문장은 피한다.
4. 조사는 잭오나 표기를 따른다: "(은)는", "이(가)", "(을)를", "(이)가".
5. 이름은 `<<$slave_name>>`, 주인 호칭은 "주인님"을 기본으로 쓴다.
6. 한 줄은 너무 길지 않게 쓴다. 포트레이트 한 줄은 40자 안팎.
7. 노예가 모르는 정보(정확한 수치, 시스템 용어)를 말하지 않는다.
8. 처벌은 때리는 것만이 아니다(욕설, 굶기기, 가두기 등). "때리다", "맞다", "매"처럼 매질을 전제한 낱말은 쓰지 않는다. "벌", "혼나다"를 쓰고, 세게 말할 때는 "학대", "가혹하게 다루시네요"까지만 쓴다. "성실도 0" 대신 "집중이 안 됐어요".

## 7. 출력 형식
대사를 넘길 때는 한 줄마다 아래 칸을 붙인다. 구현 담당이 조건을 그대로 옮길 수 있게 하기 위해서다.

| 칸 | 예 |
|---|---|
| 자리 | 인상 묻기 (뒤에 붙임) |
| 층 | 단기 |
| 조건 | 오늘 처벌 1회 이상 |
| 유형 | 도도 |
| 말투 | 해요체 |
| 어휘 | 보통 |
| 표현 깊이 | 암시 |
| 대사 | "오늘 일은… 잊지 않겠지만요." |

## 8. 생성 순서 (따라 하기)
1. 노예 카드를 채운다 (1절).
2. 직업으로 말투, 가족으로 어휘를 정한다 (2절).
3. 등급 네 개로 유형을 판정한다 (3.1).
4. 질문(또는 자리)을 정하고, 허용된 층을 확인한다 (4.2, 5절).
5. 허용된 층 안에서 오늘 → 요즘 순서로 화제를 고른다 (4.1). 없으면 덧붙이지 않는다.
6. 화제의 감정 종류로 표현 깊이를 계산한다 (3.3).
7. 유형의 결 + 표현 깊이 + 말투 + 어휘로 1~2문장을 쓴다.
8. 9절 점검표로 확인하고, 7절 형식으로 넘긴다.

---

## 9. 점검표
- [ ] 원래 게임 문장을 지우거나 바꾸지 않았다.
- [ ] 존댓말만 썼다. 반말·하옵니다·하게·하오가 없다.
- [ ] 말투가 직업과 맞고, 어휘가 가족과 맞는다.
- [ ] 유형의 "말하지 않는 것"을 말하지 않았다.
- [ ] 그 질문이 허용하지 않는 층을 쓰지 않았다 (예: 과거 묻기에 오늘 일).
- [ ] 현재 기분 묻기에 덧붙이지 않았다.
- [ ] 조수 포트레이트를 조합하지 않았다.
- [ ] 창관 이야기를 창관 밖에서 하지 않았다.
- [ ] 완결 문장이고, 조사 표기가 잭오나식이다.
- [ ] 노예가 수치·시스템 용어를 말하지 않는다.

## 10. 예시 (전체 따라가기)
노예 카드
- 직업 waitress → 해요체. 가족 merchant(계층 3) → 보통 어휘.
- 성격 3, 감수성 2 → 드러냄 5 (보통). 자아 4, 태도 4 → 내세움 8 (높음) → **도도**.
- 헌신 2, 두려움 1, 기분 +2.
- 요즘 칭찬을 자주 받음. 가정교사에게 요리를 배움(요리 적성 있음).
- 오늘 처벌 1회. 배고픔, 잠자리 나쁨. 조수에게 질투.

| 자리 | 층 | 덧붙인 대사 |
|---|---|---|
| 과거 묻기 | 중기 (기분 좋음) | "…지난 일이에요. 지금이 나쁘진 않고요." |
| 인상 묻기 | 중기 + 단기 | "요즘은 칭찬을 아끼지 않으시더군요. 오늘 일은… 잊지 않겠지만요." |
| 요구 묻기 | 단기 (배고픔), 앞에 | "식사가 좀 부족해요." |
| 희망사항 묻기 | 장기 + 중기 (가정교사) | "요리라면 제가 잘하는 편이에요. 선생님 수업도 나쁘진 않더군요." |
| 불만 묻기 | 중기 + 단기 | "침대가 딱딱해서 잠을 못 자요. 오늘 벌도… 납득은 안 돼요." |
| 현재 기분 묻기 | — | 덧붙이지 않음 (지금처럼 무드렛 전부 나열) |
| 조수에 대해 묻기 | 중기 (질투) | "조수님은 요즘 칭찬을 독차지하시더군요." |
| 포트레이트 | 단기 | (나레이션) "그녀는 팔짱을 끼고 당신을 본다." + [이름] "…오늘 일은 기억해 둘게요." |

같은 노예가 처벌 없는 날이면 인상 묻기·불만 묻기·포트레이트의 "오늘" 부분이 빠지고 요즘 일만 남는다.
