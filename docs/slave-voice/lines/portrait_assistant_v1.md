# 조수 포트레이트 말투판 v1

- 작성: 2026-10-15, Claude (대사 생성 규정집 v1 기준)
- 자리: 조수 포트레이트를 눌러 정보 화면을 열 때 하단 상자 (`assistant_stat`)
- 원칙: **대사를 조합하지 않는다.** 지금의 보고 내용을 그대로 두고 말투만 조수 직업에 맞춘다 (규정집 5.2).

## 1. 판 고르기
| 조수 직업의 말투 | 쓰는 문장 |
|---|---|
| 합니다체 | **원문 그대로** (이미 합니다체로 쓰여 있다) |
| 해요체 | 아래 해요체 판 |
| 투박한 해요체 | 아래 투박한 해요체 판 |

- 링크(`전공 조건보기`), 전공 목록(`<<$mid($spec_list, 3)>>`), `[<<$assistant_name>>]<br>` 머리, `</div>` 등 코드 부분은 원문과 똑같이 둔다.

## 2. 문장

### O1 노예가 없을 때의 기본 보고
| 판 | 문장 |
|---|---|
| 원문 (합니다체) | 새 노예는 혼란을 틈타 탈출을 모색하거나 아무일도 하려하지 않으려 합니다만, 제가 지켜보겠습니다. 만약 특별히 관리를 지시하시면, 주의를 주며 가르치겠습니다. 이 여자들은 당신의 소유물이니 만큼, 망가지지 않게 조심히 다룰겁니다. 나의 주인님. |
| 해요체 | 새 노예는 정신없는 틈에 도망치려 하거나 아무것도 안 하려 할 수도 있지만, 제가 지켜볼게요. 따로 관리를 맡기시면 주의를 주면서 가르칠게요. 다 주인님 거니까, 망가지지 않게 조심히 다룰게요, 주인님. |
| 투박한 해요체 | 새로 온 애들은 어수선한 틈에 튀려 하거나 손 놓고 버티기도 하는데, 제가 지켜볼게요. 따로 맡기시면 따끔하게 가르칠게요. 다 주인님 물건이니까 망가지진 않게 할게요. |

| 해요체 | 지금 이 노예는 상표가 없어요. 조합 안에서 팔 순 있지만, 시중가보다 싸게 받게 돼요. |
| 투박한 해요체 | 이 애는 상표가 없어요. 조합에서 팔 순 있는데, 시세보다 덜 받아요. |

## 3. 작성 메모
- 합니다체 조수는 원문을 그대로 쓰므로 바뀌는 문장이 없다. 원문의 띄어쓰기·문장부호 손질은 이 묶음의 범위가 아니다 (내용 변경 금지 원칙).
- 원문 O1의 "당신의 소유물"은 해요체·투박한 해요체 판에서 "주인님 거", "주인님 물건"으로 바꿨다. 조수가 주인을 "당신"으로 부르는 것은 일상 존댓말 원칙(규정집 2절)과 어긋나기 때문이다. 내용은 같다.
- 합계: 4문장 × 2판 = 8문장.
