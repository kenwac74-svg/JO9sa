# 인형 + 신경쇠약·정신분열 대사 v1

- 작성: 2026-10-15, Claude
- 상태: 사용자 검수 대상
- 근거 (2026-10-15 사용자 결정)
  - 가장 극단에 있는 인형 유형은 **말할 의지가 없는** 것이고, 반대쪽 극단인 반항형은 **말하기 싫어서 반항하는** 것이다.
  - 인형의 대사를 극단적으로 줄이는 것은 **유형 + 트레잇**으로 정한다.
  - 트레잇 중 신경쇠약이나 정신분열이 오면 거의 말을 하지 않거나, 무의미한 조현병 증상 같은 대사를 출력한다.

## 1. 게임의 트레잇 (코드 확인, `#static_base` `$update_slave_features_list`)
- 정신력 = 자아 + 성격 + 태도 (각 0~5)
- 정신력 2 이하 → **정신분열** (설명창 제목은 "정신붕괴": "정신이 완전히 망가졌습니다. 인형과도 같은 상태입니다… 모든 행동, 대화, 명령 등에 의지를 상실")
- 정신력 3~4 → **신경쇠약** ("정신 상태가 위험 수준에 이르렀습니다")
- 둘 다 새 변수가 아니라 화면에 이미 표시되는 특성이다. 대사 쪽에서도 같은 계산식을 쓴다.

참고: 인형 유형은 내세움(자아 + 태도)과 드러냄(성격 + 감수성)이 모두 3 이하이므로, 인형 노예 상당수가 이 트레잇을 함께 가진다.

## 2. 적용 규칙
| 상태 | 질문하기 덧붙임 | 노예 포트레이트 한 줄 |
|---|---|---|
| 인형 (트레잇 없음) | 지금 대사 그대로 (짧은 인형 대사) | 지금 대사 그대로 |
| 인형 + 신경쇠약 | **덧붙이지 않는다** | `[이름]` 다음에 "……"만 |
| 인형 + 정신분열 | 아래 3절의 무의미한 대사 한 줄로 **바꾼다** | 아래 3절의 무의미한 대사 한 줄 |

- 원래 게임 문장은 이 경우에도 그대로 나온다. 바뀌는 것은 우리가 덧붙이는 한 줄뿐이다.
- 요구 묻기의 "요구 없음"일 때 인형은 원래부터 덧붙이지 않는다 (요구 묻기 1.1).
- 3절 대사는 **말투 구분 없이 한 벌**만 둔다. 망가진 정신 상태에서는 말투 차이가 의미 없기 때문이다. 다만 반말은 쓰지 않는다 (규정집 2.3).
- 어떤 줄을 고를지는 기존 의사난수 문법(날짜 + 행동 번호)으로 돌린다. 같은 날 같은 질문은 같은 줄이 나온다.

## 3. 정신분열 대사 (공통 12줄)
1. …쉿. 벽이 듣고 있어요.
2. …하나, 둘, 하나… 숫자가 자꾸 돌아와요.
3. …빵은 파란색이었어요. 그쵸?
4. …누가 창밖에서 제 이름을 불러요. 대답하면 안 돼요.
5. …손가락이 열한 개예요. 아까는 열 개였는데.
6. …비가 안에서 와요.
7. …그 노래, 또 시작했어요. 들리세요?
8. …오늘은 어제예요.
9. …주인님 그림자가 웃었어요.
10. …거울 속 애가 먼저 움직였어요.
11. …문이 숨을 쉬어요.
12. …네, 네. 알아요. 조용히 할게요. (허공에 대고)

- 질문과 상관없는 말이 나오는 것이 의도다. 플레이어는 대답이 어긋나는 것으로 노예가 망가졌음을 느낀다.
- 특정 가족(엄마, 아빠 등)은 노예마다 다르므로 넣지 않았다.

## 4. 확인할 것
- 신경쇠약·정신분열 트레잇이 **인형이 아닌 유형**(예: 순종, 여린)에 붙은 경우는 이번 결정에 들지 않아, 지금은 그 유형의 대사를 그대로 쓴다. 다른 유형에도 적용할지 정해야 한다.
