# 신경쇠약·정신분열 트레잇 대사 v1

- 작성: 2026-10-15, Claude
- 상태: 사용자 검수 대상
- 근거 (2026-10-15 사용자 결정)
  - 가장 극단에 있는 인형 유형은 말할 의지가 없는 것이고, 반대쪽 극단인 반항형은 말하기 싫어서 반항하는 것이다.
  - **신경쇠약**은 어투를 바꿀 필요까지는 없다. **인형 유형이 자신의 요구를 표현하지 않게 하는 트리거** 정도면 된다.
  - **정신분열**은 12개 정도의 전용 대사를 두고, **어투를 무작위로 마구 섞어서** 출력한다.

## 1. 게임의 트레잇 (코드 확인, `#static_base` `$update_slave_features_list`)
- 정신력 = 자아 + 성격 + 태도 (각 0~5)
- 정신력 2 이하 → **정신분열** (설명창 제목 "정신붕괴": "정신이 완전히 망가졌습니다. 인형과도 같은 상태입니다… 모든 행동, 대화, 명령 등에 의지를 상실")
- 정신력 3~4 → **신경쇠약** ("정신 상태가 위험 수준에 이르렀습니다")
- 화면에 이미 표시되는 특성이며, 대사 쪽에서도 같은 계산식을 쓴다. 새 변수 없음.

## 2. 적용 규칙
| 상태 | 처리 |
|---|---|
| 신경쇠약 + 인형 | **요구 묻기(1113)에서 덧붙이지 않는다.** 몸 상태 요구도, "요구할 처지가 아니지만…" 이음 문장도 없다. 다른 질문과 포트레이트는 인형 대사 그대로. 어투도 그대로 |
| 신경쇠약 + 다른 유형 | 영향 없음. 유형 대사 그대로 |
| 정신분열 (모든 유형) | 질문하기 덧붙임과 노예 포트레이트 한 줄을 **3절의 전용 대사로 바꾼다.** 유형·직업 말투는 무시하고 조각마다 어투를 무작위로 고른다 |

- 원래 게임 문장은 어느 경우에나 그대로 나온다. 바뀌는 것은 우리가 덧붙이는 한 줄뿐이다.
- 현재 기분 묻기(1116)와 조수 포트레이트는 원래 덧붙이는 대사가 없으므로 해당 없다.
- 정신분열을 모든 유형에 적용한 것은 "정신분열은 전용 대사 + 어투 섞기"라는 결정을 유형 구분 없는 규칙으로 읽은 것이다. 게임 설명도 "인형과도 같은 상태"라 유형이 의미를 잃는다.

## 3. 정신분열 전용 대사
### 3.1 출력 방법
1. 12줄 중 한 줄을 무작위로 고른다.
2. 그 줄의 조각(①, ②)마다 **합니다체·해요체·투박한 해요체 중 하나를 따로 무작위로** 고른다. 그래서 한 줄 안에서도 어투가 뒤섞인다.
3. 조각은 "…"로 시작하고, 조각 사이는 띄어 쓴다.
4. 무작위는 기존 의사난수 문법(날짜 + 행동 번호 + 조각 번호)을 쓴다. 새 변수 없음.
- 반말은 넣지 않았다 (규정집 2.3: 반말은 사건 통 대사 전용). 반말까지 섞을지는 확인이 필요하다.

### 3.2 대사 (조각별 어투)
| # | 조각 | 합니다체 | 해요체 | 투박한 해요체 |
|---|---|---|---|---|
| 1 | ① | 쉿. | 쉿. | 쉿. |
| | ② | 벽이 듣고 있습니다. | 벽이 듣고 있어요. | 벽이 듣고 있다니까요. |
| 2 | ① | 하나, 둘, 하나… | 하나, 둘, 하나… | 하나, 둘, 하나… |
| | ② | 숫자가 자꾸 돌아옵니다. | 숫자가 자꾸 돌아와요. | 숫자가 자꾸 돌아온다니까요. |
| 3 | ① | 빵은 파란색이었습니다. | 빵은 파란색이었어요. | 빵은 파란색이었다고요. |
| | ② | 그렇지 않습니까? | 그쵸? | 맞죠? |
| 4 | ① | 누가 창밖에서 제 이름을 부릅니다. | 누가 창밖에서 제 이름을 불러요. | 누가 창밖에서 제 이름 부른다고요. |
| | ② | 대답하면 안 됩니다. | 대답하면 안 돼요. | 대답하면 안 된다니까요. |
| 5 | ① | 손가락이 열한 개입니다. | 손가락이 열한 개예요. | 손가락이 열한 개라고요. |
| | ② | 아까는 열 개였는데. | 아까는 열 개였는데. | 아까는 열 개였는데. |
| 6 | ① | 비가 안에서 옵니다. | 비가 안에서 와요. | 비가 안에서 온다니까요. |
| 7 | ① | 그 노래가 또 시작됐습니다. | 그 노래, 또 시작했어요. | 그 노래 또 시작이네요. |
| | ② | 들리십니까? | 들리세요? | 들려요? |
| 8 | ① | 오늘은 어제입니다. | 오늘은 어제예요. | 오늘은 어제라니까요. |
| 9 | ① | 주인님 그림자가 웃었습니다. | 주인님 그림자가 웃었어요. | 주인님 그림자가 웃었다고요. |
| 10 | ① | 거울 속 애가 먼저 움직였습니다. | 거울 속 애가 먼저 움직였어요. | 거울 속 애가 먼저 움직였다니까요. |
| 11 | ① | 문이 숨을 쉽니다. | 문이 숨을 쉬어요. | 문이 숨 쉰다고요. |
| 12 | ① | 네, 네. | 네, 네. | 네, 네. |
| | ② | 알겠습니다. 조용히 하겠습니다. | 알아요. 조용히 할게요. | 알았다고요. 조용히 할게요. |

### 3.3 출력 예
- 4번 줄, ① 합니다체 + ② 투박한 해요체 → "…누가 창밖에서 제 이름을 부릅니다. …대답하면 안 된다니까요."
- 7번 줄, ① 투박한 해요체 + ② 합니다체 → "…그 노래 또 시작이네요. …들리십니까?"
- 3번 줄, ① 해요체 + ② 합니다체 → "…빵은 파란색이었어요. …그렇지 않습니까?"

- 질문과 상관없는 말, 어긋나는 어투가 섞여 나오는 것이 의도다. 플레이어는 대답이 맞지 않는 데서 노예가 망가졌음을 느낀다.
- 특정 가족(엄마, 아빠 등)은 노예마다 다르므로 넣지 않았다.
