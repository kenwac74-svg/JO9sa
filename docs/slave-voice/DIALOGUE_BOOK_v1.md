## 2. 인상 묻기 (1112)

- 작성: 2026-10-15, Claude (대사 생성 규정집 v1 기준)
- 메뉴 문구: "저에 대해 어떻게 생각하세요?"
- 상태: 사용자 검수 대상 (2026-10-15 결정: 다른 AI와 비교하지 않고, 어색한 문장만 사용자가 다듬는다).

### 1. 붙이는 자리
- 원래 게임 문장(`$slave_relation_description`, `$slave_obed_description` 등 `[이름]` 블록들)은 그대로 둔다.
- 마지막 블록 뒤에 `[이름]` 블록 하나를 더 붙이고, 아래 표의 문장을 넣는다.

### 2. 화제와 조건
| 화제 | 층 | 조건 (게임 값) | 감정 종류 |
|---|---|---|---|
| A 요즘 자주 칭찬 | 중기 | 최근 칭찬 횟수가 많음 (`already_done_recent`의 칭찬 계열) | 긍정 |
| B 요즘 자주 처벌 | 중기 | 최근 처벌 횟수가 많음 (`already_done_recent`의 처벌 계열) | 적대·취약 |
| C 오늘 처벌 | 단기 | 오늘 처벌받음 (`punished_today` > 0) | 적대·취약 |
| D 오늘 칭찬 | 단기 | 오늘 칭찬받음 (`rewarded_today` > 0) | 긍정 |

고르는 규칙
1. 오늘 일(C·D)이 있으면 오늘 일 문장 하나만 쓴다.
2. 단, 요즘 일과 오늘 일이 **반대**일 때(A+C, B+D)는 요즘 문장 뒤에 오늘 문장을 이어 붙인다. 예: A+C → "요즘은 칭찬을 아끼지 않으시더군요. 당연한 일이지만요. 오늘 일은… 잊지 않겠지만요."
3. 오늘 일이 없으면 요즘 일(A·B) 문장 하나를 쓴다. 둘 다 해당하면 횟수가 많은 쪽을 쓴다.
4. 아무것도 없으면 덧붙이지 않는다.
- "많음" = 최근 횟수 3 이상 (2026-10-15 사용자 동의). 최근 횟수는 행동마다 +1, 밤마다 −2이므로 하루에 세 번 이상이거나 이틀에 걸쳐 꾸준히 해야 3이 된다.
- 어휘는 보통 어휘 기준이다. 궁정·세련·거친 어휘 낱말 바꿈 표는 아직 없다.

## 3. 요구 묻기 (1113)

- 작성: 2026-10-15, Claude (대사 생성 규정집 v1 기준)
- 메뉴 문구: "제게 바라는 게 있나요?"
- 상태: 사용자 검수 대상 (2026-10-15 결정: 다른 AI와 비교하지 않고, 어색한 문장만 사용자가 다듬는다).

### 1. 붙이는 자리
- 원래 게임 문장(편안함·사치·단것·명성·성향 요구, 없으면 "전 감히 어떤 것도 요구할 수 없어요")은 그대로 둔다.
- **원래 문장 앞에** `[이름]` 블록 하나를 넣고, 아래 표의 문장을 넣는다. 몸이 원하는 것을 먼저 말하는 것이 자연스럽기 때문이다 (규정집 4.2).

#### 1.1 원래 문장이 "요구 없음"일 때 (2026-10-15 사용자 결정)
원래 게임은 바라는 것이 없을 때 두 문장 중 하나를 쓴다.
- `$no_need_gentle`: "전 감히 어떤 것도 요구할 수 없어요. 주인님."
- `$no_need`: "전 뭔가를 요구할 입장이 아니잖아요. 그렇죠? 전 집에 가고 싶고, 이 모든 악몽을 잊어버리고 싶어요. 그게 전부에요."

몸 상태 덧붙임이 있으면 앞뒤가 어긋나지 않게 이렇게 처리한다.
| 원래 문장 | 몸 상태 있음 | 몸 상태 없음 |
|---|---|---|
| `$no_need_gentle` | 원래 문장 대신 **"전 주인님께 뭘 요구할 처지가 아니지만…"** 을 쓰고, 그 **뒤에** 몸 상태 대사를 붙인다 | 원래 문장 그대로 |
| `$no_need` (반항형) | 원래 문장 그대로. **덧붙이지 않는다** — 비꼬기만 하고 더 말하지 않는다 | 원래 문장 그대로 |
| 그 밖 (요구가 있음) | 몸 상태 대사를 원래 요구 **앞에** 붙인다 | 원래 문장 그대로 |

예 (불꽃, 배고픔, `$no_need_gentle`)
> [이름] 전 주인님께 뭘 요구할 처지가 아니지만…
> [이름] 배고파요! 먹을 것부터 주세요!

- 이음 문장 "전 주인님께 뭘 요구할 처지가 아니지만…"은 말투별로 둔다: 합니다체 "저는 주인님께 무엇을 요구할 처지가 아니지만…", 해요체 "전 주인님께 뭘 요구할 처지가 아니지만…", 투박한 해요체 "전 주인님한테 뭘 달라고 할 처지가 아니지만…".
- `$no_need`(반항형) 처리 (2026-10-15 사용자 결정): 비꼬기만 하고 더 말하지 않는다.
- **인형 유형도 "요구 없음"일 때는 덧붙이지 않는다** (2026-10-15 사용자 결정: 가장 소극적인 유형도 마찬가지로 말하지 않게). `$no_need_gentle`이라도 이음 문장으로 바꾸지 않고 원래 문장만 나온다.

### 2. 화제와 조건
모두 단기(몸 상태)다. 원래 게임의 몸 상태 무드렛을 조건으로 쓴다.
| 화제 | 조건 (무드렛) | 우선순위 |
|---|---|---|
| F 병 | `neg_slave_ill` | 1 |
| E 상처·아픔 | `neg_slave_wounded`, `neg_pain` | 2 |
| A 배고픔 | `neg_hungry`, `neg_starvation` | 3 |
| C 피로 | `neg_exhausted` | 4 |
| B 더러움 | `neg_slave_dirty` | 5 |
| D 잠자리 나쁨 | `neg_bad_sleep` | 6 |

고르는 규칙
1. 해당하는 무드렛 중 **우선순위가 가장 높은 하나**만 쓴다.
2. 아무것도 없으면 덧붙이지 않는다.
3. 현재 기분 묻기(1116)가 같은 무드렛 문장을 이미 보여 주므로, 여기서는 **불평이 아니라 요구**로 쓴다.
- 어휘는 보통 어휘 기준이다.

### 1. 붙이는 자리
- 원래 게임 문장(적성 있는 일 "~가 되고 싶어요", 없으면 "명령하시는 거라면 뭐든지")은 그대로 둔다.

- 원래 문장이 적성 없음("명령하시는 거라면…")이면 덧붙이지 않는다.

### 2. 주제와 조건

### 3. 작성 메모
- 합니다체 조수는 원문을 그대로 쓰므로 바뀌는 문장이 없다. 원문의 띄어쓰기·문장부호 손질은 이 묶음의 범위가 아니다 (내용 변경 금지 원칙).
- 원문 O1의 "당신의 소유물"은 해요체·투박한 해요체 판에서 "주인님 거", "주인님 물건"으로 바꿨다. 조수가 주인을 "당신"으로 부르는 것은 일상 존댓말 원칙(규정집 2절)과 어긋나기 때문이다. 내용은 같다.
- 합계: 4문장 × 2판 = 8문장.

## 9. 트레잇: 신경쇠약·정신분열

- 작성: 2026-10-15, Claude
- 상태: 사용자 검수 대상
- 근거 (2026-10-15 사용자 결정)
  - 가장 극단에 있는 인형 유형은 말할 의지가 없는 것이고, 반대쪽 극단인 반항형은 말하기 싫어서 반항하는 것이다.
  - **신경쇠약**은 어투를 바꿀 필요까지는 없다. **인형 유형이 자신의 요구를 표현하지 않게 하는 트리거** 정도면 된다.
  - **정신분열**은 12개 정도의 전용 대사를 두고, **어투를 무작위로 마구 섞어서** 출력한다.

### 1. 게임의 트레잇 (코드 확인, `#static_base` `$update_slave_features_list`)
- 정신력 = 자아 + 성격 + 태도 (각 0~5)
- 정신력 2 이하 → **정신분열** (설명창 제목 "정신붕괴": "정신이 완전히 망가졌습니다. 인형과도 같은 상태입니다… 모든 행동, 대화, 명령 등에 의지를 상실")
- 정신력 3~4 → **신경쇠약** ("정신 상태가 위험 수준에 이르렀습니다")
- 화면에 이미 표시되는 특성이며, 대사 쪽에서도 같은 계산식을 쓴다. 새 변수 없음.

### 2. 적용 규칙
| 상태 | 처리 |
|---|---|
| 신경쇠약 + 인형 | **요구 묻기(1113)에서 덧붙이지 않는다.** 몸 상태 요구도, "요구할 처지가 아니지만…" 이음 문장도 없다. 다른 질문과 포트레이트는 인형 대사 그대로. 어투도 그대로 |
| 신경쇠약 + 다른 유형 | 영향 없음. 유형 대사 그대로 |
| 정신분열 (모든 유형) | 질문하기 덧붙임과 노예 포트레이트 한 줄을 **3절의 전용 대사로 바꾼다.** 유형·직업 말투는 무시하고 조각마다 어투를 무작위로 고른다 |

- 원래 게임 문장은 어느 경우에나 그대로 나온다. 바뀌는 것은 우리가 덧붙이는 한 줄뿐이다.
- 현재 기분 묻기(1116)와 조수 포트레이트는 원래 덧붙이는 대사가 없으므로 해당 없다.
- 정신분열은 모든 유형에 동일하다 (2026-10-15 사용자 확인).

### 3. 정신분열 전용 대사 (12줄 = 조합형 6 + 통 대사 6)
2026-10-15 사용자 결정
- 정신분열은 모든 유형에 동일하다.
- 반말은 기본적으로 이벤트에만 쓴다. 정신분열 전용 대사에는 **광인의 반말·독백·환청·환영을 묘사한 통 대사**가 들어갈 수 있다.
- 다만 **어투 조합에는 반말을 넣지 않는다** (조합형은 합니다체·해요체·투박한 해요체만 섞는다).

#### 3.1 출력 방법
1. 12줄 중 한 줄을 무작위로 고른다.
2. **조합형(Z1~Z6)** 이면 조각(①, ②)마다 합니다체·해요체·투박한 해요체 중 하나를 따로 무작위로 고른다. 한 줄 안에서도 어투가 뒤섞인다. 반말은 없다.
3. **통 대사(T1~T6)** 이면 적힌 그대로 출력한다. 어투 조합을 하지 않는다. 반말·독백·괄호 속 묘사가 들어 있다.
4. 무작위는 기존 의사난수 문법(날짜 + 행동 번호 + 조각 번호)을 쓴다. 새 변수 없음.

#### 3.2 조합형 6줄 (조각별 어투, 반말 없음)
| # | 조각 | 합니다체 | 해요체 | 투박한 해요체 |
|---|---|---|---|---|
| Z1 | ① | 쉿. | 쉿. | 쉿. |
| | ② | 벽이 듣고 있습니다. | 벽이 듣고 있어요. | 벽이 듣고 있다니까요. |
| Z2 | ① | 누가 창밖에서 제 이름을 부릅니다. | 누가 창밖에서 제 이름을 불러요. | 누가 창밖에서 제 이름 부른다고요. |
| | ② | 대답하면 안 됩니다. | 대답하면 안 돼요. | 대답하면 안 된다니까요. |
| Z3 | ① | 손가락이 열한 개입니다. | 손가락이 열한 개예요. | 손가락이 열한 개라고요. |
| | ② | 아까는 열 개였는데. | 아까는 열 개였는데. | 아까는 열 개였는데. |
| Z4 | ① | 그 노래가 또 시작됐습니다. | 그 노래, 또 시작했어요. | 그 노래 또 시작이네요. |
| | ② | 들리십니까? | 들리세요? | 들려요? |
| Z5 | ① | 주인님 그림자가 웃었습니다. | 주인님 그림자가 웃었어요. | 주인님 그림자가 웃었다고요. |
| | ② | 오늘은 어제입니다. | 오늘은 어제예요. | 오늘은 어제라니까요. |

출력 예
- Z2, ① 합니다체 + ② 투박한 해요체 → "…누가 창밖에서 제 이름을 부릅니다. …대답하면 안 된다니까요."
- Z4, ① 투박한 해요체 + ② 합니다체 → "…그 노래 또 시작이네요. …들리십니까?"

#### 3.3 통 대사 6줄 (그대로 출력, 반말·독백·환청·환영)
| # | 종류 | 대사 |
|---|---|---|
| T1 | 반말 독백 | …빵은 파란색이었어. 그치? 그치? 아무도 안 믿어 줘. |
| T2 | 환청 (보이지 않는 목소리에게 반말) | …아니야, 안 할 거야. 시끄러워… 너네 다 시끄러워! |
| T3 | 환영 | …저기, 천장에서 하얀 꽃이 자라요. 아, 떨어진다… 떨어진다! (허공을 향해 두 손을 뻗는다) |
| T4 | 강박 독백 | …하나, 둘, 하나. 하나, 둘, 하나. 틀리면 안 돼. 틀리면 또 와. |
| T5 | 환영 (주인을 알아보지 못함) | …누구야? 아… 주인님, 주인님이세요? 얼굴이 자꾸 바뀌어서… |
| T6 | 환영 + 반말 독백 | …거울 속 애가 먼저 움직였어. 쟤가 나야? 내가 쟤야? 히히… |

- 질문과 상관없는 말, 어긋나는 어투가 섞여 나오는 것이 의도다. 플레이어는 대답이 맞지 않는 데서 노예가 망가졌음을 느낀다.
- 통 대사의 반말은 정신분열 전용 대사 안에서만 허용된다. 일상 대사 규칙(규정집 2.3)은 그대로다.
- 특정 가족(엄마, 아빠 등)은 노예마다 다르므로 넣지 않았다.
