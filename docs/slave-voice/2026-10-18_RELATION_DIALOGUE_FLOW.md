# 다른 인물에 대해 묻기: 대사 연결 수정

2026-10-18 사용자 지시 중 세 번째 안건을 구현했다. 첫 번째 안건인 인상 묻기 페이지 통합/재분류는 비교 샘플만 작성했으며 게임의 1112 출력은 변경하지 않았다.

## 달라진 출력

- 1117(노예에게 조수에 대해 묻기)와 1118(조수에게 노예에 대해 묻기)에서 각 조각에 반복되던 행동 지문을 답변 전체에 최대 한 번만 출력한다. 원래 도입 장면의 서술은 유지한다.
- 지적 능력의 호평 다음에 자존심의 혹평이 나오는 경우 서로 다른 평가 근거를 명시하고 ‘다만’으로 잇는다. 부정 평가 다음의 긍정 평가는 ‘그래도’로 잇는다. 같은 방향의 평가를 무조건 긍정/부정으로 바꾸지 않는다.
- 16개 의미 그룹의 말투 3종, 총 48개 발화에서 모호한 신분·교우·특성 평가의 근거를 명료하게 했다. 원문 말투, 욕설·멸시와 추측/질문 형식은 유지했다.
- ‘상대가 더 똑똑함/아름다움’은 화자의 시기나 위축을 표현할 수 있다. high/low 이름만으로 연결 방향을 정하지 않고, 원래 특성 평가의 의미와 수치 증감을 확인한 그룹만 분류했다.

출력 예(두 번째 첨부의 두 특성):

> 지적으로 저와 가까운 여자애를 만난 건 좋은 일이에요.
> 다만 저렇게 자존심도 없는 모습이 여자가 어디까지 추락할 수 있는지 보여 줘요.

앞선 배경 평가에서 이미 행동 지문을 출력했다면 이 페이지에는 새 지문을 붙이지 않는다.

## 입출력과 호출 경로

패치 ID: `2026-10-18_relation_dialogue_flow`.

1. `interaction`의 공통 대사 캐시 검사에 `VOICE_ARGON_RELATION_FLOW_V6` 정의 확인을 추가했다. 기존 세이브에 이전 함수 정의가 저장돼 있어도 1111~1118 진입 시 현재 `#dynamic` 정의를 읽는다. 대사 은행 revision은 5 그대로다.
2. `origins_relations`의 `VOICE_RELATION_CONTEXT`에서 응답 전용 임시 변수를 초기화한다. 원래 77개 `$voice_native` 호출에 현재 페이지 번호를 네 번째 인자로 넘긴다. 화자 교환, 지능에 따른 원문 선택, 친족·고유 배경, 관계 계산 분기는 유지한다.
3. `$voice_native`가 선택한 core/detail과 다섯 원본 토큰의 바인딩을 마친 뒤, 색상 HTML을 감싸기 전에 `$voice_relation_line(group, selected_text, page_index)`을 호출한다. 선택 실패의 원문 대체 출력은 이 경로를 타지 않는다.
4. 새 함수는 이미 선택된 문자열을 받으며 새 대사를 무작위로 다시 고르지 않는다. 알려진 선두 지문 8종만 분리하고 임의의 괄호 내용은 보존한다. 그룹·말투·정확한 원문이 일치하는 경우에만 검토한 문구로 바꾼다.
5. 페이지 4의 특성 평가 그룹에만 앞/뒤 평가 방향에 따른 연결어를 붙인다. 출신/인종/가문 평가에 막연한 긍정·부정 분류를 강제로 적용하지 않는다.
6. `VOICE_RELATION_CONTEXT_END`에서 응답 전용 상태를 모두 지운다. 기존 기록 저장 방식은 그대로이고 새로운 영구 인물 키, 세이브 변환, 로케이션, 외부 의존성은 없다.

## 부작용과 유지보수

수정 로케이션은 `#dynamic`, `origins_relations`, `interaction` 세 곳이다. `#txt_man`의 9,120개 채택 원문 은행은 바꾸지 않고 출력 시 검토한 일부 문구만 정리한다. 원래 반복 방지용 이력은 선택된 원본 조각 ID로 계속 저장한다. 게임 수치·관계 점수·조건·개별 인물 배경은 바뀌지 않는다.

내부 함수 정의는 기존 함수들과 동일하게 대사 캐시에 포함된다. 조립 시 임시 상태는 `jo9_relation_active`, `jo9_relation_cue_used`, `jo9_relation_last_sign`이고 응답 종료 때 삭제한다. 함수 내부의 `jo9_vrl_*` 변수도 매 호출 후 삭제한다. 세이브 파일을 직접 수정하지 않는다.

함수만 제거하고 호출부를 남기면 문자열 출력이 깨질 수 있다. 되돌릴 때는 해당 패치 전체를 역적용하거나 작업 직전 백업을 복구한다. 컨텍스트 초기화·종료부를 따로 제거하면 다음 답변의 지문·연결어 상태가 남을 수 있다. 대사 은행이 바뀌어 정확한 원문이 달라지면 해당 문구 교정은 적용하지 않고 현재 선택된 문장을 유지한다.

## 검증 범위

- 수정 전 최신 플레이 파일의 바이트 왕복 및 해시 확인, 패치 역적용 바이트 일치, 259개 로케이션 유지.
- 1112/1113 조합 함수와 대사 은행의 바이트 동일 확인. 인상 묻기 샘플은 미반영.
- 별도 QSP 엔진에서 양방향 화자·말투 3종·지문 형식 3종 및 특성/배경 조합 검사. 독립 검토는 지능 3단계, 격리·복종 거부·고유/친족 배경, 빈 은행 대체 출력과 원래 관계 수치도 대조한다.
- 설치 FastQSP의 필수 출고 9경로와 구형 캐시를 설정한 실제 대화 8경로를 격리 복사본에서 실행한다. 원본 플레이/배포/세이브는 검사 중 수정하지 않는다.
- 실제 세이브 선택 UI, 모든 인물 조합의 문학적 자연스러움, 게임 창의 글자 배치는 자동 검사 범위가 아니다. 인상 묻기 두 답변 통합안의 실제 화면 배치는 선택 후 별도로 측정해야 한다.

백업·적용 해시와 검사 결과는 별도 QA 기록에 남긴다. 자동 생성한 진단 게임과 세이브 상태 원문은 저장소·배포에 넣지 않는다.
