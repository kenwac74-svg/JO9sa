# 인물 평가: 구어체와 의미를 연결하는 대화

2026-10-18 사용자 교정: ‘너무 원시적이다’와 ‘문화적으로 가깝다’를 따로 출력하면 상태 설명처럼 들린다. 실제 대화처럼 두 판단의 관계를 풀어 말하고, 다른 보고서 같은 표현도 구어체로 바꾼다.

## 달라진 말

> 그녀는 교양이라고는 하나도 모르는 야만인 같아요. 하지만 그녀가 살던 세계의 문화는 익숙하네요.

출신 세계의 문명 수준과 민족·문화의 친숙함은 원래 서로 다른 판단이다. 두 변수를 합치거나 둘 중 한 평가를 삭제하지 않는다. 위 예시는 이미 두 조건이 실제로 선택되었을 때의 발화다.

일반 인물 평가 277그룹의 세 말투를 검토했다. 고유 인물 배경 두 그룹은 원래 전용 대사로 보존한다. 기존 교정과 같은 문구를 제외하고 58그룹의 170개 발화를 구어체로 정리했다.

| 기존 표현 | 구어체 예 |
|---|---|
| 문화적으로 제게 가까워요 | 그녀가 살던 곳의 문화는 제게 익숙해요 |
| 지적으로 저와 가까운 여자애를 만난 건 좋은 일이에요 | 저랑 비슷하게 똑똑한 여자애를 만나서 좋아요 |
| 그녀와의 대화는 최소한으로 줄이고 싶어요 | 그녀와는 꼭 필요한 말만 하고 싶어요 |
| 그녀의 존재는 제 삶에 아무 영향도 없어요 | 그녀가 있든 없든 제 삶은 달라질 게 없어요 |

말투는 기존의 격식체·존댓말·반말을 구분한다. 모욕·경멸·질투·무관심의 강도와 원래 가정·질문은 유지한다. 이미 자연스러운 짧은 대사는 그대로 두고, 원문 뜻이 불명확한 부분을 임의의 사건이나 심리로 해석하지 않는다.

## 실제 조합에 따른 연결

다섯 관계 조합을 원래 지능별 문안 3종과 말투 3종에 맞춘 45개 연결 문장으로 작성했다.

- 낮은 문명 수준에 대한 멸시 + 친숙한 이름·억양·문화.
- 낮은 문명 수준에 대한 멸시 + 낯선 이름·억양·문화.
- 낮은 문명 수준에 대한 멸시 + 민족 자체는 중요하지 않다는 판단.
- 같거나 비슷한 세계 + 친숙한 이름·억양·문화.
- 상대가 자신을 야만인 취급한다는 판단 + 친숙한 이름·억양·문화.

지능별 원문에서 이름을 말하는 경우를 억양이나 문화로 멋대로 바꾸지 않는다. 같은 문화라고 정확히 같은 고향 세계 출신이라고 단정하지 않는다. ‘그래서’처럼 원래 없던 인과관계를 만들어 연결하지 않는다.

상태 설명이 줄줄이 줄바꿈되는 대신, 배경·특성 평가의 원래 문장 구분 16곳을 공백으로 이어 한 문단으로 읽히게 했다. 색상, 첫 행동 지문, 인물명과 원래 페이지 구분은 유지한다.

종합 평가 도입부에서 답하는 여성이 스스로 질문하는 것처럼 쓰인 기존 서술 두 곳은 질문 주체를 ‘당신’으로 바로잡았다. 대사 선택이나 판정에는 영향을 주지 않는다.

## 호출과 입출력

패치 ID: 2026-10-18_relation_semantic_speech.

- interaction의 1111~1118 공통 캐시 검사는 $voice_relation_line 안의 VOICE_ARGON_RELATION_FLOW_V8을 확인한다. 예전 세이브에 V6 함수가 들어 있어도 현재 #dynamic 정의를 읽는다. 대사 데이터 revision7은 그대로다.
- origins_relations는 원래의 화자·상대 교환과 계산을 수행한다. 실제 원래 그룹에서 선택된 조각만 $voice_native_actor로 전달한다. 새 대사를 보여 주기 위한 조건·능력치 변경은 없다.
- $voice_relation_line(group,selected_text,page_index)은 기존 지문 분리와 V6 교정을 먼저 수행한 다음, 그룹·말투·정확한 현재 문구가 일치할 때 새 구어체 문장을 사용한다.
- $voice_relation_continue(previous_group,current_group,previous_body,current_body,tone,previous_tone)은 실제 직전 문장과 현재 문장이 모두 45개 검토 조합 중 하나와 정확히 일치할 때만 뒷절을 바꾼다. 일치하지 않으면 현재 문장을 그대로 반환한다. 대사 재추첨과 이력 기록은 하지 않는다.
- $jo9_relation_prev_group[page], $jo9_relation_prev_body[page], jo9_relation_prev_tone[page]에 페이지별 실제 직전 발화를 기록한다. 페이지나 말투가 다르면 연결되지 않는다. 원문 대체 출력이 중간에 나오면 직전 문맥을 비워 잘못 건너뛰어 연결하지 않는다.
- 새 임시 문맥은 origins_relations 진입과 종료 때 삭제한다. 함수 내부의 continued 문자열도 매번 정리한다. 새 영구 인물 키나 세이브 변환은 없다.

수정 로케이션은 #dynamic, origins_relations, interaction 세 곳이다. 기존 원문 대사 은행, 공개 조건, 성격·관계·깊이 검사, 원래 계산과 최근 대사 이력은 보존한다. 인상 묻기 통합·재분류 함수와 직전 대사 은행은 바이트 단위로 그대로다.

## 수동 수정과 되돌리기

교정은 정확한 현재 문구가 일치할 때만 적용한다. 사용자가 원고를 수동 변경해 일치하지 않으면 기존 교정으로 덮어쓰지 않는다. 새 원고나 새 조합을 추가할 때는 해당 연결도 검토해야 한다. 런타임에서 외부 AI가 문장을 생성하는 기능이 아니다.

새 함수만 제거하고 호출부를 남기면 출력이 깨질 수 있다. 캐시 검사만 예전 마커로 되돌리면 재정의가 반복되거나 오래된 코드가 남을 수 있다. 되돌릴 때는 해당 패치 전체를 역적용하거나 작업 직전 백업을 복원한다.

## 검증과 범위

바이트 왕복·역적용·공식 적용기 재생/재적용, 원래 관계 계산과 인물 배경 보존, 모든 교정 문구의 실제 엔진 적용, 45개 조합의 정상/불일치 문맥, 말투·페이지 분리, 재추첨 없음, 같은 원래 이력 ID, 색상과 임시 상태 정리를 검사했다. 설치 엔진의 출고·대화 경로는 격리 복사본으로 검사한다.

원래 글꼴로 실제 대화 조건 108개, 본문 432페이지의 배치를 측정한다. 실제 게임에서 세이브 선택 UI를 조작한 검증과 가능한 모든 대사의 문학적 자연스러움은 별도 범위다. 진단 QSP나 원본 세이브 상태를 저장소·배포에 넣지 않는다.
