## 원고와 적용 범위

반환 원고 9,891행 중 9,120행을 데이터에 수록하고 771행은 제외했다. 대사 문구와 선택 메타데이터는 작성본을 사용하며, 원고의 다섯 토큰은 실제 출력 때 기존 게임 변수로 바인딩한다. 원고의 새 조건을 실행 가능한 게임 조건으로 바꾸지 않는다.

## 함수 입출력과 상태

- 기존 `$voice_profile`, `$voice_depth_level`, `$voice_pick_fragment`, `$voice_impression`을 사용한다. 기존 1112/1113 의미 선택과 최근 두 번 이력 키는 유지한다. 사건 반응은 기존 최고 허용 깊이를 우선한다.
- `$voice_native(group, originalText, optionalSpeaker)`는 이미 원래 코드에서 선택한 그룹과 원래 완성 문자열을 받는다. 선택 가능한 완결 핵심·보충을 한 페이지로 조합해서 문자열을 반환한다. 후보가 없으면 원문을 반환한다. 선택된 화자의 성격·직업·관계·감정 깊이·공포·기분을 읽으며 게임 능력치와 관계 수치를 바꾸지 않는다.
- `$voice_native_actor`는 위 함수의 인스턴스별 내부 실행 코드다. 기본 화자는 `slave`, 인물 평가는 `slave1`이다. 후자의 저장 이력은 `sa_rel=1`이면 `slave`, 2이면 `assistant`에 기록한다. `PH_001/004`는 화자 나이별 기존 명사, `PH_002`는 화자 용기, `PH_003`은 기존 `$little_txt`, `PH_005`는 상대 `$slave2['name']`다. 원고 전체를 코드로 평가하지 않는다.
- `$voice_native_stored(category, storedText)`는 일반 배경 152개 정의 중 실제 저장 문장의 정확한 한 항목 일치를 확인한다. 원래 세계·가족·직업 선택을 수치로 다시 계산하거나 새 인물 설정을 만들지 않는다.
- `$voice_native_moods`는 기존 `$text`의 기분 페이지 문구만 바꾼다. 선택 순서, 무드렛 값, 전체 기분 계산은 바꾸지 않는다. 비교에 쓰는 배열과 문자열은 호출 뒤 지운다. 별도 기분 키 배열을 세이브에 추가하지 않는다.
- 새 일반 그룹은 해당 인물의 기존 문자열 배열에 `jo9_voice_last1_native_<group>`, `jo9_voice_last2_native_<group>` 두 선택 서명을 필요할 때만 기록한다. 대화 한 번에 여러 주제가 나와도 다른 주제의 최근 이력을 덮어쓰지 않는다. 새 장기·중기 기억 DB나 마이그레이션은 없다.
- `$voice_native_history_write`, `$voice_native_pending_clear/commit`은 표시 확정 때의 짧은 이력 기록을 맡는다. 원래 인물 평가가 답변 성공 판정보다 먼저 조립되므로 이력만 임시 보류한다. 1117 성공 또는 원래 1118 출력 경로에서 확정한다. 원래 고유 사연에 가려지는 일반 평가와 사라지는 ‘요구 없음’ 페이지는 이력에 남기지 않는다. 실패한 대화의 실제 거절 문구는 그 거절의 이력을 기록한다.

캐시 revision은5다. 1111–1118에 들어갈 때 이전 세이브의 함수와 대사 데이터만 보충하며 성별 원래 배열을 데이터 전용 갱신으로 덮어쓰지 않는다. 이미 현재 revision의 전 행이 로드된 경우, 반복되는 원래 텍스트 갱신이 동일한 큰 데이터 사전을 다시 만들지 않는다. 실행 중인 게임은 QSP 수정이 즉시 로드되지 않으므로 다시 실행해야 한다.

## 수정 위치와 분리·복구

변경 로케이션은 `#txt_man`, `#dynamic`, `interaction`, `chose_answer`, `interaction_result`, `origins_relations` 여섯 개다. 전체 로케이션 수259는 유지한다. 다른 로케이션, 이미지, 실행 파일, 실제 세이브, INI는 이번에 수정하지 않는다.

- `VOICE_ARGON_DATA`: 원고·색인·감정 메타데이터와 revision5.
- `VOICE_ARGON_NATIVE`, `VOICE_ARGON_STORED`, `ARGON_R2_NATIVE_TOPICS`: 공통 출력 함수 및 이미 선택된 일반 사연·기분 페이지의 연결.
- `VOICE_ARGON_CACHE_V5`: 모든 질문의 구 캐시 보충.
- `VOICE_ARGON_FACT_NATIVE_*`: 원래 과거·인물 평가 텍스트 선택 지점의 감싸기.
- `VOICE_ARGON_DEFER_ORIGINS`, `VOICE_ARGON_CONFIRM_HISTORY`: 인물 평가의 이력 확정 시점.
- 기존 `VOICE_REQUEST_DISTRIBUTION`: 원래 구체 요청과 추가 요구 페이지 연결. 기본 답변 판단은 번역 문장 비교가 아닌 원래 선택 지점의 임시 플래그를 사용한다.

기존 `chose_answer`, `origins_relations`, 기분 사전, 성별 사전, `$voice_profile`, 게임 대화 성공 판정과 페이지 출력기가 의존성이다. 데이터만 빼면 후보가 사라지고, 함수를 빼고 호출부를 남기면 실행 오류가 날 수 있다. 임의 블록 삭제보다 정확한 패치 역적용 또는 직전 QSP 백업으로 복원한다. 적용 후 새 이력 문자열이 남아 있어도 기존 원본은 이를 읽지 않는다.

## 검증 기록과 한계

검증 결과와 최종 QSP 지문은 별도 QA 요약에 기록한다. C 작업 공간에서 원본과 후보를 격리하고 실제 QSP WASM, 실제 설치 FastQSP의 진단 사본을 사용한다. 원본 세이브는 읽기만 하며 실제 불러오기 UI를 자동 조작하지 않는다. 새 게임 초기화 검사와 GUI 캐릭터 선택은 구분한다.

원고의 가능한 모든 조합의 문학적 자연스러움, 모든 캐릭터의 사용자 사연, 화면 픽셀 정렬과 실제 GUI 세이브 선택은 사용자가 플레이하며 확인할 범위다. 이번 원고의 수록 수가 모든 상태의 최소 세 후보를 보장하지는 않는다. 이전 고정 원문이 의도적으로 남는 곳은 식별되지 않는 저장 사연, 고유 인물 사연, 후보가 없는 원래 분기다.
