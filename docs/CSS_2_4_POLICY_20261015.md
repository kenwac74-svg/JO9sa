# JO9 2.4 CSS 기준 — 2026-10-15 사용자 확정

## 역할과 배포 원칙

1. 원본 CSS가 정의하는 종류의 값은 2.4 패치본에서도 CSS가 정의한다. 배치·좌표·크기·글꼴·색·여백·테두리·배경 이미지·이미지 표현·툴팁 외형과 hover 처리가 해당한다.
2. 원본 CSS를 가급적 유지한다. 원본 규칙이 승인된 변경을 방해할 때 해당 선택자/화면에 한정해 최소 변경하고 이유를 기록한다. 기존 2.4 UI의 누적 스타일을 원본으로 통째로 되돌리라는 뜻은 아니다.
3. 원본 CSS에 없던 고정 문구 생성·문구 치환, 게임 상태 판정이나 출력 내용 변경은 QSP에서 관리한다. 작업 중 수시 변경을 시험할 때만 CSS를 임시 저장소로 사용할 수 있다.
4. 사용자가 커밋·푸시를 지시하거나 저장소 규칙에 따라 커밋·푸시할 때, 임시 CSS 변경을 먼저 조사한다. 위 3번에 해당하면 QSP로 이전하고 임시 CSS 규칙을 제거한 뒤 검증한다. 모든 CSS를 QSP로 이전하는 절차가 아니다.
5. 원본 CSS가 담당하던 리소스 경로와 표시 스타일도 CSS에 유지한다. CSS 역할 여부를 보지 않고 이미지 경로·display:none·빈 content를 일괄 이관/삭제하지 않는다.
6. QSP 문구를 표시하는 원본 방식인 content:attr(tooltip-data), 테두리와 배경을 위한 빈 content는 유지한다. 게임 조건에 따라 어느 내용을 출력할지는 QSP가 결정한다.

## 검증과 한계

- 수정 전 검사에서 CSS 고정 문구 5개를 탐지해 실패하는 것을 확인했다. 이전 단계의 헐렁함은 이미 제거된 상태였다.
- 수정 후 두 설치본의 CSS 고정 문구 검사와 QSP 왕복/제목 출력/편집기 대사 분류 검사 통과.
- 서로 다른 두 설치본 QSP를 각자 수정하여 기존 차이를 보존했다. 수정한 7개 본문 조각 외의 필드는 보존했다.
- 격리된 HTML을 Headless Edge에서 실행하여 7개 화면의 기존 가상 제목과 새 HTML 제목의 display, box-sizing, 높이, padding, line-height, font, 색, 배경, border, 자간, text-shadow 및 문구가 동일함을 확인했다.
- 위 검사는 네이티브 QSP 실행 검증이 아니다. 사용자가 게임 재시작 후 집·도시·개인실 이름줄, 메뉴와 툴팁 위치를 확인해야 한다.
- 저장된 옛 화면 HTML에는 새 제목 요소가 없을 수 있다. 기존 세이브를 불러온 뒤 해당 화면을 재진입/재출력해 확인한다.
