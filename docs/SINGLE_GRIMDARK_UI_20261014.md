# 단일 그림다크 UI · CG 스타일 자리 (2026-10-14)

사용자 승인: 그림다크 기반 유지 + 올드처럼 좌측/하단 테두리, 옵션 뒤로 버튼을 우측 열 정렬. 후속 정정: 배경 선택 버튼 자리를 삭제하지 않고 제목을 `< CG 스타일 >`, 세 슬롯은 모두 `개발중`으로 바꾼다. 스타일 변경 기능만 없앤다.

## 적용

실제 game/jack.qsp와 css/base.css에 설치 완료. 집(menu_form=2000)과 도시(city_form=1000)의 옵션에 동일하게 적용한다. 세 400x40px 슬롯은 기존 under_gray 그림을 사용하며 클릭 링크/변수 변경이 없다. 자동 저장/난이도/콘텐츠/음향 설정은 유지한다. 옵션 뒤로 컨테이너는 우측 옵션 열과 같은 x570으로, 다른 화면에서는 x100으로 유지한다. 실제 뒤로 목적지 코드는 보존한다.

ui_style=2를 공통 레이아웃/화면/장면 이동 진입에서 고정해 기존 세이브의 old/classic 선택값도 그림다크로 표시한다. `mods/2026-10-14_single_grimdark_cg_slots.json`으로 9개 본문만 변경, 기존 248 locations 및 행동/설명 필드는 바이트 그대로 유지했다. 현재 사용자 QSP f465bdaff를 기준으로 생성했으며 오래된 전체 QSP를 덮어쓰지 않았다.

CSS는 원래 바이트 뒤에 frame 블록만 추가했다. 기존 grimdark/bg_main.png의 금속 띠를 CSS 장식으로 재사용하여 좌측 16px 외곽과 하단 프레임을 연결한다. 이미지/버튼의 크기나 일반 배치를 변경하지 않고 pointer-events:none으로 클릭을 통과시킨다. 새 래스터 이미지 생성/편집은 없다.

## 검증과 복구

- 테스트 RED 6개 확인 후 GREEN 6/6.
- 248 locations 왕복 바이트 검증, 행동/설명 필드 및 원래 CSS 바이트 보존, 변경 본문 구문 오류 코드 증가 없음.
- 공식 apply_mods.ps1 시험 DryRun과 실제 적용 결과의 해시가 후보본과 일치.
- 격리 브라우저 미리보기에서 오른쪽 열/뒤로 x570, 개발중 슬롯 3개 400x40/링크0, 이미지 20,45,980,755 유지, 장식 클릭 통과 확인. 이 화면은 레이아웃 fixture이며 실제 native 게임 실행 검증은 아니다.
- 실제 게임은 완전히 종료하고 다시 실행한 뒤 집·도시 설정을 확인한다. 게임 native 실행/클릭은 사용자 담당.

백업 및 정확한 해시: `records/ui/2026-10-14-single-grimdark-cg-slots.json`. 백업 ZIP의 game/jack.qsp와 game/css/base.css를 같은 실제 경로에 복원하면 수정 직전 상태로 돌아간다. 공식 QSP 적용기의 .bak 및 CSS .bak_singleui도 생성했다.

재적용: `tools/install-single-grimdark-ui.ps1 -GameDir <실제 game 폴더>`. 다른 작업으로 수정된 QSP에서 기존/신규 본문을 확인할 수 없으면 공식 적용기가 중단한다. CSS는 원래 인코딩을 다시 쓰지 않고 장식 블록만 바이트 추가한다. 재실행은 QSP/프레임의 중복 적용을 건너뛴다.
