# 인물 상태 편집기 테스트판 0.1 — 2026-10-16

이전 설계 시안과 별개로, 실제 QSP의 명기 상태 체계를 읽고 편집하는 로컬 도구를 구현했다. 원본 경로·SHA256·현재 소스 값과 수정 위치를 표시한다. 실제 게임 플레이 실행은 하지 않았다.

## 구현한 기능

| 범위 | 실제 지원 |
|---|---|
| 상태표 | 코드 0~4의 표시명 5개, 툴팁 5개, 기본/개인실 아이콘 경로 10개 |
| 전환 | 최초 발견 확률 1개를 실제 6개 역할 연결에서 편집 |
| 연결 효과 | 기존 보장 하한 6개, 지정 교육 XP 1개, 시장/경매 배수 2개 |
| 코드 확인 | 내부 상태 코드·이력·초기화/일회 지급 버전·실제 전환 호출 위치 |
| 실제 작업 | 프로젝트 저장/불러오기, 후보 비교, 대상별 백업·적용·복원, 패치 JSON 묶음 내보내기 |
| 보호 | 오래된 원본/후보/복원 충돌 거부, 중간 쓰기 실패 복구와 journal, 죽은 프로세스 잠금 회수 |
| 이미지 | 입력 경로의 미리보기와 대상별 파일/헤더/크기 검사, 적용 직전 재검사 |
| 저장된 정의 | 표시명/XP 편집 시 기존 캐시 가드 갱신. QSP 복원 후 명시적인 저장 캐시 갱신 후보 생성/적용 제공 |

표시·수치 편집은 총 30개 항목이다. 캐시 버전과 표시 슬롯 갱신은 후보 비교에 별도 자동 변경으로 표시한다. 같은 숫자라는 이유로 무관한 위치를 수정하지 않는다. 플레이본과 배포본의 기존 차이를 보존한다.

## 사용과 한계

`tools/state-editor/Start-StateEditor.ps1` 또는 설치본 `game/modtools/state-editor/Start-StateEditor.ps1`로 실행한다. 실행 결과 localhost URL을 Codex 우측 브라우저에 연다. [도구 사용법](../tools/state-editor/README.md).

1. 상태표/전환·이력/연결 효과에서 값을 조정한다.
2. 적용할 설치본을 명시적으로 선택하고 변경 미리보기를 확인한다.
3. 검증한 변경 적용을 누른다. 적용 이력에서 QSP 원본을 복원할 수 있다.

게임·세이브는 페이지를 열거나 프로젝트를 저장하는 것만으로 바뀌지 않는다. 이 도구는 QSP 소스 편집기이며 인물의 현재 세이브 수치·발견 이력·이미 지급된 효과를 직접 되돌리지 않는다. 변경한 게임을 저장한 뒤 QSP만 복원했다면, 현재 QSP 기준의 저장 캐시 갱신 후보를 적용하고 게임을 다시 시작해 세이브를 불러온다.

내부 코드 재매핑·저장 키·임의 조건식/분기·역할 추가·새 상태 추가·독립 복제는 이번 테스트판에서 미지원이다. 첫 등록은 명기의 기존 상태 축 한 개이며 모든 특성이나 모든 상태 체계에 자동 적용되는 편집기는 아니다. 거래 배수를 바꾸어도 기존 거래 대사의 숫자는 자동 수정하지 않는다.

여러 파일을 OS 수준에서 한 번에 원자 교체한다고 보장하지 않는다. 후보와 백업을 모두 준비하고 단계별 journal을 기록하며, 일부 실패 시 검증된 백업으로 복구한다. 사용자의 이후 수정이 있으면 덮어쓰지 않고 충돌을 표시한다.

## 검증

- 새 편집기 40개와 기존 text-workshop 회귀를 함께 실행: 108개 중 107 통과, 실패 0, Windows 파일 심볼릭 링크 검사 1개 환경상 제외.
- 실제 work/Full QSP의 모든 30개 필드를 메모리 후보에서 바꾸고 역패치해 전체 원본 바이트 복원 확인. 설치된 QSP는 쓰지 않았다.
- 브라우저: 실제 QSP 사본 값 로드 → 편집 → 후보 무효화 → 프로젝트 저장/재개방 → 서로 다른 두 대상 적용 → 정확한 바이트 복원, 오래된 후보/프로젝트 거부, 입력 범위, 아이콘 미리보기/누락 거부, 저장 캐시 갱신 적용/복원.
- 320/736/1024 폭에서 네 화면의 가로 넘침 없음, 밝은/어두운 화면, pageerror 없음.
- 코드 검토의 아이콘 누락, 중단 잠금, 저장 캐시 복구 문제를 회귀 시험과 함께 수정했다.
- 순정·세이브·게임 CSS·실제 클라이언트 실행은 변경하지 않았다. 게임 플레이 결과는 별도 사용자 확인 사항이다.

[검증 기록](qa/2026-10-16_state-editor-prototype.json). 런타임 후보/백업/프로젝트는 git과 배포 압축에서 제외하고, PC 이전 때 필요한 로컬 기록을 별도로 보관한다.

현재 후속판은 [0.2 사용성 개선·생성 초기값](STATE_EDITOR_USABILITY_20261016.md)이다. 아래는 최초 0.1 구현 당시 기록이다.

## 현재 배치 확인

저장소와 플레이/배포 양쪽 game/modtools/state-editor에 도구 10개 파일을 배치하고 바이트 일치를 확인했다. 현재 세션 주소는 http://127.0.0.1:5284/ 이며 재실행하면 포트가 바뀔 수 있다. 실제 두 QSP의 해시·30개 필드, 아이콘 15개 로드, pageerror 0, 적용 대상 초기 미선택을 확인했다. 실제 QSP는 변경하지 않았다.
