# TEST9 이후 승인 수정 — 빌드 보류

2026-09-28 사용자 답변의 번호는 남은 이슈 제안 목록 기준이다. 기존 접수 문서의 번호와 혼동하지 않는다.

- 1: 소지품 아이콘 오연결 수정 승인. 원작 slave_stat 장비 탭(2)으로 연결했다. 현재 개인실 대상을 기존 교환 로직으로 전달하고, 장비 변경 item_change의 노예 슬롯 20~35를 허용한다. 닫기는 대상 복원 후 같은 개인실로 돌아간다. 보상 등 하위 메뉴에서도 현재 개인실 번호를 사용한다.
- 2: 질문 흐름 사용자 정상 확인.
- 3: 보상 실행 사용자 정상 확인.
- 4: 식단 명칭 수정 및 신규 효과 추가 승인. 소스 표시명을 일반식 / 고열량식 / 특별식단으로 변경했다. 효과 종류·수치·시점·비용·부작용은 사용자에게 질문한 상태이며 아직 구현하지 않았다. 기존 ration=2 로직은 남아 있으므로 이 상태를 완성된 특별식단으로 배포하면 안 된다. 기존 로직에는 체형 조절, 기호 변화, spawn_semen 소비가 있다.
- 5: 개인실 2~4 사용자 정상 확인.

검증: 수정 소스를 메모리에서 생성하여 기존 검사와 소지품 연결 검사 총 13개 통과. 원작 장비 탭 본문 및 item_change 본문 유지 확인. 실제 FastQSP 게임에서 장비 변경/복귀는 미검증.

새 QSP, 설치 패키지, ZIP을 생성하지 않았으며 G: 게임 파일에 설치하지 않았다. 다른 접수 이슈의 수정 완료를 뜻하지 않는다.
