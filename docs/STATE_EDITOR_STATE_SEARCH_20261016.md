# 상태 편집기 0.2.2 — 초기 상태 검색·직접 입력

사용자 지시로 생성 초기 상태의 드롭다운을 제거했다. 유형 코드와 초기 상태 모두 텍스트 입력이며 초기 상태는 현재 QSP 정의의 상태명·툴팁·코드로 찾는다. 고정된 0~3 목록 때문에 빠졌던 명기(4)를 지원한다.

- 초기 상태에 명기 또는 4를 입력하거나 부분 검색 결과의 이 값 사용을 누르면 실제 숫자 4로 확정된다.
- 검색은 #variative의 literal $virginity 정수 코드 정의 전체에서 읽는다. 이후 정의된 5 이상도 다시 불러오면 검색된다. 검색 결과는 입력 허용 목록이 아니며 정의 없는 정수 코드도 직접 입력할 수 있다. 이 동작이 새 상태의 게임 표시·효과를 정의하지는 않는다.
- 빈칸·미확정 검색어를 숫자 0으로 바꾸지 않는다. 확정 전 저장/미리보기를 막는다. 엔진 정수 범위 밖 값도 오류로 표시한다. 규칙 해제 또는 -1로 기존 생성 규칙을 유지한다.
- 기존 숫자 프로젝트와 유형 코드 초안, 후보 무효화·백업·대상별 독립 적용·원본 복원을 유지한다.

명기(4)는 기존 jo9_meiki_state가 현재 상태 4를 인식해 known/checked를 설정하고 일회 보장을 처리하도록 이미 구현돼 있었다. 이전 편집기의 초기값 4 미지원 설명을 철회했다. 생성 규칙은 stock의 virginity 값만 지정하고, 소유 역할의 기존 갱신 경로가 나머지를 처리하게 한다. 새 이력 대입·초기화 버전·helper 호출·발견 확률 조건은 추가하지 않았다. 기존 helper의 역할·연령 지원 범위도 변경하지 않는다.
