# Kindroid로 컷신 텍스트 만들기 — 설정과 작업 방법

목적은 Jack-o-nine-tails 컷신마다 들어갈 대사·지문을 Kindroid로 초안 작성하고, Text Workshop `[수정]`으로 게임에 넣는 것이다.

## 0. 먼저 알아둘 것

- Kindroid의 설정 항목은 Backstory, Key Memories, Response Directive, Example Message, Journal이다 ([참고](https://aiindigo.com/tutorials/getting-started-with-kindroid-crafting-deeply-personal-ai-companions)). 앱 버전에 따라 이름과 **글자 수 제한**이 다를 수 있다. 아래 붙여넣기 문구가 입력창에 안 들어가면 "짧은 버전"으로 줄여 쓴다. 제한 숫자는 확인하지 못했다.
- Kindroid는 대화 상대용 앱이라 긴 설정을 지키다가 문체가 흐트러질 수 있다. 그래서 **컷신 1개 = 새 대화 1개**로 쓰고, 고정 규칙은 Key Memories에 둔다.
- 아래의 세계관·인물 정보 중 `[채우기]`는 사용자가 직접 넣어야 한다. 게임 정설을 제가 추정해서 적지 않았다.
- 변수는 쓰지 않는다. Text Workshop v0.1은 `<<변수>>`를 넣을 수 없으므로(검증에서 거부) 주인공은 "당신"으로 쓴다.

## 1. 게임 대사 형식 (실제 `jack.qsp` 29,818개 문장 분석)

| 항목 | 실제 분포 | 의미 |
|---|---|---|
| 대사 | 약 6,000개가 `[이름]<br> 대사` 형태 | 화자 표시 뒤에 `<br>` |
| 지문 | 약 2,500개가 `<br> 문장`으로 시작 | 앞에 `<br>` 한 칸 |
| 2인칭 | 5,668개에 "당신" | 주인공은 "당신" |
| 길이 | 중앙값 53자, 90%가 183자 이하 | 한 문장 덩어리는 짧게 |
| 태그 | `<br>`, `<b>`, `<font color>` 사용 | 줄바꿈은 반드시 `<br>` |

규칙은 이렇게 정리한다.
- 줄바꿈은 실제 엔터가 아니라 `<br>`로 쓴다. 엔터는 Text Workshop이 거부한다.
- 한 덩어리는 대사 1개 또는 지문 1단락으로 끊는다. 컷신 하나에 여러 덩어리가 나온다.
- 따옴표(`'` `"`)는 그냥 써도 된다. 저장할 때 자동 escape된다.
- 그대로 쓰면 안 되는 것은 `<<`, `>>`, 실제 줄바꿈, 코드(`gs`, `if` 등)다.

## 2. Kindroid 설정 (그대로 붙여넣기)

Kin 이름은 `JO9 컷신 작가`처럼 짓는다. 연애·롤플레이 상대로 쓰지 않는다.

### Backstory

```
너는 한국어 인터랙티브 픽션 게임 "Jack-o-nine-tails"의 컷신 텍스트를 쓰는 작가다.
너는 등장인물이 아니다. 대화 상대가 아니라 집필 도구로 행동한다.
사용자가 장면 카드를 주면 그 장면의 게임 텍스트 초안만 쓴다.
세계관: [채우기: 시대, 도시, 노예 제도 등 사용자가 정한 설정 3~5줄]
문체: 담담하고 구체적인 한국어. 과장된 수식어를 줄이고 감각 묘사는 한두 개만 쓴다.
시점: 주인공은 항상 2인칭 "당신". 지문은 현재 사건을 과거형 평서문("~했다")으로 쓴다.
모든 등장인물은 성인이다. 미성년으로 읽힐 수 있는 묘사는 쓰지 않는다.
```

### Key Memories (형식 규칙, 가장 중요)

```
[출력 형식 규칙]
1. 지문은 <br> 로 시작한다. 예: <br> 당신은 사무실 문을 밀고 들어섰다.
2. 대사는 [이름]<br> 대사 형식이다. 예: [글로리아]<br> 어서 오세요. 무엇을 도와드릴까요?
3. 줄바꿈은 실제 엔터 대신 <br> 만 쓴다. 한 덩어리 안에서 엔터를 치지 않는다.
4. 덩어리(대사 1개 또는 지문 1단락)는 한 줄에 하나씩, 번호 없이 출력한다.
5. 한 덩어리는 가능하면 180자 이하로 쓴다.
6. 변수 표기 << >> 는 절대 쓰지 않는다. 주인공 이름은 쓰지 않고 "당신"으로 부른다.
7. 코드, 설명, 사과, 제안, 마크다운(**, #, -)을 출력하지 않는다. 텍스트 덩어리만 출력한다.
8. 허용 태그는 <br> <b> 뿐이다.
[인물]
[채우기: 이름 / 나이(성인) / 역할 / 말투 한 줄씩. 자주 나오는 인물만]
[세계관 고정 사실]
[채우기: 화폐 이름(예: 스파크), 장소 이름, 금칙 설정 등 지켜야 할 것]
```

### Response Directive

짧게 둔다(제한이 짧을 수 있다).

```
항상 장면 카드의 형식 규칙대로 텍스트 덩어리만 출력한다. 설명·인사·마크다운 금지. 주인공은 "당신".
```

### Example Message

Kindroid는 예시 문체를 강하게 따라간다. 실제 게임 문체에 맞는 짧은 예를 2~3개 넣는다. 아래는 실제 게임 문장의 형식을 따른 예시다.

```
<br> 당신이 가게로 들어서자, 주인은 특유의 미소로 당신을 반겼다.
[주인]<br> 어서 오시오. 오늘은 괜찮은 물건이 몇 개 들어왔소.
<br> 시설 내부는 넓고, 가구는 편안하고 값비싼 것들로만 장식되어 있다.
```

### Journal (선택)

인물이나 장소 설정이 길어질 때 항목별로 나눠 넣는다. 예를 들어 `글로리아 — 부동산 관리인, 정중한 존댓말, 사무적` 한 줄씩이다. 장면별 임시 정보(오늘 쓸 컷신)는 Journal이 아니라 대화창에 장면 카드로 준다.

## 3. 컷신 하나를 쓰는 순서

1. **새 대화를 연다.** 이전 컷신의 문체와 사건이 섞이는 것을 막는다.
2. **장면 카드를 붙여넣는다.**

```
[장면 카드]
컷신 이름: [예: 부동산 사무실 첫 방문]
장소: [Location 이름이나 장소 설명]
화면 이미지: [그림에 보이는 것 한두 줄]
등장인물: [이름 — 이번 장면에서의 태도]
분위기: [예: 사무적, 약간의 긴장]
앞 장면 마지막 문장: [있으면]
뒤 장면 첫 문장: [있으면]
분량: 지문 3덩어리, 대사 4덩어리
꼭 넣을 정보: [예: 계약금 10스파크 언급]
```

3. **출력을 점검한다.** 아래 점검표를 통과시킨다.
4. **고칠 때는 대화로 요청한다.** 예: "두 번째 대사를 더 짧고 사무적으로. 형식 그대로."
5. **Text Workshop에 넣는다.** `[현재 화면]` 또는 `[텍스트 검색]`에서 바꿀 원문을 찾아 `[수정]`을 누르고, 수정문 칸에 **덩어리 하나씩** 붙여넣는다. 덩어리마다 `[적용 전 확인]`을 거친다.

## 4. 점검표 (붙여넣기 전)

- [ ] 지문은 `<br> `로 시작하고, 대사는 `[이름]<br> `로 시작한다.
- [ ] 실제 줄바꿈(엔터)이 덩어리 안에 없다.
- [ ] `<<` `>>`가 없다. 주인공을 "당신"으로 불렀다.
- [ ] `<br>` `<b>` 외 태그나 마크다운(`**`, `#`)이 없다.
- [ ] 모든 인물이 성인이고, 정한 세계관 사실(화폐 이름 등)과 맞는다.
- [ ] 교체하려는 원문 덩어리의 역할(대사/지문)과 같은 종류다.

## 5. 알아둘 한계

- Text Workshop v0.1은 **원문 한 덩어리를 수정문 한 덩어리로 바꾼다.** 새 컷신 장면을 통째로 추가하거나 덩어리 개수를 늘리는 기능은 없다. 새 컷신이 필요하면 소스에 새 문장이 들어갈 자리가 있어야 하며, 그것은 Phase 2 이후의 일이다.
- 원문이 변수 포함 문장이면 수정할 수 없다. 이때는 변수 없는 부분만 다르게 쓰는 방식이 안 되므로 다른 방법을 정해야 한다.
- AI는 길이와 형식 규칙을 가끔 어긴다. 항상 점검표로 확인한다.
- Kindroid에 입력한 설정과 텍스트는 외부 서비스에 전송된다. 게임 소스 전체를 붙여넣지 말고 장면 카드 수준의 정보만 준다.
