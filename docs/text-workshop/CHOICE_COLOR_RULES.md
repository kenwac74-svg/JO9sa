# 선택지 표시 공통 규칙

사용자 확정: 2026-10-08. 이후 선택지 추가·수정 시 이 규칙을 적용한다.

기존 게임의 대사창 안에서 문장을 클릭하는 형식을 사용한다. 별도 선택박스는 만들지 않는다.

| 색상 | 용도 |
|---|---|
| 초록 `#228B22` | 수락·동의·진행 |
| 붉은색 `#B22222` | 거절·취소·중단 |
| 진한 보라 `#7B1FA2` | 질문·다른 제안·중립 선택 |
| 파랑 `#0000FF` | 일반 링크 전용. 선택지에는 사용하지 않는다. |

색은 선택지의 번호나 나열 순서가 아니라 행동의 성격으로 정한다. 같은 성격의 선택지가 여러 개라면 같은 색을 사용할 수 있다. 색만으로 클릭 명령이나 변수 변화가 결정되지 않는다. 실제 효과와 이동 대상은 별도로 연결한다.

현재 게임의 잡파 판매 장면은 초록색과 붉은색을 문장별로 직접 지정하며, 모든 선택지에 적용되는 자동 색상 규칙은 없었다. 위 표는 이번에 확정한 제작 기준이다. 이 결정 기록에서 기존 게임 선택지를 일괄 수정하지는 않았다.
