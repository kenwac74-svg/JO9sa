[개인 작업 이전 패치](PERSONAL_TRANSFER_20261009.md)에 ZIP 위치·해시·적용 방법·포함 범위가 있다. EXE 교체 없이 현재 QSP, 검증된 개인 작업 이미지, 도구와 설정을 옮기는 별도 ZIP이다. 제작 소스는 `tools/build-transfer-zip.py`, 적용기는 `tools/transfer-zip/Apply.ps1`이다. PowerShell 입력의 BOM 유무와 관계없이 출력에는 BOM을 한 번만 기록한다.
