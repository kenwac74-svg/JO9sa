# 치트 설정·주인 편집기 배치 수정

사용자 요청: 첨부한 치트 설정 화면과 주인 편집기의 글자·UI 정렬을 맞춘다.

## 적용 범위

- 최신 플레이 파일 `G:/somi/Jack O Nine Tails v2.4_work/game/jack.qsp`의 `menu_form` 로케이션만 수정.
- 플레이 `game/css/base.css` 및 저장소의 CSS 원천 `assets/css-2.4/base.css` 갱신.
- 배포 폴더와 보호 원본 JO9O는 변경하지 않는다.
- 변경 기록: `mods/2026-10-17_zzz_cheat_master_layout.json`.

## 화면에 생기는 차이

- 치트 설정(2100): 글자를 행 중앙에 맞추고, 버튼 높이를 40px로 통일한다. 구역 사이 간격도 일정하게 한다.
- 주인 편집기(2110): 항목명은 왼쪽에, 감소·증가·S 버튼은 오른쪽의 고정 위치에 배치한다.
- 두 화면의 클릭 영역을 버튼 테두리에 맞춘다. 하단 뒤로 버튼도 같은 높이를 사용한다.
- 치트 설정에서 같은 동작의 뒤로 버튼이 두 번 생성되던 것을 한 번만 생성하도록 한다.

## 코드 설명과 식별표

| 표식 | 위치 | 하는 일 |
|---|---|---|
| `CHEAT_SINGLE_BACK` | `menu_form`, 2100 분기 | 중복 뒤로 출력 하나를 제거한 자리. 같은 화면 끝의 기존 뒤로 출력을 유지한다. |
| `CHEAT_MASTER_LAYOUT` | `menu_form` 끝, `gt 'main_screen'` 직전 | 완성된 화면 문자열을 배치 클래스가 붙은 div로 감싼다. |
| `CHEAT_MENU_LAYOUT` | `base.css` 끝 | 치트 설정의 행 높이·글자 정렬·구역 간격을 지정한다. |

입력은 기존 `menu_form` 값과 `$setting_display`, `$setting_display_r`, `$setting_display_c`, `$setting_display_c2` 네 표시 문자열이다. 반환값은 없으며 해당 문자열에 표시용 div만 덧붙인다. 새 함수·로케이션·저장 변수·세이브 변환은 없다.

주인 편집기는 앞서 만든 `.jo9-slave-editor`의 공통 행 배치를 재사용하고 `.jo9-master-editor` 클래스로 대상을 식별한다. 기존 2101~2106 화면의 CSS 실행 규칙은 바꾸지 않는다. 기능·치트 상태·능력치·증감 수치·숫자 입력 명령·등급 정의는 그대로다.

## 분리하거나 되돌릴 때

`CHEAT_MASTER_LAYOUT` 전체를 제거하면 이 두 화면에 배치 클래스가 붙지 않아 이전 배치로 돌아간다. 기존 기능 실행문이나 조건 분기는 이 블록에 들어 있지 않다. 이 블록의 일부 문자열 연결만 잘라내면 HTML 태그가 맞지 않을 수 있으므로, 되돌릴 때는 전체 표식 구간을 단위로 취급한다.

CSS의 `CHEAT_MENU_LAYOUT`만 제거하면 치트 설정의 새 정렬이 풀린다. 기존 공통 편집기 CSS까지 함께 제거하면 기존 노예 편집기와 주인 편집기의 정렬에도 영향을 준다. `CHEAT_SINGLE_BACK`은 실행 기능을 막는 조건이 아니며, 삭제된 중복 출력을 복원하면 뒤로 버튼이 다시 두 개 생성된다.

## 확인한 내용

- 원본 읽기·쓰기 왕복 검증 및 표준 `apply_mods.ps1` 재생 결과가 후보 파일과 바이트 단위로 일치.
- 255개 로케이션 중 `menu_form`만 변경. 중복 뒤로 링크 한 개를 제외한 627개 링크와 순서·명령 보존.
- 패치를 역적용하면 수정 직전 파일과 바이트 단위로 일치. 기존 수동 편집과 직전 등급 표시 수정 보존.
- 첨부 HTML에서 화면 내용만 추출한 독립 미리보기로 두 화면의 40px 행, 24개 편집 버튼, 13개 전체 클릭 영역의 배치·클릭 대상 확인.
- QSP 5.7 엔진에서 후보 로딩과 추가 표시 문자열 블록 실행 성공, 오류 0. 2100·2110에만 클래스가 붙고 2101은 변경되지 않음.

게임 클라이언트는 실행하지 않았다. 첨부 HTML 미리보기는 실제 게임 실행 화면이 아니며, 첨부 당시의 문구·상태값을 보여준다. 기존에 정리한 최신 등급 표시 정의는 후보 QSP에 보존되어 있다.

적용 시점의 해시와 백업 경로는 같은 작업 폴더의 `installed.json`에 기록한다.
