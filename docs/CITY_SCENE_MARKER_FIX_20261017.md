# 도시 방문이 하사 장면으로 덮이는 회귀 복구

2026-10-17 사용자 보고. 반복 억제 시범은 아직 플레이 QSP에 적용하지 않은 상태였다. 현재 플레이의 기존 특성/전투 패치에 누락된 줄 경계를 확인했다.

## 원인과 최소 변경

`interaction_city`에서 `! JO9 MOD END TBV_GIFT_ANAMELEH` 바로 뒤의 `IF interaction_city = 9140:` 앞에 CRLF가 없었다. 엔진은 조건문까지 주석으로 읽고, 아래 하사 방문 처리를 다른 NPC 대화에서도 실행했다. 그 결과 NPC·장소·대화가 하사 쪽으로 덮였다.

동일 유형 전수 조사에서 다음 네 경계를 찾았다.

| 로케이션 | 표식 | 복구한 경계 |
|---|---|---|
| `interaction_city` | `TBV_GIFT_ANAMELEH` | 하사 방문 IF를 다음 줄로 분리 |
| `interaction_city` | `TBV_GIFT_BIKER` | 이어 붙은 다음 설명 주석을 분리 |
| `начать_бой` | `FOG_KEEP_ENEMY_HP` | 전투 메뉴 초기화 GS를 다음 줄로 분리 |
| `jo9_meiki_sale` | `TBV_HAGGLE_NATIVE57` | 이어 붙은 바깥 END 표식을 분리 |

선언형 복구: `mods/2026-10-17_zzzzzzzzzzz_restore_marker_boundaries.json`. CRLF 네 개, UTF-16 기준 총16바이트만 추가했다. 줄바꿈을 제외한 문자·수치·문구는 바꾸지 않았다. 새 로케이션·함수·저장 키·캐시 버전은 없다. 실제 실행 명령 두 개를 원래 위치에서 다시 읽을 수 있게 복원했고, 나머지 두 곳은 주석 경계만 복원했다.

누락된 줄바꿈 자체가 없는 경우여서 기존 단독 CR/LF 검사는 통과했다. 이번 검사 누락을 별도의 오류로 기록한다.

## 재현과 검증

- 기존16efdf5b…: 무기점111·보석상11441·미용실11631·부동산1311의 NPC 대화가 모두 하사로 덮이는 것을 실제 설치 FastQSP에서 재현했다. 진짜 하사9140 방문은 정상 대조군이다.
- 수정9a73b88b…: 위5개 진입에서 NPC와 장소가 일치했다. 원래 도시 화면을 끝까지 생성하는 무기점/미용실2개 경로도 통과했다.
- 전투 시작: 불량본에서는 메뉴 초기화 호출이 건너뛰어졌고, 수정본에서는 호출 완료를 확인했다. 이 검사는 전투 전체 승패·밸런스 시험은 아니다.
- 표준 패치 재생·재적용·정확 역복원, QSP 바이트 왕복과 전체 줄 경계, 기존 편집기 등 회귀79개를 확인했다.
- 세부 결과: `docs/qa/2026-10-17_city-scene-marker-fix.json`. 초기 시험 중 상점 메뉴로 바로 이동하는 번호를 NPC 대화 종료 지점으로 잘못 기대한 시험은 제외했다. 최종 재현은 실제 NPC 대화 번호를 사용한다.

## 검사기 보강

`tools/qa/check-qsp-marker-boundaries.cjs`를 출고 검사에 연결했다. 알려진 JO9 START 식별명과 END 줄의 나머지를 비교해, END 주석 뒤에 명령이나 다른 표식이 붙은 파일을 거부한다. 기본 행동 코드도 포함한다. 식별명 뒤의 명시적 `|` 메타데이터는 허용한다.

`tools/apply_mods.ps1`에도 같은 검사를 추가했다. 최종 코드가 잘못됐으면 QSP와 백업을 쓰기 전에 중단한다. 자동으로 원문을 수정하지 않는다. 일반 주석 전체나 모든 QSP 문법을 완전히 해석하는 검사기는 아니다.

기본 실제 엔진 검사를6개에서9개로 늘렸다. 기존 홈·새 게임 초기화·노예/조수 편집기·캐시·하루 진행에 무기점 대화·미용실 대화·전투 메뉴 호출을 추가했다. 도구와 보고서는 내부에서만 실행·보관한다.

## 적용과 남은 확인

최신 플레이 QSP에만 백업 후 표준 적용했다. 배포본과 기존 세이브는 수정하지 않았다. 실행 중인 클라이언트는 이전 QSP를 메모리에 유지하므로 완전히 종료하고 플레이 실행기로 다시 시작해야 한다. 실제 GUI의 세이브 불러오기 및 픽셀 단위 화면 검수는 자동 시험에 포함되지 않는다.

진행 중이던1112 반복 억제 시범은 미적용 상태로 보류했다. 해당 내부 산출물은 남겨 두었고, 활성 저장소의 시범 사본 삭제는 자동 승인 검토에서 범위 밖 삭제로 거절되어 그대로 보존했다. 이번 복구에는 선별된 줄 경계 패치만 적용했다. 이후 시범 적용 때는 이 수정본을 기준으로 다시 생성·검증해야 한다.
