# 커뮤니티 배포 2.4.0 — 사용자 확정 기준

확정일: 2026-10-11. 담당: 이 프로젝트의 Codex(아스트라). 패치 제작을 주요 업무로 등록한다. 이 문서는 기존 PROJECT.md의 PM 전용 빌드 및 사용자가 통압축을 제작한다는 제한보다 우선한다.

## 두 배포물

| 배포물 | 내용 | 대상과 설치 |
|---|---|---|
| 풀팩 2.4.0 | 플레이 가능한 게임 본체·클라이언트 + 올걸팩 + 인디패치 + 기타 외부 리소스 + SAnk 작업 | 처음 플레이하는 유저. 다운로드한 압축을 풀고 바로 실행. 모딩툴, 개발 PC, JO9O 경로에 의존하지 않는다. |
| 간소화 패치 2.4.0 | SAnk가 작업한 이미지·대사·QSP·UI·기능 변경 중 필요한 파일만 | 기존 게임 유저. 올걸팩·인디패치 등 외부 패치는 사용자가 별도 설치. 원본 게임이나 외부 패치 자체를 동봉하지 않는다. |

두 종류 모두 Codex가 빌드·패키징·파일 검증을 담당한다. 게임 플레이 검증은 사용자에게 필요한 확인 항목을 부탁한다. 실제 커뮤니티 게시·업로드는 별도 지시에 따른다. 이번 요청은 배포 기준과 체크리스트 개선이며, 아직 배포 ZIP을 만들거나 공개하지 않는다.

## 이미지 전환과 충돌 처리

- 원래 경로와 파일 이름을 유지한다. 윈도우의 ‘둘 다 유지’로 생긴 `이름 (2).확장자`는 두 번째 전환 리소스로 취급한다. 이후 번호도 보존한다.
- 같은 파일 이름을 덮어쓰거나 기존 전환 번호를 임의로 재배열하지 않는다. 원본 B컷 예약과 이미 존재하는 번호의 충돌도 검사한다.
- 외부 패치와 간소화 패치를 조합해도 기존 이미지와 교체 이미지 모두 전환 가능해야 한다.
- **출시 전 확인 필요:** 현재 도구는 `(N)` 파일을 인식하지만 QSP 전환 목록에는 갱신 단계가 있다. 모딩툴 없이 윈도우에서 복사한 `(2)` 파일이 게임에서 자동으로 발견·등록되는지는 아직 배포 검증 완료가 아니다. 새 복사, 재실행, 저장·로드, 포트레이트·회색 변형까지 실제 확인하고 필요하면 구현을 보완한다.

## 체크리스트의 확정 대기 목록

- ‘미체크 전체 보기’는 상태 체크가 하나도 없는 파일만 각각 표시한다. 빈 상태 배열도 미체크로 본다.
- 큰 이미지뿐 아니라 포트레이트·UI·짝 이미지·미적용 시안을 포함한다. 체크한 부모의 미체크 자식도 빠뜨리지 않는다.
- 기존 완료·보관·수정 등 상태가 하나라도 있으면 이 목록에서 제외한다. 이 보기의 일괄 적용은 목록에 표시된 파일에만 적용한다.
- 보기를 여는 것만으로 상태를 변경하지 않는다. 기존 상태 체계를 유지하며 새 필수 체크박스를 만들지 않는다. 사용자가 파일을 검토하고 기존 체크로 결정한다.
- 미체크는 미사용·삭제 가능이라는 뜻이 아니다. 사용 여부, 외부 리소스 여부, 개인 작업 여부는 별도 참조 및 소유 이력으로 판정한다.
- 확정 전 파일을 AI가 자동 완료 처리하거나 배포 승인으로 간주하지 않는다. 남은 항목과 제외 사유는 빌드 기록에 남긴다.

## 빌드 담당자의 검증 기준

1. 동일한 확정 소스에서 두 버전을 만들고, 버전·파일 목록·해시·포함 출처·크레딧·적용 순서·제외 사유를 기록한다.
2. 풀팩에는 실행에 필요한 리소스와 원본 전환 파일을 실제 파일로 포함한다. 개발 PC를 가리키는 링크·절대 경로를 제거한다.
3. 간소화 패치는 개인 작업 기록과 원본 대조로 포함 대상을 정한다. 체크리스트 체크만으로 소유권을 추정하지 않는다. 외부 패치 리소스가 섞이지 않게 검사한다.
4. 백업·세이브·임시 산출물·모딩툴·개인 설정·API 키를 배포에서 제외한다. 미사용 이미지는 동적 참조와 장면 전환까지 확인한 것만 제외한다.
5. 압축을 빈 폴더에 풀어 누락 파일·링크·QSP 구조·전환 리소스를 확인하고, 사용자가 게임을 플레이해 검증한다. 크레딧과 외부 리소스의 배포 조건도 포함 대상을 기준으로 확인한다.
6. 용량은 실제 확정 파일과 압축 결과로 산출한다. 앞선 용량 분석은 예상치이며 완성된 배포판의 검증 결과가 아니다.
