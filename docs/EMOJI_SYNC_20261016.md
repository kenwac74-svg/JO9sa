# 10번 이모지 동기화 불일치 후속

2026-10-16 사용자는 일괄 확인 10번에 대해 현재 이모지팩과 동기화되지 않으며 게임 장비/보관함과 편집기 두 화면 모두에서 보인다고 보고했다. **현재 상태는 편집기 수정·실제 브라우저 확인 완료, 게임 장비 화면 사용자 확인 대기다.** 전체 화면 문제가 해결됐다고 기록하지 않는다.

현재 게임의 새 PNG 355개는 이 프로젝트의 `emoji-review/redesigned`와도 전부 일치했다. 저장소/설치 편집기의 예전 파일은 `emoji-review/originals` 쪽이다. 과거 리뷰팩의 채택 대기 기록만 보고 현재 설치된 새 팩을 되돌리지 않았다. 새 팩 자체를 새로 그리거나 생성하지 않았다.

이번 동기화 방향은 **현재 설치된 게임 팩 → 저장소 및 두 설치 편집기**다. 기존 게임 이미지를 예전 편집기 파일로 덮어쓰지 않았다. 교체 전 편집기 세 곳을 외부 백업했고 파일명·PNG 해상도 보존을 확인했다. 외부 백업 및 파일별 결과는 [적용 기록](evidence/emoji-sync-20261016/installed.json)에 있다. 재검사 도구는 `tools/qa/sync-dialogue-emoji.cjs`, 읽기 전용 기본 실행에서 불일치가 있으면 비정상 종료하며 실제 복사는 `--apply`를 명시해야 한다.

## 화면 경로와 검증 한계

- 실제 서버는 플레이 설치본 편집기의 3813 포트이며 게임 대상도 새 플레이 `jack.qsp`다. 8425는 별도 현재 화면 이미지 교체기다.
- 편집기의 이모지 선택창은 `assets/dialogue-emoji`를 직접 쓰지 않고 `/api/pic`으로 게임의 `ui/dialogue_emoji`를 읽는다. 삽입 태그도 같은 게임 경로다. 따라서 저장소 자산 드리프트만으로 두 화면의 불일치 원인이 모두 증명된 것은 아니다.
- 실제 `/api/pic` HTTP 응답 **355개 전부**가 현재 게임 PNG와 일치했고 응답은 `Cache-Control: no-store`다. HTTP 검증 기록은 [전송 검증](evidence/emoji-sync-20261016/http.json).
- 장비/보관함 3개 location의 이모지 img 참조는 같은 게임 폴더를 가리켰고 별도의 유니코드 이모지 리터럴은 없었다.
- 실행 중인 `jack.exe` 경로는 새 플레이 폴더의 `game/engine/jack.exe`였다. 다른 옛 게임 폴더 실행으로 확정할 증거는 없다.
- 두 게임의 QSP·CSS와 게임 PNG는 변경하지 않았고 전후 해시를 확인했다. 사용자 세이브도 편집하지 않았다.

현재 파일 기준은 비교 미리보기의 윗줄(차분한 채색), 이전 편집기 자산은 아랫줄(기존 3D)이다. 사용자가 다른 팩을 뜻했는지 확인 중이다. 게임 재실행과 편집기 새로고침은 기존 화면의 이미지를 갱신하는 확인 방법이며, 캐시가 근본 원인이라고 확정한 것은 아니다.

이 기록은 2026-10-15 개인 장비 복원 문서의 “현재 이모지팩 연결 완료” 주장이 영구적인 전체 화면 동기화를 입증하지 않는다는 후속 정정이다. 10번은 아직 사용자 화면 통과로 닫지 않는다.


## 실제 선택창 후속 수정 — 2026-10-16

파일 동기화와 HTTP 검증 뒤에도 사용자가 열어 둔 3813 선택창에는 이전의 노란 3D 얼굴이 남아 있었다. 디스크의 같은 smile.png는 새 채색 얼굴이었다. 선택창을 처음 만들 때 생성한 img 요소를 숨겼다가 다시 보여 주는 구조라, 파일을 바꿔도 이미 표시한 이미지가 갱신되지 않았다. 앞 절의 파일/HTTP 확인만으로는 이 문제를 검출하지 못했다.

선택창을 열 때 현재 분류·페이지를 다시 그리며 이미지 URL에 요청 버전을 넣었다. 분류 탭 그림도 함께 갱신한다. 기존 292종 목록·분류, 삽입 태그의 게임 상대 경로·19px 크기, 수정문은 보존했다. PNG 파일 355개와 선택 항목 292종의 차이는 기존 별칭 구성이며 이번에 목록을 늘리지 않았다.

저장소·플레이·배포 설치본의 editing-tools.js 세 곳에 반영했다. 각 파일의 원래 줄바꿈을 보존했다. 이번 후속 작업에서는 게임 QSP·CSS·게임 PNG·세이브를 변경하지 않았다.

- 회귀 테스트 6개 통과. 새 요청 URL 테스트는 수정 전 실패하고 수정 후 통과했다.
- 실제 내부 브라우저 3813을 새로고침해 새 채색 얼굴 팩 표시를 확인했다.
- 생활·거래 2페이지에서 닫았다 열어 분류·페이지·수정문 유지, 요청 버전 변경을 확인했다.
- 별도 코드 검토에서 차단 결함 없음. 292개 삽입 태그·분류 불변 및 두 게임 QSP/CSS 해시 불변을 확인했다.
- [화면 증거](evidence/emoji-sync-20261016/picker-fixed.jpg), [적용·백업 기록](evidence/emoji-sync-20261016/picker-refresh-installed.json), [브라우저 검증](evidence/emoji-sync-20261016/picker-browser.json).

이 절이 앞 절의 편집기 화면 확인 대기 상태를 갱신한다. 게임 장비/보관함의 실제 화면은 이번 브라우저 검사 대상이 아니므로 10번 전체를 완료 처리하지 않는다.
