# 1112 인상 묻기 — 의미 단위 조합 적용

2026-10-17. 플레이폴더에 먼저 적용하는 패치다. 대사 문구를 새로 쓰지 않고 현재 플레이 QSP의 기존 문구를 재료로 등록했다. 배포폴더와 원본 spete.sav는 변경하지 않는다.

## 게임에서 달라지는 것

인상 묻기에서 기존 정보의 표시 조건을 유지하고, 도입과 오늘/요즘 반응을 각각 선택한다. 한 답변의 모든 조각을 동일한 변형 번호에 묶지 않는다. 원래 instinct[5]의 비유와 custom[5]의 생활 이야기는 각각 끝까지 한 발언으로 표시한다. 글자 수나 구두점으로 문장을 절단하지 않는다.

관계·유형·표현 깊이에 맞는 후보만 고른다. 적대적인 인물에게 칭찬했다고 곧바로 감사와 헌신을 표현하게 하지 않는다. 깨진 정신상태(broken)에서는 추가 도입을 생략한다. 최근 두 번의 선택을 피하되 후보가 적을 때는 반복 제한만 완화한다. 부적합한 문장을 다양성을 위해 사용하지 않는다.

기존 원문 정보의 변형이 없는 칸은 원문 전체를 그대로 사용한다. 따라서 유형별 본문 재작성과 모든 조건의 풍부한 표현까지 완성했다는 뜻은 아니다. 대사셋 추가 없이 연결 구조부터 바로잡는 범위다. 원문 본문에 대한 자동 존댓말/어미 치환은 하지 않는다.

## 수정 위치와 표식

- `#dynamic`: VOICE_FRAGMENTS_HELPERS. 기존 `$voice_impression`을 교체하고 `$voice_depth_level`, `$voice_pick_fragment` 두 동적 함수를 추가한다.
- `interaction` 1112의 기존 `$special_part`: 수락된 답변에서만 조립기를 호출하고 확정된 발언 목록을 `$text[1..n]`으로 복사한다. 거부 분기는 수정하지 않는다.
- `#txt_man`: VOICE_FRAGMENT_DATA_ROUTE, VOICE_FRAGMENT_DATA. 성별 원문 배열을 다시 읽지 않는 상수 전용 진입점과 684개의 기존 문구/메타데이터 행을 추가한다. 로케이션 수는 259 그대로다.
- 선언형 기록: `mods/2026-10-17_zzzzzzzzzzzzzz_voice_fragments.json`. 변경 직전 해시와 결과 해시를 고정하며 역패치가 원본 바이트로 돌아오는지 확인했다.

## 입력·출력·부작용

`$voice_impression`은 실제 `$slave_occupation`, 성격 네 값, `$slave_psy_status`, 헌신·두려움·기분·복종과 기존 오늘/최근 행동 횟수를 읽는다. 원래 1112의 maid 예외, 반항 시 복종 초기화, 경험, 흥분, 공포·이성·본능·습관·응석·헌신 선택 조건을 보존한다.

`$voice_depth_level`은 감정 종류 하나를 받아 0=감춤, 1=암시, 2=드러냄을 숫자로 반환한다. 규정집 3.3의 계산을 두 배 정수로 처리해 반 단위 값을 잃지 않는다.

`$voice_pick_fragment` 입력은 의미 자리, 원문 fallback, 최대 표현 깊이다. 현재 유형/직업 말투/관계와 원문 조건에 맞는 메타데이터 행을 고르고 완결 문자열을 반환한다. 현재 허용 깊이 이하에서 가장 높은 표현 자료를 먼저 쓴다. 적합한 추가 대사가 없으면 빈 문자열, 원래 정보라면 완결 원문 fallback을 반환한다. 후보는 자리·유형·말투별 인덱스로 찾으므로 발언마다 전체 표를 훑지 않는다.

조립 결과는 임시 `$jo9_vf_pages`이고, 호출부가 이름/HTML을 붙여 기존 `$text`로 복사한 뒤 임시 배열을 지운다. 원문의 잘린 font/div 포장은 페이지마다 균형을 맞추며 본문 자체는 자르지 않는다. 다음·이전 화면은 기존 `$text`를 읽으므로 재추첨하지 않는다.

기존 두 키 `$slave['jo9_voice_last1_1112']`, `last2`에 완성 답변 번호 대신 선택한 조각들의 서명을 저장한다. 새 인물별 기억 키는 없다. 구 형식의 기록은 새 조각 토큰과 일치하지 않으므로 첫 선택처럼 처리한다. 모든 조각을 고른 뒤 두 기록을 한 번 갱신한다. 거부나 화면 그리기에서는 기록하지 않는다. 기분·헌신·성격·몸 상태·게임 행동 횟수는 조립기가 변경하지 않는다.

메타데이터와 revision은 재독 가능한 상수이며 새로운 사건 기억이 아니다. 기존 세이브에 오래된 함수가 남아 있으면 신규 marker/helper를 확인해 보충하고, `voice_fragment_revision`이 다르면 전용 진입점에서 상수만 보충한다. 여성 원문 배열을 남성 원문으로 덮어쓰지 않는다.

## 분리·제거 영향

호출부만 제거하면 신규 조립 결과가 실제 질문에 연결되지 않는다. 함수/상수만 제거하면 bootstrap이 다시 읽으려 하므로 호출부와 함께 다뤄야 한다. 원문 정보 조건과 선택기를 무작정 삭제하면 해당 정보가 빠진다. 최근 두 기록만 비우면 다음 발언부터 기록이 다시 쌓인다. 구 110자 분할기와 신규 의미 단위 출력을 동시에 사용하면 이번 오류가 재발하므로 신규 경로에 연결하지 않는다.

## 비교 세이브

`spete_dialogue_test.sav`만 갱신한다. 아홉 유형은 유지하고 낙관·적대·조심스러움·협조·우울·헌신·울음·공포·순응 상태를 나눴다. 오늘/요즘 칭찬·처벌도 분산 배정했다. 원래 `spete.sav`, 인물의 배경·직업·나이·지능과 기타 업무 누적 기록은 보존한다. 비교용 기분 보정은 첫날용이며, 하루가 지나면 기존 게임 규칙대로 바뀐다.

키쿠치요는 새 테스트 공포값 때문에 기존 용감함 발견 알림이 정상 발생할 수 있어, 비교 세이브에서만 발견 완료값을 반영했다. 게임의 발견 코드나 실제 용기 수치는 바꾸지 않았다.

## 검증과 한계

원문 조건 대조 4,455개를 포함한 실제 1112 통합 검사, 의미 단위 보존, 독립 조합, 최근 조각 회피/단일 후보 반복, 구 캐시 갱신, 거부 경계, 기분/관계 불변, 세이브 왕복, 임시값 정리를 검사했다. 실제 FastQSP에서 9명 36답변과 렌더러, 구 캐시, 실제 interaction → result → screen 경로도 검사했다.

기존 QSP/편집기 회귀 검사 79개 및 출고 검사 실제 엔진 9경로 결과는 QA 기록을 따른다. 출고 과정에서 정상 특성 발견 팝업으로 멈춘 첫 실행도 기록하며, 실패를 통과로 취급하지 않는다.

실제 세이브 불러오기 UI/CRC 및 픽셀 단위 화면 배치와 전체 게임 플레이는 자동 검증 범위가 아니다. 한 후보뿐인 조각은 반복될 수 있고, 단순 도입 변화만으로 기존 본문 전체가 매번 달라지지는 않는다. 문장 재료는 이후 기존 조립기의 메타데이터에 추가할 수 있다.
