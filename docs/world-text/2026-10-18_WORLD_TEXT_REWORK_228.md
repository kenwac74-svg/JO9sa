# 월드·시설·NPC 설명 228건 반영

사용자 요청: JACK_WORLD_TEXT_REWORK_20261018.zip의 문구를 사용자 검수 완료본으로 반영한다. 문구를 다시 편집하지 않는다.

## 기준과 적용 범위

작업 직전 최신 플레이 QSP를 기준으로 병합한다. 입력 ZIP의 QSP는 구조 검사를 통과하지 못하고 최근 대화 작업도 포함하지 않아 전체 교체하지 않았다. 해당 파일에서 로케이션 경계를 확인해 설명문을 추출한 뒤, 함께 제공된 Markdown 문서의 승인 본문과 228건을 대조했다. 입력 원본은 그대로 보관했다.

장소 설명 87건, NPC 설명 119건, 평판 12건, 고블린 대사 2건, 약국·의뢰 대사 6건, 고유 인물의 관계 대사 2건이다.

## 보존·제거

변경하지 않은 254개 로케이션은 바이트 단위로 보존한다. 변경한 interaction_city와 origins_relations에서도 승인한 8개 문자열 외의 기존 대화 처리 코드는 보존한다. #dynamic, #txt_man, interaction, interaction_result, chose_answer의 최신 내용은 입력 ZIP으로 되돌리지 않는다.

선언형 mods의 old/new를 역적용하면 작업 직전 파일과 바이트가 같다. 전체 복구는 설치 영수증에 기록한 백업 QSP를 사용한다. 작업 이후 추가 수정이 있으면 전체 백업 교체 전에 그 수정부터 보존해야 한다. 캐시 갱신 구간만 제거하면 기존 저장 상태의 설명은 갱신되지 않을 수 있다. 설명문 처리 자체를 제거하면 해당 보충 설명을 더 이상 제공하지 않는다.

## 검증 범위

후보의 왕복, CRLF, 로케이션 중복, 마커 경계, 패치 재생·재적용, 역적용을 검사한다. 실제 설치 엔진의 격리 복사본에서 출고 검사 9개 경로를 실행한다. 별도 기능 검사는 문구 일치와 이전 값·수동 값의 갱신 동작을 확인한다.

사용자가 승인한 문구의 창작 검수는 다시 하지 않는다. 실제 세이브 UI 선택·CRC 호환 전수 검사·전체 지점 화면의 글자 배치 검사는 이번 자동 검사 범위가 아니다.

플레이본에만 적용한다. 배포본 동기화와 커밋·푸시는 이번 요청에 포함하지 않는다.
