# 오래된 펜딩 순차 처리

2026-10-15 사용자 지시: 가장 오래된 펜딩부터 한 항목씩 보고·해결한다. 완료 보고와 보류 결정, 단순한 기록 누락을 구분하고 이미 정상 확인한 항목을 다시 고치지 않는다. 현재 항목의 판정 전 다음 항목을 병렬 수정하지 않는다. 과거 SNKmod 전환 체크박스는 2.4의 이후 결정으로 대체된 것이 많으므로 체크되지 않았다는 이유로 현행 버그로 복원하지 않는다.

## 1. BUG-001 — 아마란스 살롱의 이전 서비스 이미지 잔류

- 최초 등록: **2026-09-27**. 원문은 로컬 `claude/sweet-meitner-72rd73` 브랜치의 `docs/BUGS.md`에서 확인했다.
- 원래 증상: 문신 등 다른 서비스를 본 다음 아마란스 살롱의 20$/50$ 서비스를 열면 이전 `$service_picture`가 추가로 남는다.
- 옛 원인: 해당 분기에서 변수를 비우지 않아 `interaction_result_city`의 공용 서비스 렌더링이 이전 경로를 `$bg_path`로 복사한다.
- **현재 상태: 해결·종료.** 2026-10-15 사용자가 “이건 아마란스 살롱 이미지 이벤트를 교체하면서 해결되었어”라고 확인했다. 해결 계기는 살롱 이미지 이벤트 교체이며, 이번 감사에서 새로 고친 것으로 기록하지 않는다. 이전 인계의 미해결 표시와 재시험 요청은 종료한다.

### 현재 두 설치본에서 확인

`interaction_city`의 102024·102025 각각 남녀 주인공 대응 분기, 총 4곳에 `$service_picture = ''`가 있다. `interaction_screen_city`에도 두 이벤트에 한정한 `$service_picture = ''`, `$bg_path = ''` 재출력 보호가 있다. 이 보호는 저장된 옛 화면 변수가 남은 경우에도 적용된다. 별도의 전체 서비스 초기화로 범위를 넓히지 않았다.

QSP 251 location 바이트 왕복, 네 이벤트의 초기화 및 두 화면 보호 검사가 양쪽에서 통과했다. **이번 항목에서는 게임 QSP·CSS·이미지·세이브를 수정하지 않았다.** 해시와 줄 위치는 [현재 코드 감사](qa/2026-10-15_bug001-current-audit.json)에 기록했다. 이 검사는 네이티브 실행을 대신하지 않는다.

### 사용자 해결 확인

사용자의 기존 해결 확인을 근거로 종료했다. 앞서 요청한 문신→살롱 20$/50$ 재시험은 반복 요청하지 않는다. 이번에는 기록만 정정했으며 게임 파일·세이브는 변경하지 않았다.

## 2. BUG-002 — 애완묘 훈련 후 간헐적인 메인 화면 공백

- 최소 확인 이력: 2026-10-03 `HANDOFF_2_4_TO_LOCAL.md`에서 미해결·재현 불가로 인계. 최초 발생일은 확정하지 않는다.
- 과거 보고: 애완묘 훈련을 마친 뒤 메인 화면이 간헐적으로 비어 보임.
- **현재 상태: 잠정 해결·종료.** 2026-10-15 사용자가 “재현불가.,잠정 해결된 것으로 간주.”라고 지시했다. 원인 규명이나 특정 수정의 효과가 입증됐다는 의미는 아니다.
- 재개 조건: 같은 증상이 다시 발생한 경우 직전/직후 저장 파일과 메뉴·교육 담당·종료 순서를 확보해 재개한다. 현재 추가 재시험이나 예방성 코드 수정은 하지 않는다.

## 3. 전투 메뉴 항목이 한 줄로 붙는 표시 문제

- 수정 기록: 2026-10-10 [전투 메뉴 형식 복구](COMBAT_MENU_RESTORATION_20261010.md). 이전 대사 정리에서 UI 문자열의 실제 CRLF를 공백으로 바꾼 회귀였다.
- 현재 상태: **해결·종료.** 사용자가 “정상표시 된다.”라고 확인했다. 직전 코드 감사에서 두 현행 QSP의 복원 조각 4개와 옛 조각 부재를 확인했다. 사용자 보고를 모든 조합의 전수 플레이 시험으로 확대하지 않는다.
- 사용자 확인 결과: 일반 공격·특수 기술·물약 사용·무기 변경·방어 메뉴의 정상 표시. 중앙 로그의 공백 여부는 이 메뉴 형식 문제와 별도다.
- 이번 확인에서는 게임 파일·CSS·세이브를 바꾸지 않았다.

## 4. 무기 선택 버튼 글자 정렬

- 수정 기록: 2026-10-10 [무기 선택 버튼 정렬 복구](LEGACY_SCENE_BUTTON_ALIGNMENT_20261010.md). 부모 메뉴의 왼쪽 정렬이 기존 버튼에 상속되던 문제였다.
- 현재 상태: **해결·종료.** 해당 항목을 안내한 뒤 사용자가 “정상”이라고 확인했다.
- 두 현행 QSP의 `$menu`에 활성·비활성 `under` 버튼을 가운데 정렬하는 규칙이 남아 있고 바이트 왕복도 일치함을 읽기 전용으로 확인했다.
- 게임 추가 변경 없음.
