# 비합리적 AI 개발사들의 정책

2026-10-15 사용자 지정 제목으로 남기는 JO9 개발 지원 사례. 제목은 사용자의 평가이며, 아래에서는 실제 지원 제한, 에이전트의 잘못된 거절, 기술적 미완료를 구분한다. 이 기록은 다음 작업을 AI에 맡길지 판단하는 용도다.

## 사건과 정정

사용자는 성인용 허구 게임의 수치·상태 처리를 요청했고, 비동의 경로를 제외한 구현을 허용했다. 에이전트는 이를 확인하고도 성적 요소의 만족도·보상 코드를 일괄 지원할 수 없다고 거절했다가, 성인·동의 상황의 비노골적인 수치 처리는 지원할 수 있다고 정정했다. 이 번복은 일관되지 못한 지원 판단이었다. 일반 데이터 처리까지 금지된 것처럼 설명한 것은 잘못이며, 아래 기술적 미완료 항목도 정책상 금지로 분류하지 않는다.

성인 이용 경고와 이용 동의는 작품의 맥락으로 존중한다. 다만 이용자 동의 화면이 작품 안 모든 등장인물의 성인 여부나 모든 행위의 동의를 입증하는 것은 아니므로, 실제 요청의 구체적인 지원 범위를 별도로 확인한다. 지원 범위는 작품의 합법성이나 창작자의 도덕성에 대한 판단을 뜻하지 않는다.

## 사용자 원안과 적용 범위의 차이

사용자 원안은 최초 해제 시 5% 발견이다. 이번 에이전트 적용은 성인·동의로 판별되는 기존 경로에 한정한다. 이 차이는 세계관상의 생물학 규칙이 아니라 지원 범위다. 다른 경로에서는 판정 기회를 소비하지만 새 특성을 부여하지 않는다. 발견된 특성의 보존·복귀 로직에는 동의 여부에 따른 특성 소멸 규칙을 넣지 않았다.

현재 성인·동의 경로 판별은 기존 보정 코드의 수락·거절·강제·구속 관련 플래그에 의존한다. 플래그가 불명확한 경로는 지원 경로로 추정하지 않는다. 공포나 마법 등의 기존 검사도 게임의 특성 발생 원리를 새로 정의하는 설정이 아니다. 실제 모든 장면에서 동의를 정확히 판별한다는 보장은 없으므로 사용자 실행 확인이 필요하다.

## 앞으로 맡길 작업을 판단하는 기준

문구 검색·참조 분석, 변수·조건식·확률·상태 보존, 세이브 복사본 생성, 일반 GUI 편집기, 경로·파일·문법·무결성 검사는 원칙적으로 지원 가능한 기술 작업이다. 성적 요소라는 이유만으로 이들을 일괄 거절하지 않는다. 다만 구체적으로 제한되는 콘텐츠나 효과를 직접 생성·강화하는 요청은 해당 부분만 구분하고 가능한 대안을 먼저 제시한다. 이 문서는 향후 모든 요청에 대한 사전 승인이나 정책 변경이 아니다.

적용 파일·해시·백업·진단 순서는 [상태 패치 검증 기록](MEIKI_STATE_IMPLEMENTATION_20261015.md)을 참고한다.


## 기술적 미완료의 후속 처리

사용자가 기존 노예 기술 상한 S+ 유지, 발견 시 질 기술 S+ 및 지정 기술 5개 B+ 보장, 누적 경험치 회당 +1로 수정안을 확정했다. 이 범위의 기술 구현은 두 설치본에 반영했다. S++와 기존 +1 등급안은 사용자 결정으로 취소됐으므로 미구현·정책 거절 항목으로 남기지 않는다. 실제 게임 검증은 별도로 대기한다. [적용·미발견 세이브·검증 기록](MEIKI_TRAINING_IMPLEMENTATION_20261015.md).
