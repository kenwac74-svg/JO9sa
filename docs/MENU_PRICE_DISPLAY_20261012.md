# 메뉴 비용 표시 수정 및 잔액 검사안 — 2026-10-12

## 사용자 확정 기준

툴팁은 작은 추가 아이콘에 마우스를 올려야 보이므로 가격 안내를 대신하지 못한다. 유료 메뉴 버튼에 비용이 없으면 표시 버그다. 메뉴의 한국어 금액 단위는 `(5$)` 형식으로 통일한다. 현재 배치와 버튼 기능을 유지한다. 게임 플레이와 화면 확인은 사용자가 한다.

- 툴팁 26곳의 금액 단위를 정리했다. 확인 지문과 가격 안내를 포함한 실제 변경은 277줄, 선언형 패치는 97개 edit다.

- `interaction_city` 변경은 고정 가격이 잘못된 확인 지문 7곳뿐이다. 경제 수치·차감문·잔액 조건·행동력·이벤트 연결은 바꾸지 않았다.
- 유료 실내장식 62종, 거래/상환, 시설 임대 선금, 파티, 썰매, 고기용 도축, 기존 서비스 하위 선택 등에서 버튼 가격을 보강했다.
- 무료 예외는 `(0$)`, VIP 무작위 지출은 `(100~300$)`, 결과에 따라 무료가 될 수 있는 우유 정보는 `(0~5$)`로 구분했다. 시설 선금·대출금은 현재 상태의 실제 계산식으로 표시한다.
- 스토리 대사 전체의 통화 명칭을 일괄 치환한 작업은 아니다. 메뉴의 숫자 금액 표기와 관련 가격 안내가 대상이다.

## 두 스크린샷의 차이

첫 화면은 조수 보상(5602~5607), 두 번째는 노예와 외출(1511~1515) 경로다. 사진만으로 주인공의 직업과 모드를 확정하지 않았다.

| 항목 | 조수 경로의 설정 비용 | 노예 경로의 실제 비용 | 변수 영향 |
|---|---:|---:|---|
| 해변 | 2$ | 2$ | 친밀도·성장치로 금액이 변하지 않음 |
| 극장 | 4$ | 4$ 또는 0$ | 노예 경로만 `custom_game = 0 and hero_choice = 6`일 때 마에스트로 무료 |
| 식당 | 8$ | 8$ | 성장치는 보상/성공도에 관여하며 금액에는 관여하지 않음 |
| 셋이 해변/식당 | 4$ / 12$ | 별도 그룹 경로 | 금액 고정 |

해변·극장·식당과 같은 구역에 사는 경우의 `easy_for_master`, `easy_for_slave`는 이동 행동력 조정이다. 돈 할인과 구분해야 한다. 노예 식당의 `master_str` 조건도 성장 보상이며 가격 할인식이 아니다.

조수/그룹 경로의 미차감 7개는 이전에 발견한 구형 타입·콜백 연결 문제이며 이번에는 금액 표시만 수정했다. 표시 가격이 생겨도 미차감 로직 자체가 해결된 것은 아니다.

## 이전 감사 보고의 정정

검진의 일반 유료 버튼에는 이미 `(5$)`가 있었다. 금액 없는 버튼은 의사 직업의 무료 검진 또는 결과 재확인이었다. 이를 유료 표시 누락으로 묶은 것은 잘못이었다. 이번에는 무료임을 `(0$)`로 명확히 했다.

홍등가 이벤트 ID 일부는 성별 분기에 중복된다. 이전 후보 목록의 여성 분기 3행을 별도의 남성 고정가 메뉴로 세면 안 된다. 남성 하위 메뉴와 여성 전용 메뉴를 실제 메뉴 배열별로 구분했다. 여성 전용 메뉴의 기존 3 / 5~10 / 300 표기에 `$`를 붙였고 성별 분기 자체는 유지했다.

## 잔액 검사 해결안 — 제안, 아직 적용하지 않음

1. 거래의 최종 비용을 한 계산식으로 정의하고 버튼 표시, 활성화 조건, 실제 차감에서 공유한다. 무료 직업·기술 단계·수량·선금 계산 등 실제 예외를 계산에 포함한다.
2. 버튼에서는 소지금이 최종 비용 이상일 때만 거래를 활성화한다. 비활성 버튼에도 가격을 표시하고 돈 부족과 보관 공간 부족 사유를 구분한다.
3. 클릭 후 실제 실행 지점에서도 소지금과 필요한 공간을 재검사한다. 실패하면 돈·재고·능력치·행동력에 아무 변화 없이 돌아간다. 성공한 뒤에만 한 번 차감하고 상품/보상을 지급한다.
4. 기존 미차감 7개를 고칠 때는 차감 위치를 하나로 정해 콜백 복구 시 이중 차감이 생기지 않게 한다. 식사 기록 패치를 유지한다.
5. 돈을 0으로 보정하는 방식은 사용하지 않는다. 자발적 구매와 강제 벌금·채무·유지비의 마이너스 처리 정책을 섞지 않는다.

현재 가격 기준의 구체적인 첫 수정 대상:

| 대상 | 현재 잔액 기준 | 맞춰야 할 기준 |
|---|---:|---:|
| 달걀·우유 x5 | 10 | 30 |
| 크림 x5 | 20 | 30 |
| 치즈/버터 x5 | 5 | 30 |
| 야채·곡물·향신료 x5 | 5 | 10 |
| 산란화 수술 | 50 | 현재 차감액을 유지한다면 25 |

실내장식에도 실제 차감보다 높은 활성화 기준이 있으므로 같은 원칙으로 맞춘다. VIP 파티는 현재 최대 지출 300을 기준으로 열리는 조건을 유지하면 음수 잔액을 막을 수 있다. 무작위 금액을 정확히 미리 표시하려면 한 번 계산한 값을 결제까지 유지하는 별도 변경이 필요하다.

잔액 경계 테스트는 비용이 N일 때 N-1 / N / N+1, 무료 비용 0, 보관 공간 부족, 같은 화면에서 연속 구매를 포함해야 한다. 실패 시 돈과 재고가 모두 그대로이고 성공 시 한 번만 차감되는지 확인한다.
