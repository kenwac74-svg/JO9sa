# 콜로세움 해방 결말 누락 수정

2026-11-02. 일반 승리 1294만 수정했던 이전 작업에서 별도 해방 이벤트 1295가 빠졌다. 이전 검사도 1295를 제외하여, 상금 $65·별도 상금 3쪽·귀환/이탈 그림 미연결을 놓쳤다. 당시 제작된 두 그림은 시안으로만 보관되어 있었다. 이번 사용자 보고와 기존 시안 채택 규칙에 따라 WORK와 이미지 목록에 함께 반영한다.

## 동작

- 기존 무패 해방 승리의 상금 산식에 일반 승리와 같은 최소 50·최종 2배를 적용한다. 시험에서 이전 $65가 $130이 된다. 별도 챔피언 보너스 신설이 아니라 앞서 승인한 두 배 증액의 누락 보완이다.
- 1쪽은 관중의 해방 선언과 기존 처형/살려줌 결과 이미지를 유지한다.
- 2쪽은 귀환 또는 영구 이탈 결과와 상금을 함께 표시한다. 귀환은 `scene/champion_return.png`, 이탈은 `scene/champion_departure.png`를 사용하며 둘 다 795×596이다.
- 상금만 표시하던 3쪽은 생성하지 않는다. 실제 문장 배열이 두 페이지이므로 다음 버튼이 세 번째 상금 페이지를 만들지 않는다.
- 상금 지급은 기존 정산 위치에서 한 번 한다. 그림을 다시 그리거나 앞뒤 페이지를 오가는 동작에는 지급 코드를 넣지 않는다.
- 귀환/이탈 판단과 인물 제거·성장 보상은 유지한다. 새 저장 변수·로케이션·세이브 형식을 추가하지 않는다.

## 저장과 재검사

변경 후 경기 종료 직전의 저장부터 다시 진행하면 새 정산과 그림을 확인할 수 있다. 이미 $65를 받은 옛 결과 화면 저장은 소급 재정산하지 않는다. 이 파일들에 표시된 이전 지급액과 오래 저장된 결과 배열은 새 경기의 정산 결과와 구분해야 한다.

사용자 빠른 확인: 같은 경기 직전 저장에서 귀환/이탈 두 경우를 확인한다. 해방 선언 다음 장이 집의 문 또는 도시를 떠나는 그림이고, 같은 장에 우승 상금이 표시되어야 한다. 다음 버튼은 별도 상금 페이지 없이 정상 복귀해야 한다. 이전·다음·재표시를 반복해도 잔액이 늘지 않아야 한다.

## 파일·의존성·검증 범위

기능 수정은 `interaction_city`의 1295 블록 한 곳이다. 기존 `выход_из_боя`가 진입하고 `interaction_screen_city`/`$objsel`이 페이지를 표시한다. 새 그림은 기존 `$special_image_full[2]`로 연결한다. 두 그림을 제거하면 해당 결과 2쪽이 누락되므로 QSP 참조와 함께 되돌려야 한다.

실제 엔진 결과·Qt 이미지 디코딩·정상 복귀와 과거 그림 잔류 검사, 공식 출고 검사 결과는 `FINAL_RESULT.json`, `green-report.json`, `release-report.json`을 따른다. 이는 개인 세이브 GUI 불러오기나 게임 전체의 모든 분기 인증을 뜻하지 않는다.

WORK·추적 패치·이미지 목록이 대상이다. 배포본은 중단 중인 최종 동기화 재개 단계에서 반영한다. ZIP·커밋·푸시는 수행하지 않는다.
