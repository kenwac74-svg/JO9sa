# 2.4 배포 마무리 — 2026-10-18

현재 후보는 Windows 복사 이미지 규칙까지 적용한 QSP `244d02c997a5ae58a01a79f397dc1d318cb3ab8180522a93f04b62f927d2afcd`이다. Play와 배포 작업본 및 QSP를 포함한 풀팩·간소 패치 ZIP의 QSP가 같다. 선택 도구 ZIP에는 QSP를 넣지 않았다. 최신 플레이를 기준으로 표준 mods·직전 백업·배포 mirror 검사를 수행했다. ## 마친 항목

- 1113의 0시작 페이지 뒤로 이동을 복구하고 1시작 sentinel 배열 동작을 보존했다. 실제 렌더러/객체 선택 5개와 기존 대사 회귀 223개가 통과했다. 대사 원고·숫자 효과를 변경하지 않았다.
- 인물 편집기는 번들 Node와 현재 게임 폴더를 우선 사용한다. 기존 명시 대상/설정 우선순위와 앱 기본 대상 ID work를 보존했다. 초기화 10개, 재추출 번들 Node의 실제 HTTP HTML/app/32개 필드 읽기와 QSP 불변을 확인했다.
- 원본 B238을 실제 (2)로 배치하고, (2)~(4)의 존재 검사·누락 건너뛰기·삭제 선택 A복귀·한 장 버튼 비활성화를 구현했다. 같은 실행 중 추가/삭제 및 기존 ID·E이상 보존을 확인했다.
- 깨끗한 풀팩, 개인 변경만 담은 간소 패치, 선택 도구 부록을 만들었다. 새 ZIP을 빈 폴더에 풀어 전 파일 SHA와 manifest를 대조했다. 지정 세이브 1~7만 포함했고 다른 저장·백업·개인/API 설정·미반영 참고 자료는 제외했다. 기존 reserve와 실제 게임용 backup 이름 이미지는 임의 삭제하지 않았다.
- 간소 설치기는 수신자 원본238·물리B238·정확한 이전/복사111을 수신자 파일에서 구성한다. 원본/외부 이미지 바이트와 외부 NPC/index는 개인 payload에 넣지 않았다. 재추출 패치의 실제 설치에서 payload1067·등록504경로·원본·기존NPC/index/저장·복구백업을 확인했다.
- 이미지 선별1062개는 개인 이력/승인 기능/사용자 확인을 근거로 했다. 빈민가 메뉴 아이콘2개는 이번 사용자 확인으로 포함했다. 외부 e3 및 미포함 기존 전환 이미지의 전제조건은 설치기가 쓰기 전에 확인한다. 이모지 기존 notice와 Noto OFL/저작권 문구를 유지·추가했다. 외부 자원의 모든 재배포 조건을 새로 인증했다는 뜻은 아니다.

## 재현 기준과 남은 범위

[체크포인트 사슬](release/2026-10-18/checkpoint-chain-windows-slots.json)은 검증된 16ef 배포 체크포인트에서 현재까지의 정확한 적용 순서를 기록한다. [통합 old/new 패치](release/2026-10-18/checkpoint-sync-windows-slots.json)는 이 체크포인트에서 같은 최종 바이트를 만드는 대안이다. 이 대안과 사슬의 개별 패치를 중복해 전체 mods 디렉터리에 적용하지 않는다. 순정부터 과거 모든 수동 변경을 재생한다는 보장은 남기지 않는다.

아르곤 추가 대사 원고와 향후 화제/지문 확장은 대기한다. 실제 UI로 기존 저장 불러오기·CRC 복원, 전체 장면 시각 검수와 전체 플레이는 자동 진단과 구분한다. 최고 권력자 엔딩·창관 본체·30셀 크라이오 등 보류/별도 기능은 이번 마무리로 새로 구현하지 않았다. 공개 게시/업로드도 수행하지 않았다.
