## 검증

tests/test_salon_menu.cjs는 수정 전 살롱 네 분기와 메뉴 배경 검사에서 실패했다. 후보와 실제 적용본에서는 6개 검사가 통과했다. QSP 바이트 왕복, 정확한 치환 횟수, 명시한 변경 외 전체 QSP 바이트 동일, VIP3·가격 유지, 컨테이너 투명화 및 자식 opacity 미사용을 검사했다. tools/apply_mods.ps1 DryRun과 적용 해시가 일치하고 재적용은 쓰기 없이 건너뛴다.

이 검사는 소스 검증이다. 실제 게임 실행·화면 확인은 사용자 담당이다. 기존 전체 mods를 재적용하지 말고 이번 JSON만 들어 있는 별도 폴더를 -ModsDir로 지정한다.

## 불사의 코셰이 — 미수정, 증상 확인 대기

현재 파일에서 kotshey NPC 등록, 12038→120381 첫 방문, 12039→120391 재방문, 소개 대사 배열이 존재한다. 120381 퀘스트 줄 연결에는 빈 continuation 줄이 없다. 기존 해금 조건은 바바야가 진행 2 + 코셰이 진행 0 + 노예 없음, 또는 코셰이 진행 1에 따른 분기다. 이 조건을 무조건 해제하지 않는다.
