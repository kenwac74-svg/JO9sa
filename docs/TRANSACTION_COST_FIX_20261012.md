# 2026-10-12 비용 차감·잔액 검사 수정

사용자: 표시 정상 확인 후 미차감·잔액 검사 수정 시작 승인. 플레이는 사용자 담당.

## 적용 범위

- 조수 해변 5602: 2$, 극장 5603: 4$, 식당 5604: 8$.
- 셋이 해변 5543: 4$, 식당 853: 12$.
- 조수 온천 5606: 2$, 황금 새장 5607: 5$.
- 위 7개는 이벤트 본문의 첫 처리에서 비용 설정, 잔액 확인, 단일 차감을 수행한다. 부족하면 menu_form으로 돌아가며 이벤트 보상·식사·행동력 처리를 시작하지 않는다. 기존에 호출되지 않던 온천·황금 새장 콜백의 차감 줄은 제거하여 향후 콜백 복구 시에도 중복 결제되지 않게 했다.
- 식료품 11521~11524: 기존 실제 가격 30$ 유지. 11531~11533: 10$ 유지. 메뉴 잔액 기준을 실제 가격에 맞추고 구매 시 냉장고 여유 5칸·주방·잔액을 다시 검사한다. 실패하면 해당 상점 페이지로 복귀하며 차감·재고 증가가 없다.
- 유료 인테리어 62종: 최종 확인의 첫 줄에서 잔액을 다시 검사한다. 메뉴 오차 3건 수정: 13412 25→20$, 13419 150→100$, 13457 25→20$.
- 시술 3326/33261: 기존 실제 가격 25$ 유지, 메뉴 기준 50→25$, 최종 확인 잔액 재검사.
- 황금 새장: 2~4$에서 피로가 아닌 잔액 부족으로 표시.

## 유지한 사항과 한계

- 가격 인상·할인 신설 없음. 직업/성장치별 기존 가격 계산, 기존 메뉴 제목·레이아웃·경로 유지.
- 기존 식사 기록(ATE_ALREADY=5, pos_self_food), 날짜·영양 처리, 이벤트 타입, 보상 수치 및 결과 처리기를 그대로 유지했다.
- 옛 prise_date/assistant_prise_date/assistant_rest의 결과 콜백 누락 전반을 이번에 연결하지 않았다. 비용 문제를 고치기 위해 현대 praise_date로 바꾸면 보상 필드·참여자·행동력 처리까지 달라지므로 범위를 분리했다. 휴식·보상 효과 전체의 정상 작동을 이 패치의 검증 결과로 주장하지 않는다.
- 이번에 확인된 거래 경로를 수정했다. 모든 게임 거래·여성 플레이 전용 무작위 거래의 잔액 안전성을 보증하는 전체 감사가 아니다. 세금·강제 비용·부채 규칙은 변경하지 않았다.

## 검증
