## 현재 등록 상태

이 문서는 브랜치와 기준본을 등록하는 관리 문서다. 이 커밋에 기준 배포본의 전체 소스나 실행 파일이 포함되었다는 뜻은 아니다. 초기 소스 반입은 별도 커밋으로 완료하고, 반입 후 원본 바이트와 해시를 대조해야 한다.

## 유지할 기능과 작업 범위

- 게임의 Show HTML을 이용하는 기존 현재 화면 이미지 자동감지와 대상 선택 UX를 유지한다.
- PIC 폴더 등록 영역을 이미지 목록 위로 이동한 수정 HTML을 사용한다.
- 기존 원본 이미지 교체, 이미지 조절, 설치 및 복구 기능을 보존한다.
- SNmod 이벤트 전용 이미지 연결 기능은 아직 기준본에 구현되지 않았다.
- 부동산 NPC는 노예 데이터의 ID를 전제로 다루지 않는다. 부동산 구매 완료 이벤트 범위를 소스에서 확인한다.
- 새 전용 이미지를 추가할 때 공용 원본과 다른 이벤트의 참조를 보존한다.
- 소스 수정, 실행 데이터 반영, Windows 실행 및 인게임 검증의 완료 여부를 구분해서 기록한다.
