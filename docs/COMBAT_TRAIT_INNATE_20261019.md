# 발견 시 전투 특성 부여 — 2026-10-19

사용자 승인: 앞서 제시한 배경별 50%/50%/25% 안에 대해 “그렇게 적용해”. 본인의 직업 배경이 모험을 겪은 전사(`heroine`)인 신규 일반 무작위 인물을 대상으로 한다.

| 본인 직업 | 가족 배경 | 부여 후보 | 한 번의 부여 확률 |
|---|---|---|---:|
| heroine | amazon 또는 viking | 광전사 (`jo9_combat_trait=1`) | 50% |
| heroine | knight | 성기사 (`=2`) | 50% |
| heroine | 그 외 | 역전의 용사 (`=3`) | 25% |

후보를 먼저 정한 뒤 1~100 단일 추첨을 한다. 앞의 50% 판정이 실패했을 때 역전의 용사로 다시 추첨하지 않는다. 가문만으로 부여하지 않으며 다른 직업 배경에는 이 추첨이 없다. 성기사 연결은 사용자 승인한 방어형 기사 전투 스타일의 기획이다. 원문에 종교 신앙이나 광폭화 이력이 명시되어 있었다는 의미로 설명문을 새로 쓰지 않았다.

## 코드 위치·입출력

- 패치: `mods/2026-10-19_combat_trait_innate.json`.
- 변경 위치: `generate_stock`의 기존 일반 특성 생성 직후, 최종 특성 갱신과 목록 준비 이전.
- 안정된 블록 ID: `COMBAT_TRAIT_INNATE_BACKGROUND`.
- 입력: `special_stock`, `creating_clone`, `$stock_occupation`, `$stock_family`, `stock['jo9_combat_trait']`.
- 출력: 성공할 때에만 기존 `stock['jo9_combat_trait']`를 1/2/3 중 정해진 후보로 설정한다. 별도 함수 반환값은 없다.
- 임시 값: `jo9_trait_innate_roll` 하나이며 블록 뒤에서 지운다. 새 인물 영구 키·함수·로케이션·세이브 형식 변경은 없다.

배경 식별은 기존 문자열 키를 사용한다. `family_index`와 `work_index`는 광범주이므로 특성 판정에 사용하지 않는다. 번역된 설명문이나 화면 이름으로 배경을 비교하지 않는다.

## 기존 인물과 별도 생성 경로

- `special_stock=0`인 새 일반 무작위 생성에서만 호출한다. 고정 프리셋에는 적용하지 않는다.
- 이미 전투 특성이 있으면 추첨하거나 덮어쓰지 않는다.
- 복제인간은 일반 생성기를 거친 뒤 배경을 인공 제작 이력으로 교체한다. 임시 배경으로 특성이 잘못 붙지 않도록 기존 `creating_clone=0` 조건을 사용한다. 별도 저장 상태를 추가하지 않는다.
- 기존 인물, 이미 생성된 상점 재고, 세이브 로드, 데이터 갱신, 인물 이동에는 새 추첨 호출을 추가하지 않았다.
- 기존 배열 교환은 배경 문자열 키와 `jo9_combat_trait`를 함께 옮긴다. 선천·후천 획득을 따로 기록하는 출처 필드는 추가하지 않았다.
- 앞서 적용한 누적 실전10·15·20…승 각3% 추첨과 안개 승리 자아·기질 누적값 각5는 유지한다. 발견 당시 특성을 얻은 사람은 후천 추첨의 기존 보유자 제외 조건을 따른다.

## 의존성과 분리 시 영향

이 블록은 배경이 정해지고 기존 일반 특성이 생성된 다음, `special_stock`가 아직 초기화되지 않은 위치에서 실행해야 한다. 앞쪽으로 옮기면 배경을 읽지 못하고, 생성 종료 뒤로 옮기면 프리셋 구분값을 잃을 수 있다. 복제인간 호출에서는 기존 `creating_clone` 상태가 의미를 갖는다.

블록만 제거하면 이후 새 일반 인물의 발견 시 전투 특성 획득이 중단된다. 이미 획득한 특성·승수·후천 획득 로직은 사라지지 않는다. 생성기 전체나 기존 특성 갱신 호출을 제거할 필요가 없다.
