# 포털 가디언 우측 설정

가디언을 만나 싸움 여부를 고르는 화면 우측에 제목·역할·위치와 설정3문단을 추가했다.

포털 가디언 / 차원 관문의 수호자 / 안개경계 · 포털 지대

영원의 로마와 이계가 맞닿는 문턱을 지키는 수호자. 교황청의 기사가 명령을 집행한다면, 이 존재는 관문에 새겨진 금제 그 자체다. 허가받지 않은 발길은 도시를 향하든 고향을 향하든 똑같이 가로막힌다.

관문 아래 흐르는 마력은 그 육신의 고대 술식을 끊임없이 깨운다. 건립기의 유산인지, 누군가를 깎아 만든 병기인지는 전해지지 않는다. 다만 문 너머의 재앙을 막는 힘이 도망자의 희망도 함께 짓누른다는 사실만은 분명하다.

관문을 여는 인가와 제어의 열쇠는 교황과 도시의 지배자들이 쥐고 있다. 수호자에게 애원과 협박, 황금은 아무런 통행증이 되지 못한다. 돌아갈 세계가 문 너머에 보여도, 허락 없는 자에게 이 문은 영원히 닫혀 있다.

## 입력·출력·부작용

shop_general에서 $place=fogs_battle2, interaction_city=6216, sp_txt=6216, get_weapon=0, $враг[1]=strazhnik일 때 공통 제목과 jo9_reference_panel로 표시한다. $ongload는 같은 저장 준비화면(skip_to=6216 또는 sp_txt=6216)만 shop_general로 다시 그린다. 62172나 전투 초기화를 재호출하지 않는다. 생성·인벤토리·소지금·퀘스트·보상 값을 바꾸지 않는다. 기존 팔라딘6215, 무기901/get_weapon1, 일반상점은 기존 표시를 쓴다.

신규 변수·로케이션·저장 형식, 이미지 경로·파일, CSS, 전투 능력/수치 변경은 없다. 기존 대사·선택 콜백을 보존했다. 패널 분기를 제거하면 가디언 준비화면 우측이 빈 메타데이터 출력으로 돌아가고, 로드 분기만 제거하면 옛 저장 HTML은 다음 재표시 전까지 남을 수 있다.

## 검증 및 수동 확인

구조·줄/주석 경계·패치 재생/역재생·기존 본문 보존을 확인했다. 실제 설치 엔진의 준비/옛 준비 로드2유형/무기/팔라딘/일반상점과 공식9경로를 통과했다. 로드 처리를 두 번 실행해도 배우·인벤토리·소지금·진행·보상 센티널이 유지된다. 실제 GUI 저장파일 불러오기 클릭과 전투 전편 완주는 별도 수동 범위다.

WORK 일반 EXE를 재시작하고 가디언 선택 화면을 열어 오른쪽 이름과 본문을 확인한다. 기존 TC_09_PORTAL_GUARDIAN_EVENT.sav에서 포털 지대→소개3쪽→가디언과 싸운다로 갈 수 있다. Full·원본·기존SAV·이미지·목록은 수정하지 않았다.
