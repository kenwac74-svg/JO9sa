## 1. 현황

- '문학과 예술'은 `#options`의 `$library_city_options[5]`다. 지금은 `아직 등록된 문헌이 없습니다.`와 '뒤로' 버튼만 있다.
- 다른 분류의 책은 공용 리더(`CITY_LIBRARY_BOOK_READER_20261106`)로 열린다. 책마다 IF 블록을 따로 만들 필요가 없다. 등록 항목은 다음과 같다.
  ```
  $jo9_library_book_title['<id>'] = '제목'
  jo9_library_book_category['<id>'] = <분류 번호>
  jo9_library_book_start['<id>'] = <첫 페이지 번호>
  ```

- 기존 페이지 본문은 한국어 약 170~200자다. 아래 초안도 이 분량에 맞췄다.
- 비어 있는 번호 (오늘 덤프 기준):

## 5. 1차 초안에서 바뀐 것

- 수업료와 학과 비용, 무희 의상 가격을 모두 뺐다.
- 각 권에 세계관 서사 쪽을 하나씩 넣었다(음악 2쪽, 무용 2쪽, 미술 2쪽).
- 각 권에 '수업 앞의 차림' 쪽을 넣었다. 수업을 돕는 의복과 벗겨야 할 것을 태도로 쓰고, 구하는 곳은 서술 안에서 밝혔다.
- 예술가 전공이 판매가를 올린다는 문장을 뺐다. 가격 계산에 전공 보너스가 있는지 확인하지 못했기 때문이다. "귀족들이 눈여겨본다"로 바꿨다.

## 6. 적용 전 확인할 것

1. 학교 수업과 가정교사 수업에 등급 상한이 있는지는 확인하지 않았다. 그래서 본문에 학교·교사의 상한은 쓰지 않았다.
2. 동물 구속복·구속복의 판매처는 확인하지 않았다. 본문은 판매처를 쓰지 않고 "입힌 채로는 배우지 못한다"로만 썼다.
3. `../characters/...` 배경 키가 열리는지 게임에서 확인한다.
4. 무용 책(15031)은 테르프시나 NPC가 적용된 뒤에 넣는다. 서문은 확정 배경("영원의 로마 대극장의 프리마", 가문 소속 없음)에 맞췄다.
5. 본문에 `<<...>>` 치환을 쓰지 않았다. 기존 책과 같이 고정 문장이다.
