## 5. 적용 전 확인할 것

1. 예술가 전공이 판매가를 올리는지: 15032의 5쪽 문장은 `von_valtz`의 소개문("평범한 노예의 몸값을 귀족들의 사치품…")을 근거로 했다. 실제 가격 계산에 전공 보너스가 있는지는 확인하지 않았다. 없으면 "귀족들이 눈여겨본다" 정도로 낮춘다.
2. 학교 수업과 가정교사 수업에 등급 상한이 있는지는 확인하지 않았다. 그래서 본문에 학교·교사의 상한은 쓰지 않았다.
3. `../characters/...` 배경 키가 열리는지 게임에서 확인한다.
4. 무용 책(15031)은 테르프시나 NPC가 적용된 뒤에 넣는다.
5. 본문에 `<<...>>` 치환을 쓰지 않았다. 기존 책과 같이 고정 문장이다.

## 6. 확인 포인트 (적용 후 사용자가 게임에서)

1. 도서관 → 문학과 예술에 세 권이 보이는지
2. 각 책이 1/5~5/5까지 넘겨지고 마지막 쪽에서 멈추는지
3. 쪽마다 배경 그림이 나오는지. 리더는 `nsfw = 0`일 때만 책 배경을 그린다.
4. 다른 분류의 책 쪽 번호가 밀리지 않았는지
