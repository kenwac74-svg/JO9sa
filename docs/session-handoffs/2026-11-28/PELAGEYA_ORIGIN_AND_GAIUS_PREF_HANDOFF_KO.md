## 3. 수정 B — 가이우스 의뢰 대사 [5] 중복 (location `#npc_base`)

### 문제
`#npc_base`에서 `$ImperatorGay_pref[5]`가 두 번 연달아 대입된다.
```
$ImperatorGay_pref[5] = '…말이 통하고… 영리하고, 강인하고, 뚱뚱하지 않으며, 약간 이국적인 여자 말이다. 하지만 물론, 제 자리는 알아야지.'
$ImperatorGay_pref[5] = '…펠라게야가 이 일에 대해 어떻게 느끼는지 알고 싶나?…<!-- #nwtx -->'
$ImperatorGay_pref[6] = '…그냥 내게 맞는 여자 하나를 데려와라…'
```
- 의뢰 화면(`interaction_city` 70631)은 `txt_count = 6`, `copyarr '$text', '$ImperatorGay_pref'`로 보여 준다.
- 그래서 요구 조건 줄(영리함·강인함·비만 아님·이국적)이 덮여 화면에 나오지 않는다.
- 원문은 5줄이었고, 한국어판이 원문 [2]를 두 줄로 나누면서 번호가 하나씩 밀렸다.

### 수정
1. `#npc_base` (각 count 1)
   - 두 번째 `$ImperatorGay_pref[5] = '[황제 가이우스]<br>&nbsp;펠라게야가 이 일에…` → `$ImperatorGay_pref[6] = …` (본문 그대로)
   - `$ImperatorGay_pref[6] = '[황제 가이우스]<br>&nbsp;그냥 내게 맞는 여자 하나를…` → `$ImperatorGay_pref[7] = …` (본문 그대로)
2. `interaction_city` `IF interaction_city = 70631:` 블록의 `txt_count = 6` → `txt_count = 7`
   - WORK에 ` txt_count = 6`이 21곳 있으므로 70631 블록 범위로 좁혀 교체한다.
3. 구세이브 정리 (`$newloc`)
   - `$newloc` 12527 부근의 기존 이행 줄은 옛 펠라게야 문장이 있으면 `[5]`에 새 문장을 넣는다. 그 줄은 그대로 두고, 그 **뒤에** 다음 정리를 추가한다.
   ```
   if $ImperatorGay_pref[6] = '[황제 가이우스]<br>&nbsp;그냥 내게 맞는 여자 하나를 데려와라. 내가 직접 보고, 마음에 들면 네게 빚을 지지.' and $ImperatorGay_pref[7] = '':
   	$ImperatorGay_pref[7] = $ImperatorGay_pref[6]
   	$ImperatorGay_pref[6] = $ImperatorGay_pref[5]
   	$ImperatorGay_pref[5] = '(수정 1의 첫 번째 [5] 요구 조건 문장 원문 그대로)'
   end
   ```
   - 세이브에 이 배열이 저장되는지, `$newloc`에서 `#npc_base`가 다시 실행되는지 먼저 확인한다. `#npc_base`가 매번 다시 실행되면 3은 필요 없다.
