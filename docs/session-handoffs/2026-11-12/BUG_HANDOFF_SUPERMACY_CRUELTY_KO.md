## 1. 버그: 장악력이 다른 인물에게 섞여 쓰인다 (심각)
- 계산: `$calculate_attributes` 543~563행. `dynamic $replace(…, 'dyn'+'slave', iif(slave_state > no_slave, 'slave', 'assistant'))`로 **메인 노예(없으면 조수) 하나만** 기준으로 `master_supermacy`를 만든다.
  `장악력 = (매력 + 지배력 + 스타일 + 힘 + 구타 경험 + 마그나 + 유물 보너스) − (성격 + 자아 + 태도 + 체력 + (지성 − 3)) + 옷·무기·연령·주인공 보정`
- 그런데 그 값을 아래 인물에게도 그대로 쓴다.
  | 위치(최신 qsp, 0부터) | 대상 | 용도 |
  |---|---|---|
  | next_day 4808·4826·4846·4864 | 개인실 노예 1~4 | 매일 사육 +1 판정 |
  | interaction_result 1557·1692·1694 | 외양간 소 | 저항(`will_to_resist`)·반항 판정 |
  | next_day 4304 | 조수 | 발정 이벤트 판정 |
  | next_day 2874 (`$next_day_fear_effects`) | 노예 공통 템플릿 | 장악력 < 0이면 사육 감소 |
  | interaction_result 1431·1434 (`$interaction_result_rape`) | 노예 공통 템플릿 | 저항·반항 |
  | #dynamic 2248 | 노예 공통 템플릿 | 아이템 일일 보너스 상한 |
- 결과: 의지가 강한 개인실 노예도 메인 노예가 약하면 매일 사육이 오르고, 반대도 생긴다.

### 수정 (mod 1)
- 새 location `jo9_supermacy`(함수, `args[0]` = 인물 배열 이름: slave, assistant, room1~room4, cow, farmhand 등). 기존 계산식을 그대로 옮기고 결과만 `result`로 돌려준다.
- `$calculate_attributes`는 이 함수로 메인 노예 값을 계산한다(결과 동일).
- 위 표의 자리를 그 인물 기준 호출(`func('jo9_supermacy', '<인물>')`)로 바꿨다. 템플릿 안의 `'dynslave'` 문자열은 기존 `$replace`가 실제 인물 이름으로 바꿔 준다.

### 함께 반영: 악명(크루얼)과 장악력 (사용자 결정)
- 크루얼(`jo9_cruel_mercy`, 음수 = 잔인)은 노예 밖 활동의 잔혹 행위로 쌓이는 악명이다. 단계별로 장악력에 더한다.
  | 크루얼 | 단계 | 장악력 |
  |---|---|---|
  | −10 이하 | 무자비 | +1 |
  | −20 이하 | 잔인 | +2 |
  | −30 이하 | 흉폭 | +3 |
  | −40 이하 | 악행 | +4 |
- 구타 경험(`beaten_ever`)과는 **둘 중 큰 값**을 쓴다(더하지 않음). 의미: 때려서 길들이는 장악도 있지만, 악명 높은 주인은 말만으로 같은 효과를 낸다.

### 검증 결과 (QSP WASM 엔진)
- 메인 노예 장악력 패치 전후 동일(−5 = −5).
- 구타 경험 없음: 크루얼 −9 → +0, −10 → +1, −20 → +2, −30 → +3, −45 → +4.
- 구타 경험 1: −5 → +1, −30 → +3, 머시 +10 → +1.
- 개인실 노예는 자기 의지로 따로 계산(개인실 −18, 메인 −5).
- 이 세션에는 PowerShell이 없어 `apply_mods.ps1` 자체로는 돌리지 못했다. 같은 규칙(old/new 개수, 왕복, 줄 끝, MOD START/END 표식)을 따르는 파이썬 사본으로 적용·검사했다.

## 3. 분석만 하고 바꾸지 않은 것
- 힘 중복: 힘은 스타일에 ±1(힘 > 3 +1, < 3 −1)로 들어가고 장악력에도 더해진다. 영향은 최대 ±1. 저항 판정은 `장악력 − 스타일`을 써서 그쪽에는 중복이 없다.
- 지성 − 3: 지성이 낮을수록 장악이 쉽다. 사용자 확인: 의도됨.
- 초반 음수: 새 게임 주인공 능력치는 제각각이라 문제 아님(사용자).
- 사용처 상한(min 5, /2, /5): 의도됨(사용자).

## 4. 확인해 달라는 것
1. 두 mod 적용 후 게임 실행, 개인실·소·조수가 있는 세이브에서 밤 넘기기(사육 변화), 아우스펙스 표시.
2. 순찰 성기사단 처형 후 크루얼 −0.5, 구한 여자 감방 −0.5.
3. 결투 패배 노예 처형 기준(크루얼 −5 이하)이 장악력 첫 단계(−10)보다 먼저 온다. 의도한 순서인지 사용자 확인 대기.
