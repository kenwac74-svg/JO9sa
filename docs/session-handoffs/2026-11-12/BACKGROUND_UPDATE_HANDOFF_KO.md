## 1. 배경 스토리 대사 개정
- 개정본: 세계 40변형 + 출신 57 + 직업 64 = **161개**(원 인계 묶음 `JO9_Source_Handoff_20261112.zip`의 개정)에 신규 직업 초안 여학생·무용가 2개를 더해 163개.
  - 개정의 기준 데이터: `tools/jo9-history-lab/docs/background-revision-20261112.json`(분류명 + 본문, 세계는 변형별 배열). 사용자 설정 백업에 개정을 입히는 도구: `docs/apply-background-revision-20261112.py --backup <백업.json> --output <결과.json>`(연결·ID·수치는 바꾸지 않음).
  - 편집기 기본 데이터(`dist/data/backgrounds.json`, `background-drafts.json`)와 `presets/`의 두 전체 설정 JSON(연결 검수본, 01-46-18 백업)은 **모두 개정본과 같다**(161개 대조, 다름 0). 원문 표: `presets/JO9_배경명칭_전체대사_개정본_20261112.md`.
- **게임에는 아직 반영되지 않았다**(사용자 확인). 최신 qsp 대조 결과 152개 모두 옛 문장이다.
  - 위치: 각 레코드의 `source`가 게임 위치다(`#static_txt:줄`, **1부터 센 줄 번호**). 예: 출신 `tribe` → `#static_txt` 2648번째 줄 `$family_description["tribe"] = '…'`. 세계는 `$<세계>_description[n]`, 직업은 같은 방식의 직업 배열.
  - 변환: 편집기 문장의 첫 줄 `{이름}` → 게임 `'<<$dynslave_name>><br>'` 접두. 본문의 작은따옴표는 `''`로.
  - mod로 넣을 때 old는 게임의 현재 문장 전체(줄 단위)로 잡는다. 줄 번호만 믿지 말고 `old` 문자열 일치로 확인한다.
- **신규 ID 11개는 게임에 없다**(엔진 표본 1만 명에서 0회): 세계 `earth_rome`(지구의 고대 로마), 출신 `ancient_noble`·`ancient_citizen`·`roman_freedslave`, 직업 `courtesan`·`serial_killer`·`gang_member`·`mafia_boss`·`former_slave`·`schoolgirl`·`dancer`. 대사 외에 생성 풀(`$<세계>_family`, `$<출신>_occupation`)·연결·연령 조건·직업 처리 코드가 함께 필요하다.
- 사용자가 편집기에서 고친 대사는 브라우저 저장소(`config.backgroundSettings.texts`)에 있다. **최종본은 사용자의 "전체 설정 내보내기" JSON을 받아 쓴다.** 편집기 배경 설정 목록에 "저장된 수정 대사 n개 → 모두 개정본으로" 버튼을 새로 넣었다(예전 설정을 불러와 개정본이 가려진 경우 복원용).
- 작성 원칙(원 인계 5장): 1인칭 담담한 회상, 광고·구호 금지, 가족 관계 모순 금지, 시대에 맞지 않는 학교·교복 전제 금지.

## 3. 배경에 따른 능력치·특성 추첨
### 3.1 책임 나눔(원 인계 8장, 확정)
| 구분 | 역할 |
|---|---|
| 세계 | 초기 능력치 추첨 보정 |
| 출신 | 행동에 따른 성장·하락폭 보정, 세련됨 추가 추첨(예외적으로 특성 연결) |
| 직업 | 초기 스킬과 특성 연결. 능력치 추첨·성장폭 보정은 붙이지 않음 |

### 3.2 출신(확정)
- 원본: `presets/JO9_Origin_Personality_Presets_20261111.xlsx` '출신보정' 시트, X~AD 열(사용자 최종 결정). C~N·Q 열은 폐기된 옛 안.
- 계층 7개(57개 출신 전부 분류): 세습 귀족·공주 4 / 비세습 상류층 15 / 중산층 14 / 예술가류 2 / 노동자·중하류층 12 / 하류층 5 / 극빈층 5. 계층별 보정 표는 원 인계 8장.
- 적용 원칙: 해당 방향 변화에만 적용(−10의 하락폭 +10% → −11), 소수 누적 보존, 세련됨은 기본 추첨 뒤 추가 1회(0~5 제한), 고정 캐릭터에는 적용하지 않음.

### 3.3 직업
- 데이터: `dist/data/occupation-specs.json`(명세 30개, 규칙 80개 = **확정 39 · 미정 28 · 메모 13**). 원본 `docs/occupation-specs-source.mjs`, 생성 `docs/build-occupation-specs.mjs`, 검사 `checks-occupation-specs.mjs`(없는 특성·직업·등급, 배척 그룹 합, 부여·제외 겹침).
- 미정 28개는 수치가 정해지지 않은 규칙이다. **임의로 채우지 않는다.** 사용자에게 받을 목록:
  수녀(4), 살인마(3), 범죄자 공통(자유로운 영혼 확률), 여마법사의 제자, 공주계열(3), 직조공, 선반공(2), 운동선수 공통, 시공경찰관, 미래경찰, 교도관, 작가(2), 화가, 클러버(3), 우주군 사관생도, 궤도 정비공, 영웅 여전사(상위 특성 세부 가중치).
- 확률 해석(원 인계 7장): "30%"는 최종 집단의 목표 비율, 배척 특성은 그룹 단위 추첨, 뒤의 공통 추첨이 목표 확률을 다시 올리지 않게 한다.
- 활동·집중 특성 단계형 개편(`presets/JO9_특성배척_버그기록_20261111.md`, 사용자 승인): 끈기/워커홀릭/산만함/무기력함은 하나만 보유, 상위가 하위를 대체.
- 직업 대분류(편집기 표시·계수용, `dist/data/background-categories.json`): 창녀, 범죄자(해커 포함, 사용자 확인), 공주계열, **세습 상류층(귀족 아가씨, 사용자 결정)**, 혼인·신부, 운동선수, 경찰관류, 목축업자, 노동자, 하녀·서비스, 학업·지식, 주술·마법·종교, 전사·모험가, 예술·연예(무용가 포함), 그 밖(소녀·거지·점쟁이·펑크·페미니스트·노예, 공통 규칙 없음).
- 외양간지기 임명 조건(게임 확인): moral ≥ 3, 간호 > 2(B), 비서 > 2(B).

### 3.4 생성 순서(원 인계 7장 권장안)
유니크 구분 → 세계·연령·연결 후보 → 세계 능력치 보정 → 출신 성장 규칙·직업 분류 부착 → 직업 특성(배척 그룹) → 특성·스킬 조건에 맞춰 나머지 채움 → 공통 특성 추첨 → 최종 검증. 차기 업데이트의 과거 경험(통계)은 **모든 특성 추첨이 끝난 맨 마지막**에 계산한다(사용자 결정).
