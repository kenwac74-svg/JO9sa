### 2.2 직업 특성 확률 해석 (중요, 원 인계 7장을 대체)
- 규칙의 `mode:"add"`(대부분): **게임의 기본 추첨 확률에 %p를 더한다.** 공통 특성 추첨(1287~) 뒤에, 그 특성이 아직 없을 때만 추가로 굴린다. 정확히 "기본 + X"가 되게 하려면 추가 추첨 확률 = X ÷ (100 − 기본) × 100. 단순하게 X%로 굴리면 최종값이 조금 낮다(기본 5% + X 20 → 24%). 직업별 기본 비율은 `dist/data/generated-stock.json`(엔진 표본 1만 명)으로 확인할 수 있다.
- `mode:"final"`: 그 직업의 최종 비율(수녀 처녀 90%). 배척 그룹(페미니스트 레즈비언 30·양성애자 30·없음 40)과 단계형(영웅 여전사: 20% 진입 → 타고난 투사/용감함 반반 → 진입자 중 20%에 역전의 용사/성기사/광전사 같은 비중)도 최종 비율.
- `grant` = 확정 부여, `exclude` = 추첨 대상에서 제외, `forbid` = 등장 금지, `skillMin` = 스킬 최저 등급, `skillExclude` = 해당 스킬 등급 제외.
- 같은 게임 값을 쓰는 특성은 동시에 가질 수 없다(예: 촌뜨기 `grace < 0` ↔ 품위있는 여자). 그래서 부족 공주는 촌뜨기 대상에서 뺐다. 검사 `checks-occupation-specs.mjs`가 이 충돌을 잡는다.
- 활동·집중 특성 단계형(끈기/워커홀릭/산만함/무기력함 중 하나만): `presets/JO9_특성배척_버그기록_20261111.md`.

## 3. 묶음 C · 차기 업데이트(필로우토크) 요약
세부는 인계 3. 확정된 핵심만 적는다.
- **대사 저장 방식(QSP 안 / 별도 JSON)은 모드 제작자가 판단한다.** 사용자 희망은 세이브 영향 없는 별도 JSON. 판단 자료와 10분 시험(큰 시험 JSON을 두고 세이브 크기 비교)은 인계 3의 3장.
- 커맨드: 대화하기 > 질문한다 아래, 하루 1회, 행동력 0.5. 거부: 절망 ≥ 3 → 응석 ≥ 3 → 인식 ≤ 2. 헌신 1~5로 질문 22개가 열림.
- 거짓말: **이 노예에 대한 장악력 < 0**이면 기존 오답으로 답함(장악력은 묶음 A의 `jo9_supermacy`).
- 사실은 두 층: 영입 전 과거(영입 때 한 번 계산해 고정) + 영입 후 누적(주인·주인 외 창관·길거리 등·이종). 등장 직후에는 과거만 말하고, 육성하면서 누적을 반영한다.
- 이종 경험: 성경험 횟수·상대 수에 포함. 초기값은 등장 사건만(안개 경계 구출 = 장면 상대 수, 오크 포함). 이전 주인 촉수 착정은 **영원의 로마에 오래 머문 유니크에게만 수동 지정**(무작위 생성 0%).
- 첫 경험 평균 나이: 선사 14, 야만 15, 로마 16, 현대 18(러시아), 그 밖 초안. 19세 미만은 표시 불가(B1).
- 상대 수: 한 명당 평균 횟수 접객업 2, 성노예 2(전직 노예 중 성 기술 평균 3 이상), 밤 문화 5, 집 노예 10, 그 밖 10, 기혼 100.
- 호칭: 초기 상태(사육·헌신·두려움 모두 1 이하) 또는 적대면 반말·당신. 초기 상태 세습 귀족·공주는 너/네놈(인식 2 이상이면 하지 않음). 비속어는 주인에게 쓰지 않고 독백·제3자에게만(범죄자·하류층·극빈층).
- 표시불가 코드 B1 청소년기, B2 수간, B3 근친, B4 금기 목록, B5 SNS, B9 빈 대답. 화면에는 코드 없이 "[이 대사는 표시 불가합니다.]".
- 펠리시티: 기존 조교 −3, 새 보살핌 분기 +12(분기 퀘스트 완료 때 반영).
