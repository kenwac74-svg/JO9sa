### 2. 답변 · 턴 a007ea30-03ca-4923-9e02-f7e55d8b1166

가능해. **엔진 수정 없이 QSP/UI 레벨에서 처리할 수 있어.**

지금 화면의 `-착용 가능 장비-` 목록은 각 장비를 그냥 `<a>` 링크로 만들어 `$equip_choice`에 붙이는 구조다. 예를 들어 갑옷 목록도 `아라미드 전투복`, `상어가죽 갑옷` 등을 단순 링크로 출력한다. :chatgpt-content-reference{index="0"} 그리고 노예 장비 화면에서는 그 `$equip_choice`를 그대로 오른쪽 영역에 표시한다. :chatgpt-content-reference{index="1"}

좋은 점은 **장비 설명 데이터가 이미 전부 존재한다**는 거야. 예를 들어 카타나는 `$item_description['катана']`에 설명과 피해 정보가 이미 들어 있다. :chatgpt-content-reference{index="2"} 갑옷도 같은 방식으로 설명이 있다. :chatgpt-content-reference{index="3"}

게다가 현재 UI 자체가 이미 `tooltip-data` 기반 마우스오버 툴팁을 사용하고 있다. 상단 장비 아이콘에 마우스를 올리면 이름이 뜨는 기능도 이 방식이다. :chatgpt-content-reference{index="4"}

그래서 구조는 이렇게 바꾸면 된다.

현재:
```qsp
<a href="...">카타나 [1]</a>
```

변경:
```qsp
<a class="tooltip-left"
   tooltip-data="카타나 설명..."
   href="...">카타나 [1]</a>
```

다만 `$item_description`에는 `<br>`, `<font>` 같은 HTML이 포함돼 있으므로 **그 문자열을 그대로 `tooltip-data`에 넣지는 않는 게 좋다.** 툴팁용으로 태그를 제거한 텍스트를 자동 생성해서 넣는 방식이 안전하다.

예를 들면 실제 표시 느낌은:

**카타나 [1]** ← 마우스 오버  
> 카타나는 대중에게 완벽한 무기로 여겨지는 검.  
> 베기형 무기 / 피해량: 힘 + 4

처럼 만들 수 있다.

그리고 이건 **마스터 / 노예 / 조수 장비 화면 전부 동일하게 적용 가능**하다. 현재 세 화면이 거의 같은 장비목록 함수를 따로 가지고 있어서 한쪽만 고치기보다는 세 곳을 같이 맞추는 게 낫다.

특히 네가 올린 화면처럼 오른쪽 목록이 좁으니까, 툴팁은 **목록 왼쪽 방향으로 펼치게** 만들어 중앙 빈 공간을 활용하면 UI를 가리지 않고 보기 좋을 것 같다.

원하면 이 기능을 **현재 쿠라 개인 패치에 같이 넣지 않고, 별도의 공통 UI 개선 패치로 분리해서** 만들 수 있어.
