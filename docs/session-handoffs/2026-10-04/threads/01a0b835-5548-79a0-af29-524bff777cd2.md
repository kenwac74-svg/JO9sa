이해했습니다. 확정 기준은 **순정 원본과의 해시 비교**입니다.

- **같은 경로·같은 해시:** 패키지에서 제외하고 원본 사용.

- **영문명으로 변경한 리소스:** 앞서 정한 예외대로 SNKmod에 포함하고 참조도 변경.

즉, **기존 패치의 변경 파일에는 의존하지 않되, 변경하지 않은 순정 리소스는 재사용**하는 독립 설치형입니다. 클로드의 분류 방향이 맞으며, 제가 앞서 원칙 차이라고 지적한 부분을 정정합니다.

| 구분 | UI 패치 처리 |
|---|---|
| 순정과 동일한 리소스 | 제외, 원본 참조 유지 |
| UI 패치 작업으로 교체·추가한 리소스 | SNKmod에 포함하고 참조 변경 |
| UI 패치에서 영문명으로 변경한 리소스 | 내용이 같아도 포함 |
