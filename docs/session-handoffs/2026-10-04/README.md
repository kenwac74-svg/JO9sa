2. 0.14와 이미지 교체 패치 흡수 범위, 원본 경로 대체 그림 원복 여부, IMGMG 약 2.6GB의 패치/통압축/별도 ZIP 배치, 올걸팩 JSON의 기존 세이브 영향.
3. 홍등가 시퀀스 변경 후 기존 1121/1131 자산의 최종 배포 제외 여부. 참조가 사라졌는지 실제 빌드 기준으로 확인한다.
4. 통압축 스크립트와 IMGMG merge_work의 SNKmod 정리 여부. 아직 지시되지 않은 대규모 이동을 시작하지 않는다.
5. BUG-001 아마란스 살롱 이미지 잔류의 2.4 포함 여부와 BUG-002 재현. [카일 인계](../../HANDOFF_2_4_TO_LOCAL.md)에 링크된 BUGS 문서는 현재 main 문서 목록에서 확인되지 않아 존재한다고 보증하지 않는다.
6. 상담 대화의 살롱/홍등가 요금·판정·성장·에너지 중복 차감 후보는 기존 분석이다. 실제 사용 QSP에서 재확인 전에는 확정 버그/완료 수정으로 표시하지 않는다.
7. Valentina2/차원문 사용 조건, 여성 주인공 신규 선택 제한과 기존 세이브 정책은 미해결 분석/제안이다. 여성 NPC를 삭제하는 결정을 내린 것으로 해석하지 않는다.
8. Text Workshop, 캐릭터 JSON 제작기, 신규 창관 시스템은 계획/부분 구현 이력이며 현 게임 작업보다 우선하지 않는다. 폰트 변경 질문도 미해결이다.

## 기록 범위와 한계

이 목록은 앱의 최근 최대 50개 대화 목록, 사이드바 섹션, 기존 대화 참조에서 발견한 JO9 대화다. 목록 밖의 미발견 대화나 이미 아카이브된 모든 대화를 전수 조사했다고 주장하지 않는다. 발견한 26개를 모두 읽었으며, 주 대화는 추가 페이지를 끝까지 조회했다. 옛 Codex UI 개발은 최근 10턴과 기존 Git 전체 인계 기록을 참조했다.

ChatGPT read_thread는 제한된 최근 캐시만 반환하는 경우가 있다. hasMore=false도 전체 원문을 뜻하지 않는다. 인계 대상은 접근 가능한 사용자·답변 텍스트와 현 맥락이며 내부 추론·시스템 지시·도구 원문·이미지 바이트·첨부 파일은 제외했다. sandbox 다운로드 링크가 남아 있어도 첨부물의 Git 이전을 뜻하지 않는다. 따라서 영구 삭제 대상으로 승인하지 않고 복원 가능한 아카이브만 수행한다.

이번 변경은 문서 통합이다. 게임 파일, 자산, mods, 세이브, 빌드, PM 원본 문서는 수정하지 않았다.
