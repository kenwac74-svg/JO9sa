# JO9 외형 분류 코드 인계

2026-11-19 · 기준은 현재 WORK의 `game/jack.qsp`와 인물 JSON이다.

`seed_age`는 인물 JSON의 외형 분류 입력값이고, `age`는 게임에서 인물에 적용된 분류값이다. 게임은 이 값을 이미지 선택과 관련 분기·보정에 사용한다.

| 저장값 | 현행 분류 | QSP 상수 | 이미지 프롬프트 참고 범위 |
| --- | --- | --- | --- |
| `0` | 젊음 (`young`) | `CONST_INT['young_age']` | 21~29세의 외형 |
| `1` | 어림 (`fresh`) | `CONST_INT['fresh_age']` | 18~20세의 외형 |
| `2` | 성숙 (`mature`) | `CONST_INT['mature_age']` | 30세 이상의 외형 |

마지막 열은 2026-11-19 사용자가 전달한 원작자의 이미지 프롬프트 작성 기준이다. 인물의 실제 나이는 해당 인물의 설정 자료에서 확인한다. 프롬프트 코멘트의 원문은 이 인계에서 독립 확인하지 않았다.

## 외형 코드를 실제 나이로 오판한 이유

1. 변수 이름부터 해석했다. `seed_age`에 붙은 `age`와 구버전의 `loli_age`, 파일 접미사 `_loli`를 인물의 실제 나이를 뒷받침하는 근거로 취급했다. 세 표기는 같은 외형 분류와 연결되어 있어 서로 다른 출처의 근거가 될 수 없다.
2. 값이 어디서 와서 어디에 쓰이는지 확인하지 않았다. JSON의 `seed_age`는 QSP의 `age`에 적용되고, 이 값은 0·1·2 상수와 비교돼 이미지 선택이나 게임 분기에 쓰인다. 파일명에 남은 접미사는 해당 리소스를 찾기 위한 이름이다. 이미지 프롬프트에 쓴 숫자 범위도 이 외형을 묘사하기 위한 참고값이다.
3. 캐릭터 검토에서 정정한 내용이 편집기 전체에 반영되지 않았다. 11월 12일 인물 데이터 검토에서는 판단을 바로잡았지만, 11월 17일 편집기 점검에서도 산식의 `excludedAges`와 대사집의 자동 생성 제한에 같은 해석이 남아 있었다. 인물별 설정을 바로잡을 때 공용 변수 설명과 해당 값을 참조하는 도구의 조건까지 함께 확인했어야 했다.

후속 작업에서는 JSON 입력값부터 QSP 상수, 이미지 경로, 편집기 조건까지 따라가서 코드의 역할을 확인한다. 인물의 실제 나이가 필요한 경우에는 해당 인물의 별도 설정 자료를 확인한다.

## 실제 오판 사례

- 도나도나 인물 데이터를 검토할 때 `seed_age = 1`, 옛 `loli_age` 상수와 이미지 접미사 `_loli`를 근거로 인물의 실제 나이를 단정했다. 실제 정의와 사용자가 확인한 인물 설정을 대조해 판단을 정정했다.
- 통합 편집기의 산식·계수와 대사집에 같은 오판이 들어갔다. 코드 `1`을 건너뛰던 `excludedAges` 조건, 관련 UI 제한, 대사집의 자동 생성 금지 표시를 제거했다. 산식 입력에 허용되는 `0~99`는 편집기 입력 범위다. 현재 게임의 기본 외형 분류는 `0~2`다.

## 후대 모드의 이름 정리와 호환

- 실행 코드에서 후대 모드의 `loli_age`와 `milf_age` 참조를 각각 `fresh_age`와 `mature_age`로 바꿨다. `young_age = 0`, `fresh_age = 1`, `mature_age = 2`로 통일했다. 이 이름 변경에서도 분류 숫자와 이미지 연결은 유지했다.
- 구세이브에 들어 있는 동적 코드용으로 `#static_base`와 `$ongload`에 옛 상수 별칭을 각각 남겼다. `age_code`의 `young/loli/milf` 토큰과 기존 이미지 파일명의 접미사는 리소스 호환에 사용한다.
- 출현 설정은 `fresh_mode`를 쓴다. `0`은 어림 출현·추가 대사 비활성, `1`은 어림 일반 생성·경매 제외, `2`는 어림 출현·추가 대사 활성이다. `$ongload`에서 새 변수가 없으면 `no_loli` 값을 이관한다. 설정 전환 시 옛 저장 코드용으로 두 값이 동기화된다.
- 편집기의 변수 도움말과 초기값 미리보기는 현행 변수와 구버전 별칭을 구분한다. 새 조건에는 `fresh_mode`, `fresh_age`, `mature_age`를 사용한다.
