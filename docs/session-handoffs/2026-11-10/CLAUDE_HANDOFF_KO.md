### 3-4. 안개 경계 탐색 (외근, 변동성 큰 업무)

## 11. 다음 세션이 조심할 것 (QSP 함정)
- `$result=''` 로 먼저 비운 뒤 숫자 `func`/`dyneval` 을 쓰면 **문자열이 반환**된다(하지 말 것).
- 주석에 작은따옴표(`'`)를 쓰면 따옴표 균형이 깨진다. `! ...` 주석에서 쓰지 않는다.
- `add_locations` 는 `actions: []` 필요, 본문은 **CRLF**. 여러 줄 `if` 에는 콜론 누락 주의.
- `*p '<script src=...>'` 는 화면마다 다시 출력해야 한다. `_layout` 은 대부분의 화면에서 실행된다.
- 엔진 오브젝트(`addobj`)는 `a[href^="obj:"]` 로 렌더되고 `$selobj` 가 공통 처리한다. `msg` 팝업은 쪽 이동과 충돌해 장부 뷰어로 대체했다.
- 개인실 부상은 **밤 회복 뒤** 적용해야 하룻밤에 낫지 않는다(`injure` 액션).
- 처녀 값: 0 처녀 / 1 가짜 처녀 / 2 뻑뻑한 / 3 잘 젖는 / 4 최고(명기). `pregnant_revealed` 는 2도 유효(`>0`로 판단).
- 개인실 임시 테스트 세이브(p01~p05)는 사용자 개인 파일이다. 읽기만 하고 덮어쓰지 않는다.

- 커밋·푸시는 사용자가 요청할 때만. WORK 전용 동기화(Full 자동 동기화 금지).
- 밸런스는 사용자와 먼저 상의한다("너무 밸붕을 원하진 않는다").
- 이미지는 사용자가 GPT로 제작하며 Claude는 파일명과 프롬프트만 제공한다.
- 이미지 추가 도구의 모든 작업은 로컬 통합 로그(일자·시각 포함)에 남아야 한다.
