# 사용자 지침 정리 — 2026-10-11

이 문서는 현재 대화에서 확정한 방향과 구현 결과를 구분해 인계한다. 게임 설정은 QSP의 실제 대사·분기를 읽어 확인하며 추측을 원작 설정으로 기록하지 않는다. 기존 결정은 SESSION_HANDOFF_INDEX에서 연결한 기록과 함께 읽는다.

## 작업·UI·리소스

- 기본 플레이 테스트는 사용자에게 구체적인 확인 항목을 부탁한다. 이번 이미지 정리에서는 사용자가 직접 실행 확인을 요청했으므로 그 범위에 한해 시도했다. 실행과 실제 플레이 검증을 구별하고 못 확인한 부분을 통과로 기록하지 않는다.
- UI 전면 개편은 보류한다. 현재 창 크기·화면 배분·버튼 기능과 익숙한 UX를 유지한다. 메인 이미지 795×596 및 포트레이트 기존 규격을 유지하고 표시 정보와 기존 메뉴를 누락하지 않는다. 디자인 시안 승인을 실제 설치 승인으로 간주하지 않는다.
- 여자 플레이어 주인공은 제거 예정이며 남자 주인공 기준으로 신규 내용을 설계한다. 제거 범위와 구형 저장 호환은 별도 검토하며 여성 NPC 제거를 뜻하지 않는다.
- SNKmod 폴더는 신규 리소스의 배치 기준으로 쓰지 않는다. 과거 경로를 사용하는 파일은 현재 코드 참조를 확인하기 전 임의 삭제하지 않는다.
- 미체크는 미사용이 아니다. 고정 참조 외에 동적 경로·picMax 번호 풀·저장본·JSON/CSS·새 장면전환·원본 B컷을 조사한다. 판단이 불확실하면 보존하고, 확정 파일만 JO9 밖으로 해시 확인과 복구 journal을 갖춰 옮긴다. JO9main과 플레이본은 각각 현재 자료로 확인한다.
- [2.4.0 풀팩·간소화 패치 기준](COMMUNITY_RELEASE_2_4_0.md), [실제 외부 보관 결과](UNUSED_IMAGES_ARCHIVE_20261011.md)를 따른다. 큰 이미지와 실제 게임 자료는 Git에 넣지 않고 경로·해시·작업 이력을 기록한다. API 키·토큰·세이브·백업은 커밋/배포에서 제외한다.

## 최고 권력자 엔딩 — 기획 확정, 이 커밋에서 구현하지 않음

- 기존 지역 최종 해금은 지배자를 전투로 복속시키는 것으로 가정하지 않는다. 기존에 요구한 조건에 맞춘 노예를 공급해 인정받는 육성 게임의 구조를 유지한다.
- 모든 구역 지배자에게 인정받은 뒤, 추가로 고급 노예를 뇌물로 상납해 주인공 편으로 만든다. 육성은 시간이, 구입은 돈이 든다. 노골적인 수치 대신 지배자의 취향을 대사로 암시한다.
- 새 상납 노예의 외모는 S 이상. 그 외는 각 지배자의 기존 요구와 같거나 한두 조건을 추가한다. 기존 요구의 정확한 항목은 실제 QSP를 확인하고 정한다.
- 돈 30만 스파크에서 이벤트 진입을 열지만 이후 비용·유지비·노예 조달까지 감당할 수 있는 금액으로 보지 않는다. 펠라게야 회유에는 약 5만 스파크의 선물/물건 구입을 사용한다. 가이우스의 보유금은 원작에 있다고 꾸며내지 않는다.
- 순서: 지역 지배자 회유 → 펠라게야 회유 → 경비대장 교체(선택 전투) → 가이우스 축출(전투) → 로마 최고 권력자 엔딩.
- 펠라게야의 아들을 명목상 황제로 세우고 주인공은 제국총리로 실권을 장악한다. 황제와 펠라게야의 관계·아들 설정과 명칭은 원작 대사와 대조한다.
- 레가트는 현존 최강 몬스터의 약 2배 전투력. 기간 내 노예 상납으로 중독시키면 최강 몬스터 수준으로 약화한다. 기한 내 상납 실패 시 강제 전투가 발생한다. 기한·중독 조건·수치는 아직 구현하지 않았다.
- 경비대장을 주인공 또는 무력 노예 하나가 이기면 해당 노예가 경비대장을 대체하는 흐름을 검토한다. 교체 성공 시 마지막은 가이우스만, 미교체 시 가이우스와 경비대장이 함께 나온다. 가이우스는 현존 최강 몬스터 수준으로 잡는다.

위 항목은 사용자 기획을 인계한 것이며 현재 QSP에 엔딩/전투가 적용됐다는 의미가 아니다. 실제 구현 전에 기존 퀘스트·전투 처리·저장 상태를 읽고 별도의 mods와 검증을 만든다.

## 추가 컷·SNKmod 폐기 — 사용자 추가 확정

기존 B컷은 유지하고 bishop_nerilis·kerulis_veil·magister_gilmeritus의 구버전 그림은 C컷, Manhunter는 빈 B컷에 넣는다. 버전 번호 없는 사본과 체크리스트/전환 연결을 유지한다. SNKmod 리소스를 실제 용도별 정규 위치로 이전하고 참조를 고친 뒤 빈 폴더를 없앤다. 새 패치 안내에 설치 완료 후 구버전 SNKmod 삭제 권고를 포함한다. [실제 적용과 검증](SNKMOD_RELOCATION_20261011.md).
