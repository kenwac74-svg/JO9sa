이 표는 r4에 추가할 변경분 **QSP 1개, PNG 17개, 캐릭터 JSON 2개**다. 도서관 아이콘과 캐릭터 파일은 r4 ZIP의 항목과 실제 플레이 폴더를 대조했다. 정식 누적 ZIP을 조립할 때는 본편 기준의 기존 필수 파일도 유지한다.

이미지 패치리스트에서 11월 7일 자동 적용 이력은 0건이었지만, 별도 캐릭터 도구로 저장된 펠라게야 PNG 4개와 JSON이 실제 폴더에 있었다. 11월 6일 시루 도미나 복장 교체도 실제 파일로 확인했다. 같은 날 기록된 `characters/fabrika (2).png`는 B컷 파일이며 현재 게임 호출 연결은 확인되지 않았다. 비밀서고 배경은 해금 이벤트가 보류된 상태다. 이 둘은 게임 필수 배포 목록과 분리한다.

페넬로페의 기존 문의 대사는 상담 기록을 저장하지 않았다. 이미 문의한 세이브는 업데이트 후 한 번 다시 묻거나 거래를 제안하면 목표에 나타난다. FastQSP 격리 시험에서 번역과 목표 표시, 구매 대기 중 숨김, 페이지 이동과 이전 페이지로의 복귀를 확인했다.

### 3차 누적 패치 재대조

- 길드 판매 경매의 출품·진행·반복 입찰·낙찰, 시장 구매 경매의 잡파 진행·매물 소개·입찰 반응·낙찰, 잡파 직접매입·위탁 판매 대사를 각각 확인했다. 같은 입찰자의 반복 대사에 변화를 주는 규칙은 길드 판매 경매에 적용한다. 미반영 특수 구매 대사안은 보류 상태다.
- r4 대비 게임 JSON 전체에서 바뀐 것은 시루의 설정 및 전용 대사와 펠라게야의 복장 경로 두 건이다. 추가·삭제·파일명 변경은 없다. 3차 ZIP 안의 JSON 전체가 플레이 폴더와 일치한다.
- 파브리카 대체 컷은 초기 점검 뒤 QSP에 연결됐으며, 빌헬미네 전신·초상과 함께 3차 ZIP에 포함했다. 이미지 패치리스트에서 파브리카 대체 컷과 빌헬미네 이미지가 각각 완료다. 빌헬미네 초상은 최종 플레이 폴더 파일을 묶었으며, 캐릭터 단위 상태는 작업 예정이다. 비밀서고는 여전히 보류한다.
- 시루와 펠라게야는 알몸·비서·하녀·도미나 외형의 JSON 연결과 실제 이미지를 모두 확인했다. 이미지 체크리스트에서 두 캐릭터를 완료로 갱신했다. 시루의 전용 등장 경로와 과거 이야기도 배포본에 있다.
- 3차 r2는 기존 보유 시루도 저장을 불러올 때 정액 중독을 적용해 표시한다. 재적용 방지 기록과 카오틱 에센스 치료 기록을 보존하며, 노예·조수 정보창의 즉시 갱신까지 네이티브 검사했다.
