# 이미지 무작위 선택 규칙 (모딩 기준)

게임이 장면 이미지를 무작위로 고르는 방식이다. 새 이미지를 넣거나 장면 이미지 mod를 만들 때 이 규칙을 따른다. 근거는 현재 게임 qsp(`G:\somi\JO9\game\jack.qsp`)의 `display_pic` location과 각 장면 코드다(2026-10-04 확인).

## 1. 번호 규칙과 `picMax`

- 같은 계열의 그림은 **기본 이름 하나 + `_2`, `_3`, …** 으로 둔다. 1번은 번호를 붙이지 않는다.
  - 예: `scene\master_cooking.png`(1번), `master_cooking_2.png`, `master_cooking_3.png`
  - `display_pic` 끝부분: 번호가 1이면 그대로, 2 이상이면 `'_' + 번호`를 붙인다(`_1`은 쓰지 않음, `_10`과 헷갈리지 않게).
- 계열의 그림 개수는 `picMax['계열 이름']`으로 읽는다. **qsp에는 `picMax`에 값을 넣는 코드가 없다.** 엔진(`jack.exe`)이 시작할 때 `content\pic`를 읽어 채우는 것으로 보인다(추정). 따라서 같은 규칙으로 파일을 추가하면 **QSP를 고치지 않아도 바로 무작위 후보에 들어간다**.
- 키에는 폴더가 들어가지 않는다(예: `picMax['master_cooking']`, `picMax['sex_black_long_young']`). 폴더는 부르는 쪽 코드가 앞에 붙인다.
- 엔진이 "파일 개수"를 세는지 "가장 큰 번호"를 쓰는지는 확인하지 못했다. 지금 게임에는 번호가 빈 계열이 16개(예: `wash_blond_long_young_alyce` 1,2,5…), 기본 파일 없이 `_2`부터 시작하는 계열이 5개(예: `glad_mistress`) 있다. **새로 넣을 때는 빈 번호 없이 이어서** 붙인다. 빈 번호가 문제를 일으키는지는 게임에서 확인이 필요하다.

## 2. 단순 무작위 (장면 코드에서 직접)

```qsp
$bg_path = 'scene\master_cooking'
g = rand(1, picMax['master_cooking'])
if g > 1: $bg_path += '_' + $str(g)
```
요리, 청소, 서비스(`$service_picture`, 예: `service_tattoo_fiend`) 등이 이 방식이다. 그림을 늘리려면 번호 파일만 추가한다.

## 3. `display_pic` (성인 장면 등 인물에 따라 고르는 그림)

호출: `func('display_pic', '배우[, 상대]', '행위', '폴더/'[, 'any_age' 또는 제외할 번호])`. 예: `func('display_pic', 'slave', 'tentacles', 'girls/sex_scenes/')`

1. **인물 특성 → 이름 조각**: `머리색_길이_나이`(예: `black_long_young`). 나이는 `$age[...]`(loli/young/milf). 일반 풀은 `general_나이`.
2. **고유씬 우선**: 인물에 고유씬 태그(`$..._scene_tag`)가 있고 `행위_특성+태그` 그림이 있으면 그 풀만 쓴다.
3. **혼자 나오는 장면**: 특정 풀 `행위_머리색_길이_나이`와 일반 풀 `행위_general_나이` 중에서 고른다. 둘 다 있으면 개수 비율로 정하는데, 특정 풀이 조금 더 잘 나오게 보정돼 있다.
4. **둘이 나오는 장면**: 이름을 `A~B`로 잇는다(예: `lesbo_black_long_young~blond_short_milf`). 다음 순서로 있는 풀을 특정 풀로 쓴다: 둘 다 특정(`A특정~B특정`) → 주인공 특정 + 상대 일반 → 상대 특정 + 주인공 일반. 나머지 중 하나를 일반 풀로 무작위로 고른다. `A~B`와 `B~A`가 둘 다 있으면 반반이다.
5. **배우 유형 전용 폴더**: 상대가 없고 `picMax['배우유형_행위']`가 있으면 `girls/sex_scenes/<배우유형>/배우유형_행위`를 쓴다.
6. **`any_age`**: 나이 조각을 빼고 머리만 맞춘다.
7. **반복 방지**: 같은 풀에서 직전 번호(`last_pic[풀]`)나 호출 때 넘긴 번호는 다시 고르지 않는다(그림이 2장 이상일 때).

결과 경로: `폴더 + 풀 이름 [+ '_' + 번호]`. 확장자는 엔진이 찾는다(`.png`가 대부분, `.gif`도 있음).

## 4. 모딩에 반영하는 법

- **같은 장면에 그림을 더 넣을 때**: 같은 계열 이름으로 다음 번호를 붙여 넣는다. QSP 수정은 필요 없다. 예: `sex_black_long_young_64.png`.
- **인물 조건별로 다른 그림**: 파일 이름의 `머리색_길이_나이`를 맞춘다. 조건이 맞는 특정 풀이 없으면 `general_나이` 풀이 쓰인다.
- **새 장면 시퀀스(mod로 경로를 바꾸는 경우)**: 지금 홍등가 mod들은 `rand(1, 2)`로 변형을 고르고 경로를 직접 적는다. 변형이 늘어날 것 같으면 `picMax`를 쓰는 방식이 낫다. 예: `whore_redlight_bj` 계열을 번호로 두고 `g = rand(1, picMax['whore_redlight_bj'])`. 이렇게 하면 그림만 추가하면 된다.
- **같은 이름이 여러 폴더에 있으면** 키가 겹칠 수 있다(현재 3,052개 계열이 여러 폴더에 같은 이름. 대부분 `girls\face`·`girls\full`의 번호 없는 그림이라 무작위와는 무관). 번호 계열을 새로 만들 때는 다른 폴더와 이름이 겹치지 않게 한다(추정에 따른 주의).
- 이미지 교체 팩(QSP 없음)에서도 1~3의 규칙은 그대로라서, 번호 파일을 추가하면 원본 QSP에서도 후보가 늘어난다(엔진이 `picMax`를 채운다는 추정이 맞는 경우).
