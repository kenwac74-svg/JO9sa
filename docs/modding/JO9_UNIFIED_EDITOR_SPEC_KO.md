# JO9 통합 모딩 편집기 — 개발 목표 및 1차 범위

사용자 확정: 2026-11-15. 상태: 사이드바·기존 도구 연결은 사용자 승인으로 구현. 이후 기능 설계는 협의 중이다. [구현·확인 기록](../../records/sidebar-integration-20261115/REPORT_KO.md).

## 최상위 개발 목표

> AI의 판단이 개입하지 않는 자유로운 창작툴

이 목표를 기능 설계·구현·검토의 기준으로 삼는다. 사용자가 대사·코드·변수·조건·이미지를 직접 정의하고 편집하며, 내용의 채택·수정·적용 여부를 결정한다.

- 핵심 편집 경로에 AI 호출·내용 분류·AI 승인을 필수 단계로 두지 않는다. AI를 연결하지 않아도 소스 불러오기, 검색·비교, 사용자 정의 목록 편집, 변경안 작성·저장·선택 반영·되돌리기를 수행할 수 있어야 한다.
- AI가 사용자 원문을 임의로 고치거나 선택지를 숨기고, 조건·변수·결과를 자동으로 덧붙이지 않는다.
- 프로그램의 기계적 진단은 문법·자료형·파일 경로·연결 충돌 등 기술적 사항을 다루며 위치와 근거를 표시한다. 창작 내용의 채택 판단과 구분한다.
- AI는 사용자가 필요할 때 요청하는 보조 수단이다. 현재 우측 대화창에서 코드 해석·수정안을 상의하고, 사용자가 선택한 변경을 반영한다. 별도 AI 자동 판단 기능은 현재 범위에 넣지 않는다.

## 1차 범위 — JO9 자유 편집

- 클로드 캐릭터 편집기의 디자인을 공통 틀로 사용하고 익숙한 기존 도구 화면을 유지한다.
- 기존 대사 편집과 이전 QSP·JSON·구글시트 소스 비교를 함께 지원한다. 사용자가 고정한 편집 대상과 체크한 변경을 유지한다.
- 게임 DB의 변수 사전에서 기존·사용자 정의 변수의 이름, 자료형, 값, 표시명, 툴팁과 드롭다운·조건 태그 구성을 직접 편집할 수 있게 한다. 확인하지 못한 변수 의미를 확정된 사실로 만들지 않는다.
- 선택지에 새 값을 등록하는 것과 그 값의 실제 게임 처리 코드를 연결하는 것을 구분하고, 사용자가 둘 다 편집할 수 있게 한다.
- 캐릭터·대사·이미지·게임 DB·작업 일정의 통합을 설계한다. HTML 카탈로그·비교표·릴리즈노트 등은 기타 산출물에 묶는다. 사운드는 기존 지시대로 목록을 제공한다.
- 원본·사용자 수동 편집·기존 저장 자료를 보존하고 변경 미리보기와 선택 반영·되돌리기를 제공한다.

## 2차 범위 — 보류

QSP 기반 새 게임 제작, 새 게임 골격·시작 로케이션·일반 프로젝트 빌드 등은 2차 스펙이다. 1차를 이 기능들 때문에 확대하지 않는다.

## 2026-11-15 구현 범위

클로드 편집기 디자인을 유지한 사이드바, 기존 모드툴 프레임, 맨 아래 HTML 기타 산출물 목록, 브라우저/전용 앱 실행을 연결했다. 기존 산식·연령 코드·대사·캐릭터 편집 기능은 수정하지 않았다. QSP/JSON/구글시트 비교와 사용자 변수·드롭다운 정의, 범용 DB 구조, 새 게임 제작은 이 단계에서 구현하지 않는다.
