# 대사 서식·주인공 지칭 기준

2026-10-09 사용자 확정. 새 대사 작성과 기존 대사 수정에도 적용한다.

- 문장 시작의 대화 표시용 `-`는 제거한다. 문장 중간의 대시, 음수, 코드·메뉴의 `[-]`는 그대로 둔다.
- 장소에 방문해 NPC가 말하는 대사는 `[NPC 이름]<br>&nbsp;대사`로 표시한다. 이름과 대사 사이에 줄바꿈을 한 번 넣고, 대사 첫 줄만 HTML의 실제 한 칸 공백으로 들여쓴다. 이름 앞에는 들여쓰기를 넣지 않는다.
- 문자열 내부에 들어간 불필요한 실제 줄바꿈·탭·중복 공백은 한 공백으로 접는다. 화면 폭에 따른 자동 줄바꿈, 의도된 HTML 문단 구분, 노랫말·표·UI 정렬은 보존한다.
- 내레이션에서 주인공을 가리키는 `너는`·`넌`은 `당신은`으로 쓴다. **다른 인물을 가리킬 때는 기존 표현을 유지한다**(사용자 추가 확인).
- `[당신]` 또는 `[<<$master_name>>]` 화자의 말, 조수·노예에게 하는 발화, NPC끼리의 대화는 대상을 확인한다. 한 문자열 안에서도 화자가 달라질 수 있으므로 문자열 전체를 일괄 호칭 치환하지 않는다.
- 변수·조건문·치환문 `<<...>>`·HTML 속성·이미지 경로·서식 강조는 이 정리 과정에서 변경하지 않는다. `건넌`, `파트너는`, `넌지시` 등 단어 일부를 대명사로 판단하지 않는다.

## 이번 적용

현재 플레이 QSP를 직접 기준으로 삼아 표시 문자열 6,674개를 정리했다. 머리 대시 5,430곳을 제거했고 주인공 호칭 438곳을 통일했다. 순정 폴더는 변경하지 않았다.

모드 기록: `mods/2026-10-09_dialogue_format_and_protagonist.json`. 준비 도구는 `tools/prepare-dialogue-normalization.cjs`이며, 게임에 직접 쓰지 않고 후보·모드·검증 결과를 만든다. 입력은 `--input`, 출력은 `--out`으로 지정한다. 다른 PC에서는 해당 저장소의 `tools/text-workshop/core.cjs`를 사용한다.

검증: 바이트 왕복, location 순서·개수, 문자열 수·따옴표, 실행 코드, 비줄바꿈 HTML 태그·치환문 보존, 후보 전체 재정리 시 무변경, 공식 모드 적용 결과와 후보의 동일성. 게임 실행과 화면 확인은 사용자가 한다.

연령 조건에 걸린 대사와 미성년 성적 내용이 포함될 수 있는 문맥은 자동 정리에서 제외했다. 해석할 수 없는 특수 마크업 한 항목도 보존했다. 이 항목들의 원문은 보고서에 복제하지 않는다.
