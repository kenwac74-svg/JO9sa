#### 2604와 2618의 관계 추가 대조

사용자는 2604가 원래 소냐 정의이고 2618이 이를 재사용한 것으로 추정했다. 두 JSON을 대조하면 공통 값 169개가 일치하며, 다른 키는 9개다. 2604의 러시아어 이름 `Соня`와 인물 설명 6개가 2618에서는 영문 `Sonya`와 같은 내용의 영어 설명으로 되어 있다. 나머지 차이는 전신 경로와 2618에만 있는 `seed_alchemy = 5`다. 얼굴 3종과 그 밖의 공통 능력치·외형 값은 같다. 따라서 번역·복제 관계일 가능성은 높지만, 생성 순서까지 입증한 것은 아니다.

현재 QSP에서 직접 확인되는 소냐 획득은 `interaction_city = 9222`의 바이커 추가 옵션 보상이며, `special_stock = 2618` → `generate_stock` → `stock_to_slave_nogt` 흐름이다. `source/jack_2026-10-01.qsp`에도 같은 분기에서 2618을 사용한다. 2604를 캐릭터 타입으로 직접 지정하는 QSP 코드는 두 버전에서 찾지 못했다. 이는 직접 획득 경로의 조사 결과이며, 범용 JSON 로드·생성 경로까지 2604를 사용하지 않는다는 증명은 아니다.

관계 조사 당시 결론: **2604는 구형 소냐 정의, 2618은 그 번역·수정본일 가능성이 있으며, 실제 확인된 획득용 ID는 2618이다.** `Sonya_black_long.png`를 2618 소유의 그림이라고 단정하지 않는다. 원형의 역사적 순서는 미확정이다. 이 초기 대조 단계에서는 파일을 바꾸거나 두 ID를 통합하지 않았고, 이후 위에 기록한 별도 감사·승인으로 2604만 삭제했다. QSP 추출 근거는 `tmp/girls-audit-20261026/sonya-qsp-evidence.txt`에 별도 기록한다.

일반 무작위 생성 여부 추가 확인: **2604와 2618 모두 기본 무작위 생성 대상이 아니다.** 현재 `slave_index.json`의 기본 범위는 1–247 / 1001–1449 / 2001–2323이며 두 ID는 모두 범위 밖이다. `generate_stock`은 `special_stock`이 있으면 지정 ID를 쓰고, 없으면 이 세 범위에서만 추첨한다. 2618은 바이커 이벤트가 `special_stock = 2618`로 지정하여 생성한다. 2604는 기본 무작위 범위에도 없고 캐릭터 획득 직접 참조도 발견하지 못했으므로 잔존 정의 가능성이 있으나, 외부·수동 로드나 기존 저장 객체까지 미사용이라고 확정한 것은 아니다. 현재 QSP 해시가 조사 근거와 동일함을 재검증했다.
