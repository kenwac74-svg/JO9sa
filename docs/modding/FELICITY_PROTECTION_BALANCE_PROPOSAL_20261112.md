# 펠리시티 보호 분기 — 커맨드 성장·불안 회복 수치 제안

2026-11-12 KST · 사용자 검토용 · 게임 미적용

**최신 결정에 따른 상태 정정:** 사용자는 느린 회복 예외 대신 초기 절망을 높이고 원작 자연 회복을 사용하는 방향을 선택했다. 각성 절망은 보통·하드 4, 이지는 기존 상한 3으로 정리한다. 아래 절망 2·느린 회복 계산은 과거 시안이며, 현재안의 검증 결과가 아니다. 방치 가중치와 270일 달성일은 다시 계산해야 한다. 커맨드별 성장량과 일일 상한은 아직 제안 상태다.

## 확정 조건과 계산 범위

- 영입 후 270일 종료, 초기 10일의 인지·각성 과정을 포함하여 성장 구간은 약 260일로 계산했다.
- 각성: 헌신 1, 사육 0, 습관 0, 두려움 3, 절망 2, 인식 4, 응석 0.
- 해피엔딩: 헌신 5 / 절망 0 / 두려움 2 이하 / 사육 2 이상 / 습관 3 이상을 마지막 날 동시에 충족. 보호 실패 시 엔딩 대상에서 제외.
- 응석 상승 차단, 원본 성격·자아·지성·태도·순종 보정 유지, 비성적 교육과 생활만 허용. 신체적 위해·성적 행위는 실패.
- 이지의 기존 절망 상한 3은 유지한다.
- 아래는 이 조건을 만족시키는 **보호 분기 전용 총효과 시안**이다. 기존 효과에 그대로 더하는 추가 보너스가 아니다. 같은 상태값에 원작 보너스와 신규 보너스가 이중 적용되지 않게 해야 한다.
- 원래 기분·관계·기술 경험치·행동력·비용 효과를 전부 삭제하자는 제안은 아니다. 헌신·사육·습관과 두려움·절망에 대해서만 기존 중복 경로를 찾아 분기 전용 결과와 조정한다.

## 1. 커맨드별 성장 시안

숫자는 등급 상승이 아니라 기존 ‘단계’에 쌓는 누적값이다. 성공적으로 수행한 활동만 인정하며 같은 커맨드의 당일 반복은 성장·돌봄 점수를 추가하지 않는다.

| 활동 | 헌신 | 사육 | 습관 | 돌봄 점수 | 직접 교류 |
|---|---:|---:|---:|---:|---|
| 일반적인 대화 | +1 | 0 | 0 | 2 | O |
| 격려 | +1 | 0 | 0 | 2 | O |
| 함께 외출·해변 나들이·조수와 함께 외식 | +2 | 0 | +1 | 3 | O |
| 여가시간 부여 | +1 | 0 | +1 | 1 | X |
| 비성적 선물 | +1 | 0 | 0 | 1 | X |
| 조수와 함께 집안일 | +1 | +1 | +2 | 2 | O |
| 조수와 안전한 체조 | +1 | +1 | +1 | 2 | O |
| 직접 또는 조수의 비성적 개인교습 | +1 | +1 | +2 | 2 | O |
| 관용 교육 | +1 | 0 | +1 | 2 | O |
| 잘못을 용서함 | +1 | 0 | 0 | 2 | O |
| 언어적 위협 | 0 | +1 | 0 | 0 | 돌봄으로 미인정 |
| 정당한 훈계 | 0 | +1 | +1 | 0 | 돌봄으로 미인정 |
| 식사 준비 규칙 실제 수행 | 0 | +1 | +1 | 0 | X |
| 청소 규칙 실제 수행 | 0 | +1 | +1 | 0 | X |
| 개인침대 또는 개인실에서 충분히 휴식 | 0 | 0 | +1 | 0 | X |
| 정상적인 식사 제공·남은 음식 식단 | 0 | 0 | 0 | 0 | X |

- 일일 성장 상한: **헌신 +2 / 사육 +2 / 습관 +3**. 예를 들어 외출 + 격려가 헌신 +3을 제안하더라도 그날은 +2만 쌓는다.
- 외출 계열은 하루 한 종류만, 개인교습 계열은 하루 최초 성공 한 번만 관계 성장 보상을 준다. 기술 교육 자체의 경험치와 횟수는 별도다.
- 개인침대와 개인실 휴식을 겹쳐 계산하지 않는다. 원작 수면의 습관 보너스와도 중복하지 않는다.
- ‘관용 교육’과 ‘잘못 용서’는 서로 다른 명령이다. 실제 연결 메뉴를 확인한 뒤 있는 명령에만 적용한다. 죄책감 조작이나 일부러 잘못을 유도하는 반복 보상은 만들지 않는다.
- 위협과 훈계는 당일 한 번, 실제 효과가 있거나 실제 잘못에 대응했을 때만 성장시킨다. 원작의 무제한 반항·기분·공포 효과를 겹치지 않도록 검토한다.
- 위협의 부작용 시안: 두려움 누적 +2, 절망 누적 +1. 훈계의 부작용 시안: 두려움 누적 +1. 이 값 역시 미승인이다. 위협만 반복하면 헌신이 자라지 않고 불안이 커져 해피엔딩을 얻지 못한다.
- 반투명·성적 의상 등 부적절한 선물과 장면은 허용 목록에 포함하지 않는다. ‘데이트’라는 기존 메뉴도 실제 장면을 비성적 보호자 동반 나들이로 확인해야 한다.

## 2. 두려움·절망 회복 방식

커맨드 즉시 회복량은 **모두 0**으로 제안한다. 활동은 돌봄 점수를 만들며 그날의 전체 교류를 하루 종료에 평가한다.

**충분한 돌봄을 제공한 날:** 돌봄 점수 2 이상이면서 직접 교류 활동이 최소 한 번 성공한 날이다. 선물·여가·식사·잠자리만으로는 직접 교류를 대체할 수 없다. 대화 또는 격려 한 번은 직접 교류 기준을 충족하지만, 그것만 매일 하면 성장량이 모자라 해피엔딩 조건 전체를 만족하지는 못한다.

| 연속으로 충분한 돌봄을 제공한 기간 | 그날의 방치 불안 증가 | 두려움 회복 | 절망 회복 |
|---|---:|---:|---:|
| 첫날~2일째 | 억제 | 0 | 0 |
| 3~6일째 | 억제 | 누적 -1 | 누적 -1 |
| 7일째부터 | 억제 | 누적 -2 | 누적 -1 |

- 이미 쌓인 불안 누적값과 등급은 첫날의 활동으로 초기화하지 않는다.
- 연속 3일째부터 기존 방치 부담을 하루 1일분씩 완화한다. 예를 들어 20일 방치 뒤 하루 잘해 줘도 방치 부담은 그대로이며, 3일 연속 돌본 뒤에야 19일로 줄어든다.
- 돌봄이 부족한 날에는 연속 돌봄 기록을 끊고, 남아 있는 방치 부담에 하루를 더하여 방치 가중치를 적용한다. 미완료·거절·취소는 활동으로 세지 않는다.
- 두려움·절망 회복은 별도 회복 포인트가 아니라 기존 단계 누적값에 적용한다. 등급이 바뀌는 것은 누적 기준에 도달했을 때뿐이다.
- 위협·훈계를 함께 했다면 그날의 부작용과 회복량을 합산한다. 회복 수치만 따로 표시해 부작용을 숨기지 않는다.
- 기존의 ‘헌신이 높으면 두려움 등급을 바로 감소’ 및 빠른 절망 자연 회복은 이 보호 대상에게 그대로 중복 적용하지 않는 방안을 제안한다. 다른 인물의 원래 규칙은 보존한다.
- 원작 절망이 성격·자아를 자동으로 깎는 효과도 보호 분기에서는 제외하는 안이 필요하다. 사용자에게 승인받기 전 구현하지 않는다.

## 3. 방치 가중치

| 누적 방치 부담 | 하루 두려움 증가 | 하루 절망 증가 |
|---|---:|---:|
| 1~3일 | +1 | +1 |
| 4~7일 | +2 | +3 |
| 8~10일 | +3 | +5 |
| 11~14일 | +4 | +8 |
| 15~21일 | +6 | +12 |
| 22일 이상 | +8 | +18 |

각성 상태의 절망 2·두려움 3, 누적값 0에서 완전히 방치하면 약 30일에 절망 5에 도달한다. 이미 절망 0까지 회복한 뒤의 재방치는 출발점이 달라 같은 30일에 정확히 5가 되는 것은 아니다. 계산에서는 마지막 30일을 방치한 경우 절망 4가 되어 해피 조건에서 탈락했다.

이지는 원래 절망 상한 3을 유지하며, 상한 초과 누적값을 숨겨 두었다가 나중에 적용하지 않는다.

## 4. 270일 안에 가능한가

각성 누적값을 0으로 맞추는 가정은 이번 제안에 포함되며 아직 사용자 승인을 받지 않았다. 헌신 1→5에는 누적 300, 습관 0→3에는 70, 사육 0→2에는 30이 필요하다.

- 헌신을 일일 상한 +2로 150일 쌓으면 5가 가능하다. 각성 이후 약 260일 중 최소 150일의 유효 성장 기회를 확보해야 한다.
- 시작 절망 2→0은 누적 -20이 필요하다. 지속 돌봄의 회복이 시작되기까지 2일, 회복 20일을 합쳐 최단 22일의 관리가 필요하다.
- 시작 두려움 3→2는 누적 -20이 필요하다. 위 회복 시안에서는 지속 관리 시 14일째 2가 된다. 이는 임의로 등급을 바로 낮추는 것이 아니다.
- 초기에는 교육을 거부할 수 있으므로 외출·격려·허용된 선물·여가 등을 통한 관계 성장으로 교육 가능 구간에 진입한다. 조수 교육도 학생 거부 판정을 우회하지 않는다.

## 5. 적용 전에 합의할 핵심 제안

1. 위 커맨드별 누적값과 **헌신 +2 / 사육 +2 / 습관 +3**의 일일 상한.
2. 충분한 돌봄 기준과 **3일째부터 회복, 절망 회복은 하루 -1**이라는 느린 회복 방식.
3. 보호 대상의 기존 두려움·절망 자동 회복과 절망에 따른 성격·자아 감소를 분기 전용 방식으로 조정하는 범위. 이지 상한 3은 유지.
4. 각성 시 등급 변경과 함께 관계·불안 누적값을 0으로 정리하는 방식.

모든 수치와 처리 방식은 제안이다. 게임 데이터 복제·QSP 변경·패치 설치·커밋·푸시는 하지 않았다.
