## 기존 세이브 호환 방식

QSP의 `jo9_json_ko`는 등록된 원문과 정확히 일치하는 과거·친족 문구만 표시 시 한국어로 바꾼다. 244개의 정확한 원문 문자열이 등록되어 있다. 직접 편집한 문구, 미등록 문구, 이미 번역된 문구는 그대로 반환한다. 저장 파일과 캐릭터의 원문 변수는 쓰지 않는다.

`#dynamic`의 과거 대사 기본 반환, `interaction`의 구형 함수 캐시 갱신 조건, `origins_relations`의 관계 설명 출력만 수정했다. 기존 말투 변형은 원래 입력으로 비교하며, 관계 계산·성격·성공/거절 분기와 수치는 유지한다. 신규 location은 `jo9_json_ko` 하나다.

실행 중이던 게임은 완전히 종료하고 다시 실행한다. 실제 이전 세이브는 파일을 변환할 필요 없이 새 QSP로 불러온다.

## 다른 작업 PC에서 적용

1. 현재 게임과 저장소의 수동 편집을 보존한다. 게임을 종료한다.
2. 저장소에서 전달 브랜치를 가져온다. 기존 변경을 강제로 덮어쓰거나 `reset --hard`하지 않는다.
3. 선택 파일 명세: `records/translations/json-ko-20261102/handoff-manifest.json`.
4. 읽기 전용 사전 확인(명령의 게임 경로는 실제 PC 경로로 바꾼다):

```powershell
python tools/json-ko-20261102/sync-game.py --game '실제_작업폴더/game'
```

5. 정상 확인 후 동일 명령에 `--apply`를 붙인다. 선택한 JSON 128개와 QSP 1개만 복사한다. 이미지·세이브·다른 게임 폴더는 건드리지 않는다.

```powershell
python tools/json-ko-20261102/sync-game.py --game '실제_작업폴더/game' --apply
```

완성 소스는 `assets/json/slaves/`와 `assets/runtime/2.4.1/jack.qsp`에 있다. 도구는 기준 main 또는 앞서 적용된 이미지 경로 수정본/이미 완성된 번역본의 해시만 허용한다. 다른 해시는 수동 변경으로 보존하고 적용을 중단한다. 이때 강제 덮어쓰지 말고 차이를 검토한다. Python 3.9 이상이 필요하다.
