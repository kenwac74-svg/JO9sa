# 펠리시티 보호 분기 — 다음 구현 안건

2026-11-12 KST · 기획 확정 · 구현 대기 · 게임 미적용

사용자 지시로 이번 작업은 기획과 임시 컷신 준비에서 멈춘다. 다음 구현 시 이 문서를 시작점으로 삼는다. 아래 확정 사항을 다시 임의로 설계하거나 과거 제안으로 되돌리지 않는다.

## 확정한 흐름

- 원본 펠리시티(2572)와 스펙터 의뢰는 보존하고, 보호 분기용 인물 데이터를 별도로 만든다. 이야기 속 인물은 같은 펠리시티다.
- 영입 직후에는 원래 수치를 유지한다. 보호 실패 없이 3일이 지나면 주인공이 처한 위험을 알게 되고, 추가 7일 뒤 각성 이벤트가 발생한다.
- 영입일부터 총 270일을 관리한 뒤 엔딩을 판정한다. 기존 의뢰의 기간 종료와 보호 분기의 진행은 분리한다.
- 교육은 비성적으로만 진행한다. 언어적 질책·훈계·위협은 허용하지만 신체적 위해나 성적 행위는 보호 실패로 처리한다. 자동 활동도 점검 대상이다.
- 각성 이후 응석은 0으로 두고 상승을 차단한다. 그 외 교육·성장·두려움과 절망 회복은 기존 규칙을 최대한 사용한다. 별도 느린 회복이나 커맨드별 추가 성장 보상은 도입하지 않는다.
- 방치는 기간에 따라 두려움·절망이 가중 상승하도록 한다. 약 30일 방치 시 절망 5에 이르는 방향이며, 이지 모드의 기존 절망 상한 3은 유지한다. 구체 증가량은 아직 미정이다.

## 확정한 각성 값

| 항목 | 설정 |
|---|---|
| 특성 | 자유로운 영혼 제거, 기존 강한 복종심 낮은 단계 부여 (`meekness=1`) |
| 태도 | 3 |
| 헌신 | 3, 누적값 +60 |
| 인식 | 4 |
| 응석 | 0, 이후 상승 차단 |
| 두려움 | 3 |
| 절망 | 보통·하드 4 / 이지 3 |
| 사육·습관 | 각각 0 |
| 그 외 관계·불안 누적값 | 설계 데이터에 기록된 값 0 |
| 초기 이벤트에서 유지 | 성격·자아·지성, 나이·생식 관련 값, 신원·외형·장비·기존 기술 |

성격·자아·지성의 유지는 초기 이벤트에서의 유지이며, 이후 기존 일일 처리까지 영구 동결하라는 뜻은 아니다.

## 엔딩

- 해피: 헌신 5, 절망 0, 두려움 2 이하, 사육 2 이상, 습관 3 이상을 모두 달성한다. 펠리시티가 주인공에게 아버지가 되어 달라고 하며 비성적 가족 관계로 남는다.
- 노멀: 보호에 실패하지 않았으나 해피 조건을 충족하지 못하면 친아버지에게 돌려보내고 보상을 받는다.
- 두 엔딩 모두 스펙터와의 관계는 최악이 된다. 보호 실패는 이 두 엔딩과 별도로 처리한다.

## 다음 구현 전에 정할 사항

1. 보호 분기용 미사용 번호를 확인하고 배정한다.
2. 기존 자연 회복과 초기 절망 4를 반영하여 방치 가중치를 다시 계산한다. 과거의 느린 회복·초기 절망 2 모형은 사용하지 않는다.
3. 노멀 엔딩 보상과 최종 비성적 교육 목표를 정한다. 원본 의뢰의 보상을 임의로 재사용하지 않는다.
4. 이벤트 대사·전환·실패 이후 처리 원고를 준비한다. 새 문장에는 비표시 `<!-- #nwtx -->` 태그를 넣는다.

## 구현 및 검증 범위

- 안전한 분기 진입, 별도 인물 데이터, 3일·10일·270일 일회성 이벤트 및 저장·불러오기를 구현한다.
- 모든 관련 커맨드·자동 활동에서 실제 신체 위해와 성적 행위를 실패 처리한다. 메뉴를 열거나 취소한 것만으로 실패시키지 않는다.
- 음식·휴식·선물·보상·장비·이벤트를 포함해 각성 후 응석 상승 누락이 없는지 확인한다.
- 기존 의뢰·일반 인물·난이도별 규칙에 영향이 없는지 검사한다.
- 독립 계산은 실제 게임 270일 검증이 아니다. 교육 가능 여부, 자원·행동력, 방치와 회복, 세 엔딩 경로를 게임에서 확인해야 한다.
- 게임은 사용자가 수동 패치한다. 실행 폴더를 자동으로 덮어쓰지 않는다.
