# 개인실 메이드 임무 기획안 (초안) · 2026-11-09

사용자 지시: 개인실에 토글로 메이드에게 자동 임무를 준다. 제시한 수치는 샘플이며 밸런스는 기획자가 맞춘다. 아직 구현하지 않았고, 아래 "확인 필요"가 정해지면 구현한다.

## 1. 현재 코드에서 확인한 것

- 개인실은 4개(room1~4). 메이드 임무 뼈대(`cooks_rule`, `cleans_rule`, `jo9_household_worker`)는 코드에 남아 있고 UI만 빠져 있다. 작업자 순서는 슬레이브, 조수, room1~4다.
- 하루 종료(`next_day`)에서 요리(약 21206행)와 청소(약 21808행)를 자동 처리하고, 결과는 `roomN_auto_cook`·`roomN_auto_clean` 플래그로 하루 종료 화면에 넘긴다.
- 등급은 F(0) D C B A(4) S(5). 부상은 `wounds` 1~5단계(`wounds_rate` 누적), 기분은 `mood_rate`로 오르내린다.
- 특성 이름 확인: 역전의 용사·성기사·광전사(전투), 아레나 챔피언/그랜드 챔피언, 타고난 투사, 색정광, 정액 중독, 펠라 중독, 애널섹스 중독, 워커홀릭, 타고난 마법사, 예민한 미각. **"타고난 비서"는 게임에서 "보좌관"(secretary_affinity)이다.**
- 메모리 방침(개인실은 창관이 아니다, 매춘 메뉴 비노출)과 3번 임무가 부딪힌다. 3번은 개인실 매춘이 아니라 "사창가 골목 길거리 외근"으로 구현하고, 기존 개인실 매춘 코드(1015~1022)는 되살리지 않는다.

## 2-1. 외근 컷신 (사용자 확정 2026-11-09)

집안일을 뺀 안개 탐색·길거리·알바는 모두 **외근**이다. 외근은 하루 종일 밖에 나가 일하고 돌아오는 것으로 보며, 하루 종료 때 상황에 맞는 컷신과 대사가 나온다.

- 구성: 하루 종료 화면에 메이드별 장면 1개(그림 + 서술/대사). 집안일은 기존처럼 한 줄 보고만 쓴다.
- 장면 분기(임무마다): 평소 / 대박(특·대 수확) / 빈손 / 부상 / 휴무. 길거리는 평소 / 고수입 / 기분 상승(색정광·정액 중독) / 불쾌(부정 특성) / 휴무로 나눈다.
- 대사: 메이드의 말투·성격·특성(복종심, 거센 반항심, 노예근성 등)에 따라 변형. NPC 대사에 게임 밖 안내문은 쓰지 않는다. 시스템 정보(수입·부상)는 대사와 분리한 안내 줄로 둔다.
- 그림: 기존 장면 이미지를 우선 쓴다. 없으면 필요한 그림 목록을 따로 뽑아 사용자에게 요청한다.
- 분량 제안: 임무 3개 × 분기 5개 × 대사 변형 2~3개 = 약 30~45개 문구.
- 길거리 컷신은 개인실이 아니라 사창가 골목 길거리를 배경으로 한다.

## 2-3. 방치와 충성 (사용자 확정 2026-11-09)

"10일"은 수입 밸런스의 기준 단위일 뿐 강제 시스템이 아니다. 계속 일만 시키고 피드백이 없을 때의 결과는 **조수·슬레이브와 똑같이** 나와야 하므로 기존 "잊힌 보상(virtue)" 메커니즘을 그대로 쓴다.

기존 동작(`next_day_forgotten_rewards`, 약 22225행):
- 공을 세운 날(경주 승리·절정 등) `virtue = 5`가 된다. 칭찬·보상 상호작용이 `virtue = 0`과 `neg_no_praise = 0`으로 지운다.
- 하루 끝에 `virtue > 0`이면(칭찬받지 못함), 충성이 5(완전 헌신)가 아니고 심리 피학 성애자가 아닌 경우: 기분 rate `-virtue × 2`, 충성 < 3이면 불안 rate `+virtue`, 기분 요인 `neg_no_praise`, 이성 rate `-virtue`. 그 뒤 `virtue = 0`.
- 불안이 2를 넘거나 공포 > 4이면서 기분 < 0이면 `next_day_slave_moral`이 충성을 깎는다. 즉 방치 → 기분·불안 악화 → 충성 하락이 기존 시스템 안에서 이어진다.

임무에 적용:
- 외근이 성과를 냈을 때(수확·수입이 있었던 날, 알바·길거리 성공, 안개 탐색 성공) `roomN['virtue'] = 5`를 세운다. 빈손·휴무인 날은 세우지 않는다.
- 칭찬·보상 상호작용은 조수·슬레이브와 동일한 기존 상호작용을 그대로 쓴다(새 버튼 없음). 개인실에서 기존 칭찬이 메이드의 `virtue`를 지우는지만 확인한다.
- 임무 숙련 적성은 기존 `pos_job`(적성 > 0, 기분 상승)과 `neg_job`(적성 < 0, 기분 하락) 처리를 그대로 쓴다(타고난 하녀·예민한 미각·타고난 마법사·보좌관 등).
- 지침상 지친 상태는 기존 `neg_exhausted`가 그대로 반영된다.
- 확인 필요: 개인실 메이드가 이 하루 처리(`unfrozen_slave_characters` 목록)에 들어 있는지.

## 2-3b. 성과 단계와 공로(virtue) (사용자 확정 2026-11-09)

외근 결과를 5단계로 나누고 공로(`virtue`)를 성과에 비례해 세운다. 외근 3종 공통. 집안일은 공로를 세우지 않는다(기존 청소·요리 규칙과 같음).

| 단계 | 빈손 | 소 | 중 | 대박 | 초대박 |
|---|---:|---:|---:|---:|---:|
| 공로 | 0 | 1 | 2 | 3 | 4 |

단계별 확률과 가치(기댓값은 샘플 기준 목표에 맞춤):

| 임무 | 빈손 | 소 | 중 | 대박 | 초대박 | 하루 기댓값 |
|---|---|---|---|---|---|---:|
| 안개 탐색 확률 | 13% | 35% | 36% | 13% | 3% | 약 30 |
| 안개 탐색 스파크 | 0 | 10~18 | 22~34 | 40~60 | 50 + 아이템 | |
| 길거리 확률 | 8% | 40% | 34% | 15% | 3% | 약 24 |
| 길거리 가치 | 0 | 16~22 | 23~30 | 35~45 | 약 60 | |
| 알바 확률 | 8% | 37% | 37% | 15% | 3% | 약 31 |
| 알바 가치 | 0 | 15~25 | 28~38 | 45~60 | 100~120 | |

- 특성의 보상량 보너스(%)는 가치에 곱하고 단계 확률은 바꾸지 않는다. 안개 탐색의 부상 판정은 단계와 별개로 굴린다.
- 안개 탐색은 스파크 + 가끔 아이템(3-2), 길거리는 현금 수입, 알바는 요리·연금에 쓰는 재료 아이템(물약 500 초과 금지 하드캡)이다.
- 하루 평균 공로: 안개 1.58, 길거리 1.65, 알바 1.68.
- 칭찬을 받지 못했을 때의 하루 벌점은 공로 v에 대해 기분 rate -2v, 이성 rate -v, 충성 < 3이면 불안 rate +v. 평균 기준 하루 기분 rate 약 -3, 10일이면 약 -30이다(기분 자연 회복은 미반영).
- `virtue` 는 업무 후처리를 잊힌 보상 처리(`next_day_forgotten_rewards`) 뒤에 세워서, 다음 날 칭찬하면 지울 수 있게 한다.

## 2-3c. 행동력·기분 밸런스 (사용자 지시 2026-11-09)

### 코드에서 확인한 값
- 행동력 상한 = `min(5, 체력 + 1)`, 어려움 난이도는 `min(5, 체력)`. 체력 A(4)면 5칸(어려움 4칸), S(5)면 5칸. 행동력은 별 5칸이고 반칸 단위(`half_action`)가 있다.
- 기분 1단계 = rate 10. 매일 밤 `기분 += (기분 rate) ÷ 10`. 그리고 전날 기분 절반이 이월되고(`10 + 기분×2 + 충성 + (체력-3) - 흥분 - 공포 - 응석 - 불안×2 - 위생 - (집 어지러움-1)`), 기분 요인은 값이 100인 동안 계속 작용한다.
- 기존 청소·요리 규칙은 행동력이 0 이상이면 수행하고, 모자라면 다음 아침에 깎는다(빚). 이번 외근은 그 방식을 쓰지 않는다.

### 행동력 규칙
- 외근은 그날 남은 행동력이 필요량 이상이어야 나간다. 모자라면 **그날은 쉰다**(휴무, 기분 하락 없음, 행동력·기분은 회복 쪽으로).
- 필요량: 집안일 2, 안개·길거리·알바 3. 상한이 5칸이므로 낮에 주인이 그 메이드의 행동력을 2칸 넘게 쓰면 외근을 못 나간다. 어려움 난이도(상한 4)는 1칸 넘게 쓰면 못 나간다.
- 휴무 시 하루 종료 화면에 "기운이 없어 오늘은 쉬었다"는 짧은 안내.
- 외근 소모는 반칸 빚 없이 차감한다.
- 임무 후보가 되려는 체력 A(상한 5/4) 이상 조건과 필요량 3이 맞물려, 외근은 사실상 하루에 한 번만 가능하다.

### 기분 규칙 (rate 단위)
- 임무 기분 하락: 집안일 -10(1단계), 외근 -20(2단계) 기준. 기분 요인(`neg_outwork` 100, 외근 피로)으로 얹어 매일 작용한다.
- 기존 이월·기분 요인 합산이 있으므로 하락 자체는 하루치만 적용되고 그대로 누적되지는 않는다. 다만 기분 기본값이 낮은 메이드(불안·공포가 높은 경우)는 하락이 누적되어 0 아래로 내려간다.
- 특성 보정은 기분 단계 단위로 가감한다(-2 → -1 → 0, 상승은 +1).
- 공로 벌점(칭찬 없음)은 별도로 기분 rate `-2v`.
- 하루 기분 합계 예(기분 요인 없는 평범한 메이드, 외근 -20, 공로 평균 1.5 미칭찬 -3): 약 -2.3단계 상당. 이월·회복으로 상쇄되는지는 구현 시 시뮬레이션으로 검증한다.

### 검증 계획
구현 후 복사본에서 메이드 유형(적성 있음/없음, 충성 높음/낮음)별로 30일 시뮬레이션해 기분·충성·행동력이 무너지지 않는지 확인한다.

## 2-4. 적성 배치 (사용자 방향 2026-11-09)

기분 하락을 줄이거나 막는 특성이 있는 메이드를 알맞은 임무에 두는 쪽이 유리해야 한다. 기분이 유지되면 충성 성장도 유지되고(기분 > 0일 때만 오름), 휴무 조건(기분 최저)에도 덜 걸리기 때문이다.

- 임무 토글 툴팁에 해당 메이드 기준 예상 효과를 보여 준다: 하루 기분 변화(예: -2 → 0), 수입 보정(%), 부상 확률 보정, 적용된 특성 목록.
- 임무별 대표 적성: 집안일=타고난 하녀·노예근성·워커홀릭, 안개 탐색=역전의 용사·성기사·광전사·아레나 챔피언·타고난 투사, 길거리=색정광·정액 중독·펠라 중독·애널섹스 중독, 알바=워커홀릭·타고난 마법사·예민한 미각·보좌관.
- 기분 하락이 0 이하로 막힌 메이드는 하락이 없는 만큼 충성 성장이 이어진다. 

## 2-5. 원칙: 기존 조수/노예 메커니즘 그대로 (사용자 확정 2026-11-09)

개인실 임무는 특별 규칙이 아니라 조수·슬레이브가 이미 쓰는 규칙 시스템을 그대로 차용한다. 새로 만든 독자 규칙은 최소화한다.

기존 메커니즘 확인 결과(`next_day`):
- 임무는 "규칙"이다. 켜져 있으면 하룻밤 규칙 수(`overnight_rules_count`)에 들어가고, 복종도가 기준 미만이면 거부(`neg_rules`)한다.
- 행동력은 `energy -= 1`, 모자라면 `half_action += 2`로 다음 아침에 깎는다. 임의 소모값을 따로 만들지 않고 이 경로를 쓴다.
- 기분은 임의 `mood_rate` 가감이 아니라 기분 요인(moodlet, `neg_...`/`pos_...` 100/0)과 기존 rate 경로로 반영한다.
- 충성은 `next_day_slave_moral`이 그대로 처리한다(기분·복종도 > 0일 때만 오르고, 불안·공포일 때 깎임).

이에 따라 아래를 바꾼다.
- 독자 정산 카운터는 만들지 않는다(2-3 참조).
- 공통 규칙표의 독자 휴무 규칙(기분 최저·부상 3단계 휴무 등)은 기존 규칙의 거부·행동력 조건으로 대체한다.
- 기분 하락·상승은 임무별 전용 기분 요인(예: 외근 피로, 외근 보람)으로 만들어 기존 기분 합산에 얹는다.

## 6. 아이템 처리: 일일 정산창 선택 (사용자 확정 2026-11-09)

가게마다 판매 UI를 두면 너무 복잡하므로 판매 기능은 넣지 않는다. 대신 **하루 정산창에서 그날 얻은 아이템을 매각할지 보관할지 고른다.**

- 안개 탐색은 스파크 수입 + 확률로 아이템 **최대 1개**(하루 한 개). 결과 단계별 확률은 3-2.
- 정산창 문구 예:
  - "[키쿠치요가 안개 경계 순찰에서 21스파크와 치도를 획득해 왔습니다.]"
  - 선택지: "치도를 암시장에 내다판다 +$120" / "치도를 무기고에 보관한다"
- 매각처는 **암시장**, 매각가는 구매가의 60%(예시의 치도 200 → 120, 확정). 아이템 종류에 따라 "무기고"(무기·방어구) / "옷장"(의복) / "패물함"(패물)로 문구만 바꾼다. 보관하면 보유 수량 +1.
- 알바는 요리·연금 재료라 선택 없이 보관하고, 길거리는 현금뿐이라 선택이 없다.
- 일반 판매 UI(가게 "팔기")는 만들지 않는다. 한 번 보관한 아이템을 나중에 파는 방법도 없다.

- 기본값은 **보관**(확정). 선택하지 않고 넘어가면 보관한다.
- **자동 처리 토글**(확정): 정산창에 "아이템 처리: 매번 묻기 / 보관 자동 / 매각 자동" 3값 토글을 둔다.
  - **매번 묻기**(기본): 정산창에서 매각/보관을 고른다. 고르지 않고 넘어가면 보관.
  - **보관 자동**: 묻지 않고 보관하고 안내만 한다.
  - **매각 자동**: 묻지 않고 암시장에 팔고 "치도를 암시장에 팔아 +$120"처럼 한 줄로 안내한다.
- 메이드 여러 명이 같은 날 아이템을 얻으면 한 명씩 차례로 정산한다.
