# JO9 로컬 모딩 — 계획

핸드오프 원문은 `JO9_Claude_Local_Modding_Handoff.md`. 이 문서는 그 요약과 이 repo에서의 운용 방식을 적는다.

## 목적
JO9를 완성도 높은 모딩 버전으로 다듬는다. 웹 포팅과 AI 런타임은 후순위이며 지금 만들지 않는다.

## 작업 방식
- 플레이 중 사용자가 지시하면, 로컬 Claude Code가 게임 폴더의 QSRC/QSP를 직접 찾아 최소 변경으로 고친다.
- 로컬 게임 폴더: `C:\MOVE\Jack O Nine Tails v2.3 Kor_nosex`
- 이 클라우드 세션은 게임 폴더에 접근할 수 없다. 소스 수정과 실행 검증은 로컬에서 한다.
- 이 repo는 UI 패치(`JO9UIpatch`), Image Workshop(`JO9imgtool`)과 섞지 않는다.

## 기본 루프
1. 문제 장면 / Show HTML / 이벤트 상황 수신
2. QSRC/QSP에서 분기 역추적
3. 변수·이미지·텍스트·이벤트 ID 확인
4. 최소 수정
5. QSP 재빌드
6. 게임 실행 검증
7. 수정 파일, Location/이벤트, 핵심 변경, 빌드 여부, 확인 포인트만 보고

## 원칙
전체 QSP 재분석 금지, 최소 변경, 기존 식별자 유지, 이벤트 전용 이미지는 분기에서만 새 경로 사용(공용 이미지 교체 금지), 수정 전 백업.
