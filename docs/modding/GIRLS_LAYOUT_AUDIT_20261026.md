`display_fullimage`는 현재 개별팩으로 기본/역할 경로를 보정하고, 선택 의상이나 표정 키가 **빈 문자열일 때** 기본 그림으로 돌아간다. 비어 있지 않은 잘못된 파일 경로는 파일 존재 여부를 검사해 자동 복구하지 않는다. 초상화도 일반/기절/사망 경로의 자동 파일 대체가 없다. 따라서 물리 파일 누락 수와 실제 분기에서 나타나는 오류 수는 같지 않다.
