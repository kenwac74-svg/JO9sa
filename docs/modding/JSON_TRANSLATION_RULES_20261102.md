# 캐릭터 JSON 번역·설정 규칙 — 2026-11-02

사용자 확정 지침이다. 일반적인 문체 선호보다 아래 개별 승인·보류를 우선한다.

- 직접 부르는 호칭 `여주인님`은 성별에 관계없이 `주인님`으로 통일한다. 제삼자를 설명하는 `예전 여주인` 같은 표현과 고유명·직책은 별도로 구별한다.
- 독립적이고 강한 인물의 태도를 단순 반말로 대신하지 않는다. 엘자에 대해 사용자가 제시한 것처럼 격식을 갖추면서 자부심·거부감·독립 의지를 유지할 수 있다. 낮추는 자기지칭이나 무조건적인 복종을 추가하지 않는다.
- 엘자 2624의 세 설명은 이 방향으로 수정 승인됐다. 직업 설명 마지막의 생존을 위한 협조와 굴복 거부는 사용자 직접 제시 각색이며 원문 직역이라고 기록하지 않는다.
- 공주·왕녀 등 높은 신분, 강한 반항성·독립성 때문에 말투 판단이 애매한 인물은 근거와 현재 문장·제안 문장을 보여주고 사용자 컨펌 후 수정한다. 이미 존대인 인물에게 신분만 보고 오만함을 새로 부여하지 않는다. 같은 인물의 순종·변형 상태도 구별한다.
- 도나도나 출신은 별도 명단을 유지하고 수동 번역·설정·컨펌 필요로 보고한다. 고유 설정이 부족한 다른 명명 인물도 같은 검토 대상으로 기록한다. 공백을 창작 설정으로 자동 보충하지 않는다.
- 이름이 고정된 숫자 파일명 JSON은 `번호_영문명.json`으로 정리한다. 확인 가능한 원문 영문명을 우선하고 없으면 한글명을 로마자로 옮긴다. 번호·확장자·파일 내용·이미지 경로는 이름 변경 때문에 바꾸지 않는다. 이름이 있다는 사실만으로 1회 등장 유니크 획득을 구현했다고 보지 않는다.
- 새로 쓰거나 고치는 배경 설명의 숨은 `<!-- #nwtx -->` 표시는 유지한다. 기존 잔나의 원문 보존 4필드는 그대로 둔다.
- 현재 WORK를 다시 읽어 수동 변경을 보존한다. 개인 세이브와 이미지는 수정하지 않는다. 고유명 파일 정리 시 같은 번호의 중복 JSON을 남기지 않고 이전/이후 이름을 기록한다.
