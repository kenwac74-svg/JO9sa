# JO9 2.4 리소스·배포 기준 — 2026-10-05 사용자 확정

- 목표는 별도 UI 패치가 아니라 현재 플레이 폴더를 기반으로 한 JO9 2.4 통합 압축본이다.
- 이미지 교체는 기존 게임 경로·파일명에 1:1 반영한다. 이미지 교체만을 위해 QSP를 SNKmod로 우회시키지 않는다.
- 현재 게임이 참조하는 SNKmod 파일은 참조 이전을 마치기 전까지 이동하거나 삭제하지 않는다.
- 게임에서 사용하지 않는 것으로 확인된 리소스는 `content/pic/reserve/<기존 pic 상대경로>`로 옮긴다. 폴더 이름만으로 미사용을 판정하지 않는다.
- reserve는 게임 코드·CSS·데이터에서 참조하지 않아야 하며, 이용자가 reserve를 삭제해도 실행에 영향이 없어야 한다. 참조가 불확실한 파일은 현 위치에 유지하고 검토한다.
- 체크리스트 `spare`(보관), `branch`(재활용) 태그가 있는 리소스는 2.4 배포에 포함한다. 그 밖의 reserve 항목은 최종 보관/제외 판단 대상이며 이번 정리에서는 삭제하지 않는다.
- 체크리스트는 게임용 폴더와 reserve의 [미적용] 폴더 트리를 분리한다. 이미지 외 JSON·압축파일·폰트 등은 이미지 목록에 넣지 않는다. 파일 이동 시 작업번호·태그·진행 기록을 보존한다.
- 출시 전 이미지패치 ZIP은 수시 배포 가능하다. 사용자 직접 제작 리소스만 포함하며 원본·개성패치·올걸팩 등 타인 제작 리소스는 제외한다. 출처 불명 리소스도 포함하지 않는다.
- 이미지패치 ZIP에는 QSP를 포함하지 않는다. 이용자가 백업을 담당한다. 동봉 카탈로그는 '원본 vs 이미지패치' 비교임을 명시하고 하단에 올걸팩과 겹치는 경로를 안내한다.
- 정책 확정이 지금 ZIP 생성·배포를 뜻하지는 않는다. 통합본을 만들 때 백업·도구·로그와 미보관 reserve 파일은 배포 목록에서 제외한다.
- 게임 실행·화면 검증은 사용자가 한다. 시스템 수정·롤백·서버 재시작은 먼저 확인받는다.

이번 확인: jo9mod, bg/DB_BG, ui/approved_main_v1은 현재 QSP·CSS·JSON에 직접 경로 참조가 없으며, approved_main_v1 19개는 현재 사용되는 SNKmod/ui 복사본과 바이트 동일하다. 나머지 리소스의 동적 호출 분석은 아직 완료되지 않았다.
