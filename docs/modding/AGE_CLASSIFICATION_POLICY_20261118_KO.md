- `age`와 `seed_age`의 0·1·2는 실제 만 나이를 저장한 숫자가 아니라 게임의 발육·외형 분류 코드다. 생성·이미지 선택·기계적 보정에 사용된다.

- 인물 JSON에서 별도의 실제 나이·생년월일 필드는 이전 조사와 2026-11-18 재확인에서 발견하지 못했다. 전체 게임에 나이 관련 문장이 없다는 증명으로 확대하지 않는다.
- 2026-11-19 사용자 정정 기준에 따르면 원작자는 이미지 프롬프트에서 젊음 21~29세, 어림 18~20세, 성숙 30세 이상의 외형을 참고했다. 개별 인물의 실제 나이는 해당 인물 설정에서 확인한다. 원작자 코멘트의 원문은 독립 확인하지 않았다.
- 이 정책 기록은 게임 분기·대사·수치의 변경 승인이 아니다. 코드명 정리는 별도 명시 지시에 따라 호환성을 확인하고 진행한다. 캐릭터의 숫자 분류·이미지 경로·세이브 상태를 이름 정리 때문에 재추첨하거나 변경하지 않는다.
