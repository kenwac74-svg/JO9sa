## 다른 PC에서 이어받기

1. 현재 PC의 수동 작업을 보존하고 `git fetch origin`을 실행한다.
2. `origin/codex/release-2.4.1-update3-20261107`의 최신 커밋을 기준으로 작업을 연다. 이전 전달 브랜치를 이미 받은 PC는 로컬 작업을 보존한 뒤 원격 최신 커밋에서 새 작업 브랜치를 연다.
3. 공개 안내에는 `releases/2.4.1-update3-20261107/RELEASE_NOTES_KO.html`과 함께 같은 폴더의 `release-notes-media/`를 사용한다. 영어 안내도 같은 폴더에 있다.
4. 패치 적용은 ZIP의 `INSTALL_KO.txt`를 따른다. 게임과 WORKSHOP을 닫고 ZIP을 게임 폴더 밖에 푼 뒤, `INSTALL.cmd` 자동 적용 또는 수동 적용을 선택한다.
5. 수동 적용은 개인 JSON 수정과 `game/json/save_config.json`을 보관한 뒤 기존 `game/json` 전체를 교체하고, 패치의 `game` 폴더를 합치는 방식이다. 적용 후 기존 실행 파일로 게임을 실행한다.

최종 런타임은 수동 전달한 ZIP의 `game/` 아래에 있다. 표의 QSP·시루 JSON 해시는 이 ZIP의 파일을 가리킨다. 저장소의 `assets/runtime/2.4.1/jack.qsp`와 기존 `assets/json/`·`resources/new/`에는 이전 기준 자료가 있으므로, 실행 파일을 꺼낼 때는 수동 전달 ZIP과 위 해시를 사용한다. 다음 PC의 실제 플레이 폴더 경로를 먼저 확인한다.

이후 대용량 파일을 추가 전달할 때는 사용자 지시에 따라 Google Drive를 사용한다. 전달할 파일명과 해시를 기록해 다른 PC에서 같은 파일을 식별할 수 있게 한다. 시루와 펠라게야의 이미지 세트는 완료 상태다.

## 이번 패치의 핵심

- **초보자 의뢰 안내** — 이지 모드에서 `목표 → 고객들의 특별한 요구`를 열고 의뢰를 선택하면 하단에 납품 대상의 등급·기술·특성 등 조건이 나온다. 공개 노트의 첫 개선 사항이며 사용자 제공 스크린샷을 포함한다.
- **경매 대사** — 단조로운 반복을 줄이도록 길드 판매 경매의 반복 입찰 대사를 바꿨다. 시장 구매 경매의 잡파 진행·매물 소개·입찰 반응·낙찰과 직접매입·위탁 판매 대사도 각각 보완했다.
- **특별요리 명령** — 조수가 특수 식재료로 기존 식사의 품질을 한 단계 높인다. 공개 안내의 핵심은 명령과 식사 효과다. 과일과 와인은 사용 재료의 예로 설명한다.
- **시루와 펠라게야** — 두 캐릭터의 알몸·비서·하녀·도미나 외형이 완성돼 연결됐다. 시루의 전용 등장 경로·과거 설정도 완성됐다. 공개 노트에는 두 비서 복장 이미지를 넣었다.
- **시루의 정액 중독** — 새 영입 시 보유·공개 상태로 시작한다. 기존 보유 시루도 저장을 불러올 때 한 번 보정해 특성 목록에 표시한다. 보정 기록은 인물과 함께 이동하며 카오틱 에센스 치료 기록을 인정한다.
- **신규 공통 특성** — 정액 중독은 색정광의 상위 단계이고 석녀는 불감증의 상위 단계다.

공개 노트는 플레이어가 체감하는 변화와 사용 경로를 우선한다. 식사 품질이 한 단계 높아진다는 기능 설명은 공개할 수 있다. 상세 포인트·계산식·확률과 스토리·시나리오의 전개는 공개 노트에서 다루지 않는다. 내부 수정 기록을 그대로 공지로 옮기지 않는다.
