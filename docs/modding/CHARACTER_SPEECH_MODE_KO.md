## 저장값과 호출

기존 인물배열의 문자열키 `jo9_plain_tone`을 재사용한다. 추가 인물키·전역배열은0이다. -1은 현재 존댓말, 1은 현재 반말, 없음/0은 기본 정책이다. 0의 기본값은8명 반말·나머지 기존 격식/일반 존댓말이며, 공주출신은 자동 조건에 따라 갱신한다.

0이 아닌 값은 자동 전환 대상 표시도 겸한다. 따라서 -1을 설정해도 존댓말이 영구 고정되지 않으며, 조건이 해제되고 응석3이상이면1로 복귀한다. 일반 비공주를 대상에서 빼려면0을 넣는다. 지정8명·공주출신의 자동 대상 자격은0으로 지워지지 않는다.

`func('jo9_plain_voice','update','assistant')`는 조수의 현재 말투를 갱신하고 -1/0/1을 반환한다. 인수는 실제 인물 변수 접두사이며 slave, assistant, room1 등을 쓴다. 이 갱신기는 인식·헌신·사육·두려움·응석 수치를 바꾸지 않는다.

`func('jo9_plain_voice','enabled',번호,말투값)`은 활성 여부0/1만 반환하며 상태를 갱신하지 않는다. 기존 `jo9_plain_voice(번호,문장,말투값)` 완성문장 교정표와 `$voice_profile` 인수는 유지한다.

## 공주 출신과 직업

일반 무작위 외형 범위는 generate_stock의 현재 loli/young/milf 범위(young최소상한1462, milf최소상한2340), 제외1448/1450을 그대로 따른다. 여기서 `$인물_family='mprincess'`인 경우만 공주출신이다. 야만족 공주(barbarian_king)·직업만 공주·범위 밖 유니크는 자동 포함하지 않는다.

새 생성의 유효한18개 세계/출신/연령 행은 공주 직업만 선택한다. 기존 생성의 직업 처리 전에도 같은 기준을 적용한다. 기존 세이브는 불러올 때 모든 기존 인물역할과 주차 인물의 직업·직업설명·경매표기·work_index만 공주 기준으로 맞춘다. 대화 갱신 때도 재확인한다. 육성값·이미 적용된 기술/특성·경험·관계·소유일·처녀상태·진행은 다시 생성하지 않는다.

## 캐시·유지·한계

`gs 'jo9_plain_voice','cache'`는 알려진 옛 말투 콜백 조각만 갱신하고 반복해도 가드를 늘리지 않는다. 기존 음악 로드의 #dynamic 재초기화는 별도 기존 동작이다. `gs 'jo9_plain_voice','load'`는 공주 직업 메타데이터만 맞춘다. 두 호출은 $ongload에 연결돼 있다.

직접 작성한 고유 배경·도시 사건 각본을 자동 재각색하지 않는다. 모르는 수동 원고는 보존한다. 역할 교환은 기존 배열 복사를 따르므로 말투값도 사람과 함께 이동한다.

제거할 때는 R05/R05a 조립기·실제화자·교정·로드·생성 호출을 함께 검토한다. 기존 말투값은 다른 속성으로 재해석하지 않는다. 공주 직업 동기화의 제거는 원래 직업을 복구하지 않는다. 현재 변경에 과거 직업의 새 보관필드를 만들지는 않았다.
