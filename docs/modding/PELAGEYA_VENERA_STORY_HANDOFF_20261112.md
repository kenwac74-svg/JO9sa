# 펠라게야·베네라 설정 및 용어 통일 인수인계

작성일: 2026-11-12 KST

상태: 사용자 요청에 따라 설정·수정 기준을 정리한 문서. 게임 QSP·JSON에는 아직 미반영. 이 문서 작성만으로 게임 적용·배포·커밋·푸시를 완료한 것으로 보고하지 않는다.

## 1. 이번에 통일하는 가족 설정

기존 본편은 아이들을 펠라게야의 친자이자 가이우스의 양자로 설명한다. 이번 정리는 사용자가 제기한 가족관계의 자연스러움을 반영하여 **가이우스의 친자이자 펠라게야의 의붓자녀**로 변경하는 기준이다. 단순 오역 수정과 구분해야 한다.

| 관계 | 통일 기준 |
|---|---|
| 펠라게야 ↔ 베네라 | 친자매. 펠라게야가 언니, 베네라가 여동생이다. |
| 가이우스 ↔ 아이들 | 친부와 친자녀. 기존 대사상 아들들이다. |
| 펠라게야 ↔ 아이들 | 후처와 의붓아들들. 혈연은 없지만 어린 시절부터 돌보며 어머니 역할을 해 왔다. |
| 베네라 ↔ 아이들 | 의붓어머니의 여동생. 가족 안에서는 이모처럼 지냈으나 혈연상 이모는 아니다. |
| 가이우스 ↔ 베네라 | 아내의 여동생, 즉 처제다. |
| 야만왕 ↔ 자매 | 혈연관계가 없다. 야만왕의 여동생이라는 표현은 사용하지 않는다. |

아이들의 생모가 누구인지, 생존 여부, 이전 혼인의 경위는 정하지 않는다. 관련 사건이나 인물을 임의로 추가하지 않는다.

### 황후 지위와 후일담의 연결

- 펠라게야의 궁정 노예 출신 과거와 가이우스의 아내라는 현재 신분은 유지한다.
- 황후라는 지위와 아이들의 어머니 역할은 그녀에게 소속감과 안전을 제공한다. 가이우스에게는 황실의 체면을 유지하는 수단이기도 하다.
- 기존의 “펠라게야가 낳은 아들들에게 생모의 과거를 감추려고 결혼했다”는 설명은 삭제한다. 새 가족관계와 맞지 않는다.
- 아이들이 그녀를 외면하는 후일담은 유지한다. 핵심은 친모를 잃는 사건이 아니라, 자신이 가족이라 믿고 키운 아이들에게 어머니로 인정받지 못하는 상실이다.
- 베네라는 이 상황을 안타까워하고 언니를 걱정한다. 자유분방한 초기 성격과 언니에 대한 애착은 함께 유지한다.
- 아이들이 외면하는 원인을 혈연 부재 하나로 단정하지 않는다. 정변과 신분 추락 이후의 가족 단절이라는 기존 맥락을 유지한다.

## 3. 유지할 이야기 구조

1. 자매는 평범한 마을 출신이며 서로 의지했다. 고향과 로마 도착 경위의 세부 설정은 현재 공백으로 둔다.
2. 펠라게야는 황후가 되어 아이들의 교육과 황실의 체면에 신경 쓴다. 베네라는 궁정 생활에 염증을 느끼고 프라이빗 클럽을 드나든다.
3. 베네라는 가이우스의 지배를 거부한다. 황제는 그녀에게 집착하며, 주인공에게 베네라를 넘기면 펠라게야를 주겠다고 제안한다.
4. 발랄라이카를 통한 베네라 확보, 훈련, 황제와의 교환이 진행된다.
5. 야만왕은 펠라게야의 궁정 내부 정보를 이용해 가이우스에게 복수하고 왕좌를 차지한다. 프리실라의 개입과 주인공의 협력은 유지한다.
6. 정변 뒤 자매가 돌아온다. 두 사람의 순응과 별개로 가족관계의 상실과 괴로운 기억이 남아 있다는 후일담을 유지한다.

베네라가 가이우스를 거부한 구체적 이유, 가이우스가 야만왕을 배신한 사건의 상세 내용은 현재 확인한 대사에 없다. 이 문서를 근거로 임의 보충하지 않는다.

### 펠라게야 인물 소개

> 궁정 노예 출신으로 황후의 자리에 오른 가이우스의 아내. 황제의 아들들을 어린 시절부터 돌보며 어머니 역할을 해 왔다. 혈연은 없지만 아이들을 자기 가족으로 여기며, 그들의 교육과 황실에 걸맞은 품행에 큰 관심을 쏟는다. 황후라는 지위도 가이우스의 변덕 앞에서는 안전하지 않다.

### 펠라게야 거처 소개

> 황후 펠라게야가 머무는 궁정 내실. 이곳에서 그녀는 직접 키운 황제의 아들들을 보살피고 교육할 인물을 구한다. 화려한 황후의 권위 뒤에는 자신의 자리와 가족을 지키려는 불안이 감춰져 있다.

### 베네라의 결말 후 가족 대사

> 제 처지는 받아들이려고 해요. 그래도 펠라게야 언니는 걱정돼요. 언니는 황제의 아이들을 어릴 때부터 제 자식처럼 키웠거든요. 저도 아이들 곁에서 이모처럼 지냈고요. 그런데 그 일 뒤로 아이들이 저희를 피하고 있어요. 언니는 이제 자신이 아이들에게 아무것도 아닌 사람이 된 것 같아 괴로워해요.

### 펠라게야의 결말 후 가족 대사

> 아이들이 잘 지낸다니 다행이에요. 제가 낳지는 않았어도, 어릴 때부터 제 자식처럼 키웠거든요. 이제는 곁에 다른 사람이 있고 저를 찾지도 않지만… 그래도 가끔은 보고 싶네요.

모든 신규·교체 설명에는 기존 사용자 규칙대로 보이지 않는 `<!-- #nwtx -->`를 붙인다. QSP에서는 HTML 문자열 안에, JSON에서는 해당 값의 끝에 넣는다. 기존 태그가 있으면 중복 추가하지 않는다. 등장 전 NPC 말투와 획득 후 말투는 장면에 맞게 유지하고, 이번 작업을 이유로 일반 대화 전체의 말투를 바꾸지 않는다.

## 5. 데이터와 게임 동작 보존

- 정규 퀘스트의 인물 흐름은 베네라 `2584 → 2606`, 펠라게야 `2585 → 2607`이다. 사건 전후의 같은 인물이며 별개의 자매가 아니다.
- 펠라게야 `2577`도 같은 고유 인물 ID를 사용한다. 이번 조사에서는 정규 퀘스트의 직접 생성 호출을 발견하지 못했다. 사용하지 않는다고 단정해 삭제하거나 획득 경로를 새로 만들지 않는다.
- 가족관계 변경은 서술 설정 변경이다. 자매 사이의 `stock_id`, `stock_id_relative`, 관계 연결은 유지한다. 아이들과의 새 시스템 관계를 추가하지 않는다.
- 납품 능력치, 의뢰 활성화, 금액, 인물 지급, 정변 결과, 기존 조수 유무에 따른 베네라 수령 분기는 수정하지 않는다.
- 초기형 JSON `2577_pelageya`·`2585_pelageya`·`2584_venera`의 가족 문장은 자매 관계 중심이므로 무조건 재작성하지 않는다. 혈연 설정과 충돌하는 문장만 수정한다.
- 기존 세이브는 과거 설명을 인물 변수에 저장했을 수 있다. JSON 변경만으로 이미 영입한 인물의 문장이 갱신된다고 보고하지 않는다. 실제 저장·로드 경로를 확인한 뒤, 필요하면 알려진 구문과 정확히 일치하는 기존 문장만 갱신하는 방식을 검토한다. 사용자 수동 편집 문장을 일괄 덮어쓰지 않는다.
- 루미너스 3002의 일반 대화 비존대 예외는 별도 보류 작업이며 이번 범위에 포함하지 않는다.
