## 확정 정책 요약

- UI/UX는 `game/SNKmod/content/pic/`에 별도 설치하고 관련 QSP/CSS 참조만 바꾼다. 원본 UI 이미지는 보존하며 UI 연결 복구를 지원한다. 기본은 원본 상대경로·파일명 유지, 산재 UI의 예외 목적지는 사용자가 패키징 시 지정한다.
- 캐릭터·NPC·일반 배경은 기존 경로에 덮어쓴다. 원본 이미지 백업·자동 복구는 만들지 않는다. 원하는 그림만 수동 교체할 수 있도록 기존 경로·파일명을 유지한다.
- BG는 파일마다 정책을 구분한다. 번역 BG와 트로피룸은 UI/UX다. UI 제거가 일반 이미지 교체 결과를 되돌리면 안 된다.
- 일반 이미지 자동 교체 직전에 `원본이미지 교체에 동의하십니까?`라는 별도 동의를 받는다. 거절·취소·명시적 승인 없는 무인 실행에는 교체하지 않는다. 거절해도 UI만 설치할 수 있어야 한다.
- 동명 파일은 사용 여부와 바이트 동일성을 먼저 구분한다. 사용되는 동일 사본은 통합 경로를, 내용이 다르면 이미지·용도 차이까지 보여 주고 한 묶음씩 질문한다. 승인 후에만 통합한다. 미사용 확인 사본은 모드 배포에서 제외하되 원본은 삭제하지 않는다. 고정 검색 미발견은 미사용 증거가 아니다.
- `SNKmod`는 이 UI 리소스 루트다. 별도 기능인 `SNmod`/`pic_SNmod`와 혼동하지 않는다. 취소한 전체 UI 이미지 참조 HTML 카탈로그는 재개하지 않는다.

## 다음 담당자가 먼저 할 일

인계 ZIP을 작업 폴더에 풀고 `START_HERE.md`를 읽은 다음 `python tools/verify_bundle.py`를 실행한다. `source/FIX6/`를 별도 작업 사본으로 복사해 작업한다. 이 ZIP을 새 설치팩으로 게임 폴더에 통째로 덮어쓰지 않는다.

실제 설치 `jack.qsp`, 전체 게임 소스/HTML 로딩부, 사용자 최신 SNKmod 폴더, 일반 이미지 교체팩은 인계에 없다. 필요한 것은 먼저 접근 가능한 실제 자료에서 읽고, 접근할 수 없을 때 필요한 자료 하나만 요청한다. 이미 확정된 정책을 다시 승인받지 않는다.

기존 5개 location 변경 범위를 넘어가야 하면 해당 위치와 이유를 먼저 승인받는다. CSS 연결·기존 FIX6 설치본의 원본 복구 전환·다른 모드 공존을 검증해야 한다. 현재는 새 구조 미구현이므로 QSP만 되돌리면 전체 순정이 된다고 보장하지 않는다. 엔진 보호와 FIX6 레이어/1px 정렬 보정을 보존한다.

이번 인계에서는 FIX6 안의 `gear.png`, `sound_off.png`, `sound_on.png` 동명 쌍이 각각 바이트 동일함을 확인했다. 실제 게임 사용 여부와 통합 경로는 아직 미확정이다. 원본 파일을 이동하거나 참조를 변경하지 않았다.
