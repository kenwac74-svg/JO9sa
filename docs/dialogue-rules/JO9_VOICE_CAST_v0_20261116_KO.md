## 0. 공통 규칙
| 항목 | 규칙 |
|---|---|
| 인물 정하기 | 영입 때의 유형으로 한 번 정하고 바꾸지 않는다. 유니크는 지정 |
| 태도 | 정신 상태에서 온다. **움츠림**(두려움·슬퍼함·우울증), **순함**(상냥함·온순함·긍정적), **따름**(복종중·노예근성·발정중). 맞섬은 기존 거부 대사, 무너짐은 공통 전용 대사 |
| 변하는 것 | 목소리는 그대로, 태도에 따라 **거리**가 변한다. 움츠림은 겁과 가라앉음, 순함은 예의 바른 거리, 따름은 마음을 준 상태 |
| 한 줄의 모양 | `"대사"` 가 중심. 짧은 몸짓 지문을 붙일 수 있다. 속마음은 『 』 |
| 호칭 | 원고에는 `{호칭}` 빈칸으로 쓴다. 존댓말 인물은 맞섬일 때만 "당신", 그 밖은 "주인님" |
| 길이 | 움츠림에서는 한 단계 짧게, 느낌표 없음 |
| 금지 | 한 줄에 느낌표 두 번, 매질을 전제한 낱말("때리다", "매"), 노예가 알 수 없는 게임 수치, 어미 자동 변환을 전제한 문장 |
| 수치 | `{N}` 어림말, `{X}` 정확한 숫자. 부풀림·줄임은 유형별 배율이 처리하므로 원고에서 숫자를 고치지 않는다 |

**세 태도를 가르는 한 줄 기준**
| 태도 | 주인을 보는 눈 | 문장에서 드러나는 것 |
|---|---|---|
| 움츠림 | 무섭거나, 지금 너무 가라앉아 있다 | 말이 끊긴다. 눈을 피하는 지문. 변명과 사과가 먼저 |
| 순함 | 거스를 생각은 없지만 속은 주지 않았다 | 묻는 것만 답한다. 자기 얘기를 덧붙이지 않는다 |
| 따름 | 이 사람 곁이 자기 자리다 | 묻지 않은 것도 말한다. 주인을 문장의 중심에 둔다 |

| 따름 | "{호칭}께 칭찬받는 날은 잠이 잘 와요. …이런 말, 해도 되나요." | "그때는 늘 눈치만 봤어요. 지금은… 여기가 더 편해요." |

## 5. 공주
| | |
|---|---|
| 해당 | 공주 출신 직업(mprincess, barbarian_princess). 반말 유니크의 기본 |
| 한 줄 소개 | 명령만 하고 살았던 사람. 노예가 되어서도 말버릇은 남는다 |
| 말투 | **반말. 평생 반말이다.** 복종해도 존댓말로 바뀌지 않는다 |
| 호칭 | 맞섬 "너 / 네놈"(인식 2 이상이면 "당신") → 그 밖 "당신 / 주인공 이름" → 따름 또는 헌신 3 이상 "주인 / 마스터" |
| 말버릇 | 명령형과 단정형("~해", "~야", "~거든"). "감히", "내가" |
| 문장 | 짧고 끊어 말한다. 부탁도 명령처럼 들린다 |
| 잘 말하는 것 | 자기가 누구였는지, 불쾌함, 요구 |
| 말하지 않는 것 | 사과, 고맙다는 말(따름에서 서툴게 한 번) |
| 수치를 말할 때 | 유형 배율을 따른다(대개 부풀린다) |
| 망설일 때 | "그런 건 묻는 게 아니야." 하고 잘라 낸다 |
| 속마음 | 겉으로는 버티고 속으로 흔들린다. 『왜 이 사람 앞에서는 말이 길어지지.』 |
| 태도 변화의 핵심 | 말투가 아니라 **호칭과 명령의 방향**이 바뀐다. 처음에는 주인에게 명령하고, 나중에는 같은 말투로 주인의 명령을 청한다 |

| 태도 | 호칭 | 요즘 칭찬을 자주 받았을 때 | 과거를 물었을 때 |
|---|---|---|---|
| 움츠림 | 당신 | "…칭찬 같은 거 필요 없어. 그냥 내버려 둬." | "말하면 뭐가 달라져? 이제 다 없어졌는데." |
| 순함 | 당신 | "칭찬? 당신 눈이 이제야 제대로 뜨였네." | "궁에서는 내 말 한마디에 서른 명이 움직였어. 믿든 말든." |
| 따름 | 주인 | "주인이 칭찬하니까 하는 말인데, 더 해도 돼." | "그 시절 얘기는 주인한테만 해. 다른 데 가서 말하지 마." |

- 같은 '따름'이라도 공주는 "더 해 주세요"가 아니라 "더 해도 돼"라고 말한다. 허락하는 말투로 청하는 것이 이 인물의 따름이다.

## 6. 다섯을 가르는 시험 문장
같은 상황(벌을 받은 날 저녁, 태도 순함)에서 다섯이 이렇게 갈려야 한다. 새 원고가 어느 인물인지 헷갈리면 이 표와 견준다.

| 인물 | 문장 |
|---|---|
| 순한 아이 | "오늘 일은 제가 잘못했어요… 다시는 안 그럴게요." |
| 담백한 아이 | "오늘은 좀 서운했어요. 그래도 제가 틀린 건 맞아요." |
| 센 아이 | "벌은 받았으니 그 얘기는 여기까지 하시죠." |
| 조용한 아이 | "…알겠어요." |
| 공주 | "벌은 받았어. 그러니까 그 얘기는 그만해." |

|---|---|---|---|
| 순종 | 순한 아이 | 1쪽 | 70% |
| 여린 | 순한 아이 | 2쪽 | 50% |
| 평범 | 담백한 아이 | 1쪽 | 100% |
| 솔직 | 담백한 아이 | 2쪽 | 100% |
| 도도 | 센 아이 | 1쪽 | 150% |
| 불꽃 | 센 아이 | 2쪽 | 300% |
| 인형 | 조용한 아이 | 단답 | 100%, 아주 짧게 |
| 관조 | 조용한 아이 | 단답~1쪽 | 100%, 정확한 숫자 |
| 얼음 | 조용한 아이 | 단답~1쪽 | 100%, 정확한 숫자 |

- 한 칸에 긴 줄과 짧은 줄을 섞어 써 두면, 길이 상한이 유형에 맞는 줄만 고른다. 유형별로 따로 쓰지 않아도 된다.

## 8. 원고를 쓸 때의 순서
1. 자리와 주제를 정한다(예: 섹스토크의 "상대 수").
2. 다섯 인물 × 순함 태도로 먼저 한 줄씩 쓴다(다섯 줄). 6장의 표처럼 서로 갈리는지 본다.
3. 각 줄을 움츠림과 따름으로 옮긴다(열다섯 줄). 목소리는 두고 거리만 바꾼다.
4. 칸마다 변형을 둘 더 쓴다(마흔다섯 줄). 긴 줄 하나, 짧은 줄 하나를 섞는다.
5. 망설임 줄을 인물마다 하나씩 쓴다(다섯 줄, 태도 공통).
6. 순한 아이 칸이 비면 담백한 아이 줄이, 그것도 없으면 공통 줄이 나온다. 급하면 2번까지만 써도 게임은 돌아간다.

## 9. 정하지 못한 것
- 반말 유니크 8명 각각이 '공주' 목소리에 맞는지는 인물 설정을 보지 않아 판단하지 못했다. 맞지 않는 유니크는 전용 줄이 필요하다.
- 조수와 개인실 메이드도 같은 다섯 인물을 쓰는 것으로 잡았다. 조수 전용 목소리가 필요한지는 정하지 않았다.
- 예문의 낱말(예: "궁", "서른 명")은 출신 세계에 따라 사전으로 바뀌어야 한다. 사전은 아직 없다.
