| 위치: `interaction_torture` 또는 `dungeon` | ✕ 그런 location이 없다. 인두 낙인은 `interaction`의 `interaction = 1811`(지하 감옥 필요). 글은 `$fire_branding` |

- **가려낼 지점**: `interaction` 1811의 결과부(`brand = 1`), `interaction_city` 4217의 `$do_service`(`brand = 2`), 마법 성공 분기(`brand = 3`).
- **지금 글에 없는 것**: 시술을 묘사할 뿐 그 인물이 어떻게 받아들이는지가 없다. 세 방식의 성격이 다르므로(인두는 고통, 문신은 견딤, 마법은 낯선 감각) 블록의 몸짓 지문만 방식별로 한 줄씩 다르게 하고 대사는 공통으로 쓴다.

## 2. 수술
| 메모의 내용 | 대조 |
|---|---|
| `#options` 1384, 1449 | ○ 두 줄 모두 "성형 수술 ($250)" 메뉴 항목이다 |
| `jo9_traits_combat`의 체질 개선 | △ location이 있고 `jo9_constitution`을 15번 참조한다. 수술과의 연결은 읽지 않았다 |
| 성형 시 5% 확률로 `jo9_peerless = 1` | △ `jo9_peerless`는 있으나 성형 분기에서 설정하는 줄을 찾지 못했다 |
| 회복 기간 `rehabilitation > 0` | △ 값은 있다(`#options` 40회, `interaction_city` 20회 참조). 수술 직후 설정하는 줄은 정규식으로 찾지 못했다 |
| 영구 젖분비 `lactation = 1`, 난생 `fertility = 1`, 불임 `fertility = -1` | △ 두 값 모두 있다. `next_day`에 `fertility ! -2`, `! 1` 조건이 있어 -2도 쓰인다. 각 수술이 어떤 값을 넣는지는 확인하지 않았다 |
| 처녀막 복원 `virginity < 2` | △ `virginity`는 있다. 값의 뜻은 확인하지 않았다(기존 인계 문서에 4 = 명기) |
| 수술별 글 2~4행 | 세지 못함 |

- 수술은 **종류마다 값이 달라** 한 줄로 가려낼 수 없다. 메모의 "결제 직후" 기준보다, 수술 메뉴 번호(`interaction_city` 값)로 가려내는 편이 안전하다. 메뉴 번호 목록은 아직 뽑지 않았다.
- 되돌릴 수 없는 것(영구 젖분비, 난생 개조, 불임)과 되돌릴 수 있는 것(성형, 처녀막 복원)을 나눠, 앞쪽만 무게 3으로 두는 것을 권한다.

## 3. 임신 확인
| 메모의 내용 | 대조 |
|---|---|
| 위치: `newday` 또는 `master_stat` | ✕ `newday`는 없다. 밤 처리는 `next_day`다 |
| `sjm_UI_UIadds`, `sjm_UI_UIadds_buystethoscope` | ○ 둘 다 있다 |
| 판정: `pregnant` 수치의 구간 | △ **`pregnant_revealed`라는 값이 따로 있다.** `next_day` 2008~2012행: 아직 드러나지 않았고, `pregnant >= 120`이거나 (`pregnant > 90`이고 청진기가 있고 주인 의학이나 조수 간호가 2 초과이고 21분의 1 확률)이면 1이 된다 |
| 구간 120 / 196 / 273 | △ 120은 위 조건에 있다. 196과 273은 코드에서 찾지 못했다(코드에 나오는 수는 9, 10, 90, 100, 120, 140, 150, 200) |
| `pregnant >= 150`에 수녀원장 사건 | △ 150이 7번 나온다. 사건과의 연결은 읽지 않았다 |
| 의료 센터 검진 | ○ `next_day` 1596행 주석: `pregnant > 9`부터 의료 센터가 알아낼 수 있다 |
| 첫 자각 글 2~3행 | 찾지 못했다. 값이 밤 사이에 바뀔 뿐이다 |

- **가려낼 지점**: `pregnant_revealed`가 0에서 1이 되는 순간. 두 경로다(밤 사이 자동, 의료 센터 검진).
- 밤 사이에 드러난 경우는 그 자리에서 글을 낼 수 없다(하루 끝 보고에 쪽을 붙이지 않는다는 기존 결정). **다음 날 그 인물을 처음 마주할 때** 내는 것이 맞다. 그러려면 "아직 말하지 않은 큰 일" 표시 하나를 인물에 저장해야 한다. 태도 넘어감, 등급 변화처럼 밤에 일어나는 다른 사건도 같은 표시를 쓴다.

## 4. 우승
| 메모의 내용 | 대조 |
|---|---|
| 위치: `выход_из_боя` | ○ 승리 시 `arena_level < 5`면 +1. 5가 되면 `interaction_city = 1295`(전적에 패배가 없을 때), 아니면 1294 |
| 위치: `colosseum` | ✕ 없다(`colosseum_fight`가 있다) |
| 위치: `hippodrome` | ✕ 없다. 경주 결과는 `$ride_finish`(76행 `has_ride_win += 1`) |
| 아레나 챔피언 5, 그랜드 챔피언 9 | ○ 특별 전투 세 종류가 6~8로 올리고(`interaction_city` 1903~1916), 네 번째가 9로 만든다(1919) |
| 경주 4승, 7승 | △ 4와 7이 조건에 세 번씩 나온다. 칭호와의 연결은 읽지 않았다 |
| 칭호 정의 `#static_base` 1976~1985 | ✕ 그 줄은 굶주림 표시다. 칭호 정의 위치는 찾지 않았다 |
| 승급마다 3~6문단 | △ 아레나 승리 장면 1294는 4줄 약 340자, 챔피언 장면 1295는 4줄 약 300자. 경주 쪽은 세지 못했다 |

- 우승은 이미 글이 있는 편이다. 다만 관중과 의식의 묘사이고 그 인물의 말은 없다. 승리 후 `virtue = 5`가 되므로(경주) 보상을 기대하는 상태다. 블록은 "주인에게 돌아와 하는 한마디"로 잡는다.
- 헌신 3 미만인 챔피언은 자유민이 되어 떠난다. 남는 경우(헌신 3 이상)가 무게 3 중에서도 가장 무거운 순간이다. 따로 한 사건으로 둔다.

## 5. 조수 승격
| 메모의 내용 | 대조 |
|---|---|
| 위치: `interaction`, `interaction_slave` | ✕ `interaction_slave`는 없다. 자리 바꿈은 **`slave_to_assistant` location**이고 `main_screen`의 교환 버튼(헌신 3 이상일 때 보임)이 부른다 |
| 특수 인물 영입은 `interaction_city` | △ `get_special_assistant`, `get_special_assistant_quest` location이 따로 있다 |
| `assistant`, `$assistant_id`, `is_assistant` | ✕ `is_assistant`, `assistant_id`는 없다. 인물 값 묶음을 통째로 바꾼다(`$swap_slave_instances`) |
| 승격 통보와 반응이 2~4문단으로 분기 | ✕ **`slave_to_assistant`에는 서술 글이 없다.** 54줄 중 한글은 퀘스트 실패 문구 하나뿐이다 |

- 다섯 사건 중 **지금 글이 전혀 없는 유일한 사건**이다. 헌신 3이라는 문턱을 넘은 결과인데 버튼을 누르면 자리만 바뀐다. 보강 효과가 가장 크다.
- 교환 버튼은 노예와 조수를 맞바꾸므로 한 번에 두 사람의 사건이다(올라가는 쪽, 내려오는 쪽). 블록은 올라가는 쪽을 먼저 내고, 내려오는 쪽은 한 줄만 붙인다.
- 같은 날 여러 번 바꿀 수 있으므로, 그 인물이 **처음 조수가 될 때만** 무게 3으로 낸다(인물에 표시 하나 저장).

## 6. 풍부화 규칙에 주는 것
1. **밤에 일어나는 사건을 위한 표시가 필요하다.** 임신 확인, 태도 넘어감, 등급 변화는 값이 밤 사이에 바뀐다. 인물마다 "아직 말하지 않은 큰 일" 하나를 저장하고, 다음 날 처음 마주할 때 블록을 낸다. 풍부화 규칙 9장의 미결 항목이 이것으로 풀린다.
2. **"처음 한 번"을 가려낼 표시가 필요하다.** 조수 승격처럼 되풀이할 수 있는 행동은 첫 번째만 무게 3이다.
3. **사건을 가려내는 기준은 값의 변화보다 실행 지점이 낫다.** 낙인은 세 지점, 수술은 메뉴 번호, 조수 승격은 location 하나로 잡힌다. 값의 변화를 감시하는 방식은 `brand`처럼 뜻이 여럿인 값에서 틀린다.
4. **무게 3 목록을 다듬는다.** 수술은 되돌릴 수 없는 것만, 우승은 "챔피언이 되고도 남음"을 따로, 조수 승격은 처음 한 번만.

## 7. 아직 조사하지 않은 무게 3 사건
처음 겪는 일(첫 경험 포함), 태도가 넘어감, 신경쇠약 진입, 숨은 성향이 드러남, 처형 위협(반응 글 122자는 셈), 판매·납품 직전, 도주·반란 실패, 강제로 당함. 수술의 메뉴 번호와 종류별 값, 경주 우승 장면의 글, `brand = 5`의 뜻.
