# 게임 반영 빌드 계획 (2026-11-19)

- 상태: **계획, 사용자 확인 전.** 아직 게임 파일을 바꾸지 않았다.
- 기준 파일: `assets/runtime/2.4.1/jack.qsp` (SHA-256 `8332e185…94f`).
- 결과물: `mods/drafts/`의 mods JSON 초안. 맨 위 `mods/`로 올리는 것은 사용자 확인 뒤(초안 폴더는 `apply_mods`가 읽지 않는다).
- 검증: 이 컨테이너에 QSP 엔진(`@qsp/wasm-engine` 2.0.0)을 설치해 현재 파일을 열고 질문 조각을 읽는 것까지 확인했다. 빌드 뒤 같은 엔진으로 실제 대답을 뽑아 검사한다. 게임 실행과 화면 확인은 사용자가 한다.

## 1. 나눠서 한다
| 단계 | 내용 | 원고 |
|---|---|---|
| 1 | 질문 메뉴 7개 + 공용 줄 | `question-fill/q*_manuscript.json` 약 580줄(승인됨) |
| 2 | 풍부화 사건(무게 2·3) 덧대기 | `db/enrich-db.json` 154블록(승인됨). 사건마다 넣을 자리를 찾아야 해서 따로 한다 |

이 문서는 1단계를 다룬다.

## 2. 지금 게임이 질문 대사를 고르는 방식
- `#txt_man`의 `jo9_voice_fragment_data`에 조각 9,120줄과 색인(역할_유형_말투 → 조각 목록)이 있다.
- `#dynamic`의 `$voice_profile`이 **부를 때마다** 현재 수치로 9유형을, **직업**으로 말투 1·2·3을 정한다.
- 관계는 정신 상태로 8갈래(`$jo9_vf_mode`)를 정하고, 조각의 관계 태그와 맞춰 거른다.
- 고르는 곳은 두 군데다. 인상 묻기 조립(`#dynamic` 5990행 근처)과 그 밖의 질문(6220행 근처).

## 3. 1단계에서 바꾸는 것
| # | 바꿀 것 | 방법 |
|---|---|---|
| 1 | 목소리 고정 | 처음 대사를 고를 때 9유형(또는 공주)을 `$slave['jo9_vtype']`에 저장하고 이후 그대로 쓴다. 이미 진행 중인 세이브도 첫 질문 때 저장된다 |
| 2 | 공주 | 출신이 공주 계열(직업 mprincess·barbarian_princess, slave_type 3002·2610·2620·3010·3021·3023·2621·3012)이면 유형을 `princess`로 둔다 |
| 3 | 말투 | 직업 대신 목소리로 정한다(B안). 도도·얼음·인형·관조 1, 순종·여린·평범 2, 솔직·불꽃 3, 공주 3(반말 줄만) |
| 4 | 관계 칸 | 확정한 순서(무너짐 → 헌신 3↑ → 헌신 0~1 맞섬 → 복종 단계 3↑ → 움츠림/순함)로 `$jo9_vf_mode`를 정한다 |
| 5 | 새 조각 | 승인된 원고를 새 조각으로 더하고 색인에 붙인다. 원래 줄은 지우지 않는다 |
| 6 | 분리 | 새 판을 쓴 목소리의 태그를 원래 줄에서 뺀다(예: 명랑한 판을 쓴 줄에서 `frank`) |
| 7 | 반말 줄 | 말투 3의 반말 줄은 공주만 쓰게 태그를 바꾼다. 명랑한·거센은 그 칸에서 말투 2 줄로 내려간다 |
| 8 | 호칭 빈칸 | 대사를 화면에 내기 직전에 `{호칭이}`·`{호칭부름}` 등을 규칙대로 바꾼다 |

- 새 조각과 태그 변경은 새 위치 `jo9_vf_extra`에 모아, 조각 데이터를 읽은 직후 한 번 실행한다. 큰 데이터 블록을 old/new로 바꾸지 않는다.
- 고르는 코드의 수정은 몇 줄씩이라 mods의 old/new로 기록한다.

## 4. 확인받을 것
1. **말투 B안.** 원고는 B안으로 썼지만 안 자체는 명시적으로 고르지 않으셨다. 이대로 가면 지금 직업으로 정하던 말투가 바뀐다(예: 메이드 출신도 목소리가 순한이면 보통 존댓말, 도적 출신은 반말 대신 편한 존댓말).
2. **원래 줄의 호칭.** 원래 대사 수천 줄에는 "당신/주인님"이 글자로 박혀 있다. 1단계는 새 줄만 빈칸으로 바꾸고 원래 줄은 그대로 둔다. 그래서 한 대답 안에서 원래 줄은 "당신", 새 줄은 "주인님"처럼 섞일 수 있다. 원래 줄까지 바꾸는 일은 따로 한다(추천).
3. **목소리 고정 시점.** 영입 순간에 저장하려면 영입 경로마다 고쳐야 한다. 1단계는 "처음 대사를 고를 때 저장"으로 한다(추천). 인물이 교체될 때 이 값이 따라가는지는 아직 확인하지 못했다(기존 미확인 항목).

## 5. 검사
- mods 적용 전후 SHA-256, 왕복(읽고 다시 쓴 파일이 같음), old가 정해진 횟수만큼만 나오는지.
- 엔진으로: 목소리 7 × 관계 칸 × 헌신·복종 몇 값에서 각 질문을 불러, 오류 없음 / 공주 외 반말 없음 / 빈칸 남지 않음 / 승인된 새 줄이 실제로 뽑힘 / 원래 줄이 사라지지 않음을 확인.
