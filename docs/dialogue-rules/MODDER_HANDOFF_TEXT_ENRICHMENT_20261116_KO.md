## 2. 목적과 원칙 (사용자 확정)
- 목적은 **풍부화**다. 기존 규칙과 대사를 갈아엎지 않는다. 임팩트 있는 사건·명령의 결과가 하단 대사창에 한두 줄로 끝나는 것을 고친다.
- 원래 글은 그대로 두고 **그 뒤에 덧붙인다.**
- 덧붙이는 것은 사건 설명이 아니라 **그 인물의 반응**이다.
- 보강 글은 수치를 바꾸지 않는다.
- **사건 발생만 따진다.** 마음이나 등급이 바뀐 것 자체는 사건으로 치지 않는다.
- 노예·조수·개인실 메이드 **모두에게** 적용한다. 개인실 화면의 대사창도 일반 대사창과 같은 크기로 본다.

## 3. 인물을 가르는 값
| 값 | 정하는 법 | 언제 | 상태 |
|---|---|---|---|
| 목소리 인물(5) | 유형(표현 = `temper` + `sensitivity`, 주장 = `ego` + `pride`, 0~3 / 4~6 / 7+)으로 묶음. 순종·여린 = 순한 사람, 평범·솔직 = 담백한 사람, 도도·불꽃 = 센 사람, 인형·관조·얼음 = 조용한 사람. 공주 출신 직업(mprincess, barbarian_princess)과 반말 유니크는 공주 | **영입 때 한 번 정해 저장.** 기존 세이브는 값이 없으면 그때의 유형으로 한 번 정함 | 사용자 "진행" |
| 태도(3 + 2) | `psy_status` 묶음. 움츠림 = frightened·lachrymose·depresive / 순함 = soft·docile·optimistic / 따름 = obedient·servile·horny / 맞섬 = reluctant·resistant·arrogant·hateful·hysteric / 무너짐 = broken | 매번 읽음(하루 안에서도 바뀜). 헌신과 부딪히면 헌신이 먼저(아래 "원고 칸 고르기") | 묶음은 Claude 제안, 우선순위는 사용자 확정 |
| 호칭 | **헌신 등급(`moral`) 하나로.** 반말 인물은 0 "너·네놈", 1~2 "당신·이름", 3 이상 "주인·마스터". 존댓말 인물은 0 "당신", 1 이상 "주인님" | 매번 읽음 | 사용자 확정 |
| 여운 지문 | 헌신 2 이상일 때만 붙임 | 매번 읽음 | 사용자 확정 |

**원고 칸 고르기.** 헌신이 태도보다 먼저다(사용자 결정 2026-11-16). 칸은 아래처럼 고른다.

| 헌신 등급 | 정신 상태가 움츠림 쪽 | 맞섬 쪽 | 순함·따름 쪽 |
|---|---|---|---|
| 3 이상 | 움츠림 칸 | **따름 칸** | **따름 칸** |
| 0~2 | 움츠림 칸 | 맞섬(기존 거부·맞받는 말) | **순함 칸** |

- 따름 칸은 헌신 3 이상에서만 나온다. 호칭이 "주인·마스터"로 바뀌는 선과 같다. 정신 상태가 복종중이어도 헌신이 2 이하면 순함 칸을 쓴다.
- 헌신 3 이상이면 그날 정신 상태가 순함 쪽이든 맞섬 쪽이든 따름 칸을 쓴다. 맞섬 쪽까지 따름 칸으로 보내는 것은 "헌신을 먼저 따른다"를 그대로 적용한 Claude의 해석이다.
- 움츠림(두려움·슬퍼함·우울증)은 헌신과 부딪히지 않는다. 헌신이 높아도 울거나 가라앉아 있을 수 있다.

- 말투는 인물에게 고정이다. 일반 노예는 존댓말, 공주와 반말 유니크는 반말. 관계가 변해도 바뀌지 않는다.
- 노예의 속마음은 직접 적지 않는다(기존 게임에 그런 표기가 없다). 여운은 관찰 지문이다.
- 칸 안의 두 낱말(너/네놈, 당신/이름, 주인/마스터) 중 어느 것을 쓸지는 아직 사용자 확정이 없다. Claude 제안: 네놈 = 주장 높음, 이름 = 표현 높음, 마스터 = 현대 이후 세계 출신.

## 6. 구현 방향 (Claude 제안, 미검증)
1. 명령 결과를 만드는 곳(`interaction_result`)이 원래 글을 `$text[n]`에 채운 뒤, 보강 호출 한 줄이 무게를 본다.
2. 블록은 `갈래(또는 사건).목소리 인물.태도` 키로 찾고, 없으면 목소리 인물을 `*`로, 그다음 태도를 `*`로 바꿔 찾는다.
3. 원고는 변수에 올리지 않는다(세이브에 들어가지 않게). 작은 location에서 필요할 때 읽는다.
4. 인물마다 새로 저장하는 값: 목소리 인물(숫자 하나), 갈래별 마지막으로 낸 날짜와 줄 번호(문자열 하나), 아직 말하지 않은 큰 일. 인물을 바꿀 때 함께 따라가야 한다. **인물 교체 때 값이 따라가게 등록하는 위치는 아직 찾지 못했다.**
5. 조수용 반응 글(`*_reaction_assistant`)과 개인실 화면에도 같은 호출을 넣는다. 넣을 자리는 확인하지 않았다.

## 7. 새 대화 커맨드(헌신 등급으로 주제가 열림)에 대해 정해진 것
- 위치는 대화하기 > 질문한다 아래, 하루 1회, 행동력 0.5(기존 결정).
- 거부 순서: 절망 3 이상 → 응석 3 이상 → **헌신 0**(2026-11-16에 "인식 2 이하"에서 바꿈).
- 연령 코드 1에게는 열지 않는다.
- 거짓말 판정에 쓰는 장악력은 `master_supermacy`가 이미 대상 인물 기준으로 계산된다(`$calculate_attributes` 545행). 판정 직전에 그 인물로 다시 계산해 쓴다.
- 대답 문장은 사용자가 쓴다. Claude는 구조만 만든다.

## 8. 아직 모르는 것
- 인물 교체 때 새 값이 따라가게 하는 등록 위치.
- `brand = 5`의 뜻.
