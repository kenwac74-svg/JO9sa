## 1. 재검토 결론
기존 정책의 문제는 하나다. **분기 축이 너무 많고, 그중 여럿이 게임이 이미 계산해 둔 값을 다시 계산한다.**

- 기존 축: 유형 9 × 말투 3 × 어휘 4 × 관계 모드 7 × 감정 종류 3 × 깊이 3. 한 대답 자리에 이론상 수백 칸이 생긴다. 원고를 다 채울 수 없고, 못 채운 칸은 공통 문장으로 떨어져 축을 나눈 의미가 없어진다.
- 게임의 **정신 상태**(`psy_status`, 화면의 "정신 상태")는 이미 기분·헌신·두려움·절망·응석·인식·흥분·복종도·성격·자아·태도·감수성을 종합해 15가지 중 하나를 낸다(`#static_base` 1087~1143행). 기존 정책의 관계 모드, 감정 깊이 식 3개, 현재 상태 반영은 이 값을 다시 만드는 일이었다.

그래서 방향을 이렇게 바꾼다.

1. **분기는 플레이어가 화면에서 보는 값으로만 한다.** 정신 상태, 헌신 등급, 속성 네 개, 직업. 플레이어가 "왜 이렇게 말하지?"를 화면으로 설명할 수 있어야 한다.
2. **원고를 나누는 축은 둘뿐이다.** 말결 4종 × 태도 3종 = 한 대답 자리에 최대 12칸. 나머지 정보는 원고를 늘리지 않는 방식(호칭 빈칸, 길이 상한, 수치 배율, 주제 열림)으로 반영한다.
3. **단계(0~5 등급)만 쓰고 진행 수치("단계" 칸의 −4, 8 같은 값)는 쓰지 않는다.**

## 3. 분기 판정표: 노예 정보 → 대사
대사 하나는 아래 일곱 값으로 정해진다. 왼쪽 세 열이 "어떤 정보를 읽어 무엇을 정하는가"다.

| 판정값 | 읽는 정보(화면 표기) | 결과 | 원고를 나누는가 |
|---|---|---|---|
| ① 말문 | 특성(벙어리), 정신 상태, 자리별 조건 | 대답 / 거부 / 말 없음 | 거부 대사만 따로 |
| ② 말투 | 직업, 유니크 지정 | 일반 존댓말 / 격식 존댓말 / 반말 | 문장 칸(일반 필수) |
| ③ 말결 | 성격·감수성·자아·태도 | 짧은 / 낮추는 / 담백한 / 내세우는 | **나눈다(4)** |
| ④ 태도 | 정신 상태 | 맞섬 / 움츠림 / 순함 / 따름 / 무너짐 | **나눈다(3)**, 맞섬·무너짐은 말문에서 처리 |
| ⑤ 열림 | 헌신 등급 | 0 닫힘 / 1 조금 / 2 다 | 주제·조각의 필요 등급으로 거름 |
| ⑥ 길이 | 말결, 태도 | 단답 / 1쪽 / 2쪽 | 안 나눈다(상한만) |
| ⑦ 호칭 | 말투, 태도, 헌신·인식 등급, 유형, 출신 세계 | 너·네놈 / 당신·이름 / 주인·마스터 / 주인님 | 안 나눈다(빈칸) |

여기에 섹스토크 같은 사실 대답에는 ⑧ 꾸밈(9유형 배율)과 ⑨ 속내(장악력 < 0이면 거짓)가 붙는다. 둘 다 원고를 나누지 않는다.

### 3.1 ① 말문
순서대로 보고 먼저 걸리는 것으로 끝낸다.
1. 선천적 벙어리 → 대사 없음(기존 안내 문구).
2. 태도 무너짐(정신병) → 침묵 지문 또는 정신분열 전용 대사.
3. 태도 맞섬 → 기존 거부 대사(`$refuse_talk`, 정신 상태별). 새로 쓰지 않는다.
4. 자리별 조건(섹스토크는 4장).
5. 그 밖은 대답.

### 3.2 ② 말투
| 말투 | 대상 | 원고 |
|---|---|---|
| 일반 존댓말(~요) | 아래 둘이 아닌 모든 인물 | **필수** |
| 격식 존댓말(~습니다) | 직업 maid, valertry, secretary, nun, policewoman, mind_contol, time_plice, jailer, academy, mech | 선택. 없으면 일반 존댓말 문장을 쓴다 |
| 반말 | 지정 유니크 8명(3002·2610·2620·3010·3021·3023·2621·3012), 공주 출신 직업(mprincess·barbarian_princess) | **핵심 대답만 필수.** 덧붙임 조각에 반말 문장이 없으면 그 조각은 건너뛴다(말이 짧아질 뿐 존댓말로 떨어지지 않는다) |

- 말투는 평생 바뀌지 않는다. 관계가 나빠도 존댓말 인물은 존댓말, 복종해도 반말 인물은 반말이다.
- 반말 인물이 존댓말 문장으로 떨어지는 일은 없어야 한다. 그래서 핵심 대답에는 반말 칸이 반드시 있어야 하고, 빌드 도구가 빠진 칸을 검사한다.

### 3.3 ③ 말결 4종
표현 = 성격 + 감수성, 주장 = 자아 + 태도. 0~3 낮음, 4~6 중간, 7 이상 높음(기존 9유형 판정 그대로).

| 주장 \ 표현 | 낮음 | 중간 | 높음 |
|---|---|---|---|
| 낮음 | 인형 → **짧은** | 순종 → **낮추는** | 여린 → **낮추는** |
| 중간 | 관조 → **짧은** | 평범 → **담백한** | 솔직 → **담백한** |
| 높음 | 얼음 → **짧은** | 도도 → **내세우는** | 불꽃 → **내세우는** |

| 말결 | 쓰는 법 | 예(일반 존댓말, 칭찬받은 날) |
|---|---|---|
| 짧은 | 한두 마디. 감정 낱말을 쓰지 않는다 | "…들었어요." |
| 낮추는 | 자기를 낮추고 고마움·미안함이 먼저 나온다. 말끝을 흐린다 | "칭찬해 주셔서… 더 열심히 할게요." |
| 담백한 | 느낀 대로 말한다 | "칭찬받으니까 기분 좋아요." |
| 내세우는 | 당연하다는 투, 조건을 달거나 요구한다 | "받을 만하니까요. 계속 그래 주세요." |

- 유형 전용 문장을 더 쓰고 싶으면 조각에 유형을 지정할 수 있다(전용 행이 말결 행보다 먼저 뽑힌다). 필수는 말결 4칸이다.
- 같은 말결 안의 차이(순종과 여린, 도도와 불꽃)는 길이(3.6)와 꾸밈 배율로 드러난다.
- 지정 유니크는 유형 지정값으로 말결을 정한다.

### 3.4 ④ 태도 5종
| 태도 | 정신 상태(화면 표기) | 뜻 | 원고 |
|---|---|---|---|
| 맞섬 | 거리감 reluctant, 저항심 resistant, 혐오감 arrogant, 증오심 hateful, 관심병 hysteric | 대답하지 않거나 맞받는다 | 기존 거부 대사. 새 대답 원고 없음 |
| 움츠림 | 두려움 frightened, 슬퍼함 lachrymose, 우울증 depresive | 묻는 말에 답하지만 겁먹었거나 가라앉아 있다 | 태도 칸 1 |
| 순함 | 상냥함 soft, 온순함 docile, 긍정적 optimistic | 거스르지 않지만 아직 마음을 주지 않았다 | 태도 칸 2 |
| 따름 | 복종중 obedient, 노예근성 servile, 발정중 horny | 스스로 따른다 | 태도 칸 3 |
| 무너짐 | 정신병 broken | 말이 되지 않는다 | 전용 대사 |

- 게임이 정신 상태를 정할 때 이미 기분, 헌신, 두려움, 절망, 응석, 인식, 흥분, 복종도, 속성 네 개를 본다. 태도는 그 결과를 그대로 받는다. 따로 식을 만들지 않는다.
- 조각의 태도 칸은 `*`(공통)로 둘 수 있다. 핵심 대답은 움츠림·순함·따름 세 칸을 따로 쓰기를 권한다.
- 발정중은 따름에 넣되, 섹스토크에서는 전용 머리말 지문을 붙일 수 있다.

### 3.5 ⑤ 열림
| 헌신 등급 | 열림 | 뜻 |
|---|---|---|
| 0~1 | 0 닫힘 | 사실만 짧게. 속마음·바람·옛 상처는 말하지 않는다 |
| 2~3 | 1 조금 | 에둘러 말한다. 암시 |
| 4~5 | 2 다 | 속마음을 그대로 말한다 |

- 조각마다 필요 열림(0~2)을 적고, 인물의 열림보다 큰 조각은 뽑지 않는다.
- 말결 '짧은'과 '내세우는'은 열림 2라도 약한 모습을 말하지 않는다(말결이 먼저다).
- 기존의 취약·적대·긍정 깊이 식 세 개는 쓰지 않는다. 적대 감정을 드러내는지는 태도(맞섬)가 이미 정한다.

### 3.6 ⑥ 길이
| 말결·유형 | 기본 상한 |
|---|---|
| 짧은(인형·관조·얼음) | 단답, 1쪽을 넘지 않는다 |
| 순종·평범·도도 | 1쪽(230자) |
| 여린·솔직·불꽃 | 2쪽(460자) |

- **태도가 움츠림이면 상한을 한 단계 낮춘다**(2쪽 → 1쪽, 1쪽 → 단답 수준). 기분이 바닥인 노예가 길고 밝게 말하지 않게 하는 유일한 장치다. 기분을 별도 축으로 두지 않는다.
- 태도 움츠림에서는 느낌표를 쓰지 않는다.
- 몸 상태(기력 바닥, 배고픔, 상처, 흥분)는 대사 앞에 지문 한 줄만 붙인다. 대사 문장은 바꾸지 않는다.

### 3.7 ⑦ 호칭
관계 단계는 말투와 상관없이 하나로 정한다.

| 단계 | 조건 |
|---|---|
| 나쁨 | 태도가 맞섬 |
| 복종 | 태도가 따름이거나 헌신 등급 3 이상(맞섬 제외) |
| 중간 | 그 밖 |

| 단계 | 반말 인물 | 존댓말 인물 |
|---|---|---|
| 나쁨 | 너 / 네놈 (인식 등급 2 이상이면 당신) | 당신 |
| 중간 | 당신 / 주인공 이름 | 주인님 |
| 복종 | 주인 / 마스터 | 주인님 |

- 칸 안의 두 낱말은 인물마다 고정한다. 네놈 = 주장 높음(얼음·도도·불꽃), 주인공 이름 = 표현 높음(여린·솔직·불꽃), 마스터 = 출신 세계가 현대 이후(modern, cyberpunk, utopia, darkfuture, space, sns). 그 밖은 너, 당신, 주인.
- 원고는 호칭을 빈칸으로 쓴다. 조사까지 붙은 꼴 표는 v0 4.4에 있다.
- 헌신 3은 게임이 조수 자격과 외양간 지기 임명에 쓰는 선이다(QSP 확인).
- 존댓말 인물이 중간 단계에서 "주인님"을 쓰는 이유: 두려워하거나 순한 노예는 마음을 주지 않았어도 그렇게 부르도록 길들여져 있다. 호칭을 거부하는 것은 맞설 때뿐이다.

### 3.8 원고량 비교
| | 기존 정책 | 재검토안 |
|---|---|---|
| 한 대답 자리의 칸 | 유형 9 × 관계 7 × 깊이 3 = 189 (어휘 4종 포함 시 756) | 말결 4 × 태도 3 = **12** |
| 최소 원고 | 유형 공통 1 + 관계 공통 1 | 공통 1 |
| 권장 원고 | 정해진 바 없음 | 핵심 대답 12칸, 덧붙임은 말결 4칸 |
| 문장 벌 수 | 말투 3벌 | 일반 1벌 필수, 격식 선택, 반말은 핵심만 |

섹스토크 22개 주제의 핵심 대답을 권장량으로 쓰면 22 × 12 = 264칸이다. 반말 인물용은 22 × 4(말결) = 88문장을 더 쓴다(태도는 공통).

## 4. 섹스토크 관문 수정안
| 순서 | 조건 | 반응 |
|---|---|---|
| 1 | 오늘 이미 함 | 메뉴 비활성 |
| 2 | 연령 코드 1 | 메뉴 없음 |
| 3 | 3.1의 말문(벙어리, 무너짐, 맞섬) | 각각의 기존 처리 |
| 4 | 절망 등급 3 이상 | "말씀 드리고 싶어도 기억이 안 납니다" |
| 5 | 응석 등급 3 이상 | "몰라요, 말하기 싫어요, 흥~" |
| 6 | **헌신 등급 0** | "그런 은밀한 제 비밀에 대해서 대답할 의무는 없습니다" |
| 7 | 헌신 등급 1~5 | 등급만큼 주제가 열린다 |

- 바꾼 것은 6번이다(기존: 인식 등급 2 이하). 주제표가 헌신 1부터 시작하므로, 헌신 0은 열 주제가 없는 상태이고 그때 이 거부 대사가 나오는 것이 자연스럽다.
- 인식은 "자기가 노예임을 아는 정도"라서 낮으면 오히려 경계 없이 말할 수도 있다. 속을 여는 정도는 헌신이 맞다.
- 태도 맞섬은 3번에서 이미 걸러지므로 기존 "적대면 거절" 규칙과 겹치지 않는다.

## 5. 실제 예: 화면 값으로 판정해 보기
사용자가 2026-11-16에 준 화면의 노예 값이다.

|---|---|
| 감수성 여림(5), 성격 수동적임(3), 자아 주관적(3), 태도 당당함(3) | |

| 판정값 | 계산 | 결과 |
|---|---|---|
| 유형 | 표현 3 + 5 = 8(높음), 주장 3 + 3 = 6(중간) | 솔직 |
| ③ 말결 | 솔직 | 담백한 |
| 정신병 여부 | 자아 3 + 성격 3 + 태도 3 = 9 | 정상 |
| ④ 태도 | 슬퍼함 | 움츠림 |
| ⑤ 열림 | 헌신 5 | 2(다 말한다) |
| ⑥ 길이 | 솔직은 2쪽, 움츠림이라 한 단계 낮춤 | 1쪽, 느낌표 없음 |

## 7. 확인하지 못한 것
- 정신 상태의 바탕값(`psy_basic`, 인물마다 타고나는 기본 상태)이 어떻게 정해지는지 읽지 않았다. 태도 판정은 최종 값만 쓰므로 영향은 없다.
- 반말 인물의 "공주 출신"을 직업 두 개(mprincess, barbarian_princess)로 잡았다. 출신 가족이 공주인 경우까지 넣을지는 데이터에서 확인하지 않았다.
- 출신 세계 키(modern 등)는 편집기 계수 파일의 이름이며 게임 변수 이름과 같은지 확인하지 않았다.

## 8. 다른 대사 조립형 게임과의 비교 (Sixth Sense, 2026-11-16)
사용자가 준 단일 HTML(약 19MB, 묶인 스크립트)을 읽었다. 구조만 참고하고 문장과 코드는 가져오지 않는다. 묶이고 줄여진 코드라 대사 데이터와 등록 함수, 데이터 안의 설명문(`_doc`)까지 읽었고, 고르는 함수 전체는 읽지 못했다.

### 8.1 그 게임의 구조
| 항목 | 내용 |
|---|---|
| 인물 | 고정 히로인 3명. 인물마다 말투·호칭·말버릇을 손으로 따로 썼다. 성격 유형 같은 일반화는 없다 |
| 대사 양 | 인물 자리표시가 든 줄이 약 3만 8천, 속마음 표시(『 』)가 약 1만 5천 |
| 한 줄의 모양 | 3인칭 행동 서술 + "대사" + 『속마음』이 한 문장 단위에 섞여 있다 |
| 키 | 점으로 이은 계층 키. 자리.인물.행위.세부.결과 꼴이고 `*`로 일반 줄을 둔다(구체적인 키가 없으면 일반 키) |
| 관계 축 | 관계 단계 0~5 하나. 원고는 묶음으로 쓴다: low(0~1), mid(2~3), high(4~5), all |
| 결과 축 | accept(받아들임) / hesitate(망설임) / refuse(거절) / displeased(불쾌) 네 가지 |
| 상태 반영 | 상태를 키의 한 칸으로 넣는다(잠 깊이 deep·mid·light, 안마 분위기 calm·tense·melt 등). 자리마다 필요한 상태만 |
| 조건·가중 | 줄에 조건(when)과 가중치(desire 등)를 붙일 수 있다 |
| 조사 | 빈칸 안에 조사를 적는다(`{her|이/가}`). 이름 받침에 맞춰 자동 선택 |
| 숨은 성향 | 성향마다 쌓이는 계기(triggers), 누르는 계기(suppress), 힌트 한 줄, 봉인 문구가 있다 |
| 반복 방지 | 키마다 줄을 여럿(많은 곳은 24개) 두고 최근에 쓴 줄을 피한다 |
| 데이터 분리 | 대사는 엔진과 떨어진 묶음(pack)이고 우선순위와 추가 방식이 있다 |

### 8.2 재검토안과 같은 점
- **원고를 나누는 칸 수가 비슷하다.** 그 게임은 한 행위에 인물당 단계 묶음 3 × 결과 4 = 12칸, 재검토안은 말결 4 × 태도 3 = 12칸이다. 조립형 대사에서 사람이 채울 수 있는 크기가 이 정도라는 근거가 된다.
- **관계는 0~5 한 축을 세 묶음으로 쓴다.** 재검토안의 열림(헌신 0~1 / 2~3 / 4~5)과 같은 방식이다.
- **말투는 인물에게 고정이다.** 관계가 깊어져도 존댓말 인물은 존댓말, 반말 인물은 반말이고, 달라지는 것은 내용과 거리감이다. "말투 고정, 관계는 호칭만" 방향과 맞는다.
- 숨은 성향 힌트, 최근 줄 피하기, 대사를 엔진과 분리하는 것도 같다.

### 8.3 다른 점
| | Sixth Sense | JO9 |
|---|---|---|
| 인물 | 3명 고정, 인물별 원고 | 랜덤 노예 다수 + 유니크. 인물별 원고가 불가능해 말결 묶음이 필요하다 |
| 관계 | 호감이 쌓이는 한 방향 사다리 | 맞섬·움츠림·무너짐처럼 호감 축 밖의 상태가 있다(정신 상태) |
| 서술 | 지문 중심, 대사는 그 안에 | 대화 커맨드는 이름표 + 대사 중심 |
| 분기 방식 | 키 계층과 `*` 대체 | 조각 행의 메타데이터 칸으로 거름 |

### 8.4 가져올 것 (제안)
1. **결과에 '망설임'을 넣는다.** 재검토안의 말문은 대답과 거부 둘뿐이다. 주제의 필요 열림이 인물의 열림보다 한 단계 높을 때 조각을 버리지 않고 **망설임 대답**(얼버무림)을 낸다. 두 단계 이상 높으면 거부. 섹스토크에서 "아직 못 여는 주제"가 그냥 안 보이는 대신 말끝을 흐리는 반응으로 보인다.
2. **조각을 계층 키로 쓴다.** `자리.주제.말결.태도.결과` 꼴에 `*`를 허용한다. 예: `sextalk.partners.담백한.따름.accept`, 없으면 `sextalk.partners.*.따름.accept`, 그다음 `sextalk.partners.*.*.accept`. 메타데이터 칸을 채우는 것보다 쓰기 쉽고, 빠진 칸이 무엇으로 대체되는지 눈에 보인다. 유니크는 말결 자리에 인물 id를 써서 전용 줄을 먼저 뽑는다.
3. **조사 표기를 빈칸 안에 적는다.** `{호칭|이/가}` 꼴. 꼴이 바뀌는 '너'(네가, 네)만 예외 표로 둔다. v0 4.4의 여섯 가지 빈칸이 하나로 줄어든다.
4. **속마음을 줄 안에 함께 쓴다.** 꾸밈(부풀림·줄임)이나 거짓말일 때 따로 속말 조각을 고르지 않고, 같은 줄에 『 』로 붙여 쓴다. 조각 수가 줄고 겉말과 속말이 어긋날 일이 없다.
5. **상태는 필요한 자리에서만 키 한 칸으로.** 모든 대사에 현재 상태 축을 두지 않는다는 재검토안과 같다. 자리가 필요로 하면(예: 관계 직후) 그 자리 키에만 칸을 더한다.

### 8.5 가져오지 않을 것
- 인물별 전용 원고 방식: 3명에 3만 8천 줄이다. JO9의 인물 수에는 맞지 않는다.
- 호감 한 축만으로 관계를 나타내는 것: JO9는 정신 상태가 이미 있다.
- 지문 중심 서술을 대화 커맨드에 쓰는 것: 반복 커맨드(B)에는 맞지만 대화 커맨드(C)는 대사 중심을 유지한다.

## 9. Wayward 원본과 한국어판 두 개 분석 (2026-11-16)
사용자가 준 세 파일을 읽었다. 영어 원본(2026-09-30, 약 3MB) 하나와 한국어판 둘(약 18MB씩)이다. 구조만 참고하고 문장과 코드는 가져오지 않는다. 줄여진 코드라 데이터와 일부 함수만 읽었다. 원본의 기억·속마음·숨은 성향 장치는 기존 설계 문서(Wayward식 대화 구조 설계 v1, 10.1)가 이미 정리했으므로 여기서는 **대사 분기 방식**과 **한국어판의 말투 처리**만 적는다.

### 9.1 원본: 아내 한 명의 대사
| 항목 | 내용 |
|---|---|
| 인물 | 주인공의 아내 한 명. 말투는 고정이고 유형 일반화가 없다 |
| 대사가 있는 곳 | 대부분 코드 안 조건문에 문장이 직접 들어 있다. 대사 표(데이터)가 따로 없다 |
| 고르는 법 | 질문마다 대답 종류 후보를 만들고 상태로 점수를 매겨 가장 높은 것을 낸다. 확인한 종류 12가지(devoted, content, guarded, resentful, making_amends, taboo_charged, drifting, self_loss 등) |
| 후보에 붙는 값 | 털어놓는지(disclosure), 반응 종류, 기분 변화, 신뢰 변화 |
| 반응 종류 | eager / accept / neutral / hesitant / refuse / angry 여섯 가지. 가장 많은 것이 hesitant(97곳)이고 그다음이 refuse(69), eager(57) |
| 상태 | 신뢰, 기분, 욕구, 수치, 원망, 속죄 같은 여러 수치가 점수 식에 들어간다 |

- Sixth Sense는 대사를 **데이터(계층 키)** 로 두고, Wayward는 **코드(조건과 점수)** 로 둔다. Wayward의 생동감은 한 인물에 맞춰 조건마다 문장을 손으로 쓴 데서 나온다.
- 반응 중 **망설임이 가장 많다.** 받아들임과 거절 사이의 중간 반응이 이런 게임의 기본값이라는 뜻이다. 8.4의 1번(망설임 결과 추가)을 뒷받침한다.

### 9.2 한국어판: 말투를 어떻게 처리했나
이 부분이 JO9에 가장 직접 닿는다. 한국어판은 원본에 없는 **말투 계층**을 표시 단계에 덧붙였다.

| 항목 | 내용 |
|---|---|
| 말투 종류 | 4가지: plain(반말), polite(해요체), hage(하게체), hao(하오체) |
| 누가 어떤 말투인가 | **화자의 종류로 고정**한다. 손님 유형별(단골·호감형 = 해요, 술 취한 대담형·건달 = 반말, 귀족 = 하게, 부유한 호색가·수금원 = 하오)이고 이름 있는 인물은 따로 지정 |
| 문장을 만드는 법 | 줄마다 기본 문장 하나와 **말투 4벌을 미리 써 둔다.** 데이터 끝에 "검수한 정확한 표시 변형. 임의의 글을 실행 중에 활용하지 않는다"는 주석이 있다 |
| 양 | 말투 변형이 있는 줄은 **435개뿐**이다(435 × 4벌). 손님이 말하는 줄에만 적용했다 |
| 화자 표시 | 줄 안에 따옴표가 여럿이면 각각 누구 말인지 적어 둔다(손님 P, 아내 W). 손님 부분만 말투가 바뀌고 아내 부분은 그대로다 |
| 관계에 따른 변화 | 없다. 말투는 관계가 바뀌어도 그대로다 |
| 겹침 | 4벌 중 반말과 하게체가 같은 줄이 48개, 네 벌이 모두 같은 줄이 5개. 문장에 따라 말투 차이가 드러나지 않는 경우가 있다 |

- **아내의 말투는 나누지 않았다.** 주요 인물은 한 벌로 쓰고, 여러 명이 나오는 손님만 말투를 나눴다.
- 한국어판 두 파일은 같은 판(원본 2026-09-30 기준)이고 말투 계층의 함수 구성이 같다. 본문 크기가 약 15만 자 다른데, 어디가 다른지는 가려내지 못했다.

### 9.3 재검토안에 주는 뜻
| 재검토안 | 이 게임에서 확인된 것 |
|---|---|
| 말투는 인물에게 고정, 관계로 바뀌지 않는다 | 한국어판이 같은 방식이다. 화자 종류로 정하고 끝 |
| 어미를 자동으로 바꾸지 않고 말투마다 문장을 따로 쓴다 | 한국어판도 실행 중 활용을 금지하고 미리 쓴 변형만 쓴다 |
| 말투는 분기 축이 아니라 문장 칸이다 | 한국어판의 "기본 문장 + 말투별 변형" 구조가 그것이다 |
| 일반 존댓말만 필수, 나머지는 필요한 줄에만 | 한국어판도 전체가 아니라 435줄에만 말투 변형을 달았다 |
| 점수 판단 층은 보류 | Wayward 방식은 인물 한 명에 조건별 문장을 코드로 쓴 것이라 JO9의 인물 수와 원고량에 옮기기 어렵다. 보류 판정을 유지한다 |

### 9.4 추가로 가져올 것 (제안)
1. **여러 화자가 섞인 줄에는 화자 표시를 둔다.** 조수나 손님이 함께 나오는 줄에서 누구 말에 말투·호칭 규칙을 적용할지 줄마다 적는다. 지금 재검토안은 노예 한 명이 말하는 줄만 가정했다.
2. **말투 변형이 없는 줄은 변형 칸을 비워 둔다.** 반말과 존댓말이 같은 문장(지문만 있는 줄, 한 낱말 대답)은 한 벌만 쓰고 "말투 공통"으로 표시한다. 한국어판에서도 벌이 겹치는 줄이 적지 않았다.
3. **노예가 아닌 화자(손님, 고객, 상인)의 말투는 화자 종류표로 정한다.** 이 문서의 범위 밖이지만, 필요해지면 한국어판처럼 종류별 고정 말투 표 하나로 처리하면 된다. 노예에게 금지한 하게체·하오체도 그런 화자에게는 쓸 수 있다.

## 10. 화자를 다섯 인물로 줄이기 (사용자 방향 2026-11-16, 세부는 Claude 제안)
사용자: 화자가 수천 명이라 문제이니, 각각에게 개성을 주지 말고 유형으로 묶어 5개 이하로 줄이면 대상 인물이 5명 이하가 된다.

이 방향을 채택한다. 3.3의 말결 4종은 조각에 붙이는 꼬리표였는데, 이것을 **목소리가 정해진 인물(목소리 인물)** 로 바꾼다. 그러면 JO9의 원고 작업이 Sixth Sense(고정 인물 3명)나 Wayward(1명)와 같은 종류의 일이 된다. 이 절이 3.2·3.3을 대체한다.

### 10.1 목소리 인물 다섯
| 목소리 인물 | 해당 노예 | 말투 | 목소리 |
|---|---|---|---|
| 순한 아이 | 영입 때 유형이 순종·여린 | 일반 존댓말 | 자기를 낮추고 고마움·미안함이 먼저 나온다. 말끝을 흐린다 |
| 담백한 아이 | 평범·솔직 | 일반 존댓말 | 느낀 대로 말한다. 꾸밈이 없다 |
| 센 아이 | 도도·불꽃 | 일반 존댓말 | 당연하다는 투. 조건을 달고 요구한다. 비꼬는 존대 |
| 조용한 아이 | 인형·관조·얼음 | 일반 존댓말 | 한두 마디. 감정 낱말을 쓰지 않는다 |
| 공주 | 공주 출신 직업(mprincess·barbarian_princess) | **반말** | 명령하던 사람의 말. 호칭이 너·네놈 → 당신·이름 → 주인·마스터로 바뀐다 |

- 지정 유니크는 다섯 중 하나를 지정한다. 전용 줄을 쓴 유니크는 그 줄이 먼저 나온다(8.4의 계층 키에서 목소리 인물 자리에 유니크 id).
- 반말 유니크 8명은 기본이 '공주' 목소리다. 성격이 맞지 않는 유니크는 전용 줄을 쓴다.
- 정신병(무너짐)은 목소리 인물과 관계없이 공통 전용 대사다.

### 10.2 목소리 인물은 영입 때 정하고 바꾸지 않는다
- 영입 때의 속성(성격·감수성·자아·태도)으로 한 번 정해 저장한다(숫자 한 자리).
- 이유: 조교로 태도와 자아가 내려가면 유형이 바뀌는데, 그때 목소리까지 바뀌면 다른 사람처럼 들린다. 목소리는 그대로 두고 **변화는 태도(맞섬 → 움츠림·순함 → 따름), 열림, 호칭이 보여 준다.** "센 아이가 따르게 됐을 때"의 대사가 따로 있어야 길들인 보람이 드러난다.
- 이렇게 해야 목소리 인물 5 × 태도 3의 15칸이 모두 실제로 쓰인다. 지금 수치로 판정하면 '센 아이 × 따름' 같은 칸은 태도가 내려가는 순간 다른 유형으로 넘어가 거의 나오지 않는다.
- 기존 대사 9,120행은 지금처럼 현재 수치로 9유형을 판정한다. 이 규칙은 새로 쓰는 원고에만 적용한다.

### 10.3 개성은 목소리가 아니라 내용에서 나온다
수천 명이 다섯 목소리를 나눠 쓰더라도 아래가 인물마다 달라 같은 말을 하지 않는다.

| 인물마다 다른 것 | 원고 비용 |
|---|---|
| 과거 사실(첫 경험, 상대 수, 장소 등)과 영입 후 누적 | 없음(빈칸) |
| 수치 꾸밈 배율(9유형) | 없음 |
| 길이 상한(9유형과 태도) | 없음 |
| 호칭 단계 | 없음(빈칸) |
| 열린 주제(헌신 등급) | 없음 |
| 특성 화제, 출신 세계 사전 | 사전만 |

- 같은 집에 같은 목소리 인물이 둘 이상 있을 수 있다(노예, 조수, 개인실 4명). 키마다 변형을 3개 이상 두고, 최근에 쓴 줄을 **인물이 아니라 집 전체 기준**으로 피한다.

### 10.4 바뀌는 판정
| 재검토안 앞부분 | 이 절로 바뀜 |
|---|---|
| 말투 3종(일반 필수, 격식 선택, 반말 핵심만) | 목소리 인물마다 말투 하나. 일반 노예 넷은 일반 존댓말, 공주는 반말. **격식 존댓말은 새 원고에서 쓰지 않는다** |
| 말결 4종(꼬리표) | 목소리 인물 5(일반 4 + 공주) |
| 한 대답 자리 12칸 × 말투 벌 | 목소리 인물 5 × 태도 3 = **15칸, 문장은 칸마다 한 벌** |
| 유형을 말할 때마다 판정 | 영입 때 한 번 판정해 저장 |

- 섹스토크 22개 주제의 핵심 대답은 22 × 15 = 330칸이고, 말투 벌이 따로 없으므로 이것이 전부다. 앞의 계산(264칸 + 반말 88문장)과 비슷한 양이지만 칸마다 누가 말하는지가 분명하다.
- 격식 존댓말을 뺀 이유: 직업 10종 때문에 모든 문장을 두 벌로 쓰게 되는 축이고, Wayward 한국어판도 주요 인물은 한 벌로 썼다. 하녀·비서의 격식은 낱말(사전)로 드러낸다.

### 10.5 더 줄일 수 있는가
- 공주를 '센 아이'의 반말판으로 보면 네 명까지 줄지만, 반말 문장은 어차피 따로 써야 하므로 원고량은 같다. 다섯으로 둔다.
- 순한 아이와 담백한 아이를 합치면 세 명(+공주)이 된다. 다만 낮추는 말과 꾸밈없는 말은 같은 문장으로 쓰기 어렵다. 원고가 모자랄 때는 순한 아이 칸이 비면 담백한 아이 줄로 대체하도록 한다(계층 키의 대체 순서).
