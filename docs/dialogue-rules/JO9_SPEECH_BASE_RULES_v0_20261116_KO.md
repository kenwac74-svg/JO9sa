# JO9 말하기 기본 규칙 기획서 v0 (2026-11-16)

- 상태: **기획 초안. 게임 적용 전.** QSP와 mods는 건드리지 않았다.
- 성격: 섹스토크 전용 문서가 아니다. 노예·조수가 말하는 **모든 자리**가 따르는 기본 규칙이며, 섹스토크는 이 규칙을 쓰는 자리 중 하나다(7장).
- 표기: 각 규칙 끝의 **[확정]** 은 이미 사용자 결정이 있는 것(출처는 11장), **[제안]** 은 이 문서에서 새로 묶거나 채운 것이다. [제안]은 사용자 확인 전까지 구현하지 않는다.
- 우선순위: 이 문서와 옛 문서가 어긋나면 날짜가 늦은 사용자 결정이 우선한다. 어긋난 곳은 10장에 모았다.

## 1. 한 장 요약
대사 하나는 네 가지 물음에 차례로 답해서 만든다.

| 물음 | 정하는 것 | 주로 쓰는 입력 |
|---|---|---|
| ① 말하는가 | 대답 / 거부 / 말 못 함 | 현재 상태, 관계 |
| ② 무엇을 말하는가 | 화제와 사실 | 배경(저장된 사실), 현재 상태(오늘·요즘 일), 관계 |
| ③ 얼마나 말하는가 | 털어놓는 깊이, 길이, 부풀림·줄임 | 관계, 성격 |
| ④ 어떻게 말하는가 | 결(유형), 어미(말투), 낱말(어휘), 호칭 | 성격, 배경, 관계 |

핵심 원칙 세 가지.
1. **내용과 말투를 섞지 않는다.** 사실(무엇을)은 배경과 기록이 정하고, 성격은 말하는 방식에만 영향을 준다. [확정]
2. **오래가는 것이 바탕, 짧게 가는 것이 덧칠이다.** 배경 → 성격 → 관계 → 현재 상태 순으로 바탕에서 덧칠로 간다. 오늘 일이 평소 태도를 뒤집지 않는다(오늘 칭찬받은 얼음은 여전히 얼음처럼 말한다). [확정]
3. **대화는 수치를 바꾸지 않는다.** 남는 것은 기록(이력·숨긴 이야기·성향 표시)뿐이다. 예외는 섹스토크의 경험치 반영 하나다(7장). [확정]

## 2. 입력 네 묶음
| 묶음 | 변하는 속도 | 게임 값 | 정하는 것 |
|---|---|---|---|
| **배경** | 고정 | 세계, 출신 가족(`$slave_family`, 계층), 직업(`$slave_occupation`), 영입 때 저장한 과거 사실, 유니크 지정값 | 말투, 어휘, 호칭 예외, 말할 과거 내용, 빈칸 사전(장소·옛일) |
| **성격** | 조교로 느리게 변함 | 성격 `temper`, 감수성 `sensitivity`, 자아 `ego`, 태도 `pride` | 유형 9종, 길이 상한, 꾸밈(부풀림·줄임), 정신 상태 |
| **관계** | 며칠 단위 | 정신 상태 `psy_status`, 헌신 `moral`, 두려움 `fear`, 사육, 인식 `rational`, 응석 `spoil`, 이 노예에 대한 장악력 | 관계 모드, 깊이, 높임·호칭 덮어쓰기, 열리는 주제, 거짓말 |
| **현재 상태** | 하루 안 | 기분 `mood`, 절망 `angst`, 무드렛, 기력 `energy`, 몸 상태(배고픔·더러움·상처·잠자리), 흥분 `arousal`, 오늘 횟수(`already_done_today`, `daily_reward_count`, `daily_punishment_count`) | 말하는가, 오늘·요즘 화제, 몸 상태 머리말 |

- 같은 값이 두 묶음에 걸치는 경우: 헌신·두려움은 관계 묶음으로만 쓴다. 절망은 관문(①)에서만 쓴다.
- 이 표에 없는 값으로 말투를 바꾸지 않는다. 새 수치도 만들지 않는다. [확정: "새 값 없음" 원칙]

## 3. 결정 순서
아래 순서로 판정하고, 앞 단계가 "끝"을 내면 뒤 단계는 하지 않는다.

```text
0. 자리 확인        이 자리가 대사를 내는 자리인가, 하루 상한을 넘지 않았는가 (6장, 8장)
1. 말 못 함         선천적 벙어리 → 대사 없음(기존 안내 문구)                       → 끝
2. 정신 상태        정신분열 → 전용 대사 / 신경쇠약 → 일부 자리 차단 (4.1)
3. 거부             자리별 거부 조건(절망·응석·인식, 기존 거부 판정) → 거부 한마디  → 끝
4. 관계 모드·깊이    psy_status·헌신으로 모드, 감정 종류별 깊이 0~2 (4.5, 4.6)
5. 내용             자리가 허용하는 층에서 화제 고르기: 오늘 → 요즘 → 평소·과거 (5장)
6. 꾸밈             유형별 고정 배율로 수치를 부풀리거나 줄임, 거짓말 분기 (4.8, 7장)
7. 표현             유형 → 말투 → 어휘 → 호칭으로 조각 거르기, 반복 방지 (4.2~4.4, 4.7, 8장)
8. 조립·출력        빈칸 치환, 겉말·속말, 이어 붙이기, 230자 쪽 나눔 (4.9, 6장)
9. 기록             대사 이력, 숨긴 이야기, 성향 표시 (8장)
```

**덮어쓰기 우선순위**(④ 어떻게 말하는가에서 규칙이 부딪힐 때). [제안, 10장 결정 1·2]
1. 정신분열 전용 대사
2. 지정 유니크 프리셋(유형·말투·호칭)
3. 관계에 따른 높임·호칭 덮어쓰기(초기 상태·적대)
4. 배경에 따른 말투·어휘
5. 유형의 결

## 4. 규칙

### 4.1 말 못 함과 정신 상태 [확정]
- 선천적 벙어리(`jo9_voice_trait = 1`)는 발화가 필요한 자리 전부에서 대사 없이 안내 문구만 낸다. 새 대화 자리를 만들면 이 차단 범위에 함께 넣는다.
- 정신력 = 자아 + 성격 + 태도. **2 이하 정신분열, 3~4 신경쇠약.**
- 정신분열: 유형과 관계없이 전용 대사를 쓴다(조합형은 어투를 무작위로 섞고, 통 대사는 독백·환청).
- 신경쇠약: 유형 대사는 그대로 쓰되, 인형 유형이면 요구를 말하는 자리에서 덧붙이지 않는다.

### 4.2 유형 9종: 말하는 결 [확정]
표현 = 성격 + 감수성, 주장 = 자아 + 태도. 각각 0~3 낮음, 4~6 중간, 7 이상 높음. 유니크는 지정 유형(`seed_jo9_voice_type`)이 있으면 그것을 쓴다.

| 주장 \ 표현 | 낮음 | 중간 | 높음 |
|---|---|---|---|
| 낮음 | 인형 | 순종 | 여린 |
| 중간 | 관조 | 평범 | 솔직 |
| 높음 | 얼음 | 도도 | 불꽃 |

| 유형 | 결 | 쉽게 말하는 것 | 말하지 않는 것 |
|---|---|---|---|
| 인형 | 아주 짧다. 낱말만 | 거의 없음 | 자기 자신 |
| 순종 | 공손하고 자기를 낮춘다 | 작은 기쁨, 고마움 | 불만, 원하는 것 |
| 여린 | 망설이고 말끝을 흐린다 | 두려움, 슬픔, 정 | 분노, 원하는 것 |
| 관조 | 담담하게 사실만. 숫자를 정확히 | 판단, 관찰 | 바람, 속마음 |
| 평범 | 무난하고 그날 기분이 묻어난다 | 그날의 기분 | 깊은 속내 |
| 솔직 | 감정이 바로 나온다 | 기쁨, 서운함, 바람 | 거의 없음 |
| 얼음 | 짧고 차갑다. 선을 긋는다 | 경멸, 무관심, 자기 능력 | 감정 전부 |
| 도도 | 예의 있게 선을 긋는다. 은근한 우월감 | 자존심, 취향, 불쾌함 | 기쁨, 고마움 |
| 불꽃 | 거침없고 과시한다. 되묻는다 | 불만, 분노, 원하는 것 | 두려움, 약한 모습 |

- 유형은 저장하지 않고 말할 때마다 판정한다. 조교로 성격 값이 바뀌면 유형도 바뀐다.
- 유형의 "말하지 않는 것"과 깊이 계산(4.6)이 부딪히면 유형을 따른다.

### 4.3 말투와 어휘: 배경이 정한다
**말투(어미)** [확정 2026-11-13]

| 번호 | 말투 | 대상 |
|---|---|---|
| 1 | 격식 존댓말(~습니다) | 직업 maid, valertry, secretary, nun, policewoman, mind_contol, time_plice, jailer, academy, mech |
| 2 | 일반 존댓말(~요) | 그 밖의 일반 노예 |
| 3 | 반말 | 지정 유니크 8명(3002·2610·2620·3010·3021·3023·2621·3012), 공주 계열 직업(mprincess·barbarian_princess) |

- 반말 원고가 없는 조각은 2번 문장을 쓴다.
- 하옵니다체·하게체·하오체는 쓰지 않는다.

**어휘(낱말)** [확정 2026-10-15, 현행 여부는 10장 결정 3]

| 어휘 | 출신 가족 |
|---|---|
| 궁정·귀족가 하인 | mprincess, knight, valetry, servant |
| 세련된 | 그 밖의 계층 2 |
| 보통 | 계층 3·4, policeman, minitruth, church |
| 거친 | barbarian_king, tribe, amazon, nomad, gypsy, workhouse, orphan, orpnange, anter |

- 말투와 어휘는 따로 정해져 겹친다(예: 하녀 직업 + 하녀 집안 = 격식 존댓말 + 귀족가 하인 어휘).
- 비속어: 범죄자 직업·하류층·극빈층 출신만 쓸 수 있고, **독백과 제3자에게만** 쓴다. 주인을 부르는 데는 절대 쓰지 않는다. [확정]

### 4.4 높임과 호칭: 관계가 덮어쓴다 [확정 2026-11-12, 범위는 10장 결정 1]
| 상황 | 주인에게 |
|---|---|
| 기본 | 주인님, 4.3의 말투 |
| 초기 상태(사육·헌신·두려움 모두 1 이하) 또는 적대 관계, 출신 무관 | 반말, 당신 |
| 초기 상태 + 세습 귀족·공주 계층 + 인식 1 이하 | 반말, 너 / 네놈 |
| 지정 유니크 | 프리셋 |

- 인식이 2 이상이면 '너 / 네놈'은 쓰지 않는다. '당신' 반말은 남는다.
- 적대가 아닌 노예가 주인을 '당신'이라고 부르지 않는다(인칭 정리 R2).
- 서술문에서 주인공은 "당신", 노예는 이름 또는 "그녀". 한 블록 안에서 "너/널"을 섞지 않는다.

### 4.5 관계 모드 [확정]
| 모드 | `psy_status` |
|---|---|
| 적대 | reluctant, arrogant, hateful, resistant, hysteric |
| 두려움 | lachrymose, frightened |
| 우울 | depresive |
| 무너짐 | broken |
| 기대 | optimistic |
| 의무 / 헌신 | obedient, servile, horny (헌신 4 미만 의무, 4 이상 헌신) |
| 중립 | docile, soft |

- 모드는 조각의 "관계" 칸과 맞춰 후보를 거르는 데 쓴다. 무너짐 모드에서는 화제를 덧붙이지 않는다.

### 4.6 감정 깊이: 얼마나 털어놓는가 [확정, 식은 10장 결정 4]
감정 종류마다 점수를 내어 0 감춤 / 1 암시 / 2 드러냄으로 나눈다(4 미만 0, 8 미만 1, 그 이상 2).

| 감정 종류 | 점수 |
|---|---|
| 취약(두려움·수치·슬픔) | 2·헌신 − 태도 − 2·(두려움 4 이상) |
| 적대(분노·원망·혐오·질투) | 자아 + 성격 − 2·두려움 |
| 긍정(자부심·애정·고마움) | 2·헌신 + 감수성 − 태도 |

- 조각의 깊이가 허용 깊이보다 크면 후보에서 뺀다.
- 감출 때는 내용을 말하지 않고 겉모습만 말한다(적대 감춤 → "괜찮아요").
- 깊이가 모자라 말하지 못한 화제는 **숨긴 이야기**로 남기고, 나중에 깊이가 차면 꺼낸다(8장).

### 4.7 길이 [확정 2026-11-13]
| 표현 축 | 유형 | 상한 | 먼저 쓰는 대답 |
|---|---|---|---|
| 낮음 | 인형·관조·얼음 | 단답 수준, 최대 1쪽 | 단답(20자 이하) |
| 중간 | 순종·평범·도도 | 1쪽(230자) | 보통(21~89자) |
| 높음 | 여린·솔직·불꽃 | 최대 2쪽(460자) | 풍부(90자 이상) |

- 표현 낮음에 풍부한 답, 표현 높음에 단답은 쓰지 않는다. 맞는 길이가 없으면 보통을 쓴다.
- 주장 축은 길이가 아니라 태도로 드러난다(낮음 = 자기를 낮춤, 높음 = 선을 긋거나 과시).

### 4.8 꾸밈: 부풀림과 줄임 [확정]
수치를 말할 때 유형별 고정 배율을 곱한다. 배율이 고정이라 같은 질문에는 언제나 같은 수치가 나온다.

| 유형 | 배율(%) | 표현 |
|---|---|---|
| 불꽃 | 300 | 어림말, 과시 |
| 도도 | 150 | 어림말 |
| 솔직·평범 | 100 | 어림말 |
| 관조·얼음 | 100 | 정확한 숫자 |
| 순종 | 70 | 어림말, 줄여 말함 |
| 여린 | 50 | 어림말, 줄여 말함 |
| 인형 | 100 | 어림말, 아주 짧게 |

- 꾸밈은 말투의 일부다. 저장된 사실은 바뀌지 않는다.
- 꾸밈이 들어간 대답에는 속말을 붙여 실제 값을 흘릴 수 있다(4.9).
- 노예는 자기가 모르는 정보(정확한 게임 수치, 시스템 용어)를 말하지 않는다.

### 4.9 조립 형식 [확정]
```text
[이름] "대사 1: 핵심 대답"                         (필수)
       "대사 2: 기억 연결 — {그때} + 원인이 된 일, 또는 숨긴 이야기"
       "대사 3: 이전 대답 참조"
       (짧은 몸짓 지문 한 줄)
       속말: 기울임 1인칭, 겉말과 분리
```
- 조각은 끝까지 갖춘 완결 문장으로 쓰고 문장끼리만 잇는다. 어미를 자동으로 바꾸지 않고 말투마다 문장을 따로 쓴다.
- 빈칸: `{이름}`, `{상대}`, `{그때}`, `{장소}`, `{예전 일}`, `{N}` 어림말, `{X}` 정확한 숫자, 조사.
- `{그때}`: 오늘 − 기억 날짜가 0이면 "아까/오늘", 1 "어젯밤/어제", 2~3 "며칠 전", 4~7 "지난주", 그 이상 "전에".
- 한 줄에 느낌표는 한 번만 쓴다. 매질을 전제한 낱말("때리다", "매") 대신 "벌", "혼나다"를 쓴다.

## 5. 내용 고르기: 현재 상태와 과거
### 5.1 세 층 [확정]
| 층 | 다루는 것 | 쓰는 값 |
|---|---|---|
| 단기(오늘) | 오늘 일과 몸 | 오늘 횟수, 오늘 처벌·칭찬, 몸 상태 무드렛 |
| 중기(요즘) | 요즘 쌓인 일 | 무드렛, 최근 횟수, 기분, 기억 버퍼 |
| 장기(평소·과거) | 배경, 저장된 사실, 적성 | 원래 게임 문장, 영입 전 사실, 영입 후 누적 |

- 자리가 허용하는 층 안에서 **단기 → 중기 → 장기** 순으로 고른다. 오늘 일이 있으면 오늘, 없으면 요즘, 그것도 없으면 덧붙이지 않는다.
- 원래 게임 문장은 지우지 않는다. 새 대사는 그 앞이나 뒤에 붙는다.

### 5.2 현재 상태가 말에 끼치는 영향 [제안]
현재 상태는 **유형을 바꾸지 않고** 아래 세 곳에만 작용한다.

| 작용 | 내용 | 값 |
|---|---|---|
| 관문 | 말할 수 있는가, 거부하는가 | 절망, 기력, 자리별 거부 판정 |
| 화제 | 오늘·요즘 화제 후보를 연다 | 오늘 횟수, 무드렛, 기억 버퍼 |
| 머리말 | 첫 몸짓 지문 한 줄을 고른다(지쳐 있다, 배가 고프다, 달아올라 있다 등) | 기력, 몸 상태 무드렛, 흥분 |

- 기분(`mood`)은 평범 유형에서만 말의 결에 직접 묻어난다. 다른 유형은 화제 선택으로만 반영한다.
- 머리말은 지문이며 대사 본문의 말투·길이 규칙을 바꾸지 않는다.

### 5.3 사실의 일관성 [확정]
- 과거 사실은 영입 때 한 번 정해 저장하고 다시 뽑지 않는다. 같은 질문에는 언제 물어도 같은 사실이 나온다.
- 영입 후의 일(주인과, 주인 외, 이종)은 따로 누적하고, 과거 사실은 고치지 않는다. 대답은 "주인님을 만나기 전에는…", "여기 와서는…"으로 나눠 말할 수 있다.
- 날마다 바뀌는 것은 문장 표현과 덧붙임뿐이다.

## 6. 자리별 적용 [확정]
| 자리 | 예 | 시점 | 이 문서에서 쓰는 규칙 |
|---|---|---|---|
| A 비반복 특수 이벤트 | 고유 이벤트, 획득 장면 | 장면별 | 4.3·4.4(말투·호칭)만. 변주 없음 |
| B 반복 커맨드 | 노예와 섹스하기 등 | 3인칭 관찰자 | 결정적 한두 마디에 4.2~4.5. 한마디 = 주인 만족 등급 × 관계 × 유형 |

- 주인공은 어느 자리에서도 대사를 하지 않는다. 플레이어는 선택지만 고른다.
- 조수·개인실 인물도 같은 규칙을 쓴다.
- 창관 이야기는 창관 화면에서만 한다. 섹스토크의 누적 경험 언급과 겹치는 부분은 10장 결정 5.

## 7. 섹스토크에 적용할 때
세부는 `JO9_Sex_Talk_Planning_v0_20261112.md`(editor/character-studio-20261112 브랜치)가 기준이고, 여기서는 3장 순서의 어느 단계에 무엇이 들어가는지만 적는다.

| 단계 | 섹스토크의 내용 |

| 0 자리 | 대화하기 > 질문한다 아래. 하루 1회, 행동력 0.5 |
| 3 거부 | 절망 3 이상 → 응석 3 이상 → 인식 2 이하 순서 |
| 4 관계 | 헌신 1~5 등급이 주제 22개를 차례로 연다 |

| 9 기록 | 숨은 성향 표시. 경험치가 기준의 70% 이상이면 대화 1회 = 경험치 1(하루 1회) |

- 표시 불가 분류(B1 청소년기, B2 수간)는 원고 없이 키만 두고 화면에는 `[이 대사는 표시 불가합니다.]`만 낸다. 고르기·이력·일관성은 다른 조각과 똑같이 키로 돌아간다. [확정]

## 8. 조각 데이터와 저장 상태
### 8.1 조각 한 행의 칸 [확정]
| 칸 | 값 |
|---|---|
| 자리·질문 | 어느 자리의 어느 질문인가 |
| 역할 | 핵심 대답, 화제, 거부, 속말, 머리말 등 |
| 유형 | `*`(공통) 또는 유형 목록 |
| 관계 | `*` 또는 모드 목록 |
| 감정·깊이 | 감정 종류, 0~2 |
| 문장 | 말투 1·2·3별 원고 |
| 대기 일수 | 다시 쓰기까지의 날 수 |
| 표시 불가 코드 | 있으면 본문 없이 키만 |

- 고르기: 역할 → 관계 → 깊이로 거르고, 유형 전용 행을 공통 행보다 먼저 쓴다.
- 반복 방지: 대기 일수 안의 조각 제외 → 그래도 없으면 최근 2회만 제외 → 그래도 없으면 허용. 조건을 완화해 다양성을 만들지 않는다.
- 역할마다 공통 유형 행과 공통 관계 행이 하나씩은 있어야 후보가 비지 않는다.
- 조건은 `[값, 비교, 수]` 목록만 쓴다. 임의 코드는 넣지 않는다.

### 8.2 새로 저장하는 것 (인물당 문자열, 합계 약 250바이트) [확정 초안]
| 키 | 내용 |
|---|---|
| `jo9_mem` | 기억 버퍼. 강한 사건 최대 6개(종류·날짜·상대·세기) |
| `jo9_kept` | 숨긴 이야기. 화제 id와 날짜, 최대 4개 |
| `jo9_said` | 대사 이력. 최근 쓴 조각 id와 날짜, 최대 12개 |
| `jo9_talk_day` | 자리별 마지막 발화 날짜와 오늘 횟수 |

- 과거 사실은 별도 문자열 한 줄(약 250바이트). 인물을 바꿀 때 함께 따라가야 한다.
- 대사 원고는 변수에 두지 않는다(세이브에 들어가지 않게). 저장 방식은 PC에서 엔진 확인 뒤 정한다.

## 9. 구현 단계 [제안]
이 기획서가 승인된 뒤의 순서다. 각 단계는 앞 단계만으로 검증된다.

1. 판정 함수: 유형·말투·어휘·호칭·관계 모드·깊이를 한 곳에서 내는 함수(기존 `$voice_profile` 등 재사용). 검증은 편집기 시뮬레이터와 같은 입력 대조.
2. 과거 사실 생성·저장.
3. 섹스토크 관문과 화면 뼈대(대사 대신 주제 키만 출력).
4. 대답 조립: 원고가 있는 주제(첫 경험·상대 수·이종 경험)부터.
5. 기록(숨은 성향, 숨긴 이야기, 이력).
6. 영입 후 누적 연결.
7. 기존 대화(1111~1118)와 반복 커맨드를 같은 규칙으로 옮기기.
