# 칭찬·처벌·처형 커맨드의 노예 대사 추출 (2026-11-17)

- 대상: `assets/runtime/2.4.1/jack.qsp`. `interaction`에서 `$interaction_type`이 compliment(칭찬 1561~1565), execution(처형 182~187), 처벌 계열(torture, abuse, present_torture, prisoner_torture, torture_assistant, 낙인) 이거나 `torture_intensity`를 정하는 커맨드 78개와, 그 커맨드가 쓰는 글 변수, 정신 상태별 반응 글(`compliment_reaction`, `*_torture_reaction`, `bondage_reaction`, `compassion_reaction`, `execution_reaction`, 조수용 포함)을 훑었다.
- 대사의 기준: 따옴표로 직접 인용한 말, 또는 `[이름]` 표를 단 말. "애원했다"처럼 전한 말(간접 전달)은 대사로 치지 않았다.

## 1. 노예의 직접 대사가 있는 줄 (3줄, 모두 처형 위협)
| 위치 | 정신 상태 | 대사 |
|---|---|---|
| `#txt_woman` 1215행 `$execution_reaction['reluctant']` | 거리감 | "안 돼, 안 돼, 제발!" |
| `#txt_woman` 1227행 `$execution_reaction['hysteric']` | 히스테리 | "너 같은 좆도 못 세우는 호모 새끼가 그럴 배짱이나 있겠어." |
| `#txt_man` 991행 `$execution_reaction['reluctant']` | 거리감 | "안 돼요, 안 돼요, 안 돼, 제발!" |

- **칭찬**: 노예의 직접 대사 없음.
- **처벌**: 노예의 직접 대사 없음(구타·채찍·고문·구속·치욕·고문 관람, 조수용 포함).
- **처형**: 위 3줄뿐. 처형 위협 반응 글 45줄(`#txt_woman` 30, `#txt_man` 15) 가운데 3줄이다.
- `#txt_woman`과 `#txt_man`은 같은 변수를 따로 정의한 두 벌이다. 게임이 어느 쪽을 언제 쓰는지는 확인하지 않았다.

## 2. 대사로 잡혔지만 해당하지 않는 것
| 위치 | 이유 |
|---|---|
| `$woodenhorse_presentation_description` | 따옴표가 기구 이름("목마")에 쓰임 |
| `$humility_rule` | 따옴표가 호칭("주인님")에 쓰임. 규칙 설명 |
| `$abuse_need`, `$abuse_dislike` | 노예의 대사지만 처벌 메뉴가 아니라 대화(요구·불만 묻기)의 대답 |
| `interaction_result` 373·379행 | 조수가 수업 결과를 보고하는 대사. 처벌 메뉴 아님 |
| 앞선 조사에서 구속 반응 1줄, 가벼운 고문 2줄을 "대사 있음"으로 센 것 | 글 전체를 큰따옴표로 감싼 줄을 잘못 센 것. 실제 대사는 없다 |

## 4. 원칙 3에 비춘 결과
- 칭찬·처벌 커맨드는 원래 대사가 없는 장면이다. 풍부화하면 관찰 지문만 덧댄다.
- 처형 위협은 정신 상태 둘(거리감, 히스테리)의 원래 글에만 대사가 있다. 그 둘에만 대사를 덧댈 수 있고, 나머지는 관찰 지문만이다.
