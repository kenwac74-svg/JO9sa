# 모드 개발 핸드오프: 개인실에서 일반 노예로 돌아갈 때 강등 기분 (2026-11-19)

- 받는 쪽: 모드 개발. 이 문서를 쓴 쪽은 QSP를 바꾸지 않았다.
- 기준 파일: `assets/runtime/2.4.1/jack.qsp` SHA-256 `887f7e570e8df2a463c50c4855d4139a6e7a8602202f7039288d5bf15981d438`(main 커밋 ad10a099). 줄 번호는 이 파일 기준.
- 사용자 확정(문답 62): 조수 → 노예 강등 규칙을 개인실 → 일반 노예에도 적용한다. 개인실에서 방을 빼는 것이 일반 노예로 돌아가는 것이다.

## 1. 지금 규칙 (원래 게임에 있음)
- 노예·조수 맞바꾸기 `slave_to_assistant` 39~48행: 두 사람의 `shift` 표시를 켜고 끈다(같은 날 다시 바꾸면 꺼진다).
- 하루가 넘어갈 때 `next_day` 4473~4482행: 노예 자리 인물에 `shift = 1`이면 `slave["neg_sa_demote"] = 10`(강등 나쁜 기분), `pos_sa_promote = 0`. 조수 자리 인물은 승격 기분 100. 표시를 지운다.
- 이 기분이 있으면 기분 묻기(1116)에서 `native_1116_slave_neg_sa_demote_core` 대사가 나온다(목소리별 보완 원고 승인됨).

## 2. 개인실 코드
| 동작 | 위치 | 하는 일 |
|---|---|---|
| 방 배정 | `interaction` 12533~12611행(`interaction` 77711~77714) | 헌신 3 이상이면 `$swap_slave_instances, 'slave', 'roomN'`. 글 "방을 배정했다" |
| 방 빼기 | `interaction` 12617~12659행(`interaction` 77721~77724) | `$swap_slave_instances, 'roomN', 'slave'`. 글 "내 명령에 따라 방을 비웠다". 방에 있던 인물이 노예 자리로 온다 |

## 3. 바꿀 것
1. **새 표시 하나:** `jo9_room_shift`(인물 배열 키). 인물 배열과 함께 옮겨진다(`$swap_slave_instances`가 배열 전체를 옮김, QSP 엔진으로 확인함).
2. **방 빼기 4곳**(12623·12634·12645·12656행의 맞바꾸기 바로 뒤): 노예 자리로 온 인물에 표시를 켠다.
   ```
   slave['jo9_room_shift'] = 1
   ```
3. **방 배정 4곳**(12540·12560·12580·12600행의 맞바꾸기 바로 뒤): 방으로 들어간 인물의 표시를 끈다. 같은 날 방을 뺐다가 다시 넣으면 기분이 생기지 않는다.
   ```
   roomN['jo9_room_shift'] = 0
   ```
4. **`next_day` 4482행 뒤:** 노예 자리 인물만 강등 기분을 받는다. 그날 조수가 됐으면 일반 노예가 아니므로 받지 않고 표시만 지운다.
   ```
   if slave['jo9_room_shift'] = 1:
   	slave["pos_sa_promote"] = 0
   	slave["neg_sa_demote"] = 10
   end
   slave['jo9_room_shift'] = 0
   assistant['jo9_room_shift'] = 0
   ```

## 4. 정리한 동작
| 상황 | 결과 |
|---|---|
| 방을 빼서 일반 노예가 됨 → 하루 넘김 | 강등 나쁜 기분 10. 기분 묻기에서 강등 대사 |
| 방을 뺐다가 같은 날 다시 방에 넣음 | 기분 없음 |
| 방을 빼고 같은 날 조수로 올림 | 기분 없음(조수 승격 규칙은 원래대로) |
| 방 배정 | 이번 변경에서는 기분 없음(승격 기분은 요청 범위 밖) |

## 5. 검사
- 적용 전후 SHA-256, 왕복 동일, old 횟수.
- QSP 엔진: 방 배정 → 방 빼기 → `next_day` 실행 뒤 `slave['neg_sa_demote'] = 10`. 방 빼기 → 같은 날 다시 배정 → `next_day` 뒤 0. 기존 노예·조수 맞바꾸기 결과가 그대로인지.
- 게임 화면 확인은 사용자가 한다.
