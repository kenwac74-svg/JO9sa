## 4. 호칭 빈칸 (명랑한만)
명랑한의 호칭은 헌신·복종 수치에 따라 "당신" 또는 "주인님"으로 바뀐다. 그래서 주인공을 가리키는 말은 반드시 아래 빈칸으로 쓴다.

| 빈칸 | 낮을 때 | 높을 때 | 쓰는 자리 |
|---|---|---|---|
| `{호칭}` | 당신 | 주인님 | 조사 없이(예: "{호칭} 곁에", "{호칭}처럼") |
| `{호칭이}` | 당신이 | 주인님이 | 주어 |
| `{호칭은}` | 당신은 | 주인님은 | 주제 |
| `{호칭을}` | 당신을 | 주인님을 | 목적어 |
| `{호칭의}` | 당신의 | 주인님의 | 소유 |
| `{호칭에게}` | 당신에게 | 주인님께 | 받는 쪽 |
| `{호칭부름}` | (지워짐) | 주인님 | 문장 끝에서 부를 때. ", {호칭부름}."처럼 쉼표 뒤에 둔다. 낮을 때는 쉼표와 함께 지워진다 |
