## 1. 다시 쓸 때 지킬 것
1. 아래 "지금 줄"과 "닮은 줄"을 그대로 쓰거나 몇 단어만 바꿔 쓰지 않는다. 몸짓 자체를 바꾼다.
2. 목소리의 결(몸짓 사전)과 칸의 뜻(움츠림·순함·따름(복종)·따름(헌신))은 그대로 지킨다.
3. 같은 목소리라면 사건끼리 **첫 문장(첫 동작)이 달라야** 한다. 이번에 새로 쓰는 보상 줄과 절정 줄끼리도 마찬가지다.
4. 보상·절정·임신 장면에는 벌의 흔적(아픈 자리, 맞은 자리 등)을 쓰지 않는다.
5. 자세가 한 줄 안에서 맞아야 한다(서 있으면서 턱을 괴는 식은 안 된다).
6. 등장인물은 모두 성인이다. 미성년자를 떠올리게 하는 표현, 동물과의 성행위는 쓰지 않는다.

## 2. 사건별 장면
- **부끄러운 벌** (`shame_punish`): 치욕 계열 처벌 뒤. 부끄러움과 굴욕이 몸에 남아 있다(이번에 다시 쓰지 않음, 비교용)
- **몸으로 받는 보상** (`erotic_reward`): 성적 보상을 받은 뒤. 벌이 아니라 **받은 쪽**이다. 몸이 풀렸거나 달아올랐고, 그것을 대하는 태도가 칸마다 다르다. 아픔·벌 흔적을 쓰지 않는다
- **절정과 그 뒤** (`climax`): 절정 직후. 숨이 가라앉지 않았고 다리·손끝에 떨림이 남았으며, 땀과 흐트러진 옷매무새를 어떻게 다루는지가 칸마다 다르다. 보상 장면과 겹치지 않게 **몸이 아직 회복되지 않은 상태**를 중심으로 쓴다
- **임신 확인** (`pregnancy_reveal`): 임신이 드러난 뒤 주인을 처음 마주함. 배·손·자세의 변화가 중심이다. 다른 사건(벌·보상)의 몸짓을 가져오지 않는다
