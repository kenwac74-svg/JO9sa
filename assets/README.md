# assets — mods가 쓰는 이미지 원본

mods(`mods/*.json`)가 새로 부르는 이미지를 게임 폴더 기준 경로(`game\` 아래)로 보관한다.
경로는 지금 mods에 적힌 그대로(`content\pic\SNKmod\...`)다. 2.4 빌드가 `SNKmod\`를 일괄로 지우므로 여기서는 옮기지 않는다.

- `content/pic/SNKmod/scene/whore_redlight/whore_redlight-{p,r,s,t,u}00{1,2,3}.png` (15개): 홍등가 장면 시퀀스
  - r/s: 펠라 담당(22701) `2026-10-02_whore_redlight_sequences`
  - t/u: 길거리 창녀(22702) `2026-10-03_whore_redlight_b_v_tu_random`
  - p: 개인 영업녀(22703) `2026-10-03_whore_redlight_c_p_sequence`
- `content/pic/SNKmod/characters/master_robertus_rufus.png`, `content/pic/SNKmod/ui overhaul/robertus_rufus.png`, `robertus_rufus_gray.png` (3개): 미술 교사 로베르투스 루푸스(`2026-10-01_robertus_rufus_art_tutor`, 아이콘은 `json/menu_icon.json`의 `menu_item_art_tutor`·`_gray`). 2.4 정식 이미지.
