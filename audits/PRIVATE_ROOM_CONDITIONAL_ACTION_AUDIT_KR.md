# 개인실 하단 조건부 행동 버튼 점검

점검일: 2026-09-28. 대상: TEST11 소스 및 배포 qsp-patches.json. 정적 코드 대조이며 실제 게임 클릭 검증이나 수정/재빌드는 수행하지 않았다.

## 확정된 누락

모유 착유 버튼이 개인실 1~4 및 snk_room_menu_screen 모두에 없다. 배포 패치의 각 화면에는 식사 설정, 보상, 씻기만 존재한다.

- 원작 메인 UI: main_screen.qsrc:523–529. 노예가 존재하고 lactation > 0이면 착유 버튼 표시. milk_summ >= 10이면 활성, 그 미만이면 회색 비활성 및 ‘젖이 부족함’ 안내. 수유하지 않으면 숨김.
- 원작 개인실: slave_private_room1~4.qsrc:217. 방별 착유 호출은 interaction 596, 597, 598, 599로 이미 존재한다.
- 누락 원인: build/private_room.py:164 이후 하단 행동칸에는 착유가 없다. 같은 파일 236 이후 착유 생성 코드는 과거 자체 정보 팝업 안에 들어 있으며, 246 이후 해당 팝업 블록을 통째로 제거하므로 최종 결과에 남지 않는다. UI 통합 과정의 누락이다.
- 복구 대상은 활성 착유와 모유 부족 시 비활성 표시 두 상태다. 권장 순서: 식사 설정 → 보상 → 씻기 → 착유.
- 후속 구현 시 방별 기존 로직을 재사용한다. 행동 하위 메뉴에서는 임시 대상 교환을 먼저 복구해야 하므로 방 번호 및 원래 거주자 대상으로 실행되는지 확인해야 한다.

## 메인 노예 행동칸 전체 대조

main_screen.qsrc:984의 실제 출력 항목 7개를 기준으로 점검했다.

| 항목 | 개인실 상태 | 판정 |
|---|---|---|
| 보상 | 있음 | 누락 아님 |
| 씻기 | 있음, 위생 조건에 따른 활성/비활성 | 누락 아님 |
| 모유 착유 | 없음 | 확정 버그 |
| 처벌 | 없음 | 사용자 결정에 따른 숨김 |
| 청소 | 없음 | 사용자 결정에 따른 숨김 |
| 음식 준비 | 없음 | 사용자 결정에 따른 숨김 |
| 안개 괴물 착정 | 없음 | 사용자 결정에 따라 개인실에서 제외 |

안개 괴물 착정은 main_screen.qsrc:334–340에서 tentacle_state = 1, slave_state = slave_exist, slave['tentacle_rule'] = 1일 때 나타나며 interaction 59를 호출한다. 자신의 모유 착유와는 다른 기능이다. 2026-09-28 사용자 확정: 개인실은 노예가 쉬는 공간이자 특별한 포상이므로 이 임무는 개인실에서 제외한다. 개인실 1~4 및 개인실 행동 하위 메뉴에 해당 버튼이나 연결을 추가하지 않는다. 메인 UI의 기존 기능은 유지한다. 따라서 이번 점검에서 복구가 필요한 누락 기능은 모유 착유뿐이다.

식사 설정은 개인실에 추가된 버튼이다. 성적 상호작용 빠른 버튼은 메인 주인공 행동칸에 속하며, 개인실에서는 좌측 메뉴로 제공하므로 노예 하단 행동칸 누락으로 세지 않는다. 우측 모유 물방울 표시는 상태 정보이며 착유 행동 버튼을 대신하지 않는다.

## 후속 확인 기준

1. 수유 없음: 착유 버튼 숨김.
2. 수유 중, 모유 10 미만: 회색 버튼과 부족 안내.
3. 수유 중, 모유 10 이상: 활성 버튼과 해당 방 거주자 착유 실행.
4. 개인실 1~4 및 보상 등 하위 메뉴에서도 같은 표시 유지.
5. 실행 후 해당 거주자의 모유량/결과가 반영되고 개인실 화면으로 복귀.

이번 점검에서는 코드와 배포물 변경 없이 이 기록만 추가했다.

후속 처리: 사용자 재빌드 요청에 따라 TEST12에서 모유 착유 버튼과 부족 시 회색 표시를 복구했다. 안개 괴물 착정은 제외 유지. 검증 결과는 TEST12_REPORT_KR.md 참조.
