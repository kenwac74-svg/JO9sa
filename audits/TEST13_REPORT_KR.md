# TEST13 개인실 출산 및 부정적 분기

2026-09-28. 개인실 1~4의 임신 150일 이상 출산 호출을 기본 화면/하위 메뉴에 연결했다. 1층 메인 화면에서 발생해도 동일한 개인실 반환 경로를 사용한다. 이벤트 전 임시 대상 교환을 복구하며 원래 개인실 슬롯을 유지한다. 기존 의료시설 이벤트 종료와 ESC 모두 출산한 인물의 개인실로 돌아온다.

원작 500 스파크 정상 분기와 잔액 부족 시 부정적 결과를 유지했다. 개인실별 누락된 부정적 대사는 원작 일반 노예 대사를 해당 방 이름으로 적용했다. 잘못된 roomN_mood 대입을 roomN['mood'] = -8로 고쳤다. 여러 방의 출산은 순차 처리하며 출산 중 중복 호출을 막는다.
