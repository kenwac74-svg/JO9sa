JO9 대사 편집실

대사를 찾아 각본으로 저장하거나 수정합니다. 각색 요청은 전송 버튼을 누를 때만 실행하며, 승인한 수정문을 현재 QSP에 저장합니다.

게임 파일을 읽고 있습니다.

1. 게임에서 본 원문 찾기

화면에 치환된 이름은 원문과 다를 수 있습니다. 이름을 제외한 문장 일부로 찾아 주세요. 결과는 최대 200개입니다. 「게임에 보이는 대사만」은 변수 이름·경로·코드 문자열을 숨깁니다.

저널 호출 키워드

Kindroid Narrator에 등록한 NPC·장소 저널을 이름으로 호출합니다. 선택한 키워드는 각색 전송과 요청 복사에 포함됩니다.

2. 선택한 대사 수정

선택한 따옴표 안의 문자열 하나만 바뀝니다. 코드나 경로 문자열이 검색될 수도 있으므로 위치와 원문을 확인하세요.

＋ 대사 추가

선택한 원문은 그대로 두고 새 대사를 추가합니다. 다음 페이지 추가는 뒤쪽 대사·페이지 조건·그림·소리·실행 처리를 함께 조정합니다. 새 페이지는 앞 페이지의 그림을 이어받으며 실행 처리와 소리는 복제하지 않습니다.

변수·조건 코드 확인 · 읽기 전용

대사를 먼저 선택하세요.

확인 후 반영

변수·치환문·HTML 태그 보존 검사를 통과했습니다. 파일 전체를 백업한 뒤 이 위치에만 반영합니다.

3. 장면의 흐름




조건별 대사는 별도 경로로 표시합니다. 이미지는 현재 플레이 폴더의 최신 파일이며, 여러 후보가 있으면 각각 고를 수 있습니다. 세이브 변수에 따른 최종 선택은 게임에서 확인하세요.

수정 각본 검토·반영


수정본을 아래에 붙여 넣거나 TXT를 여세요. 검토 결과 오른쪽 수정문도 직접 편집할 수 있습니다. 카드에서 고친 내용은 전체 각본에 동기화되며, 다시 구문·화면 검토 후 WORK에 반영합니다.








재대조는 원문이 그대로이며 위치가 유일한 대사만 연결합니다. 이미 바뀐 원문은 덮어쓰지 않습니다.




화면 분량은 지정한 텍스트 영역의 줄바꿈·넘침을 측정합니다. 변수는 표기 그대로 표시하며 실제 이름 길이·게임의 글꼴·이미지 배치에 따라 달라질 수 있습니다. 실행 중인 게임 전체를 검사하는 기능은 아닙니다.







고급 출력 · 각색본 일괄 반영

선택한 장면에서 시작해 선택지·이동으로 이어지는 장면을 따라가며 대사 전체를 페이지 구분선과 함께 한 문서로 만듭니다. AI가 각색한 결과를 아래 ‘각색본 반영’에 붙여 넣으면 페이지 번호로 원래 대사를 찾아 한 번에 반영합니다.



 
 
 
 
 
 
 






단어 일괄 치환

단어가 포함된 대사를 찾고 치환할 위치를 체크하세요. 한 대사에 여러 번 나오면 모두 바뀝니다. 검색 결과 전체 선택은 모든 페이지에 적용됩니다.




위의 보기 설정을 따릅니다. 정규식 없이 입력한 글자 그대로 찾고 바꿉니다. 게임 파일은 마지막 반영 버튼을 눌렀을 때 저장됩니다.
