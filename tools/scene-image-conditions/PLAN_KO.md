# Scene 이미지 재현 조건 표시

요청: WORK scene 폴더의 이미지마다 등장 조건을 이미지 체크리스트 카드에 표시한다.

- 현재 QSP·실행 JSON·CSS를 읽어 이미지 경로, enclosing if/else, 호출 이벤트/메뉴, 페이지 슬롯, 난수와 명시적 번호 조합을 추적한다. 재생 연결과 데이터/대체컷 등록을 구분한다. 파일명이나 그림 내용만으로 조건을 만들어내지 않는다.
- 직접 연결, 명시적 무작위/동적 후보, 아이템 등 정의부 등록, 수동 대체컷, 실행 연결 미확인을 구분해 모든 파일에 항목을 만든다. 조건은 정적 분석이며 실행 성공 검증과 다름을 표시한다.
- 체크리스트의 기존 rowHtml 출력에 읽기 전용 설명만 추가한다. 요약은 항상, 상세 코드/위치는 펼쳐서 표시한다. 기존 상태·교체 기능·이미지·QSP·세이브는 유지한다. 기존 /api/state로 QSP 해시가 달라졌는지 알린다. 서버 신규 API/재시작은 필요 없다.
- WORK와 catalog-seed에 동일 모듈/데이터를 삽입한다. 카탈로그에 없는 현재 씬은 상태를 건드리지 않고 목록에 추가한다. 실제 브라우저에서 표시·다른 필터·체크 상태 비변경을 검증한다.
- 회귀 테스트: 주석 배제, 조건/else, 공용 번호 무작위의 명시적 연결, 자동 연결 금지(public_use), 경로별 분리, 데이터 정의/수동대체 구분, HTML escape, 전체 파일 포함. 최종 기록과 재생성 스크립트를 보존한다. 배포/커밋/푸시 없음.
