잭오나인 캐릭터 추가 · 통합 편집 도구
2026-11-03 개선본

■ 실행
「캐릭터추가.bat」을 실행하고 위쪽에서 사용할 game 폴더를 선택합니다.
add_character.py와 character_editor_ui.py는 같은 폴더에 두세요.
Python 3와 Pillow가 필요합니다. rembg는 배경 제거를 쓸 때만 필요합니다.

■ 기존 캐릭터 교체 — 한 화면에서 끝내기
1. 왼쪽 얼굴 목록에서 캐릭터를 클릭하거나 기존 ID를 입력하고 [불러오기].
   ID·이름·JSON 파일명 검색, 머리색·나이 필터를 사용할 수 있습니다.
2. [전신 이미지 선택 / 교체]로 새 전신 한 장을 선택합니다.
   원본 크기와 구도로 표시하며, 이 단계에서는 전신을 자르거나 재배치하지 않습니다.
3. 전신 위에서 얼굴 영역을 정사각형으로 드래그합니다.
   오른쪽 원본·흑백·세피아 미리보기를 확인합니다.
   다시 드래그하면 얼굴 위치를 다시 지정할 수 있습니다.
4. [ID ○○ 변경사항 저장]을 누릅니다.
   전신과 얼굴 3종을 함께 저장합니다. 별도 편집 창은 열리지 않습니다.

이미 얼굴이 따로 있으면 [별도 파일]을 선택해도 됩니다.
전신만 바꾸려면 새 전신을 선택한 뒤 [기존 얼굴 유지]를 고릅니다.
얼굴만 바꾸려면 불러온 전신에서 새 영역을 지정하거나 별도 얼굴 파일을 고릅니다.

■ 기존 정보 보존
· 기존 ID, JSON 파일명, 머리색·길이·나이 분류, 랜덤 등장 등록 범위는 유지합니다.
· 2579_egeya.json처럼 번호 뒤에 이름이 있는 JSON도 불러옵니다.
· 전신과 얼굴 파일명이 다른 인물도 JSON에 적힌 각각의 경로에 저장합니다.
· 선택하지 않은 하녀·도미나·비서 복장과 나머지 설정은 유지합니다.
· 신체 정보만 바꾸면 이미지 파일은 다시 저장하지 않습니다.
· JSON 내용이 바뀔 때 처음 한 번 .bak을 남깁니다.
· 기존 세이브의 능력치·분류를 새 JSON 값으로 바꾸는 기능은 아닙니다.
  같은 경로의 그림 교체는 기존 세이브에서도 해당 경로를 사용할 때 보입니다.

■ 복장
하녀·도미나·비서의 [선택]으로 추가/교체할 그림을 지정합니다.
[지우기]는 저장 시 해당 복장 연결을 없앱니다. 다시 누르면 삭제 예약을 취소합니다.
이미 예약한 교체를 모두 버리려면 [변경 취소]를 누르세요.
기존 복장은 원래 경로를 사용하고, 새 복장은 full/cloth·mistress·secretary에 저장합니다.
단, 기본 전신이나 다른 복장과 파일을 공유하면 선택한 복장용 파일을 따로 만듭니다.
다른 슬롯이나 indpack 설정에서 계속 참조하는 파일은 복장을 지워도 남겨둡니다.

■ 새 캐릭터 추가
1. [＋ 새 캐릭터]를 누릅니다.
2. 전신을 선택하고 얼굴을 드래그합니다.
3. 머리색·머리길이·나이 분류와 필요한 신체 정보를 고릅니다.
4. 필요하면 복장 3종을 추가하고 [캐릭터 추가]를 누릅니다.
새 번호·JSON·전신·얼굴 3종을 만들고, 등록 옵션을 켰다면 랜덤 등장 범위도 갱신합니다.
기존 캐릭터 편집에서는 이 등록 옵션을 변경하지 않습니다.

■ 이미지 옵션
· 배경 자동 제거: rembg 설치 시 사용 가능합니다. 처음 사용 시 모델을 받을 수 있습니다.
· 최종 저장 크기: 얼굴 지정·배경 제거를 원본 크기로 처리하고, 저장 직전에만
  전체 이미지를 비율대로 조절해 795×596 안에 맞춥니다.
  비율 차이로 남는 부분은 중앙 기준 투명 여백으로 채웁니다.
  원본을 크롭하거나 인물·알파 경계를 찾아 이동하지 않습니다.
  이미 795×596인 입력은 그대로 사용합니다. 복장 전신에도 같은 규칙을 적용합니다.
· 얼굴 표준 크기: 원본 도구와 같은 151×150으로 맞춥니다.
얼굴은 크기 조절·배경 제거 전의 원본 전신에서 잘라 흑백·세피아를 자동으로 만듭니다.
예전에 잘못 배치되어 저장된 이미지를 다시 불러오는 것만으로 원래 구도는 복원되지 않습니다.
이 경우 중앙에 인물이 있는 원본 전신을 다시 선택하고 얼굴을 지정해 저장하세요.

■ 저장 전 확인
[저장 내용 미리보기]는 로그로 변경 예정 경로를 보여주며 파일을 저장하지 않습니다.
[변경 취소]는 편집 중인 변경을 버리고 현재 저장된 캐릭터를 다시 불러옵니다.
다른 캐릭터로 이동하거나 창을 닫을 때 미저장 변경이 있으면 확인합니다.
같은 ID의 JSON이 두 개 이상 있으면 잘못 덮어쓰지 않도록 저장을 중단합니다.
기존 캐릭터 저장 중 파일 쓰기가 실패하면 이번 저장에서 바뀐 파일을 복구합니다.

■ 캐릭터 삭제
오른쪽 아래 [캐릭터 삭제]를 누르면 삭제 범위와 확인 안내가 나옵니다.
중간 번호는 기존 도구처럼 번호 유지/번호 이동 중 선택합니다.
번호 이동은 기존 세이브의 인물 참조에 영향을 줄 수 있습니다.
삭제 전 원본 자료와 게임 JSON·이미지는 별도로 보관하세요.

게임을 실행한 뒤 전신, 얼굴 3종, 선택한 복장이 의도대로 보이는지 확인하세요.
