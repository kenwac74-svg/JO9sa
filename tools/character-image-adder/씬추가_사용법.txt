  잭오나인테일즈 씬(scene) 추가 도구  (add_scene.py)
════════════════════════════════════════════════════════════

■ 캐릭터 추가와 다른 점 (씬이 훨씬 간단)
  · json 등록 / slave_index 갱신 / 흑백·세피아 생성 전부 없음.
  · 그냥 '파일 이름 규칙에 맞춰 폴더에 넣으면' 게임이 자동 인식(폴더 개수만 셈).
  · 누끼 필요 없음 (씬은 배경 있는 완성 이미지).


■ 실행
  · 「씬추가.bat」 더블클릭.  (python add_scene.py)


■ 쓰는 순서
  1. 씬 종류 고르기 : 일반 / 성행위 / 고문 / 보상
  2. 행위(act) 고르기 : 목록에서 선택(그 폴더의 기존 행위들) 또는 직접 입력.
       예) bj, analsex, whip, bath, cook ...
       * 게임이 실제로 부르는 행위 이름이어야 그 상황에서 뜹니다.
         (목록에 있는 것을 쓰는 게 안전)
  3. 카테고리 :
       - 공용(general) : 모든 머리색 공용. 한 장이면 그 나이대 전부 커버. (추천/간단)
       - 특정          : 머리색 + 길이 지정.
  4. 나이 고르기 : loli / young / milf   (특정이면 머리색/길이도)
  5. (선택) 2인 조합(~) 씬이면 체크하고 상대 캐릭터 조합도 지정.
  6. 씬 이미지 선택.
  7. 아래 파란 글씨로 '저장될 파일 이름'을 확인하고 [씬 추가하기].
  8. 같은 조합을 또 넣으면 자동으로 _2, _3 ... 번호가 붙습니다.


■ 파일 이름 규칙 (참고)
  · 특정 : <행위>_<머리색>_<길이>_<나이>.png    예) bj_black_long_young.png
  · 공용 : <행위>_general_<나이>.png             예) bj_general_young.png
  · 2인  : <행위>_<A>~<B>.png                    예) lesbian_black_long_loli~general_milf.png
  · 여러 장 : 뒤에 _2, _3 ...  (자동)


■ 옵션
  · 큰 이미지는 표준 크기에 맞게 축소 (기본 켜짐) :
      성행위/일반은 795x596, 고문은 800x600 박스 안에 '비율 유지'하며 축소.
      - 표준보다 큰 이미지만 줄이고, 작은 건 그대로 둡니다.
      - 비율을 유지하므로 찌그러지지 않습니다. (4:3 이미지는 딱 795x596 이 됨)
      - 끄면 원본 크기 그대로 저장.
