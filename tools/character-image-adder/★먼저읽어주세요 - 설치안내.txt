이 도구는 게임에 내 캐릭터 일러스트/씬 이미지를 편하게 넣어줍니다.
  · 캐릭터추가.bat  - 노예 캐릭터(전신+얼굴) 추가, 수정, 삭제, 옷(외형) 추가
  · 씬추가.bat      - 각종 씬 이미지 추가

2026-11-03 통합 편집 개선:
  기존 캐릭터는 왼쪽 목록/ID로 불러와 같은 화면에서 편집합니다.
  전신 한 장 선택 → 얼굴 영역 드래그 → 변경사항 저장으로 끝납니다.
  전신은 원본으로 작업하고, 저장 직전에 전체 비율을 유지해 795×596에 맞춥니다.
  add_character.py와 character_editor_ui.py를 같은 폴더에 두세요.


────────────────────────────────────────────────
■ 준비물 : 파이썬(Python) 3
────────────────────────────────────────────────
1) 파이썬이 없으면 https://www.python.org/downloads/ 에서 설치.
   ★ 설치 화면에서 "Add Python to PATH" 체크박스를 꼭 켜세요.
   (이미 파이썬이 있으면 건너뛰어도 됩니다)


────────────────────────────────────────────────
■ 설치 (한 번만)
────────────────────────────────────────────────
2) 「1_필수설치_먼저실행.bat」 을 더블클릭하면 파이썬 라이브러리를 자동 설치합니다.

   [무엇이 설치되나요?]  아래 명령을 실행합니다:
        python -m pip install --upgrade pillow rembg onnxruntime

   · Pillow             : 이미지 처리(리사이즈/흑백/세피아 등).  ★필수★ (용량 작음)
   · rembg              : 전신 배경 자동제거(누끼) AI.  선택
   · onnxruntime        : 위 rembg 의 AI 모델을 돌리는 엔진.  (rembg 용)

   rembg 는 혼자 못 돌아서 아래 패키지들도 '자동으로 같이' 설치됩니다
   (전부 PyPI 공식 오픈소스 - 이미지/수치 계산용 표준 라이브러리):
        numpy, scipy, scikit-image, opencv-python-headless, numba, llvmlite,
        pymatting, imageio, tifffile, pooch, jsonschema, coloredlogs,
        sympy, networkx  등

   [안전한가요?]  네. 전부 PyPI(공식 파이썬 패키지 저장소)의 유명 오픈소스이고,
        개인정보 수집/전송 없이 전부 '내 PC 안에서만' 동작합니다.
        부담되는 건 용량뿐 - rembg 쪽이 무거워서 다 합치면 수백 MB 정도 됩니다.
        누끼를 '처음 쓸 때' AI 모델(isnet-anime, 약 170MB)을 한 번 더 받습니다.

   [누끼가 필요 없다면 - 가볍게 설치]
        배경 제거(누끼) 기능을 안 쓸 거라면 Pillow 하나만 설치해도 됩니다.
        (이미지 추가/수정/삭제, 씬 추가 전부 정상 동작. 누끼 버튼만 비활성)
        명령창(cmd)에서 아래만 실행하세요:
            python -m pip install pillow
        rembg 는 나중에 필요할 때 추가로 깔면 됩니다.
