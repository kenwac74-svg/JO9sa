Jack O Nine Tails 2.4.1 한국어판 — 1차 패치 안내
2026-11-03

■ 캐릭터 대사 번역 보완
아르곤이 작업한 캐릭터 설정·과거 대화 번역을 반영했습니다. 일부 인물의 이미지 경로를 수정하고, 기존 세이브의 번역 표시를 보완했습니다.

■ 장비 이미지 보완
집 상단 장비칸에서 표시되지 않던 퍼레이드 복장, 노예 팔찌, 빵봉지 등 29개 아이템의 소형 아이콘을 추가했습니다. 창녀 코스튬의 대표 그림도 교체했습니다.

■ 보관함 정리
보관함을 식품 저장고 / 재료상자 / 물약상자 / 가구 및 용품의 네 열로 나누어 확인하기 쉽게 정리했습니다.

■ 연금술 화면 개선
캐릭터가 대사창을 가리던 배치를 수정했습니다. 우측 재고를 재료상자와 물약상자로 나누고, 기존에 빠져 있던 물약도 표시하도록 개선했습니다.

■ 아이템 명칭 통일
도수높은 주류 → 증류주
안개 괴물 점액질 → 괴물 점액질

■ 물약 상점 설명 보완
마리아나의 이름 표시를 한글로 수정하고 물약 효과 설명을 보완했습니다. 다음 물약의 표시 이름을 변경하고, 카오틱 에센스 안내를 추가했습니다.
대사+ → 아나볼릭 / 대사- → 코르티코
지방+ → 메게이스 / 지방- → 위고비

■ 명기 생산 조건 조정
크라켄 생산은 안개괴물 교육 B등급부터 가능하도록 조정했습니다. 기존 수확 보너스는 유지됩니다.

■ 카오틱 에센스 제거 규칙 수정
부정 특성을 먼저 제거하고, 해당 특성이 없을 때만 장단점이 있는 특성을 제거하도록 정리했습니다. 이상성욕 선호, 용감함, 색정광, 가학성애자와 지정된 신체 특성은 제거 대상에서 제외했습니다. 대사량도 전용 약물로 조절하도록 보호했습니다.

■ 패치 적용 방법
이 패치는 기존 2.4.1 한국어판 Full용입니다.
1. ZIP을 별도 폴더에 압축 해제하고 게임을 완전히 종료합니다.
2. 기존 게임의 game\json\slaves 폴더를 제거합니다.
   캐릭터 파일명이 바뀐 항목이 있어 폴더 교체가 필요합니다. 세이브는 game\save에 유지됩니다.
3. 패치의 game 폴더를 기존 게임 폴더에 복사하여 덮어씁니다.
4. 평소 사용하던 실행 파일로 게임을 다시 실행합니다.

별도 설치 프로그램이나 실행 파일 교체는 필요하지 않습니다. 기존 세이브를 사용할 수 있으며, 이미 저장된 인물의 설명은 저장 내용에 따라 새 번역과 일부 다를 수 있습니다.
