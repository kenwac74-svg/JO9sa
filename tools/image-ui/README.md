# JO9 이미지 편집

프로젝트 루트의 `start-image-ui.cmd`를 더블클릭합니다. 실행 창은 사용 중 열어둡니다.
또는 API 키를 설정한 PowerShell에서 `npm run image-ui`를 실행하고 http://127.0.0.1:3099 에 접속합니다.

1. API 설정에서 OpenRouter 키를 입력합니다. 서버 환경변수에 키가 있으면 생략합니다. 화면 입력 키는 서버 메모리에만 보관되며 재시작하면 다시 등록해야 합니다.
2. 원본 이미지와 선택적으로 고정 캐릭터의 얼굴 기준 이미지를 불러옵니다.
3. 작업 방식과 변경 프롬프트를 지정하고 이미지 편집하기를 누릅니다.
4. 결과를 확인한 후 PNG 저장을 누릅니다. 결과를 원본으로 버튼은 다음 편집의 원본을 바꿉니다. 얼굴 기준은 유지됩니다.

인페인팅은 브러시로 칠한 영역을 시각적 가이드로 전송하고 생성 결과에서 그 영역만 원본에 합성합니다. 네이티브 마스크 API가 아니므로 영역 내 생성 위치와 경계 품질은 보장하지 않습니다.
아웃페인팅은 확장 캔버스를 전송하고 결과를 목표 크기에 맞춘 후 원본 영역을 복원합니다. 경계 연속성은 결과에서 확인해야 합니다.
img2img의 얼굴 유지에는 기준 이미지와 유지 지시를 사용하며 동일 캐릭터를 보장하는 얼굴 잠금 기능은 아닙니다.

원본, 기준 이미지, 수정 영역 가이드, 프롬프트는 편집 버튼 실행 시 OpenRouter 및 모델 제공자에게 전송됩니다. 결과는 브라우저 메모리에 표시하며 저장 버튼으로 다운로드합니다. 새로고침 전 저장하세요.
실제 생성은 유료이며 사용자가 실행합니다. 원본 게임 파일은 수정하지 않습니다.
