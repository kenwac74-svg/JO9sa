# 일대일 치환 검토 화면 시안

실제 편집기 구현 전의 화면 시안이다. 예시 문구만 사용한다.

2026-11-15 사용자 결정으로 범용 편집기 개발은 긴급패치 이후로 보류했다. 확정한 목적과 미정 사항은 [설계 보류 기록](DESIGN_PAUSED_KO.md)에 남겼다. 이 시안 자체는 당시 화면을 보존하며, 새로 논의한 코드·조건 태그 기능을 구현한 상태는 아니다.

- 원문과 대상 문구를 나란히 표시한다.
- 대상 위치를 사용자가 직접 지정한다.
- 체크박스로 치환할 항목을 선택한다. 처음에는 모두 미선택이다.
- 선택한 항목의 변경 전후를 미리 볼 수 있다.
- 검색은 검색 버튼이나 Enter를 눌렀을 때 실행한다.
- 파일 열기·파싱·교체·저장은 구현하지 않았다. Python 코드는 이 시안 폴더만 읽기용으로 표시한다.
- 문구 내용이나 연령 코드에 따른 분류·필터는 없다.

사용자가 이 시안을 검토한 후 설계를 다시 정한다. 기존 QSP 및 자동 복원안은 적용하지 않는다.

로컬 미리보기: `python preview.py`를 실행하고 출력된 주소를 연다. 서버는 이 폴더만 정적으로 제공하며 게임 파일 쓰기 API가 없다.
