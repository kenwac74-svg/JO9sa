# 범용 QSP 대사·연결 코드 편집기 — 설계 보류 기록

기준일: 2026-11-15. 상태: 사용자와 요구사항 협의 중, 긴급패치 이후로 개발 보류.

## 2026-11-15 최신 개발 목표

사용자 확정 최상위 목표: **AI의 판단이 개입하지 않는 자유로운 창작툴**. 핵심 편집에 AI 호출·내용 분류·AI 승인을 요구하지 않으며, 사용자가 변수·선택지·조건·대사·이미지와 변경 적용을 직접 결정한다. AI는 사용자가 요청할 때만 현재 우측 대화창에서 보조한다.

1차는 JO9 자유 편집과 기존 모드툴 통합, 2차 새 게임 제작은 보류한다. 긴급패치는 완료되어 설계 협의를 재개했으며 구현은 아직 시작하지 않는다. 최신 기준은 [개발 목표 및 1차 범위](../../docs/modding/JO9_UNIFIED_EDITOR_SPEC_KO.md)이다. 아래 긴급패치 우선·개발 보류 항목은 당시 기록으로 보존한다.

## 사용자 결정

- 긴급패치를 우선한다. 이 도구의 구현은 긴급패치 이후에 이어간다.
- 긴급패치에서 구버전 2.2 대사 복원은 제외한다.
- 남은 긴급패치 논의는 하드모드 노예 데이터 숨김 규칙이다. 다른 완료 작업을 다시 열지 않는다.
- 현재 파일은 화면 시안이다. 실제 QSP 읽기·파싱·수정·저장 기능은 없다.

## 목적

사용자가 한 퀘스트의 연속된 대사와 관련 코드를 직접 확인하고 편집할 수 있게 한다. 현재 QSP를 기준으로 이전 QSP·JSON·구글 스프레드시트를 소스로 비교하고, 교체·추가·신규 작성·편집 및 이미지와 조건·동작 연결을 수행한다. 핵심 편집 기능은 AI 호출을 필수로 두지 않는 로컬 파일 처리로 설계한다.

## 지금까지 확정한 방향

1. 이전 QSP를 불러오면 같은 코드에 대응하지만 대사가 다른 항목을 찾는다. 사용자가 체크한 편집 대상은 작업 목록에 고정하고 탐색 중에도 유지한다. 관심 없는 차이는 선택하지 않는다.
2. 선택한 코드에 연결된 텍스트·대사·발동 조건·후속 조건·결과 처리·게임 동작·이미지를 추적해 확인하고 편집한다. 연결된 다른 코드는 참고로 펼쳐 보이고, 편집 대상으로 삼을지는 사용자가 추가 선택한다.
3. 원문 소스, 현재 QSP, 사용자 수정안을 비교한다. 체크한 변경만 반영할 수 있게 한다.
4. 선택 목록·드롭다운·태그에 들어가는 코드 자체를 사용자가 작성한다. 도구가 미리 정한 조건 목록만 제공하는 구조로 한정하지 않는다.
5. 사용자가 코드와 수치를 직접 입력하고, 자유롭게 이름과 설명을 붙여 태그로 등록한다. 태그 체크는 해당 코드를 수정안에 포함하는 조작이다. 자연어를 AI가 자동 해석해 실행 조건으로 변환하는 기능은 확정한 요구가 아니다.
6. 기존 코드의 뜻과 게임 내 영향을 툴팁으로 확인한다. 사용자 정의 코드의 설명도 직접 작성·수정할 수 있게 한다. 확인된 해석과 미확인 연결은 구분한다.
7. 문법·적용 위치·변경 미리보기는 사용자의 작업을 돕는다. 사용자가 작성한 코드의 결과 판단은 사용자가 하며, 원본 보존·백업·되돌리기를 제공하는 방향이다.

- 현재 WORK의 대사 편집실: `game/modtools/text-workshop/`. 장면 탐색·각본 추출·대사/이미지 연결·QSP 반영 기능이 있다. 이 기록에서는 수정하지 않았다.
- 클로드의 PR 18: `editor/character-studio-20261112`, 확인 head `e0edb0648248e8b264464a2748aa6e8a0c5d605e`. 캐릭터별 대사집·DB 원문 참조·Excel 기능이 있다. 별도 대사집 저장과 QSP 장면 편집은 역할이 다르다. 해당 브랜치를 이 시안에 병합하지 않았다.
- 인계 PR 17: `handoff/stats-background-generation-20261112`, 확인 head `9d2efaab9cd2ff195f3cdc34cadc16603d180ab7`. 편집기 브랜치에 없는 후속 커밋 6개가 있으므로 재개 시 최신 상태를 다시 확인한다.
- 이 폴더의 `index.html`: 무해한 예시 문구로 원문/대상 비교·체크·미리보기를 보여 주는 시안이다. 실제 게임 파일을 변경하지 않는다.

## 미정 사항 — 재개 후 협의

- 여러 참고 소스를 동시에 비교하는 화면과 우선순위.
- 코드 대응 판정의 상세 기준과 불확실한 후보 처리.
- 조건 태그의 AND/OR 묶음 표현 및 실행 시점의 편집 방식.
- JSON·스프레드시트 항목 매핑과 연결 권한/방식.
- 임의 코드 삽입 위치, 충돌 처리, 백업·되돌리기 및 mods 내보내기 형식.
- 클로드 편집기와 기존 대사 편집실의 실제 통합 범위.

요구사항 기록과 초기 시안의 보존만 승인된 상태다. 위 미정 사항은 확정하거나 구현한 것으로 간주하지 않는다. 긴급패치 완료 후 이 문서와 시안부터 읽고 사용자와 설계를 이어간다.
