# 사운드 청취 목록

기존 Pixabay 후보와 지역 BGM 목록에 사용자가 고른 로컬 음원을 연결하고, 재제작·채택·보류를 표시하는 독립 도구입니다. 게임에는 적용하지 않습니다.

## 만들기

저장소에서 `node tools/sound-audition/build.cjs`를 실행하면 같은 폴더에 `청취_목록.html`이 생성됩니다. `build.cjs`, `audio-library.cjs`, `browser.js`를 함께 둡니다. 생성 HTML은 필요한 스크립트를 포함하므로 단독으로 열 수 있습니다.

격리된 소스에서 만들 때는 다음 옵션을 사용합니다.

```powershell
node build.cjs --repo G:/somi/JO9sa --out ./청취_목록.html
node --test audio-library.test.cjs build.test.cjs
```

입력은 저장소의 `records/audio-planning-20261106/pixabay-candidates.json`, `MONSTER_INTRO_SFX_KO.md`, `docs/NEXT_PATCH_AUDIO_20261106_KO.md`, `local.config.json`입니다. 기존 기본 BGM 위치는 설정 파일의 GameRoot에서 읽습니다. 출력은 HTML 하나이며 입력 문서와 게임 음원은 수정하지 않습니다.

## 사용

- **폴더 선택**으로 하위 폴더의 음원을 읽거나 **음원 파일 추가**로 여러 파일을 고릅니다. 폴더 선택을 지원하지 않는 브라우저에서는 파일 추가를 사용합니다.
- **내 음원**에서 바로 듣고 각 후보의 **파일 지정** 또는 개인 음원 선택 칸으로 해당 항목의 음원을 정합니다. **지정 해제**는 수동 배정을 지우며, BGM은 선택한 파일 중 이름이 정확하게 일치하면 그 음원을 다시 제안합니다. 기존 원본 링크와 기본 BGM 재생기는 계속 남습니다.
- BGM 이름은 대소문자를 구분하지 않고 정확하게 맞춥니다. 같은 이름이 여러 폴더에 있으면 자동 선택하지 않으므로 상대경로를 보고 직접 고릅니다.
- 이름·경로·크기·수정시각이 모두 같은 파일을 다시 추가하면 기존 연결을 유지하고 안내합니다. 이미 고른 음원은 선택 칸에서 지정하며, 다른 폴더의 동명 파일이라면 폴더 선택으로 상대경로를 구분합니다.
- 각 후보 A/B, BGM, 개인 음원마다 **재제작·채택·보류** 중 하나를 표시합니다. 같은 버튼을 다시 누르면 해제됩니다. 청취 목록을 다시 생성해도 같은 항목 ID에 상태와 배정이 유지됩니다.

## 저장과 다시 열기

브라우저 localStorage에는 음원 이름·상대경로·크기·수정시각, 항목별 배정, 검토 상태만 저장합니다. 음원 바이트·절대경로·blob 주소·파일 핸들을 저장하거나 복사하지 않습니다. 재생은 사용자가 직접 선택한 File의 임시 blob 주소를 사용합니다.

다시 열면 메타데이터를 복원하고 **재선택 필요**를 표시합니다. 같은 폴더/파일을 다시 고르면 이름·경로·크기·수정시각이 일치하는 음원이 다시 연결됩니다. 파일이 수정·이동됐다면 해당 항목을 다시 지정합니다. 저장된 지정 파일을 아직 고르지 않았을 때 다른 음원으로 자동 대체하지 않습니다.

**설정 내보내기/불러오기**는 이 메타데이터와 상태만 JSON으로 옮깁니다. 브라우저가 로컬 파일의 저장을 제한하거나 페이지 주소/브라우저를 바꿀 때 사용합니다. 가져온 설정에 없는 이전 음원의 임시 재생 연결은 해제합니다. 잘못된 JSON은 기존 설정을 유지합니다. 개인 파일은 외부로 전송하지 않으며 기존 원본 링크를 열 때만 해당 사이트로 이동합니다.

## 확인

자동 검사는 음원 필터, 중복·상대경로 매칭, 메타데이터 복원, 배정/해제, 상태 토글/복원, 스크립트 이스케이프, 기존 후보·BGM 보존과 생성 스크립트 문법을 확인합니다.

화면에서는 ① 폴더와 개별 파일을 추가하여 재생·배정/해제, ② 같은 이름이 다른 폴더에 있을 때 자동 선택하지 않는지, ③ 상태 지정 후 다시 열어 상태 복원과 파일 재선택 안내를 확인합니다. 실제 디코딩 가능 여부는 브라우저의 음원 형식 지원에 따릅니다.
