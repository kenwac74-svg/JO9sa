# JO9 통합 모드 작업실

통합 전용 HTML과 시작 코드가 기존 캐릭터·계수·배경 기능 모듈을 직접 실행한다. 요청한 화면만 먼저 준비하고 나머지는 처음 선택할 때 불러온다. 게임 파일을 변경하는 기능은 각 도구의 원래 저장 동작을 따른다.

## 실행

- `통합작업실_앱창.cmd`: 전용 WebView2 창. 주신 ZIP에 있는 `start-studio-app.py`의 포트 선택·창·설정 저장·종료 처리를 그대로 재사용한다. 7719부터 7729까지 빈 포트를 사용한다. `py -3 -m pip install pywebview`가 최초 1회 필요하다. 현재 PC에는 설치했다.
- `통합작업실_브라우저.cmd`: 기본 브라우저. 현재 실행 주소는 `runtime/server.json`에 저장한다. 기존 주소를 재사용하고, 다른 프로그램이 포트를 쓰면 7689~7709 중 빈 포트를 사용한다.
- PowerShell: `tools/local-workspace/Open-Modding-Tools.ps1 -AppWindow` 또는 같은 명령에서 `-AppWindow`를 생략한다. `-NoBrowser`는 서버만 준비한다.

전용 창과 브라우저의 설정 저장소는 서로 다르다. 설정을 옮길 때 기존 **전체 설정 내보내기 → 설정 불러오기**를 사용한다. 포트가 바뀐 경우에도 브라우저 저장소는 구분된다. 기존 저장값을 자동으로 가져오거나 덮어쓰지 않는다. 앱 저장소는 원래 실행기 위치의 `.app-data/`다.

현재 클로드 원본 실행 사본은 `G:/Codex/tmp/claude-character-studio-e0edb064/tools/jo9-history-lab`이다. 운영 중인 소스이므로 임시자료 정리 대상에서 제외한다. 경로를 옮길 때 앱을 닫고 `Start-Modding-Hub.ps1 -StudioRoot <jo9-history-lab 경로>`로 연결한다. 설정·`.app-data/`·원본의 형제 `character-image-adder`도 보존한다. 저장소에 원본 도구가 있으면 `../jo9-history-lab`도 찾는다.

## 구성과 저장

- `server.py`: 원래 `studio_server.StudioHandler`를 상속한다. 기존 API/POST는 원래 코드에 전달한다. 새 `workspace.html`과 `workspace-app.mjs`를 제공하며, 원본 app 부팅은 실행하지 않는다. 원본 기능 모듈과 API는 재사용한다.
- `integration.mjs` / `integration.css`: 사이드바와 도구·산출물 프레임. 기존 스타일을 사용한다. 선택한 도구 프레임은 메뉴 이동 시 유지한다.
- `registry.py`: HTML 목록 생성과 등록 파일·관련 리소스의 읽기 전용 제공. 저장 파일·임의 JSON은 제공하지 않는다.
- `app_launcher.py`: 원본 앱 실행기 함수를 불러오고 서버 생성 함수만 통합 서버로 연결한다. 포트 선택과 `.app-data/`는 원래 실행기를 따른다. 창 종료 시 그 앱의 서버도 종료한다.
- `Start-Modding-Hub.ps1` / `Start-Modding-App.ps1`: 자신의 실행 기록·프로세스를 확인해 재사용한다. 다른 프로그램을 종료하지 않는다. 이전 빌드 앱이 열려 있으면 저장 후 닫도록 안내한다.
- `runtime/`: 주소·PID·소스 경로·로그·실제 기존 도구 URL. Git 제외. 캐릭터/일정/체크리스트의 원래 저장 파일과 별개다.

기존 대사·폴더 비교 서버의 프레임 제한은 이 실행기가 전달한 loopback 주소만 허용한다. 독립 실행 시 환경값이 없으면 기존의 프레임 차단을 유지한다. 외부 웹 주소는 허용하지 않는다. 캐릭터 JSON·이미지·QSP/SAV 저장은 기존 기능의 명시적인 사용자 조작을 따른다.

## 이번 범위와 확인

사이드바·기존 화면 연결·산출물 목록·두 실행 방식을 구현했다. 새 대사 비교/변수 정의/범용 DB 구조/산식 변경/새 게임 제작은 이후 설계 범위다.

HTML 목록·중복 처리·등록 경로·탈출 거부·file URL 변환의 단위 검사 4개 통과. 수정 코드 문법 검사 통과. 브라우저에서 캐릭터 화면·대사·이미지 도구·게임 DB·일정·기타툴·산출물을 확인했다. 대표 카탈로그 초상 2개 로딩 확인. 포트 7719를 임시 점유한 상태에서 앱이 7720으로 실행됐다. 이후 기본 7719로 다시 실행했다.

첫 앱 시험 창에는 메뉴·1884명 목록이 표시됐지만 구형 작업대 초기 로딩에서 `Failed to fetch` 알림이 있었다. 해당 JSON 4개는 모두 정상 200/JSON이다. 앱을 숨기는 실행 옵션을 고쳐 `pythonw`로 실제 창을 표시하도록 변경했다. 이 변경 후 앱 내부 육안 확인은 컴퓨터 제어 승인 시간이 만료돼 완료하지 못했다. 사용자는 전용 창에서 **배경 설정 목록**, **대사 편집** 두 곳의 표시와 초기 경고 재발 여부를 확인하면 된다. 경고가 계속되면 앱 초기 로딩 문제로 분리해 조사한다. 게임 전체 기능 재검사는 하지 않았다.

## 게임 DB · 웹 대시보드 (Helper)

게임 DB 상단의 **웹 대시보드**에서 리림의 JO9 Helper 공략·세이브 분석 화면을 사용한다. 기존 특성·아이템·마법·MOB DB와 일반/인터뷰 대사 DB는 그대로 유지한다. 세이브 선택·육성 목표·스포일러 표시·컴팩트 보기·퀘스트/캐릭터 상세·가이드는 원본 Helper의 기능을 사용한다. 세이브와 게임에는 쓰지 않는다.

원본 `JO9_Helper.exe`가 게임 상위 폴더 또는 `JO9_Helper_v1.0.0/` 안에 있어야 한다. 다른 위치는 실행 환경 변수 `JO9_HELPER_EXE`로 지정한다. EXE를 복사·변경하거나 Git에 포함하지 않는다. Helper 원본의 공략/계산 데이터는 통합 작업실 자체 DB와 별도이며, 통합이 그 내용을 현재 QSP와 전수 대조했다는 뜻은 아니다.

탭을 처음 열 때만 원본 EXE의 웹 분석 서버를 `--no-overlay --no-tray --no-browser --game-dir <현재 WORK>`로 숨김 실행한다. 전용 동적 포트와 Windows 자식 작업에서 실행하고 소유 프로세스의 포트만 조회하므로 기존 8765 서버나 사용자 실행 창을 재사용/종료하지 않는다. 작업실 종료 시 전용 Helper도 닫힌다. 웹 주소는 작업실의 `/workspace/helper/`로 고정하며 기존 API와 분리한다. 데스크톱 오버레이/Helper 종료 버튼은 웹 통합 화면에서 제외한다. 원본 EXE를 직접 실행하면 원래 기능을 그대로 쓸 수 있다.

세이브는 원본 Helper가 마지막 저장 파일을 분석한다. 게임 메모리를 실시간으로 읽는 기능은 아니다. 첫 분석이 길어져도 같은 화면의 중복 요청은 하나로 합치고, 도중에 세이브 선택을 바꾸면 완료 뒤 최신 선택을 다시 읽는다. 기존 브라우저 설정 키와 제작자 표시는 유지한다.

관련 코드: `helper_dashboard.py`(리소스/분석 서버/읽기 프록시), `helper_dashboard_html.py`(화면·요청 조절), `helper-dashboard.css`(작업실 색상). `server.py`와 실행기의 빌드 목록에 세 파일을 함께 등록한다. 기록: `records/helper-web-integration-20261118/REPORT_KO.md`.

## 게임 DB · 노예 상태 수치 공식표

게임 DB의 **노예 상태 수치 공식표**에서 제공된 HTML의 관계도·수치 공식·계산기를 연다. 원본은 WORK 상위 폴더의 `노예 상태 수치 공식표.html`이며, 내용 수정 없이 `data/slave-status-formulas.html`에 보존하여 작업실에서 제공한다. 원문 설명과 수식의 현재 QSP 일치 여부를 새로 검증한 것은 아니다. 게임이나 세이브에 값을 반영하지 않는다.

## 게임에 연결되는 캐릭터 배경 분류

캐릭터 → 배경·설정 → 노예용 설정의 세계·출신·직업 소분류를 고르면 실제 JSON 분류로 저장한다. 기존 대사집에만 있던 선택은 **게임 분류로 적용**을 누른다. 배경 설명문·기존 수치·특성을 재추첨하지 않는다. 게임을 완전히 재실행하고 저장을 불러온 뒤 화면을 전환하면 기존 인물도 현재 분류로 갱신한다. 사용·변수·저장·검사 한계: [변경 원장](../../records/character-background-20261118/REPORT_KO.md).
