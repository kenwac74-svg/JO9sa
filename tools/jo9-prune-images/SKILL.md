# JO9 미사용 이미지 정리

목표는 게임과 패치에 필요 없는 이미지를 **JO9 폴더 밖에 보관**해 배포 용량을 줄이는 것이다. 이미지를 삭제하거나 화질을 낮추는 작업이 아니다. 현재 폴더 안의 `reserve`로 옮겨서는 이 목표를 달성하지 못한다.

## 조사와 판정

1. 조사 대상 JO9 루트와 실제 실행 파일·패치 구성부터 확인한다. 보관본 `JO9main`, 플레이용 `JO9`, 원본 `JO9O`는 서로 다른 대상이다. 다른 대상의 조사 결과로 이동하지 않는다. 원본·백업·동기화된 참조 소스는 보존한다.
2. 실행되는 `jack.qsp`를 해독해 조사한다. `.qsrc`만 보고 결론을 내리지 않는다. CSS, HTML, JSON, 설정, 연결된 스크립트도 조사한다. 읽기 실패나 버전 불일치는 보고한다.
3. [참조 판정 규칙](references/reference-rules.md)을 읽고 고정 경로, 변수 조합, JSON 이미지 필드, 이미지 선택 함수, 엔진의 랜덤 인덱스와 저장 데이터까지 확인한다. 파일명 문자열 검색은 후보 추출용이다.
   특히 새 장면전환의 `interior_change` 목록, `name (2).png` B컷·C컷, `image-original-cuts.json`과 원본 연결 경로는 미사용 후보에서 제외한다. JO9main의 미사용 판정만으로 모딩된 JO9의 미사용을 확정하지 않는다.
4. 파일마다 아래 판정을 기록한다. 경로·바이트·판정 이유·근거 위치를 남기고 후보의 원본 파일은 건드리지 않는다.

| 판정 | 의미 | 처리 |
|---|---|---|
| KEEP | 직접 또는 동적 사용, 랜덤 선택·인덱스에 영향 | 유지 |
| HOLD | 참조 미발견이지만 동적 경로·외부 데이터·용도 불확실 | 유지하고 필요한 확인을 명시 |
| MOVE_READY | 모든 관련 참조 경로와 부수 효과를 검토해 불필요함을 확인 | 외부 보관 계획에 포함 |

`unused`, `SNKmod`, 임시 파일처럼 보이는 이름, 숨겨진 메뉴, 여성 주인공 분기, 중복 그림이라는 이유만으로 MOVE_READY로 판정하지 않는다. 같아 보이는 그림이라도 호출 경로가 다르면 필요할 수 있다. 향후 사용할 작업용 그림은 게임의 미사용 자원과 구별해 외부 작업 보관 대상으로 기록한다.

## 이동과 복구

- 조사·규칙 작성 요청은 실제 파일 이동까지 승인한 것으로 해석하지 않는다. 사용자가 정리·이동을 요청했으면 그 범위의 검증된 파일을 처리하고 이미 받은 승인을 반복해서 묻지 않는다. 필요한 승인은 경로와 용량이 표시된 구체적인 계획을 만든 뒤 요청한다.
- [이동 절차와 도구](references/operations.md)를 읽는다. 외부 보관 루트는 대상 JO9 및 다른 보호 대상과 겹치지 않아야 한다. 예: `G:/somi/JO9_unused_images/<작업ID>/`. 원래 상대 경로를 유지한다.
- `scripts/archive_images.py`는 조사 시작 시점의 스냅샷, 파일별 검토 근거, 이동 계획, SHA256, 복구 기록을 관리한다. 이 도구는 미사용 여부를 자동 판정하지 않는다. 코드·이미지 목록이 조사 이후 달라지면 재조사한다.
- 파일을 외부에 복사하고 해시를 확인한 뒤 원래 파일을 제거한다. 기존 파일을 덮어쓰지 않는다. 실패한 단계는 기록을 보존하고 복구한다. 실제 작업은 한 번에 하나만 실행하고 JO9 편집·게임·이미지 교체 도구는 변경하지 않는 상태에서 진행한다.
- 카탈로그의 이미지 ID, 패치 이력, 백업, 재사용 예정 여부를 잃지 않도록 원래 경로→외부 경로를 기록한다. 카탈로그 연동 방식이 확인되지 않으면 임의로 DB를 수정하지 말고 외부 manifest를 남긴다.

## 패치와 확인

배포 스크립트가 외부 보관 폴더, 이미지 백업, 작업 그림을 다시 포함하지 않는지 확인한다. 개인 패치가 새로 쓰는 그림은 원본 코드에 참조가 없더라도 유지한다. ZIP 내부 목록과 크기로 실제 절감량을 측정한다. 파일 용량 합계와 ZIP 절감량은 구분한다.

자동 확인은 참조 재검사·외부 파일 해시·원래 경로 제거·패치 목록으로 한다. 플레이 테스트는 사용자가 담당하는 것이 기본이다. 영향을 받는 장면과 클릭 경로를 짧게 전달하고 확인 결과가 오기 전에는 게임 동작까지 검증했다고 말하지 않는다. 필요한 이미지를 옮긴 것으로 드러나면 manifest로 복구하고 해당 호출 규칙을 보완한다.

보고에는 조사 대상, KEEP/HOLD/MOVE_READY 수, 실제 이동 수·바이트, 보관 위치·복구 방법, 남은 불확실성을 포함한다. 후보 수를 실제 미사용 확정 수로 표현하지 않는다.
