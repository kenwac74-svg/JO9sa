# JO9 · 경력 초기값 설계실

최신 인계: [통계·배경 스토리·생성 공식 핸드오프](docs/JO9_Stats_Background_Generation_Handoff_20261112.md). 통계의 게임 구현은 다음 업데이트로 이월한다. 아래 구버전 이력과 충돌하면 최신 인계 문서 및 현재 코드를 우선한다.

## v0.11 · 세계·출신·직업 연결 검수

세계 14종·출신 57종·직업 66종의 명시적 연결을 구성했다. 기술 기반, 마법, 출생 신분, 생활 여건, 세계 제도를 함께 확인하며 세계–직업별 출신 허용 목록을 적용한다. 승인된 여학생·무용가를 목록에 추가했다. 기존 저장값은 자동으로 교체하지 않으며 “검수 연결 적용”으로 새 연결을 적용한다. 대사·수치·기존 연령 조건은 보존하고 미지정된 승인 연령 기본값만 채운다. 이후 개별 연결 수정은 유지한다. 검사: `node checks-background-connections.mjs`. 게임 본체에는 미반영이다.

## v0.10 · 배경 명칭과 회상 대사

세계 40개 변형·출신 57개·직업 64개의 기본 대사를 2026-11-12 회상형으로 개정했다. 소개용 분류명과 캐릭터의 1인칭 설명을 구분하고, 체제 찬양 구호와 번역 오류·가족관계 모순을 정리했다. 내부 ID·생성 연결·연령 조건·수치와 캐릭터 통계는 변경하지 않았다. 이미 브라우저에 저장한 대사가 기본값보다 우선하므로, 기존 이용자는 제공된 개정 설정 JSON을 불러오면 전체 대사가 함께 적용된다. 직업별 특성 설계나 게임 본체 반영과는 별도 작업이다. 검사: `node checks-background-dialogue.mjs`.

## v0.9 · 배경 본문에서 직접 편집

배경 설정 목록의 세계·출신·직업경력 본문 칸에서 직접 수정한다. 입력한 유효 대사는 기존 `backgroundSettings.texts`에 자동 저장되며, 아래 대사·연결 편집기와 같은 값을 공유한다. 이름 자리표시자 `{이름}`은 원형으로 편집·저장한다. 같은 항목의 모든 조합과 검색·메모 불러오기·전체 설정 내보내기에 수정값이 적용된다. 이미 캐릭터에 불러온 메모는 다시 불러오기 전까지 유지한다. 브라우저 저장 데이터와 소스 커밋은 별개이며 채팅의 승인 기획·엑셀 변경이 사이트 코드에 자동으로 동기화되지는 않는다.

성인 캐릭터의 영입 전 경력 추정과 조정을 위한 독립 기획 대시보드. 게임 소스와 세이브에는 접근하지 않는다.

현행 소속 전 경력의 최상위 통계는 성적 경험(`intimacy`), 승리·패배·도주(`wins`, `losses`, `escapes`), 임신·낙태·출산·자녀(`pregnancies`, `abortions`, `births`, `children`)의 8개다. 성적 경험은 상세 분포를 보존하고, 전투는 PvP(아레나·캣파이팅)·PvE(안개경계)·미분류별 승패도주를 기록한다. 최상위 전적은 분류 합계로 산출하며 중복 가산하지 않는다. 분류가 불명인 기존 기록을 임의 배분하지 않는다. 참전은 필요시 승리+패배+도주로 산출하고 처치·전투불능은 현행 통계에서 제외한다. 근거 없는 임신·낙태 수는 미상이다.

소속 후 별도 집계는 `jo9_owner_history`의 주인 수익만이며 신규 영입 시 확정 기록 0으로 시작한다. 과거 수익을 추정하거나 이관하지 않는다. 과거 현재 주인별 성행위·관계·기타 누적안은 설계 이력으로 남긴다.

교육받음·지도·요리 인분·연금 제작·간호 치료 누적 통계는 활용처가 없어 계산·메인 UI·신규 JSON 생성에서 제외한다. 세계관에 맞지 않는 콘텐츠 신설을 유지 근거로 삼지 않는다. 미검토 생산·치료·승급 등은 후보로만 남긴다. 과거 JSON의 제외 항목·과거 수익·참전·처치·전투불능 값과 구버전 백업·스냅샷은 보존하여 읽을 수 있게 한다. 게임 스킬과 원본 `seed_cook`·`seed_enchanter`·`seed_nurse` 등은 삭제하지 않는다.

`dist/index.html`, `styles.css`, `app.mjs`, `engine.mjs`로 동작하는 정적 사이트. 외부 의존성과 서버 데이터 저장이 없다. 편집값은 브라우저 localStorage에 저장하며 전체 설정 JSON으로 이동할 수 있다.

- 프로필·스킬·생활 배경·직업·예외 태그 조정
- 등급 기준량, 분야별 기술 가중치, 배경 계수, 성향·분류·전투 계수 편집
- 항목별 자동 / 확정 기록 / 직접 지정 선택, 명시된 0 보존
- 합계를 보존하는 상대 × 유형 분배, 산출 과정 확인
- 확정 당시 프로필·계수·결과 보관과 최대 4개 비교
- 전체 설정 JSON 가져오기/내보내기, 결과 JSON·보관함 CSV·설계 명세 Markdown 내보내기

초기 수치들은 조정 초안이며 조사된 실제 경력 데이터가 아니다. 배경 메모는 자동 분석하지 않고 사람이 분류와 지정값으로 연결한다. 통계 도입 이전부터 소유한 캐릭터의 기록 이관은 별도 설계가 필요하다.

검사: `node --check dist/app.mjs`, `node --check dist/engine.mjs`, `node checks.mjs`.

## v0.2 · 캐릭터 JSON 작업대

- 실제 캐릭터 JSON 가져오기, 원본 대비 필드 편집, 초기값 포함 JSON 내보내기
- 이사벨라 실제 원본과 검증용 표준 케이스, 명시적 0·미상 null·저장된 추정값 보존
- 자유 입력 종족 태그, 원본 3종 배경 텍스트 및 직업·생활 배경에 따른 메모 자동 선택
- 게임 생성 풀의 1,803개 배경 조합 검색·앞뒤 이동·번호 이동·무작위 선택
- 사용자 특성 열람표 128개 검색·추가·삭제, 조건값과 지정된 계산 보정 동기화
- 열람표의 traits.json 갱신, 전체 원본 필드 보존, 현재 편집 초안 자동 저장

추가 검사: `node checks-character-json.mjs`. 범위 조정 전 검증 이력은 314개 통과이며, 현행 통계 조정 후 최종 검증 숫자는 아니다. 데이터와 초기값 블록의 상세 계약은 [JSON 작업대 핸드오프](docs/JO9_Character_JSON_Workbench_Handoff_20261110.md)를 따른다.

JSON 편집 표에는 한국어 필드 해설과 입력 참고를 표시한다. 기본 31개 키는 사용자가 제공한 원본 템플릿 순서로 정렬하고, 나머지 키는 불러온 원본 순서를 유지하며 새 키를 뒤에 추가한다. 같은 순서를 전체 편집기와 내보낸 JSON에도 적용한다. 해설은 JSON 안에 주석 문자열을 삽입하지 않는 화면 주석이며, 내보낸 파일은 표준 JSON 형식을 유지한다. 필드명·해설·값 모두 검색할 수 있다. `seed_world`와 새 미등록 필드는 용도 미확인으로 표시한다. 검사: `node checks-character-fields.mjs`.

샘플 `dist/samples/2571_isabella_initial_history_example.json`의 통계는 검증용 가정이며 캐릭터 공식 설정이 아니다. 게임이 `jo9_initial_history`, `jo9_owner_history`, `jo9_race_tags`, `jo9_history_design`을 읽는 코드는 별도 구현 대상이다.

출처: JO9 소스 조사 스냅샷 `607c7ec6`의 직업·출신 구조와 기술 주입 설정. 경력 환산식과 계수는 새로 제안한 모델이다. 게임 내 길거리 업무 수익·등급 규칙과 분리한다.


## v0.4 · 배경별 보정

세계/출신/직업경력 독립 필터와 고정 탐색, 원문/두 배수/네 범위의 3열 편집, 세계×출신×직업 배수, 직업→출신→세계 우선 범위, 고정 시드 정수 추첨을 지원한다. 편집값은 전체 설정 JSON에 저장하며 1,803개 전체 조합의 최종 배수·범위·출처를 CSV로 내보낼 수 있다. 기본 배수 1/범위 미지정이며 확정된 캐릭터 초기값을 덮어쓰지 않는다. 관련 검사: `node checks-background-modifiers.mjs`, `node checks-background-browser.mjs`.
