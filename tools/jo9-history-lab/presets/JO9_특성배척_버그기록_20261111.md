# JO9 활동·집중 특성 단계형 개편 기획

- 최종 결정일: 2026-11-11 (한국시간)
- 상태: 사용자 승인 기획 / 게임·편집기 코드 미반영
- 우선순위: 이 최신 기획이 아래의 이전 배척·중복 기록을 대체한다.

## 승인된 단계와 효과

| 계열 | 단계 | 특성 | 개편 후 효과 |
|---|---|---|---|
| 긍정 | 1 | 끈기 | 동일 업무·교육 반복 시 획득 경험치 +10%, 반복 시 기분 보너스 |
| 긍정 | 2 | 워커홀릭 | 끈기 효과 전체 포함 + 하루 두 번째 업무·교육 활동부터 기분 보너스, 직접 휴식·마사지 보상 절반 |
| 부정 | 1 | 산만함 | 동일 업무·교육 반복 시 획득 경험치와 업무 성과 -10% |
| 부정 | 2 | 무기력함 | 산만함 효과 전체 포함 + 하루 두 번째 업무·교육 활동부터 기분 하락, 직접 휴식·마사지 보상 두 배 |

기분 보정의 기존 내부 수치를 유지한다. 끈기의 반복 기분 보너스는 +2, 워커홀릭의 두 번째 활동부터의 추가 보너스는 +2, 무기력함의 두 번째 활동부터의 하락은 -2다. 화면상 기분 등급 +2를 의미하지 않는다. 워커홀릭은 반복 조건과 활동 횟수 조건을 모두 만족하면 각 효과를 한 번씩 적용한다. 고정 규칙 업무의 기존 집중 보정 제외 범위는 유지한다.

## 단일 보유와 상위 대체

- 없음 또는 네 특성 중 하나만 보유한다. 같은 계열 하위·상위의 중복과 긍정·부정 동시 보유를 모두 금지한다.
- 끈기 → 워커홀릭, 산만함 → 무기력함은 효과의 상위 단계다. 상위가 부여되면 하위 특성을 대체하고 하위 효과를 포함한다. 하위 효과를 별도 실행해 중복 가산하지 않는다.
- 자동 승급·승급 조건·승급 경험치·승급 확률은 이번 기획에 포함하지 않는다.
- 기존 직업별 끈기 등의 확률은 유지한다. 상위 특성으로 자동 치환하지 않으며, 단계별 신규 추첨 분포는 별도 미정이다.
- 랜덤 생성·직업 추가 추첨·발견 및 획득·유니크 초기값·JSON·편집기에 같은 단일 보유 규칙을 적용한다.
- 기존 캐릭터의 충돌 값 정리와 저장 필드 이관 정책은 미정이다. 이번 문서 작성으로 게임 저장값을 변경하지 않는다.

## 기존 시스템에 대한 정정

확인한 2.4.1 소스에는 집중 성향 `jo9_focus`가 +1 끈기 / 0 없음 / -1 산만함으로 이미 구현되어 있다. 활동 성향은 편집기 연결값 `activity_sign`의 +1 워커홀릭 / -1 무기력함이며, 소스의 `jo9_work_ethic` 등 호환·통합 처리는 구현 시 함께 확인한다. 기존은 별개 두 축이므로 교차 보유가 가능하다는 사실만으로 버그가 확정되는 것은 아니다. 기존 교차 배척 누락 제보는 이번 단계형 개편 요구로 대체한다.

## 직조공과 검증 기준

- 직조공은 끈기 최종 부여 확률 20% 유지, 무기력함 직업 추가 추첨 제외.
- 동일 활동 반복 / 서로 다른 활동 교대 / 하루 첫 활동 / 두 번째 이후 활동 / 날짜 변경을 나누어 효과를 검증한다.
- 상위 특성에 포함된 하위 효과가 정확히 한 번만 적용되는지 확인한다.
- 휴식·마사지 보상 배율과 단일 특성 보유를 확인한다.
- 게임 특성 설명·툴팁·편집기 열람표를 단계형 규칙에 맞춰 갱신한다.

## 확정 요구사항

끈기와 무기력함은 서로 배척하는 특성이므로 한 캐릭터가 동시에 보유할 수 없어야 한다. 게임 시스템에서 동시 부여를 허용한다면 버그로 수정한다. 직업별 추천에서만 조합을 피하는 것으로 해결 완료 처리하지 않는다.

## 발견 경위와 확인 범위

직조공 기획에서 끈기 20%와 무기력함 10%를 독립 추첨하도록 추천한 오류가 있었다. 사용자가 두 특성의 배척 관계를 지적했고, 게임 시스템에서도 차단하지 않는 문제를 버그로 기록하도록 지시했다. 이 기록 작성 시 실제 게임의 동시 보유 재현 및 배척 코드 조사는 수행하지 않았다. 따라서 게임 코드의 구체적인 결함 위치·원인은 아직 미확인이다.

## 후속 확인 및 수정 범위

- 실제 내부 특성 키와 기존 배척 정의를 확인한다.
- 일반 랜덤 생성, 직업·배경 추가 추첨, 플레이 중 발견·획득, 유니크 초기값·JSON 입력에서 동시 보유가 가능한지 확인한다.
- 두 특성을 서로 반대 순서로 부여해도 같은 배척 규칙을 적용하는지 확인한다.
- 편집기에서도 충돌을 검출하고, 실제 게임에서도 부여 시점에 차단한다.
- 이미 충돌한 캐릭터가 있다면 처리 정책을 별도로 정한다. 기존 값을 자동 삭제하는 정책이나 어느 특성을 우선할지는 아직 확정하지 않았다.

## 완료 판정

지원하는 각 부여 경로에서 끈기·무기력함 동시 보유가 방지되고, 양방향 부여 순서에서 검증되면 수정 완료로 처리한다. 발견·획득 표시만 숨기는 것으로는 해결되지 않는다.

## 추가 결정: 끈기·워커홀릭 중복

사용자가 끈기와 워커홀릭을 중복으로 판단했다. 둘은 중복 계열로 관리하고 동시 부여하지 않는 것으로 기획한다. 기존 기획에서 끈기로 승인한 확률은 유지하며, 워커홀릭으로의 일괄 치환이나 효과 통합은 이번 결정으로 확정하지 않는다.

| 조합 | 처리 기준 |
|---|---|
| 끈기 + 무기력함 | 상반 성향으로 배척 |
| 워커홀릭 + 무기력함 | 상반 성향으로 배척 |
| 끈기 + 워커홀릭 | 중복 성향으로 동시 부여 방지 |

편집기 특성 열람표 확인 결과, 끈기는 `jo9_focus = 1`, 워커홀릭은 `activity_sign = 1`, 무기력함은 `activity_sign = -1`로 연결되어 있다. 설명상 끈기는 같은 활동의 반복에, 워커홀릭은 하루 두 번째 활동부터 기분 변화에 관여해 현재 효과가 완전히 동일하지는 않다. 사용자의 중복 판정은 설계 결정이며, 두 효과를 합치거나 어느 특성을 삭제할지는 별도 미확정이다. 실제 게임의 이 조합 차단 여부도 소스 검증·게임 재현 전까지 미확인으로 둔다.
