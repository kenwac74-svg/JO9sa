# 영입 이후 대화 소재: 게임 내 사건 목록 v0 (2026-11-13)

- 목적: 노예가 **주인을 만난 뒤 겪은 일**을 대화(필로우토크·섹스토크·노예와 대화)에서 말하게 하려면, 게임이 이미 가진 사건과 기록부터 쓴다. 이 문서는 그 **재료 목록**이다. 대사 원고와 최종 규칙은 쓰지 않는다.
- 대원칙(유지): 같은 사건이라도 **성격 9유형·말투·관계 모드·감정 깊이**에 따라 말하는 길이와 결이 다르다(세계관 자료집 7장). 표현 낮음(인형·관조·얼음)은 짧게, 높음(여린·솔직·불꽃)은 길게. 과거 사실(영입 전)은 고치지 않고 영입 뒤 일은 더해서 말한다("그 뒤로 주인님이랑 {N}번").
- 근거: 사용자 최신 qsp `4354cf39…`(모드 제작자 작업본 `29f4c048…`와 차이는 확인 안 함). 위치는 location 이름과 대화 번호(`interaction` 값).

## 7. 대화로 쓰는 법 (초안, 결정 필요)
1. **소재 고르기**: 기억 버퍼(`jo9_mem`, 대화 구조 설계 2.2)에 강한 사건을 6개까지 남기고, 0장의 기존 횟수로 "얼마나 자주"를 말한다.
2. **유형별 결**: 같은 사건(예: 대변기 규칙 7일째)
   - 얼음·관조: 사실만 짧게("익숙해졌습니다.")
   - 순종·여린: 감정과 함께, 여린은 길게
   - 불꽃·솔직: 거침없이 길게, 불꽃은 부풀림
   - 인형: 낱말 수준
3. **관계·감정 깊이**: 적대면 원망·거부, 헌신이면 받아들임. 깊이 0이면 감춤.
4. **상대 구분**: 주인 / 조수 / 손님(매춘굴·길거리) / 괴물(착정·유충) / 그 밖. 필로우토크의 "주인과 / 주인 외 / 이종" 누적과 같은 구분.
5. **사실 두 층**: 영입 전 과거(고정) + 영입 후 누적(위 사건의 기존 횟수). 새로 저장할 것은 기존 기록에 없는 것만(예: 길거리 손님 수, 매춘굴 하루 손님 수).

## 8. 정해야 할 것
1. 어떤 사건을 대화 소재로 우선 쓸지(제안: 규칙 · 길거리/매춘굴 · 처벌 · 선물 · 처녀 상실 · 임신 · 착정).
2. 기존 기록으로 부족해 새로 셀 것(손님 수, 길거리 벌이, 착정 횟수 등)과 저장 키.
3. 질문 22개 중 영입 후 기록을 붙일 질문과, 새로 필요한 질문(예: "여기 와서 가장 힘들었던 일").
4. 대화 메뉴 위치(질문하기 111 / 영향주기 112)와 하루 횟수.
- 게임 반영은 모드 제작자 몫이다(기획서로 넘김).
