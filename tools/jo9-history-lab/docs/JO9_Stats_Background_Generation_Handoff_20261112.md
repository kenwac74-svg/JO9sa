## 4. 통계: 다음 업데이트 확정 범위

### 기간과 항목

| 기간 | 유지 항목 | 제외·금지 |
|---|---|---|
| 영입 이전 | 성적 경험 상세, 특별히 지정한 임신·출산 경험 | 전투 전적 자동 추정, 과거 수익, 과거 낙태·자녀 자동 생성 |
| 영입 이후 | 실제 경험 기록, 수익, PvP/PvE 전투, 임신·출산·낙태·자녀 | 스킬 상승만으로 과거 기록 재산출 |
| 통계에서 제외 | 교육·지도·요리·연금·간호 누적 횟수 | 스킬 자체를 삭제한다는 뜻은 아님 |

성적 경험은 성인 캐릭터 대상이다. 주인과의 경험 / 주인 외 인간 / 인간 외를 구분하고, 주인 외 인간은 이성·동성을 구분한다. 현재 편집기의 영입 전 교차표는 “주인 외 인간 이성 / 동성 / 인간 외” 3열이며 주인과의 실제 경험 누적은 별도 게임 구현 대상이다.

전투는 **소속 이후만 누적**한다. PvP(아레나·캣파이팅), PvE(안개경계), 미분류 각각 승리·패배·도주만 둔다. 신규 전투 콘텐츠는 큰 분류 아래에 연결한다. 전체 전적은 분류별 합계이며 중복 가산하지 않는다. 과거 데이터의 옛 전적은 삭제하지 않되 새 영입 전 추정에 사용하지 않는다.

임신·출산은 영입 전 특별 이력이 있을 때만 지정 범위에서 추정한다. 영입 후에는 임신·출산·낙태·자녀를 모두 실제 기록한다. 출산 횟수와 자녀 수는 서로 대체하지 않는다.

### 초기값 산식: 현재 편집기 구현

`총경험 = 반올림(스킬 등급 기준량의 가중평균 × 배경 계수 × 개인 배율 × 성향 계수 × 고정 난수)`

- 성적 경험 등급 기준량 F/D/C/B/A/S = 0 / 3 / 15 / 50 / 140 / 320. 가중치 애무 0.2, 구강 0.4, 삽입 0.4. 모두 조정용 값이며 실제 게임 횟수의 역산 결과가 아니다.
- 구조화한 세계·출신·직업을 선택하면 세 배수를 곱한다. 이때 구버전의 큰 직업 분류 계수와 생활 배경 계수는 다시 곱하지 않는다.
- 기본 난수 편차 ±15%. 캐릭터 ID·시드·항목을 사용해 같은 입력에 같은 결과.
- 현재 성향 기본 배율 1.15 / 1.3 등은 초기 경험 추정 계수다. 개인실 업무의 수익 보정과 혼용하지 않는다.
- 상세 분포는 기술 가중치로 배분하고 총합을 보존한다. 전체 미경험은 자동값 0, 일부 미경험은 대응 상세 가중치만 0으로 처리한다.
- 실제 기록·직접 지정·저장한 추정값이 자동 추정보다 우선한다. 명시된 0과 미상을 구별한다.
- 인간 외 경력을 스킬만 보고 만들지 않는다. 자유 입력 종족 태그 자체가 경력이나 특수종족 생성 확률을 자동 확정하지 않는다.
- 기술 주입·클론은 기술이 높아도 자동 성적 경력 0. 명시 기록·특별 지정값은 별도.
- 임신·출산 범위는 **직업 → 출신 → 세계** 중 처음 지정한 범위 하나를 사용한다. 최소~최대 양 끝 포함 정수 추첨. 범위를 합산하지 않는다. 0~0도 유효한 지정이며 미지정은 미상.
- 초기값을 영입 시 확정한 뒤 스킬·직업 변경으로 다시 추정하지 않는다. 게임의 확정 저장 시점과 이관 정책은 다음 업데이트에서 구현한다.

### 다음 업데이트의 누적 설계

성공 사건이 확정되는 지점에서 캐릭터 고정 ID를 기준으로 누적한다. 명령을 누른 횟수와 실제 성공 횟수를 분리한다. 취소·거절·실패가 성공 횟수를 늘리지 않게 한다. 성교육은 주인 흥분치 감소 및 실제 처리 경로를 게임 소스에서 재확인한 뒤 포함 여부를 결정한다.

개인실 길거리 업무의 인원 매핑은 빈손 0 / 소 1 / 중 2 / 대박 3 / 초대박 5. 상세 횟수·특성·수익 보정은 별도 업무 로직과 연결해야 한다. 본 편집기의 과거 경력 추정식을 실시간 업무 정산에 그대로 쓰지 않는다. 성공등급에 이미 반영된 특성을 다시 인원 배율로 더하지 않는다. 기존 대화의 최종 수정값을 실제 업무 소스와 대조한 후 적용한다.

정보창 통계 UI는 조수·노예·개인실 메이드 창의 아우스펙스 옆 탭을 추가하며 기존 게임 UI 자산을 재사용한다. 이번 문서로 게임 UI가 반영된 것은 아니다.

## 5. 배경 스토리: 작성·편집 원칙

- 소개 시 표시되는 세계·출신·직업명은 자연스러운 분류명으로 정리한다. 내부 ID는 번역명 변경과 무관하게 유지한다.
- 본문은 캐릭터가 관계를 맺은 주인에게 과거를 담담히 회상하는 1인칭이다. 노예상의 광고 문장이나 지도자 찬양 구호로 쓰지 않는다.
- 세계는 사회·기술·제도를 설명하고, 출신은 자란 환경, 직업은 이후 본인의 일을 설명한다.
- “부모를 모른다”와 “아버지가 어떤 사람이었다” 같은 모순, 특정 시대의 학교 시설·교복·학년을 불필요하게 전제하는 문구를 피한다.
- 과거의 신분 하락이나 특별 사건이 필요한 직업은 연결 또는 본문에서 근거를 확보한다. 모든 조합에 숨은 사건을 임의 가정하지 않는다.
- 특수종족·안드로이드 같은 설정은 유니크 캐릭터에서 지정한다.
- 본문 수정은 `config.backgroundSettings.texts`에 저장한다. 세계 키는 `세계ID:변형`, 출신·직업은 각 ID.
- 이미 캐릭터 메모에 가져온 문장은 복사본이다. 원문 수정만으로 기존 메모를 자동 교체하지 않으며 다시 불러올 때 갱신한다. 수동 메모 백업을 유지한다.
- 현재 163개 본문 = 세계 40변형 + 출신 57 + 직업 66. 추가 직업 여학생·무용가는 기본 데이터에 포함한다.
- 소녀는 중세 이전, 여학생은 중세 및 이후 세계로 나누며 둘의 기본 직업 보너스는 같다는 기획이다. 이후 소녀에 순수한 영혼 추가 지시가 있었으므로 두 직업에 공통 적용할지는 직업 명세 통합 때 확인한다. 현재 연결 구현이 특성 적용까지 의미하지는 않는다.

## 6. 연결 조건: 현재 구현

새 연결 기본값 버전: `20261112-links-v2`.

```text
허용 세계
  → 그 세계에서 허용한 출신
  → 그 세계에서 허용한 직업
  → 그 세계·직업이 요구/거부하는 출신 검사
  → 세계·출신·직업의 연령 조건 교집합
  → 유효 후보만 선택
```

- `links.worldFamilies[world]`: 세계별 출신 목록.
- `links.worldOccupations[world]`: 세계별 직업 목록. 모든 직업이 특정 출신 한 곳에 종속될 필요는 없다.
- `links.occupationFamilies["world:occupation"]`: 해당 세계·직업의 출신 허용/거부.
- `required:null`: 그 세계에서 허용한 출신 전체. 빈 배열 `[]`: 허용 출신 없음. `rejected`에 있으면 거부.
- 연령 `required:[]`는 제한 없음이며 여러 선택은 OR, 세계·출신·직업 간은 AND. 거부는 제외한다. 출신 허용 배열과 연령 필수 배열의 빈 배열 의미가 다름에 주의한다.
- 출신을 고정하지 않고 세계–직업만 탐색 가능하다. 출신을 고정하면 그 출신 조건까지 반영한다.
- 현재 검수 연결은 세계 본문 변형을 포함해 14,998개. 캐릭터 연령을 지정하면 후보 수가 달라진다. 이 숫자는 각 세계의 확률이나 개별 배경의 동일 확률을 의미하지 않는다.
- 우주 시설 직업은 우주 세계, 실제 마법 직업은 마법 세계, 공주는 왕가, 빈곤·생계형 경력은 해당 생활 여건 중심으로 제한한다. 세부 목록은 연결표를 기준으로 한다.
- 가난하거나 부모 직업이 다르다는 이유만으로 대학생·간호사 같은 교육 경력을 차단하지 않는다.
- 목록에 없는 새 세계/직업은 검토 없이 전역 연결하지 않는다.
- 기존 사용자의 연결을 자동 덮어쓰지 않는다. “검수 연결 적용”은 연결을 교체하고, 미지정된 승인 연령 기본값만 채운다. 기존 대사·수치·연령값은 보존한다. 이후 사용자 수동 연결도 재실행 시 유지한다.
- 사용자 예외 허용은 가능하므로 수동 수정 이후의 전체 조합 무모순까지 자동 보장하는 것은 아니다.

**연령 코드 주의:** seed_age 0/1/2의 실제 게임 의미를 숫자만 보고 나이로 환산하지 않는다. 현재 `background-settings.mjs`에는 `adultOnly && age===1` 제외 로직이 있다. 게임 본체 매핑과 대조해야 할 통합 검증 지점이다. 성인 대상 통계와 연령 필터가 일치하는지 재개 시 우선 확인한다.

## 7. 캐릭터 생성 공식: 기획과 구현의 경계

현재 `autoBackground()`는 이미 구성된 **유효 조합 행 중 고정 시드로 한 행**을 고르는 편집기 도우미다. 큰 직업·생활 분류의 후보가 없으면 그 분류 조건만 완화하고 연결·연령을 만족하는 전체 후보로 넓힌다. 금지 연결과 연령 조건은 해제하지 않는다. 게임의 능력치·특성까지 생성하는 함수가 아니다.

조합 행 추첨은 조합이 많은 세계 및 문장 변형이 많은 세계의 비중을 키울 수 있다. 이를 게임 본체의 세계별 독립 추첨 확률이라고 해석하면 안 된다. 게임 생성에서 세계/출신/직업별 가중치를 어떻게 둘지는 아직 별도 확정·구현이 필요하다.

### 통합 시 권장 처리 순서 — 미구현

1. 유니크 캐릭터인지 구분한다. 유니크의 고정 배경·스킬·특성·초기 기록을 우선한다.
2. 일반 캐릭터는 세계와 연령 코드, 허용 출신·직업 조합을 선택한다. 실제 추첨 전에 후보 교집합을 계산한다.
3. 세계에 따른 기본 능력치 추첨 보정을 적용한다.
4. 출신의 행동 성장 규칙과 직업 분류를 부착한다. 출신 성장 보정은 생성 시 능력치를 다시 뽑는 보정과 구분한다.
5. 직업/예외 출신의 특성 후보를 배척 그룹 안에서 추첨한다. 직업별 스킬 최저 조건과 특성 필요 조건을 함께 검사한다.
6. 특성이 요구하는 값과 직업 스킬 조건을 만족하도록 허용 범위 안에서 나머지 초기값을 채운다. 기존 값과 충돌하면 제한 횟수 재추첨 또는 명시적 실패로 처리한다.
7. 공통 특성 추첨으로 나머지를 채우되 이미 확정한 목표 확률·배척·금지 조건을 침범하지 않는다.
8. 최종 검증 후 저장한다. 과거 경험 초기값 확정은 통계 업데이트 도입 시 연결한다.

이 순서는 순환 의존성 방지용 권장안이며 게임 구현 완료나 모든 세부 우선순위의 최종 승인으로 취급하지 않는다. 배경에 맞춘 특성을 주기 위해 성격·스킬을 무제한 조작하거나 후보가 없다고 금지 조건을 풀지 않는다.

### 확률 해석

- “자유로운 영혼 30%”는 최종 생성 집단 10명 중 대략 3명이라는 목표다. 기존 공통 확률에 별도 30%를 더 굴리는 뜻이 아니다.
- 10% 보정이 직접 최종 확률인지, 기본 추첨 확률의 상대 배율인지 명세에서 구분한다. 이전 대화에서 수치가 생략된 항목을 일괄 10%로 채우지 않는다.
- 배척 특성은 그룹 단위로 추첨한다. 예: 레즈비언 30%, 양성애자 30%, 둘 다 없음 40%; 둘의 동시 보유 불가.
- 영웅 여전사: 20% 진입 → 타고난 투사/용감함 중 하나 확정 → 진입자 중 다시 20%에 역전의 용사/성기사/광전사 중 하나. 상위 세 특성은 중복 불가. 전체 기준 상위 획득 비율은 4%. 그룹 안의 세부 선택 가중치는 별도 명세가 필요하다.
- 뒤의 공통 추첨으로 위 목표 확률이 다시 올라가지 않게 한다. 최종 검증 단계에서 최소 조건·등장 금지·배척·실제 빈도를 검사한다.

## 8. 세계·출신·직업 보정 책임

| 구분 | 확정 역할 |
|---|---|
| 세계 | 초기 능력치 추첨 보정 |
| 출신 | 행동에 따른 성장·하락폭 보정. 예외적으로 특성 연결 가능 |
| 직업 | 초기 스킬과 특성 연결. 일반 능력치 추첨·성장폭 보정을 임의 추가하지 않음 |

현재 편집기에 남은 과거 경력용 세계×출신×직업 배수와 위 게임 생성 책임은 서로 다른 설계 층이다.

출신 보정 확정 요약:

| 계층 | 자아 | 태도 | 감수성 상승폭 | 세련됨 추가 추첨 |
|---|---|---|---|---|
| 세습 귀족 | 없음 | 상승폭 +10% | +10% | 20%로 +1 |
| 공주 | 없음 | 상승폭 +15% | +15% | 30%로 +1 |
| 야만족 공주 | 없음 | 상승폭 +15% | +10% | 10%로 +1 |
| 비세습 상류층 | 상승폭 +5% | 없음 | +10% | 10%로 +1 |
| 중산층 | 없음 | 없음 | 없음 | 10%로 +1 |
| 노동자·중하류층 | 하락폭 +5% | 하락폭 +5% | 없음 | 없음 |
| 하류층 | 하락폭 +10% | 하락폭 +10% | 없음 | 10%로 -1 |
| 극빈층 | 하락폭 +15% | 하락폭 +15% | 없음 | 20%로 -1 |
| 예술가류 | 없음 | 없음 | 없음 | 10%로 +1 |

해당 방향의 변화에만 적용한다. -10의 하락폭 +10%는 -11, 반대 방향 변화에는 영향 없음. 소수 변화량을 누적 보존한다. 태도는 낮을수록 좋고 자아·성격은 높을수록 좋다는 사용자 기준을 설명에 반영한다.

세련됨은 기본 초기 추첨 후 추가 1회, 최종 단계 0~5 제한. 기존 캐릭터와 초기값이 지정된 고정 캐릭터에는 적용하지 않는다. 57개 출신의 상세 분류는 최신 엑셀 우선.

구매형 모딩 개인실 거주와 동반 식당 외출에 감수성 성장 추가 기획이 있다. 기존 정보창의 개인침대와 별개다. 기본 증가량·상한·일일 적용 횟수는 미정이며 중복 처리부터 확인한다.

## 9. 직업별 기획을 재개할 때 지킬 공통 결정

아래는 이 대화에서 명시된 핵심 결정이다. 모든 직업의 수치가 완성된 데이터 표라는 뜻은 아니다. 사용자 특성·스킬 지정 후 추천한 확률 중 현재 기록에 전문이 없는 값은 미확정으로 남긴다.

- 평민: 직업 추가 특성 없음.
- 사냥꾼: 촌뜨기, 높은 대사량 각 10%. 문명생활 밖 직업의 촌뜨기 공통 규칙을 적용할 때 대상 목록을 명시한다.
- 바이킹의 아내: 비처녀 100%, 물기호증 40%, 촌뜨기 10%.
- 수녀: 은둔형 외톨이·동성애 혐오자·순수한 영혼·노출기피 방향, 처녀 90%. 너그러움 제외. 개별 특성 확률은 원명세 확인.
- 살인마: 혈액 기호증, 가학성애자 확률 상승, 무모함, 자유로운 영혼 30%. 직업 전투 스킬 부여 없음.
- 범죄자 공통: 자유로운 영혼을 범죄 경력 정도별로 설정하되 갱단·마피아 등 미확인 수치를 임의 복원하지 않는다.
- 도둑: 초기 체력 쇠약함·죽어감 제외.
- 목축업자: 착유사·돼지치기에 외양간지기를 맡길 간호·비서 기준 보장. 현 인계 기준 권장 하한 간호 B/비서 B는 실제 임명 조건을 게임에서 재검증하고 확정한다. 다른 추가 보너스 없음.
- 하녀: 타고난 하녀 발견 누적 경험치 기준 절반.
- 여마법사의 제자: 강한 복종심·집안일 보너스. 노예근성으로 대체하지 않음.
- 공주계열: 거센 반항심·벌레공포증·품위있는 여자 기획, 화술·회계·음악·미술·무용 F 제외. 직업별 확률은 별도 명세.
- 직조공: 끈기 20% 및 불감증 기획. 선반공은 직조공과 동일 방향.
- 페미니스트: 레즈비언/양성애자 각각 30%, 배척; 과대망상 30%, 거센 반항심 20%.
- 운동선수 공통: 초기 체력 B 이상, 운동광. 개별 운동광 확률은 최종 직업 표와 확인.
- 경찰관류: 화술·끈기 제외. 시공경찰관 건강체질 확률, 미래경찰 용감함 제외·옹졸함 확률, 교도관 가학성애자 추가.
- 대학생·작가: 천재 5%. 작가는 끈기 제외·달변가, 작가/화가는 야심가 기획.
- 모델: 운동광·품위있는 여자 제외, 낮은/미약한 대사량 등장 금지, 절세미인 5%.
- 클러버: 미련한 소·이국적인 댄서·무기력함 확률, 무용 D/F 제외, 무모함 제외.
- 무용가: 이국적인 댄서 확정, 끈기 제외.
- 우주군 사관생도: 야심가 5%, 용감함·비서 제외, 거센 반항심 확률.
- 전투로봇 파일럿: 거센 반항심·운동광 부여, 용감함 제외.
- 궤도 정비공: 운동광 추가.

성인 접객업 및 그 밖의 상세 성기술 초기값·발견 조건은 기존 승인 직업 명세와 대조하여 별도로 통합한다. 배경 연결 구현이 그 수치까지 반영했다는 뜻은 아니다. 직업 분류별 숨은 설정은 제안된 방식이며 `창녀/범죄자/목축업자` 등을 캐릭터별 데이터로 저장하는 것이 적절하다. 전역 임시 변수로 구현하더라도 캐릭터 간 값 누출을 막고 세이브 수명·역할 변경 시 보존을 설계해야 한다.

### 활동·집중 특성 최신 개편

끈기 → 워커홀릭 / 산만함 → 무기력함의 단계 구조. 없음 또는 네 특성 중 하나만 보유한다. 상위는 하위를 대체하고 효과를 포함하며 중복 실행하지 않는다. 자동 승급은 이번 기획에 없음. 상세 효과와 미정 이관 정책은 연결한 최신 개편 문서를 따른다. 기존 두 축을 통합하는 개편 요구이며 기존 교차 보유만으로 원작 버그라고 단정하지 않는다.

주요 JSON 키:

- 전체 설정 `schema: jo9-history-lab/v1`, `config`, `character`, `snapshots`; `backgroundBrowser`가 추가될 수 있다.
- `config.backgroundSettings`: `texts`, `links`, `ageRules`, `defaultConnectionsVersion`.
- 캐릭터 `storySelection`: `world / variant / family / occupation`.
- 게임 JSON 제안 블록 `jo9_initial_history`: 영입 이전 초기값 및 상세 분포.
- `jo9_owner_history`: 소속 이후 수익·가족 기록·전투 `combat_categories`.
- `jo9_history_design`: 편집기 프로필·선택·계수 관련 메타데이터.
- 위 블록은 편집기에서 왕복 가능하다는 뜻이다. 게임 본체가 읽고 누적하는 기능은 별도 구현해야 한다.
- 표준 샘플 `dist/samples/2571_isabella_initial_history_example.json`는 원작 확정 경력이 아니라 검증용 예시다.

## 11. 다음 담당자 작업 순서

1. 사용자의 가장 최근 전체 설정 JSON을 확보하고 기존 백업과 구분한다.
2. 편집기 소스 커밋과 게임 본체 커밋을 각각 기록한다.
3. seed_age 실제 매핑·특성 바인딩·직업 임명 조건을 게임 소스에서 확인한다.
4. 직업별 최종 스킬·특성 표를 데이터화한다. 확정 숫자와 확률 미정 항목을 구분한다.
5. 세계–출신–직업 연결과 배척·스킬 필요조건을 함께 검증한다. 상충 후보에 대한 실패 정책과 추첨 가중치를 정한다.
6. 통계 구현은 다음 업데이트에서 시작한다. 사건별 누적 위치, 초기값 고정, 구버전 이관·중복 방지를 먼저 설계한다.
7. 실제 게임 통합 후에만 게임 반영 완료를 보고한다.

검증 기준: 금지 조합 0건, 각 승인 후보 도달 가능, 연령 조건 교집합, 빈 후보 시 불법 대체 없음, 목표 최종 확률·배척 유지, 고정 캐릭터 보존, 명시된 0/미상 구별, JSON 원본 필드 보존, 확정 초기값 재추첨 방지, 성공 사건 중복 누적 방지.

## 12. 검증 이력과 한계

v0.11 배경 연결·대사·검색·보정·캐릭터 JSON·필드 순서·소속 후 전투/가족·설정 저장 관련 검사 통과. 브라우저에서 “검수 연결 적용” 후 14/57/66종 및 14,998개 조합 표시 확인. 이 이력은 독립 편집기 검증이며 게임 엔진 실행·실제 세이브 이관·사건 누적 테스트가 아니다.

이번 인계에서는 문서만 추가한다. 소스 기준 커밋 이후 인계 문서 추가 커밋은 작업 완료 보고에 별도로 기재한다.
