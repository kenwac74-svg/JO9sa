# 캐릭터 시뮬레이터 v1 (2026-11-12)

이전 산식(v0.11) 페이지를 기준으로 다시 받은 지시 9개를 반영한 새 화면이다. 편집기 사이드바 맨 위 "◆ 캐릭터 시뮬레이터"(기본 탭, `#character`). 이전 산식 페이지는 그대로 남겨 두었다.

## 1. 지시 반영
| # | 지시 | 반영 |
|---|---|---|
| 1 | 버튼 [랜덤 생성하기][유니크 불러오기][JSON 편집], 이사벨라 표준 케이스 삭제, [새로 만들기]로 전체 초기화 | 하단 패널 첫 줄. 새로 만들기는 확인 후 캐릭터 값·고정·대화 상태·지정값을 모두 지운다(배경 대사 수정본과 공식 계수는 유지) |
| 2 | 이름·ID는 유니크 JSON에서, 세계/출신/직업은 대분류 → 소분류, 배경 메모는 배경 설정 목록 구조(고정·직접 수정·저장하기·복원) | 위 "02 배경" 카드. 대사 저장은 배경 설정 목록과 같은 저장소(같은 항목의 모든 조합에 적용). 유니크는 JSON의 `seed_*_description`을 고치고 복원하면 JSON 원문으로 |
| 3 | 랜덤이면 실제로 뽑힌 이름·ID | 엔진 표본을 다시 뽑으며 `$stock_name`(이름)·`stock_type`(ID)을 기록(1만 명, 실패 0) |
| 4·5 | 출신·직업 대분류는 기존 분류 우선, 직업은 공통 특성 규칙 기준, 누락 보고 | 3장 |
| 6 | 전투 관련 제외 | 전적·전투 그룹 입력·표시 없음 |
| 7 | 입력 창은 하단 고정 패널, 가운데는 캐릭터 정보와 랜덤 필로우토크 | 하단 패널(접기 가능) + 위 카드 4개(정보·배경·과거 경험·필로우토크) |
| 8 | 특성·스킬은 게임 용어 텍스트 입력 | "특성·스킬 입력" 탭. 예: `겁쟁이, 펠라 4, 애널 B, 외모 3, 처녀, 헌신 4, 관계 순종`. 입력 중 후보 표시, 모르는 용어는 넣지 않고 표시. 특성 삭제는 카드의 특성 버튼(×) |
| 9 | 나머지 기능 중 내부 설정은 하단, 게임에 보이는 정보는 상단 | 2장 배치표 |

## 2. 이전 산식 페이지 기능 배치표
| 이전 기능 | 새 위치 | 비고 |
|---|---|---|
| 캐릭터 이름·고정 ID | 위 01 카드(표시) / 하단 JSON 편집 | 랜덤은 엔진 표본 값, 유니크는 JSON 값 |
| 이전 직업·생활 배경 | 하단 "배경 선택" (세계·출신·직업 대분류 → 소분류) | 이전의 설계용 묶음 대신 게임 ID |
| 배경 메모 | 위 02 배경 카드 | 3칸 구조 |
| 배경·예외 태그(레즈비언·클론·미경험·중독 등), 성향 보정(색정광·정액중독) | 하단 "특성·스킬 입력" (게임 특성 이름으로) | 예: `레즈비언`, `클론`, `처녀`, `색정광` |
| 개인 경력 보정 ×, 동성·인간 외 비중 % | 넣지 않음 | 승인된 과거 경험 공식은 이 값 대신 성향 특성·공식 계수를 쓴다. 필요하면 공식 계수에서 조정 |
| 고정 난수 시드 | 하단 "대화 상태·내부 설정" | |
| 스킬 분포(F~S 드롭다운) | 하단 텍스트 입력, 위 01 카드에 등급 표시 | 게임 성 기술 13종 |
| 초기 경력 미리보기 | 위 03 과거 경험 | 승인된 공식(세계·출신·직업) 결과 |
| 과거 경력 값 지정(확정 기록·직접 지정) | 하단 내부 설정 "직접 지정" | 총횟수·임신·출산. 빈칸 = 공식 |
| 소속 이후 누적 기록(수익·임신·출산·낙태·자녀) | 표시: 위 03 / 입력: 하단 내부 설정 | 전투 전적은 제외 |
| 산출 과정 | 하단 "섹스토크 사실" 탭 | 과거 경험·사실 산출 과정 함께 |
| 비교 보관함 확정·결과 내보내기 | 하단 JSON 편집의 [JSON 저장] | 보관함 연결은 아직 옮기지 않음(이전 캐릭터 형식 전용) |
| 전투 기록·전투 그룹 | 제외 | 추후 별도 패널 |
| 종족 태그·시드에이지 | 시드에이지는 연령 코드(0·2)로, 종족 태그는 아직 옮기지 않음 | |

- **세계**(지시대로 7개): 선사(원시 부족) · 고대(부족 전쟁, 지구의 고대 로마) · 중세(봉건 농경) · 판타지(검과 마법, 쇠락한 마법, 마법 문명) · 근대(증기 산업, 근대 산업) · 현대(현대 산업) · 미래(기업 지배 정보, 풍요로운 미래, 전체주의 통제, 성간 우주 문명).
- **출신**: 기존 분류가 있었다. 출신 성격 프리셋 엑셀 `presets/JO9_Origin_Personality_Presets_20261111.xlsx` '출신보정' 시트의 "사용자 최종 결정" 계층 분류 7개를 그대로 썼다. 세습 귀족·공주 4 / 비세습 상류층 15 / 중산층 14 / 예술가류 2 / 노동자·중하류층 12 / 하류층 5 / 극빈층 5. 57개 전부 들어간다.

  3. 귀족 아가씨(noble_bride)는 세습 상류층(사용자 결정 2026-11-12). 직업 대분류에 '세습 상류층'을 새로 두었다.
  4. 무용가는 예술·연예(사용자 확인 2026-11-12).
  5. 엑셀 '직업기획'은 기존 64개 + 여학생인데 편집기 배경 목록은 66개다(편집기 쪽 초안 7개 포함). 대조는 아직 안 했다.

## 4. 알려진 한계
- 유니크는 세계·출신·직업 ID가 없어 과거 경험을 기본 묶음으로 계산한다(유니크의 확정 과거값 `jo9_initial_history` 연결은 아직).
- 생성 단계의 정신 상태(sanity)는 0(미설정)이라 정신 상태 특성은 표시하지 않는다. "상표 없음"은 실제 생성 값이라 상태에 나온다.
- 필로우토크는 헌신 등급별 주제 목록을 보여 주고, 대사는 지금 있는 초안(첫 경험·횟수·이종 경험)만 나온다. 주제별 대사 원고는 아직 없다.
