# 필로우토크 샘플 v0 (2026-11-11)

사용자 지시: 과거 경험 데이터를 바탕으로 "노예와 대화한다" 메뉴에 여자 캐릭터가 주인공에게 과거 성경험을 이야기하는 대사를 넣는다. 대사는 속성·성격에 따라 섞는다(과시형은 부풀리고, 수줍은 형은 줄여 말한다). 이번 문서는 샘플이며 게임에는 넣지 않았다.

- 구현: `dist/pillow-talk.mjs`. 편집기 초기값 시뮬레이터 결과 칸의 "필로우토크 미리보기"에서 바로 확인한다.
- 대상: 과거 경험 공식 대상과 같다. 연령 코드 0·2의 랜덤 노예만. 연령 코드 1과 고유 캐릭터는 대사를 내지 않는다.
- 근거 규칙: `design/slave-voice` 브랜치 `docs/slave-voice/DIALOGUE_GENERATION_RULES.md`(유형 9종, 말투 3종, 존댓말만).

## 1. 무엇을 말하는가 (과거 경험 공식 결과)
1. 횟수 한마디: 성경험 총횟수. 0이면 경험이 없다는 말.
2. 화제 한마디(최대 2개): 유부녀면 남편 이야기와 출산(아이가 있으면), 성인 접객업이면 손님 이야기. 그다음 동성 상대가 1/3 이상이면 여자 상대 이야기, 아니면 구강·애널이 질보다 많을 때 그 이야기.
3. 인형형은 횟수 한마디만 한다(묻는 말에만 짧게 답하는 유형).

## 1-1. 문체 (사용자 결정 2026-11-12)
- 잭오나에 맞게 비속어와 노골적 표현을 쓴다. 게임 원문에는 이런 대사가 거의 없어서 원문을 참조하지 않고 새로 쓴다.
- 존댓말은 유지한다(대사 규정 2.3). 거친 성격은 비꼬는 존대와 비속어로, 수줍은 유형은 더듬지만 내용은 노골적으로 쓴다.
- 칸마다 변형을 여러 개 두고 시드로 고른다. 같은 노예·같은 시드면 같은 문장이다.
- 유부녀의 횟수 한마디는 남편 한 사람 기준 원고를 따로 쓴다.
- 성욕 특성(정액 중독·색정광·불감증·석녀)이 있으면 그 화제를 먼저 말한다.

## 2. 어떻게 말하는가
### 2.1 유형 9종 (성격+감수성 = 드러냄, 자아+태도 = 내세움)
| 유형 | 횟수를 말하는 방식 | 화제 말투 |
|---|---|---|
| 불꽃 | 실제의 3배로 부풀린다 | 과시 |
| 도도 | 1.5배 | 과시 |
| 솔직 | 어림말 그대로 | 과시 |
| 평범 | 어림말 그대로 | 담담 |
| 관조·얼음 | 정확한 숫자 | 담담 |
| 순종 | 0.7배로 줄인다 | 수줍음 |
| 여린 | 0.5배로 줄인다 | 수줍음 |
| 인형 | 어림말 그대로, 아주 짧게 | 화제 없음 |

- 어림말: 한·두·세 번, 몇 번(4~9), 열댓 번(10~19), 스무 번, 서른 번, 쉰 번, 백 번(70~149), 수백 번, 천 번.
- 여린·순종이 줄여 말해도 50회 이상이면 "많지 않다" 대신 부끄러움을 드러내는 원고를 쓴다(앞뒤 모순 방지).

### 2.2 말투 3종 (직업 기준)
합니다체(하녀·비서·수녀·경찰 계열·교도관·사관생도·로봇 파일럿), 투박한 해요체(부족 소녀·도둑·거지·점쟁이·창녀 계열·강도·산적·펑크·밀수업자), 그 밖은 해요체. 횟수 한마디는 세 말투 원고가 모두 있고, 화제 한마디는 아직 해요체만 있다.

## 4. 다음 단계
1. 화제·성욕 한마디의 합니다체·투박체 원고(지금은 해요체라 합니다체 노예도 화제는 해요체로 말한다)와 유형별 변형(지금은 과시·담담·수줍음 3갈래).
2. 화제 늘리기: 세계·출신 배경(예: 전쟁터, 궁정, 우주선), 순수한 영혼·이상성욕 선호, 처녀 고정 배경인데 비처녀가 된 경우. 변형 수 늘리기.
3. 같은 이야기 반복 방지와 해금 조건(호감·관계 단계), 하루 횟수.
4. 게임 적용: 과거 경험 값을 노예 값으로 저장하는 QSP 공식 → "노예와 대화한다" 메뉴 항목 → 원고 상수표(`#txt_man`) → 실제 엔진으로 여러 노예 대사 검증.
