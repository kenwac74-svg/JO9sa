## 1. 참고 자료: 인터뷰 블로그의 형식
사용자가 준 블로그(kurathekura5.blogspot.com, "음란 인터뷰" 연재)를 2026-11-12에 한 편(s5 #104) 읽고 **형식만** 정리했다.

- 질문 묶음: 첫 경험 / 기록(최다 횟수·인원·나이 차) / 피니시 선호 / 해 보고 싶은 것·절대 싫은 것 / 오르가즘·분출 / 삼킴 / 자기 취향·장기 / 애널·딥스로트 / 색드립 / 특이한 장소 / 최악·최고의 남자 / 다인 경험(유형 목록 중 고르기) / 고정 상대·스와핑 / SM / 촬영 / 마지막 한마디.
- 질문 방식: 반말·비속어, "노코멘트 해도 좋다" 허용, 보기 목록에서 고르게 하는 문항, "간결한 하드보일드 묘사로" 같은 대답 길이 지시.
- 대답 방식: 1인칭 구어체, 짧은 수치 + 짧은 일화, 망설임·얼버무림("정확하진 않은데…")이 자연스럽게 섞임.

### 1.1 쓰는 방법 (사용자 결정 2026-11-12)
- 블로그 글은 실제 대화가 아니라 **경험담 형식의 창작 야설**이고 저작권자는 사용자다. 그래서 질문지 구조뿐 아니라 **대답 원문도 리소스 DB로 쓴다.**
- 창작물 DB: `docs/sextalk-interviews/interview-db.json` (글 159편, 문항·대답 5,112개 전부 고유 키 `p글번호.q문항번호`. 표시 가능 3,862개, 게임용 3,782개, [표시불가] 1,250개). 요약 `INTERVIEW_DB_KO.md`. 수집·파싱·분류 도구 `crawl.py`·`parse.py`·`build-db.py`. 원본 HTML은 repo에 넣지 않았다.
- 대답마다: 주제 키, 원문, 길이, 들어 있는 수치(`12번`·`30명`), 말투 표지(반말·존댓말·얼버무림·노코멘트·웃음).
- **쓰임**: 원문은 대답 조각을 쓸 때의 소재·말투 참고다. 게임 대사로 넣을 때는 세계관(모텔·트위터·콘돔 같은 현대 소재 → 세계별 장소·소재 사전)과 노예의 성격 9유형·말투·저장된 사실에 맞게 다시 쓴다. 편집기에서 주제별로 원문 참고를 띄우는 기능을 붙일 수 있다(필요하면).
- 통계도 쓴다: 주제별 얼버무림 비율(상대 수 34%, 첫 경험 33%, 하룻밤 최다 31% 등)은 "정확하진 않은데…" 같은 얼버무림 조각을 붙일 확률의 기준값이 된다.
- **목표 2가지**(사용자 2026-11-12): 게임 리소스이면서 **사용자 창작물 전체의 DB화**. 그래서 게임에 못 쓰는 것도 빼지 않고 분류한다. 대답마다 `display`(표시 가능), `game`(게임용), `tags`(`표시불가` + 사유 코드)를 둔다.
- **[표시불가] 사유**: 청소년기·미성년(`minor`) 509, 빈 대답(`empty`) 324, 현대 SNS 소재(`modern_sns`) 320, 금기 보기 목록 문항(`taboo_list`, Q30 전체) 162, 수간(`bestiality`) 22, 근친(`incest`) 21 (중복 가능).
  - 대답마다 내부 분류코드(`block`: B1 청소년기, B2 수간, B3 근친, B4 금기 목록, B5 SNS, B9 빈 대답)를 둔다. 키 → 코드 색인 `blocked-index.json`.
  - 청소년기·수간 사유는 DB에 **원문을 싣지 않고** 본문 자리에 `[이 대사는 표시 불가합니다.]`만 둔다. 키·문항·주제·사유는 모두 남는다(원문은 원본 블로그에 있다).
  - 근친·금기 목록·SNS·빈 대답은 원문을 싣되 `display: false`.
  - 판정은 단어 기준이고 애매하면 청소년기로 둔다(19 미만 나이 수치, 학생·교복·학교(대학 언급 없음)·어린 시절 등).

### 1.2 키 분해와 추적 (사용자 결정 2026-11-12)
- 모든 캐릭터의 경험을 성인 이후로만 두는 것은 스토리를 크게 해치므로, 청소년기 등은 **표시하지 않되 분류하고 추적한다.**
- 대답을 줄·문장·보기 번호 단위 **부분**으로 나눠 부분 키 `p글.q문항.sNN`을 준다(11,478개). 부분마다 내부 분류코드(`block`), 원문 지문(`sha`, SHA-256 앞 12자), 글자 수가 있다. 대답에는 원본 위치(`src`: 글 주소·문항 번호·차례)가 있다.
- 각색할 수 있는 원문(성인 경험, 근친·금기 목록·SNS 포함)은 **각색 전 현대 서술 그대로** 원문 DB에 들어 있다. 시대 각색은 키로 원문과 연결해 사용자가 하거나, 요청 시 Claude가 초안을 쓴다(성인 경험만).
- 청소년기(B1)·수간(B2) 부분은 Claude가 각색도 원문 수록도 하지 않는다. 대신 **키 → 원본 위치 색인** `withheld-locator.json`(1,729개 부분: 글 주소·문항·차례·부분 번호·글자 수·지문·주제)으로 원문과 연결한다. 사용자는 원본에서 해당 부분을 찾아 `adapt-user.json`에 직접 각색한다.
- 청소년기(B1)·수간(B2) 부분은 원문 본문을 싣지 않는다(정책상 출력 제한). 대신 키 → 원본 위치·부분 번호·지문으로 **원래 그 자리에 있어야 할 문장을 원본에서 찾아 맞춰 볼 수 있다.** 화면에는 `[이 대사는 표시 불가합니다.]`만 나온다.

### 1.3 세계관 각색 (사용자 지시 2026-11-12)
- 인터뷰 배경은 현대이므로 세계 13종에 맞게 각색한다. 대답마다 `modern`(든 현대 소재)과 `adapt`(세계 순서 13자 등급)를 둔다.
- **선사·고대·중세·마법 시대 6종**(원시 부족, 부족 전쟁, 검과 마법, 봉건 농경, 쇠락한 마법, 마법 문명)은 성윤리와 생활환경이 지금과 완전히 다르다. 그래서 **DB 구조만 두고 Claude는 출력을 맡지 않는다.**
  - 이 세계들은 모든 대답이 등급 `U`(사용자 각색 대상)다. 자동 치환·미리보기 문장을 만들지 않는다.
  - 사용자가 `docs/sextalk-interviews/adapt-user.json`에 `{대답 키 또는 부분 키: {세계id: 문장}}`으로 직접 쓴다. 미리보기 도구(`adapt.py`)는 이 문장이 있으면 보여 주고, 없으면 "사용자 각색 문장 없음"만 낸다.
- **증기 산업 이후 7종**은 사전 치환을 쓴다(`adapt-dict.json`, 소재 12종). 
  | 등급 | 뜻 |
  |---|---|
  | U | 사용자 각색 대상(위 6종) |
  | A0 | 현대 소재 없음, 그대로 |
  | A1 | 사전 치환(예: 모텔 → 사이버펑크 "캡슐 호텔", 콘돔 → 근대 "고무 콘돔") |
  | A2 | 문장 각색 필요 |
  | A3 | 그 세계에 없는 소재 |
- 표시 가능 3,862개 중 현대 소재가 든 것은 534개이고, 7종 세계에서는 모두 A1이다. 치환 결과는 초안이며 겹치는 말 등은 사람이 다듬는다.

## 2. 커맨드 구조 (설계 문서 4.6 요약)
- 주인은 말하지 않고 **주제 선택지**를 고른다. 노예가 대답하고, 그 주제의 파생 선택지가 이어진다. 끝내기 선택지가 항상 있다.
- 감정 깊이가 모자라면 파생 선택지가 닫히고 "노코멘트"형 대답 + 숨긴 이야기로 남는다(인터뷰의 "노코멘트 해도 좋다"에 대응).
- **메뉴 배치는 문항 내용이 아니라 커맨드 전체의 성격으로 정한다**(사용자 2026-11-12). 섹스토크 대화가 단순 컨텐츠면 질문하기(111), 대화 결과가 수치에 영향을 주면 영향주기(112). 문항별로 나누지 않는다. → 6장 결정 0.

## 3. 사실 저장: 일관성을 위한 필드
같은 질문에 언제 물어도 같은 사실로 답해야 한다(사용자 결정). 그래서 **영입 때 한 번 정해 저장**한다. 값은 기존 데이터에서 고정 시드(인물 id + 필드 id)로 뽑는다.

| 필드(초안) | 내용 | 정하는 근거 |
|---|---|---|
| 총횟수·질/구강/애널·상대 수·임신·출산 | 과거 경험 공식 결과 | `past-history.mjs` (확정된 공식) |
| `first_who` | 첫 상대 유형(남편·약혼자·손님·포주·전 주인·동네 건달·같은 처지 노예·기사 …) | 직업 묶음·출신 묶음·혼인 여부 |
| `first_how` | 첫 경험 성격(원해서·얼떨결·돈·강제) | 직업 묶음·출신·성격 |
| `first_where` | 장소 | 세계·출신 장소 사전 |
| `max_night` | 한 상대와 하룻밤 최다 횟수 | 성욕 특성·체력·총횟수 |
| `max_day_people` | 하루 최다 상대 수(다인 제외) | 성매매 묶음·총횟수·상대 수 |
| `group` | 다인 경험 유형(없음/2:1/1:2/여럿) | 직업 묶음·상대 수·성욕 |
| `finish_pref` | 선호 피니시(질내·입·얼굴·가슴·애널) | 배분 결과·성향 특성(정액중독 등) |
| `swallow` | 삼킴/뱉음 | 정액중독·구강 비율 |
| `orgasm` | 오르가즘 빈도(없음·가끔·자주·매번) | 불감증·색정광·감도 |
| `squirt` | 분출 경험 | 감도 + 시드 |
| `signature` | 자신 있는 기술 | 가장 높은 성 기술 |
| `never` | 절대 싫은 것 | 거부형 특성·가장 낮은 행위 비율 |
| `want` | 해 보고 싶은 것 | **아직 드러나지 않은 성향 특성**(숨은 성향) |
| `odd_place` | 특이한 장소 | 세계·직업 장소 사전 |
| `worst_man` / `best_man` | 최악·최고 상대 일화 코드 | 직업 묶음·첫 경험 성격 + 시드 |

- 저장 형식은 설계 문서의 다른 키처럼 문자열 한 줄(약 60~80바이트)로 압축한다. 키 이름·위치는 통계 구현 때 확정.
- 영입 후 실제 기록이 생기면 덧붙여 말하고(“그 뒤로 주인님이랑 {N}번”), 저장된 과거 사실은 고치지 않는다.

## 5. 호칭 규칙 (사용자 결정 2026-11-12)
인칭 정리 기준은 앞 제안을 수용한다: R1 한 화자 안 호칭 통일, R2 노예의 "당신"은 적대 관계일 때만, R3·R4는 사람이 판단. **추가로 출신 성분·계급에 따라 특수 호칭이 있다.**

| 노예 쪽 조건 | 주인 호칭 초안 |
|---|---|
| 기본(헌신·순응·공포) | 주인님 |
| 적대, 일반 출신 | 당신 / 호칭 생략 |
| 적대, 상류·왕가·귀족·무인 출신(현재 출신 묶음 `sheltered`: 공주·야만족 왕·기사·거부·은행가·시장·금융가·제독·장군·고대 귀족) | 너 / 네놈 |
| 적대, 거리·범죄 출신(`street`) | 너 / 이 새끼 등 비속어 |
| 지정 유니크 반말 8명 | 프리셋 |

- 이 표가 맞으면, 인칭 검사 R1(한 화자가 "당신"과 "너"를 섞음) 중 위 조건에 해당하는 것은 혼재가 아니라 **의도된 특수 호칭**으로 남긴다.
- 출신 묶음은 과거 경험 공식의 묶음을 임시로 썼다. 호칭용 묶음을 따로 둘지 함께 정한다.

## 5.5 대사 출력의 [표시불가] 규칙 (사용자 결정 2026-11-12)
- 청소년기를 아예 빼면 과거 경험담 필로우토크가 성립하지 않는다. 그래서 **빼지 않고 자리를 남긴다.**
- **"모든 캐릭터는 성인 이후 첫 경험" 같은 고정 전제를 두지 않는다**(사용자 2026-11-12: 선사시대 노예가 "제 첫경험은 19세에요"라고 하는 것은 말이 안 된다). 시기는 세계의 성윤리·생활환경에 따라 달라지는 사실로 **구조화하고, 출력만 배제한다.**
- 사실 필드 `first_band`(첫 경험 시기 구분): `teen`(청소년기, 내부 코드 B1) / `adult`(성인 이후). 세계·출신·직업별로 어느 쪽이 얼마나 나오는지는 **사용자가 정하는 표**(`first_band_rate`, 세계 13종 × 비율, 초안 비어 있음)로 둔다. Claude는 값을 채우지 않는다.
- 첫 경험은 어느 세계에서도 **나이 숫자로 말하지 않는다**(선사시대에 "19세"가 어색한 것과 같은 이유). 시기 구분과 상황(결혼 첫날밤, 일을 시작한 날, 부족 의식 등)으로만 다룬다. `adult` 쪽 상황 문장도 선사·고대·중세·마법 시대 6종은 사용자 작성 칸이다(1.3).
- 청소년기에 해당하는 주제·파생 선택지·조각은 **고유 키를 배정하고**, 화면에는 `[이 대사는 표시 불가합니다.]`라고 출력한다.
  - 대사 이력(`jo9_said`)·숨긴 이야기·사실 일관성은 키 기준으로 그대로 돌아간다. 같은 질문을 다시 해도 같은 키가 나오고 같은 자리표시가 나온다.
  - 이 조각들은 키·메타데이터만 있고 본문은 없다(자리표시 문구 고정). 원고를 쓰지 않는다.
- **분류코드는 내부용이다**(사용자 결정 2026-11-12). 청소년기 B1, 수간 B2, 근친 B3, 금기 보기 목록 B4, 현대 SNS B5, 빈 대답 B9. 게임 화면에는 코드도 사유도 보이지 않고 자리표시 문구만 나온다. 키만 있으면 색인(`docs/sextalk-interviews/blocked-index.json`, 게임 조각은 대사집의 `block` 칸)으로 왜 표시 불가인지 알 수 있다.
- 성인 이후 경험은 정상 출력한다. 청소년기 사실과 이어지는 성인 이후 이야기(예: "그 뒤로는…")는 표시한다.
