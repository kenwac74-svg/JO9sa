# 통합 캐릭터 편집기 사용법 (2026-11-12)

캐릭터 시뮬레이터(배경·과거 경험·필로우토크)와 캐릭터 이미지 도구(전신·얼굴·외형)를 한 브라우저 화면으로 합친 편집기다. 시뮬레이터 탭은 그대로 있고, 맨 위에 **캐릭터 편집** 탭이 생겼다.

## 실행
| 방법 | 명령 |
|---|---|
| repo에서 | `python tools/jo9-history-lab/start-history-lab.py` |
| 단독 실행기 | `python JO9_character_studio.py` (또는 더블클릭). 게임 폴더를 바로 주려면 `--game "G:\...\game"` |

- 게임 파일 기능(외형·JSON·대사집·QSP)에는 **Pillow**가 필요하다: `python -m pip install pillow`. 없어도 시뮬레이터는 쓸 수 있다.
- 게임 폴더: repo의 `local.config.json`(GameQsp)이 있으면 그 폴더를 쓴다. 없으면 화면에서 `content/pic/girls/full`과 `json/slaves`가 있는 game 폴더 경로를 넣는다. 값은 `studio.local.json`(git 제외, 단독 실행기는 실행기 옆)에 남는다.
- 서버는 이 PC(127.0.0.1)에서만 열리고, 게임 폴더 밖에는 쓰지 않는다.

## 캐릭터 편집 탭
왼쪽 목록에서 번호·이름·파일명으로 찾아 연다. **+ 새 캐릭터**로 새로 만든다.

| 탭 | 하는 일 | 저장 위치 |
|---|---|---|
| 외형 | 슬롯(기본·타이틀·하녀·비서·도미나) 이미지 선택, 정렬(끌기·휠·화살표·숫자, 전체 맞춤, 투명 여백 기준, 두 점: 정수리→하단 컷/정수리→턱), 얼굴 상자 또는 얼굴 파일, 기존 이미지 다시 정렬, 연결 해제 | 게임 이미지 + 캐릭터 JSON. **외형 저장…**으로 쓸 파일을 먼저 보여 준다 |
| 배경·설정 | 이름, 나이 분류, 기본 심리, 처녀 여부, 배경 이야기 3칸(줄바꿈 = `<br>`) | 캐릭터 JSON(**저장…**) |
| 능력치·특성 | 게임이 읽는 seed 값 전부, 특성 88개 추가·빼기. ×는 고정값을 지워 게임이 무작위로 정하게 함 | 캐릭터 JSON(**저장…**) |
| 대사집 | 배경 분류(세계·출신·직업), 필로우토크 22칸마다 원본 DB를 골라 원문을 보며 직접 쓰기, 추가 칸, 메모. **시뮬레이터에서 열기 →** / **← 시뮬레이터 결과를 대사집에 담기** | `<게임>/jo9_talkbook/<ID>.json`(게임 JSON과 따로) |
| QSP 이벤트 | 이름·장면 태그로 jack.qsp 줄을 찾아 고친 뒤 **초안 만들기·검사** → JSON 내려받기 또는 repo `mods/`에 저장 | qsp는 직접 쓰지 않는다. `tools\apply_mods.ps1`로 적용 |
| 원본 JSON | 저장 전 변경을 포함한 미리보기 | — |

- **복제…**: 이미지는 원본과 함께 쓰고 이름·배경·능력치만 따로 고치는 새 번호(랜덤 풀 미등록).
- **삭제…**: 확인 번호를 넣어야 지운다. 랜덤 풀 중간 번호면 '번호 유지'(세이브 안전) 또는 '마지막 번호 이동'(세이브 주의)을 고른다. 다른 캐릭터가 함께 쓰는 이미지는 지우지 않는다.
- 캐릭터 JSON·대사집은 처음 저장할 때 같은 폴더에 `.bak`을 남긴다. 이미지는 덮어쓴다.
- 작업 기록: 게임 폴더의 `picture_modding/작업기록`(기존 이미지 도구가 있으면) 또는 `jo9_editor/작업기록`.

## 연령 코드 1
편집기가 스스로 만드는 것(시뮬레이터의 대사·과거 경험 자동 생성)만 하지 않는다. 시뮬레이터에서 담으면 배경 분류와 원본 DB 연결 코드(키·표시불가 코드)만 온다. 직접 쓴 칸은 그대로 저장한다.

## 기존 이미지 도구와 다른 점
- 배경 자동 제거(rembg)는 없다. 필요하면 기존 도구(캐릭터추가.bat)를 쓴다.
- 같은 입력이면 같은 PNG가 나온다(서버가 기존 도구의 `align_core`·`add_character` 함수를 그대로 쓴다).
