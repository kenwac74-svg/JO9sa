# 1a장. 주인공 카드

- 쓰는 곳: 그 세이브의 주인공(`hero_select`) 카드 하나만 붙인다.
- 주인공의 위치(세력·자금·처지)와 성격은 고른 주인공 설정에 따라 달라진다. 이 장에서 다루지 않는 공통점은 1장에 있다.
- **여주인공(번호 101~124)은 한국어판에서 삭제되었다.** 주인공 선택 화면에는 1~18번 남성 주인공만 나온다(`$scroll_heroes_man`). 여주인공 데이터가 qsp에 남아 있어도 카드는 만들지 않는다.
- 노예와 대사에서 주인공은 이름(`$master_name`, 플레이어가 바꿀 수 있음) 또는 '당신'으로 나온다. 노예가 주인공을 부르는 호칭은 7장 호칭표를 따른다.
- 능력은 시작값 기준으로 4~5인 것만 적었다(0~5 척도). 능력 이름은 내부 변수 기준이다.
  - tutor=교육, butler=집사, artdirector=예술 감독, medic=의술, fighter=전투, mage=마법, torture=고문, domination=지배, bondage=속박, flagelation=채찍질, petting=애무, oral=구강, penetration=삽입, fetish=페티시, str=힘, cha=매력, style=세련됨, libido=성욕, energy=행동력

## 카드 형식
`번호 · 이름` / 세력 · 시작 자금 · 난이도 / 내력 / 강한 능력 / 특이 사항 / 창작할 때 붙잡을 결

## 근거

- `start_game`: `hero_select = hero_choice`, 10번 `is_kid = 1`.
