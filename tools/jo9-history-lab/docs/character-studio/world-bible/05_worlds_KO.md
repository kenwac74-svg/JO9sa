# 5장. 출신 세계별 각색 지침

- 쓰는 곳: 그 캐릭터(또는 엑셀 열)의 세계 절만 붙인다. 8a장(각색 요령)과 함께 쓴다.
- 근거: 게임 배경 대사(`dist/data/backgrounds.json`, 세계마다 3가지 변형), 바꿀 말 사전(`docs/sextalk-interviews/adapt-dict.json`). "게임 속 모습"은 게임 문장의 요약이고, 나머지는 그 세계에 맞춘 각색 지침이다.
- 공통: 노예는 그 세계에서 살다 안개에 흘러들어 영원의 로마로 왔다. 과거 이야기에는 그 세계의 소재만 쓰고 로마 소재(길드·경매·낙인)는 쓰지 않는다.

## 5.1 원시 부족 세계 (`prehistoric`)
- 게임 속 모습: 며칠을 걸어도 이어지는 숲, 눈과 얼음의 땅, 늪과 악어의 강. 사냥과 채집, 동굴과 모닥불, 큰 짐승의 위협, 사냥감은 무리가 나눔.
- 생활: 무리(씨족) 단위로 산다. 일은 사냥·채집·불 지키기·가죽 손질. 돈이 없고 고기·가죽·도구를 나눈다.
- 만남과 관계: 상대는 같은 무리나 이웃 무리의 사냥꾼·연장자. 짝짓기는 무리가 다 아는 일이고, 계절 축제·모닥불 가, 사냥 뒤 같은 때가 계기다. 혼인 제도보다 짝과 무리의 승인. 임신은 운에 맡긴다.
- 둘만 있을 곳: 동굴 안쪽, 가죽 천막, 모닥불 뒤 어둠, 숲속 풀밭, 물가 바위 그늘.
- 소재 바꾸기: 숙박·집 → 동굴·가죽 천막 / 탈것 → 없음(걸어서, 통나무배) / 유흥 장소 → 모닥불 둘레의 춤·잔치 / 공중 장소 → 수풀·바위 뒤 / 피임 → 없음(사후 약초 정도) / 성인용품 → 깎은 뼈·나무 / 촬영·통신 → 없음(벽화, 소문) / 직장·학교 → 사냥터·채집터 / 돈 받는 만남 → 고기·가죽과 바꾸는 잠자리
- 말에 묻어날 낱말: 무리, 우두머리, 사냥꾼, 불, 가죽, 창, 짐승, 달이 몇 번 차고
- 없는 것: 글자, 돈, 쇠붙이, 옷감 상점, 날짜·나이를 정확히 세는 습관(나이는 '겨울을 몇 번 났다'로).

## 5.2 부족 전쟁 세계 (`barbarian`)
- 게임 속 모습: 초원의 기마 부족, 숲·강·초원의 마을과 습격, 거센 바람의 협만과 배·항구. 전쟁과 약탈의 전리품이 살림을 좌우.
- 생활: 부족·씨족과 족장. 남자는 싸우고 가축을 돌보고, 여자는 집·가축·베 짜기. 포로가 노예가 되는 일이 흔하다.
- 만남과 관계: 중매·약탈혼·전리품. 부족 잔치와 술, 원정 뒤 귀환, 강한 전사가 데려가는 것. 처녀성과 가문 체면이 중요한 부족도 있다.
- 둘만 있을 곳: 천막(유르트)·긴집, 마구간·헛간, 배 위, 강가, 잔칫집 뒤.
- 소재 바꾸기: 숙박·집 → 천막·긴집 / 탈것 → 말·수레·배 / 유흥 장소 → 족장의 잔치·술자리 / 공중 장소 → 마구간·창고 / 피임 → 없음 / 성인용품 → 없음(뿔잔·가죽끈 정도) / 촬영·통신 → 없음(전령·노래) / 직장·학교 → 목초지·배·싸움터 / 돈 받는 만남 → 전리품·포로로 바쳐지기
- 말에 묻어날 낱말: 족장, 전사, 원정, 전리품, 말, 꿀술, 노래꾼, 모피
- 없는 것: 도시 상점, 종이, 정식 학교, 화약.

## 5.3 검과 마법의 세계 (`sns`)
- 게임 속 모습: 여러 왕국과 제국의 전쟁, 도시 밖 약탈자, 사막·깊은 숲·여러 부족의 풍습, 마법사와 이름난 전사의 이야기. 보통 사람은 농사·장사·수공업.
- 생활: 왕국의 도시와 마을. 마법은 있지만 드물고 비싸다. 은화·금화로 사고판다. 모험가·용병·상단이 오간다.
- 만남과 관계: 마을 축제, 여관, 상단·용병단 동행, 신전 의식. 결혼은 집안끼리, 혼전 관계는 숨긴다. 매춘은 여관·사창가.
- 둘만 있을 곳: 여관 방, 헛간 건초더미, 야영 천막, 성채 뒤뜰, 신전 뒤 정원.
- 소재 바꾸기: 숙박 → 여관 방 / 집 → 다락방·셋방 / 탈것 → 마차·말 등 / 유흥 장소 → 주점·여관 1층 / 공중 장소 → 뒷골목·마구간 / 피임 → 약초 달인 물·마녀의 물약 / 성인용품 → 매끈하게 깎은 나무·마법 장신구 / 촬영 → 초상화·환영 마법 / 통신 → 편지·전서구·소문 / 직장·학교 → 공방·상점·마법 학원 / 돈 받는 만남 → 여관·사창가에서 몸 팔기
- 말에 묻어날 낱말: 여관, 주점, 금화, 기사, 용병, 마법사, 신전, 영주
- 없는 것: 총·기계, 사진, 근대식 학교.

## 5.4 봉건 농경 세계 (`medieval`)
- 게임 속 모습: 숲·밭·강을 따라 이어진 마을, 영주의 땅과 공물, 귀족·기사·장인·농민·사제의 뚜렷한 신분. 계절 농사와 세금.
- 생활: 장원과 교구. 신분이 일과 혼인을 정한다. 교회가 의식과 교육, 도덕을 맡는다.
- 만남과 관계: 정혼과 지참금, 교회의 혼인. 혼전 관계와 간음은 죄이고 소문이 무섭다. 영주·기사의 권력, 하녀와 주인, 순례길·장날의 만남.
- 둘만 있을 곳: 건초 헛간, 방앗간 다락, 하인 숙소, 성의 침실, 여관, 숲속 오두막.
- 소재 바꾸기: 숙박 → 여관·순례자 숙소 / 집 → 오두막·하인 방 / 탈것 → 수레·말 / 유흥 장소 → 장터·선술집·축제 / 공중 장소 → 헛간·마구간·교회 뒤 / 피임 → 없음(동정·질외, 약초) / 성인용품 → 없음 / 촬영·통신 → 없음(편지, 사람 말) / 직장·학교 → 장원 일터·공방·수도원 / 돈 받는 만남 → 몸 팔기(목욕탕·사창가)
- 말에 묻어날 낱말: 영주, 장원, 사제, 고해, 지참금, 장날, 하녀, 순결
- 없는 것: 마법, 총, 기계, 사진, 피임 도구.

## 5.5 쇠락한 마법 세계 (`darkfantasy`)
- 게임 속 모습: 옛 제국이 무너진 뒤의 쇠락, 버려진 길과 약탈자, 괴물과 강령술사, 용의 습격과 전염병. 살아남는 일이 먼저.
- 생활: 성에 숨은 영주, 굶주린 마을, 떠돌이·피난민, 용병과 마녀사냥꾼. 돈보다 식량과 보호가 값지다.
- 만남과 관계: 거래와 생존이 섞인다. 보호해 주는 사람, 피난길에서 만난 사람, 하룻밤 따뜻한 잠자리. 다정함은 드물고 짧다.
- 둘만 있을 곳: 폐허, 버려진 예배당, 피난민 천막, 성벽 아래 움막, 여관 마구간.
- 소재 바꾸기: 숙박 → 낡은 여관·버려진 집 / 탈것 → 수레·피난 행렬 / 유흥 장소 → 음침한 선술집 / 공중 장소 → 폐허·지하 묘지 / 피임 → 마녀의 약초 / 성인용품 → 없음 / 촬영·통신 → 없음(소문·포고문) / 직장·학교 → 성의 부엌·대장간·약초방 / 돈 받는 만남 → 빵 한 덩이·보호와 바꾸는 잠자리
- 말에 묻어날 낱말: 폐허, 역병, 망자, 강령술사, 마녀, 피난, 성벽, 굶주림
- 없는 것: 풍요, 밝은 축제, 기계.

## 5.6 마법 문명 세계 (`highfantasy`)
- 게임 속 모습: 큰 힘의 마법사 회의, 마법 실험의 소동, 인간·엘프·드워프 동맹과 강령술사 왕의 전쟁, 일곱 왕국의 통합과 장벽 너머의 오래된 존재.
- 생활: 번창한 도시와 마법 학원, 여러 종족이 섞인 거리. 마법이 생활 곳곳에 쓰인다(빛, 치료, 전령).
- 만남과 관계: 종족이 다른 상대, 마법 학원·궁정의 연애, 전쟁 원정. 귀족 혼약, 엘프의 긴 수명 같은 차이가 사연이 된다.
- 둘만 있을 곳: 학원 기숙사, 탑의 연구실, 숲속 엘프 마을, 궁정 정원, 여관.
- 소재 바꾸기: 숙박 → 여관·마법 숙소 / 집 → 탑의 방·학원 기숙사 / 탈것 → 마차·그리폰·마법 배 / 유흥 장소 → 연회장·음유시인의 주점 / 공중 장소 → 정원·회랑 / 피임 → 피임 마법·물약 / 성인용품 → 마법이 깃든 기구 / 촬영 → 기억 수정·환영 / 통신 → 전령 마법·편지 / 직장·학교 → 마법 학원·길드 / 돈 받는 만남 → 몸 팔기·후원자
- 말에 묻어날 낱말: 마법사, 학원, 엘프, 드워프, 왕국, 회의, 주문, 수정구
- 없는 것: 총, 공장, 전기.

## 5.7 증기 산업 세계 (`steampunk`)
- 게임 속 모습: 자원을 다투는 제국과 전함·증기기관, 계산 기계와 비행선, 공장으로 몰린 시골 사람들, 석탄 연기와 오염.
- 생활: 공장 도시와 귀족 저택, 노동자 공동주택. 신분과 돈의 격차가 크다.
- 만남과 관계: 무도회·살롱, 공장 동료, 하숙집, 중매. 체면을 따지는 상류층과 거친 노동자 거리의 풍습이 다르다.
- 둘만 있을 곳: 하숙집 방, 여관 객실, 기차 객실, 공장 창고, 살롱 뒷방.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 여관 객실 · 집 → 공동주택 방 · 탈것 → 증기기관차 객실 · 유흥 장소 → 살롱 · 공중 장소 → 증기 승강기 안 · 피임 → 고무 주머니 · 성인용품 → 태엽 진동기 · 촬영·영상 → 은판 사진 · 통신·SNS → 전신 · 직장·학교 → 공장 · 돈 받는 만남 → 몸 팔기
- 말에 묻어날 낱말: 증기, 공장, 비행선, 신사, 숙녀, 살롱, 은판 사진, 전신
- 없는 것: 전화·컴퓨터·자동차(증기차는 가능).

## 5.8 근대 산업 세계 (`industrial`)
- 게임 속 모습: 공장·은행 자본가와 노동조합·파업 진압, 포격과 가스의 세계대전과 배급, 전쟁 뒤 통합 국가와 폐허.
- 생활: 공장 노동, 전쟁 동원, 배급표, 신문과 라디오. 20세기 초~중반 느낌.
- 만남과 관계: 댄스홀·카바레, 공장 동료, 전쟁으로 떨어진 연인, 편지와 전보. 매춘과 전쟁 미망인.
- 둘만 있을 곳: 싸구려 호텔, 공동주택 방, 기차 객실, 공장 탈의실, 방공호.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 싸구려 호텔 · 집 → 공동주택 방 · 탈것 → 기차 객실 · 유흥 장소 → 카바레 · 공중 장소 → 공중변소 · 피임 → 고무 콘돔 · 성인용품 → 전기 안마기 · 촬영·영상 → 사진 · 통신·SNS → 전보 · 직장·학교 → 공장 · 돈 받는 만남 → 몸 팔기
- 말에 묻어날 낱말: 공장, 노조, 배급, 전보, 라디오, 카바레, 전선, 징집
- 없는 것: 휴대전화·인터넷·SNS.

## 5.9 현대 산업 세계 (`modern`)
- 게임 속 모습: 부유한 나라와 가난한 나라, 선거와 독재·내전, 한 강대국의 영향력과 경제 위기·시위, 냉전 뒤 세계화.
- 생활: 인터뷰 원문과 같은 시대. 소재는 그대로 둔다.
- 만남과 관계: 원문 그대로. 화자만 노예(주인 앞)로 바꾼다.
- 둘만 있을 곳: 원문 그대로.
- 소재 바꾸기: 바꾸지 않는다(소재 그대로).
- 말에 묻어날 낱말: 원문 그대로
- 없는 것: 바꿀 것 없음. 단 영원의 로마 이야기와 섞지 않는다.

## 5.10 기업 지배 정보 세계 (`cyberpunk`)
- 게임 속 모습: 거대 통신망과 가상 공간, 지원금에 기대 사는 인구, 기업이 관리하는 구역과 낡은 공공시설, 정부 역할까지 하는 대기업.
- 생활: 메가시티, 기업 구역과 슬럼, 사이버웨어 이식, 넷. 돈 없는 사람은 보호받기 어렵다.
- 만남과 관계: 넷과 홀로 클럽, 기업 사내, 뒷골목 거래. 몸과 정보가 상품이 된다.
- 둘만 있을 곳: 캡슐 호텔, 메가블록 방, 호버카 안, 클럽 뒷방, 가상 공간.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 캡슐 호텔 · 집 → 메가블록 방 · 탈것 → 호버카 안 · 유흥 장소 → 홀로 클럽 · 공중 장소 → 공용 위생칸 · 피임 → 피임 임플란트 · 성인용품 → 신경 자극기 · 촬영·영상 → 홀로 녹화 · 통신·SNS → 넷 · 직장·학교 → 기업 타워 · 돈 받는 만남 → 몸 팔기
- 말에 묻어날 낱말: 기업, 넷, 임플란트, 크레딧, 메가블록, 홀로그램
- 없는 것: 종이 편지·마법.

## 5.11 풍요로운 미래 세계 (`utopia`)
- 게임 속 모습: 식량·치료 걱정이 없는 사회, 자연과 조화, 주민 협의, 기계가 만드는 물자, 배움과 예술, 군대·경찰 없는 중재.
- 생활: 일하지 않아도 되는 풍요, 공동체 의논, 예술과 학문.
- 만남과 관계: 자유롭고 합의 중심. 다자 관계·실험이 흔할 수 있다. 소유·독점 개념이 약하다.
- 둘만 있을 곳: 거주 모듈, 공용 정원, 쾌락 라운지, 숙박 포드.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 숙박 포드 · 집 → 거주 모듈 · 탈것 → 운송 캡슐 · 유흥 장소 → 쾌락 라운지 · 공중 장소 → 위생 캡슐 · 피임 → 나노 피임막 · 성인용품 → 쾌락 기구 · 촬영·영상 → 감각 기록 · 통신·SNS → 뉴럴 링크 · 직장·학교 → 연구소 · 돈 받는 만남 → 쾌락 거래
- 말에 묻어날 낱말: 공동체, 모듈, 라운지, 협의, 창작
- 없는 것: 가난·돈 문제·폭력 조직.

## 5.12 전체주의 통제 세계 (`darkfuture`)
- 게임 속 모습: 지도자의 가르침과 배급, 바깥세력 경계, 대립하는 세 나라와 진리부의 공식 발표, 같은 제복·규격 주택, 감정까지 관리.
- 생활: 감시와 배급, 당원과 비당원, 사적 공간이 거의 없음.
- 만남과 관계: 허가된 짝, 감시를 피한 몰래 만남, 고발의 두려움. 사적인 감정 자체가 위험하다.
- 둘만 있을 곳: 배정 주거칸, 공용 위생칸, 감시가 없는 숲·폐공장, 지하 술집.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 배급 숙소 · 집 → 배정 주거칸 · 탈것 → 통제 열차 · 유흥 장소 → 지하 술집 · 공중 장소 → 공용 위생칸 · 피임 → 배급 피임약 · 성인용품 → 밀수 기구 · 촬영·영상 → 감시 기록 · 통신·SNS → 감시망 메신저 · 직장·학교 → 배정 작업장 · 돈 받는 만남 → 배급표 받고 몸 대주기
- 말에 묻어날 낱말: 배급, 감시, 당, 진리부, 제복, 고발
- 없는 것: 자유로운 연애 문화·사치품.

## 5.13 성간 우주 문명 (`space`)
- 게임 속 모습: 여러 행성의 은하 공화국과 초공간 항해, 통합 정부의 정착지와 탐사선, 황제와 교회의 거대 제국과 외계의 위험.
- 생활: 함선·정거장·식민 행성. 승무원·정착민·군인.
- 만남과 관계: 함선 승무원끼리, 정거장 바, 장기 항해의 외로움, 외계 종족.
- 둘만 있을 곳: 정거장 선실, 함선 거주 구획, 셔틀 안, 정거장 바.
- 소재 바꾸기: 맨살 → 맨살로 · 숙박 → 정거장 선실 · 집 → 거주 구획 · 탈것 → 셔틀 안 · 유흥 장소 → 정거장 바 · 공중 장소 → 위생 구획 · 피임 → 피임 임플란트 · 성인용품 → 신경 자극기 · 촬영·영상 → 홀로 녹화 · 통신·SNS → 성간 통신 · 직장·학교 → 함선 근무지 · 돈 받는 만남 → 몸 팔기
- 말에 묻어날 낱말: 함선, 정거장, 행성, 항해, 성간 통신, 홀로
- 없는 것: 말·마법(제국 교회는 신앙).

## 5.14 지구의 고대 로마 (`earth_rome`, 신규 초안)
- 게임 속 모습(초안 배경): 돌을 깐 거리와 시장, 목욕탕, 노예를 거느린 저택. 영원의 로마와 생활이 비슷해 적응이 쉽다. 마법과 안개만 고향에 없다.
- 생활: 귀족·자유시민·해방노예·노예의 신분. 가문과 후견인.
- 만남과 관계: 집안끼리의 혼인, 주인과 노예, 목욕탕·연회·축제. 노예는 주인의 소유라 관계를 거절할 권리가 약하다.
- 둘만 있을 곳: 저택의 침실·노예 방, 목욕탕, 여관, 신전 뒤.
- 소재 바꾸기: 숙박 → 여관 / 집 → 인술라(공동주택)·저택 / 탈것 → 가마·마차 / 유흥 장소 → 연회·목욕탕·사창가 / 피임 → 약초·질외 / 통신 → 편지·전령 / 직장 → 가게·공방·저택 일 / 돈 받는 만남 → 사창가(루파나르)
- 말에 묻어날 낱말: 주인님(도미누스), 저택, 목욕탕, 연회, 원로원, 해방
- 없는 것: 마법, 안개, 기계.
- 주의: 바꿀 말 사전(13개 세계)에는 아직 열이 없다. 엑셀 각색 열도 없다.
