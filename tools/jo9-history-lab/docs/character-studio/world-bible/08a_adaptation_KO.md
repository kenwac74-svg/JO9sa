# 8a장. 인터뷰 대답 각색 요령

- 쓰는 곳: 인터뷰 대답 각색 작업마다 **항상** 붙인다. 대상 세계의 5장 절과 그 캐릭터의 카드(6장·7장)를 함께 붙인다.
- 작업 대상: 사용자가 준 엑셀(`jo9-interview-adapt-*.xlsx`)의 행. 열은 `키`, `주제`, `대답 원문(수정 금지)`, 그리고 세계 13열이다. 세계 열에 각색 문장을 쓴다.
- 기준: 바꿀 말 사전(`docs/sextalk-interviews/adapt-dict.json`), 필로우토크 조립 규칙(`docs/JO9_Pillow_Talk_Rules_v1_20261112.md`), 창작 의도 보존 지침(`docs/CREATIVE_INTENT_RULES_20261015.md`).

## 1. 무엇을 바꾸는가
- 원문: 현대 한국에 사는 실제 사람이 블로그 인터뷰에서 자기 성경험을 1인칭으로 답한 글이다.
- 결과: 잭오나 세계의 **노예가 영원의 로마에서 주인에게 자기 과거를 이야기하는 대사**다(게임의 "노예와 대화한다" → 필로우토크·섹스토크).
- 원문은 소재 창고다. 사람·나이·장소·방법·느낌 같은 **사실의 뼈대**는 살리고, 그 세계에 없는 물건·장소·제도와 현대 말투를 바꾼다.

## 2. 순서
1. **사실 뼈대 뽑기**: 누구와(관계), 대략 몇 살쯤, 어디서, 무엇을, 어떻게 느꼈는지. 원문에 없는 사건을 덧붙여 부풀리지 않는다.
2. **세계 소재 바꾸기**: 3장의 표와 대상 세계의 5장 절을 따른다.
3. **화자 바꾸기**: 노예가 주인에게 말하는 1인칭 회상으로 바꾼다(4장).
4. **시점 확인**: 고향 세계에서 있었던 일(영입 전)과 로마에서 있었던 일(영입 후)을 섞지 않는다. 영입 전 이야기에는 로마의 소재(길드, 경매, 낙인, 파리드 등)가 나오지 않는다.
5. **길이**: 한 대답은 1~3문장, 230자 안팎(게임 대사 상자가 230자 경계에서 페이지를 나눈다). 원문을 길게 그대로 옮기지 않는다.

## 4. 화자와 말투
- **1인칭 담담한 회상.** 노예가 주인 앞에서 기억을 꺼내는 말이다. 광고 문구·구호·설명문 투를 쓰지 않는다.
- **말투**: 기본은 일반 존댓말. 직업 코드 maid, valertry, secretary, nun, policewoman, mind_contol, time_plice, jailer, academy, mech는 격식 존댓말(필로우토크 규칙 3.2). 반말은 사용자가 지정한 유니크 8명만 쓴다(일반 노예에는 쓰지 않는다).
- **성격 9유형**에 맞춘다(7장): 불꽃은 과시하고 부풀리고, 도도는 거리를 두고, 순종·여린은 줄여 말하고, 관조·얼음은 숫자를 정확히 말하고, 인형은 아주 짧게 말한다.
- **관계 모드와 감정 깊이**: 적대(반항)이면 짧고 차갑게, 두려움·우울이면 머뭇거리며, 헌신이면 솔직하게. 같은 사실이라도 말하는 결이 달라진다. 엑셀 칸 하나에는 관계가 정해지지 않았으므로 **중립 모드(담담한 일반 존댓말)** 로 쓴다. 다른 결이 필요한 작업은 따로 지시한다.
- 주인에게 비속어를 쓰지 않는다. 주인을 하대하지 않는다.

## 5. 하지 말 것
- 현대 말(폰, 모텔, 회사, 카톡 등)이 다른 세계 문장에 남는 것.
- 원문에 없는 사실을 지어내 사건을 키우는 것, 반대로 원문의 고유한 경험을 하나의 전형으로 뭉개는 것.
- 가족 관계가 앞뒤 모순되는 것(예: 외동이라더니 언니 이야기).
- 그 세계의 시대에 맞지 않는 소재(원시 부족 세계의 열차 등).
- 현실의 가치판단으로 세계관·설정을 바꾸는 것(창작 의도 보존 지침 1).
- `대답 원문` 열과 `키` 열을 고치는 것. 고쳐도 가져올 때 무시된다.

## 6. 작은 예 (소재 치환만 보이는 예)
- 원문 조각: "…모텔에서 처음 했어요."
- 증기 산업 세계: "…여관 객실에서 처음이었습니다."
- 성간 우주 문명: "…정거장 선실에서 처음이었어요."
- 봉건 농경 세계(다시 쓰기): 모텔이라는 것 자체가 없으므로, 그 세계에서 둘이 단둘이 있을 만한 곳(헛간, 방앗간 다락 등)으로 장면을 다시 짓는다.

## 7. 결과 넘기는 법
- 받은 엑셀의 세계 열에 써서 돌려주거나, 키를 맞춘 별도 JSONL(`{"key": "p0012.q07", "world": "steampunk", "text": "…"}`)로 낸다(`AI_WORK_SCHEMA_KO.md`).
- 사용자가 편집기 DB 탭 '엑셀 가져오기'로 검사한 뒤 반영한다. 검사는 키 기준이라 정렬·필터로 행 순서를 바꿔도 된다.
- `*`는 원문 일부를 가린 자리다(`[클로드 정책준수]`, 분류 열에 표시). 가린 부분을 추측해 채우지 말고 보이는 사실만으로 각색한다. 원문은 사용자가 원본 글 링크에서 본다.
