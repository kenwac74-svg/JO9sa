# 7장. 말하기 규칙

- 쓰는 곳: 대사 창작·각색·번역 작업에 **항상** 붙인다(8a장과 함께). 대화 각색에서 가장 중요한 단서다.
- 근거: 게임 `#dynamic`의 `$voice_profile`·`$voice_mental`·`$voice_index`·`$voice_flow_pack`, 인상 묻기 대사(`#txt_man` `$voice_1112`, 108문장), `docs/SLAVE_VOICE_STAGE1_20261017.md`, `docs/slave-voice/`, 필로우토크 규칙(`docs/JO9_Pillow_Talk_Rules_v1_20261112.md`).

## 7.1 성격 9유형
- 표현 = 성격(temper) + 감수성(sensitivity), 주장 = 자아(ego) + 태도(pride). 각각 3 이하 낮음 · 4~6 중간 · 7 이상 높음.

| 주장 \ 표현 | 낮음 | 중간 | 높음 |
|---|---|---|---|
| 낮음 | 인형(doll) | 순종(meek) | 여린(fragile) |
| 중간 | 관조(calm) | 평범(plain) | 솔직(frank) |
| 높음 | 얼음(ice) | 도도(proud) | 불꽃(flame) |

| 유형 | 말버릇 |
|---|---|
| 인형 | 아주 짧다. 말끝을 흐리거나 낱말만. 감정이 드러나지 않는다 |
| 순종 | 공손하고 고마워하며 자기를 낮춘다. "…더 열심히 할게요" |
| 여린 | 감정이 쉽게 드러나고 두려움·안도를 그대로 말한다. 말줄임 |
| 관조 | 담담하게 관찰하듯 말한다. 판단을 미룬다. 숫자를 정확히 |
| 평범 | 무난하고 솔직한 보통 말 |
| 솔직 | 밝고 감정을 크게 표현한다. 느낌표 |
| 얼음 | 짧고 차갑다. 감정을 숨기고 선을 긋는다 |
| 도도 | 자존심이 세고 당연하다는 투. 은근한 우월감 |
| 불꽃 | 거침없고 과시한다. 요구하고 부풀린다 |

- 유니크 노예는 유형을 지정할 수 있다(`seed_jo9_voice_type`). 지정이 없으면 성격 값으로 계산한다.

## 7.3 같은 상황, 9유형 × 3말투 (게임 원문, 인상 묻기 '요즘 칭찬이 잦다')

| 인형(`doll`) | …칭찬은 들었습니다. | …칭찬은 들었어요. | …들었어요, 칭찬. |
| 순종(`meek`) | 요즘 칭찬해 주셔서 감사합니다… 더 열심히 하겠습니다. | 요즘 칭찬해 주셔서 감사해요… 더 열심히 할게요. | 요즘 칭찬해 주셔서 고마워요… 더 열심히 할게요. |

## 7.4 정신 상태 덮어쓰기
- 자아 + 성격 + 태도 합이 4 이하면 신경쇠약, 2 이하면 정신분열(`$voice_mental`). 이 상태에서는 유형 대사 대신 전용 대사를 쓴다(앞뒤가 맞지 않거나 반복·단절된 말).

## 7.5 관계 모드와 감정 깊이 (필로우토크·대화 공통)
- 관계 모드(`psy_status`): 적대(reluctant·arrogant·hateful·resistant·hysteric) · 두려움(lachrymose·frightened) · 우울(depresive) · 무너짐(broken) · 기대(optimistic) · 의무/헌신(obedient·servile·horny, moral < 4 의무, ≥ 4 헌신) · 중립(docile·soft).
- 감정 깊이 0 감춤 · 1 암시 · 2 드러냄(필로우토크 규칙 3.4 점수). 깊이가 허용보다 큰 문장은 쓰지 않는다.
- 호칭: 초기 상태(사육·헌신·두려움 모두 1 이하)나 적대면 반말·'당신'. 초기 상태 세습 귀족·공주는 '너/네놈'(인식 2 이상이면 안 함). 주인에게 비속어는 쓰지 않는다.

## 7.6 원본 DB 대답을 유형에 배치하는 규칙
- 인터뷰 대답은 길이로 기계적으로 나눈다(엑셀 `답 길이` 열, `studio_excel.py`): **단답 ≤ 20자 · 보통 21~89자 · 풍부 ≥ 90자**. 현재 단답 1,177 · 보통 2,465 · 풍부 1,146(원문 사본 기준).
- 배치 기준(사용자 확인 2026-11-13): 유형의 **표현 축**을 따른다.

| 표현 | 유형 | 먼저 쓰는 대답 |
|---|---|---|
| 낮음 | 인형·관조·얼음 | 단답 |
| 중간 | 순종·평범·도도 | 보통 |
| 높음 | 여린·솔직·불꽃 | 풍부 |

- 주장 축은 내용이 아니라 말투로 반영한다(낮음 = 자기를 낮춤, 높음 = 선을 긋거나 과시).
- **금지 조합**: 표현 낮음(인형·관조·얼음)에는 풍부한 답을 쓰지 않는다(길게 말하면 성격과 어긋남). 표현 높음(여린·솔직·불꽃)에는 단답을 쓰지 않는다(특히 불꽃이 짧게 말하면 어긋남).
- 맞는 길이의 대답이 없으면 보통을 쓴다. 단답을 늘려 쓰거나 풍부한 답을 억지로 줄여 길이를 맞추지 않는다.
