## 4. 말할 내용의 순서
1. **거절 판정**: 관계가 적대이고 적대 깊이가 0이면 거절 한마디만 하고 끝낸다.
2. **횟수 한마디(필수 1개)**
   - 경험 0 → `none`
   - 유부녀 묶음(인형 제외) → `countMarried` (남편 한 사람 기준)
   - 말한 횟수 50 이상이고 그 유형의 `countHigh` 후보가 있으면 → `countHigh`
   - 그 밖 → `count`
3. **화제(최대 2개)**: 경험 0, 인형 유형, 무너짐 모드에서는 붙이지 않는다.
   - 1순위: 유부녀 → `married`, 출산 1회 이상이면 `birth` / 접객업 → `sexWork`
   - 2순위(하나만): 성욕 특성이 있으면 `libido<값>` → 동성 상대가 1/3 이상이면 `sameSex` → 구강이 질보다 많고 애널 이상이면 `oral` → 애널이 가장 많으면 `anal`
4. 이어 붙이기와 페이지 나누기는 게임 `$voice_flow_pack`(230자 경계, 문장 가운데서 자르지 않음)을 쓴다.

| 유형 | 말한 횟수 (실제 × 배율/100) | 표현 |
|---|---|---|

| 도도 | 150 | 어림말 |

## 7. 후보 고르기
1. 역할 일치 → 관계 허용 → 깊이 허용 행만 남긴다.
2. 유형 전용 행을 먼저, 공통 행을 나중에 찾는다.
3. 반복 회피: 최근 2회 → 직전 1회 → 반복 허용 순서. 조건을 완화해서 다양성을 만들지 않는다.
4. 남은 풀에서 `rand`로 하나를 고른다. 후보가 없으면 그 한마디는 생략한다(횟수 한마디는 공통 행이 있어야 한다).
5. 이력 키는 게임 규칙과 같은 형식: `jo9_voice_last1_<질문번호>`, `jo9_voice_last2_<질문번호>`.

### 10.2 필로우토크 보완 제안 (우선순위)
1. **겉말과 속말**: 대사 뒤에 속마음 지문을 붙인다. 불꽃·도도가 부풀렸거나 여린·순종이 줄였을 때, 속말로 실제 숫자를 흘린다. 예: 겉말 "백 번은 넘는다니까요!", 속말 "실제로는 서른 번 남짓이다." 유형별 과장이 플레이어에게 '거짓말'로 읽히게 하는 가장 값싼 장치다. 조각 역할 `inner` 추가.
2. **대답 종류와 결과**: 횟수 한마디를 대답 종류(자랑·담담·수줍은 고백·숨김·거절)로 나누고, 종류마다 결과를 붙인다(예: 고백 → 기분 +1, 거절 → 변화 없음). 결과를 실제 수치에 반영할지는 사용자 결정. 반영하지 않으면 지금 게임 조립 규칙(수치 불변)과 같다.
3. **숨긴 이야기와 점진 공개**: 깊이가 모자라 말하지 못한 화제를 '숨긴 이야기'로 남긴다. 같은 질문을 다시 할 때 관계·깊이가 올랐으면 그 이야기를 꺼낸다. 이미 말한 화제는 일정 일수 동안 다시 고르지 않는다(항목별 대기). 횟수는 기존 `already_done_total[질문번호]`, 화제별 기록은 이력 키 확장.
4. **지금과 잇기**: 관계 직후라는 상황을 쓴다. 오늘 주인과의 관계(`already_sex_today`)·절정 무드렛·주인과의 누적(`already_sex_total`)과 과거를 비교하는 화제를 둔다. 시간 표현은 기존 기억 층(오늘·요즘·평생)으로 정한다.
5. **몸 상태 머리말**: 관계 직후 몸 상태(기력, 흥분, 통증 무드렛)로 첫 지문을 고른다. Wayward 아침 상태의 축소판.
6. **숨은 성향 발견**: 깊이 2 고백(정액 중독·애널 중독 등)이 나오면 해당 `*_revealed`를 켠다.
7. **거래 경력의 갈등**: 접객업·노예 출신에 대해, 기존 `angst`와 `moral`의 차이를 정체성 갈등의 근사로 써서 담담/자기혐오/개의치 않음 갈래를 나눈다. 새 변수는 만들지 않는다.
8. **반복 방지 강화**: 최근 2회 회피에 더해, 조각마다 재사용 대기 일수를 둔다(편집기 튜닝 항목).
