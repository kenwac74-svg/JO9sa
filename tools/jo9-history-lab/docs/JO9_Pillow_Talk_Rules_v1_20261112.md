# 필로우토크 조립 규칙 v1 (2026-11-12)

## 0. 범위와 역할 분담
- 이 문서는 **규칙**이다. 대사 원고 전체를 만들지 않는다(사용자 결정 2026-11-12).
- 수치와 원고는 **프리셋 초안**이다. 최종 튜닝은 사용자가 노예 통계 편집기에서 한다.
- 유니크 노예의 과거 경험 값과 말하기 유형은 사용자가 지정한다.
- 게임 대사 조립 규칙(`SLAVE_DIALOGUE_ASSEMBLY_RULES_CURRENT_20261112_KO.md`)과 같은 축을 쓴다: 성격 9유형, 말투 번호, 관계 모드, 감정 깊이, 메타데이터 조각 행, 반복 회피.
- 시제품 구현: `dist/pillow-talk.mjs`. 예시 조각 62행은 규칙을 시험하기 위한 프리셋 초안이다.

## 3. 판정 규칙
### 3.1 말하기 유형
- 지정 유형이 있으면 그것을 쓴다.
- 없으면 E = temper + sensitivity, A = ego + pride로 9유형을 정한다(0~3 낮음, 4~6 중간, 7 이상 높음). 게임 `$voice_profile`과 같다.

### 3.2 말투
- 1 격식 존댓말: maid, valertry, secretary, nun, policewoman, mind_contol, time_plice, jailer, academy, mech
- 2 일반 존댓말: 그 밖
- 3 반말: 사용자가 지정한 유니크 8명(3002·2610·2620·3010·3021·3023·2621·3012)만. 일반 노예에는 쓰지 않는다. 게임에서 말투3을 고르는 직업도 필로우토크에서는 2로 둔다.

### 3.3 관계 모드 (`psy_status`)
| 모드 | 상태 |
|---|---|
| 적대 | reluctant, arrogant, hateful, resistant, hysteric |
| 두려움 | lachrymose, frightened |
| 우울 | depresive |
| 무너짐 | broken |
| 기대 | optimistic |
| 의무 / 헌신 | obedient, servile, horny (moral < 4 의무, ≥ 4 헌신) |
| 중립 | 그 밖(docile, soft) |

### 3.4 감정 깊이 (0 감춤, 1 암시, 2 드러냄)
| 감정 | 점수 |
|---|---|
| 취약 | 2·moral − pride − 2·(fear ≥ 4) |
| 적대 | ego + temper − 2·fear |
| 긍정 | 2·moral + sensitivity − pride |
점수 4 미만 0, 8 미만 1, 그 이상 2. 원고 깊이가 허용 깊이보다 크면 후보에서 뺀다.

## 4. 말할 내용의 순서
1. **거절 판정**: 관계가 적대이고 적대 깊이가 0이면 거절 한마디만 하고 끝낸다.
2. **횟수 한마디(필수 1개)**
   - 경험 0 → `none`
   - 유부녀 묶음(인형 제외) → `countMarried` (남편 한 사람 기준)
   - 말한 횟수 50 이상이고 그 유형의 `countHigh` 후보가 있으면 → `countHigh`
   - 그 밖 → `count`
3. **화제(최대 2개)**: 경험 0, 인형 유형, 무너짐 모드에서는 붙이지 않는다.
   - 1순위: 유부녀 → `married`, 출산 1회 이상이면 `birth` / 접객업 → `sexWork`
   - 2순위(하나만): 성욕 특성이 있으면 `libido<값>` → 동성 상대가 1/3 이상이면 `sameSex` → 구강이 질보다 많고 애널 이상이면 `oral` → 애널이 가장 많으면 `anal`
4. 이어 붙이기와 페이지 나누기는 게임 `$voice_flow_pack`(230자 경계, 문장 가운데서 자르지 않음)을 쓴다.

## 5. 횟수 말하기
| 유형 | 말한 횟수 (실제 × 배율/100) | 표현 |
|---|---|---|
| 불꽃 | 300 | 어림말, 과시 |
| 도도 | 150 | 어림말 |
| 솔직·평범 | 100 | 어림말 |
| 관조·얼음 | 100 | 정확한 숫자 `{X}` |
| 순종 | 70 | 어림말, 줄여 말함 |
| 여린 | 50 | 어림말, 줄여 말함 |
| 인형 | 100 | 어림말, 아주 짧게 |
- 경험이 1 이상이면 말한 횟수는 최소 1.
- 어림말 `{N}`: 1~3 한·두·세 번 / 4~9 몇 번 / 10~19 열댓 번 / 20~29 스무 번 / 30~39 서른 번 / 40~69 쉰 번 / 70~149 백 번 / 150~999 수백 번 / 1000 이상 천 번. '쯤·정도'는 원고가 붙인다.
- 배율과 경계는 프리셋 초안이다. 편집기에서 튜닝한다.

## 6. 조각 행 형식
| 칸 | 값 |
|---|---|
| 역할 | refuse, count, countHigh, countMarried, none, married, birth, sexWork, sameSex, oral, anal, libido2, libido1, libido-1, libido-2 |
| 유형 | `*`(공통) 또는 유형 키 목록 |
| 관계 | `*` 또는 모드 목록 |
| 감정 | `-`(제한 없음), vulnerable, hostile, positive |
| 깊이 | 0~2 |
| 문장 | 말투별 원고(1·2, 지정 유니크용 3) |
| 자리표시 | `{N}` 어림말, `{X}` 정확한 숫자, `{C}` 아이 수, `{이나}` 조사(아이 2명 이상일 때만, 받침에 따라 이나/나) |

- 원고 문체: 비속어와 노골적 표현을 쓴다. 일반 노예는 존댓말을 유지하고, 거친 성격은 비꼬는 존대로 표현한다.
- 각 역할마다 최소한 공통(`*`) 행 하나, 관계 `*` 행 하나가 있어야 후보가 비지 않는다.

## 7. 후보 고르기
1. 역할 일치 → 관계 허용 → 깊이 허용 행만 남긴다.
2. 유형 전용 행을 먼저, 공통 행을 나중에 찾는다.
3. 반복 회피: 최근 2회 → 직전 1회 → 반복 허용 순서. 조건을 완화해서 다양성을 만들지 않는다.
4. 남은 풀에서 `rand`로 하나를 고른다. 후보가 없으면 그 한마디는 생략한다(횟수 한마디는 공통 행이 있어야 한다).
5. 이력 키는 게임 규칙과 같은 형식: `jo9_voice_last1_<질문번호>`, `jo9_voice_last2_<질문번호>`.

## 8. 게임 적용 지점 (통계 구현 때)
1. 과거 경험 값 저장: `stock_to_slave_nogt` 94행 뒤(랜덤), 유니크는 지정값.
2. 질문 번호: "노예와 대화한다"에 새 번호(예: 1119)를 둔다. 기존 1111~1118과 같은 진입·캐시 확인 경로.
3. 원고: `#txt_man`의 `$voice_fragment_text` 행과 같은 메타데이터 형식으로 넣고 `$voice_pick_fragment`를 재사용한다.
4. 검증: 실제 엔진(QSP WASM)으로 여러 노예·관계 상태에서 뽑아 규칙대로 거르는지 확인한다.
