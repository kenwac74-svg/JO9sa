# JoNT 장면 프롬프트 통합

통합 모드툴의 **이미지 작업 → 장면 프롬프트**에서 연다. 기존 이미지 체크리스트·이미지 교체·편집·폴더 비교 탭은 유지한다. 통합 창에서는 공통 회색·금색 스타일을 적용하고 중복 제목을 숨긴다.

## 사용

1. 처음에는 **폴더 선택**으로 원본 이미지 폴더를 고른다.
2. 원본 식별자와 대상 식별자를 확인하고 **설정 적용·작업표 열기**를 누른다. 식별자는 번호 또는 이름을 사용할 수 있다. 파일명에 사용할 수 없는 문자는 거절한다.
3. 기존 해석 결과가 있으면 원본 도구의 장면·샘플 작업표가 열린다. 결과가 없는 새 폴더는 원본 도구의 `describe` 명령으로 먼저 해석한다. 통합 화면을 여는 것만으로 해석이나 생성 API를 호출하지 않는다.
4. CLI에서 결과나 모델을 변경했다면 **작업표 다시 읽기**를 누른다. 로컬 작업표 서버를 다시 열어 결과를 읽는다.

해석·모델 선택·내보내기 등 원본 CLI 명령과 상세 설정은 [원본 사용법](README.md)을 따른다. 이 통합은 별도의 폴더 일괄 해석 버튼이나 API 키 입력 화면을 추가하지 않는다. 원본 작업표의 프롬프트 편집·복사·의상 교체·샘플 라이브러리 기능과 API는 원본 소스를 그대로 사용한다.

## 실행과 저장

- 통합 실행: `tools/local-workspace/Open-Modding-Tools.ps1`. 기존 전용 앱 창 실행 방식도 지원한다.
- 단독 실행: 이 폴더의 `Start-Jont-Remake.ps1`이 출력한 주소를 연다. 포트가 사용 중이면 다음 빈 포트를 선택한다. 정상 실행 중이면 기존 서버를 재사용한다.
- `config.json`: 원본 폴더·대상·모델 등 프로젝트 설정. 기존 비공개 API 설정과 추가 항목은 보존한다. 브라우저 설정 API에는 키를 내보내지 않는다.
- `work/<원본>_to_<대상>/`: 원본 도구의 해석 결과·내보내기·썸네일. `library.json`: 원본 도구의 공용 샘플 라이브러리. 편집과 복사 등 브라우저 저장 방식은 원본 작업표를 따른다.
- `runtime/`: 실행 주소·PID·로그. 위 사용자 자료와 함께 Git에서 제외한다. `config.json`의 키를 포함해 개인 설정을 배포하지 않는다.
- 새 설치에서는 예제의 실제 이미지 경로와 대상 번호를 자동 적용하지 않는다. 사용자가 폴더와 대상을 지정하기 전에는 원본 작업표 프로세스를 시작하지 않는다.

## 구현 범위

사용자가 제공한 ZIP의 `remake.mjs`, `worksheet.html`, `config.example.json`, `README.md`는 수정하지 않았다. `hub-server.mjs`는 로컬 설정·작업표 프록시·테마만 담당한다. `hub-client.js`는 폴더 선택과 프로젝트 적용·다시 읽기를 연결한다. 통합 메뉴는 `promptWorksheet` 주소를 다른 이미지 도구와 별도 프레임에 보존한다.

변경하지 않은 원본 API는 `/api/library`, `/api/extract`이며, 명시적으로 조작하면 원본 코드가 동작한다. 키는 서버 설정 또는 환경변수에서 읽는다. 이번 통합 검증에서는 외부 API와 실제 이미지 해석·생성을 실행하지 않았다.

연결을 제거하면 메뉴의 `promptWorksheet` 항목과 통합 실행기의 `JONT_REMAKE_HUB_20261115` 블록을 제거한다. 원본 도구·개인 설정·작업 결과는 별개로 남는다. 게임 QSP·캐릭터 JSON·세이브·이미지·배포물에는 연결 시 자동 변경을 가하지 않는다.

검증: 빈 이미지 폴더에서 설정 보존·비밀값 비노출·로컬 작업표·API 프록시·다시 읽기, JS/PowerShell 구문, 기존 서버 재사용, 통합 화면 표시를 확인했다. 실제 해석·샘플 추출·생성의 서비스 동작은 확인 범위 밖이다.
