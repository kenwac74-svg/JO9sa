REVIEW & APPLY

비교·적용

변경 0개

미리보기는 선택한 설치본의 최신 원본과 변경 위치를 검사합니다. 검사가 끝나면 적용할 수 있습니다.

적용할 설치본을 선택하고 변경 미리보기 또는 저장 캐시 갱신 후보를 실행하세요.

적용·복원 이력

복원은 적용 직후의 파일과 현재 파일이 일치하는 경우에만 진행됩니다.

복원의 범위와 저장 캐시

복원은 QSP 파일에 적용됩니다. 세이브의 인물 현재값·이력은 복원되지 않습니다.

변경 후 저장한 세이브의 표시·교육 XP 캐시는 현재 QSP를 기준으로 ‘저장 캐시 갱신 후보’를 만든 뒤 적용하고, 게임에서 다시 불러와 갱신하세요.

아직 적용 이력이 없습니다.
