참조 이미지 편집 기반의 시험 기능입니다. 서버 마스크 편집을 보장하지 않습니다. 원본이 있는 픽셀은 유지하고 지정한 사각형의 투명 부분에만 결과를 넣습니다.

서비스 정책을 준수하는 이미지에만 사용하세요. 차단되면 중지하며 다른 서비스로 자동 전환하지 않습니다.

API 배치 안전장치

예상 요금은 모델·입력·해상도에 따라 다릅니다. 고정 단가를 가정하지 않습니다. 제공된 실제 비용만 요청 이력에 표시합니다.

HTML 단독: 파일 추가, 규격 조정, 합성, PNG/ZIP 저장 가능.
API 모드: 압축을 풀고 START_WINDOWS.bat 실행. Python 3.10 이상 필요. 추가 패키지는 없습니다.
작업 저장: 설정만 JSON에 저장됩니다. 원본은 다시 선택하고 AI 결과는 PNG/ZIP으로 별도 보관하세요.

원본은 그대로. 필요한 부분만.

1 / 파일 추가와 배치

PNG 파일 여러 개 또는 폴더를 선택합니다. 이미지가 이미 표준이면 그대로 승인하세요. 전신 이미지는 기준점 맞춤에서 정수리 중앙과 원하는 무릎 위 컷 위치를 차례로 찍습니다. 새 그림 없이 등비 확대·크롭합니다. 화면 드래그와 배율/X/Y로 미세 조정할 수 있습니다.

2 / 잘린 이미지의 확장

머리 크기 맞춤이나 배율로 크기를 정한 뒤 빈 하단이 생긴 파일만 AI 대상으로 체크합니다. 보완 사각형을 맞추고 1장을 시험하세요. 생성 후 원본 픽셀은 보호하고 사각형 안의 투명 픽셀만 채웁니다. 모델이 참조 구도를 바꾸면 이음새가 어긋날 수 있으므로 반드시 검수합니다.

3 / API 사용

HTML만 더블클릭하면 로컬 편집만 됩니다. AI는 ZIP을 풀고 START_WINDOWS.bat로 열어야 합니다. API 키는 여기에 입력하거나 환경변수로 설정하세요. 유료 생성 전 확인창이 뜹니다. 중지는 현재 생성의 과금을 취소하지 않으며 다음 파일부터 멈춥니다.

4 / 저장

결과를 확인해 승인한 후 ZIP으로 저장합니다. 원래 파일명은 유지하고 같은 이름은 __2를 붙여 충돌을 막습니다. manifest.json에 대응표가 들어갑니다. 게임 적용과 카탈로그 변경은 하지 않습니다. 새로고침 전 결과 PNG/ZIP과 작업 JSON을 저장하세요.

한계

자동 무릎 인식, 완전한 배경 분리, 모델의 원본 유지·정책 통과는 보장하지 않습니다. 캐릭터의 나이·신체를 판정하거나 바꾸지 않습니다. 이 버전은 로컬 편집과 승인형 AI 보완 도구입니다.

받은 AI 결과 구도 맞춤
