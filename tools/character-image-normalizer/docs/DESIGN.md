# JO9 이미지 규격 통일기 v1.0

사용자 확정: 795×596 PNG, 가로세로 비례 유지, 상단 여백 10~50px(초기값 24), 중심 x397.5,
하단은 무릎 위~무릎 부근 컷. 허용 사례는 그대로 둘 수 있다. 원본 덮어쓰기/게임 반영 금지.

구현 선택: 단독 HTML의 로컬 Canvas 편집 + Python 표준 라이브러리 localhost API 중계.
외부 CDN/폰트/분석 추적 없음. 작업 상태 JSON은 키와 원본이미지를 포함하지 않는다.
폴더/다중 선택, 원본/결과 비교, 이동/등비확대, 기준점 2회 클릭, 원본 보존, ZIP 출력.
자동 인체 검출은 하지 않는다. 알파 경계는 인체가 아닌 머리카락/무기/장식도 포함할 수 있다.
배경이 불투명하면 경계 검출은 배경 포함이며, 단색 가장자리 제거는 선택 기능이다.

API: OpenRouter /api/v1/images + input_references; Mage /v1/{route}/generate + image,
status_url polling. 공식 공개 스키마에서 마스크 지원은 확인되지 않음: 참조 기반 확장 시도이며
생성 결과를 로컬 마스크 영역에만 합성. 원본 비투명 픽셀은 그대로 보존. 마스크 밖 불변.
원본 알파가 없는 부분의 배경 생성 가능성, 연결 오차, 누드 정책, 실제 과금은 실키 검증 필요.
자동 서비스 전환/정책 우회/자동 유료 재시도 없음. 모든 AI 요청은 명시적 버튼과 확인 필요.

검증: 브라우저 로컬/서버 모드, 합성 픽셀 불변, 795×596 ZIP, 세션 저장/복원,
provider payload·폴링·실패·키 비저장·SSRF/Origin 차단을 모의 응답으로 검사.
