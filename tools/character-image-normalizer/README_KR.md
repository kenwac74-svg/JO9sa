# JO9 이미지 규격 통일기 v1.2.1

795×596 캐릭터 PNG의 크기·위치·하단 컷을 정렬하고, 필요한 파일에만 OpenRouter 또는 Mage.Space의 참조 이미지 편집을 요청하는 로컬 도구입니다.

## 2026-11-05 응답 비율 복구

1152×896처럼 요청과 비율이 다른 결과도 버리지 않고 원본 결과와 요청·사용량 정보를 메모리에 보존합니다. 자동으로 늘이거나 바로 적용하지 않습니다. **받은 결과 구도 맞춤 · 추가 생성 없음**에서 등비 배율·가로/세로 위치를 미리 보고 **이 구도로 사용**을 누르세요. 결과는 795×596이며 기존 얼굴·신체 픽셀은 보호됩니다. 취소하면 기존 적용 결과를 유지합니다. 비율 검수 대기 중인 파일은 추가 유료 제출을 막고 먼저 받은 결과를 확인하도록 안내합니다.

구버전 화면에서 실패한 경우, 먼저 **수신한 AI 원본 결과 저장**으로 받은 PNG를 보관하세요. 그다음 새로고침하여 **외부 생성 결과 불러오기**로 다시 불러오면 구도 맞춤 창을 사용할 수 있습니다. 이 과정에는 API 생성 요청이 없습니다. 저장한 PNG가 없다면 새로고침·탭 닫기로 메모리의 수신 결과가 사라집니다.

## 가장 먼저

- **규격 조정만:** `JO9_Normalizer.html`을 Chrome/Edge에서 엽니다. 서버·API 키·인터넷 없이 사용하도록 구성했습니다.
- **AI 보완까지:** ZIP을 폴더에 모두 풀고 `START_WINDOWS.bat`를 실행합니다. 브라우저에 `http://127.0.0.1:8766`이 열립니다.
- Python 3.10 이상이 필요하며 **추가 pip 설치는 없습니다**. Python이 없으면 시작 파일이 안내 후 종료합니다.
- ChatGPT 미리보기/내장 브라우저에서는 폴더 선택이 제한될 수 있습니다. 다운로드한 파일을 PC의 Chrome/Edge에서 여세요.
- 이 도구는 게임 파일을 배치하거나 카탈로그·Git을 수정하지 않습니다. 결과물은 채택 대기입니다.

## 사용 순서

### 1. 파일 불러오기
PNG 여러 개 또는 폴더를 선택합니다. JPEG/WebP도 읽지만 출력은 PNG입니다. 파일당 20MB, 1600만 픽셀, 한 작업 500개 제한이 있습니다. 메모리가 부족하면 30~100개 단위로 나누세요.
이미지가 이미 적절하면 변경하지 않고 승인할 수 있습니다. 사용자 원본이나 노출 이미지는 이 배포물에 포함하지 않았습니다. ‘도형 샘플’ 버튼으로 기능을 먼저 확인할 수 있습니다.

### 2. 규격 정렬
확정된 규격은 795×596, 투명 배경, 등비 확대, 중심 X=397.5, 머리 상단 10~50px, 무릎 위~무릎 부근 하단 컷입니다. 상단 목표 초기값은 24px입니다.

- **전신이 작게 들어간 이미지:** ‘기준점 맞춤: 정수리 → 하단 컷’을 누르고 커진 원본 창에서 정수리 중앙과 원하는 무릎 위 컷을 클릭합니다. 그 두 지점 사이를 목표 높이에 맞추고 아래쪽을 잘라냅니다. AI는 필요하지 않습니다.
- **허벅지/허리에서 이미 잘린 이미지:** 배율을 조절하거나 ‘머리 크기 맞춤: 정수리 → 턱’을 이용합니다. 머리 길이 142px은 도구의 조정용 초기값일 뿐 사용자가 확정한 규칙이 아닙니다. 규칙 탭에서 바꾸거나 표준 PNG를 겹쳐 비교하세요.
- **배치만 어긋난 이미지:** 마우스 드래그, 휠 확대, 배율/X/Y 숫자 입력으로 조정합니다. 알파가 있는 이미지는 ‘투명 여백 기준 정렬’도 사용할 수 있습니다.
- **여러 이미지:** 선택 체크박스 → 현재 수치 복사 또는 각 파일의 여백 정렬. 체형/포즈가 다르면 일괄 수치 복사만으로 맞지 않으므로 검수하세요.

폭과 높이를 따로 늘리는 기능은 없습니다. 자동 인체·무릎·성별·연령 검출도 없습니다. 알파 경계는 머리카락, 모자, 꼬리, 무기까지 포함하므로 신체 기준과 다를 수 있습니다.

### 3. API 설정과 AI 보완
`START_WINDOWS.bat`로 연 화면에서 AI 보완 탭을 사용합니다. API 키를 대화에 붙여넣지 말고 **도구의 키 입력란**에 입력하세요.

- **OpenRouter:** 서비스를 선택 → 키 입력 → ‘이미지 입력 지원 모델 목록 조회’ → 모델 ID 선택. 이 버전의 전송 비율은 4:3이므로 해당 비율 지원 여부도 확인하세요. 모델별 비용은 고정하지 않았습니다.
- **Mage.Space:** 모델 종류와 model_id 선택 → Mage 키 입력. Mango, Nano Banana 2, SDXL, SDXL Plus 어댑터가 포함됩니다. 기본값은 `mango-v3-turbo`입니다. SDXL 계열은 일반 img2img로 정밀 편집이 약할 수 있어 시험용으로 표시했습니다. 가격·허용 콘텐츠는 서비스 기준입니다.
- 키를 환경변수 `OPENROUTER_API_KEY`, `MAGE_API_KEY`로 제공해도 됩니다. 화면 입력을 비우면 환경변수를 사용합니다.

해당 파일을 ‘AI 보완 대상’으로 체크 → 빈 하단에 사각형 영역 맞춤 → **현재 1장 생성**으로 먼저 시험하세요. 한 번 확인된 후 ‘선택 대상 일괄’로 순차 처리합니다. 일괄은 선택됨 + AI 보완 체크 + 아직 AI 결과 없음인 파일만 실행합니다. 기본 최대 요청 수는 10개입니다.

**확실히 구분할 것:** 공개 문서에서 공통의 정밀 마스크 API를 확인하지 못했습니다. 이 버전은 원본에 여백을 넣어 참조 이미지 편집을 요청한 뒤, 지정 영역의 투명 픽셀에만 결과를 붙이는 방식입니다. 네이티브 인페인팅/아웃페인팅의 품질을 보장하는 구현은 아닙니다.

795×596과 공급자 비율 차이는 패딩으로 처리합니다.
- OpenRouter: 800×600(4:3), 원본 배치 오프셋 (2,2)
- Mage: 800×640(5:4), 원본 배치 오프셋 (2,22)
- 응답을 받으면 패딩 부분을 제거해 795×596 좌표로 합성합니다. 비율이 크게 다르면 합성하지 않습니다.

**원본 보호:** 크기·위치 조정을 마친 원본에서 알파가 0보다 큰 모든 픽셀은 유지합니다. AI 결과는 사각형 안이면서 원본 알파가 0인 픽셀에만 들어갑니다. 원본 변환 과정의 리샘플링은 별개입니다. 얼굴과 기존 신체를 AI 결과로 덮어쓰지 않지만, 새 부분과의 이음새나 비례가 어긋날 수 있습니다.

AI 입력의 투명 여백은 RGB(128,128,128) 회색 배경으로 임시 합성됩니다. 이를 **투명화 완료로 가정하지 않습니다.** 결과가 회색 배경이면 ‘생성 결과 검수·배경 → 제거’로 가장자리에 연결된 유사 색만 제거하세요. 이는 단색 제거일 뿐 고급 누끼가 아닙니다. 회색 옷·머리카락 손상이나 남은 테두리는 검수해야 합니다. 최종 합성에는 체크무늬, 가이드, 표준 겹침 이미지가 들어가지 않습니다.

실패하거나 비율이 틀린 결과도 수신했다면 ‘수신한 AI 원본 결과 저장’으로 보관할 수 있습니다. 배치를 멈추더라도 이미 제출한 요청이 취소/환불되는 것은 아닙니다. 현재 요청을 마친 뒤 다음 요청부터 중지합니다. 실패 시 전체 배치를 중단하며 **자동 유료 재시도, 공급자 자동 전환, 필터 우회는 하지 않습니다.** 타임아웃 뒤에는 공급자 생성 기록을 확인하고 재시도하세요.

### 4. 승인과 저장
- 한 장 확인 → ‘현재 이미지 승인’ → 선택 이미지 ZIP 저장.
- ZIP 안에 원래 파일명의 795×596 PNG, `manifest.json` 대응표, `jo9_project.json` 설정이 들어갑니다.
- 파일명이 겹치면 `__2`, `__3`으로 구별합니다. 하위 폴더 구조는 그대로 재생성하지 않으며 원래 상대 경로는 대응표에 남깁니다.
- ‘작업 설정 저장’ JSON에는 이미지/키가 들어가지 않습니다. 다음에 원본을 다시 선택한 뒤 설정을 복원하세요. 파일명·경로·크기·수정시각으로 대응합니다.
- AI 결과와 배경 제거 결과는 JSON에 포함되지 않습니다. 반드시 PNG/ZIP을 별도로 저장하세요. 해당 파일의 승인은 설정 복원 시 해제됩니다.
- 새로고침·탭 닫기는 메모리의 이미지/키/작업을 지웁니다. 떠나기 경고가 있지만 먼저 저장하세요.

## 보안과 비용

원본 읽기·정렬·단색 제거·PNG/ZIP 생성은 브라우저 내부에서 처리합니다. API 생성 버튼을 누르고 확인창을 승인한 파일만 선택한 외부 서비스로 전송합니다. 모델 목록 조회는 이미지 전송이나 생성이 아닙니다.

중계 서버는 127.0.0.1에만 바인딩하고 출처·Host·세션 토큰을 확인합니다. 고정된 공식 API 주소만 이용하며 임의 프록시 기능이 없습니다. 외부 스크립트/CDN/폰트/텔레메트리를 사용하지 않습니다. 키를 LocalStorage, 프로젝트 JSON, ZIP, 서버 로그에 기록하지 않습니다. 단, 실행 중인 브라우저/프로세스의 메모리에는 존재합니다. 공용 PC에서 사용하지 마세요.

제공업체에 전송된 이미지의 보관/과금/허용 정책은 별도입니다. 성인 누드 등 모든 자료의 API 허용 여부와 성공률은 실제 계정 시험 전에는 보장하지 않습니다. 특히 거절된 요청도 비용이 발생할 수 있으므로 대표 1장부터 확인하세요. 8,000 Gems를 자동 예산으로 가정하지 않았습니다. 화면 이력과 manifest에는 응답에 제공된 실제 사용량만 기록합니다.

## 문제 해결

- **API 버튼이 서버를 요구함:** HTML 더블클릭이 아니라 START_WINDOWS.bat로 실행합니다.
- **포트 사용 중:** 터미널에서 `python server.py --port 8767`로 실행합니다.
- **창을 닫았더니 연결 끊김:** 서버 터미널은 사용 중 열어 둡니다.
- **이미지가 너무 작음:** 정수리→하단 컷을 찍거나 배율을 올립니다. ‘여백 정렬’은 배율을 자동 결정하지 않습니다.
- **흰색 배경:** 원본 알파가 없으면 흰색도 이미지입니다. 단색 제거 또는 별도 배경 제거 후 사용합니다.
- **모델 오류:** 실제 이미지 입력·비율 지원, 모델 ID, 키, 계정 잔액을 확인하세요. 이 도구는 서비스 정책을 변경할 수 없습니다.
- **들어맞는 기준점을 찍기 어려움:** 커진 원본 창을 이용하고 표준 PNG 겹쳐보기와 수치 조정으로 보완하세요. 자동 판정으로 억지 수정하지 않습니다.

## 검증 범위

구현 환경에서 JavaScript 핵심 검사 12개, Python/HTTP 검사 20개, Chromium UI/ZIP/PNG/모의 API 흐름 검사를 수행했습니다. 개인 키를 사용하거나 유료 생성하지 않았습니다. 실제 OpenRouter/Mage 생성 성공·출력 품질·누드 정책 통과·Windows 실행은 검증하지 않았습니다.

테스트 환경의 관리형 Chromium은 file://와 localhost 탐색이 차단되어 HTML을 메모리에 주입해 UI를 검사했습니다. 실제 로컬 서버의 HTTP/Host/Origin/토큰 검사는 Python HTTP 클라이언트로 별도 수행했습니다. 브라우저 정책을 변경하거나 우회하지 않았습니다.

## 소스와 다시 빌드

- `JO9_Normalizer.html`: 단독 실행 파일
- `server.py`: Python 표준 라이브러리 중계
- `src/`: 읽기 쉬운 HTML/CSS/JS 원본
- `build.py`: 소스를 단독 HTML로 묶기
- `tests/`: 모의 응답/브라우저 검사. 사용자가 실행할 필요는 없으며 개발용 Playwright/Pillow는 테스트에만 필요합니다.
