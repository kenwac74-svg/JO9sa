잭 오 나인 테일즈 2.4.1 3차 누적 패치 — 2026-11-07

기존 2.4.1 본편용입니다. 1차·2차 패치가 없어도 이 ZIP 하나면 됩니다.
먼저 게임과 WORKSHOP을 닫고 ZIP 전체를 게임 폴더 밖에 풉니다.

[자동 적용]
1. 압축을 푼 폴더에서 INSTALL.cmd를 실행합니다.
2. Jack-o-nine-tails.exe가 있는 기존 2.4.1 폴더를 선택합니다.
3. 완료 후 평소 실행하던 게임 EXE로 실행합니다.

[수동 적용]
1. 개인 수정 JSON이나 game/json/save_config.json이 있으면 따로 보관합니다.
2. 기존 게임에서 game/json 폴더만 지웁니다. game 전체나 save 폴더는 지우지 마세요.
3. 압축에서 나온 game 폴더를 기존 게임 폴더에 합쳐 동일 파일을 덮어씁니다.
4. 보관한 save_config.json이 있다면 돌려놓고 기존 게임 EXE로 실행합니다.

전체 JSON을 교체해야 이름이 바뀐 구형 인물 파일이 남지 않습니다.
자동 적용은 기존 save_config.json을 보존합니다. 세이브와 게임 EXE는 교체하지 않습니다.
기존 WORKSHOP 복구 파일을 포함합니다. WORKSHOP 설정을 직접 바꿨다면 적용 전에 보관하세요.
