Jack-o-nine-tails 2.4.1 — Cumulative Update 3 — 2026-11-07

For the existing 2.4.1 full game. This ZIP includes the previous updates.
Close the game and WORKSHOP, then extract the ZIP outside the game folder.

[Automatic]
1. Run INSTALL.cmd from the extracted patch folder.
2. Select your 2.4.1 folder containing Jack-o-nine-tails.exe.
3. When the process finishes, launch the game as usual.

[Manual]
1. Set aside any personal JSON edits and your game/json/save_config.json, if present.
2. Delete only the existing game/json directory. Keep game and the save directory.
3. Merge the extracted game directory into your game installation and overwrite matching files.
4. Restore your save_config.json, if applicable, and launch the existing game EXE.

Replace the complete JSON directory to avoid leaving old, renamed character definitions behind.
Automatic installation preserves the existing save_config.json. Saves and the game EXE are not replaced.
The previous WORKSHOP repair is included. Keep a copy of any customized WORKSHOP settings before applying it.
