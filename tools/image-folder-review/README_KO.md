# 이미지 폴더 비교·선택

폴더를 두 개 등록하고 번호가 이어지는 이미지들을 한 그룹으로 비교합니다. 원본·비교본 중 무엇을 남길지 선택하는 독립 도구입니다.

## 실행

`Open-Image-Folder-Review.cmd`를 더블클릭합니다. 로컬 서버가 시작되고 브라우저가 열립니다. 같은 저장 폴더의 서버가 실행 중이면 다시 사용합니다. 기본 주소는 `http://127.0.0.1:11332/`이며 포트가 사용 중이면 빈 포트로 시작합니다.

Python 3.12 이상과 Pillow가 필요합니다. 이 PC에서는 이미 설치된 Codex Python을 사용합니다. 다른 PC는 Python과 Pillow를 설치한 뒤 아래 실행 옵션으로 Python을 지정할 수 있습니다.

```powershell
.\Start-Image-Folder-Review.ps1 -PythonPath 'C:\Python312\python.exe' -DataDir 'D:\ImageReviewData'
```

## 사용 순서

1. 원본 폴더와 비교 폴더의 **폴더 선택** 버튼을 누릅니다. 경로를 직접 입력해도 됩니다.
2. 폴더쌍의 이름을 적고 **폴더쌍 등록 · 검사**를 누릅니다. 하위폴더의 이미지도 검사합니다.
3. 파일 목록이 만들어지면 썸네일이 자동 생성됩니다. 화면에 보이는 이미지부터 준비하며 다음 실행에는 저장된 썸네일을 재사용합니다.
4. 각 번호의 **원본 유지 / 비교본 유지 / 보류** 중 하나를 체크합니다. 선택은 즉시 저장됩니다. 현재 선택을 다시 누르면 미검토로 되돌릴 수 있습니다.
5. 그룹 상단에서 전체를 선택할 수 있습니다. 이후 특정 파일만 다른 선택으로 바꾸면 **혼합 선택**이 됩니다. 선택한 쪽의 파일이 없는 행은 건너뛰며 기존 선택을 유지합니다.
   큰 그룹은 처음 20개씩 표시하고 **더 보기**로 이어서 엽니다. 그룹 전체 선택은 아직 펼치지 않은 파일까지 적용됩니다.
6. 썸네일을 누르면 좌우 원본 이미지를 확대합니다. **화면 맞춤**, **100% 보기**, 확대창의 선택 컨트롤을 사용할 수 있습니다.
7. **JSON 내보내기 / CSV 내보내기**로 선택 목록을 저장할 수 있습니다. 현재 버전은 선택 기록을 내보내며 이미지 파일의 복사·덮어쓰기·삭제는 실행하지 않습니다.

등록한 폴더쌍은 상단 목록에서 다시 엽니다. 선택은 폴더쌍별로 분리되며 원본과 비교 폴더를 반대로 등록하면 별도 프로젝트가 됩니다.

## 번호 그룹 규칙

- `dt_pink_short_milf_3.png`, `_4.png`, `_10.png`는 같은 그룹에서 3 → 4 → 10 순서로 보입니다.
- 확장자가 생략된 실제 이미지 파일도 파일 헤더로 인식합니다. 예를 들어 확장자 없는 `dt_pink_short_milf_3`도 같은 그룹에 포함할 수 있습니다.
- `1092_bath_2.png`의 앞 ID는 유지하고 끝 `_2`만 번호로 봅니다.
- 번호 없는 기본 파일, `_1`, `_2`, `_02`, Windows 복사본 ` (2)`는 각기 다른 항목입니다. 한 그룹 안에서 볼 수 있지만 임의로 같은 파일로 합치지 않습니다.
- 상대 하위폴더가 다르면 동명 파일도 다른 그룹입니다. 양쪽 폴더의 대응 경로를 기준으로 비교합니다.
- 정확한 파일명이 같으면 우선 대응합니다. 확장자만 다른 경우에는 남은 후보가 양쪽에 한 개씩일 때만 짝짓습니다. 후보가 여럿이면 각각 보존합니다.
- 한쪽에 없는 파일도 표시합니다. JPG/PNG/WebP/GIF/BMP/TIFF 등 지원 이미지를 검사하며 GIF 등의 썸네일은 대표 첫 프레임입니다. TIFF 확대는 원본을 수정하지 않고 같은 크기의 PNG로 변환해 보여줍니다.
- 링크·연결 폴더를 따라가지 않습니다. 읽지 못한 파일·건너뛴 경로는 **검사 알림**에서 확인합니다. 이미지가 아닌 일반 파일은 검사 대상에서 제외됩니다.

## 폴더 내용이 바뀌었을 때

**폴더 다시 검사**를 누릅니다. 바뀌지 않은 대조 쌍의 선택은 유지됩니다. 새 이미지는 미검토이며, 판단했던 파일의 바이트가 바뀌거나 대조 상대가 바뀌면 **재검토 필요**로 표시됩니다. 같은 크기·수정시각을 유지한 변경도 검토한 파일의 해시로 확인합니다. 이전 선택은 이력에 남으며 JSON에 포함됩니다.

재검사 시 썸네일도 백그라운드에서 다시 확인합니다. 파일 수가 많으면 전체 썸네일 확인에 시간이 걸립니다. **저장 실패**가 표시되면 저장 완료로 간주하지 말고 오류 안내를 확인하세요. 접근 권한 문제나 검사 실패 시 마지막 정상 목록과 선택은 유지됩니다.

화면에 표시한 썸네일과 실제 파일의 해시가 다르면 선택 저장을 거부하고 재검사를 안내합니다. 이미지가 바뀌었는데 크기와 수정시각이 같아도, 이전 이미지를 보고 새 파일을 승인하는 일을 막습니다.

## 존재 여부·해시 필터 (1.1.0)

목록 상단에서 다음 조건별로 **전체 표시 / 골라보기 / 숨기기**를 선택합니다.

- 원본 X · 비교본 O
- 원본 O · 비교본 X
- 동일 파일명 · 해시 불일치
- 동일 파일명 · 해시 일치

여러 필터와 검색·검토 상태는 모두 함께 적용합니다. 조건이 서로 모순되면 결과가 없습니다. **필터 초기화**로 검색과 필터를 모두 해제할 수 있습니다. 그룹 안에서도 조건에 맞는 항목만 표시하며, 그룹 선택은 필터에 맞는 항목에만 적용됩니다. 숨긴 파일이나 선택 기록을 삭제하지 않습니다.

해시는 양쪽에 파일이 있고 파일명이 대소문자·확장자까지 같은 경우에만 비교합니다. 불일치한 두 파일명은 노란색과 '해시 불일치' 표시로 구분합니다. SHA-256은 기존 백그라운드 썸네일 작업 결과를 재사용하므로 필터를 바꿀 때 파일 전체를 다시 읽지 않습니다. 확인 중/읽기 오류는 일치·불일치로 판정하지 않으며, 확인이 끝나면 목록이 자동 갱신됩니다. '숨기기'에서는 아직 판정되지 않은 파일을 그대로 둡니다. 외부에서 파일을 바꿨다면 **폴더 다시 검사**로 해시와 썸네일을 갱신하세요.

## 저장 위치와 구조

기본 데이터 위치는 `G:\somi\IMGMG\folder-review`입니다. 실행기의 `-DataDir` 또는 Python 실행의 `--data-dir`로 바꿀 수 있습니다. 이 폴더는 원본·비교 폴더 밖에 두어야 합니다.

- `projects/*.json`: 폴더쌍·검사 목록·선택·해시·이력. 삭제하면 해당 선택 기록을 잃습니다.
- `thumbnails/`: 자동 생성한 축소 이미지와 메타데이터. 서버 종료 후 캐시만 삭제하면 다음 실행에 다시 생성합니다.
- `server.json`, `*.lock`, `server.*.log`: 실행 주소·프로세스·동시 실행 제어·오류 기록. 서버 실행 중에는 변경하지 마세요.

서버는 이 PC의 `127.0.0.1`에만 연결됩니다. 외부 업로드가 없으며 게임 실행·QSP·기존 이미지 카탈로그를 변경하지 않습니다. 브라우저 탭을 닫아도 서버는 실행 상태를 유지합니다.

## 소스 모듈과 유지보수

- `catalog.py`: `scan_pair(original, comparison)`가 읽기 전용 목록을 만들고 `build_groups`가 번호별 그룹과 좌우 대응을 반환합니다. 번호 규칙을 바꾸면 기존 대조 쌍이 바뀔 수 있으므로 재검사·선택 이력을 함께 검증해야 합니다.
- `project_store.py`: `ProjectStore`가 등록·선택·재검사·내보내기를 담당합니다. `set_decision`의 입력은 행 ID 목록과 `original/comparison/defer/null`, 반환값은 적용·건너뜀 개수입니다. 파일 해시를 읽고 상태 JSON만 씁니다. 이 모듈을 제거하면 선택 복원·재검토·내보내기가 작동하지 않습니다.
- `thumbnails.py`: `ThumbnailCache`가 최대 두 작업 스레드에서 EXIF 회전·비율·투명도를 반영한 WebP를 만듭니다. 원본 이미지는 읽기만 합니다. 캐시만 지워도 선택 기록은 유지됩니다.
- `server.py`: 웹 API와 등록된 이미지의 읽기 전용 전달을 담당하며, 위 모듈을 호출합니다. 파일 접근 직전에 등록 경로와 링크 여부를 다시 확인합니다.
- `picker.py`: Windows 폴더 선택창을 별도 프로세스로 열고 선택/취소를 반환합니다. 이 기능이 안 되는 환경에서도 경로를 직접 입력할 수 있습니다.
- `launcher.py`, 실행기: 실행 중인 도구의 종류·버전·저장 경로를 확인해 재사용합니다. 확인되지 않은 다른 서버를 종료하거나 재사용하지 않습니다.
- `static/`: 한국어 화면. API를 통해 선택을 저장하므로 HTML만 따로 열어서는 동작하지 않습니다.

## 검증

격리된 테스트 폴더에서 다음 명령으로 검사합니다. Python 단위·API 검사는 번호 충돌, 누락, 이미지 변경, 저장 실패, 폴더 선택 취소, 경로 이탈, 서버 재사용을 포함합니다. 브라우저 검사는 폴더 등록, 그룹/개별 선택, 재시작 복원, 확대, 내보내기, 재검토, 좁은 화면을 확인합니다.

```powershell
python -m unittest discover -s tests -v
node tests/browser-smoke.cjs
```

브라우저 검사에는 Playwright와 Microsoft Edge가 필요하며 `JO9_PLAYWRIGHT`, `JO9_BROWSER`, `JO9_PYTHON`, `JO9_BROWSER_OUTPUT`으로 경로를 지정할 수 있습니다. 서버·썸네일·선택 동작의 자동 검증과 실제 사용자의 폴더 선택·이미지 판단은 구분합니다.
