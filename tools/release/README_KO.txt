Jack O Nine Tails 2.4.0 SAnk 간소 패치

이 패치는 SAnk의 이미지·대사·QSP·UI·기능 변경분을 담습니다.
게임 본체와 외부 팩의 원본 그림·NPC 자료는 포함하지 않습니다.
올걸팩과 다른 외부 패치는 이용자가 별도로 받아 설치해야 합니다.
세이브는 포함하지 않으며 이용자의 기존 저장을 변경하지 않습니다.
새로 시작하는 이용자는 풀팩을 선택하면 됩니다.

설치 방법

설치 순서: 게임 본체 → 올걸팩과 사용할 외부 팩 전부 설치 완료 → 2.4 간소 패치(마지막).

1. 게임을 완전히 종료하고 게임 폴더와 기존 저장을 별도로 백업합니다.
2. 패치 압축을 게임 폴더와 다른 폴더에 전부 풉니다.
3. 간소패치_설치.exe를 더블클릭합니다.
4. '폴더 선택'으로 기존 게임 설치 폴더 또는 jack.qsp가 있는 game 폴더를 고릅니다.
5. 표시된 게임 경로를 확인하고 '설치 전 검사'를 누릅니다.
   검사는 게임 파일을 바꾸거나 백업 폴더를 만들지 않습니다.
6. 검사를 통과하면 '패치 설치'를 누릅니다.
   설치할 때도 다시 검사한 뒤 바뀔 기존 파일을 모두 백업합니다.
7. 완료 메시지와 백업 위치를 확인하고 '닫기'를 누른 뒤 게임을 새로 실행합니다.

'안내 보기'로 자세한 설치·문제 해결·복구 안내를 열 수 있습니다.
안내 파일은 README_INSTALL.txt입니다. 명령줄 실행 방법도 그 안에 있습니다.
설치 파일만 따로 옮기지 말고 동봉 파일과 game 폴더를 함께 두세요.
설치창은 관리자 권한을 강제로 요구하지 않습니다.

설치와 보존

설치기는 패치 파일의 손상, 필요한 외부 자료, 원본 보존과 경로 충돌을 확인합니다.
기존 NPC 정의·인덱스·세이브는 자동으로 덮어쓰지 않습니다.
동일한 패치와 필요한 보존 파일이 이미 있으면 추가 복사나 새 백업을 만들지 않습니다.

교체할 원본 그림 238개는 게임의 content\jo9o_original_cuts에 보존하고,
같은 원본 238개를 원래 그림 폴더의 '이름 (2).확장자'에 원본 B컷으로 둡니다.
이미 보존된 원본은 유지합니다. 다른 내용의 (2) 그림이 있으면 덮어쓰거나
번호를 올리지 않고 설치 전에 중지합니다. 해당 파일을 보존한 채 충돌을 확인하세요.
필요한 다른 그림 경로 111개는 이용자 게임에 이미 있는 그림을 복사해 채웁니다.
외부 원본 이미지를 패치에 동봉하거나 다른 게임·인터넷에서 가져오지 않습니다.

백업은 설치 폴더 바깥의 JO9_patch_backups\<설치 시각_고유값>에 보관합니다.
예: D:\Games\My JO9\game에 설치하면 D:\Games\JO9_patch_backups 아래에 생성합니다.
정확한 위치는 설치창에서 확인하고, rollback.json을 포함한 백업 폴더 전체를 보관하세요.
설치 도중 멈췄다면 일부 파일이 바뀌었을 수 있으므로 상세 로그와 복구 안내를 확인하세요.
자동 복구 기능은 없으며, 새로 만든 파일도 자동으로 삭제하지 않습니다.

추가 그림

추가 그림은 같은 폴더의 '이름 (2).확장자'~'이름 (4).확장자'를
다음 표시·전환부터 인식합니다. 원본 B가 (2)를 쓰면 새 그림은 (3), (4)를 사용하세요.
자동으로 확인하는 번호는 (2)~(4)까지입니다. (5) 이상은 기존에 등록된 그림만 유지하며,
새 파일을 두는 것만으로 자동 인식하지 않습니다.
게임 요소의 변경점은 CHANGELOG_KO.md에서 확인하세요.

기존 SNKmod를 사용했다면 새 QSP·CSS·JSON·정규 리소스를 모두 설치한 뒤
옛 SNKmod 폴더를 별도 보관할 수 있습니다. 폴더 이름만 바꿔 설치하지 마세요.
