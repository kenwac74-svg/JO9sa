JO9 2.4 SAnk 간소 패치 설치 안내

이 패치는 기존 게임에 SAnk의 이미지·대사·QSP·UI·기능 변경분을 설치합니다.
게임 본체와 외부 팩의 원본 그림·NPC 자료는 포함하지 않습니다.
올걸팩과 다른 외부 패치는 이용자가 별도로 받아 설치해야 합니다.
세이브는 포함하지 않으며 이용자의 기존 저장을 변경하지 않습니다.

1. 설치 준비

설치 순서: 게임 본체 → 올걸팩과 사용할 외부 팩 전부 설치 완료 → 2.4 간소 패치(마지막).

게임을 완전히 종료하고, 게임 폴더와 기존 저장을 별도로 백업하세요.
패치 압축은 게임 폴더와 다른 폴더에 전부 풉니다.
압축 안에서 바로 실행하거나 설치 파일만 따로 꺼내지 마세요.
간소패치_설치.exe, Install-Bridge.ps1, Install-Patch.ps1과
동봉 JSON 파일들·game 폴더가 함께 있어야 합니다.
설치창은 관리자 권한을 강제로 요구하지 않습니다.

2. 설치창으로 설치하기

① 간소패치_설치.exe를 더블클릭합니다.
② '폴더 선택'을 눌러 기존 게임의 설치 폴더를 고릅니다.
   jack.qsp가 있는 game 폴더를 직접 골라도 됩니다.
   설치 폴더를 고르면 그 안의 game 폴더를 자동으로 찾습니다.
   패치 압축을 푼 폴더가 아니라, 실제로 플레이하던 게임을 선택하세요.
③ 창에 표시된 게임 경로를 확인하고 '설치 전 검사'를 누릅니다.
   패치 파일, 필요한 외부 자료, 원본 그림과 경로 충돌을 검사합니다.
   이 검사는 게임 파일을 바꾸거나 백업 폴더를 만들지 않습니다.
④ 검사를 통과하면 '패치 설치'를 누릅니다.
   설치할 때도 다시 검사하고, 바뀔 기존 파일을 모두 백업한 뒤 설치합니다.
   작업 중에는 게임 실행, 패치·게임 파일 변경, 창 닫기를 피하세요.
⑤ 완료 메시지와 백업 위치를 확인하고 '닫기'를 누릅니다.
   게임을 새로 실행합니다.

'안내 보기'를 누르면 이 안내를 열 수 있습니다.
문제가 생기면 창의 결과와 상세 로그에서 해당 경로와 이유를 확인하세요.
이미 같은 패치가 설치되어 있고 필요한 보존 파일도 모두 있으면,
추가 복사나 새 백업 없이 설치된 상태라고 알려 줍니다.

3. 설치되는 파일과 보존되는 자료

설치기는 목록에 등록된 패치 파일과 이용자 게임 안의 그림 복사본만 설치합니다.
현재 배포본의 패치 파일은 1,067개입니다.
기존 NPC 정의 JSON·인덱스와 세이브는 자동 설치하거나 덮어쓰지 않습니다.
게임을 실행하거나 저장 내용을 수정하지도 않습니다.

개인 그림으로 교체할 원본 238개는 설치 전에
game\content\jo9o_original_cuts 안의 지정된 경로에 보존합니다.
이미 보존된 원본은 그대로 사용합니다. 새로 보존할 같은 경로에 서로 다른 원본이
배정되어 있으면 설치 전에 중지합니다.

보존한 원본 238개는 원래 그림 폴더의 '이름 (2).확장자'로도 복사합니다.
이 파일이 원본 B컷입니다. 기존 (2) 파일이 보존 원본과 같으면 유지합니다.
내용이 다르면 설치 전에 중지하며, 덮어쓰거나 (3)으로 바꾸지 않습니다.
이용자가 추가한 다른 컷 파일도 변경하지 않습니다.

필요한 그림 경로 111개는 이용자의 기존 게임에 있는 그림을 복사해 채웁니다.
109개는 기존 DB_BG 그림에서, 2개는 기존 SNKmod 그림에서 가져옵니다.
대상 파일이 이미 있으면 유지하며, 없을 때만 지정된 기존 그림이 필요합니다.
외부 원본 그림을 패치에 담거나 다른 게임·인터넷에서 가져오지 않습니다.

보존 원본이 없는 상태에서 현재 그림이 이미 이 패치의 개인 그림과 같으면
원본을 확보할 수 없으므로 설치 전에 중지합니다.
설치 전 백업에서 원래 그림을 복구하거나, 따로 보관한 원본을 안내된
보존 경로에 복원한 뒤 다시 검사하세요.
다른 예전 패치의 그림까지 모두 자동으로 구별할 수는 없습니다.

4. 백업 위치

바뀌는 기존 패치 대상 파일은 게임 파일을 바꾸기 전에 모두 백업합니다.
백업은 설치 폴더 바깥의 JO9_patch_backups 폴더에 저장됩니다.
각 설치마다 UTC 시각과 고유값을 붙인 하위 폴더를 사용합니다.

예를 들어 게임 파일이 다음 위치라면:
  D:\Games\My JO9\game\jack.qsp
백업 위치는 다음과 같습니다:
  D:\Games\JO9_patch_backups\<설치 시각_고유값>\

설치창에 표시되는 정확한 백업 위치를 확인하세요.
백업 폴더 안의 files에는 바꾸기 전 파일이 게임 폴더와 같은 구조로 들어 있고,
rollback.json에는 설치 경로, 파일 지문과 작업 진행 내역이 기록됩니다.
복구를 위해 하위 파일을 포함한 백업 폴더 전체를 보관하세요.

5. 검사가 멈췄을 때

설치 전 검사에서 멈춘 경우에는 백업이나 게임 파일을 만들지 않습니다.
상세 로그에 표시된 원인을 해결하고 다시 검사하세요.

· 게임 경로를 찾지 못함: jack.qsp가 있는 기존 game 폴더를 다시 선택합니다.
· 필요한 외부 그림이 없음: 해당 게임 본체·외부 팩을 먼저 준비합니다.
· 패치 파일 누락·손상: 패치 압축을 별도 폴더에 다시 전부 풉니다.
· 원본 또는 (2) 그림 충돌: 해당 파일을 보존한 채 내용을 확인합니다.
· 읽기 전용·접근 거부: 해당 폴더의 쓰기 권한과 파일 속성을 확인합니다.

바로가기처럼 다른 경로를 가리키는 연결 폴더·파일과 안전하지 않은 경로는
사용할 수 없습니다. 패치와 게임을 실제 폴더에 둔 상태로 검사하세요.
검사 후 설치까지 패치·게임 파일을 바꾸지 마세요.

6. 설치 도중 멈췄거나 되돌리고 싶을 때

설치창에는 자동 복구 기능이 없습니다. 게임을 종료하고 백업 폴더와
rollback.json을 보관하세요. 파일들을 차례로 복사하므로,
용량 부족·권한 문제·장치 오류·다른 프로그램의 파일 변경으로 중단되면
일부 파일만 설치되었거나 파일 일부만 복사된 상태일 수 있습니다.

기존 파일을 복구할 때는 다음 순서로 확인합니다.
① rollback.json에 기록된 모든 설치 예정 파일을 확인합니다.
   완료 표시가 없는 항목도 복사 도중 일부가 바뀌었을 수 있습니다.
② 현재 파일을 기록된 설치 후 SHA-256 지문과 비교합니다.
   설치 뒤 직접 바꾼 파일은 그 변경을 확인한 후 복구 여부를 정하세요.
   중단된 파일은 지문이 일치하지 않을 수 있으므로 백업과 함께 확인합니다.
③ 백업의 files\<상대경로> 파일을 게임의 같은 상대경로로 복사합니다.
   예: files\jack.qsp → 선택했던 game 폴더의 jack.qsp
④ 복구한 파일의 SHA-256 지문이 기록된 설치 전 값과 같은지 확인합니다.

새로 만든 패치 파일·그림 경로 복사본·보존 원본·원본 B컷에는 이전 파일이
없으므로, 백업을 복사해도 이 파일들은 자동으로 없어지지 않습니다.
완료 표시가 없어도 새 파일 일부가 남아 있을 수 있습니다.
설치 전처럼 파일이 없던 상태까지 되돌리려면 해당 경로를 따로 검토해야 합니다.
설치기는 파일을 삭제하거나 이동하지 않으며, 새 파일도 자동 삭제하지 않습니다.
기존 NPC 팩·세이브·보존 원본을 일괄 삭제하는 방식으로 복구하지 마세요.

7. 추가 그림

추가 그림은 같은 폴더의 '이름 (2).확장자'~'이름 (4).확장자'를
다음 표시·전환부터 인식합니다. 원본 B가 (2)를 쓰면 새 그림은 (3), (4)를
사용하세요. 자동으로 확인하는 번호는 (2)~(4)까지입니다.
(5) 이상은 기존에 등록된 그림만 유지하며, 새 파일을 두는 것만으로 자동 인식하지 않습니다.

8. 고급 사용자용: PowerShell에서 실행

설치창 대신 Install-Patch.ps1을 직접 실행할 수도 있습니다.
Windows PowerShell 5.1 이상과 기본 .NET 환경이 필요하며 Node.js는 필요 없습니다.
패치 압축을 푼 폴더에서 PowerShell을 열고 다음과 같이 실행합니다.
명령의 게임 경로는 자신의 jack.qsp가 있는 폴더로 바꾸세요.

검사만 하기:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Install-Patch.ps1" -GameDirectory "D:\Games\My JO9\game" -DryRun

설치하기:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Install-Patch.ps1" -GameDirectory "D:\Games\My JO9\game"

백업을 다른 드라이브에 저장하려면 설치 명령 끝에 다음을 붙입니다:
  -BackupDirectory "E:\JO9 backups"

백업 위치는 게임 설치 폴더 바깥이어야 합니다.
스크립트에 지정하는 GameDirectory는 반드시 jack.qsp가 있는 폴더입니다.
-DryRun과 -WhatIf는 전체 검사를 마친 뒤 게임·백업 파일을 쓰지 않고 종료합니다.

최종 JSON 결과의 backupDirectory가 정확한 백업 위치입니다.
상태값 DRY_RUN은 검사 완료, INSTALLED는 설치 완료,
ALREADY_INSTALLED는 같은 패치와 필요한 보존 파일이 이미 있는 상태를 뜻합니다.
쓰기 시작 뒤 실패하면 rollback.json의 PARTIAL_RESTORE_REQUIRED는
일부 복구가 필요할 수 있다는 뜻입니다. 이 경우 6번의 모든 항목을 확인하세요.

복구 기록의 files 항목에는 상대경로, 설치 전 oldSha256, 설치 후 sha256,
기존 파일 유무 existed, 백업 유무 backedUp, 복사 완료 여부 completed가 있습니다.
각 항목의 completed 또는 created가 false여도 중단된 파일이 남을 수 있습니다.
지문은 Get-FileHash -Algorithm SHA256 -LiteralPath "확인할 파일 경로"로 확인합니다.

9. 패키지 관리용 자료

BUILD_MANIFEST.json은 game/ 아래의 설치 대상, SHA-256 지문, 크기를 지정합니다.
모든 대상 파일은 설치 전과 복사 때 검사합니다.
original-map.json은 이용자 게임의 그림을 원본 보존 경로에 연결합니다.
original-mirror-map.json은 보존 원본을 실제 (2) 파일에 연결합니다.
resource-map.json은 이용자 게임의 기존 그림을 필요한 다른 경로에 연결합니다.
prerequisites.json은 먼저 준비되어야 할 외부 그림을 지정합니다.
외부 그림은 존재 여부를 확인하며 내용을 덮어쓰거나 특정 지문으로 제한하지 않습니다.

이번 배포본의 두 복사 경로표에는 복사 결과를 다시 원본으로 쓰는 연결이 없습니다.
원본 B 대상은 개인 패치나 다른 그림 복사 대상과 겹칠 수 없습니다.
원본 보존표의 상위 자료에는 282개 예약이 있으나, 원본 파일이 없는 44개 예약은
이번 238개 보존 대상이나 필수 원본에 포함되지 않습니다.

설치기·안내문·목록·경로표는 패치 폴더에 남으며 게임에 복사되지 않습니다.
일반 패키지에서 resource-map.json과 original-mirror-map.json은 선택 자료지만,
이번 배포본에는 둘 다 포함됩니다. 개발용 시험 파일·소스 사본·로그는 배포하지 않습니다.
